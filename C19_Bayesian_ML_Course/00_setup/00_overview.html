1这门课讲什么

欢迎来到 概率与贝叶斯机器学习。这门课只追求一件事：让你从「会用频率派的点估计」变成「能用整个后验分布思考」——并且把支撑这套范式的五个核心算法（共轭推断、MCMC、变分推断、高斯过程、概率图模型）从零用 numpy 亲手写出来。

大多数人学机器学习，学到的是频率派的一套：最大化似然、求一个最优参数 θ̂、然后用它去预测。这套方法简单有效，但它有一个结构性的盲区——它给你一个数，却不告诉你这个数有多可信。模型说「明天降雨概率 0.7」，这个 0.7 本身确定吗？训练数据只有 5 个样本和有 5 万个样本，给出同样的 0.7，但你对它的信任天差地别。频率派的点估计把这个区别抹掉了。

贝叶斯方法的核心主张是：把不确定性当成一等公民。不求单个最优参数，而是求参数的整个分布——posterior（后验分布）p(θ|D)。它回答的不是「最优参数是几」，而是「看到数据后，每个可能的参数有多可信」。有了后验，预测会自动带上不确定性、可信区间有了直接的概率解释、罕见但灾难性的可能也不会被一个点估计掩盖。这门课就是沿着「如何获得、近似、使用后验」这条主线，把贝叶斯机器学习的工具箱逐件打开、亲手重造。

学完你应当能回答这类问题（也是 ML/统计岗位的高频考点）：贝叶斯定理里的先验/似然/后验/证据各是什么，共轭为什么能给闭式解？后验没有闭式解时，MCMC 和变分推断分别怎么逼近它、各自的代价是什么？高斯过程凭什么能在没有参数的情况下做回归并给出不确定性？概率图模型怎么把一个高维联合分布的推断变得可处理？——并且能在 numpy 里把这五样东西都从零实现、和一个可信的参照对拍到数值一致。

一句方法论上的话先说在前面：本课的价值不在「调包跑个贝叶斯模型」，而在它逼你看清每个算法的内核。PyMC、Stan、GPyTorch 这些库把采样、求 ELBO、解核矩阵都包好了，方便但也成了黑箱。本课偏要把这些黑箱拆开——你会亲手写出 Metropolis 的接受率、Gibbs 的完全条件、CAVI 的坐标更新、GP 的 Cholesky 求解、变量消去的因子乘积。把这些内核搞懂，再回去用那些库，每一个旋钮（步长、链数、核选择、诱导点）你都能说出所以然——这才是不随工具过时的硬功夫。

2世界观：贝叶斯 vs 频率派

贝叶斯与频率派的分歧，归根结底是对「概率」这个词到底指什么的两种理解。这不是技术细节，而是世界观，值得先讲清楚：

维度频率派 Frequentist贝叶斯 Bayesian
概率的含义事件在无限次重复中的长程频率信念程度（degree of belief），可对一次性事件谈概率
参数 θ 是什么固定的未知常数带分布的随机变量（反映我们的不确定）
核心产物点估计 θ̂ + 置信区间整个后验 p(θ|D)
不确定性来自「重复抽样」的想象实验直接是后验的离散程度，可读出概率
区间解释95% 置信区间：重复实验 95% 会盖住真值95% 可信区间：参数有 95% 概率在此区间（更符合直觉）
先验无（只看数据）必须指定（既是优势也是争议点）

直白说

打个比方。频率派像「掷一枚硬币很多很多次，统计正面比例」——概率是客观频率。贝叶斯像「医生看一个病人，根据症状判断他患某病的可能」——这病人要么有病要么没病，没有「重复很多次」，但医生可以有一个信念程度，并随新证据更新它。贝叶斯把概率用作量化信念的语言，所以能自然地谈「这个特定参数是某值的概率」。

严谨说

形式上，贝叶斯把参数 $\theta$ 当随机变量，先赋先验 $p(\theta)$，看到数据 $D$ 后用贝叶斯定理更新为后验 $p(\theta\mid D)\propto p(D\mid\theta)p(\theta)$。频率派则视 $\theta$ 为固定常数、只通过似然 $p(D\mid\theta)$ 推断，其「不确定性」来自对假想的重复抽样的分析。两者在数据量大时常趋于一致（后验被似然主导、collapse 到 MLE 附近），分歧在小样本、需要融合先验知识、或必须量化一次性事件不确定性时最为显著。

要强调的是：本课不站队。频率派在数据充足、计算受限时简单可靠；贝叶斯在小样本、需要不确定性、需要融合多源信息、需要做风险敏感决策时更有威力。成熟的从业者两套都懂、按问题选工具。本课专攻贝叶斯这一套，是因为它更少被系统讲授、内核更值得拆解——而且它的几个核心算法（MCMC、变分推断、GP、图模型推断）本身就是现代概率机器学习与生成模型的地基。

贝叶斯最常被攻击的一点是「先验是主观的」。这个批评既对也不全对：先验确实引入主观选择，但①数据多时先验的影响会被冲淡；②频率派的「选哪个估计量、哪个检验」同样有主观成分，只是藏得更深；③现代实践用弱信息先验（weakly-informative）只做温和正则、不强行注入结论。把先验当成一个需要被检验和报告的建模假设（就像选择模型族一样），而非作弊，是健康的态度。

3课程地图：后验是一切的中心

课程地图：后验是一切的中心

本课五个内容模块，可以全部理解为围绕一个中心问题的不同回答——怎么得到后验 p(θ|D)，得不到精确的怎么办，以及拿到后验能做什么：

贝叶斯推断的中心：后验 p(θ|D) ∝ 似然 p(D|θ) × 先验 p(θ) 模块 01 贝叶斯推断与共轭 后验有闭式解的幸运情形 │ 共轭族 / MAP vs MLE / 后验预测 / 可信区间 │ 「先在能算出后验的世界里，把贝叶斯更新看透」 ▼ 当后验没有闭式解（绝大多数真实模型）——两条路： ├─ 模块 02 MCMC 用一条马尔可夫链『采样』后验（渐近精确、慢） │ Metropolis-Hastings / Gibbs / 收敛诊断 └─ 模块 03 变分推断 把推断变成『优化』一个近似 q（快、有偏） ELBO / 平均场 / CAVI / 重参数化 两类自带后验、威力强大的概率模型： ├─ 模块 04 高斯过程 函数上的先验 → 后验，自动不确定性量化 │ 核 / GP 后验 / 边际似然 / Cholesky └─ 模块 05 概率图模型 用图结构让高维联合分布的推断可处理 贝叶斯网/MRF / d-分离 / 变量消去 / 信念传播

这不是松散的专题拼盘，而是一条有内在逻辑的主线。模块 01 在「能精确算出后验」的共轭世界里把贝叶斯更新的机制看透；但现实模型几乎都没有闭式后验，于是模块 02、03 给出两条逼近后验的主路——MCMC 用采样换精度（渐近无偏但慢、要诊断收敛），变分推断用优化换速度（快且可扩展但有偏）。这两者的权衡贯穿整个现代贝叶斯计算。模块 04、05 则是两类自身就以概率为骨架的强大模型：高斯过程把贝叶斯推断搬到无限维的函数空间，概率图模型则用条件独立结构让原本指数爆炸的高维推断变得可算。

每一个模块都对应一个可独立验证的能力，而且都用「对拍一个可信参照」来兜底：模块 01 你的共轭更新会逐位等于解析后验；模块 02 你的 MCMC 样本的均值/方差会收敛到真分布的矩；模块 03 你的 CAVI 会与 MCMC 的后验一致；模块 04 你的 GP 后验会等于 Cholesky 闭式解；模块 05 你的变量消去会等于暴力枚举的边缘。每一步都有 assert 兜底，绝不靠「感觉对了」。

4方法论：从零 numpy 并对拍解析解

方法论：纯 numpy 从零，并与解析解对拍

本课全程纯 numpy、CPU 可跑，刻意不用 PyMC/Stan/sklearn/GPyTorch。原因和「学写 GPU 内核不必有 GPU」是一样的：贝叶斯算法的难点从来不是 API，而是数学结构——接受率怎么来保证正确平稳分布、ELBO 怎么推、完全条件怎么求、核矩阵怎么稳定求解。这些用 numpy 在玩具规模上能精确地表达和验证。

贯穿全课的纪律是对拍（differential testing）：每个算法都和一个绝对可信的参照比对。这一点对贝叶斯计算尤其重要，因为它的 bug 极其阴险——一个 MCMC 采样器即使接受率公式写错、平稳分布根本不对，它照样会吐出一堆看起来像样的样本，不会报错。只有把它的输出和一个已知正确的东西比，错误才会现形。

模块你写的算法对拍的可信参照判据
01共轭后验更新（numpy）解析后验 / 网格数值积分参数逐位相等、归一化积分≈1
02Metropolis-Hastings / Gibbs目标分布的解析矩 / 共轭后验样本均值方差→真值
03平均场 CAVIMCMC 后验 / 解析后验后验均值/方差一致、ELBO 单调
04GP 回归（手写 Cholesky 路径）闭式预测方程 / 噪声→0 时插值数据预测均值方差 allclose
05变量消去 / 信念传播暴力枚举联合分布求边缘边缘分布 allclose、和为 1

直白说

我们把每个贝叶斯算法翻译成 numpy 里看得见的东西：共轭更新就是几行参数加减，MCMC 就是一个状态在循环里游走，CAVI 就是几个分布参数交替更新，GP 就是解一个线性系统，变量消去就是数组的乘和求和。你写的是机制，规模小到能一眼看懂、能和手算对上。

严谨说

关键判据是 np.allclose(算法输出, 可信参照, atol=...)。共轭后验必须逐位等于解析公式；MCMC 的样本矩必须收敛到解析矩（在蒙特卡洛误差内）；变量消去的边缘必须等于对联合分布暴力求和。结构正确 → 数值一致；数值一致 → 你的推断逻辑是对的，可以放心迁移到真实的 PPL 上。

为什么把「对拍」提到方法论的高度？因为贝叶斯计算里「看起来收敛了」和「真的对了」是两回事。一条没收敛的 MCMC 链、一个抓错峰的变分近似、一个消去顺序写错的图推断，都会给出貌似合理但其实错误的后验。在玩具问题上，我们恰好有绝对可信的 ground truth（解析后验、暴力枚举、闭式解），任何偏差都会被 assert 当场抓住。本课每个算法都先有参照、再写实现、立刻对拍——这套「先有真相，再验证」的纪律，正是真实贝叶斯建模中（用 prior/posterior predictive check、用 $\hat R$ 诊断）工作流的精神内核，只是我们在更干净的环境里把它练成肌肉记忆。

务必清楚本课不教什么：不教 PyMC/Stan 的 API 语法、不追求大规模/高性能、不写自动微分（梯度都手推或用解析式）、不做生产级采样器的工程优化（如 NUTS 的树构建）。这些在你有了正确的数学直觉后是第二步（references 里的 Stan/PyMC/GPyTorch 接手）。本课负责把第一步——数学机制与正确性夯死；这一步搞定，调库才不是抄咒语。

环境与运行

环境极简：只需 numpy（画后验图、采样轨迹可选 matplotlib）。全课 CPU 秒级运行，无需 GPU、无需 PyMC/Stan/torch/sklearn。

conda create -n bayes-ml python=3.11 -y && conda activate bayes-ml
pip install numpy            # 必需
pip install matplotlib       # 可选，仅用于画后验/采样轨迹/GP 带状图
jupyter lab

每个模块配一个 notebook，结构统一：先用 numpy 把算法从零实现并对拍（5–6 个 worked 小节，每节都跑出可打印的验证与 assert），再做 3–4 道带 assert 自测的 ✏️ 练习（先给骨架自己填，再对照 📖 参考答案），最后一个真实数据/真实模型胶囊（用真实公开数据或真实配置算一笔账，把纸面知识接到现实，带联网回退到内置真实数值）。

建议的学习节奏：先读完整章 HTML 建立直觉与数学框架，再打开 notebook 亲手实现。读和做缺一不可——只读会觉得「公式好像懂了」，真正动手写采样循环、推完全条件、让 ELBO 单调上升、让 assert 通过时，才会发现魔鬼藏在哪些细节里（未归一化常数、对数空间防溢出、精度加权、数值正定）。这门课的深度正是为「动手」服务的。

配套先读：Bishop《PRML》当主线教材（第 2/8/10/11 章 + 第 6 章 GP）、Gelman《BDA》补实践智慧、Blei 2017 变分综述、Rasmussen & Williams《GPML》（GP 必读、免费）、Koller & Friedman《PGM》（图模型权威）。完整清单见 references.md。

✅ 学完整门课，你应该能：
  1. 从贝叶斯定理出发推导共轭后验，分清 MAP / MLE / 后验均值，写出后验预测分布与可信区间；
  2. 从零实现 Metropolis-Hastings 与 Gibbs 采样，用 $\hat R$、ESS、自相关诊断收敛，讲清细致平衡为何保证正确性；
  3. 推导 ELBO、在平均场假设下导出并实现 CAVI 更新，说清 VI 相对 MCMC 的偏差-速度权衡；
  4. 从核出发实现 GP 回归（Cholesky 路径），算后验均值/方差与对数边际似然，并用它优化超参；
  5. 用 d-分离判定条件独立，实现变量消去与信念传播，并对拍暴力枚举的边缘；
  6. 把上述每个 numpy 实现对应到 PyMC/Stan/GPyTorch 的内部机制，知道调库时每个旋钮在做什么。
