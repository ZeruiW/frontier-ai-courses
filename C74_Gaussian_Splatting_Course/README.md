# C74 · 3D 高斯溅泼（3DGS）与实时渲染

> 6 个模块 · 6 个 notebook · 24 道带自测的练习 · 纯 numpy / CPU / 离线

## 这门课在回答什么

**3DGS 为什么能把 NeRF 的秒级渲染做到毫秒级？**

答案不是「更快的网络」。它把表示换成了一堆**显式的、可光栅化的**基元，
而整条链路的效率追到底来自**一个量级差**：

> 它的基元 α 大（0.1–0.9）而不是小（0.01–0.05）。

α 大 ⟹ 每像素只要十几个基元、可以提前终止省掉 92%，
但**必须显式排序**并接受「tile 内共享顺序」的近似。
其余一切——协方差的参数化、仿射投影、密度控制、球谐——
都是为了让这个量级差能被优化出来。

## 方法论：为什么不训练真实场景

本课 notebook 会**从零写出一个能出图的 tile 光栅化器**（模块 03），
但它不训练任何真实场景。理由是 3DGS 的关键设计几乎都由**结构性质**决定：

- 「α 合成是顺序相关的」是一个恒等式的性质；
- 「RSSᵀRᵀ 恒正定」是一个定理；
- 「前 19 个高斯就让像素饱和」是一个几何级数的计算；
- 「仿射投影的误差由张角决定」是一次泰勒展开的余项；
- 「大张角下投影协方差不存在」是一个矩的收敛性问题。

这些都不需要优化收敛，而它们恰好是「为什么必须排序」「为什么这样参数化」
「为什么能实时」的全部答案。

**代价说清楚，两条**：
① 本课不能回答「3DGS 的重建质量有多好」——那需要真实多视角数据与几十分钟的优化；
② 模块 04 关于密度控制的结论是**机制性**的（各操作改变什么、增长率的量级），
而不是「这套超参数最好」。

## 本课程的四处诚实修正

写作过程中有四个我原本以为对、被自己的实验推翻的结论。它们都留在课里：

1. **「α 合成的离散化误差 ∝ 1/N」是错的** —— 实测每翻一倍降到 1/4.00，是 **∝ 1/N²**（中点法则二阶）。
   顺带发现了更强的结论：对分段常数密度，α 合成是**精确**的，连 N=1 都对（模块 01）。
2. **「仿射近似在离轴处失效」抓错了主变量** —— 主变量是**张角**。
   而在大张角下，它要对比的那个「真值」（投影后的协方差）**根本不存在**（模块 02）。
3. **「暴力实现与 tile 实现关掉两个近似后应逐位相等」漏了一个近似** ——
   还有第三个：3σ 包围盒是**tile 对齐**的，tile 版对该 tile 里每个像素都求值。
   补上之后才真正逐位相等，而这个近似本身的影响是 0.50 个 8 bit 色阶（模块 03）。
4. **「尺度梯度比位置梯度更适合当密度判据」是单次运行的假象** ——
   第一次只跑一个目标一个种子时它命中 67%，跑满 6 次取均值是 28%，
   而在每一档都在随机基线之下（模块 04）。

## 验收清单里包含本课自己不通过的项

和 C72 / C73 一样，本课的自测里有几处是**本课的配置自己达不到**的：

- 模块 03：`render_tiles` 在本课的合成场景上只省 **76.5%**（而理想上界是 92.2%），
  因为该场景 α 偏小且大片背景永不饱和。notebook 明确打印了这个落差。
- 模块 04：判据在 K=8 时的 top-1/4 命中率**恰等于随机基线**，自测直接断言这一点。
- 模块 05：SH deg 3 对本课列出的四种材质里的三种**完全表示不了**。

这不是失误，是设计：验收清单要能抓住真实的疏漏，包括作者的。
