## 一、体渲染与 α 合成（模块 01）

| 术语 | 一句话 | 本课的量 |
|---|---|---|
| **体密度 / 消光系数** volume density, σ | 单位长度上光被吸收或散射掉的概率。**有量纲（m⁻¹）**，可以任意大，与步长无关 | 与 α 的量纲不同：混淆两者是一类很难查的 bug |
| **透射率** transmittance, T | 从起点走到某处还没被挡住的比例。$T(t) = \exp(-\int\sigma)$，指数形式是一阶微分方程 $\mathrm dI/\mathrm dt = -\sigma I$ 的解 | $T$ 是**路径**性质，而 σ 是**局部**性质 —— 这个区别就是「必须排序」的全部原因 |
| **不透明度** opacity, α | $\alpha_i = 1-\exp(-\sigma_i\delta_i)$。**无量纲**、夹在 $(0,1)$、**依赖步长** | 3DGS 直接存 α，所以它**没有步长概念**（模块 01 §7） |
| **α 合成** alpha compositing | $C = \sum_i T_i\alpha_i c_i$，$T_i = \prod_{j<i}(1-\alpha_j)$。与 Porter–Duff（1984）逐字相同 | **对分段常数 σ 精确到机器精度，连 $N{=}1$ 都对**（$N{=}1$ 误差 0，$N{=}256$ 是 8.9e−16）|
| **中点法则** midpoint rule | 在每段**中心**取 σ 与 c，而不是端点 | 误差 ∝ 1/N²（比值 4.00）；左端点法则只有一阶（比值 2.00）—— **一个细节换一整个收敛阶** |
| **顺序相关性** order dependence | α 合成不可交换。8 个基元、2000 次随机置换的最大通道偏差 | $\alpha\in[0.3,0.9]$ 中位 **0.2929**；$[0.1,0.7]$ **0.1961**；$[0.01,0.05]$ 只有 **0.0027**（差 73 倍）|
| **顺序敏感度的 α² 律** | 一阶展开里顺序只出现在二阶项，所以敏感度 $\propto\alpha^2$ | **只在小 α 极限成立**：等效指数从小 α 端的 1.94 退化到 α≈0.4 时的 1.55 |
| **提前终止** early termination | $T < T_{\min}$ 时停止。丢掉的量**严格小于** $T_{\min}\cdot\max c$ | 245 个高斯里只处理 **19** 个（省 92.2%），误差 2.4e−5（远低于 1/255）|
| **不透明度饱和** | 累积不透明度 $1-T$ 单调趋于 1。达 99% 所需个数 $= \lceil\ln(0.01)/\ln(1-\alpha)\rceil$ | α=0.1→44 个；0.2→21；0.3→**13**；0.5→7 —— 不管 α 多少，都是「几十个」量级 |
| **累积不透明度** accumulated alpha, A | $A = \sum_i T_i\alpha_i = 1 - T_{\text{final}}$，$\in[0,1)$ | 用途：合成背景、当前景 mask、当深度图的**置信度** |
| **未归一化期望深度** $D_{\text{raw}}$ | $\sum_i w_i t_i$，$w_i = T_i\alpha_i$ | **恒等式 $D_{\text{raw}} = A\cdot D_{\text{norm}}$，所以相对偏差恒等于 $-(1-A)$**。一个 α=0.9 的高斯在 10 m 处给出 **9.0 m** |
| **归一化深度** $D_{\text{norm}}$ | $D_{\text{raw}}/A$ | 无偏，但 A 小的地方分母噪声被放大 —— 实践中两张都输出，用 A 屏蔽（常见阈值 A>0.5）|
| **中位深度** median depth | 使归一化累积权重首次达 0.5 的基元深度 | 对「薄雾 + 实心表面」这种双峰分布比均值稳，网格提取（C75）常用它 |
| **后缀累加** suffix accumulation | 反向传播需要 $S_{>i} = \sum_{k>i}T_k\alpha_k c_k$，所以必须**从远到近**走 | 前向从近到远累积 T、反向从远到近累积 S —— 这个「一来一回」是官方 CUDA 内核的核心结构 |

## 二、高斯基元与投影（模块 02）

| 术语 | 一句话 | 本课的量 |
|---|---|---|
| **各向异性高斯** anisotropic Gaussian | $\sigma(x) = \alpha\exp(-\frac12(x-\mu)^\top\Sigma^{-1}(x-\mu))$，$\Sigma$ 有 6 个自由度 | 轴长比 100:100:1 的高斯就是一个「有厚度的面片」，而表面在真实场景里占绝大多数 |
| **协方差的参数化** | **不存 $\Sigma$**，存 $(s, q)$ 再算 $\Sigma = RSS^\top R^\top$ | 直接存 6 分量：扰动 0.01 → **71.4% 非正定**，扰动 0.10 → **94.3%**。而 RSSᵀRᵀ 恒为 **0%** |
| **正定性是恒等式** | $\Sigma = MM^\top$，$M = RS$ 满秩 ⟹ $v^\top MM^\top v = \Vert M^\top v\Vert^2 > 0$ | 「把约束写进参数化」这个手法在 3DGS 里用了三次：$\log s$、四元数、$\alpha$ 的 logit |
| **四元数不加归一化约束** | `quat_to_R` 内部先归一化，所以 $q$ 与 $\lambda q$ 给出同一旋转 | **梯度在模长方向上的分量为 0**（相对占比 1e−17 量级）—— 所以模长会漂移但无害，不需要 renormalize |
| **仿射近似 / EWA splatting** | 在高斯中心把透视投影线性化：$\Sigma' = J\Sigma J^\top$ | $J$ 的第三列 $(-fx/z^2, -fy/z^2)$ **在光轴上恰为零** —— 光轴上的高斯，深度延展不影响屏幕形状 |
| **投影雅可比** projection Jacobian | $J = [[f/z, 0, -fx/z^2], [0, f/z, -fy/z^2]]$ | 官方把 $J$ 与外参 $W$ 合成一个 $2\times3$：`T = W * J; cov2D = Tᵀ Vrk T` |
| **张角** subtended angle | $\theta = 2\arctan(\sigma/z)$ —— 高斯在屏幕上占多大角度 | **仿射近似失效的主变量**：0.92°→22.62°（24.6 倍）把误差放大 **100 倍**，而离轴 0°→45° 最多 1.6 倍 |
| **投影协方差不存在** | 张角大时高斯有一部分质量在 $z\le0$，$z\to0^+$ 的样本被投到无穷远 ⟹ 二阶矩积分**发散** | 53.13° 张角（2.28% 质量在后方）：$n$ 从 1e4 到 1e6 估计值涨 **9 倍**，种子间差 **3 倍**。**这不是精度问题，是类型问题** |
| **有界的质量口径** | 真实样本落在「仿射 3σ 椭圆」内的比例，理论值 $1-e^{-4.5} = 98.889\%$ | 张角 0.92° → +0.02%；11.42° → −0.41%；22.62° → **−2.04%**；53.13° → **−13.20%** |
| **conic** | 存 $\Sigma'^{-1}$ 的三个独立分量 $(a,b,c)$，而不是 $\Sigma'$ | 渲染阶段每个高斯只需 9 个数（uv 2 + conic 3 + α 1 + RGB 3）= 36 字节 |
| **低通 / 膨胀滤波** dilation | `cov[0][0] += 0.3f; cov[1][1] += 0.3f;` | **尺寸相关**：45 px 的高斯足迹 ×1.000148，0.15 px 的 **×14.33**。$\det(\Sigma'+dI) = \det\Sigma' + d\,\mathrm{tr}\Sigma' + d^2$ |
| **3σ 包围半径** | `ceil(3*sqrt(max(λ1,λ2)))` | 3σ 覆盖 98.889% 的质量，但该处 α 衰减因子 0.0111 = **2.8 个 8 bit 色阶** —— 高不透明度高斯会有可见硬边。4σ 才降到 1 个色阶以下，但面积变 1.78 倍 |
| **近平面剔除** near-plane culling | `if (p_view.z <= 0.2f) return;` | **数值上的必需**：离轴高斯在 $z{=}0.03$ 时长半轴比 $1/z$ 超出 **6.74 倍**（因为 $J$ 第三列 ∝ $1/z^2$）。而它剔的是**中心**深度 |
| **2DGS** | 把基元换成 2D 椭圆面片（2 轴 + 法向），射线-平面**精确求交** | 仿射近似问题整体消失；法向显式；但表示不了体积性物质（烟、雾、毛发）|
| **Mip-Splatting** | 把常数 0.3 换成随采样率变化的滤波 | 解决「训练分辨率下调好、换分辨率就掉」的问题 |

## 三、tile 光栅化（模块 03）

| 术语 | 一句话 | 本课的量 |
|---|---|---|
| **tile** | 16×16 的屏幕块。GPU 上一个 tile = 一个 block，一个像素 = 一个线程 | 1920×1080 → $120\times68 = $ **8160** 个 tile（1080/16 = 67.5，最后一行只用 8 行像素）|
| **(高斯, tile) 对** | 分箱产生的条目数 $P$，是后面所有成本的规模 | 50 万高斯 @ 8 px → **2.00 M**（每 tile 245.1）；@ 20 px → 6.12 M（750.6）。$P/N = 4.0$ |
| **覆盖 tile 数** | $\approx (2r/T_s + 1)^2$ | 半径 8→20（2.5 倍）让 $P$ 涨 **3.06 倍**；一个 100 px 的高斯抵 **44** 个正常高斯 |
| **64 位排序键** | `key = (tile_id << 32) \| depth_bits`，一次基数排序同时按 tile 与深度排好 | 基数排序 $O(P)$ vs 比较排序 $O(P\log P)$：$P{=}2$M 时 $\log_2 P = 20.9$ |
| **深度的位重解释** | 正 float32 的位模式与数值**同序**，所以按 uint32 排序 == 按 float 排序 | 零精度损失。**但只对正数成立** —— 它依赖近平面剔除，两个看似无关的细节是耦合的 |
| **深度量化的碰撞** | 线性量化后不同深度落到同一个键，相对顺序变**未定义** | 0.5–100 m 范围：16 位 **68.75%**、20 位 9.15%、24 位 0.585%、32 位 **0.0025%** |
| **顺序不变性检查** | 打乱输入**数组**顺序（不是深度顺序），输出应不变 | 这条测试能抓住排序键的相等项，而只看 PSNR 它表现为莫名的 0.5 dB 损失 |
| **两层提前终止** | 线程级（某像素饱和后自己 break，省算术）与 block 级（整 tile 都饱和才停止载入，省访存）| **后者才是省时间的主项**，而它要求整 tile 一起饱和 —— 一个像素看天空就全泡汤 |
| **popping** | 相机转动时顺序在某角度突然翻转，画面「跳一下」 | 3DGS 排的是**中心深度**，不是逐像素前后关系。逐像素排序要多排 **254 倍**次，所以 StopThePop 用分层折中 |
| **负载不均衡** load imbalance | 整帧时延由**最慢的那个 tile** 决定 | 平滑分布 **2.67×**；含近处大物体的场景 **8.67×**。空 tile 5–8% |
| **tile 对齐的包围盒** | tile 版对该 tile 里**每个**像素求值，不做逐像素包围盒测试 | 这是第三个近似（容易漏）。去掉它的影响是 **0.50 个 8 bit 色阶** |
| **每帧操作计数** | 预处理 $O(N)$、分箱/排序/载入 $O(P)$、渲染 $O(\text{像素}\times\text{每 tile 处理数})$ | 50 万高斯：0.50M / 2.00M / 16.0M 次扫描 / 72 MB 访存 / 渲染 508M（不终止）或 **39M**（终止）|
| **tile 尺寸的取舍** | $P \propto (2r/T_s+1)^2$ 而 tile 数 $\propto 1/T_s^2$，两者方向相反 | 8×8：$P$ ×2.25 而列表长 ×0.57；32×32：$P$ ×0.56 而列表长 ×2.25。**只有剪枝能真正降成本** |
| **atomicAdd 冲突** | 反向是「一个像素 → 多个高斯」，写地址高度重合 | 8 px 的高斯覆盖 **201** 个像素。官方先在 block 内共享内存归约，把 201 次降到「覆盖的 tile 数」次（约 4 次）|
| **反向必须重放终止点** | 前向记 `last_contributor`，反向 `if (contributor > last_contributor) continue;` | 否则被完全遮挡的高斯收到非零梯度，长成「看不见但吃内存」的浮物 |

## 四、密度控制（模块 04）

| 术语 | 一句话 | 本课的量 |
|---|---|---|
| **自适应密度控制** adaptive density control | 按梯度克隆/分裂、按不透明度与屏幕半径剪枝 | 把 SfM 的 ~10 万点长到 100–500 万个高斯 |
| **屏幕位置梯度判据** | $\Vert\partial L/\partial\mu_{2D}\Vert_2$ 在最近 100 步的平均，超过 $2\times10^{-4}$ 就触发 | **中等密度区秩相关 +0.63~+0.68、top-1/4 命中率 44–56%（基线 25%）；而稀疏区命中率恰等于基线，且有运行给出 −0.262** |
| **为什么是位置梯度** | 它是**向量**，模长大意味着「被不同方向拉扯」= 一个高斯在试图表示两处内容 | 尺度梯度在每一档都在基线之下（3–28%）；不透明度梯度从 K=8 的 0% 涨到 K=32 的 48% |
| **累积窗口** | 官方在 100 步上平均，densify 后清零 | 全程窗口秩相关 +0.678（极差 0.150），最后 100 步 +0.520（**极差 0.618，宽 4.1 倍**）—— **长窗口主要降的是方差** |
| **欠重建 / 过重建** under- / over-reconstruction | 判据触发后按「尺度是否 > 1% 场景尺度」二选一 | 小的 → 克隆（东西不够多）；大的 → 分裂（东西太粗）|
| **克隆** clone | 复制一份，沿位置梯度平移，**尺度不变** | 总体积 **×2.000** |
| **分裂** split | 生成 2 个，尺度 **÷1.6**，位置从父高斯的分布里**采样** | 单个体积 ÷4.10，总体积 **×0.4883**。临界 $\varphi = 2^{1/3} = 1.2599$。子高斯自动沿父高斯长轴分布（方向从协方差免费继承）|
| **percent_dense** | 克隆/分裂的分界：0.01 × 场景尺度 | — |
| **剪枝阈值** | $\alpha < 0.005$ 删掉；屏幕半径 > 20 px 或世界尺度 > 10% 场景范围删掉 | **256 个 α=0.005 叠出 0.7229** —— 按可见性该定在 2e−5（小 100 倍），所以 0.005 的含义更接近「优化器不再有效使用它」|
| **max_screen_size** | 屏幕半径超过 20 px 就剪 | 本课出现三次、三个理由：仿射近似（3.82° 张角）、分箱成本（100 px 抵 44 个）、几何补偿 |
| **不透明度重置** opacity reset | 每 3000 步把所有 α 压到 $\min(\alpha,0.01)$ | **与剪枝成对**：真正需要的会长回来，浮物不会。会让 PSNR 暂时掉几 dB —— 那是正常的 |
| **优化器状态必须置零** | 新高斯的 Adam 一/二阶动量填 0 | 从父高斯继承会让两个子高斯**朝同一方向跑**，与分裂的目的相反。而置零意味着训练是「145 次带预热的重启」 |
| **增长率** growth rate | $p = (N_{\text{final}}/N_{\text{init}})^{1/15} - 1$ | 要 20× 需每轮 **+22.1%**；**增长率涨 25% 终值涨 1.94 倍** —— 指数敏感 |
| **Pixel-GS** | 按覆盖**像素数**加权再平均（改梯度的聚合方式）| — |
| **Mini-Splatting** | 先长大再按重要度**采样**压回预算（改控制方式：阈值 → 预算）| — |
| **3DGS-MCMC** | 总数**固定**，克隆/分裂/剪枝换成重定位 + 噪声注入（改框架）| — |

## 五、外观与动态（模块 05）

| 术语 | 一句话 | 本课的量 |
|---|---|---|
| **球谐** spherical harmonics, SH | 方向函数 $c(\mathbf d)$ 的一组正交基。系数个数 $3(\ell+1)^2$ | deg 3 → **48** 个系数、每高斯 **59** floats、**SH 占 81%**、几何只占 18.6% |
| **烘死的出射辐射** baked radiance | SH 存的是「从这个方向看是什么颜色」，**不是材质** | 所以不能重打光。而这是**选择**：分解光照与材质是欠定的逆渲染问题 |
| **$+0.5$ 与 clamp** | `color = Σ k·Y + 0.5`，然后 clamp 到 $[0,1]$ | +0.5 让「系数全零」= 中性灰而非黑；**clamp 让饱和处梯度为零** → 死白斑块，加迭代不改善 |
| **阶数渐进提升** | 每 1000 步把 active_sh_degree +1，从 0 到 3 | 依据：球面均值恰等于 deg 0 项（正交性），所以低阶决定整体亮度、高阶只是修饰 |
| **SH 的角分辨率** | 流行说法 $180^\circ/(\ell+1)$ | **高估约 1.45 倍**。实测（20% 相对残差）是 $125^\circ/(\ell+1)$：deg 2/3/4/8 分别 43.3° / **31.2°** / 24.6° / 13.5° |
| **表示不了镜面高光** | 材质的高光半角远小于 SH 的能力 | 粗糙塑料 29.5°（deg3 残差 0.239，勉强）；抛光塑料 12.3°（**不能**）；漆面 7.5°；抛光金属 3.4°。**要表示抛光塑料需 deg 9，内存变 5.3 倍** |
| **浮物** floaters | 悬在空中、不对应真实几何的高斯 | 三个来源：观测不足（数据问题）、补偿位姿误差（上游问题）、被遮挡高斯仍收梯度（实现问题）|
| **浮物的检测** | ① 从训练集**之外**的视角渲一张；② 看 A 的空间分布；③ 与 LiDAR/MVS 深度对比 | 训练视角（±15° 弧）图像差 **0.0003**（0.08 色阶），25° 留出视角 **0.6300** —— 落差 **2100 倍** |
| **4DGS** | 3DGS 加时间维度 | 逐帧独立 300 帧（10 s @30fps）= **70.8 GB**；3 阶多项式轨迹 = 92 floats = **0.368 GB**（省 **192 倍**）|
| **SH 静态假设** | 几乎所有 4DGS 工作都让 SH 不随时间变 | 代价是表示不了「灯被打开」「阴影扫过物体」。动态 SH 是静态的 **4 倍**内存 |
| **压缩的两类手段** | ① 量化（改每个数占几个字节）；② 按需分配 SH 阶数（改有多少个数）| 可乘：95% 降 deg0 + SH int8 + 几何 fp16 → **31.2 B/高斯 = 基线的 0.132×** |
| **压缩的正确顺序** | 先剪高斯 → 再降 SH 阶 → 最后量化 | 剪高斯同时降存储、排序与渲染成本；量化只降存储 |
| **位置用 fp16 的坑** | fp16 相对精度 ~1e−3 | 100 m 场景里远端误差 **9.8 cm**，而高斯尺度常只有几厘米。正确做法是分块量化（每格 fp32 原点 + 格内 int16 偏移）|

## 六、六种不该用 3DGS 的情况（模块 05 §7）

| 需求 | 为什么不行 | 该用什么 |
|---|---|---|
| 重打光 / 换环境 | 光照被烘进 SH，没有材质与法向的分解 | GaussianShader / Relightable 3DGS，或传统 PBR |
| 精确表面几何 / 网格 | 第三个轴永远压不到 0（$+0.3I$ 挡着），厚度是假的、法向不明确 | **2DGS** 或 SDF 类方法；见 C75 |
| 泛化到新场景 | 3DGS 是**拟合**方法，参数不可迁移 | 前馈重建（LRM / DUSt3R / Splatter Image）；见 C75 |
| 视角很少（< 10 张）| 观测不足直接产生浮物，而这不是算法能修的 | 生成式先验（多视角扩散 + SDS）；见 C75 |
| 透明 / 折射物体 | α 合成是「吸收 + 自发光」模型，**没有折射**，光线是直的 | 光线追踪；或把玻璃当成一层视角依赖贴图（近似）|
| 极低端设备 | 需要 GPU 的基数排序与共享内存 | 烘出网格 + 贴图，走标准移动端管线（这条路径被低估了）|

## 七、本课的四处诚实修正

| 我原本以为 | 实测 | 在哪 |
|---|---|---|
| α 合成的离散化误差 ∝ 1/N | **∝ 1/N²**（比值 4.00）。而对分段常数密度它是**精确**的，连 $N{=}1$ 都对 | 模块 01 |
| 仿射近似在**离轴**处失效 | 主变量是**张角**；而大张角下要对比的「真值」**根本不存在** | 模块 02 |
| 关掉两个近似后暴力版与 tile 版应逐位相等 | 还有**第三个**近似：3σ 包围盒是 tile 对齐的（影响 0.50 个色阶）| 模块 03 |
| 尺度梯度比位置梯度更适合当判据 | 单次运行的假象。6 次均值下它在每一档都在随机基线之下 | 模块 04 |
