1体渲染积分：三个物理量与一个微分方程

先把式子写出来，再解释它每一部分从哪来。沿一条从相机出发的射线，位置用 $t$ 参数化，像素颜色是

\[C = \int_{t_n}^{t_f} T(t)\,\sigma(t)\,c(t)\,\mathrm{d}t,\qquad T(t) = \exp\Bigl(-\int_{t_n}^{t}\sigma(s)\,\mathrm{d}s\Bigr)\]
量名字单位物理含义
$\sigma(t)$体密度 / 消光系数 (volume density)$\mathrm{m}^{-1}$单位长度上光被吸收或散射掉的概率。注意它不是「不透明度」，量纲都不同
$c(t)$自发光颜色 (emitted radiance)无量纲（辐射度）这一点朝相机方向发出的颜色。3DGS 里它是球谐的求值结果（模块 05）
$T(t)$透射率 (transmittance)无量纲，$\in(0,1]$从 $t_n$ 走到 $t$ 还没被挡住的比例。它是一个累积量，这一点决定了后面的一切

$T$ 的指数形式不是假设，是一个一阶微分方程的解

考虑一束强度 $I$ 的光走过一小段 $\mathrm{d}t$。「密度」的定义就是：这一段里被吸收掉的比例是 $\sigma\,\mathrm{d}t$。所以

\[\frac{\mathrm{d}I}{\mathrm{d}t} = -\sigma(t)\,I(t)\;\Longrightarrow\; I(t) = I(t_n)\exp\Bigl(-\int\sigma\Bigr)\]

直白说

把这件事想成「一段一段地活下来」。穿过第一段活下来的概率是 $1-\sigma\delta$，第二段又是 $1-\sigma\delta$……走 $N$ 段活下来的概率是 $(1-\sigma\delta)^N$，而 $N\to\infty$ 时它就是 $e^{-\sigma L}$。指数来自「独立事件的连乘」，而不是任何经验拟合。

严谨说

而积分里的 $T(t)\sigma(t)$ 这个乘积有一个概率解释，它是本模块后面全部结论的来源：$T(t)\sigma(t)\,\mathrm{d}t$ 是「光子恰好在 $t$ 处第一次被吸收」的概率密度（活着走到 $t$ × 在 $t$ 处被吸收）。所以 $C$ 是「第一次碰撞点的颜色」的期望，而 $\int T\sigma\,\mathrm{d}t = 1 - T(t_f) \le 1$——它是一个可能有「漏光」的概率分布，漏掉的那部分 $T(t_f)$ 就是背景。

一句话记住三个量的关系：$\sigma$ 是局部的性质（这一点有多密），$T$ 是路径的性质（前面挡了多少），$C$ 是期望。「$T$ 依赖路径」正是「必须排序」的全部原因——第 3 节会把这句话量出来。

2离散化：为什么它叫 α 合成，以及一个精确性结论

把射线切成 $N$ 段，第 $i$ 段长 $\delta_i$、密度 $\sigma_i$、颜色 $c_i$。在这一段内把 $\sigma$ 和 $c$ 当常数，那么这一段的「被吸收概率」是

\[\alpha_i = 1 - \exp(-\sigma_i \delta_i)\;\in(0,1)\]

而走到第 $i$ 段之前的透射率是前面各段「活下来」概率的乘积。于是

\[C = \sum_{i=1}^{N} T_i\,\alpha_i\,c_i,\qquad T_i = \prod_{j

直白说

这个式子和图形学里 30 年前的 α 合成（Porter–Duff, 1984）逐字相同。把一叠半透明胶片从前往后叠起来，就是这个公式。所以「体渲染」与「α 合成」不是两件事：α 合成是体渲染积分在分段常数假设下的离散形式，而 $\alpha_i = 1-e^{-\sigma_i\delta_i}$ 是两者之间唯一的翻译。

严谨说

而 $\alpha$ 与 $\sigma$ 的区别值得单独记一下，因为混淆它们会导致一类很难查的 bug。$\sigma$ 有量纲（$\mathrm{m}^{-1}$）、可以任意大、与步长无关；$\alpha$ 无量纲、被夹在 $(0,1)$、依赖步长。NeRF 的网络输出 $\sigma$，所以换采样步长时 $\alpha$ 自动跟着变；3DGS 直接存 $\alpha$，所以它没有步长这个概念——这是两者最实质的一个差别，第 6 节会说清后果。

对分段常数密度，α 合成是精确的——连 $N{=}1$ 都对

$\sigma$、$c$ 在长度 $L$ 上恒定时，积分有闭式解 $C = c\,(1-e^{-\sigma L})$。把这段均分成 $N$ 段做 α 合成：

\[\sum_{i=1}^{N} (1-\alpha)^{i-1}\alpha c= c\,\alpha\,\frac{1-(1-\alpha)^N}{\alpha}= c\bigl(1-(1-\alpha)^N\bigr) = c\bigl(1-e^{-\sigma L}\bigr)\]

这个结论把「离散化误差」的来源锁死在唯一一处：$\sigma$ 或 $c$ 在一段之内发生变化。α 合成本身不引入任何误差，$N$ 也不需要大。而当 $\sigma$ 沿射线变化时，中点法则的误差是 $\propto 1/N^2$（二阶），不是 $\propto 1/N$——notebook 量到每翻一倍 $N$ 误差降到 1/4.00。这解释了为什么 NeRF 用 64+128 个采样点就够了：二阶收敛下，把 64 加到 128 只换来 4 倍精度，边际收益极快地耗尽。

两个区间差了 73 倍。而这不是巧合，可以一阶展开看出来：$\alpha$ 都很小时 $T_i = \prod_{j它与顺序无关，顺序只影响二阶项 $\sum_{i}\sum_{j。所以顺序敏感度是 $O(\alpha^2)$，而 $\alpha$ 从 0.03 涨到 0.4 是 13 倍，平方后约 180 倍——量级对得上。

严谨说

于是两种方法在「排序」上的处境完全不同。NeRF 沿射线行进，采样点天然按 $t$ 单调，顺序是免费的；而且它的 $\alpha$ 很小，就算错了也不致命。3DGS 把成千上万个高斯投影到屏幕上，它们在内存里的顺序与深度毫无关系，而每个高斯的 $\alpha$ 又大——所以它必须显式地按深度排序，而这个排序就是模块 03 里最贵的一步（50 万高斯要排 200 万个键）。

一个必须说清的诚实之处：3DGS 排的是「高斯中心的深度」，而不是「每个像素上的真实前后关系」。两个相互穿插的椭球，在某些像素上 A 在前、在另一些像素上 B 在前，但它们在整个 tile 里只有一个顺序。这是 3DGS 的一个已知近似，它在相机转动时会造成「弹跳」（popping）——顺序在某个视角突然翻转，画面跳一下。后续工作（StopThePop, 2024）用逐像素或分层排序来缓解，代价是速度。

4饱和与提前终止：实时性的第一来源

$T_i$ 是单调递减的乘积。一旦它足够小，后面所有基元的贡献 $T_i\alpha_i c_i$ 都被压到可忽略——**可以直接停下来**。累积不透明度 $1-T$ 的增长：

直白说

「达 99% 需要多少个」有闭式解：$n = \lceil \ln(0.01)/\ln(1-\alpha)\rceil$。它对 $\alpha$ 是对数依赖，所以 $\alpha$ 从 0.1 涨到 0.5（5 倍）只把 $n$ 从 44 降到 7（6.3 倍）——两者大致成反比。关键的量级是：不管 $\alpha$ 多少，都是「几十个」，而不是「几百个」或「几个」。

严谨说

而模块 03 会量出：1920×1080 下每个 tile 平均要处理 245 个高斯。而在 $T_{\min}{=}10^{-4}$ 的判据下，notebook 量到只需处理 19 个 —— 92.2% 的工作可以被提前终止省掉。这是 3DGS 实时性最大的一块来源，而它完全是 $T_i$ 单调递减这个结构性质带来的。注意它是逐 tile生效的：天空那样的 tile 只有几个高斯，近处物体的 tile 会在第 19 个左右停下，而最坏情况（一整 tile 都是低 $\alpha$ 的雾）不会终止——所以提前终止改善的是平均而不是最坏时延。

代价：它是一个近似，而且是有界的

在 $T < T_{\min}$ 时停下，丢掉的是 $\sum_{i \ge k} T_i\alpha_i c_i$。因为 $T_i \le T_k < T_{\min}$ 且 $\sum_{i\ge k}\alpha_i \prod(1-\alpha) \le 1$，所以丢掉的量 **严格小于** $T_{\min}\cdot\max_i c_i$。

所以 $T_{\min}$ 直接就是误差上界，可以按需要选。官方实现用 $T_{\min} = 10^{-4}$，对应最大误差 $10^{-4}$——远小于 8 bit 显示的 1/255 ≈ 0.0039，所以视觉上完全无损。而顺带一个 float32 的坑：$\alpha=0.3$ 时 256 个高斯后 $T = 2.2\times10^{-40}$，已经下溢为 0——所以提前终止不只是优化，它还避免了在下溢的 $T$ 上继续做无意义的乘法。

5反向传播：为什么必须从后往前走

训练要 $\partial C/\partial\alpha_i$ 与 $\partial C/\partial c_i$。颜色那一项很简单：

\[\frac{\partial C}{\partial c_i} = T_i\,\alpha_i\]

$\alpha_i$ 那一项不简单，因为 $\alpha_i$ 同时出现在**自己这一项**里，又出现在**后面所有** $T_k$（$k>i$） 里：

\[\frac{\partial C}{\partial \alpha_i} = T_i c_i - \frac{1}{1-\alpha_i}\underbrace{\sum_{k>i} T_k \alpha_k c_k}_{S_{>i}}\]

直白说

第二项的形状决定了实现方式：它需要「$i$ 之后所有项的和」。所以反向传播必须从最远的基元往近处走，一边走一边累加 $S_{>i}$。前向从近到远累积 $T$，反向从远到近累积 $S$——这个「一来一回」是 3DGS 那个 CUDA 内核的核心结构，而它意味着反向传播必须知道前向的顺序，所以排序结果要么存下来、要么重算。

严谨说

而 $1/(1-\alpha_i)$ 是个明显的病态点。$\alpha_i \to 1$ 时它发散：$\alpha=0.99$ 时是 100，$\alpha=0.9999$ 时是 $10^4$。真实实现有两道防线：① $\alpha$ 存成 logit 过 sigmoid，永远到不了 1；② 官方内核不算 $1/(1-\alpha)$，而是在反向走的过程中顺便把 $T$ 也反推回来——它保存前向结束时的 $T_{\text{final}}$，然后每退一步做一次除法恢复 $T_i$，把病态限制在同一个量上而不是每项都乘一次。

这里有一个真实会遇到的坑：反向传播必须重放提前终止。如果前向在第 19 个高斯停了，反向却对全部 245 个求梯度，那些被跳过的高斯会收到本该是零的梯度——结果是被完全遮挡的高斯也在被优化，它们会长成「看不见但吃内存」的浮物。官方内核的做法是：前向记下每个 tile 实际处理到第几个，反向只走那么多。

6同一条积分的两个副产物：累积不透明度与深度图

体渲染积分不只产出颜色。同一组权重 $w_i = T_i\alpha_i$ 换一个被加权的量，就得到 3DGS 实际会输出的另外两张图：

\[A = \sum_i w_i = 1 - T_{\text{final}},\qquad D_{\text{raw}} = \sum_i w_i\, t_i,\qquad D_{\text{norm}} = \frac{\sum_i w_i t_i}{\sum_i w_i}\]
量是什么用途
$A$ = 累积不透明度 (accumulated alpha)「这条射线一共被挡住了多少」，$\in[0,1)$合成背景：$C_{\text{final}} = C + T_{\text{final}}\cdot C_{\text{bg}}$；也直接当前景 mask 用；训练时常加一项让它逼近 0/1，逼表示变「实心」
$D_{\text{raw}}$ = 未归一化期望深度$w_i$ 加权的深度它有偏，见下
$D_{\text{norm}}$ = 归一化深度除以 $A$ 之后的加权平均深度深度监督、法向估计、导出网格（C75）、与 LiDAR 对齐

$D_{\text{raw}}$ 的偏差有闭式形式，而且不小

取最简的情形：**一个** $\alpha=0.9$ 的高斯，位于 $t=10\,\mathrm{m}$。那么 $w_1 = 0.9$，于是 $D_{\text{raw}} = 0.9\times 10 = 9.0\,\mathrm{m}$——**偏小 1 m，而真相只有一个表面、深度毫无疑义。**

\[D_{\text{raw}} = A\cdot D_{\text{norm}}\;\Longrightarrow\; \text{偏差} = -(1-A)\cdot D_{\text{norm}}\]

直白说

规律很干净：$D_{\text{raw}}$ 的相对偏差就是 $-(1-A)$，所以它只在射线被完全挡住（$A\to1$）时才正确。而「被完全挡住」恰恰是训练早期不成立的情形——那时候高斯还稀、$\alpha$ 还小，$A$ 可能只有 0.6。于是一个很常见的现象有了解释：用未归一化深度做监督时，早期的深度损失会把高斯往相机方向拉，因为减小 $t$ 与增大 $A$ 对这个损失是等效的，而前者更容易。

严谨说

但归一化也不是免费的：$A$ 很小的地方（天空、物体边缘）$D_{\text{norm}}$ 的分母接近 0，噪声被放大。实践中的做法是两者都输出，并用 $A$ 当置信度把低 $A$ 的像素屏蔽掉（常见阈值 $A>0.5$ 或 $0.9$）。还有第三种口径：$w$ 的中位数深度（表格里 20 个 $\alpha=0.2$ 时是 10.150）——它对「一层薄雾 + 一个实心表面」这种双峰分布比均值稳，所以在做网格提取时（C75）常用它而不是均值。

三个口径会给出不同的数，而它们都叫「深度图」。比较两份 3DGS 的深度结果、或把 3DGS 深度与 LiDAR 对齐时，先确认口径一致——上表第二行里 $D_{\text{raw}}$ 与 $D_{\text{norm}}$ 差了 3.7 m，这个量级足以让任何评测结论翻转。

直白说

第三行是最容易被忽略但最有后果的一条。3DGS 没有步长，等价于说它放弃了「同一段物质、不同采样密度应给出同样结果」这个性质。在 NeRF 里，把 64 个采样点换成 128 个，渲出的图基本不变（第 2 节：误差 $\propto 1/N^2$）；在 3DGS 里，把一个高斯换成两个体积各半的高斯，渲出的图会变，因为 $\alpha$ 不是从密度算来的。

严谨说

而这恰好是模块 04 里「分裂」这个操作起作用的机制：分裂不是「等价变换 + 更细的表示」，它真的改变了渲染结果，所以分裂之后必须继续优化才能收敛回去。反过来说，这也是 3DGS 的表示能力比「体密度场 + 固定采样」更强的地方——它可以用一个大高斯精确表示一层硬边的表面，而基于密度的方法要在那里放很陡的 $\sigma$，进而需要很密的采样。

$\alpha$ 大还有一个不在渲染速度上的后果：它让损失曲面更陡。$\partial C/\partial c_i = T_i\alpha_i$，而 $T_i$ 随 $\alpha$ 增大而更快衰减——所以前几个基元的梯度很大、后面的几乎为零。于是 3DGS 的优化天然是「近处先收敛、远处后收敛」的，而被完全遮挡的高斯几乎收不到梯度（这既是它能快速收敛的原因，也是浮物问题的来源之一——模块 05 第 5 节）。
带走这一条：本模块的公式对 NeRF 与 3DGS 是同一条，两者的差别全在「基元是什么」以及由此带来的 $\alpha$ 量级。$\alpha$ 大 ⟹ 必须排序、可以提前终止、每像素只要十几个基元；$\alpha$ 小 ⟹ 顺序无所谓、不能提前终止、每像素要几百个采样。3DGS 的实时性，追到底就是这一个量级差。
