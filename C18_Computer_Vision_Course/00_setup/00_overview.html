1为什么单开一门「核心 CV」

现代 AI 的图像能力大多来自两类课程：一类讲卷积神经网络架构（如何搭 conv/池化/残差，C15 的主题），一类讲视觉-语言多模态（把图像接进大模型）。但夹在中间、最基本、也最常被跳过的，是核心 CV 任务本身——给一张图，你要分类、检测、分割、或无监督地学它的表示，以及配套的一整套评测口径（IoU / NMS / mAP / Dice / mIoU / linear probe）。

这门课就补这块地基。它不重复 C15 的网络架构，而是聚焦CV 任务与算法：从最低层的滤波与边缘，到分类、检测、分割，最后到自监督表示学习。每个概念都用纯 numpy 从零写出来，因为只有亲手实现一遍 IoU、NMS、mAP、Dice、InfoNCE，你才能在读检测/分割/SSL 论文、审检测器评测代码时一眼看出它对不对。

一句话定位本课：C15 教你「卷积网络怎么搭」，本课教你「视觉任务怎么定义、怎么解、怎么评」。两者拼起来才是完整的视觉能力。这门课的全部代码都是 numpy/CPU，目标是看懂机制，不是刷 SOTA 精度。

2CV 四大任务地图

核心 CV 可以按「输出粒度」排成一条从粗到细的谱系。理解这条谱系，就理解了后面五个模块的脉络：

任务输入→输出粒度核心指标本课模块
分类 classification整图 → 一个标签整图accuracy / 混淆矩阵 / top-k02
检测 detection整图 → 多个(框, 类, 分)物体IoU / NMS / mAP03
语义分割 segmentation整图 → 每像素一个标签像素Dice / mIoU04
自监督 SSL无标签图 → 通用表示表示linear probe05

它们不是孤立的。低层视觉（模块 01 的滤波/边缘/梯度）是一切的基础——HOG 特征靠梯度、检测的早期方法靠边缘、分割的连通域靠形态学。而自监督（模块 05）则反过来：它不需要标签，先学一个好表示，再喂给前面任何一个任务。所以本课的顺序是低层 → 分类 → 检测 → 分割 → 自监督，由简到繁、层层依赖。

粒度由粗到细 ─────────────────────────────────────► 整图标签 物体框 像素掩码 [分类 02] ──► [检测 03] ──► [分割 04] ▲ ▲ ▲ └──── 低层视觉(滤波/边缘/梯度) 01 ────┘ ← 共同地基 └──── 自监督表示(SimCLR/MAE) 05 ───────┘ ← 无标签预训练，喂给上面任一任务

评测口径是本课的硬核。检测的 mAP、分割的 mIoU/Dice 不是「准确率」那么简单——它们涉及 IoU 阈值、PR 曲线、类平均等一连串约定。用错口径，论文复现就对不上数。模块 03/04 会把这些指标一行行从零写出来并验证性质。

3真实数据与离线回退

本课坚持用真实公开数据：分类/检测/分割/自监督用 UCI optdigits（8×8 手写数字，1797 张，小到可以纯 numpy 处理），低层视觉用经典的 Grace Hopper 照片（matplotlib 自带示例图）。真实数据让你看到算法在真图上的真实行为，而非精心构造的玩具。

但研究环境常常没有网络。所以每个 notebook 都遵循一条纪律：先 try 联网加载真实数据，失败就回退到逻辑等价的合成图，且两条路径下所有 assert 都成立。比如 optdigits 拉不到，就用 numpy 画几个带结构的数字状斑块；Grace Hopper 拉不到，就合成一张带边缘、渐变、纹理的灰度图。算法逻辑与验证完全不依赖数据来源。

数据缓存在 ~/.cv_data/。完整数据出处与每个算法对应的奠基论文（Canny、HOG、AlexNet、R-CNN/Fast/Faster R-CNN、YOLO、FCN、U-Net、SimCLR、MAE）见 references.md，建议边学边对照原文。

4怎么学这门课

每个模块是固定的三段式：① 读这份 HTML 讲解，建立动机 → 直觉 → 数学 → 实现 → 陷阱 → 前沿的完整链条；② 打开同名 notebook，跟着 5–6 个 worked 小节从零把算法敲出来、看 print 和 assert 验证；③ 做 3–4 道 ✏️ 练习（给你 TODO 骨架，紧跟一个 assert 自测判分），卡住了再看 📖 参考答案；最后一节 🧪 真实数据胶囊，把算法用到真图上。

学习建议：先自己写练习再看答案；每个 assert 失败都是一次精确的反馈。全部代码纯 numpy/CPU，秒级可跑，鼓励你改参数、改输入，观察指标怎么变——这比记结论有用得多。

本模块没有配套练习，环境检查 notebook 只确认 numpy 可用、真实数据能加载（或正确回退）。确认无误后，从模块 01 滤波与边缘开始正式旅程。
