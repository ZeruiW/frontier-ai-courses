# 术语词典 · Glossary（计算机视觉）

> 按主题分组，每条 2–3 句中文释义、英文术语保留原文（论文与代码库的通用语言）。读 Canny / HOG / R-CNN / YOLO / U-Net / SimCLR / MAE 等论文遇到生词回这里查。本课全部用 numpy 在 CPU 上从零实现这些概念，术语与真实 CV 系统一一对应。


## 图像与卷积基础 · Images & Convolution

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| image / channel | 图像 / 通道 | 图像是形状 (H,W) 的灰度数组或 (H,W,3) 的 RGB 数组；通道指颜色或特征平面。本课多用 8×8 灰度 optdigits 与单通道 Grace Hopper 以便从零计算。 |
| pixel intensity | 像素强度 | 单个像素的亮度值，常归一化到 [0,1] 或 [0,255]。CV 算法几乎都建立在对邻域像素强度的局部运算上。 |
| kernel / filter | 卷积核 / 滤波器 | 一个小窗口权重矩阵（如 3×3），滑过图像做加权求和实现模糊、锐化、求梯度等。核的形状与权重决定它检测或增强什么结构。 |
| convolution | 卷积 | 把核翻转 180° 后与图像逐位相乘求和的运算，满足结合律/交换律，是线性平移不变系统的数学形式。深度学习里的 conv 实为相关（不翻转）。 |
| cross-correlation | 相关 | 与卷积相同但核不翻转。CNN 框架（PyTorch/TF）的 conv 层实际做的是相关；对对称核两者结果相同。 |
| padding | 填充 | 在图像边界外补像素（补零 zero、复制 replicate、镜像 reflect），使输出尺寸可控、边界不丢信息。'same' 填充保持输出与输入同尺寸。 |
| stride | 步幅 | 核每次滑动的像素数。步幅 >1 会下采样、缩小输出分辨率，是 CNN 里替代池化做降采样的常用手段。 |
| receptive field | 感受野 | 输出某一点所依赖的输入区域大小。堆叠多层小核或加大步幅都能扩大感受野，决定网络能看到多大范围的上下文。 |
| separable filter | 可分离滤波 | 二维核能写成两个一维核外积（如高斯）时，可拆成先行后列两次一维卷积，把代价从 O(k²) 降到 O(2k)。 |

## 边缘与梯度 · Edges & Gradients

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| image gradient | 图像梯度 | 强度变化的方向与速率，由 ∂I/∂x、∂I/∂y 估计；梯度幅值大的地方即边缘。Sobel/Prewitt 是常用的离散梯度算子。 |
| Sobel operator | Sobel 算子 | 带平滑的离散梯度核：水平核 [[-1,0,1],[-2,0,2],[-1,0,1]] 估 ∂I/∂x，转置估 ∂I/∂y。比单纯差分更抗噪。 |
| gradient magnitude / direction | 梯度幅值 / 方向 | 幅值 √(gx²+gy²) 衡量边缘强度，方向 atan2(gy,gx) 给出边缘法线朝向。Canny 与 HOG 都以这两个量为基础。 |
| Gaussian blur | 高斯模糊 | 用高斯核加权平均做平滑，抑制高频噪声；σ 越大越糊。求边缘前先高斯平滑可避免噪声被误判为边缘。 |
| box filter | 盒滤波 | 权重全为 1/k² 的均值滤波，最简单的平滑，可用积分图 O(1) 实现，但有振铃、不如高斯各向同性。 |
| Canny edge detector | Canny 边缘检测 | 经典五步边缘算法：高斯平滑→求梯度→非极大抑制→双阈值→滞后连接。在定位精度与抗噪间取得最优折中，至今是基线。 |
| non-maximum suppression (edges) | 非极大抑制(边缘) | 沿梯度方向只保留局部最大的像素，把粗边细化成一像素宽的脊线。与检测里的 NMS 同名但作用对象不同。 |
| hysteresis thresholding | 双阈值滞后 | 用高/低两个阈值：高于高阈值的是强边、保留；介于两者间的弱边只有连到强边才保留，抑制断裂与噪点。 |
| morphology (erosion/dilation) | 形态学(腐蚀/膨胀) | 用结构元对二值图做集合运算：腐蚀缩小前景、膨胀扩大前景；开运算去小噪点、闭运算填小洞，常用于清理边缘/掩码。 |

## 手工特征 · Hand-crafted Features

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| feature descriptor | 特征描述子 | 把图像区域编码成对光照/小形变更稳健的向量，供分类器使用。深度学习前 CV 识别的核心工程。 |
| HOG (Histogram of Oriented Gradients) | 方向梯度直方图 | 把图像分 cell，每 cell 统计梯度方向的加权直方图，再按 block 归一化。Dalal & Triggs 用它+SVM 做行人检测，是经典强特征。 |
| SIFT | 尺度不变特征变换 | 在尺度空间检测关键点并给出旋转/尺度不变的局部描述子，用于匹配与拼接。Lowe 2004 提出，长期是图像匹配的黄金标准。 |
| color / intensity histogram | 颜色 / 强度直方图 | 统计像素值分布作为全局特征，简单但对空间结构不敏感；常作为基线或与其他特征拼接。 |
| bag of visual words | 视觉词袋 | 把局部描述子聚类成「视觉词」，用词频直方图表示图像，是深度学习前的主流图像表示。 |
| normalization (L2 / contrast) | 归一化(L2/对比度) | 对特征向量做 L2 或局部对比度归一，消除光照与尺度差异。HOG 的 block 归一化是其鲁棒性的关键来源。 |

## 分类与评估 · Classification & Evaluation

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| image classification | 图像分类 | 给整张图预测一个类别标签，是 CV 最基础任务。ImageNet + AlexNet(2012) 引爆深度学习浪潮。 |
| linear classifier / softmax | 线性分类器 / softmax | 用 Wx+b 打分、softmax 归一成概率、交叉熵训练。是分类的最简起点，也是理解 logits/概率的基础。 |
| MLP (multilayer perceptron) | 多层感知机 | 全连接层+非线性堆叠的分类头，能学非线性决策边界。本课在手工特征上接 MLP 做分类。 |
| data augmentation | 数据增强 | 对训练图做平移/旋转/翻转/加噪等保标签变换，人为注入不变性、扩大有效样本量、抗过拟合。 |
| confusion matrix | 混淆矩阵 | C[i,j]=真类 i 被预测为 j 的样本数。对角线是正确数，非对角揭示哪些类易混，比单一准确率信息量大得多。 |
| accuracy / precision / recall | 准确率 / 精确率 / 召回率 | 准确率=整体对的比例；精确率=预测为正中真正的比例；召回率=真正例中被找出的比例。类不平衡时后两者比准确率更可信。 |
| top-k accuracy | top-k 准确率 | 真标签落在概率最高的前 k 个预测中即算对。ImageNet 常报 top-5，宽容地评估近似正确。 |
| F1 score | F1 分数 | 精确率与召回率的调和平均 2PR/(P+R)，在二者间取平衡，适合类不平衡下的单一汇总指标。 |
| overfitting / regularization | 过拟合 / 正则化 | 模型记住训练噪声、泛化变差；用权重衰减、数据增强、早停等抑制。CV 小数据上尤需正则。 |

## 目标检测 · Object Detection

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| object detection | 目标检测 | 在图中同时定位（边界框）并分类多个物体，输出一组 (框, 类, 置信度)。比分类多了「在哪、有几个」。 |
| bounding box | 边界框 | 用 (x1,y1,x2,y2) 或 (cx,cy,w,h) 框住物体的矩形。检测的回归目标与评估单位。 |
| IoU (Intersection over Union) | 交并比 | 两框交集面积 ÷ 并集面积 ∈[0,1]，衡量框的重合度。判定检测命中（如 IoU≥0.5）、NMS 去重、匹配 GT 都靠它。 |
| NMS (non-maximum suppression) | 非极大抑制 | 检测后处理：按置信度排序，保留最高分框、删掉与它 IoU 过高的冗余框，逐个进行，去除重复检测。 |
| anchor box | 锚框 | 在特征图每个位置预设的一组不同尺度/长宽比的参考框，检测器只需回归相对锚框的偏移，简化定位学习。 |
| sliding window | 滑动窗口 | 用固定窗口在图上密集滑过、逐位置分类的朴素检测范式。简单但慢，是理解检测的起点，被 anchor/proposal 取代。 |
| region proposal | 候选区域 | 先用启发式或网络（RPN）生成可能含物体的少量区域，再分类/回归，避免穷举滑窗。R-CNN 系列的核心。 |
| precision-recall curve | 精确率-召回率曲线 | 按置信度阈值扫描得到的 (recall, precision) 轨迹，反映检测器在不同工作点的表现。 |
| AP / mAP | 平均精度 / 均值平均精度 | AP=PR 曲线下面积（单类），mAP=各类 AP 的均值，是检测的总指标。常报 mAP@0.5 或 COCO 的 mAP@[.5:.95]。 |
| confidence score | 置信度 | 检测框为真且类别正确的预测概率，用于排序、NMS 和 PR 曲线扫描。 |

## 图像分割 · Segmentation

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| semantic segmentation | 语义分割 | 给每个像素分配一个类别标签（如「猫/草/天空」），同类不同实例不区分。输出与输入同分辨率的标签图。 |
| instance segmentation | 实例分割 | 在语义分割基础上区分同类的不同个体（猫1/猫2），每个实例一张掩码。Mask R-CNN 是代表。 |
| mask | 掩码 | 标记某区域归属的二值或多值图，1 表示属于该类/实例。分割的输出与评估单位。 |
| Dice coefficient | Dice 系数 | 2|交|/(|预测|+|真值|) ∈[0,1]，对前景小、类不平衡更敏感，是医学分割的常用指标。与 IoU 关系 Dice=2·IoU/(1+IoU)。 |
| mIoU (mean IoU) | 平均交并比 | 各类别 IoU 的平均，语义分割的标准总指标（如 Cityscapes、PASCAL VOC）。比像素准确率更抗类不平衡。 |
| connected components | 连通域 | 二值图中相邻（4 或 8 邻接）的前景像素聚成的区域，用并查集/泛洪标记。把语义掩码切成实例的基础。 |
| thresholding (Otsu) | 阈值分割(大津法) | 选一个灰度阈值把图分前景/背景；Otsu 自动选使类间方差最大的阈值。最简单的分割。 |
| encoder-decoder | 编码器-解码器 | 编码器逐步下采样提取语义、解码器逐步上采样恢复分辨率的结构，是稠密预测（分割/深度）的通用骨架。 |
| U-Net / skip connection | U-Net / 跳连 | 对称编解码 + 把编码器各层特征跳连到解码器对应层，融合高分辨率细节与高层语义。医学分割的奠基结构。 |
| transposed convolution / upsampling | 转置卷积 / 上采样 | 把低分辨率特征放大回高分辨率的操作（转置卷积、双线性插值、unpooling），解码器恢复空间分辨率的手段。 |
| class imbalance | 类不平衡 | 分割中背景像素远多于前景，朴素交叉熵会偏向背景；用 Dice loss、加权交叉熵、focal loss 缓解。 |

## 自监督学习 · Self-supervised Learning

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| self-supervised learning (SSL) | 自监督学习 | 不用人工标签，靠数据自身构造的代理任务（pretext）学通用表示，再迁移到下游。解决标注昂贵的问题。 |
| contrastive learning | 对比学习 | 拉近同一图不同增强视图（正对）的表示、推远不同图（负对）的表示，从而学到对增强不变的语义表示。SimCLR/MoCo 的范式。 |
| SimCLR | SimCLR | Chen 2020 的简单对比框架：强数据增强 + 投影头 + 大批量内的 NT-Xent 损失，证明对比学习无需特殊结构即可逼近监督预训练。 |
| InfoNCE / NT-Xent | InfoNCE / NT-Xent 损失 | 对比损失：把正对相似度当分子、与所有负对相似度求 softmax，等价于在「一堆候选里认出正样本」的交叉熵。温度 τ 调节难度。 |
| temperature (τ) | 温度系数 | InfoNCE 里给相似度除的标量，越小越强调难负样本、梯度越尖锐。是对比学习的关键超参。 |
| positive / negative pair | 正对 / 负对 | 正对=同一图的两个增强视图（语义相同）；负对=不同图（语义不同）。对比学习的监督信号全部来自这种成对关系。 |
| masked autoencoder (MAE) | 掩码自编码器 | He 2022：随机掩掉大部分（如 75%）图块，让编码器只看可见块、解码器重建被掩块的像素。生成式自监督的代表，预训练高效。 |
| masking ratio | 掩码比例 | MAE 中被遮挡块的比例。图像冗余高，需高比例（~75%）才让重建任务足够难、表示足够有用，这与 NLP(BERT 15%) 不同。 |
| pretext / downstream task | 代理 / 下游任务 | 代理任务（对比、重建）用于无标签预训练；下游任务（分类、检测）用少量标签评估或微调学到的表示。 |
| linear probe (evaluation) | 线性探针(评估) | 冻结自监督学到的表示，只在其上训一个线性分类器，用准确率衡量表示的线性可分质量。SSL 论文的标准评测协议。 |
| representation collapse | 表示坍缩 | 自监督中所有输入被映射到同一点（损失虚低但无信息）的退化。对比学习靠负对、BYOL/SimSiam 靠停梯度/预测头避免它。 |
| data augmentation invariance | 增强不变性 | 训练目标让表示对裁剪/颜色抖动/翻转等增强保持不变，从而捕捉与这些扰动无关的语义。增强的选择直接决定学到什么不变性。 |

## 方法论与本课定位 · Methodology

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| ground truth | 真值标注 | 人工标注的正确答案（标签/框/掩码），用于训练与评估。本课在合成数据上构造已知真值以验证算法正确。 |
| held-out / train-test split | 留出 / 训练-测试划分 | 把数据分成训练与测试两部分，只在测试集报指标，避免用见过的数据高估性能。 |
| toy / synthetic data | 玩具 / 合成数据 | 小规模、结构已知的人造数据，便于逐步验证算法逻辑正确（assert 兜底）。本课所有机制先在合成数据上写对再上真实图。 |
| CPU-first / from scratch | CPU 优先 / 从零实现 | 全部用纯 numpy 在 CPU 上实现，不依赖深度学习框架，追求「看懂机制」而非性能或 SOTA 精度。 |
