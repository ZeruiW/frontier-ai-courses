# 术语词典 · Glossary（负责任 AI 与社会影响评测）

> 按主题分组，每条 2–3 句释义。读公平/毒性/隐私/危害文献遇到生词回这里查；英文术语保留原文（社区与论文的通用语言）。本课全部用 numpy/pandas 在 CPU 上从零实现这些量，术语与真实评测一一对应。

## 公平性总论 · Fairness Foundations

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| algorithmic fairness | 算法公平 | 研究自动决策系统是否对不同群体造成系统性不利的领域。核心难点是「公平」有多个互相冲突的形式化定义，没有单一正确答案，必须结合场景与价值判断选择。 |
| protected attribute / sensitive attribute | 受保护属性 / 敏感属性 | 法律或伦理上不应据以区别对待的属性，如种族、性别、年龄、宗教。公平评测按它切分子群；但它常缺失或需推断，本身带来隐私与代理变量问题。 |
| group fairness | 群体公平 | 要求某个统计量（选中率、错误率、校准）在不同受保护群体间相等的一类定义。与个体公平相对，是本课的主线，因为它可直接从混淆矩阵算出。 |
| individual fairness | 个体公平 | 「相似的个体应得到相似的对待」[Dwork 2012]。理论优雅但需要一个有争议的「相似度度量」，实践中难以操作，故本课聚焦群体公平。 |
| disparate treatment | 差别对待 | 直接将受保护属性用于决策（显式歧视）。法律上较易识别；但即使不使用该属性，模型仍可能经由代理变量产生差别影响。 |
| disparate impact | 差别影响 | 看似中立的规则对某群体产生系统性不利后果（即使无歧视意图）。常用「80% 规则」(four-fifths rule)粗判：弱势组选中率 < 优势组的 80% 即可能构成差别影响。 |
| proxy variable | 代理变量 | 与受保护属性高度相关、可间接编码它的特征（如邮编代理种族）。删掉敏感属性不能消除偏见，因为模型会从代理变量重建它，这叫「fairness through unawareness 的失败」。 |
| base rate | 基率 | 某群体中正类（如真正会还款、真正有毒）的实际比例。当两群体基率不同，多个公平定义在数学上无法同时满足——这是不可能定理的根源。 |

## 群体公平定义 · Group Fairness Criteria

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| demographic parity / statistical parity | 人口均等 / 统计均等 | 要求各群体的正预测率相等：P(Ŷ=1 \| A=a) 与组无关。直白即「选中比例一样」。缺点是无视真实标签，可能强迫错误率不均、或被「凑数」式选人满足。 |
| disparate impact ratio | 差别影响比 | 弱势组与优势组正预测率之比，= P(Ŷ=1\|弱)/P(Ŷ=1\|强)。是人口均等的连续版度量，<0.8 常被视为预警线（80% 规则）。 |
| equal opportunity | 机会均等 | 要求各群体真阳率(TPR/recall)相等：P(Ŷ=1 \| Y=1, A=a) 与组无关 [Hardt 2016]。只看「真正合格者被选中的比例」是否公平，常比人口均等更贴合「不漏掉好人」的诉求。 |
| equalized odds | 均等几率 | 同时要求各群体 TPR 与 FPR 都相等 [Hardt 2016]。比机会均等更强：合格者被选中的率、不合格者被误选的率都要跨组一致，是分配公平里最常用的强条件。 |
| predictive parity / predictive value parity | 预测均等 | 要求各群体的正预测值(PPV/precision)相等：P(Y=1 \| Ŷ=1, A=a) 与组无关 [Chouldechova 2017]。即「被判为正的人里真为正的比例」跨组一致，关注被判定者承担的错误。 |
| calibration / calibration within groups | 校准 / 组内校准 | 要求在每个预测分数 s 上，各群体的真实正类比例都等于 s：P(Y=1 \| score=s, A=a)=s。即「打 0.7 分的人里七成真为正」对每个组都成立，是把分数当概率用的前提。 |
| sufficiency | 充分性 | 给定预测分数后，标签与受保护属性条件独立：Y ⟂ A \| score。校准是其特例。与「分离性」(separation)相对，两者一般不能同时满足。 |
| separation | 分离性 | 给定真实标签后，预测与受保护属性条件独立：Ŷ ⟂ A \| Y。等价于 equalized odds。是与充分性对立的另一族公平观。 |
| treatment equality | 处置均等 | 要求各群体的假阴/假阳比(FN/FP)相等。从「两类错误的相对负担」角度刻画公平，较少用但在某些刑事司法语境被讨论。 |

## 不可能定理与权衡 · Impossibility & Trade-offs

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| impossibility theorem (fairness) | 公平不可能定理 | [Kleinberg 2016; Chouldechova 2017] 证明：当两群体基率不同且分类器非完美时，校准、TPR 均等、FPR 均等三者一般无法同时成立。意味着「公平」必须取舍，不能全都要。 |
| COMPAS | —— | 美国再犯风险评估工具，引发公平争议的经典案例。ProPublica 指其对黑人 FPR 更高（违反 equalized odds）；开发方反驳它是组内校准的——双方都对，正是不可能定理的现实写照。 |
| fairness-accuracy trade-off | 公平-准确率权衡 | 施加公平约束通常要牺牲一些整体准确率。权衡的大小取决于数据与约束强度，需在「整体效用」与「群体公平」间显式定夺，没有免费的公平。 |
| post-processing / threshold adjustment | 后处理 / 阈值调整 | 在已训练模型的分数上，为不同群体设不同决策阈值以满足某个公平准则 [Hardt 2016]。实现简单、不需重训，但「按组用不同阈值」本身在法律与伦理上有争议。 |
| pre-/in-/post-processing | 前/中/后处理缓解 | 公平缓解的三个阶段：改数据(reweighing/重采样)、改训练(加公平正则/对抗)、改输出(调阈值)。各有取舍，本课评测视角侧重度量与后处理。 |
| Pareto frontier (fairness) | 帕累托前沿 | 在「准确率—某公平差距」平面上不被支配的解集合。报告前沿而非单点，能让决策者看到取舍空间，是负责任评测的好实践。 |

## 毒性与内容危害 · Toxicity & Content Harms

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| toxicity | 毒性 | 「粗鲁、不尊重或不合理、会让人想退出讨论」的文本(Perspective API 定义)。是主观、依语境与标注者的构念，没有绝对真值——这使毒性评测本身充满测量学陷阱。 |
| Perspective API | —— | Jigsaw/Google 的毒性打分服务，输出 0–1 概率。是业界最广用的毒性基线，但已知对含身份词(尤其边缘群体)的中性句给出偏高分。 |
| Civil Comments / Jigsaw Unintended Bias | —— | 带毒性标注与身份标注的真实评论数据集(Kaggle 竞赛)。专为度量「毒性模型对身份群体的意外偏差」设计，是本课模块 02 的真实数据来源。 |
| unintended bias (toxicity) | 意外偏差 | 毒性模型把仅仅提及某身份(如 "I am a gay man")的中性文本误判为有毒 [Dixon 2018]。根源是训练数据里身份词与毒性标签的伪相关，按身份词切分 FPR 即可暴露。 |
| identity term | 身份词 | 指代某人群的词(gay、muslim、black、woman 等)。审计毒性模型时按是否含某身份词切分子群、比较假阳率，是发现意外偏差的标准操作。 |
| false positive rate (FPR) gap | 假阳率差距 | 不同子群被误判为正(有毒)的比率之差。在毒性语境，某身份子群 FPR 偏高 = 该群体的正常发言更易被误删，是内容审核公平的核心伤害指标。 |
| background positive, subgroup negative (BPSN) AUC | 背景正/子群负 AUC | Jigsaw 偏差度量之一：把「背景的有毒样本」与「含某身份的无毒样本」混在一起算 AUC。值低说明模型容易把该身份的无毒文本排得比真有毒文本还高(即对该身份过度敏感)。 |
| BPSN / BNSP / subgroup AUC | 三类偏差 AUC | Jigsaw 提出的三个细分 AUC：Subgroup AUC(组内区分力)、BPSN(对该身份的假阳倾向)、BNSP(对该身份的假阴倾向)。三者合看才能定位偏差方向。 |
| adversarial evasion (toxicity) | 对抗规避 | 用拼写变形、插入字符、同音替换等手段让有毒文本绕过毒性分类器(如 "id10t")。评测鲁棒性需主动构造这类扰动，度量分数下降。 |
| over-blocking / under-blocking | 过度屏蔽 / 屏蔽不足 | 审核系统的两类错误：误删正常内容(过度，伤表达自由)与漏放有害内容(不足，伤被害者)。阈值在两者间权衡，且对不同子群代价不同。 |

## 多语言与跨语言评测 · Multilingual Evaluation

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| cross-lingual transfer | 跨语言迁移 | 模型在高资源语言上学到的能力迁移到低资源语言的程度。评测它能揭示「英语好≠对所有语言公平」，是多语公平的起点。 |
| low-resource language | 低资源语言 | 训练语料、评测基准、标注都稀缺的语言。模型在其上性能、校准、安全性通常都更差，却服务着大量用户，是社会影响评测的重点盲区。 |
| tokenizer fertility | 分词膨胀率 / fertility | 平均每个词(或每段文本)被切成多少个 token。同一句话在低资源语言上 fertility 往往是英语的数倍，直接推高 token 数。 |
| token premium / tokenization tax | token 溢价 / 分词税 | fertility 不均带来的不公平：同样语义在某些语言上消耗更多 token，于是用户付更多按 token 计的费用、且更早撞上上下文长度上限 [Ahia 2023; Petrov 2023]。 |
| context-length inequity | 上下文不公 | 高 fertility 语言用相同字符数却占用更多 token，实际可用上下文更短。是 fertility 偏置在能力维度(而非仅价格)上的体现。 |
| BLEU / chrF | —— | 机器翻译质量自动指标：BLEU 比 n-gram 重叠，chrF 比字符级 n-gram F 值。chrF 对形态丰富语言更稳。本课用它们度量翻译质量的跨语差异。 |
| FLORES-200 | —— | Meta 的 200 语言平行评测基准。同一组句子译到所有语言，使跨语言性能可比，是多语翻译/迁移评测的事实标准。 |
| worst-group performance | 最差组性能 | 所有子群里表现最差那一组的指标。多语/公平评测中报告它(而非平均)能防止「高资源语言拉高均值、掩盖低资源语言被抛弃」。 |
| macro vs micro average | 宏平均 vs 微平均 | 宏平均给每组等权(每种语言一票)，微平均给每样本等权(大语言主导)。选择哪种聚合本身是价值判断：宏平均更护小语言。 |

## 记忆化与隐私 · Memorization & Privacy

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| memorization (LLM) | 记忆化 | 模型逐字或近逐字地复现训练数据的现象。是隐私(泄露 PII)、版权(复现受版权文本)与评测污染(背答案)三类风险的共同根源 [Carlini 2021; 2022]。 |
| extractable memorization | 可提取记忆 | 不仅被记住、且能用某个提示从模型「问出来」的训练数据。比「能记住」更严格、也更危险，是隐私攻击实际利用的部分 [Carlini 2021; Nasr 2023]。 |
| canary | 金丝雀 | 故意插入训练集的随机唯一串(如 "The secret code is 8273-…")，用来测量模型记住了多少。如矿井里的金丝雀，是审计记忆/隐私的探针 [Carlini 2019]。 |
| exposure (canary) | 暴露度 | 量化 canary 被记住程度的指标 [Carlini 2019]：用 canary 在所有同格式候选中的对数排名衡量。暴露度高 = 模型异常偏好这个真插入串 = 记住了它。 |
| membership inference attack (MIA) | 成员推断攻击 | 判断某条样本是否在模型训练集中的攻击 [Shokri 2017]。是隐私的基本威胁与审计工具：若攻击成功率显著高于随机，说明模型泄露了成员信息。 |
| loss-threshold attack | 损失阈值攻击 | 最简单的 MIA：训练样本上模型损失通常更低，故「损失 < 阈值则判为成员」。是 MIA 的入门基线，本课从零实现并画其 ROC。 |
| LiRA (Likelihood Ratio Attack) | 似然比攻击 | 强 MIA [Carlini 2022]：为每条样本训练影子模型估计「成员/非成员」两个损失分布，做似然比检验。比损失阈值法强得多，是当前 MIA 的金标准。 |
| shadow model | 影子模型 | 攻击者训练的、模仿目标模型行为的替身模型，用来估计成员/非成员下的输出分布。是 MIA 与模型窃取的通用工具 [Shokri 2017]。 |
| differential privacy (DP) | 差分隐私 | 形式化隐私保证：单条样本的有无对输出分布的影响被 ε 限制。DP-SGD 是给训练加噪声以达 DP 的标准法，能证明性地抑制记忆，代价是效用下降。 |
| deduplication | 去重 | 删除训练语料中的重复(近重复)文本。是已知最有效的低成本记忆缓解：重复次数越多越易被记住，去重显著降低提取风险 [Lee 2022; Kandpal 2022]。 |
| PII (Personally Identifiable Information) | 个人可识别信息 | 能定位到具体个人的信息(姓名、地址、电话、邮箱等)。LLM 记忆并吐出 PII 是最受关注的隐私危害，评测需专门检测其泄露。 |
| eidetic memorization (k-eidetic) | k-照相式记忆 | Carlini 2021 的定义：在训练集中出现次数 ≤ k 次却被模型逐字复现的样本。k 越小越触目惊心(出现一两次就被背下)，是记忆严重性的分级。 |

## 危害分类与风险 · Harms Taxonomy & Risk

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| harms taxonomy | 危害分类学 | 把语言模型可能造成的危害系统归类的框架，使评测有清单可循、不漏项。最广引的是 Weidinger 等的六大类。 |
| Weidinger taxonomy (six risk areas) | Weidinger 六类风险 | [Weidinger 2021/2022] 的危害六分：① 歧视/排斥/毒性；② 信息危害(泄露隐私/敏感信息)；③ 错误信息；④ 恶意使用；⑤ 人机交互危害(过度依赖/操纵)；⑥ 环境与社会经济危害。本课模块 05 的骨架。 |
| allocational vs representational harm | 分配性 vs 表征性危害 | [Barocas 2017; Crawford] 两类伤害：分配性=资源/机会被不公分配(贷款被拒)；表征性=对群体的贬损刻画/刻板印象(把某族与犯罪关联)。前者易量化，后者更隐蔽。 |
| severity × likelihood (risk matrix) | 严重度×概率(风险矩阵) | 风险管理标准做法：每种危害按「后果严重度」与「发生概率」打分，乘积(或查表)给出风险等级，用于排优先级。本课用它把定性危害变成可排序的数。 |
| risk prioritization | 风险优先级 | 在资源有限下决定先缓解哪些危害。常按风险分(严重度×概率)降序，再结合缓解成本/可行性，是把评测结果转成行动的关键一步。 |
| red teaming | 红队测试 | 主动设计对抗性输入诱发模型有害行为的过程 [Ganguli 2022; Perez 2022]。覆盖度(red-team 是否覆盖了分类学的每一类危害)是评测红队质量的元指标。 |
| coverage (red-team) | 覆盖度 | 红队/评测集触及危害分类学中各类别的比例。低覆盖意味着某些危害根本没被测过——「没测到」不等于「没风险」，是审计中最危险的盲区。 |
| residual risk | 残余风险 | 施加缓解措施后仍然存在的风险。负责任评测要报告的不是「我们做了什么缓解」，而是「缓解后还剩多少风险」，这才对决策有意义。 |
| safety case | 安全论证 | 用结构化证据论证系统在给定场景下足够安全的文档。把公平/毒性/隐私/危害评测的数字组织成「为什么可以部署」的论证，是评测的最终交付物。 |
| sociotechnical evaluation | 社会技术评测 | 主张危害不只在模型里、也在模型与人和社会的交互中，故评测须超越孤立基准、纳入部署语境与下游影响 [Weidinger 2023]。是本课的总方法论立场。 |

## 度量学基建 · Measurement Foundations

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| confusion matrix | 混淆矩阵 | TP/FP/FN/TN 四格表，几乎所有公平/毒性指标都从它派生。按子群分别构造混淆矩阵，是群体公平评测的第一步。 |
| TPR / FPR / PPV / FNR | 真阳率/假阳率/精确率/假阴率 | 混淆矩阵的派生率：TPR=TP/(TP+FN) 召回；FPR=FP/(FP+TN)；PPV=TP/(TP+FP) 精确率；FNR=1−TPR。公平定义就是要求其中某些在组间相等。 |
| ROC / AUC | ROC 曲线 / 曲线下面积 | 扫遍阈值画 (FPR, TPR) 得 ROC；AUC=随机正样本得分高于随机负样本的概率，对阈值与类别不平衡不敏感，是 MIA 与毒性评测的首选总览指标。 |
| precision-recall (PR) curve | 精确率-召回曲线 | 扫阈值画 (recall, precision)。在正类稀少(如有毒占少数)时比 ROC 更能反映性能，毒性阈值选择常看 PR。 |
| threshold | 阈值 | 把连续分数变成 0/1 决策的切点。同一模型不同阈值给出完全不同的公平/错误画像；公平评测必须说清在哪个阈值上比较。 |
| bootstrap confidence interval | 自助置信区间 | 对数据有放回重采样多次、看指标分布得到的置信区间。子群常样本少，必须报告 CI 才能区分「真差距」与「采样噪声」，本课贯穿使用。 |
| subgroup / slice | 子群 / 切片 | 按某属性切出的数据子集。「整体指标达标但某切片崩盘」是评测最常见的失败模式，slice-based 评测是负责任评测的核心动作。 |
| statistical significance vs practical significance | 统计显著性 vs 实际显著性 | 差距是否非偶然(统计) ≠ 差距是否大到该管(实际)。大数据上微小差距也会统计显著；报告效应量与 CI 而非只报 p 值，避免误导。 |
