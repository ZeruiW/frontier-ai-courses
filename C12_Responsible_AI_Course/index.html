负责任 AI 与社会影响评测

评测的伦理轴：公平 · 毒性 · 多语公平 · 记忆与隐私 · 危害分类——把「负责任」变成能写出数字的评测科学 · 纯 numpy/pandas · 真实数据 · 中文讲解 + 英文术语

6 模块 公平不可能定理 · 子群偏差 · fertility · MIA · 风险矩阵 纯 numpy / pandas · 从零实现 真实数据(civil_comments/BBQ) + 合成回退 CPU only · 无需 GPU/大模型 API
怎么用： 每个模块先读 HTML 讲解 把一个伦理评测维度的动机、数学与陷阱想透，再跑 notebook 用纯 numpy / pandas 从零实现每个指标、用 assert 判分 ✏️ 练习、最后在 🧪 真实数据胶囊 里把它接到真实公开数据（civil_comments 毒性、BBQ 偏见、canary 记忆等；联网下载、失败自动回退到内置真实数值或合成数据，逻辑不变）。配套 术语词典 与 论文清单。本课的立场是：「负责任 AI」不是合规口号，而是一门可以被精确测量、能写出数字的评测科学——公平有相互冲突的形式化定义（还有一条不可能定理证明它们一般无法同时满足），毒性检测会系统性地冤枉某些身份群体，多语 tokenizer 让低资源语言用户付更多钱、得更短上下文，模型会逐字背下训练数据并被提取出来，危害需要一张能排优先级的分类账本。我们把这五件事一一拆成可计算的量：群体公平指标、子群假阳率差、fertility 比、canary 暴露与 MIA AUC、严重度×概率风险分。全程 CPU、秒级，不调用任何大模型 API——所有机制都在玩具规模上从零实现，追求「看懂这个数字怎么来的、它会怎样骗你」。
