1这门课讲什么

欢迎来到 负责任 AI 与社会影响评测。这门课只追求一件事：把「负责任 AI」从一句合规口号，变成一门能写出具体数字、能被复现和质疑的评测科学。

「这个模型安全吗？公平吗？」——这类问题听上去像伦理或法务的事，但本课的立场是：它们首先是测量问题。一个模型对不同人群的录取率差多少？它把多少正常的同性恋者自我介绍误判成了仇恨言论？一个斯瓦希里语用户为同一句话要比英语用户多付几倍的钱？模型逐字背下了多少训练数据、能不能被人问出来？这些都不是感觉，而是可以算出来的量——一旦能算，就能比较、能监控、能写进部署决策。

绝大多数评测课只教你测能力（准确率、推理、代码）。这门课专攻另一条轴——伦理轴：当一个模型很聪明时，它可能同时很不公平、很爱冤枉某些群体、很漏隐私、很会造成不易察觉的社会危害。这五件事正是本课的五个内容模块：公平、毒性、多语公平、记忆与隐私、危害分类。

学完你应当能回答这类问题（也是 RS-Evaluation 与 AI 治理岗位的高频考点）：公平有哪几种互相打架的定义？为什么数学上证明了它们一般不能同时满足？毒性模型为什么会系统性地冤枉某些身份群体，怎么把这种偏差量化？fertility 偏置如何变成真金白银的不公？怎么测量一个模型记住了多少训练数据、外人能不能提取出来？怎么把五花八门的危害组织成一张能排优先级的账本？——并且能在 numpy/pandas 里把每个指标从零算出来。

一句方法论上的话先说在前面：负责任评测最容易犯的错，是用一个整体数字下结论。「整体准确率 92%」可能掩盖了「某个子群只有 60%」；「平均毒性很低」可能掩盖了「凡是提到某身份的句子都被误删」。本课从头到尾贯穿一个动作——切片(slice)：把数据按受保护属性、按身份词、按语言切开，分别看，并用置信区间区分真差距与采样噪声。这是整门课的灵魂。

2评测的伦理轴：五个维度

评测的伦理轴：五个维度怎么扣在一起

这五个模块不是松散的专题集合，而是覆盖「一个模型可能伤害到谁、怎么伤害」的一张地图。可以按伤害的性质把它们组织起来：

模块核心问题伤害类型可计算的量
01 公平对不同群体的决策是否系统性不利？分配性(机会/资源)DP / EO / PPV / 校准差距、不可能定理冲突
02 毒性内容审核是否冤枉了某些群体的正常表达？分配性 + 表征性子群假阳率差、BPSN AUC、对抗鲁棒性
03 多语公平非英语(尤其低资源)用户是否被区别对待？分配性(成本/上下文)fertility 比、token 税、最差组性能
04 记忆与隐私模型会泄露训练数据里的个人信息吗？信息危害(隐私)canary 暴露度、MIA AUC、去重影响
05 危害分类我们有没有漏掉某一类危害？缓解先做哪个？全部(元层面)覆盖度、严重度×概率风险分、残余风险

直白说

把五个模块连起来读：前三个讲模型怎么不公平地对待不同的人（按群体、按身份词、按语言）；第四个讲模型怎么泄露训练它的那些人的隐私；第五个站到最高处，问我们这张危害清单全不全、该先管哪个。从具体伤害到伤害的账本，由点到面。

严谨说

形式上，前三个模块都建立在同一套子群混淆矩阵上：把数据按某属性切片、各自算 TPR/FPR/PPV，再比较组间差距——只是「组」分别换成受保护属性、身份词、语言。第四模块换一套工具(暴露度、似然比、ROC)度量隐私泄露。第五模块则是把前四者的数字汇总成风险矩阵与覆盖度审计，回到决策。一套度量基建，五种伤害视角。

注意一个反复出现的主题：「负责任」几乎总是一组取舍，而非单一最优。公平的多个定义互相冲突(模块 01 的不可能定理)；毒性阈值在「过度屏蔽正常表达」与「漏放有害内容」间权衡(模块 02)；隐私保护以牺牲效用为代价(模块 04 的差分隐私)；缓解资源有限必须排优先级(模块 05)。本课不替你做价值判断，而是教你把取舍的代价算清楚、摆在台面上——这正是负责任评测区别于「打勾合规」的地方。

3课程地图：从混淆矩阵到危害账本

课程地图：从一个混淆矩阵到一份危害账本

度量基建（本模块）：混淆矩阵 + 子群切片 + bootstrap 置信区间 模块 01 偏见与公平 按受保护属性切片，比较 DP/EO/PPV/校准 —— 并撞上不可能定理 │ 「公平有好几种定义，它们打架，你得选」 ▼ 模块 02 毒性 按身份词切片，比较假阳率 —— 内容审核的意外偏差 │ 「同样的话，提到某身份就更容易被误删」 ▼ 模块 03 多语公平 按语言切片，比较 fertility/成本/性能 —— 分词税与上下文不公 │ 「非英语用户为同一句话付更多钱、得更短上下文」 ▼ 模块 04 记忆与隐私 canary 暴露 + 成员推断 —— 模型泄露训练它的人的隐私 │ 「模型逐字背下了数据，外人能问出来」 ▼ 模块 05 危害分类 严重度×概率风险矩阵 + 覆盖度审计 —— 把以上汇成账本与优先级 「我们漏了哪类危害？先缓解哪个？缓解后还剩多少风险？」

每一站都对应一个可独立交付的评测能力：模块 01 你能给一个分类器算出全部主流公平指标、并亲手演示不可能定理的冲突；模块 02 你能审计一个毒性模型在各身份词上的假阳率差、构造对抗样本测鲁棒性；模块 03 你能算出多语 fertility 比、把它换算成成本与上下文的不公；模块 04 你能用 canary 暴露度和 MIA ROC 量化记忆与隐私泄露、验证去重的缓解效果；模块 05 你能把零散危害填进风险矩阵、做覆盖度审计、排出缓解优先级。

读到最后你会发现，整门课其实在反复打磨同一套肌肉：把一个含混的伦理担忧，翻译成一个带子群、带置信区间、能复现的数字，再诚实地讲清这个数字能说明什么、不能说明什么。这套肌肉——而不是任何单一指标——才是负责任评测科学家的核心资产。

4方法论：纯 numpy/pandas、玩具规模、子群切片

方法论：为什么纯 numpy/pandas、玩具规模？

本课不调用任何大模型 API、不训练真模型，全程纯 numpy/pandas、CPU 秒级。这看似是个妥协，实则是刻意的教学选择——因为负责任评测的难点从来不是算力，而是指标的定义、子群的切法、对结果的诚实解读。

打个比方：学会计不必先有一家上市公司。公平指标、子群假阳率、fertility、暴露度、风险矩阵的算理，用几百行玩具数据就能看得一清二楚；而一旦上了真实的十亿参数模型，这些数字会被工程细节(API 限流、标注噪声、数据管线)淹没，反而看不清机制。所以本课的顺序是：先在你掌握全部真相的小数据上，把每个指标从零实现、亲眼看它怎么算出来、怎么因子群切法不同而变脸；打牢之后，换到真实模型只是把输入换大，算理一模一样。

直白说

我们把每个伦理概念翻译成 numpy/pandas 里看得见的东西：一个公平差距就是两个子群混淆矩阵的某个率之差；fertility 就是 token 数除以词数；canary 暴露就是真插入串在所有候选里的对数排名；风险分就是两个打分相乘。你写的是指标的定义本身，不是去调一个黑箱。

严谨说

关键纪律有两条。其一子群切片：任何整体指标都要追问「分组之后还成立吗」，本课每个模块都至少切一次。其二置信区间：子群样本往往很小，一个看起来很大的差距可能只是噪声；我们用 bootstrap 重采样给每个差距配一个 CI，区分真差距与采样波动——不报 CI 的子群比较是不负责任的。

伦理概念本课的 numpy/pandas 实现对应真实评测
群体公平差距两个子群混淆矩阵的率相减按受保护属性分项的 model card
毒性子群偏差按身份词 groupby 算 FPRCivil Comments 上的 BPSN AUC
分词税token 数 / 词数 的跨语比值对真实 tokenizer 跑 FLORES 语料
记忆/隐私泄露canary 对数排名 / 损失阈值 ROCSecret Sharer / LiRA on real LM
危害优先级严重度×概率 的 DataFrame 排序治理团队的风险登记册

为什么把真实数据胶囊放在每个 notebook 末尾？因为玩具数据能讲清算理，却讲不清现实有多脏、多不均。所以每个模块最后都尽量接一份真实公开数据(Civil Comments 毒性、BBQ 偏见、真实多语语料的 token 统计等)：联网能下就用真的，下不到就回退到按文献真实现象设定的内置数值或合成数据——无论哪条路径，你看到的统计结构(基率差、身份词伪相关、fertility 数倍差、成员/非成员损失分离)都与真实世界一致，结论方向不会变。

务必清楚本课不教什么：不教如何训练更公平的模型(那是建模课)、不替你裁定「哪个公平定义才对」(那是价值判断)、不提供放之四海皆准的安全阈值。本课只负责把测量这一步做扎实——给你一套能把伦理担忧变成可复现数字、并诚实标注其局限的工具。测量做对了，治理与决策才有据可依。

5环境与运行

环境与运行

环境极简：numpy + pandas（画 ROC/PR 曲线可选 matplotlib）。全课 CPU 秒级，无需 GPU、无需任何大模型 API、不联网也能跑通(真实数据胶囊会自动回退到内置数据)。

conda create -n responsible-ai python=3.11 -y && conda activate responsible-ai
pip install numpy pandas      # 必需
pip install matplotlib        # 可选，仅用于画 ROC / PR / 风险矩阵
jupyter lab

每个模块配一个 notebook，结构统一：先用 numpy/pandas 把指标从零实现并打印验证（5–6 个 worked 小节，每节都跑出可读结果与 assert 自检），再做 3–4 道带 assert 判分的 ✏️ 练习（先给 TODO 骨架，自己填，紧跟一个自测 cell，再对照 📖 参考答案），最后一个🧪 真实数据胶囊（联网下载真实公开数据，失败回退内置真实数值/合成，同样配 TODO+assert+答案）。

建议的学习节奏：先读完整章 HTML 把动机、数学与陷阱想透，再打开 notebook 亲手实现。读和做缺一不可——只读会以为「公平不就是一视同仁嘛」，真到 notebook 里发现「一视同仁」有四种互相矛盾的写法、还有定理证明它们不能兼得时，理解才真正落地。这门课的深度，正是为「动手把每个数字算出来」服务的。

配套先读：Hardt 2016(equalized odds)、Kleinberg 2016 / Chouldechova 2017(不可能定理)、Dixon 2018(毒性意外偏差)、Carlini 2019/2021(记忆与提取)、Shokri 2017(MIA)、Weidinger 2021(危害六类)、Parrish 2022(BBQ)。完整清单见 references.md。

✅ 学完整门课，你应该能：
  1. 给一个分类器算出 demographic parity / equalized odds / predictive parity / 校准 四类公平指标，并解释它们为何冲突；
  2. 陈述并用数据演示 Kleinberg–Chouldechova 不可能定理；
  3. 按身份词审计一个毒性模型的子群假阳率差、计算 BPSN 式偏差、构造对抗样本测鲁棒性；
  4. 计算多语 tokenizer 的 fertility 偏置，并把它换算成成本与上下文长度的不公；
  5. 用 canary 暴露度与 membership inference(loss 阈值/ROC)量化记忆与隐私泄露，验证去重的缓解效果；
  6. 把零散危害填入严重度×概率风险矩阵、做 red-team 覆盖度审计、排出缓解优先级；
  7. 在以上每一项里都按子群切片、报告 bootstrap 置信区间，并诚实区分统计显著与实际显著。
