1这门课讲什么

欢迎来到 深度学习理论与数据/生成媒体评测。这门课服务于一个非常具体的痛点：当你盯着一条训练曲线或一张评测表，发现它「不对劲」——测试误差先升后降、模型练了很久突然开窍、换个指标结论就翻转、自己造的数据越用越差——你能不能说清这是为什么，并用代码证明？

做评测与数据的研究者，每天都在和这类反常打交道。它们大多不是 bug，而是深度学习在过参数化、长训练、数据驱动这三个现代条件下的真实而违反经典直觉的行为。本课挑出五个最高频、最容易误判的现象——double descent（双下降）、grokking（顿悟）与涌现、数据流水线、合成数据坍塌、生成媒体评测——逐个拆开。

拆的方式是本课的灵魂：把每个现象缩小成一个能手算、能 numpy 跑通、能对拍验证的玩具。我们不满足于「读过 Belkin 那篇双下降」——我们用随机特征回归把那条双下降曲线亲手画出来；不满足于「听说过 grokking」——我们用模算术小模型让训练集早早满分、测试集很久后跳变；不满足于「知道 model collapse 很危险」——我们用迭代自训练让方差一代代地收缩给你看；不满足于「FID 越低越好」——我们在玩具高斯特征上把 FID/IS从公式一行行算出来。

学完你应当能回答这类问题（也是评测/数据岗位的高频考点）：测试误差为什么会在参数≈样本数时冲高、之后反而下降？grokking 靠什么驱动，没有 weight decay 还会发生吗？「涌现能力」有几分是真、几分是度量造成的假象？怎么做近重复去重、为什么去重能提升模型？为什么用模型自己的输出反复训练会让分布坍塌、怎么救？FID 和 IS 各自在量保真还是多样，分别能被怎样钻空子？——并且能在 numpy 里把这些现象都复现、对拍、讲清来龙去脉。

一句方法论的话先讲在前面：本课的价值不在「我们用玩具」这个妥协，而在玩具逼你把现象的因果机制想透。真实规模的实验里，双下降的尖峰可能被各种工程细节糊住、grokking 要等几十万步、model collapse 要训很多代——你很难确信自己真的理解了。而在固定种子的 numpy 玩具里，每条曲线都可逐位复现、每个机制都可单独开关（关掉 weight decay 看 grokking 消失、换个度量看涌现变平滑、把真实数据混回去看坍塌被遏制）。这种「可控的小」，是建立可靠直觉的最快路径。

2暗线：五个现象，同一种素养

为什么这五个看似松散的主题被放进同一门课？因为它们共享同一条暗线：深度学习的现代实践系统性地违反了我们从经典统计学习继承来的直觉，而这些违反恰恰发生在「评测」与「数据」这两个最影响判断的地方。把它们摆在一起，是为了训练同一种素养——面对反常曲线时，先归类、再用最小模型验证机制、最后才下结论。

轨道现象违反了什么经典直觉本课怎么复现
泛化double descent「容量越大越过拟合」随机特征回归扫容量，画出双下降
动力学grokking / 涌现「训练到收敛即学到了」「能力平滑增长」模算术 grokking；换度量让涌现变平滑
数据数据流水线「数据多即可，质量随意」MinHash 去重、质量过滤、shuffle 偏差
数据合成数据坍塌「模型造的数据可以无限自给」迭代自训练，方差逐代收缩
评测生成媒体评测「好坏可以一个分数说清」从零算 FID/IS/PR，看保真与多样分离

直白说

这五件事的共同教训是：不要用线性世界的直觉去读非线性世界的曲线。容量、训练时间、数据量、评测指标——每一个旋钮在深度学习里都可能有反直觉的拐点。看到拐点先别慌，也别急着归因为 bug，多半是某个已知现象在起作用。

严谨说

形式上，本课反复强调一个区分：「拟合训练数据」「学到可泛化结构」「在某指标上得分高」是三件可以分离的事。grokking 把前两者在时间上分离；double descent 把容量与泛化的关系非单调化；涌现假象把「能力」与「指标得分」分离；生成评测把「保真」与「多样」分离。识别出当前是哪一种分离，是正确解读的关键。

还有一条贯穿全课的实践纪律值得先点明：度量的选择本身就是有后果的研究决定。同一批模型，用 exact-match 准确率看是「涌现」，用 token 级对数似然看是「平滑提升」（模块 02）；同一个生成器，用 FID 看还行、用 precision-recall 看才发现它漏了一半模式（模块 05）。这不是技术细节，而是评测科学的核心：在下任何结论前，先问「我用的指标到底在量什么、它连续吗、它能被怎样操纵」。本课会把这条纪律变成你的肌肉记忆。

3课程地图：从理论到数据到评测

课程地图：五个现象，一条暗线

暗线：现代深度学习在 过参数化 / 长训练 / 数据驱动 下违反经典直觉 —— 而违反恰好发生在「评测」与「数据」这两个最影响判断的地方 模块 01 泛化与双下降 bias-variance 分解 → 经典 U 型 → 插值阈值尖峰 → 二次下降 │ 「容量越大越过拟合」在过参数化区失效；最小范数解是隐式正则 ▼ 模块 02 grokking/涌现 训练早过拟合、测试后跳变；weight decay 驱动；涌现是不是度量假象 │ 「训练到收敛=学会了」「能力平滑增长」都要重新审视 ▼ 模块 03 数据流水线 清洗 → MinHash 去重 → shuffle 缓冲 → 分片 → 质量统计 │ 「数据多就行」错了：质量与去重直接决定模型与评测可信度 ▼ 模块 04 合成数据坍塌 自举/蒸馏生成 → 递归自训练 → 方差逐代收缩 → 真实数据锚定 │ 「模型造的数据可无限自给」会触发 model collapse ▼ 模块 05 生成媒体评测 FID(Fréchet) / IS / precision-recall / 保真-多样 / 人评 「一个分数说清好坏」做不到：保真与多样必须分开看

这不是松散的专题集合，而是一条从理论到数据再到评测的链：模块 01–02 讲模型自身的反直觉行为（泛化与动力学），模块 03–04 讲喂给模型的数据的陷阱（清洗去重与合成坍塌），模块 05 讲怎么给生成结果打分（评测本身的科学）。三段都服务于同一个能力：看懂并解释那些「不对劲」的曲线与数字。

每一模块都对应一个可独立验证的能力：模块 01 你能用随机特征回归画出双下降、并用伪逆构造最小范数解证明它范数更小；模块 02 你能让一个模算术模型 grokking、并通过关掉 weight decay 让它不再 grok；模块 03 你能用 MinHash 估出两文档的 Jaccard 相似度并近线性去重；模块 04 你能量化迭代自训练中方差的几何衰减、并演示混入真实数据后衰减被遏制；模块 05 你能从零算出 FID/IS/PR 并构造「FID 低但 recall 差」的反例。每一步都有 assert 兜底，绝不靠「看起来对了」。

4方法论：玩具复现 + 对拍验证

方法论：玩具复现 + 对拍验证

本课全程纯 numpy、CPU 可跑、不联网为必需（部分胶囊尝试拉真实公开数据，但都带内置真实数值的离线回退）。这不是因为我们跑不动大实验，而是因为理解一个现象的机制，玩具是更好的显微镜。

打个比方：要理解共振，你不必去看一座塌掉的大桥，一根弹簧加一个周期力就够了，而且你能精确控制每个变量。深度学习的这些现象也一样——双下降的本质（最小范数解随容量的行为）在一个几十维的随机特征回归里就完整呈现；grokking 的本质（记忆解与泛化解的竞争，weight decay 选出后者）在一个模 p 加法的小模型里就能复现；model collapse 的本质（有限样本拟合再采样导致方差收缩）甚至在一维高斯的迭代里就能看见。把规模剥掉，机制反而看得更清。

直白说

我们把每个论文级现象翻译成 numpy 里看得见的小实验：双下降是一条随特征数变化的测试误差曲线；grokking 是训练准确率和测试准确率两条在时间上错开的线；model collapse 是方差随代数下降的数列；FID 是两组高斯特征间的一个距离数。你写的是机制，不是规模。

严谨说

关键纪律是对拍与自检（assert）：每个 worked 小节都跑出可打印的数字，并用 assert 把该成立的关系钉死——双下降曲线在插值阈值处确实出现峰值、最小范数解的范数确实小于其他插值解、稳定 softmax 与朴素 softmax 数值一致、FID 对自己和自己确实为 0。凡是声称「会发生 X」，就有一个 assert 当场验证 X 真的发生。这套「先有可验证的预言、再写代码」的纪律，正是可信研究的核心工作流。

论文级现象本课的 numpy 玩具钉死它的 assert（示例）
double descent随机特征回归扫特征数测试误差在 n≈d 处取最大、两侧更低
grokking模算术 (a+b)%p 小模型训练 acc 早到 1、测试 acc 后跳变；关 WD 则不跳
涌现假象同一能力换 exact-match vs 连续度量前者阶跃、后者平滑单调
MinHash 去重签名相等率 ≈ Jaccard估计值与真值误差随签名长收敛
model collapse迭代高斯自训练方差按代数近似几何衰减、趋于 0
FID / IS玩具高斯特征从零算FID(X,X)=0、分布越远 FID 越大

务必清楚本课不替代什么：玩具复现能让你理解机制，但真实规模下还有工程噪声、优化细节、数据规模效应等额外变量。本课负责把第一性的因果机制夯死；把它接到真实实验（references 里的原始论文与开源语料/评测库），是自然的第二步。先在沙盒里确信自己懂了，再上真实战场。

5环境与运行

环境与运行

环境极简：只需 numpy（画曲线可选 matplotlib，pandas 仅个别胶囊可选）。全课 CPU 秒级到分钟级运行，无需 GPU。

conda create -n dl-theory python=3.11 -y && conda activate dl-theory
pip install numpy            # 必需
pip install matplotlib       # 可选，仅用于画双下降/grokking 曲线
pip install pandas           # 可选，个别数据胶囊用
jupyter lab

每个模块配一个 notebook，结构统一：先用 numpy 把现象从零复现并自检（多个 worked 小节，每节跑出可打印的数字与 assert），再做 3–4 道带 assert 判分的 ✏️ 练习（先给骨架含 TODO，自己填，紧跟一个自测 cell；再对照 📖 参考答案），最后一个真实数据胶囊（尽量用真实公开数据或真实模型配置，带联网失败的离线回退，同样 TODO+assert+答案三件套）。

建议的学习节奏：先读完整章 HTML 建立现象与理论框架，再打开 notebook 亲手复现。读和做缺一不可——只读会觉得「好像懂了」，真正动手调容量看尖峰出现、调 weight decay 看 grokking 开关、迭代自训练看方差收缩时，才会真正把机制刻进直觉。这门课的深度正是为「动手验证」服务的。

配套必读（详见 references.md）：Belkin 2019 与 Nakkiran 2021（双下降）、Power 2022 与 Nanda 2023（grokking）、Wei 2022 与 Schaeffer 2023（涌现与假象之争）、Lee 2022 与 Broder 1997（去重）、Shumailov 2024（model collapse）、Heusel 2017 与 Salimans 2016（FID/IS）。

✅ 学完整门课，你应该能：
  1. 用随机特征回归复现 double descent，解释插值阈值尖峰与过参数化区的二次下降，并用最小范数解说明隐式正则；
  2. 用模算术小模型复现 grokking，论证 weight decay 的关键作用，并区分记忆与泛化；
  3. 就「涌现能力」做出有判断力的回应：哪些是真、哪些可能是度量不连续造成的假象（Schaeffer）；
  4. 从零搭一条数据流水线（清洗→MinHash 去重→shuffle 缓冲→分片→质量统计），并量化每步的效果与去重对评测污染的意义；
  5. 解释并复现 model collapse（迭代自训练的方差收缩），说明真实数据锚定/累积为何能遏制它；
  6. 从公式从零实现 FID（含矩阵平方根）、IS（含 KL）、improved precision-recall，并讲清保真与多样为何必须分开看、各指标能被怎样操纵；
  7. 面对一条反常的训练/评测曲线，先归类（双下降？grokking？度量假象？数据坍塌？），再用最小模型验证，最后给出有代码支撑的结论。
