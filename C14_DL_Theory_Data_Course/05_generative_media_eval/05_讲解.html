1生成评测：保真与多样两个维度

前一模块结尾立下一个 flag：评估生成质量，永远至少要分「保真」和「多样」两个维度。这一模块把这两个维度做成可计算的指标——这就是 generative media evaluation（生成媒体评测）：如何给图像、音频、视频等生成结果打分。它是生成模型研究的罗盘，也是本课所有「度量决定结论」教训的集大成。

生成评测难在哪？分类任务有 ground truth（标签对就是对），但生成任务没有唯一正确答案——一张生成的猫图，没有「标准猫图」可比对。我们真正想问的是分布层面的问题：生成分布 $p_g$ 像不像真实分布 $p_r$？而「像」至少包含两件独立的事：

直白说

① 保真度（fidelity）：生成的每个样本，像不像真的？（生成的猫，是不是一只像样的猫，而非四不像）② 多样性（diversity）：生成的样本，覆不覆盖真实的全部花样？（是只会生成橘猫，还是各种品种都有）这两件事互相独立：可以保真高多样低（只会画一种完美的猫），也可以多样高保真低（画各种四不像）。

严谨说

形式上：好的生成要求 $p_g\approx p_r$。这个「约」至少要在两个意义上成立——支撑集匹配（$p_g$ 的质量都落在 $p_r$ 的支撑内 = 保真）与覆盖匹配（$p_r$ 的所有区域都被 $p_g$ 覆盖 = 多样）。这恰好对应 precision 与 recall。任何把生成质量压成单个标量的指标，都在某种程度上把这两个维度混在了一起——这是理解所有生成指标优劣的总钥匙。

本模块从零实现三大主力指标——FID（一个混合标量）、IS（不需真实图、有缺陷）、precision-recall（显式拆分保真与多样）——并讲清每个到底在量什么、能被怎样钻空子。全部在玩具高斯特征上手算，让你看清公式而非调库。

这一模块给评测科学家的核心装备：拿到任何生成指标，先问三件事——它量的是保真、多样、还是两者混合？它需不需要真实样本做参考？它能被怎样操纵（刷高分但实际更差）？本模块会让你对 FID/IS/PR 都能答出这三问。这正是 Goodhart's law（度量成了目标就不再是好度量）在生成评测里的实操。

2FID 一：Fréchet 距离的数学

FID 之一：Fréchet 距离的数学

最广泛使用的图像生成指标是 FID（Fréchet Inception Distance）[Heusel 2017]。它的思路分两步：① 把真实图和生成图各自送进一个预训练网络（Inception）取特征向量（不直接比像素，比语义特征）；② 假设两组特征各自服从高斯分布，计算这两个高斯之间的 Fréchet distance（即 2-Wasserstein 距离）。

两个高斯 $\mathcal{N}(\mu_1,\Sigma_1)$ 与 $\mathcal{N}(\mu_2,\Sigma_2)$ 之间的 Fréchet 距离有闭式：

\[\mathrm{FID} = \underbrace{\|\mu_1-\mu_2\|^2}_{\text{均值差}}+\underbrace{\mathrm{Tr}\!\Big(\Sigma_1+\Sigma_2-2(\Sigma_1\Sigma_2)^{1/2}\Big)}_{\text{协方差差}}\]

这个公式的两项恰好对应本课反复强调的两个维度：第一项 $\|\mu_1-\mu_2\|^2$ 惩罚均值差异（生成特征的中心偏离真实，主要反映保真度——整体像不像）；第二项惩罚协方差差异（生成特征的分散结构偏离真实，主要反映多样性与结构——花样齐不齐、相关性对不对）。FID 越低越好，0 表示两分布的一二阶矩完全一致。

直白说

FID 就是「把真实图和生成图各自的特征摊成一团高斯云，量这两团云的中心差多远（保真）、形状差多少（多样/结构）」。两团云完全重合，FID=0；中心偏了或形状瘪了，FID 就升高。

严谨说

严谨地说：Fréchet 距离是两个分布间 2-Wasserstein 距离，对高斯有上面的闭式。它只依赖一阶矩（均值）和二阶矩（协方差），所以隐含了高斯假设——真实特征若非高斯（多峰、重尾），FID 会漏掉高阶差异。这是 FID 的一个根本局限，但实践中它对很多失真（模糊、噪声、模式丢失）仍相当敏感。

为什么是 Inception 特征、而不直接比像素？因为像素级距离与人类感知严重不符——把一张图整体平移一个像素，像素 MSE 巨大，但人眼觉得几乎没变；反之两张语义完全不同的图可能像素距离不大。Inception 网络在大规模分类上学到的特征，把图像映射到一个语义空间，在那里「距离近」更接近「人觉得像」。这也埋下了 FID 的一个根本依赖：它的结论高度依赖特征提取器的选择。换一个特征网络（或它的某一层），FID 的绝对值甚至模型排名都可能变（Stein 2023 系统检验过这点）。所以 FID 是一个相对指标——只在固定特征提取器下、同条件比较才有意义，不存在「绝对的好 FID 值」。

FID 的一个易忽略陷阱：它是有偏估计，且偏差随样本数变化——用 1k 样本和 50k 样本算出的 FID 不可直接比较，样本少时 FID 系统性偏高。比较不同模型的 FID 必须用相同的样本数、相同的特征提取器。KID（Kernel Inception Distance）是它的无偏替代。

3FID 二：矩阵平方根与实现

FID 之二：矩阵平方根与从零实现

FID 公式里唯一的技术难点是 $(\Sigma_1\Sigma_2)^{1/2}$——一个矩阵平方根。注意这不是逐元素开方，而是满足 $S^2=M$ 的矩阵 $S=M^{1/2}$。对对称半正定矩阵，可以用特征分解优雅地算：

\[M = V\Lambda V^\top \;\Rightarrow\; M^{1/2}=V\,\Lambda^{1/2}\,V^\top \quad(\Lambda^{1/2}=\mathrm{diag}(\sqrt{\lambda_i}))\]

即：对 $M$ 做特征分解得到特征值 $\lambda_i$ 和特征向量 $V$，把特征值开方、重新组装，就得到矩阵平方根。验证很简单——$S^2=V\Lambda^{1/2}V^\top V\Lambda^{1/2}V^\top=V\Lambda V^\top=M$（用了 $V^\top V=I$）。

实现上有两个必须处理的数值细节：① $\Sigma_1\Sigma_2$ 理论上对称半正定，但浮点误差会让它略微不对称，要先对称化 $\frac{1}{2}(M+M^\top)$；② 浮点误差可能产生微小的负特征值，要 clip 到 0 再开方（否则 $\sqrt{\text{负数}}$ 出 nan）。处理好这两点，几行 numpy 就能从零算出 FID。

从零算 FID 的流程: 真实特征 X(n×d) ──▶ μ1=mean(X), Σ1=cov(X) 生成特征 Y(m×d) ──▶ μ2=mean(Y), Σ2=cov(Y) │ matrix_sqrt(Σ1@Σ2): │ 特征分解 -> 对称化 -> clip 负特征值 -> 开方重组 ▼ FID = ||μ1-μ2||² + Tr(Σ1 + Σ2 - 2·(Σ1Σ2)^½) 自检: FID(X, X) = 0 ; 分布越远 FID 越大 ; sqrt(M)² == M

notebook 会从零实现 matrix_sqrt 与 fid，并 assert 三件事：① $S^2=M$（矩阵平方根正确）；② FID(X,X)=0（自反性）；③ 均值偏移、方差收缩都让 FID 增大（敏感性）。你会亲眼验证 FID 对均值偏移（保真下降）和方差收缩（多样性下降，正是 model collapse 的特征）都敏感——这把它和上一模块的坍塌直接连上：坍塌会推高 FID 的协方差项。

奠基必读：Heusel et al. 2017《GANs Trained by a Two Time-Scale Update Rule...》（FID 原始论文）。它证明 FID 比早期的 IS 更好地反映分布距离、对失真和模式丢失更敏感、且与人类判断更相关。见 references.md。

4Inception Score：无参考但有缺陷

Inception Score：不需真实图，但有缺陷

比 FID 更早的指标是 Inception Score（IS）[Salimans 2016]。它的巧妙之处是不需要真实图像——只看生成图本身，用一个预训练分类器给每张生成图输出类别概率 $p(y\mid x)$，再综合成一个分数：

\[\mathrm{IS}=\exp\Big(\mathbb{E}_{x\sim p_g}\,\mathrm{KL}\big(p(y\mid x)\,\|\,p(y)\big)\Big),\qquad p(y)=\mathbb{E}_x\,p(y\mid x)\]

拆开看 IS 在奖励什么。KL 散度 $\mathrm{KL}(p(y\mid x)\|p(y))$ 大，需要两件事同时成立：

  • 每张图分类置信（保真）：$p(y\mid x)$ 要尖锐（低熵）——分类器能确信这是只猫，说明图像清晰、像个真东西。模糊/四不像的图分类器会犹豫（高熵），KL 小。
  • 整体类别均匀（多样）：边际分布 $p(y)$（所有生成图的平均类别分布）要均匀（高熵）——生成图覆盖各种类别，而非全是猫。若只生成猫，$p(y)$ 尖锐，KL 小。

所以 IS 高 ⟺ 每张图都清晰可辨（保真）且整体类别丰富（多样）。它把保真和多样巧妙地编码进「条件熵低 + 边际熵高」。IS 越高越好（上界约等于类别数）。但 IS 有致命缺陷：① 它根本不看真实图像，所以无法发现「生成分布偏离真实分布」（只要清晰且类别均匀，哪怕和真实数据毫无关系也能高分）；② 它依赖分类器的类别体系，对没有对应类别的领域失效；③ 易被钻空子——每个类别精心生成一张超清晰图就能刷高 IS，哪怕多样性其实很差。

直白说

IS 像让一个「猫狗鸟分类器」给生成图打分：每张图它都能斩钉截铁说出是什么（清晰），而且各种动物都有（丰富），分就高。问题是这个裁判从没见过真实照片长啥样——你给它一堆清晰但诡异的图，它照样给高分。

严谨说

严谨地说：IS 是 reference-free metric（无参考指标），便利但脆弱。它度量的是 $p(y\mid x)$ 的尖锐度与 $p(y)$ 的均匀度，完全不涉及 $p_r$。这是它与 FID 的根本区别：FID 比较生成与真实，IS 只自评生成。现代实践 IS 已大体被 FID/PR 取代，但理解它的奖励机制是生成评测的基本功。

IS 的故事是 Goodhart 定律的经典案例：一旦 IS 成为优化目标，模型会学会「生成少数几张每类的完美图」来刷分，而真实多样性下降。这警示我们：任何单一自动指标都可能被针对性优化而背离真实质量——必须多指标交叉 + 人评兜底。

5Precision-Recall：掰开保真与多样

Improved Precision-Recall：把保真和多样掰开

FID 把保真和多样混成一个数，IS 不看真实分布。improved precision-recall [Kynkäänniemi 2019] 直面这个问题：用两个独立的数，分别量保真（precision）和多样（recall）。这是把本课中心思想做到极致的指标。

核心是用 k-NN 估计每个分布的支撑集（流形）：把每个真实样本点，连同它到第 $k$ 近邻的距离，画一个球；所有这些球的并集，就近似真实数据的流形。生成分布同理。然后：

  • Precision（保真） = 落在真实流形内的生成样本比例。生成点若落在某个真实球里，说明它「像真的」。precision 低 = 生成了很多不像真实的样本（off-manifold）。
  • Recall（多样） = 落在生成流形内的真实样本比例。真实点若落在某个生成球里，说明它「被生成覆盖」。recall 低 = 真实分布有大片区域没被生成覆盖（mode dropping）。
precision-recall via k-NN 流形: 真实流形(真实点的k-NN球并集) 生成流形(生成点的k-NN球并集) ╭───────╮ ╭───╮ │ ● ● ● │ <真实 gen │ ○ │ │ ●●●●● │ ○ off-manifold ╰───╯ ╰───────╯ (只覆盖一小块) Precision = 生成点 ○ 落在真实流形里的比例 (保真) Recall = 真实点 ● 落在生成流形里的比例 (多样/覆盖)

这套度量的威力在于它能分别诊断两种失败（FID 做不到）：mode collapse（生成只覆盖真实的一小块）表现为 precision 高、recall 低（生成的都很真，但漏了大量模式）；生成跑偏 / 噪声大表现为 precision 低、recall 高或低（生成的不像真的）。notebook 会从零实现 PR 并构造这两种反例——一个方差收缩的生成器（recall 崩、precision 不变）和一个均值偏移的生成器（precision 崩）——把「FID 一个数看不出、PR 两个数看得清」演示得明明白白。

把 PR 和前一模块连起来：model collapse 在 PR 上的指纹就是 recall 崩塌而 precision 不变。这正是为什么坍塌隐蔽——它不伤 precision（单样本质量），只伤 recall（多样性）。盯住 recall，就能在坍塌早期抓住它。PR 是监测坍塌的理想仪表盘。

6保真-多样权衡与指标取舍

保真-多样权衡与指标的取舍

有了 precision-recall，本课反复出现的 质量-多样性权衡 终于有了精确的语言。生成模型常常无法同时最大化两者，而是沿一条precision-recall 权衡曲线移动：

调节手段效果precisionrecall
降低采样温度 / truncation只采高概率区域↑（更真）↓（漏长尾）
提高温度 / 加噪采更广区域↓（更杂）↑（更全）
过度过滤合成数据只留高质量↑↓（坍塌前兆）
mode collapse塌向少数模式≈不变↓↓

这条权衡解释了很多实践现象：扩散模型的 classifier-free guidance 调大 → 图更精致（precision↑）但更同质（recall↓）；GAN 的 truncation trick 同理。没有免费的午餐——把保真推高，多样性往往要付代价，反之亦然。一个只报「FID 降了」的结果，可能是在权衡曲线上偷偷牺牲了 recall 换 precision，必须看 PR 才知道真相。

这条权衡也给「比较两个生成模型」立了规矩：只看一个数说「A 比 B 好」往往站不住。A 的 FID 比 B 低，可能是 A 在 precision 上赢、recall 上输（更精致但更同质），也可能反过来——一个标量把这两种截然不同的情况压成了同一个「更好」。正确的比较是把两个模型画在 precision-recall 平面上：如果 A 在两个维度都不差于 B（帕累托占优），才能说 A 更好；若各擅胜场（A 保真高、B 多样高），则「谁更好」取决于你的应用更看重哪一维。生成模型的比较本质是多目标的，强行标量化会丢失关键信息。

那么实践中该用哪个指标？没有银弹，要组合使用：

指标量什么需要真实图主要短板建议用途
FID保真+多样（混合）需要高斯假设、有偏、单标量主指标、横向比较（同样本数）
IS保真+多样（自评）不需要不看真实、易钻空、限类别辅助、历史对照
Precision/Recall保真、多样（分开）需要依赖 k、计算较重诊断坍塌、分析权衡
人评综合主观质量可对照贵、慢、主观、难复现最终校准、自动指标兜底

延伸（见 references.md）：Kynkäänniemi 2019（improved P-R）、Sajjadi 2018（P-R 框架源头）、Bińkowski 2018（KID，FID 的无偏替代）、Theis 2016（似然/样本质量/用途三者可不一致的经典警示）、Stein 2023（系统检验各指标与人评的相关性）。

7人评、CLIPScore 与没有银弹

人评、CLIPScore 与「没有银弹」

自动指标再精巧，最终都要回答一个问题：它和人类的判断一致吗？ human evaluation（人评）是所有自动指标的最终校准基准——常见形式有 side-by-side 偏好比较、Likert 打分、Elo 排名。人评直接测「人觉得好不好」，但贵、慢、主观、难复现，且会受标注者疲劳、文化差异、提示设计影响。所以实践是：用自动指标做大规模快速筛选，用人评在关键节点校准与拍板。

文生图时代还出现了一类重要指标：CLIPScore [Hessel 2021]，用 CLIP 的图文嵌入算「生成图与文本提示」的余弦相似度，评估对齐（生成的图符不符合要求）。它也是无参考的（不需要参考图），便利，但同样脆弱——它继承 CLIP 的偏见，且容易被「字面匹配但语义错」的图骗过。

退一步看整个生成评测领域，最该内化的一条来自 Theis 2016 的经典警示：似然、样本质量、下游用途，这三件事可以互不一致——一个似然高的模型样本可能很差，一个样本惊艳的模型可能下游没用。不存在单一指标能代表「生成得好」。这与本课从第一模块就贯穿的主线完全一致：度量的选择决定你看到的结论，没有哪个度量是全知的。

直白说

评生成模型就像评一个厨师：顾客打分（人评）最权威但贵又慢；用「摆盘机器」打分（FID/IS）快但可能错过味道；看「按菜谱做对没」（CLIPScore）测的是对齐不是好吃。没有一个数能说清「这厨师行不行」，得几个角度一起看，最后靠人尝。

严谨说

严谨地说：每个指标都是真实质量的一个有偏投影。FID 投影到一二阶矩、IS 投影到分类置信与类别分布、CLIPScore 投影到 CLIP 嵌入对齐、人评投影到标注者的主观偏好。没有任何单一投影等于真实质量；可信的评测是多个互补投影 + 人评锚定的三角测量。

整个模块、乃至整门课的终极一句话：永远不要用单一指标下「生成得好/能力涌现了/模型更强了」的结论。先拆维度（保真 vs 多样）、再多指标交叉、最后人评兜底。这套纪律——对任何度量都先问「它量什么、能被怎样骗」——是评测科学家最核心、最不可替代的素养。

8研究前沿与开放问题

研究前沿与开放问题

  • 超越高斯假设：FID 的高斯假设会漏掉高阶分布差异。KID、precision-recall、以及基于神经网络的分布距离试图改进，但「既敏感、又稳健、又与人评相关、又难被操纵」的理想指标仍未出现。
  • 特征提取器的依赖：FID/PR 高度依赖 Inception 特征，对扩散模型等可能不公平（Stein 2023）。用什么特征空间评测、是否该用任务相关的特征，是开放问题。
  • 多模态与对齐评测：文生图/视频的评测要同时管保真、多样、与提示的对齐、以及时序一致性（视频）。CLIPScore 等只覆盖一部分；统一的多模态生成评测框架仍在探索。
  • 与人评的对齐及自动化：能否让自动指标可靠预测人类偏好、甚至用模型模拟人评（LLM-as-judge），同时避免自我强化的循环偏差（呼应模块 04），是评测自动化的前沿与风险所在。

必读清单（详见 references.md）：Heusel 2017（FID）、Salimans 2016（IS）、Kynkäänniemi 2019（P-R）、Theis 2016（没有单一指标的经典警示）、Stein 2023（指标缺陷的现代检验）。至此本课五个内容模块讲完——从双下降、grokking/涌现，到数据流水线、合成数据坍塌，再到生成评测：贯穿始终的是同一条纪律——面对反常曲线先归类、用最小模型验证机制、对任何度量都先问它量什么、能被怎样骗。
