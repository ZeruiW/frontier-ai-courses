学习理论与优化理论

不止知道深度学习有效，而是理解它为什么有效 · 用纯 numpy 数值实验把每个界与收敛率钉死 · 中文讲解 + 英文术语 · 研究科学家的理论脊梁

6 模块 PAC · VC · Rademacher · 收敛率 · NTK · 隐式偏置 · PAC-Bayes 理论 + 可跑实证 每个界都数值核验 纯 numpy · CPU only
怎么用： 每个模块先读 HTML 讲解 把抽象的界与收敛率讲到能写下证明骨架，再跑 notebook 用纯 numpy 做数值实验把理论钉死——每个 worked 都 print 出「理论预测」与「实测」并用 assert 断言两者一致，✏️ 练习用 assert 判分。配套 术语词典 与 论文清单。本课的立场是：理论不是黑板上的不等式，而是可被实验反复确认的预测。我们把研究科学家的「理论脊梁」补齐——C14 讲了泛化的现象（double descent、grokking），本课讲它们背后的机制与界：为什么经验风险会收敛到真实风险、收敛多快（统计学习理论）；梯度下降为什么收敛、以什么速率（优化理论）；无限宽网络为什么等价于核回归（NTK）；为什么梯度下降在过参数化下会自发挑出 max-margin / 最小范数解（隐式偏置）；以及为什么经典容量界在深度学习上失效、当代用什么界来替代（深度泛化）。所有界、收敛率、公式都经一份 verify_math.py 数值核验，每个 notebook 的 assert 都把「理论 ≈ 实测」断言为真。纯 numpy / CPU，秒级可跑。
