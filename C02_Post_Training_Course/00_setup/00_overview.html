1后训练管线全景：base model 是怎么变成 assistant 的

预训练（pre-training）在万亿级 token 上做 next-token prediction，给模型注入了几乎全部的知识与能力。 但一个刚出炉的 base model 只会"续写"：你问它"法国的首都是哪里？"，它可能回你"德国的首都是哪里？意大利的首都是哪里？"——因为训练语料里考卷长这样。 后训练（post-training）不再注入多少新知识，而是塑造模型的行为：它是谁、为谁服务、什么该说、怎么思考。

直白讲

预训练像读完了整个图书馆，后训练像入职培训：先看示范学会"怎么回答"（SFT）， 再根据别人对你两份答案的偏好反馈调整风格与价值观（RLHF/DPO）， 最后在有标准答案的任务上反复刷题、自己摸索出解题套路（RLVR）。 每一步都不教新知识，教的是行为。

严谨讲

后训练是在预训练分布 $p_{\text{base}}$ 的支撑集内做分布调制：SFT 用极大似然把概率质量搬到示范分布上； RLHF/DPO 在 KL 约束下最大化奖励 $\max_\pi \mathbb{E}[r(x,y)] - \beta\, \mathrm{KL}(\pi \| \pi_{\text{ref}})$； RLVR 用可验证奖励信号直接强化能通向正确答案的推理轨迹。三者共享同一个核心原语：序列的对数概率 $\log \pi_\theta(y|x)$。

完整管线如下，注意每个阶段的数据形态和目标函数都不一样——这张图是全课的骨架，后面每个模块都在放大其中一格：

预训练 后 训 练 (本课范围) ┌─────────────────────┐ ┌────────────────┐ ┌─────────────────────┐ ┌────────────────────┐ │ Base Model │──►│ ① SFT │──►│ ② 偏好对齐 │──►│ ③ 推理 RL │ │ (只会续写) │ │ 指令微调 │ │ RLHF(PPO) / DPO │ │ RLVR / GRPO │ └─────────────────────┘ └────────────────┘ └─────────────────────┘ └────────────────────┘ 数据: 万亿 token 原始文本 数据: (prompt, 数据: (prompt, chosen, 数据: (prompt, 可验证 (网页/书籍/代码) response) 示范对 rejected) 偏好对 答案) 例如数学题 规模 ~10¹² token 规模 ~10⁴–10⁶ 规模 ~10⁴–10⁶ 规模 ~10³–10⁵ 目标: next-token 交叉熵 目标: 只对 response 目标: max E[r] − β·KL 目标: 组相对优势 × L = −Σ log p(tᵢ|t<ᵢ) 算交叉熵 (PPO) 或 DPO 规则奖励 (对/错, (loss masking) 闭式偏好损失 格式) 的策略梯度 产物: 知识与能力 产物: 会听指令、 产物: helpful / honest / 产物: long CoT、 的"原料" 会用 chat 格式 harmless 的助手 会反思的推理模型 ────────────────── 模块 01 ────────────── 模块 02/03/04 ─────────── 模块 05 ──────────

把四个目标函数并排写出来，能看清这条管线在数学上的递进：

$$ \text{Pre-train / SFT:}\quad \mathcal{L} = -\sum_{i\,\in\,\mathcal{M}} \log \pi_\theta(t_i \mid t_{<i}) \qquad \begin{cases}\text{预训练: } \mathcal{M}=\text{全部 token}\\[2pt] \text{SFT: } \mathcal{M}=\text{仅 response token}\end{cases} $$
$$ \text{RLHF:}\quad \max_{\pi_\theta}\; \mathbb{E}_{x\sim\mathcal{D},\,y\sim\pi_\theta}\big[\, r_\phi(x,y)\,\big] \;-\; \beta\,\mathrm{KL}\!\big(\pi_\theta(\cdot|x)\,\|\,\pi_{\text{ref}}(\cdot|x)\big) $$
$$ \text{RLVR:}\quad r(x,y) = \mathbb{1}[\,\text{answer}(y)=\text{answer}^*(x)\,] + \lambda\cdot\mathbb{1}[\,\text{format ok}\,] \quad\text{（奖励来自规则验证器，而非学出来的 } r_\phi \text{）} $$
注意三条公式里反复出现的 $\log \pi_\theta(y|x)$——逐 token logprob 是整个后训练的"原子操作"： SFT 最大化它，PPO/GRPO 用新旧策略的 logprob 比值做 importance ratio，DPO 用 policy 和 reference 的 logprob 差做隐式奖励，KL 惩罚也是两组 logprob 之差。 本模块 notebook 的冒烟测试就是先把它跑通。
这条 SFT → RM → RLHF 三段式管线由 InstructGPT [Ouyang 2022] 确立，至今仍是工业界主干； DPO [Rafailov 2023] 证明偏好对齐可以绕过显式 RM 与 RL 循环； DeepSeek-R1 [DeepSeek-AI 2025] 则展示了纯 RLVR 能"涌现"出反思与长链推理。三篇是本课的纲。

3学习法：推导 · 玩具实现 · 真实小模型实跑

每个模块都按同一个三层结构组织，对应"懂原理 → 懂实现 → 懂工程"：

  • 第一层：推导（HTML 讲解）——每个损失函数从动机出发完整推导，不跳步。你应该能在白板上从 RLHF 目标推出 DPO。
  • 第二层：玩具实现（notebook 主体）——核心算法全部用纯 PyTorch 在玩具规模实现，CPU 可跑：3-token 词表的"语言模型"、几十个参数的策略网络。规模小到每个中间张量都能打印出来看。
  • 第三层：真实小模型实跑（notebook 可选段）——用 Qwen/Qwen2.5-0.5B-Instruct 走一遍真实工具链（peft/trl），标 GPU可选，全部带确定性 mock 回退，没有 GPU、不下载模型也能跑通全流程。
✏️ 练习必做，不是可选。每个 notebook 含 2–4 道练习：给函数骨架 + TODO，配 assert 自测 cell，全过才算通过；末尾有 📖 参考答案，但先自己写。 后训练的算法（PPO 的 ratio clipping、DPO 的 logprob 差、GRPO 的组归一化）全是"看着都懂、一写就错"的类型——肌肉记忆只能靠写。

5前置自测 5 问

下面 5 问覆盖了本课依赖的全部前置概念。能口头回答 4 问以上即可直接开始；否则按括号里的指引补课（每个点 1–2 小时足够）。

  1. 交叉熵：写出分类交叉熵损失 $-\log p_\theta(y^*)$，并说明"最小化交叉熵 = 最大化正确 token 的 logprob"为什么成立。（不熟 → 复习极大似然估计）
  2. Policy gradient 直觉：一句话解释 $\nabla_\theta \mathbb{E}[R] = \mathbb{E}[R \cdot \nabla_\theta \log \pi_\theta(a)]$ 在做什么——为什么"提高高回报动作的 logprob"就是它的全部？（不熟 → REINFORCE 推导，模块 03 也会从头讲）
  3. KL 散度：写出 $\mathrm{KL}(P\|Q)=\sum_i p_i \log\frac{p_i}{q_i}$，并回答：它对称吗？什么时候为 0？为什么 RLHF 用它把策略"拴"在 reference model 附近？（不熟 → notebook 练习 2 会让你亲手实现）
  4. LoRA 概念：LoRA 把权重更新约束成 $\Delta W = BA$（低秩分解），为什么这能把可训练参数降低两个数量级而效果损失很小？（不熟 → 知道"冻结原权重、只训低秩旁路"即可，模块 01 详讲）
  5. logprob 计算：给定 LLM 输出的 logits 张量（形状 [seq_len, vocab]）和一个 token 序列，如何算出该序列的总 log 概率？（不熟 → 这正是 notebook 练习 1，做完就熟）
注意第 1、2、5 问其实是同一件事的三个侧面：后训练的所有算法最终都化归为"调整某些序列的 logprob"——SFT 无条件抬高示范序列，RLHF/GRPO 按回报加权抬高或压低采样序列，DPO 抬高 chosen 压低 rejected。抓住这条主线，整门课就是一个故事。

6全局图景与评测视角：每个阶段引入能力，也引入偏差

本课的独特视角：把后训练管线当作评测对象的"病史"来读。每个训练阶段在赋予模型新能力的同时，都系统性地引入了可测量的行为偏差——而且这些偏差不是 bug，是目标函数的必然产物：

阶段引入的能力引入的偏差偏差的根源
SFT指令遵循、对话格式格式偏置：模仿示范的表面风格（markdown、列表、固定开场白），benchmark 上"格式刷分"极大似然学的是示范分布的全部特征，分不清内容与形式 [Zhou 2023, LIMA]
RLHFhelpful / harmless 偏好谄媚 sycophancy：迎合用户既有观点；以及 length bias（越长越高分）RM 学的是"人类标注者喜欢什么"，而人偏爱认同自己、内容详尽的回答 [Sharma 2023]
RLVRlong CoT、自我反思过度思考 overthinking：简单问题也展开千 token 推理；CoT 可能与真实计算脱节奖励只看最终答案对错，更长的探索在训练中平均回报更高
评测人不懂管线，就无法归因。看到一个模型在 judge 评测里分数虚高，你必须能分诊：是 SFT 格式刷分（换 length-controlled 评测试试 [Dubois 2024]）？是 RLHF 的 sycophancy（换对抗性 persona 试试）？还是 judge 自身的偏置？ 三种病根对应三种完全不同的修复路径——开错药方比不开更糟。这正是模块 06 的核心训练内容，也与《LLM 评测科学》课的 judge 偏置、contamination 章节直接互通：那门课教你怎么测，这门课教你为什么模型会变成这样。

一个有用的心智模型：后训练阶段越靠后，行为越"讨喜"，但与 base model 真实能力分布的 KL 距离越大。评测一个对齐后的模型，本质上是在测量"这段 KL 预算花得值不值"——买到了多少安全与有用性，付出了多少多样性、校准度（calibration）与诚实性的代价 [Askell 2021 的 alignment tax]。

7研究前沿与开放问题

  • 对齐是表层的还是深层的？ superficial alignment hypothesis [Zhou 2023] 认为后训练只学了"格式与风格"，知识全部来自预训练。若为真，对齐评测应聚焦行为稳健性而非能力；但 RLVR 涌现推理 [DeepSeek-AI 2025] 似乎是反例——能力确实在后训练中变化了。这条争论决定了"能力评测"与"对齐评测"能否解耦。
  • RM 是真实偏好的劣质代理。 对 proxy reward 的过度优化必然偏离真实目标 [Gao 2022 的 overoptimization scaling laws]。开放问题：能否在线检测"策略开始 hack RM"的拐点？评测视角：RewardBench 式静态评测能多大程度预测 RM 在 RL 中的下游表现？
  • Process vs outcome supervision。 只奖励最终答案（ORM）会纵容"歪打正着"的错误推理；逐步监督（PRM [Lightman 2023]）更可靠但标注极贵，且 CoT 的忠实性（faithfulness）本身存疑——模型写下的推理未必是它真实的计算路径。这直接威胁所有基于 CoT 的评测与监控方案。
  • 对齐方法的可扩展性。 当模型强于标注者，人类偏好还能当监督信号吗？weak-to-strong generalization [Burns 2023]、Constitutional AI / RLAIF [Bai 2022] 是两条主要回应路线，模块 07 展开。评测视角：怎么评一个"评测者本身已看不懂其输出"的模型？
  • 后训练配方的科学化。 各家管线（先 DPO 还是先 RLHF？RLVR 数据配比？）仍以 ablation 玄学为主，缺少预测性理论。Tülu 3 [Lambert 2024] 是少数全开源配方，值得精读。
