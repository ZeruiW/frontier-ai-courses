怎么用： 每个模块先读 HTML 讲解 建立「agent 到底是什么」的解剖直觉，再跑 notebook 亲手用纯标准库把那一块基础设施从零写出来、用确定性 MockLLM 端到端跑通、通过 ✏️ 练习的 assert 判分。配套 术语词典 与 参考清单。本课的立场是：不止会用 Claude Code / LangChain 这类 agent 框架，而是会亲手造一个——把一个能跑的 agent 的核心结构（感知-决策-行动-观察循环、ReAct 解析、工具注册与分发、LLM 适配器、超时/重试/循环检测）一层层从零拆开、亲手重建。全程不依赖任何框架、不需要 API key：我们用一个返回预设动作的 MockLLM 当「假大脑」，让每个 agent 都端到端真实运行、用 assert 验证它确实多步完成了任务；同时每个 notebook 都附一段「换上真实 Claude Messages API」的适配代码，有 key 就接真模型、没 key 自动回退 MockLLM，绝不让缺 key 阻断 notebook。学完你能读懂任何 agent 框架的源码、并把验证过的循环逻辑接到真实 claude-opus-4-8 上。
