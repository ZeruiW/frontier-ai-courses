1随机种子方差：信号还是运气

受控实验给了你多次运行的数字。现在是研究里最关键、也最常被搞砸的一步：判断这些数字之间的差异，是真信号，还是随机的运气。这正是统计学的用武之地——它不是为了让论文显得高深的装饰，而是区分信号与噪声的唯一严谨工具。

机器学习里最普遍、最致命的统计错误，只有一个名字：random seed variance（随机种子方差）。同一个实验，仅仅换一个随机种子（影响初始化、数据顺序、dropout……），结果就会不同。而这个方差常常大到能淹没方法之间的真实差异。Henderson et al. 2018 在深度强化学习里证明：许多被报告的「提升」，在控制随机性后根本不存在——它们只是樱桃挑选的幸运种子。

直白说

打个比方：两个篮球运动员，真实命中率完全相同。让他们各投 5 球，几乎必然有一个投进得多——但这不代表他谁更准，只是这 5 球的运气。如果你看到「投进多」就宣布他更强，你就犯了机器学习里最常见的错误：把种子运气当成方法的优越性。解药是让他们各投 500 球（多种子），运气被平均掉，真实水平才显现。

严谨说

形式化：每次运行的结果 $x_i = \mu + \epsilon_i$，其中 $\mu$ 是方法的真实期望性能，$\epsilon_i$ 是该次运行的随机波动（种子噪声），$\mathbb{E}[\epsilon_i]=0$，$\text{Var}(\epsilon_i)=\sigma^2$。你想估计的是 $\mu$，但你只观测到带噪的 $x_i$。单次运行 $x_1$ 是 $\mu$ 的一个高方差估计；$n$ 次运行的均值 $\bar x$ 的方差是 $\sigma^2/n$——跑得越多，估计越准。这就是本模块所有方法的数学根基。

本模块教你五件事，每一件都直接回应「这是真的吗」：报多次运行与方差（别只报一个数）、bootstrap 置信区间（量化不确定性）、功效分析（该跑多少次才够）、多重比较校正（比较很多东西时别被假阳性骗）、效应量（差异不仅要显著，还要够大）。学完它们，你就能给任何一个「A 比 B 好」的主张，配上它应得的统计严谨性。

2报多次运行：方差不可省

报多次运行：一个没有方差的数字等于没有信息

第一条、也是最基本的纪律：永远不要只报一个数字。「我的方法准确率 90.2%」这句话，缺了最关键的信息——它有多稳？换个种子还是 90.2 吗，还是会在 88–92 之间乱跳？没有方差，读者无法判断你和基线的差距是真实的还是噪声。一个孤零零的数字，在科学上几乎没有意义。

正确的报告方式是均值 ± 标准差（或置信区间），基于多个随机种子的运行。约定俗成至少 3–5 个种子，越多越好（重要结论 10+）。报告时还要说清楚：跑了几个种子、方差是标准差还是标准误、种子是随机选的还是固定的几个。

这里要分清两个容易混淆的量。standard deviation（标准差 $\sigma$）描述单次运行的离散程度——它不随样本量减小，反映的是过程本身的内在波动。standard error（标准误 SE）描述均值这个估计的精度：

\[\text{SE} = \frac{\sigma}{\sqrt{n}}\]

关键区别：你跑更多种子，标准差 $\sigma$不会变小（过程波动是固定的），但标准误 SE会随 $\sqrt n$ 变小——你对均值的估计变精了。所以「多跑几个种子有什么用」的数学答案是：它不改变单次运行的波动，但让你对真实期望性能的估计越来越可信。报「均值的不确定性」时用 SE（或 CI），报「运行的波动范围」时用 $\sigma$，两者别混。

注意 $\sqrt n$ 这个关系暗含一个残酷的收益递减：要把标准误减半，需要四倍的种子；减到三分之一，需要九倍。这意味着「再多跑几个种子让结果更稳」的边际成本越来越高——从 5 个种子加到 20 个（4 倍算力）才把不确定性减半。所以种子数不是越多越好，而要用功效分析（下面第 4 节）算出「够用」的数量：够检测出你关心的效应即可，盲目堆种子是在为递减的精度付指数的代价。

Bouthillier et al. 2021 揭示了一个更深的问题：随机种子不是唯一的方差来源。数据划分、超参选择、数据增强的随机性、甚至硬件的非确定性，都贡献方差。只固定/只变种子，会严重低估真实的不确定性——你以为的 ±0.4 可能实际是 ±1.2（算上划分方差）。最严谨的做法是把多个随机源都纳入重复（变种子且变划分），这就是variance decomposition（方差分解）要回答的：哪个来源主导了你的不确定性。notebook 会让你做一次方差分解。

3Bootstrap 置信区间

Bootstrap：不靠分布假设地估计不确定性

你有了多次运行，想给一个统计量（均值、中位数、两方法的差……）配一个confidence interval（置信区间）。经典方法（如 t 分布 CI）需要假设数据服从正态分布；但机器学习的指标常常不正态（有界、偏态、小样本）。bootstrap（自助法）是更通用、几乎不需要分布假设的武器。

Bootstrap 的思想优雅得近乎魔法：把你手上的样本当成总体，从它有放回地反复重采样，每次采样算一遍统计量，这些统计量的分布就近似了该统计量的真实抽样分布。具体步骤：

  1. 有放回重采样：从 $n$ 个观测里，有放回地抽 $n$ 个，得到一个「bootstrap 样本」（有的原始点出现多次，有的没出现）。
  2. 算统计量：在这个 bootstrap 样本上算你关心的统计量（如均值）。
  3. 重复 B 次（如 B=10000），得到 B 个统计量值，构成它的 bootstrap 分布。
  4. 取分位数：这 B 个值的 2.5% 和 97.5% 分位数，就是 95% 置信区间（percentile bootstrap）。
Bootstrap 的核心循环 原始样本 (n=5): [88.1, 90.2, 89.5, 90.4, 89.0] │ ├─ 重采样1(有放回): [90.2, 88.1, 90.2, 89.0, 90.4] → 均值 89.58 ├─ 重采样2: [89.5, 89.5, 90.4, 88.1, 89.0] → 均值 89.30 ├─ ... (重复 10000 次) └─ 重采样10000: [...] → 均值 ... │ ▼ 10000 个均值的分布 → 取 2.5% 与 97.5% 分位数 = 95% 置信区间 [89.0, 90.1] ← 真实均值有 95% 把握落在这个区间

Bootstrap 的威力在于通用性：它对任何统计量都适用——不只是均值，还有中位数、两方法准确率之差、相关系数、甚至 AUC 这种复杂指标。只要你能在一个样本上算出这个量，bootstrap 就能给它配一个置信区间，而无需推导该量的理论分布（很多复杂指标根本推不出来）。这让它成为机器学习实验报告里最实用的统计工具之一。

Bootstrap 也有它的适用边界，值得清醒认识。它假设你手上的样本能代表总体——如果样本本身有偏（如只跑了 3 个种子、且恰好都偏高），bootstrap 会忠实地复现这个偏差，给出一个过于乐观的窄区间。换句话说，bootstrap 量化的是「在你这份样本所反映的随机性下」的不确定性，它不能凭空修复样本太小或有系统偏差的问题——垃圾进、垃圾出。所以 bootstrap 不是「少跑几次也能蒙混过关」的捷径：它需要一个足够大、足够无偏的样本（足够多的种子）才可靠。它与「多跑几个种子」是互补而非替代——先有足够的运行，再用 bootstrap 从中诚实地提取不确定性。

为什么「有放回」是关键？因为它模拟了「如果重新做一次实验，会抽到一组略有不同的数据」这件事。每个 bootstrap 样本都是「平行宇宙里的一次重做」，10000 个平行宇宙的结果分布，就告诉你你的统计量有多稳。bootstrap 把「重复实验」这个昂贵的物理过程，变成了在一份数据上的廉价重采样——这是它最聪明的地方。notebook 会让你从零实现 percentile bootstrap，并验证它的覆盖率。

4功效与样本量：跑多少种子

功效与样本量：该跑多少个种子？

一个常被问、却很少被正确回答的问题：我该跑多少个种子（或多少个样本）才够？答案藏在statistical power（统计功效）里。功效 = 当真效应确实存在时，你的实验能检测到它（得出统计显著）的概率，记作 $1-\beta$。

理解功效的关键，是分清两类错误：

真相：无效应真相：有效应
你判: 无效应✅ 正确❌ Type II error (假阴性, 概率 β)
你判: 有效应❌ Type I error (假阳性, 概率 α)✅ 正确 (概率 1−β = 功效)

功效不足的实验有一个致命的解释陷阱：当它「没测出差异」时，你无法区分「真的没差异」和「有差异但样本太少没测出来」。一个只跑 2 个种子的实验说「A 和 B 没显著差异」，几乎没有信息量——它的功效可能低到连真实存在的差异都看不见。「没发现差异」不等于「没有差异」，除非你的功效足够高。

功效由四个量相互决定：效应量（差异多大）、方差（噪声多大）、样本量 $n$（跑多少次）、显著性水平 $\alpha$。其中三个定了，第四个就定了。功效分析通常这样用：给定你想检测的最小效应量、估计的方差、希望的功效（如 0.8）和 $\alpha$（如 0.05），反解出所需的样本量 $n$。近似地，所需样本量随效应量的平方反比增长——想检测小一半的效应，要四倍的样本。

功效分析的实践价值：它让你在跑实验之前就知道「这个实验值不值得做」。如果你想检测的效应很小（如 +0.2 分）、方差又大（±0.5），功效分析会告诉你需要跑几十甚至上百个种子才有 80% 功效——这时你要么接受「跑不起，结论只能存疑」，要么想办法降低方差（如配对设计、控制更多变量）。跑一个功效不足的实验，是在浪费算力得出一个无法解释的结果。notebook 会让你做一次功效分析、算出所需种子数。

5多重比较：假阳性的陷阱

多重比较：比较越多，假阳性越多

现在一个隐蔽的陷阱：当你同时做很多次比较时——比较多个方法、多个超参、多个数据集、多个指标——即使全都没有真效应，也会偶然冒出「显著」的结果。这就是 multiple comparisons（多重比较）问题，是 p-hacking 的温床。

数学很直接：单次检验在 $\alpha=0.05$ 下，无效应时有 5% 概率假阳性。做 $m$ 次独立检验，至少一个假阳性的概率是 $1-(1-0.05)^m$：

\[m=1:\ 5\%\qquad m=10:\ 40\%\qquad m=20:\ 64\%\qquad m=100:\ 99.4\%\]

也就是说，你比较 20 个方法/超参/数据集，即使它们真实水平完全一样，你也几乎一定能找到一个「显著更好」的——然后兴高采烈地报告它。这就是为什么「我试了很多配置，发现 X 显著最好」是高度可疑的：你做了多重比较却没校正。

解药是多重比较校正，控制family-wise error rate（族错误率，FWER = 至少一个假阳性的概率）。两个主力方法：

  • Bonferroni correction：最简单——把显著性阈值除以比较次数，用 $\alpha/m$ 代替 $\alpha$。保守、可靠，但功效损失大（漏掉真效应）。
  • Holm correction（Holm–Bonferroni）：把 $m$ 个 p 值升序排列，第 $i$ 小的用阈值 $\alpha/(m-i+1)$ 检验，一旦某个不通过就停止。控制同样的 FWER，但功效更高、无额外假设——应优先于 Bonferroni。

直觉记法：Bonferroni 把「预算」（总的 5% 假阳性风险）平均分给每个检验；Holm 更聪明，先用最严的阈值卡最显著的那个，过了就把省下的预算让给后面的，所以能多发现一些真效应。还有一类是控制 false discovery rate（FDR，如 Benjamini–Hochberg），它控制的是「报告为显著的结果中假阳性的比例」，比 FWER 宽松、功效更高，适合大规模筛选（如基因、特征选择）。选哪个取决于你多怕假阳性：怕到一个都不能错用 Holm/Bonferroni，能容忍一定比例错误用 BH。notebook 会让你实现并对比 Bonferroni 与 Holm。

6效应量：显著≠重要

效应量：显著 ≠ 重要

最后一个、也是最常被忽视的概念：effect size（效应量）。统计显著（p 值小）只告诉你「差异不太可能纯由偶然产生」，它不告诉你差异有多大、多重要。这两件事经常被混为一谈，造成大量误读。

一个扎心的事实：只要样本足够大，任何微不足道的差异都能变得统计显著。在百万样本上，准确率 90.00% vs 90.01% 的差异都可能 p<0.001——统计上「极显著」，但实际上毫无意义（0.01% 的提升谁在乎）。反过来，一个真实重要的大效应，在小样本上可能不显著。所以p 值和效应量必须一起报：p 值管「是不是真的有差异」，效应量管「这差异值不值得在意」。

效应量的常见度量：

  • 绝对差异：最直白——准确率提升了几个百分点、损失下降了多少。读者能直接理解其实际意义。
  • Cohen's d：标准化的效应量 = 两组均值差 ÷ 合并标准差。它把差异用「多少个标准差」表示，让不同尺度的实验可比。约定 0.2 / 0.5 / 0.8 为小 / 中 / 大效应。
  • 相对提升：差异占基线的百分比（如错误率从 10% 降到 8% 是相对降低 20%）。注意它可能夸大小绝对差异。
\[\text{Cohen's } d = \frac{\bar x_1 - \bar x_2}{s_{\text{pooled}}},\qquad s_{\text{pooled}} = \sqrt{\frac{(n_1-1)s_1^2 + (n_2-1)s_2^2}{n_1+n_2-2}}\]

直白说

报告结果时，先问「显著吗」（差异是真的吗），再问「多大」（值得在意吗）。一个负责任的结论长这样：「方法 B 比 A 高 2.1 分（Cohen's d=0.9，大效应），bootstrap 95% CI [1.3, 2.9]，配对检验 p=0.002」——它同时给了大小、不确定性、显著性。而「B 显著优于 A（p<0.05）」这种只报显著性的句子，藏起了最重要的「大不大」。

严谨说

ASA（美国统计学会）2016 年专门发声明纠正 p 值误用：p 值不是效应为真的概率，不是效应大小，不能单独支撑科学结论。把 p<0.05 当成「重要发现」的通行证，是科学界最普遍的统计误读。本课的立场是：报效应量 + 置信区间，优先于报 p 值——前者传达了「多大、多确定」，信息量远高于一个二元的「显著与否」。

延伸阅读：Cohen《A Power Primer》（功效与效应量入门）、Wasserstein & Lazar《ASA Statement on p-Values》（p 值的六条原则）、Demšar《Statistical Comparisons of Classifiers over Multiple Data Sets》（多方法多数据集的正确统计）。清单见 references.md。

7worked：方差+CI+功效

worked 例：多 seed 方差 + bootstrap CI + 功效分析

本模块 notebook 的核心 worked 例，把统计三件套在一个场景里串起来：多 seed 运行测方差 → bootstrap 算置信区间 → 功效分析估所需 seed 数。

场景：你想证明方法 B 比基线 A 好。你各跑了若干个种子，得到两组准确率。你要回答三个递进的问题：

  1. 差异有多大、多稳？——算两组的均值、标准差，以及差异的 bootstrap 95% 置信区间。如果 CI 不跨过 0，差异可信。
  2. 这个差异显著吗？——做一个配对/独立的检验（或直接看 CI 是否含 0），得出是否统计显著。
  3. 如果想更确信，该再跑多少种子？——用功效分析，给定观测到的效应量和方差，算出达到 80% 功效所需的种子数。

这个 worked 例的价值在于，它把「A 比 B 好吗」这个看似简单的问题，拆成了一套有纪律的统计流程，每一步都防住一类错误：多 seed 防种子运气、bootstrap 防分布假设错误、功效分析防「样本不足却下结论」。做完它，你以后看到任何「A 比 B 好」的主张，脑子里会自动浮现这三个问题——这就是统计素养内化的标志。

还要点破一个常见的误会：很多人觉得「做统计」是论文快写完时补上去的一道手续——结果都跑完了，再算个 p 值、加个误差棒交差。这是本末倒置。统计应当在实验设计阶段就介入：在跑实验之前，功效分析就告诉你「要检测这个效应得跑多少种子」（跑少了等于白跑）；比较方案之前，多重比较的意识就提醒你「别试一百组挑最好的」。把统计当成事后补丁，你只能描述已经发生的（而且常常发现样本不够、结论下不了）；把统计当成事前设计的一部分，你才能主动地保证实验产出的证据足够强。这就是为什么本模块紧跟在实验设计（模块 02）之后——它们本就是一体两面。

notebook 还会让你亲眼看到一个反直觉但极重要的现象：同样真实的 +0.5 分差异，跑 3 个种子时 bootstrap CI 宽得跨过 0（结论「不显著」），跑 30 个种子时 CI 收窄到完全在 0 以上（结论「显著」）。同一个真相，样本量决定了你能不能看见它——这正是功效的直观体现，也是「该跑多少种子」这个问题为什么重要。

把这套流程养成习惯后，你看待结果的方式会发生质变。以前你看到的是数字（90.2 vs 89.7，B 赢），现在你看到的是分布（两个带不确定性的估计，它们重叠吗）。前者让你急于宣布胜负，后者让你先问「这个差异扛得住重采样吗、扛得住换一批种子吗」。这种从「点估计思维」到「分布思维」的转变，是统计素养最核心的标志，也是区分「跑实验的人」和「做研究的人」的分水岭——前者报一个数就完事，后者永远在问这个数有多确定、配不配得上他想下的结论。

8研究前沿与开放问题

研究前沿与开放问题

  • 机器学习基准的方差核算：Bouthillier et al. 推动「把所有方差来源纳入报告」，但实践中算力有限，如何在固定预算下最优地分配重复（多种子 vs 多划分 vs 多超参）仍是开放的优化问题。
  • 多数据集比较的正确统计：Demšar 主张用 Friedman + Nemenyi 等非参方法比较多个分类器，但社区仍大量误用配对 t 检验。如何让正确的统计方法成为默认，是方法学推广的难题。
  • 深度学习结果的脆弱性：Henderson et al.（RL）、Recht et al.（ImageNet）等反复揭示已发表结果对种子/划分/实现的脆弱性。在大模型时代（单次训练极贵、几乎无法多种子重复），如何保证统计严谨性，是尖锐的现实矛盾。
  • p 值之外：贝叶斯方法、置信区间优先、预注册等替代/补充 NHST（零假设显著性检验）的范式正在兴起，但各有门槛与争议，尚无统一最佳实践。
  • 效应量的领域基准：Cohen 的 0.2/0.5/0.8 来自社会科学，未必适配机器学习。一个准确率提升多大算「重要」，高度依赖任务与应用，缺乏领域共识。
  • 从 NHST 到决策：零假设显著性检验（NHST）回答「有没有差异」，但研究者真正要的常是「该不该采用这个方法」——这是一个夹带成本与风险的决策问题。如何从「显著性」过渡到「期望收益/损失」的决策框架，是统计实践正在演进的方向。

必读：Bouthillier et al.《Accounting for Variance in ML Benchmarks》（方差来源）、Henderson et al.《Deep RL that Matters》（种子脆弱性实证）、Demšar《Statistical Comparisons of Classifiers》（多方法统计）。清单见 references.md。
