# 术语词典 · Glossary（研究方法论与科学实践）

> 按主题分组，每条 2–3 句释义。读论文、设计实验、写 rebuttal、审稿遇到生词回这里查；英文术语保留原文（学术写作与审稿的通用语言）。本课用 numpy/pandas 在 CPU 上把这些概念跑成可验证的小实验，但术语与真实研究实践一一对应。

## 研究的本质 · What Research Is

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| claim / hypothesis | 主张 / 假设 | 研究产出的核心是一个**可证伪**的主张（如「方法 X 在任务 T 上优于基线 B」）。好的主张范围明确、能被证据支持或推翻；模糊到无法证伪的主张没有科学价值。 |
| falsifiability | 可证伪性 | Popper 的判据：一个主张要算科学，必须存在能推翻它的潜在观测。「我的方法在某些情况下有时更好」不可证伪，因而几乎无信息量。 |
| evidence | 证据 | 支持或反对主张的观测（实验数字、对照、消融、理论证明）。研究的功夫全在于：让证据**强到**能担起主张的**重量**——主张越大，需要的证据越强。 |
| claim–evidence mapping | 主张-证据映射 | 把论文（或自己工作）的每个主张，逐一对应到支持它的具体证据（哪张表、哪个图、哪条定理）。找不到证据的主张 = 过度声明；找不到主张的证据 = 离题。本课贯穿始终的核对工具。 |
| reproducibility | 可复现性 | 用**相同**的代码、数据、配置，能否得到**相同**的结果。是科学的最低门槛；做不到，结果就不可信。区别于 replicability。 |
| replicability | 可重复性 | 用**独立**的实现/数据，能否得到**一致**的结论。比 reproducibility 更强：它检验的是科学发现本身，而非某次运行。 |
| reproducibility crisis | 可复现性危机 | 多领域（心理学、医学、机器学习）发现大量已发表结果无法被复现的现象。成因包括 p-hacking、只报最好运行、随机种子樱桃挑选、代码/数据不公开。 |
| research taste | 研究品味 | 判断「哪个问题值得做、哪个结果重要、哪个方法优雅」的隐性能力。来自大量读论文与做实验的积累，是把「会做实验」提升到「会做好研究」的关键。 |

## 读论文与复现 · Reading & Reproducing

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| three-pass reading | 三遍读法 | Keshav 的读论文法：第一遍（5–10 分钟）读标题/摘要/章节标题/结论，判断要不要读下去；第二遍（1 小时）抓主旨、看图表、标记不懂处；第三遍（数小时）「虚拟复现」——假装自己重做这项工作，逐步质疑每个假设。 |
| ablation study | 消融实验 | 系统地移除/替换方法的某个组件，看性能掉多少，从而**归因**——证明是这个组件而非别的因素带来了增益。读论文时消融表是判断「贡献是否真实」的核心证据。 |
| baseline | 基线 | 用于对比的参照方法（已有 SOTA、朴素方法、或去掉新组件的版本）。没有强基线的「我的方法很好」毫无意义；弱基线（调参不足的对手）是论文最常见的不诚实手法之一。 |
| sanity check | 合理性检查 | 用极简的、已知答案的情形验证实现是否正确（如：随机标签下准确率应≈随机水平；恒等变换后输出应不变）。复现的第一道关卡。 |
| reproduction checklist | 复现检查表 | 复现一篇论文前要核对的清单：数据集与划分、预处理、模型与超参、训练细节、评测指标定义、随机种子、软硬件版本。任一项缺失都可能导致复现失败。 |
| credibility assessment | 可信度评估 | 给一个研究结果打信任分：是否有对照与消融、是否报多次运行与方差、基线是否够强、是否过度声明、代码数据是否公开、是否与已知结果一致。 |
| cherry-picking | 樱桃挑选 | 只挑选支持自己结论的样本/运行/指标来报告，隐藏不利结果。最隐蔽也最常见的学术不端，靠预注册、报全部运行、报方差来防。 |
| extraordinary claims | 非凡主张 | Sagan 标准：「非凡的主张需要非凡的证据」。论文声称越反直觉、越颠覆，越要警惕证据是否匹配——这是读论文时校准怀疑度的准星。 |

## 实验设计 · Experiment Design

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| controlled experiment | 受控实验 | 只改变你关心的那个变量（自变量），其余一切（数据、超参、随机种子、评测）保持不变，从而把结果差异**归因**于该变量。是因果归因的黄金标准。 |
| independent / dependent variable | 自变量 / 因变量 | 自变量是你主动改变的（如学习率、是否加某模块）；因变量是你测量的结果（如准确率、损失）。实验设计就是：变自变量、测因变量、控住其余一切。 |
| control group / treatment group | 对照组 / 实验组 | 对照组不施加干预（如不加新模块），实验组施加干预；两组其余条件相同，差异即干预效应。没有对照组，「我加了 X 就涨了」无法排除「本来就会涨」。 |
| confounder / confounding variable | 混杂变量 | 同时影响自变量与因变量、制造虚假关联的第三变量。典型陷阱：新方法同时用了更多算力/数据/调参，涨点可能来自这些混杂而非方法本身。 |
| OFAT (One Factor At A Time) | 一次只变一个量 | 受控实验的核心纪律：一次实验只改一个因素。同时改两个，涨了也不知道是哪个的功劳（甚至互相抵消）。违反它是新手最常犯、最致命的错误。 |
| randomization | 随机化 | 把样本随机分配到各组、随机化处理顺序，以打散未知混杂、让组间在期望上可比。随机种子是机器学习里随机化的具体载体。 |
| randomized controlled trial (RCT) | 随机对照试验 | 同时具备随机化与对照组的实验设计，是因果推断的最强证据形式（源自医学）。机器学习的「多种子受控对比」是它的近亲。 |
| ablation matrix | 消融矩阵 | 把多个组件的「开/关」组合排成表格，系统地测每种组合的性能，从而分离各组件贡献及其交互。比逐个消融更能揭示组件间是否协同。 |
| interaction effect | 交互效应 | 两个因素的联合效应不等于各自效应之和（A 单独无用、B 单独无用、A+B 却有用）。OFAT 看不到交互，需用因子设计（factorial design）才能捕捉。 |
| factorial design | 因子设计 | 同时系统地变化多个因素的所有组合，能在一次实验里估计主效应与交互效应，比 OFAT 信息量更高，是 OFAT 在「怀疑有交互」时的升级。 |

## 研究统计 · Statistics for Research

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| random seed variance | 随机种子方差 | 同一实验仅换随机种子（影响初始化、数据顺序、dropout 等）就会得到不同结果。这个方差常常**大到能淹没**方法间的真实差异——只跑一个种子是机器学习实验最普遍的错误。 |
| run-to-run variance | 运行间方差 | 重复同一实验得到的结果波动。报告时必须给出（均值 ± 标准差，或置信区间），否则读者无法判断差异是真效应还是噪声。 |
| confidence interval (CI) | 置信区间 | 一个区间，在重复实验意义下以给定概率（如 95%）覆盖真值。报区间比报单点更诚实：它同时传达了估计值与不确定性。 |
| bootstrap | 自助法 | 用「有放回重采样」从一份样本反复造出许多伪样本、各算一遍统计量，从而**无需分布假设**地估计该统计量的抽样分布与置信区间。本课的主力统计工具。 |
| standard error (SE) | 标准误 | 一个估计量（如样本均值）的标准差，衡量该估计本身的波动。SE = 样本标准差 / √n：样本越大，估计越稳——这是「多跑几个种子」的数学依据。 |
| statistical power | 统计功效 | 当真效应确实存在时，实验能检测到它（拒绝原假设）的概率（=1−β）。功效不足的实验「没测出差异」既可能是真没差异，也可能只是样本太少，无法区分。 |
| sample size / n | 样本量 | 实验的观测数（机器学习里常是「种子数」或「测试样本数」）。样本越大，估计越精、功效越高。功效分析就是反过来算「要多少样本才够」。 |
| effect size | 效应量 | 差异的**大小**（如 Cohen's d、准确率绝对提升），独立于样本量。统计显著（p 小）不等于效应大；大样本能让微不足道的差异也显著，所以必须同时报效应量。 |
| Cohen's d | 科恩 d | 标准化的效应量：两组均值差 ÷ 合并标准差。约定俗成 0.2/0.5/0.8 为小/中/大效应。让不同尺度的实验的效应大小可比。 |
| p-value | p 值 | 假设原假设（无效应）为真时，观测到当前或更极端结果的概率。p 小提示「数据与无效应不符」，但**不是**「效应为真的概率」，也不是效应大小——是被误用最严重的统计量。 |
| null hypothesis (H0) | 原假设 | 「无效应/无差异」的默认假设。统计检验试图用数据**反对**它；反对成功（p 小）称统计显著，但永远无法「证明」H0 为真。 |
| statistical significance | 统计显著性 | 通常指 p < α（α 常取 0.05）。它只说「差异不太可能纯由偶然产生」，不说差异**重要**或**大**——把显著当成「重要」是经典误读。 |
| multiple comparisons | 多重比较 | 同时做很多次检验时，即使全无真效应，也会偶然冒出「显著」结果（做 20 次检验，期望 1 次假阳性）。比较多个方法/超参/数据集时必须校正。 |
| Bonferroni correction | 邦费罗尼校正 | 最简单保守的多重比较校正：把显著性阈值除以检验次数（α/m）。控制「至少一个假阳性」的概率，代价是功效下降。 |
| Holm correction | 霍尔姆校正 | Bonferroni 的逐步改进：把 p 值排序后用递减的阈值检验，控制同样的错误率但功效更高，无额外假设，应优先于 Bonferroni。 |
| family-wise error rate (FWER) | 族错误率 | 一组检验中「至少出现一个假阳性」的概率。Bonferroni/Holm 控制的就是它。 |
| false discovery rate (FDR) | 错误发现率 | 被判为「显著」的结果中假阳性的期望比例。Benjamini–Hochberg 控制它，比 FWER 宽松、功效更高，适合大规模筛选。 |
| variance decomposition | 方差分解 | 把观测的总波动拆成不同来源（如「种子方差」与「数据划分方差」），看哪个主导。Bouthillier 的工作表明随机种子等多个来源共同贡献，只控一个不够。 |

## 研究工程 · Research Engineering

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| configuration management | 配置管理 | 把实验的所有可调项（超参、数据、种子、路径）集中成一份**显式、可序列化**的 config（dict/YAML/JSON），而非散落在代码里。是可复现与 sweep 的前提。 |
| hyperparameter sweep | 超参扫描 | 系统地在多组超参上跑实验找最优。两种主力策略：网格搜索（grid）枚举所有组合、随机搜索（random）从分布采样。 |
| grid search | 网格搜索 | 对每个超参取若干候选值、枚举所有组合。直观但组合数随维度指数爆炸（维度灾难），且在不重要的维度上浪费大量预算。 |
| random search | 随机搜索 | 从每个超参的分布里随机采样组合。Bergstra & Bengio 证明：当只有少数超参真正重要时，随机搜索在相同预算下通常**优于**网格搜索，因为它在重要维度上尝试了更多不同值。 |
| seed | 随机种子 | 伪随机数生成器的初始值。固定它能让「随机」过程可复现；扫描它能测量运行间方差。可复现要求固定**所有**随机源（numpy、框架、数据加载、CUDA）。 |
| determinism / non-determinism | 确定性 / 非确定性 | 给定相同输入是否总得相同输出。GPU 并行归约、多线程数据加载等会引入非确定性，即使固定种子也可能复现不出——可复现工程要专门处理。 |
| experiment tracking / logging | 实验追踪 / 日志 | 系统地记录每次运行的 config、指标、产物、代码版本（git hash）、环境。让你能回答「上周那个 0.92 是哪组参数跑出来的」。工具如 W&B、MLflow，但一个结构化 dict + CSV 也能起步。 |
| results aggregation | 结果聚合 | 把许多次运行（不同种子/超参）的结果汇总成可读的表/图：按配置分组，算均值、标准差、置信区间。pandas 的 groupby/agg 是主力。 |
| environment capture | 环境固化 | 记录并冻结软硬件环境（库版本、CUDA、随机种子、`requirements.txt`/容器），让他人能重建。可复现常死在「版本不对」上。 |
| good enough practices | 足够好的实践 | Wilson 等提出的、面向普通研究者的**务实**科研软件规范（数据管理、代码、协作、项目组织）——不追求软件工程的完美，但守住可复现与可协作的底线。 |
| pre-registration | 预注册 | 在看数据/做实验**之前**就公开登记假设与分析方案。杜绝 p-hacking 与 HARKing（事后编假设），是提升可信度的强力手段。 |

## 写作与同行评审 · Writing & Peer Review

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| IMRaD structure | IMRaD 结构 | 科学论文的标准骨架：Introduction（问题与贡献）、Methods（怎么做）、Results（发现）、Discussion（意味着什么/局限）。读者按此结构寻找信息，遵循它降低沟通成本。 |
| abstract | 摘要 | 论文的浓缩：背景、问题、方法、关键结果、意义。多数读者只读它来决定是否细读，所以它要独立、精确、含具体数字。 |
| contribution | 贡献 | 论文相对已有工作新增了什么（新方法/新发现/新数据/新分析）。Introduction 通常用一个 bullet 列表明确列出，评审据此判断价值。 |
| honest figures | 诚实图表 | 不误导的可视化：带误差棒（error bar）、标明基线、坐标轴从合理起点（不截断放大微小差异）、不用双轴制造假相关。图表诚实是科学诚信的第一线。 |
| error bar | 误差棒 | 图中表示不确定性的标记（标准差、标准误或置信区间）。没有误差棒的柱状图**隐藏**了「差异是否可信」，是审稿要追问的第一件事。 |
| cherry-picked examples | 挑选的样例 | 论文里展示的「成功案例」可能是精选的。诚实做法是同时给失败案例、随机抽样的样例，或量化整体而非晒个例。 |
| peer review | 同行评审 | 由领域专家匿名评估论文的正确性、新颖性、清晰度，决定是否发表。是科学质量控制的核心机制，也是研究者必须学会的一项**双向**技能（投稿与审稿）。 |
| rebuttal / author response | 作者回复 | 投稿者针对审稿意见的书面回应，常附补充实验。好的 rebuttal 直面质疑、用证据回应、礼貌而具体，能实质改变录用结果。 |
| reviewer #2 | 二号审稿人 | 学术圈黑色幽默，泛指那个最苛刻、最难缠的审稿人。提醒作者：写作要预先堵住可能的质疑（预答辩），审稿要严格但建设性。 |
| reproducibility checklist (venue) | 会议可复现清单 | NeurIPS/ICML 等要求作者提交的标准化清单（代码、数据、算力、超参、统计报告是否齐备）。是社区对抗可复现危机的制度性回应。 |
| limitations | 局限性 | 诚实陈述工作的边界与不成立的条件。主动写局限不是示弱，而是科学成熟的标志，也是顶会越来越强制的一节。 |
| significance vs novelty | 重要性 vs 新颖性 | 评审的两个常见维度：结果是否重要（影响大不大）、是否新颖（前人没做过）。两者不必同时满足，但论文要清楚自己主打哪一个。 |

## 跨学科与诚信 · Cross-cutting & Integrity

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| HARKing (Hypothesizing After Results are Known) | 事后假设 | 看到结果后再编一个「我本来就预测到了」的假设，把探索性发现伪装成验证性结论。严重夸大可信度，预注册是其解药。 |
| p-hacking / data dredging | p 值操纵 / 数据捞取 | 反复尝试不同分析（删样本、换指标、加协变量）直到 p < 0.05。会系统性制造假阳性，是可复现危机的主因之一。 |
| garden of forking paths | 分叉小径花园 | Gelman 的比喻：即使不刻意 p-hack，研究者在分析中无数个「看似合理」的选择，也会隐性地推高假阳性率。提醒预先定好分析方案。 |
| troubling trends | 令人忧虑的趋势 | Lipton & Steinhardt 总结的机器学习学术不良风气：解释与猜测不分、未做消融、用数学唬人（mathiness）、滥用术语。读论文与写作都要自觉规避。 |
| SOTA-chasing | 刷榜 | 只为在排行榜上多 0.1 分而堆 trick、不做消融、不问「为什么有用」。Sculley 等批评它牺牲了科学理解，本课强调归因与理解优先于刷分。 |
| empirical rigor | 经验严谨性 | 实验做得扎实可信的程度：有对照、有消融、有多次运行与方差、有强基线、结论不过度。是区分「demo」与「研究」的分水岭。 |
| internal / external validity | 内部 / 外部效度 | 内部效度：实验内部因果归因是否可靠（控住混杂了吗）；外部效度：结论能否推广到别的数据/场景/规模。两者常此消彼长，需权衡。 |
| Goodhart's law | 古德哈特定律 | 「当一个指标成为目标，它就不再是好指标」。刷某个 benchmark 到极致往往偏离了它本想衡量的真实能力，是评测与选题时要警惕的陷阱。 |
