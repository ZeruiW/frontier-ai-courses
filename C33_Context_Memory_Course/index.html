怎么用： 每个模块先读 HTML 讲解 建立「把上下文窗口当核心资源经营」的直觉，再跑 notebook 亲手用 纯 Python 标准库 从零实现机制：token 预算器与截断策略、对话 compaction 与滚动摘要、外部文件记忆、toy embedding 检索器、prompt 前缀缓存与长会话成本账。配套 术语词典 与 论文清单。本系列的立场是：不依赖 Claude Code 等任何框架，亲手把这些机制造出来——把「让一个 agent 在有限上下文里长时间不爆、不丢、不贵」这件事，拆成可独立验证的零件，一层层从零搭起来。本环境无 GPU、不需要任何 API key：凡是需要「模型」的地方一律用 MockLLM（一个确定性的、规则驱动的假模型）端到端跑通，让你专注于预算、控制流与正确性这些不随模型与厂商过时的硬功夫。每个零件都与一个朴素参考实现对拍、用 assert 兜底，并旁附可直接迁移到真实 Anthropic Messages API + prompt caching 的形状对照（model="claude-sonnet-4-6"，无 key 自动回退 MockLLM）。学完你能读懂并自己写出 token 预算、compaction/摘要、文件记忆、RAG 注入、前缀缓存这一整套上下文工程基础设施。
