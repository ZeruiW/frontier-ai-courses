1三种做法的精确 FLOP 账

$n = T \cdot S$ 个 token（$S$ 是每帧的 token 数，已按模块 01 做过时间压缩）。把时间维放进注意力有三种标准做法：

完全 3D 一个 n x n 的注意力，n = T*S -> (T*S)^2 分解 每帧内的空间注意力 (T 个 S x S) -> T*S^2 + 每空间位置的时间注意力 (S 个 T x T) -> S*T^2 合计 T*S*(S+T) 时空窗口 只在 w_t x w_s 的邻域里注意 -> T*S*(w_t*w_s)
$T$$S$完全 3D分解分解的节省窗口 $4{\times}64$窗口的节省
$16$$256$$1.68\times10^{7}$$1.11\times10^{6}$$15.1\times$$1.05\times10^{6}$$16\times$
$64$$256$$2.68\times10^{8}$$5.24\times10^{6}$$51.2\times$$4.19\times10^{6}$$64\times$
$128$$256$$1.07\times10^{9}$$1.26\times10^{7}$$85.3\times$$8.39\times10^{6}$$128\times$
$64$$1024$$4.29\times10^{9}$$7.13\times10^{7}$$60.2\times$$1.68\times10^{7}$$256\times$
$128$$1024$$1.72\times10^{10}$$1.51\times10^{8}$$113.8\times$$3.36\times10^{7}$$512\times$

分解的节省有闭式：

\[\frac{(TS)^2}{TS(S+T)} = \frac{TS}{S+T} = \frac{1}{1/T + 1/S}\]

这是 $T$ 与 $S$ 的调和平均的一半，所以它被较小的那个限住：

$T$（$S{=}256$ 固定）$16$$64$$256$$1024$$4096$上界
分解的节省$15.1\times$$51.2\times$$128.0\times$$204.8\times$$240.9\times$$\mathbf{256\times}$

节省会饱和：$T$ 从 $256$ 涨到 $4096$（$16$ 倍）只把节省从 $128\times$ 提到 $241\times$。所以「视频越长，分解越赚」是错的——赚头的上界就是 $S$。

窗口的节省是 $(TS)/(w_t w_s)$，它随 $T$ 线性增长且不饱和。所以在很长的视频上窗口比分解便宜得多（$T{=}128$ 时 $128\times$ vs $85\times$）。代价是感受野：窗口需要 $\log$ 级的层数才能覆盖全序列，而分解一层就能让任意两个 token 通过两跳相连。这两种做法的表达力边界完全不同，下面三节就是在算分解的那一边。

窗口注意力的账不一样

2分解式注意力就是 Kronecker 积

把 $n = TS$ 个 token 排成 $(t, s)$ 的网格。「对每个空间位置在时间上做注意力」这个算子作用在展平向量上是

\[A_t \otimes I_S\]

而「对每帧在空间上做注意力」是 $I_T \otimes A_s$。先做时间再做空间：

\[(I_T \otimes A_s)(A_t \otimes I_S) = A_t \otimes A_s\]

notebook 用 $T{=}6, S{=}8$ 数值验证：$\Vert\text{复合} - A_t \otimes A_s\Vert = 0.000\times10^{0}$（逐位相等）。

于是分解式注意力的表达力有一个精确的刻画：它只能产生 Kronecker 积形式的混合。自由度对比（$T{=}6, S{=}8$）：

结构可表达的混合矩阵集合自由度
完全 3D 注意力任意 $(TS) \times (TS)$ 矩阵$(TS)^2 = 2304$
分解（两层）$\{A_t \otimes A_s\}$$T^2 + S^2 - 1 = 99$

维度比 $23:1$。但「自由度少」本身不等于「表达不了你需要的东西」——关键是需要的那些混合在不在这个集合里。下一节回答这个问题。

直白说

Kronecker 积的含义是「时间模式 $\times$ 空间模式」：它先决定「往哪些帧看」，再决定「在帧内往哪些位置看」，而这两个决定互不影响。现实里我们常常需要相反的东西：往哪些位置看，取决于看的是哪一帧。

严谨说

形式化地：混合矩阵 $M$ 可写成 $A_t \otimes A_s$ 当且仅当把 $M$ 按 $T \times T$ 个 $S \times S$ 块重排成矩阵 $R$（Van Loan–Pitsianis 重排）后，$R$ 的秩为 $1$。$R$ 的秩就是所需的 Kronecker 秩，而最优 Kronecker 逼近的残差恰是 $R$ 除最大奇异值外的能量。本模块的全部结论都是这个重排 SVD 的直接读数。

3什么样的运动分解不了

构造混合矩阵「第 $(t,x)$ 个 token 该 attend 到上一帧的哪个位置」，然后算它的最优 Kronecker 逼近误差（$T{=}8, S{=}16$）：

目标混合Kronecker 逼近误差Kronecker 秩
① 全局匀速 $v{=}2$（看上一帧）$\mathbf{0.000000}$$1$
② 三个物体各自匀速 $[1,3,6]$$\mathbf{0.000000}$$1$
③ 加速：$v(t){=}t$$0.935414$$8$
④ 回看第 $0$ 帧的原始位置$0.935414$$8$
⑤ $t$ 依赖的时间跨度（回看 $t{-}1{-}(t\bmod 3)$ 帧）$\mathbf{0.000000}$$1$
⑥ 物体速度随 $t$ 变（$v = \text{owner} + t\bmod 2$）$0.707107$$2$

我最初猜「多个物体各自不同速度就分解不了」——错的，②的误差恰为 $0$。原因是空间重排（$x \mapsto x - v_{\text{owner}(x)}$）是一个固定矩阵，对所有 $t$ 都相同，所以 $M = A_t \otimes P$ 仍是 Kronecker 积。⑤也是 $0$：时间跨度随 $t$ 变而空间位移不变，同理。

精确的判据是：

混合可以分解成「与 $t$ 无关的空间模式」乘「与 $x$ 无关的时间模式」。所以：匀速运动（多少个物体、各自多快都行）完全没问题；而加速、变向、以及任何「空间往哪看取决于现在是第几帧」的依赖，都需要更高的 Kronecker 秩。

分解是精确的当且仅当…

加速度 $v(t){=}at$Kronecker 逼近误差Kronecker 秩压到 $1\%$ 残差所需项数
$a{=}0.00$$0.000000$$1$$1$
$a{=}0.50$$0.790569$$3$$3$
$a{=}1.00$$0.935414$$5$$5$
$a{=}2.00$$0.790569$$3$$3$

秩不是随 $a$ 单调的（$a{=}2$ 时因为位移在 $S$ 上取模而绕回，秩反而降回 $3$），但结论稳定：只要 $a \neq 0$ 就需要秩 $> 1$。

4深度和残差都补不回来——并行分支才行

既然一层分解只能给出秩 $1$，那么多叠几层应该能补回来？notebook 在 $T{=}5, S{=}6$（Kronecker 秩上界 $\min(T^2, S^2) = 25$）上逐个测：

结构Kronecker 秩
① 单层时间注意力 $A_t \otimes I$$1$
② 顺序两层（无残差）$(I{\otimes}A_s)(A_t{\otimes}I)$$1$
③ 顺序两层带残差 $(I{+}I{\otimes}A_s)(I{+}A_t{\otimes}I)$$\mathbf{1}$
④ 顺序八层带残差（四组交替）$\mathbf{1}$
⑤ 并行两分支 $I + A_t{\otimes}I + I{\otimes}A_s$$\mathbf{2}$
⑥ 并行两分支 $\times 2$ 层$4$
⑦ 并行两分支 $\times 4$ 层$\mathbf{16}$
⑧ 完全 3D 注意力$25$（$= \min(T^2,S^2)$）

③④为什么还是 $1$——因为它是一个恒等式：

\[(I + I_T{\otimes}A_s)(I + A_t{\otimes}I_S) = (I_T + A_t) \otimes (I_S + A_s)\]
‖(I+I⊗As)(I+At⊗I) − (I+At)⊗(I+As)‖ = 0.000e+00

顺序 $+$ 残差 $=$ 一个更大的 Kronecker 积，秩仍然是 $1$。深度和残差都不给分解式注意力增加时空交互的表达力。

⑤为什么是 $2$——因为并行分支是和而不是积，而 $I + A_t{\otimes}I + I{\otimes}A_s$ 无法写成 $P \otimes Q$。把并行块叠起来，秩按 $2^L$ 增长（⑥ $4$、⑦ $16$），直到撞上上界 $25$。

第一次：猜「多个物体不同速度就分解不了」——测出来误差恰为 $0$。第二次：猜「多叠层能补回来」——Kronecker 积的乘积仍是 Kronecker 积，秩恒为 $1$。第三次：猜「残差连接能补回来」——上面那个恒等式说明它等价于一个更大的 Kronecker 积，还是 $1$。第四次才对。而这三次错误各自对应一种流行的直觉，所以它们值得被写进课程而不是被删掉。

这对架构设计意味着什么

真实的视频 Transformer block 里，时间注意力与空间注意力并列接在同一个残差流上（$x \leftarrow x + \text{attn}_t(x) + \text{attn}_s(x)$，或者两个分支各带自己的残差后相加），而不是串成一条链。这个看起来只是接线风格的选择，恰恰是表达力的来源。

另一条推论：「在图像模型上插入时间层」的做法（Align your Latents 一类）之所以能工作，关键在于时间层是加法式插入的（$x \leftarrow x + \alpha \cdot \text{attn}_t(x)$，且 $\alpha$ 初始化为 $0$）。如果它是乘法式/串联式插入的，按上面的恒等式，整个网络的时空混合就仍然被锁在 Kronecker 秩 $1$ 里。

以上全部是线性算子层面的分析：把注意力权重当作固定矩阵，只看混合结构。真实网络里注意力权重依赖输入，而且每个 block 之间还有非线性 MLP——两者都能在原理上突破这里的界。所以本节的结论应当这样读：它给出的是「不依赖非线性也能做到什么」的下界，以及一个明确的设计信号（并行优于串联）。它不证明串联式分解注意力的网络无法学会加速运动。

这套论证的适用范围

5时间轴上的位置编码：一个被 Kronecker 分析照到的角落

上面四节把注意力的混合结构算清了，但注意力权重是从哪来的？在 Transformer 里它由 query-key 内积决定，而位置信息由位置编码注入。把时空位置编码放进 Kronecker 的框架里，会得到一个有用的观察。

若时空位置编码是可分的——即 $\text{PE}(t, x) = \text{PE}_t(t) + \text{PE}_x(x)$（相加）或 $\text{PE}_t(t) \odot \text{PE}_x(x)$（逐元素相乘）——那么 query-key 内积中由位置贡献的那部分也是可分的，于是注意力 logits 有形式

\[\text{logit}[(t,x),(t',x')] = a(t,t') + b(x,x') + c\]

而 softmax 把加法变成乘法：$\exp(a + b) = \exp(a)\exp(b)$，所以纯位置驱动的注意力矩阵恰好是一个 Kronecker 积（在归一化之前）。

它说明「用完全 3D 注意力」并不自动买到高 Kronecker 秩：如果注意力主要由位置决定（而不是由内容决定），那么即使算子形状上是 $n\times n$，实际产生的混合仍接近秩 $1$。反过来：时空混合的表达力最终来自「内容依赖」——query 与 key 的语义部分，而不是位置部分。这给出一条设计信号：如果一个视频模型的注意力图几乎只反映位置邻近性，那么它在结构上退化到了分解式的水平，$n^2$ 的算力白付了。

这条观察的用处

时间维的外推

另一个实践问题：训练时 $T{=}16$，推理时想要 $T{=}128$。空间维不需要外推（分辨率固定），而时间维经常需要。常见做法与它们的代价：

做法机制问题
绝对位置嵌入（可学）每个时间位置一个向量完全无法外推——训练时没见过的位置没有嵌入
正弦位置编码$\sin/\cos$ 的固定频率可以外推，但注意力对超出训练范围的相对距离没有校准
RoPE（时间轴）把相对位置编成旋转外推更好，但长距离的注意力权重衰减方式在训练外不受控
相对位置偏置$a(t - t')$ 的可学表表要么裁剪要么插值；裁剪即丢失长程

而模块 00 的遮挡悬崖给出一个约束：所需上下文由最长不可观测区间决定。如果那个区间在推理时比训练时长，那么无论位置编码怎么外推，模型都没有学过如何跨越那么长的遮挡——位置编码的外推能力与时间依赖的外推能力是两件事。

「能处理更长的序列」≠「能建模更长的依赖」。前者是位置编码与算力的问题，后者是训练数据里有没有那么长的依赖。本课不做位置编码的实验（它需要真实训练），但模块 00 练习 3 的遮挡悬崖给出了后者的下界：上下文窗口至少要覆盖「最长不可观测区间 $+ 2$ 帧」，而这是一个关于数据的要求，位置编码帮不上。

6这套分析的适用范围

在进入窗口注意力之前，把前四节的适用范围说清，因为它比结论本身更容易被误用。

前四节假设了什么真实网络里是什么后果
注意力权重是固定矩阵权重依赖输入（query-key 内积）真实网络可以对不同样本用不同的混合 —— 本节的界是单个样本上的
层与层之间是线性复合中间有非线性 MLP非线性能在原理上突破 Kronecker 结构
只看混合结构还有值变换 $W_V$、多头、归一化多头相当于多个并行分支 —— 见第 4 节的 ⑤

所以正确的读法是：本节给出的是「不依赖非线性也能做到什么」的下界，以及一个明确的设计信号（并行优于串联）。它不证明串联式分解注意力的网络无法学会加速运动——它只说明那个网络必须靠非线性去补，而并行接线的网络不必。

多头注意力本身就是并行分支。所以一个「多头的、分解式的」时空注意力，如果不同的头分别做时间与空间，那它在结构上就是第 4 节的 ⑤ 而不是 ③——Kronecker 秩随头数增长。这解释了为什么实践中「分头做时空」比「分层做时空」更常见，而这个选择的收益可以用本节的秩来量。

第三行值得单独说

7窗口注意力：另一种边界

时空窗口（Video Swin 一类）不做 Kronecker 分解，而是限制注意力的范围。它的表达力边界形状完全不同：

分解时空窗口
代价$TS(S+T)$，节省上界 $S$（饱和）$TS \cdot w_t w_s$，节省 $\propto TS$（不饱和）
一层的连通性任意两 token 两跳可达只在 $w_t \times w_s$ 邻域内
表达力的限制形式Kronecker 秩（结构限制）感受野（范围限制）
需要多少层覆盖全序列$1$–$2$ 层$\lceil (T{-}1)/\lfloor w_t/2 \rfloor \rceil$ 层（线性；配移位窗口可降到 $O(\log)$）
最难表达的东西加速、变向长距离的瞬时对应（如镜头切换后的重识别）

两者的限制是正交的，这解释了为什么工业模型常常同时用：空间上用窗口（分辨率高、局部性强），时间上用全注意力或分解（$T$ 相对小）。

还有一个实践上的组合值得点出：空间用窗口、时间用全注意力。理由按上表可以说清——空间维的 $S$ 很大（$256$–$1024$）而局部性强，所以窗口的算力收益大且归纳偏置合适；时间维的 $T$ 相对小（时间压缩之后常在 $8$–$32$），所以全注意力的 $T^2$ 代价可以承受，而它换来的是时间维上不受 Kronecker 秩限制。

notebook 的练习 4 让你对「窗口注意力」也做同样的 Kronecker 分析。结果值得先想一下再看：一个 $w_t \times w_s$ 的时空窗口本身就是 Kronecker 秩 $1$ 的（它是「时间上取邻域」$\otimes$「空间上取邻域」）。所以窗口注意力在结构上和分解一样受限——它换来的是别的东西（局部性归纳偏置与内存局部性），不是表达力。
