03 · 时序一致性与自回归漂移

「自回归必然漂移」是错的：误差按 $\vert\hat a\vert^k$ 演化，$\vert\hat a\vert<1$ 时任何单帧的错误都会被指数地遗忘 · 真正累积的是分布的错误，而它有两支症状相反的形态 · 一步拟合（教师强制）对持续性的估计向下有偏（$a{=}0.9,n{=}50$ 时中位数 $0.8835$）$\Rightarrow$ rollout 的运动能量只有真值的 $35\%$–$49\%$——「越往后越糊、越静止」不需要神经网络就已出现，而且是目标函数问题不是能力问题 · 而尾部：$a{=}0.995,n{=}30$ 时 $28.60\%$ 的拟合给出 $\vert\hat a\vert>1$（指数爆炸）· 方差的中位数 $8.93$ 而均值 $1.408\times10^{14}$——差 $16$ 个数量级，所以长视频指标必须报中位数 $+$ 崩坏率 · 而「用 rollout 损失修漂移」这条建议被实测限定：它修不了那个偏差，模型正确指定时几乎什么也不改

1误差增长律：漂移不是必然的

「自回归生成的视频越往后越糟」是一句几乎无人反驳的话。但它作为一般命题是错的，而错在哪里决定了该怎么修。

最简的自回归生成：学一个一步预测器 $\hat x_{t+1} = \hat a x_t$，然后反复代入自己的输出。如果初始帧带有误差 $\delta$，那么 $k$ 步后的误差是 $\vert\hat a\vert^k \delta$：

$0.90$$0.9$$0.349$$5.2\times10^{-3}$$7.1\times10^{-10}$收敛到 0

$\vert\hat a\vert < 1$ 时，任何单帧的错误都会被指数地遗忘。这不是一个近似说法——它是几何级数。所以「一帧生成得不好，后面就全毁了」在稳定动力学下不成立。而现实中的视频动力学在大多数尺度上是稳定的（物体最终会停下、光照会回到均值、镜头会稳住）。

稳定的动力学会遗忘错误

那为什么长视频确实会漂？因为真正累积的不是单条轨迹的误差，而是分布的错误。下面两节分别处理它的两种形态。

2第一种形态：一步拟合系统性低估了持续性

训练一步预测器用的是教师强制（teacher forcing）：输入真实的 $x_t$，预测真实的 $x_{t+1}$。这个目标函数有一个古老且精确的性质：它对自回归系数的估计向下有偏。

\[E[\hat a] - a \approx -\frac{1 + 3a}{n}\]

（Kendall 1954 / Marriott–Pope 1954。$n$ 是训练序列长度。）notebook 在 $6000$ 次重复上量它：

$\hat a < a$ 意味着学到的动力学比真实的更快衰减。把它拿去 rollout，稳态方差就会偏小：

$a{=}0.98$ 时 rollout 的运动能量只有真实的 $35\%$–$49\%$。

这个现象通常被归因于「模型能力不足」或「误差累积」。但本节说明：即使模型类完全正确、即使训练完美收敛到该目标的最优解，一步拟合本身就会低估动力学的持续性，于是 rollout 过度衰减、运动逐渐消失。这不是能力问题，是目标函数问题——而它也解释了为什么「多步/rollout 损失」「scheduled sampling」这类做法有用：它们改的正是这个目标。

「越往后越糊、越静止」有一个不需要神经网络的解释

4分布的错误不会自我纠正

上面两节讲的是 $\hat a$（动力学的持续性）。还有一个量同样会错，而且它的错误完全不随时间衰减：噪声尺度。

真动力学 $a{=}0.95$、真噪声 $\text{sd}{=}1.0$，真稳态 $\text{sd} = 1/\sqrt{1-a^2} = 3.2026$。如果模型用错的噪声尺度 rollout：

模型噪声 sd第 $5$ 步的 sd第 $50$ 步第 $500$ 步稳态 sd / 真值
$0.50$$2.674$$1.599$$1.605$$\mathbf{0.5012}$
$0.80$$2.962$$2.545$$2.568$$0.8020$
$1.00$$3.206$$3.179$$3.210$$1.0024$
$1.20$$3.481$$3.813$$3.852$$1.2029$
$2.00$$4.779$$6.353$$6.421$$2.0049$

比值恰好等于噪声尺度的比值（$0.5012$、$0.8020$、$1.2029$、$2.0049$）——因为稳态 sd 与噪声 sd 成正比。

直白说

单条轨迹的误差可以被遗忘（第 1 节），但分布的错误是持久的：噪声尺度低估让生成越来越静止，高估让它越来越乱，而两者都不会「收敛回正确分布」——因为错的是不动点本身。

严谨说

对 $x_{t+1} = a x_t + \varepsilon_t$，$\varepsilon \sim N(0, \sigma^2)$，稳态分布是 $N(0, \sigma^2/(1-a^2))$。误差的遗忘（第 1 节）说的是转移算子的收缩性；而不动点由 $(a, \sigma)$ 共同决定。收缩性保证「初值不重要」，它不保证「收敛到正确的分布」——两件事经常被混为一谈。

扩散模型在长 rollout 上「越来越糊」通常被解释为误差累积。更准确的说法是：采样温度 / 引导强度在自回归 rollout 里的作用被放大了——它直接决定了不动点的方差。CFG 强度偏高会让画面越来越「锐利到失真」，偏低会越来越糊，而这两个方向都不是误差累积，是不动点选错了。而修法也不同：误差累积要改训练目标（第 2 节），不动点错要改采样参数。

这解释了两个常见现象

5在扩散模型里，这两支各对应什么旋钮

前三节用 AR(1) 做最小模型。放回扩散视频生成的语境，两支失效各自对应一组具体的、可调的东西——而它们不重叠。

本课的量扩散里的对应物调它会怎样
$\hat a$（动力学的持续性）时间层学到的帧间依赖强度只能靠训练目标改（多步损失 / 更长的训练窗口）
$\vert\hat a\vert > 1$（不稳定）自回归段间的能量放大谱范数约束 / 更密的锚帧 / 段间重归一化
噪声尺度 $\sigma$（不动点）采样温度、CFG 强度、噪声调度的末端直接决定生成分布的方差 —— 训练完之后还能调
起始分布第一段的条件（首帧 / 文本）第 1 节说明它会被指数遗忘 —— 影响最小

第三行是唯一在训练之后还能调的，而它恰好对应第 4 节那一支。所以有一条直接可用的分诊规则：

长视频质量下降 | 平稳吗？（第 4 节的批级诊断） | +----+----------------------+ | | 平稳 不平稳 | | 不动点错 还在累积 | | 调采样参数 改训练目标 / 加锚帧 （CFG 强度 / 温度 / （多步损失 / 谱约束 / 噪声调度末端） 更密的锚帧） | | **训练后就能试** **需要重训**
两支的修法在成本上差几个数量级：调采样参数是分钟级的，改训练目标是天级的。而第 4 节的诊断（批级平稳性 + 能量比）只需要一批已经生成好的视频，不需要任何额外的训练或标注。所以它应该是遇到「长视频质量下降」时的第一步，而不是最后一步。

为什么这条分诊值得先做

CFG 强度在自回归 rollout 里被放大

单段生成里 CFG 强度影响的是这一段的锐度。而在自回归 rollout 里，每一段的输出成为下一段的条件，于是 CFG 造成的分布偏移进入了不动点：

按第 4 节的机制：如果 CFG 让每段的方差相对真实分布乘了 $\kappa$，那么 rollout 的稳态方差就被乘 $\kappa$——不是 $\kappa^{段数}$（那会是累积），而是一个固定的 $\kappa$（因为它改的是不动点，而不动点不随时间累积）。这个区别有实践含义：它意味着「越往后越锐」这个现象如果真的在累积，那它不是 CFG 造成的，而是 $\vert\hat a\vert>1$ 那一支。

验证「CFG 在扩散视频 rollout 里如何影响不动点」需要一个真实的视频扩散模型。本课能给的是机制层面的对应：第 4 节已经量出「噪声尺度错 $\Rightarrow$ 稳态方差按同一比例错，且不随时间累积」（比值 $0.5012 / 0.8020 / 1.2029 / 2.0049$，与噪声比值逐位对应），而 CFG 在采样里的作用正是改变有效噪声尺度。把这两件事连起来是一次推断而不是一次测量——所以本课把它标成推断。

6教师强制为什么必然产生这个偏差

第 2 节给出了偏差的数值与经典公式。这一节说清它为什么必然——因为这决定了哪些修法在原理上可能有效。

一步最小二乘的解是

\[\hat a = \frac{\sum_t x_t x_{t+1}}{\sum_t x_t^2}\]

分子分母共享同一批 $x_t$，所以它们相关。而分母 $\sum x_t^2$ 在同一份数据上恰好是偏大的方向与分子偏大的方向相关——于是比值系统性偏小。更直观的说法：有限长度的序列「看起来」比真实过程更快回到均值，因为端点效应（序列必须在某处开始和结束）压低了观测到的持续性。

直白说

想象一个几乎不衰减的过程（$a$ 接近 $1$）。在一段有限的观测里，它看起来像一条缓慢漂移的曲线。而拟合会把「漂移」的一部分解释成「均值回归」——因为在这一段里它确实回到了某个水平（那个水平就是这一段的样本均值）。样本均值本身是随机的，而拟合把它当成了真均值。

严谨说

严格地说：$\hat a$ 的偏差主要来自「用样本均值代替真均值」。去均值后的序列 $x_t - \bar x$ 的自相关被系统性压低，因为 $\bar x$ 本身随 $x_t$ 变动。这也解释了为什么偏差 $\propto 1/n$：$\bar x$ 的方差 $\propto 1/n_{\text{eff}}$，而 $n_{\text{eff}} \propto n(1-a^2)$。

既然偏差来自有限样本（而不是目标函数的形状），那么：更长的训练序列有效（偏差 $\propto 1/n$，实测跨 $20$ 倍 $n$ 缩小约 $20$ 倍）；偏差校正有效（把 $-(1{+}3\hat a)/n$ 加回去）；而多步损失不必然有效——练习 1 实测它不修这个偏差。这解释了为什么视频模型的训练窗口长度是一个比它看起来更重要的超参：它同时决定了可观测性（模块 00）与这个偏差的大小。

7四节的关系

把前四节的关系说清，因为它们不是并列的四个现象，而是一条链：第 1 节说明单条轨迹的误差会被遗忘（所以「必然漂移」是错的）；第 2 节指出真正累积的是目标函数的偏差（运动能量不足）；第 3 节指出这个偏差还有一条方差很大的尾巴（少数模型爆炸），而两支的症状相反；第 4 节说明分布的错误（不动点）与前两者都不同——它完全不随时间衰减。下面的修法表就是按「修哪一支」组织的。

8四种修法，各修哪一支

做法机制修的是哪一支代价
多步 / rollout 损失训练时就做 $k$ 步 rollout 并对全部步计损失第 2 节的目标函数偏差训练慢 $k$ 倍；梯度可能不稳
scheduled sampling训练时按概率把输入换成模型自己的输出同上（更便宜的近似）引入偏差-方差的新超参
关键帧 / 锚帧条件每 $m$ 步用一个真实（或先生成的）锚帧重置两支都截断（把 $k$ 上限压到 $m$）需要层次化生成；锚帧之间可能不连贯
一次性生成整段不自回归，一个 forward 出全部 $T$ 帧两支都不存在（没有 rollout）代价 $\propto T^2$（模块 00）；长度固定

第三行和第四行值得对照：一次性生成把「漂移」这个问题整个删掉了，代价是模块 00 算过的 $(T/p_t)^2$。所以工业上的主流是层次化：一次性生成一小段（无漂移），然后用锚帧把小段拼成长视频（把漂移限制在段间）。

纯自回归: [f1]->[f2]->[f3]->...->[f100] 漂移累积 100 步 一次性: [f1 f2 ... f16] 无漂移，但代价 (16)^2 层次化: [f1 ... f16] [f17 ... f32] ... 段内无漂移 ^锚帧 ^锚帧 段间漂移 = 段数（100/16 ≈ 6 步）

notebook 的练习 3 把这个账算清：锚帧间隔 $m$ 让有效 rollout 步数从 $T$ 降到 $T/m$，而误差按 $\vert\hat a\vert^{T/m}$ 而不是 $\vert\hat a\vert^{T}$——在不稳定（$\vert\hat a\vert > 1$）的情形下这是指数级的改善。

表里第四行值得多说一句：一次性生成把「漂移」这个问题整个删掉了，而它的代价在模块 00 已经算清（$(T/p_t)^2$）。所以「自回归 vs 一次性」这个选择的本质是用平方级的算力换掉一个不会报错的失效模式——而本模块的四节正是在说清那个失效模式到底值多少算力。

C41-04 讲的是用模型规划时的复合误差：那里的优化器会主动去找模型的错误，所以失效是对抗性的。本模块讲的是用模型生成：没有优化器在对抗它，失效是分布性的（不动点错、目标函数偏）。同一个模型、同样的一步误差，两种用法的失效机制不同，修法也不同——模块 04 会把这两者放在同一个模型上直接对比（被动 $-13\%$ vs 主动 $+251\%$）。
