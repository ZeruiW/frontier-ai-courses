# 检测数据增强工程

数据不够、稀有类太少、夜里和雨里掉点——**在加数据之前，先把手里这批数据的价值榨干**。
这就是数据增强要干的事。但检测任务的增强跟分类完全不是一回事：

> 分类增强只要变图；**检测增强必须让标注跟着像素一起变**。
> 图转了 15°，框要重算；图裁了一半，被切掉 70% 的目标算不算样本要有规则；
> 图做了 letterbox，推理端还得能把框原样还原回去。
> 一个符号错、一个阈值不对，你得到的不是"更多数据"，而是**成千上万条带错标签的训练样本**——
> 而且它不报错，只让 mAP 悄悄少涨两分。

这门课把"增强"当作一个可推导、可度量、可证伪的工程对象来讲：
框膨胀量能用几何算出来，实际触发率能用概率算出来，雾能用透射率参数化，
"这个增强到底有没有用"能用配对检验给出置信区间。

## 三条判据（贯穿全课）

任何一个增强算子上线前都要过这三关，缺一条结论就不可信：

1. **保标签语义** — 变换之后，原来的标注还成立吗？
   水平翻转让"左转"变"右转"、让限速数字镜像；色相抖动把红色禁令牌推向蓝色指示牌的色域。
   **这一条在 TSR 里是硬约束，在通用检测里常常被忽略，所以它是面试里很好的主动发挥点。**
2. **贴近部署分布** — 你造出来的样本，路上真的会出现吗？
   贴在天上的交通标志、比车还大的限速牌、色相偏了 90° 的警告牌，都是在教模型学不存在的东西。
3. **不制造训练-推理鸿沟** — 训练做了的变换，推理端能对齐吗？
   letterbox 的 padding 值、缩放取整、是否居中，**训练与推理必须逐位一致**；
   Mosaic 造出的四宫格分布推理时永远不会出现，所以要 close-mosaic 收尾。

三条其实是同一件事的三个侧面：**增强是你写给模型的一份"不变性契约"，
契约写错了，模型会一丝不苟地学错。**

## 学习路径

**主线（推荐，约 12–16 小时）**：`00 → 01 → 02 → 03 → 04 → 05`，顺序不要打乱。
01 里的 bbox 变换框架是 03 的地基（Mosaic 与 Copy-Paste 都要复用它的裁剪与丢弃规则），
04 的流水线要把 01–03 的算子串起来，05 用来判断前面所有东西到底值不值得开。

- **面试冲刺路径（约 4 小时）**：`00 → 01 → 03 → 05`。
  这四个模块覆盖了检测增强面试的全部高频点：bbox 同步变换与越界规则、
  翻转的语义禁区、Mosaic 的作用与 close-mosaic 的动机、Copy-Paste 治长尾、
  以及"+0.3 算不算提升"这个能立刻显出水平的问题。
- **工程落地路径（约 6 小时）**：`01 → 04 → 05 → 02`。
  如果你手上已经有一个在训的检测器、要把增强调对，先看 01（正确性）与 04（吞吐与可复现），
  再用 05 建立验证方法，最后按需要回到 02 补域鲁棒性。
- **每个模块的正确用法**：先读 HTML 讲解建立心智模型，再跑 notebook 亲手实现。
  练习**先自己做**再看参考答案——每题都有 `assert` 判分，做错了会立刻告诉你。

## 环境

见 `requirements.txt`。**纯 numpy / CPU，不需要 GPU，也不需要装 torch / albumentations / opencv。**
所有"图像"都用 `np.random` 按物理合理的方式合成（并说明合成规则），
所有算子都从零实现——因为本课要教的是**算子的语义与账本**
（坐标怎么变、标注怎么跟、概率怎么乘、分布怎么漂），而这才是可迁移的那部分：
Albumentations 的 API 会变，"旋转会让轴对齐外接框膨胀"不会变。

每个模块末尾有一个 🧪 **真实工程胶囊**，把当天学到的东西翻译成可以原样复制到
Albumentations / Ultralytics YOLO / MMDetection 配置里的代码与参数。

## 与相邻课程的分工

| 课程 | 它讲什么 | 与本课的边界 |
|---|---|---|
| **C18 · 计算机视觉** | 检测器本身：backbone、FPN、anchor、NMS、mAP 的定义 | C18 讲**模型吃什么、怎么算损失**；本课讲**喂进去的数据怎么造**。学本课前最好已经知道 bbox 的表示（xyxy / xywh / cxcywh）与 IoU 怎么算。 |
| **C51 · 文本数据增强与合成数据工程** | **文本**增强：同义词替换、回译、LLM 合成指令数据、质量控制 | **两课同名不同物，别搞混。** 文本是离散的、组合的——删掉一个"不"字标签就反了；图像是连续的、有几何结构的——旋转一张猫的照片它还是猫，但**框会变**。C51 的核心难题是"增强与破坏的边界很薄"；本课的核心难题是"标注必须同步变换 + 造出来的分布要贴近部署"。**共享的只有第 05 模块的方法论**（种子方差、配对检验、切片评测），而且两边都值得读——同一套统计纪律在两种数据形态上的表现不同。 |
| **C55 · 交通标志识别与自动驾驶感知** | TSR 的任务定义、数据集、系统设计、失效模式全景、安全导向评测 | C55 告诉你**哪里会错**（夜间、逆光、远距离小目标、稀有类、广告牌误检）；本课告诉你**用哪个增强去治**。本课 05 模块的"按失效模式反推配方"就是直接消费 C55 的失效模式清单。**建议 C55 → C56 顺序读，反过来也行但少了动机。** |
| **C57 · 小目标检测** | 小目标为什么难（IoU 对位移敏感、正样本稀缺、下采样丢信息）、架构与分配层面的解法、切片推理 | 有重叠但分工清晰：C57 从**模型侧**解决小目标，本课从**数据侧**解决（Mosaic 制造小目标、小尺度采样、Copy-Paste 补稀有小目标、min-visibility 阈值不要误杀小框）。两条路互补且经常要一起上。 |
| **C58 · 难例挖掘与长尾数据闭环** | 触发 → 挖掘 → 标注 → 验证的完整数据闭环、类别不平衡的处理谱系 | **决策关系**：C58 回答"要不要花钱去采/标新数据"，本课回答"手里的数据还能不能榨出更多"。Copy-Paste 是两课的交汇点——它用**已有**的稀有类实例合成新样本，成本远低于采集，所以通常应该**先试 Copy-Paste，不够再去挖掘**。C58 的重采样/重加权与本课的增强是可叠加但会互相干扰的两类手段，05 模块讲怎么把它们分开评估。 |
