增强的本质是先验注入：你在声明「这类变化不改变标签」，模型据此学到不变性。三判据（保标签语义 / 贴近部署分布 / 不制造训练-推理鸿沟）贯穿全课；检测增强难在标注必须同步变换、遮挡与截断要有规则、多目标之间还会互相干扰。

MODULE 01

几何增强与标注同步

bbox 跟随变换的唯一正确做法是四角法 + 外接框，而它有代价：旋转会让框膨胀，角度越大、框越接近正方形以外的长宽比，膨胀越狠。越界处理的三条规则（裁剪 / 按可见比例丢弃 / 全保留）对小目标的影响天差地别。水平翻转在 TSR 里是语义炸弹：「左转」翻成「右转」、限速数字镜像。letterbox 必须实现逆变换，否则推理端的框还原不回原图坐标。

MODULE 02

光度增强与域鲁棒性

交通标志的颜色承载语义，所以 HSV 抖动的幅度在 TSR 里必须比通用检测保守得多——本模块量化「色相偏多少度会把红色禁令牌推到蓝色指示牌的色域」。天气合成用物理模型而不是滤镜：大气散射给出雾，方向-长度核给出运动模糊，行扫描时延给出卷帘快门畸变。合成 vs 真采、域随机化的收益与它的边界。

MODULE 04

增强流水线工程

算子的顺序与概率如何组合，以及为什么「实际触发率」几乎总是远低于你写在配置里的数字。增强常常是训练吞吐的真正瓶颈，诊断靠的是 GPU 利用率的波动模式而不是平均值。worker RNG 是一个会真实发生、且不报错、只让指标掉一点点的事故。验证集只能做确定性变换。TTA 的框合并要用 WBF 而非 NMS，但它的延迟代价让车端几乎不可用。
