怎么用： 每个模块先读 HTML 讲解 建立工程直觉与数学框架，再跑 notebook 用纯 numpy 从零实现预训练数据/超参/稳定性的核心算法，并通过 ✏️ 练习的 assert 判分。配套 术语词典 与 论文清单。本课的立场是：大模型不是「堆算力」，而是一条由无数工程决策串成的流水线——同样的模型架构、同样的 FLOPs 预算，数据清洗、去重、配比、tokenizer、超参迁移、稳定性处理的好坏，能让最终 loss 差出一个身位。这门课把决定「预训练成败」的五个非架构环节，一个个从零拆开、用 numpy 复现核心算法、用真实论文的配置算账。本环境纯 CPU、无需 GPU：我们不训真模型，而是用玩具规模（小词表、小维度、几百条样本）把每个机制的算法骨架与正确性夯实——MinHash 估 Jaccard、从零训 BPE merges、μP 的坐标检查、loss spike 的检测与修复、DoReMi 式配比优化，每个都与朴素参考对拍、用 assert 兜底。学完你能读懂 FineWeb、Chinchilla、μP、DoReMi 等论文的设计取舍，并把验证过的逻辑放大到真实万亿 token 管线。
