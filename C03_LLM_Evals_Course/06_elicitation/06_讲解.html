1能力 vs 表现：所有分数都是下界

前五个模块都在回答"分数本身可不可信"（统计噪声、prompt 敏感性、judge 偏置、污染）。本模块换一个更根本的问题： 即使分数完全干净，它衡量的也不是模型的"能力"，而是模型在这一套特定 harness 下被引出（elicit）的"表现"。 把两者混为一谈，是评测报告里最常见、后果最严重的概念错误。

直白讲

同一个模型，换一个 prompt 模板、允许它先写推理过程、让它多试几次、给它接上工具——分数可以差出几十个点。 所以"模型在 GSM8K 上得 18 分"这句话是不完整的，完整版本是"在 zero-shot、greedy 解码、只采样一次的条件下得 18 分"。 你测到的永远是"它至少能做到这么好"，而不是"它最多只能做到这么好"。

严谨讲

设模型 $M$、评测任务分布 $\mathcal{T}$、引出配置 $H$（prompt 模板、示例、scaffold、采样预算、温度、答案抽取与判分器的整体），观测分数为 $s(M; \mathcal{T}, H)$。定义能力 capability为可行引出配置集合 $\mathcal{H}$ 上的上确界 $\;c(M;\mathcal{T}) = \sup_{H \in \mathcal{H}} s(M;\mathcal{T},H)$。 则任意一次评测只给出 $s(M;\mathcal{T},H) \le c(M;\mathcal{T})$，即能力的一个下界； 下界与上确界之差就是 elicitation gap（引出差距）。$\mathcal{H}$ 的边界如何划（允不允许微调？允不允许人类改写中间结果？）本身是评测协议的一部分，必须显式声明。

这个"下界视角"对两类评测的含义截然不同——这是 METR 反复强调的非对称性 [METR 2024]：

评测类型under-elicitation 的后果错误方向危险程度
产品 / 排行榜评测某模型被低估、排名失真对该模型不公平，但错误"看得见"（厂商会抗议）中
安全 / 危险能力评测"模型不具备危险能力 X"的结论实际只意味着"在我们尝试的引出水平下没表现出 X"系统性偏向"安全"一侧的假阴性，且没有人有动机去纠正它高
虚假安心（false assurance）是安全评测的头号失败模式。 METR 的引出指南指出：不做认真引出的评测者可能大幅低估模型能力（"dramatically underestimating model capabilities"）， 而他们的实测显示，post-training 增强（更好的 scaffold、prompt、工具接入、微调）带来的提升幅度 与 GPT-3.5 → GPT-4 的代际差同一量级 [METR 2024]。换句话说：一份 under-elicited 的危险能力评测报告， 相当于拿上一代模型的成绩单为下一代模型的部署背书。基于此，METR 的方法论是： ①评测前先做"小团队一个月内可完成"的基础引出；②把可由小修复消除的spurious failure（格式错误、工具调用语法错、token 截断） 单独核算，估计"修掉之后"的分数；③把结果显式解读为下界，并为未来引出改进预留安全余量（safety margin）。
一个有用的心智模型：评测报告里的每个数字都该带一个"引出水平"标签，就像统计量必须带误差条（模块 02）一样。 "score = 41.2" 不是一个完整的论断；"score = 41.2 ± 1.8 @ zero-shot, greedy, n=1, 答案抽取协议 v3" 才是。

2引出阶梯：从 zero-shot 到微调引出

引出手段不是一团模糊的"prompt 工程"，可以排成一个成本递增、强度递增的阶梯。评测协议要做的，就是声明自己站在哪一级、为什么。

3pass@k 的数学：定义、朴素估计的偏差、无偏估计量推导

引出阶梯的 L4（best-of-n）和"能力存在性"问题都依赖同一个核心指标：pass@k。 它最早在代码生成评测中被形式化 [Chen 2021, HumanEval]，因为代码有天然的 oracle 判分器——单元测试。

3.1 定义

对单个题目，设模型在给定温度下每次独立采样的成功概率为 $p$（per-sample 成功率）。 采 $k$ 个样本，至少一个通过的概率：

$$ \text{pass@}k(p) \;=\; 1-(1-p)^k $$

benchmark 层面是对 $M$ 道题取平均（各题真实成功率 $p_1,\dots,p_M$ 各不相同）：

$$ \text{Pass@}k \;=\; \frac{1}{M}\sum_{i=1}^{M}\bigl[1-(1-p_i)^k\bigr] $$

$p_i$ 不可直接观测，只能对每题采 $n \ge k$ 个样本、数出通过数 $c_i$，再构造估计量。问题来了：怎么估才无偏？

3.2 两种朴素估计，两个方向的偏差

记 $f(p) = 1-(1-p)^k$。对 $k\ge 2$，$f''(p) = -k(k-1)(1-p)^{k-2} < 0$，即 $f$ 严格凹。两种"看起来都对"的朴素做法分别栽在 Jensen 不等式的两侧：

朴素估计 A（聚合式，系统性高估）：把全 benchmark 汇总成一个 $\bar{p} = \frac{1}{M}\sum_i \hat{p}_i$，再代入公式 $1-(1-\bar p)^k$。由 Jensen 不等式（$f$ 凹）：

$$ \frac{1}{M}\sum_{i=1}^{M} f(p_i) \;\le\; f\!\Bigl(\frac{1}{M}\sum_{i=1}^{M} p_i\Bigr) \quad\Longrightarrow\quad \text{Pass@}k \;\le\; 1-(1-\bar p)^k, $$

且只要各题难度不全相同、$k\ge2$，不等号严格成立。题目难度越异质，高估越严重，并且偏差不随 $n\to\infty$ 消失——这是协议级错误，不是采样噪声。 极端例子：一半题 $p_i=1$、一半 $p_i=0$，真实 $\text{Pass@}k = 0.5\;\forall k$，而聚合式给出 $1-(0.5)^k \to 1$。 直觉：公式把"平均成功率 0.5"误读成"每道题都有 0.5 的机会"，但那一半 $p_i=0$ 的题采多少次都不会过。

朴素估计 B（逐题插入式，低估 + 高方差）：对每题用 $\hat p_i = c_i/n$ 代入，$\frac1M\sum_i\bigl[1-(1-c_i/n)^k\bigr]$。这次 Jensen 作用在题内采样噪声上：$\hat p_i$ 无偏但有方差，凹函数下 $\mathbb{E}\bigl[f(\hat p_i)\bigr] \le f(p_i)$，即系统性低估。 Chen et al. 在 HumanEval 论文附录中专门指出这一点：该估计是"一致的低估（consistent underestimate）"， 且即便 $n > 5k$ 偏差仍未完全消失——更糟的是偏差大小依赖 $n$，导致"采样更多、分数更高"的伪改进 [Chen 2021]。

估计量公式偏差方向偏差来源随 n→∞ 消失？
朴素 A：聚合式$1-(1-\bar p)^k$，$\bar p$ 为全集平均高估题目难度异质 + Jensen（题间）否
朴素 B：逐题插入$\frac1M\sum_i 1-(1-c_i/n)^k$低估题内采样噪声 + Jensen（题内）是，但慢（$n>5k$ 仍可见）
Chen 2021 无偏估计$\frac1M\sum_i \Bigl[1-\binom{n-c_i}{k}\big/\binom{n}{k}\Bigr]$无偏—对任意 $n\ge k$ 严格无偏

3.3 无偏估计量的完整推导

固定一道题，$n$ 个样本是 i.i.d. Bernoulli$(p)$：$X_1,\dots,X_n$，$c=\sum_j X_j$。Chen et al. 的估计量：

$$ \widehat{\text{pass@}k} \;=\; 1-\frac{\binom{n-c}{k}}{\binom{n}{k}} $$

构造直觉：$\binom{n-c}{k}\big/\binom{n}{k}$ 是"从 $n$ 个样本中无放回均匀抽 $k$ 个，恰好全是失败样本"的比例。 无偏性证明：对任一固定的大小为 $k$ 的下标子集 $S$，由独立性 $\Pr\bigl(\forall j\in S: X_j = 0\bigr) = (1-p)^k$。把估计量的组合数比值改写成对全部子集的平均：

$$ \frac{\binom{n-c}{k}}{\binom{n}{k}} \;=\; \frac{1}{\binom{n}{k}}\sum_{|S|=k}\;\prod_{j\in S}(1-X_j) \quad\Longrightarrow\quad \mathbb{E}\!\left[\frac{\binom{n-c}{k}}{\binom{n}{k}}\right] = \frac{1}{\binom{n}{k}}\sum_{|S|=k} (1-p)^k = (1-p)^k . $$

故 $\mathbb{E}\bigl[\widehat{\text{pass@}k}\bigr] = 1-(1-p)^k$，对任意 $n\ge k$ 严格无偏。$\blacksquare$ 关键洞察：随机选出的 $k$ 个样本（无放回）本身就是 $k$ 个 i.i.d. 样本，所以"子集全败比例"的期望恰好等于真概率； 而朴素 B 相当于从经验分布有放回抽 $k$ 次，失败样本会被重复抽中，"全败"概率被抬高、pass@k 被压低。

3.4 数值稳定实现

$n$ 稍大（如 $n=200$）时组合数会溢出浮点范围，必须用逐项乘积形式（恒等变形）：

$$ \frac{\binom{n-c}{k}}{\binom{n}{k}} \;=\; \prod_{i=n-c+1}^{n}\Bigl(1-\frac{k}{i}\Bigr) \qquad(\text{共 } c \text{ 项，全部} \in [0,1]\text{，绝不溢出}) $$ 
def pass_at_k(n, c, k):           # Chen et al. 2021, 数值稳定版
    if n - c < k: return 1.0      # 失败样本不足 k 个 → 任取 k 个必含正确解
    return 1.0 - np.prod(1.0 - k / np.arange(n - c + 1, n + 1))
边界行为要背下来：$c=0 \Rightarrow$ 空乘积 $=1 \Rightarrow$ 估计为 $0$；$n-c<k$（含 $c=n$）$\Rightarrow \binom{n-c}{k}=0 \Rightarrow$ 估计为 $1$； $k=1 \Rightarrow$ 退化为 $c/n$。notebook 练习 1 会让你亲手实现并对照精确组合数验证。

4pass@k 的统计性质：方差、n 怎么选、k→n 的退化

无偏只解决了一半问题。Chen et al. 之所以对每题采 $n=200$ 个样本来报告 $k\le 100$ 的 pass@k，是因为方差才是实践瓶颈 [Chen 2021]。

4.1 k 接近 n 时估计退化

看极端情形 $k=n$：估计量变成 $1-\binom{n-c}{n}\big/\binom{n}{n} = \mathbb{1}\{c\ge 1\}$——一个 Bernoulli 变量，方差 $q(1-q)$，$q = 1-(1-p)^n$， 完全没有从 $n$ 个样本中获得任何平均化收益。直觉：$k$ 越接近 $n$，不同的 $k$-子集重叠越严重， "很多子集"提供的信息趋同于"一个子集"。反之 $k\ll n$ 时，估计量接近对许多近独立子集取平均，方差小。

4.2 n 该取多大

  • 无偏性对 $n$ 没有要求（任意 $n\ge k$ 即可），$n$ 纯粹是买方差的。
  • 经验法则：$n\ge 2k$ 起步（Chen 2021 用 $n=200$, $k\le100$），预算允许时 $n\ge 5k$；报告最高的那个 $k$ 决定 $n$ 的下限。
  • benchmark 层面总方差有两个来源（模块 02 的分解在此复用 [Miller 2024]）：题目抽样方差（$M$ 道题是任务分布的样本）+ 生成随机性方差（每题 $n$ 次采样的噪声）。$k/n$ 大时第二项膨胀。
  • 实操上不要套闭式公式，直接 bootstrap：对题目维度重采样得到 $\text{Pass@}k$ 的 CI（notebook 演示）；若 CI 宽到影响结论，优先加 $n$（若方差主要来自生成噪声）或加题（若来自题目抽样）。
  • 两个免费的方差红利：$p_i$ 接近 0 或 1 的题，$c_i$ 几乎确定，贡献的生成方差≈0；所以中等难度题主导方差预算。
把 $n$、$k$、CI 三件事压缩成一句话：报告 pass@k 时必须同时报告 n 和 CI。 "pass@10 = 63%" 在 $n=10$ 和 $n=100$ 下是两个完全不同可信度的论断——前者用的还是 $k=n$ 的退化估计。

5best-of-n 与 verifier：能力上界探针

pass@k 隐含了一个强假设：存在 oracle verifier——一个完美判分器（单元测试、数学答案精确匹配）， 能从 $k$ 个候选中认出正确解。"$k$ 次里有一次对就算过"度量的是能力存在性，不是单次交付的可得性。 而部署中真正要做的是 best-of-n（BoN）：采 $n$ 个候选，用某个选择器挑一个交付。两者的关系取决于 verifier 质量：

设置选择器与 pass@n 的关系回答的问题
pass@1（t=0, greedy）无（只采一次）下界中的下界开箱即用的部署表现
BoN + oracle verifier程序判分（单测 / 精确匹配）恒等：BoN@n ≡ pass@n可验证域内、$n$ 倍推理预算能买到什么
BoN + 不完美 verifierreward model / LLM judge / 多数投票BoN@n ≤ pass@n，差距 = verifier 的假阴/假阳率真实部署中采样预算的回报
pass@k（k 大）oracle，只问存在性—能力上界探针

BoN/pass@k 作为"能力上界探针"：当 $k$ 足够大，pass@k 逼近"该温度下模型支持集中是否含正确解"， 即把 §1 的 $\sup_H$ 限制在"采样预算"这一维度上能摸到的上界。它是最便宜的引出审计手段： 不改 prompt、不搭 scaffold，只多花推理算力，就能探出"模型究竟会不会"。

安全评测中 k 的选择必须匹配威胁模型 [METR 2024 视角]。 排行榜关心 pass@1（用户体验是单次交互）；但攻击型威胁模型里，攻击者可以采样成千上万次、只需一次成功（漏洞利用、合成路线）。 此时 pass@1 = 0.1% 不是"安全"，而是"攻击者平均试 1000 次即可成功"。对危险能力，pass@k 在大 k 下的值（以及它随 k 的增长斜率） 才是与风险相关的统计量；用 pass@1 给危险能力下"不具备"结论是 under-elicitation 的一种典型形态。
pass@k 曲线（$k=1\dots n$ 的整条曲线）比任何单点都信息量大：平坦 = 模型"会就是会、不会就是不会"（$p_i$ 两极分化）； 陡峭 = 大量中等 $p_i$ 的题，采样预算回报高，也意味着一个好 verifier 的价值巨大。notebook 会画出这条曲线。

6温度与多样性：t=0 测行为，t>0 测分布

温度 $t$ 不是无关紧要的实现细节，它决定了你在测哪一个统计对象：

  • $t=0$（greedy / 近确定性）：测的是行为分布的众数——"这个模型在部署默认值下会做什么"。可复现性好，适合回归测试与 pass@1 报告。
  • $t>0$ + 多次采样：测的是整个输出分布，包括尾部——"这个模型能做什么"。pass@k、BoN、能力探针都活在这个域里。

两者会系统性地分离：升温使单样本成功率 $p$ 下降（采到次优 token 的概率变大），但多样性上升使 $k$ 个样本覆盖的解空间变大。 在 $1-(1-p)^k$ 中，前者压低单项、后者让各样本"不再犯同一个错"，净效应随 $k$ 翻转—— HumanEval 上的实测：pass@1 的最优温度约 0.2，pass@100 的最优温度约 0.8 [Chen 2021]。 greedy 采 $k$ 次只会得到同一个答案的 $k$ 份拷贝，pass@k 曲线完全平坦。

报告项采样设置它刻画什么常见误用
pass@1 @ t=0greedy，1 次部署默认行为被当成"能力"解读 → 低估
pass@k @ t≈0.6–0.8n≥2k 次采样，无偏估计能力分布 / 采样预算回报被当成"单次表现"解读 → 高估
两者都要报，且绝不跨设置比较。排行榜上同名指标"pass@1"有两种算法：greedy 一次，或 $t>0$ 采 $n$ 次后取无偏估计 $c/n$—— 数值可以差很多（前者是众数行为，后者是平均成功率）。比较两个模型时，温度、$n$、top-p、答案抽取协议必须完全一致； 论文复现失败的相当一部分根因就是温度协议不一致（与模块 03 的 prompt 敏感性同属"harness 自由度"问题）。

7scaffolding 效应实证：度量 elicitation gap

§1 把 elicitation gap 定义成 $\sup$ 与观测值之差——不可直接测。但它的逐级差分完全可测： 固定模型与题集，只改变引出配置，分数之差就是相邻两级之间的引出差距：

$$ \Delta(H_a \!\to\! H_b) \;=\; s(M;\mathcal{T},H_b) - s(M;\mathcal{T},H_a), \qquad \text{如 } H_a=\text{zero-shot},\; H_b=\text{+CoT} $$

这是一个配对设计：同一模型、同一批题、两套 harness。正确的统计处理与模块 02 的模型间配对比较完全同构—— 逐题计算 $g_i = s_i^{(b)} - s_i^{(a)}$，对题目维度做配对 bootstrap 得 $\bar g$ 的 CI； 配对消掉了题目难度这一最大方差来源，比"两个总分相减再各自挂误差条"灵敏得多。notebook 练习 3 实现这个工具。

实证上要点有三：

  • gap 可以很大：CoT 一项在推理任务上就值数十个点 [Wei 2022]；METR 测得 scaffold 迭代 + 修 spurious failure 的总效应与一次代际升级相当 [METR 2024]。
  • gap 是模型相关的：CoT 对小模型无效甚至有害 [Wei 2022]。因此排行榜在不同引出水平下排序可以翻转——A 在 zero-shot 赢 B，B 加 CoT 后反超。比较模型时必须同一引出水平，或干脆报告整条"分数–引出水平"曲线。
  • gap 本身是有价值的评测产出：gap 大 = 模型能力远未被默认接口暴露（对安全评测是警报：现成 scaffold 一接，能力就解锁）；gap 小且分数低 = 更可能是真实能力边界。
METR 的工程经验 [METR 2024]：引出工作中性价比最高的往往不是高深的 prompt 技巧，而是修伪失败—— 输出格式不合判分器预期、工具调用 JSON 语法错、上下文 / token 预算被截断、不必要的拒答。 这些失败与"能力"无关，却被计为 0 分。评测报告应分别给出"原始分"与"修复伪失败后的分"，两者之差是 harness 质量的度量（模块 07 展开）。

8研究前沿与开放问题

  • 引出协议的标准化：分数本质上是二元组（score, 引出水平），但目前没有公认的引出水平描述语言。 方向：像报告误差条一样强制报告 elicitation budget（人时、scaffold 迭代数、采样预算、是否微调）； harness 框架（Inspect、lm-evaluation-harness，模块 07）把 scaffold 声明式化，使引出配置可版本化、可复现。 评测视角：没有引出声明的跨论文分数比较应默认无效。
  • 安全评测中的引出义务：危险能力评测的"阴性结论"需要附带引出充分性论证——你凭什么相信自己接近了 $\sup_H$？ 开放问题：第三方评测者应否获得微调权限（L5 是最强引出，但厂商最难开放）； 如何预测未来 post-training 改进带来的增益，从而把 safety margin 定量化而非拍脑袋 [METR 2024]。
  • 密度估计式评测：单点分数 → 整条 pass@k 曲线 → 直接估计每题成功率 $p_i$ 的分布密度。 pass@k 曲线是该分布的一族泛函（$\mathbb{E}[1-(1-p)^k]$ 是矩母函数式的变换）；两模型曲线交叉时任何单点比较都会误导。 与 item response theory 的题目难度建模合流，是"评测科学"最数学化的前沿之一。
  • 引出效率曲线（elicitation scaling）：把分数画成引出算力（采样数、scaffold 复杂度、微调步数）的函数， 用曲线的形状（斜率、饱和点）而非单点刻画模型。它与 METR 的 time-horizon 度量（模块 08）共享同一动机： 用对协议扰动更稳健的泛函替代脆弱的标量分数。
  • verifier 的能力天花板：BoN 的收益受 verifier 质量钳制，而最强的 verifier 本身往往也是 LLM（模块 04 的 judge 偏置全部回来了）。 "生成-验证差距"（验证比生成容易多少）在哪些域成立、能否被量化，决定了采样预算换能力的兑换率。
