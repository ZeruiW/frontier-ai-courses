# 术语词典 · Glossary（小目标检测）

> 按主题分组：**问题定义与量化 / 多尺度架构 / 分配与度量 / 切片与高分辨率 / TSR 实战**。
> 每条给「英文 / 中文 / 一句话定义 / 为什么重要 / 常见误解」五项。
> 「常见误解」那一列是本词典最值得读的部分——它们大多是面试当场翻车或线上事故的来源。
> 英文术语一律保留原文。

## 一 · 问题定义与量化 · Defining & Quantifying the Problem

| 术语 (EN) | 中文 | 一句话定义 | 为什么重要 | 常见误解 |
|---|---|---|---|---|
| small object (absolute) | 小目标（绝对定义） | COCO 口径：框面积 < 32×32 = 1024 px²（medium 32²–96²，large > 96²）。 | 它是 `AP_S` 这个指标的定义基础，论文里所有「小目标涨了多少」都以它为准。 | 以为它是「看起来小」——它是**像素面积**，与图像分辨率强耦合：同一个物体在 4K 图里可能就不算小了。 |
| tiny object | 微小目标 | AI-TOD 等基准把 2–8 px、8–16 px 单独分档；TinyPerson 里的人平均只有十几个像素。 | COCO 的 small 桶里混了「32 px 的容易样本」和「6 px 的绝望样本」，一个 AP_S 完全掩盖了这个差别。 | 以为 small 和 tiny 是同义词——两者的解法优先级完全不同：tiny 主要靠分辨率与切片，small 主要靠分配与融合。 |
| relative size | 相对尺寸 | 目标框面积 ÷ 图像面积（或开方后的边长比）。TT100K 里的标志常常 < 0.1% 的图像面积。 | 跨数据集比较必须用相对定义，否则「4K 数据集里的小目标」和「VGA 数据集里的小目标」根本不是一回事。 | 以为绝对与相对定义只是单位换算——在同一份数据上，两种定义划出的 small 子集重合度可能只有六七成。 |
| AP_S / AP_small | 小目标平均精度 | COCO 里只统计面积 < 32² 的 GT 与其匹配预测算出的 AP。 | 小目标工作的主指标，也是最容易被总 mAP 稀释掉的分量。 | 以为 AP_S 低就是「模型不行」——很多时候是这个桶里 GT 的标注噪声大，AP_S 的**上界**本身就不高。 |
| IoU scale sensitivity | IoU 的尺度敏感性 | 同样的绝对像素位移，小框的 IoU 衰减远快于大框：8×8 的框对角位移 2 px，IoU 从 1.00 掉到 0.39；64×64 的框还有 0.88。 | **本课的第一性原理**：它一口气解释了正样本稀缺、评测严苛、标注噪声被放大三件事。 | 以为「小目标难」是因为「看不清」——信息量少只是原因之一，IoU 的几何性质是另一个**完全独立**的原因，即使特征完美也躲不掉。 |
| critical displacement | 临界位移 | 使 IoU 跌到匹配阈值的最小位移。方框边长 w、对角位移 d 时 IoU = (w−d)²/(2w²−(w−d)²)；令其等于 0.5 得 d ≈ 0.1835·w。 | 8 px 的框只允许 1.5 px 的误差——这个数字直接告诉你标注与预测还剩多少余量。 | 以为 0.5 的 IoU 阈值「不算严」——对 8 px 目标它等价于要求**亚 2 像素**的定位精度。 |
| positive sample scarcity | 正样本稀缺 | 基于 IoU 阈值的标签分配下，小目标能匹配上的 anchor / 特征点极少甚至为零。 | 一个目标 0 个正样本 = 它对分类分支**完全没有梯度**，模型是「没学过」而不是「学不好」。 | 以为加大 loss 权重就能解决——权重乘以零还是零。必须**先让它有正样本**，加权才有意义。 |
| downsampling loss | 下采样丢失 | stride 为 s 的特征图上，边长 p 的目标只占 p/s 个格子；stride 32、p = 8 时只有 0.25 个格子。 | 不到一个格子意味着这个目标在该层**没有专属的空间位置**去表达自己。 | 以为「信息还在，只是被压缩了」——低于采样率的高频细节是被**混叠**掉的，不可恢复。 |
| feature aliasing | 特征混叠 | 下采样率低于 Nyquist 频率时，高频细节折叠成虚假的低频成分。 | 解释了为什么小目标在深层特征里会与背景纹理「长得像」，也解释了不加抗混叠的 stride-2 卷积对小目标特别有害。 | 以为混叠只是传统图像处理的概念——CNN 里每一个 stride > 1 的层都在做欠采样。 |
| relative annotation noise | 标注噪声的相对量级 | 人工标注典型误差 ±1–2 px；对 8 px 的框是 12–25% 的相对误差，对 80 px 的框只有 1–2%。 | 小目标的**标签本身带噪**，这给 AP_S 设了天花板：再好的模型也逼不出比标注更准的框。 | 以为「多标几遍就解决了」——tiny 尺度上多人标注的一致性本身就低，得从标注协议入手（多小算有效、遮挡怎么标、要不要标）。 |
| context dependency | 上下文依赖 | 目标自身像素不足以判别时，必须依赖周围信息（杆件、路侧、车道线、天空线）。 | 「提高分辨率」和「引入上下文」是小目标的两条互补路线，前者补细节、后者补先验。 | 以为上下文越多越好——过大的上下文会把背景学成捷径（「路边黄色方块 = 警告牌」），一到分布外场景就崩。 |
| size-bucketed evaluation | 尺寸分桶评测 | 按目标像素边长（如 < 8 / 8–16 / 16–32 / 32–64 / > 64）分桶，分别算 AP 与召回。 | **不分桶，小目标的改进在总 mAP 上几乎不可见**，因为小目标在 mAP 里的权重太小。 | 以为 COCO 的 AP_S/M/L 三桶就够了——太粗；TSR 真正的战场全在 AP_S 桶的**内部**。 |
| effective receptive field (ERF) | 有效感受野 | 梯度回传强度在输入图上的分布；实际只有理论感受野的一小部分，呈高斯衰减，随深度 n 按 O(√n) 增长而非 O(n)。 | 解释了为什么「堆很多 3×3」不等于「大感受野」；也是 RTMDet 用 5×5 depthwise 大核、RFLA 用高斯 ERF 做分配先验的直接依据。 | **以为理论感受野就是实际有效范围——这是本领域最大的误解之一。** 另外 ERF 不是固定的，它随训练进程和输入内容变化。 |
| theoretical receptive field | 理论感受野 | 输出某个位置在理论上能「看到」的输入区域大小，可由 stride 与 kernel 逐层递推。 | 设计网络时的粗算工具（堆几层 3×3 能覆盖多大区域）。 | 以为它可以直接拿来做「目标尺寸与层级匹配」的依据——真正该用的是 ERF，两者能差好几倍。 |

## 二 · 多尺度架构 · Multi-Scale Architecture

| 术语 (EN) | 中文 | 一句话定义 | 为什么重要 | 常见误解 |
|---|---|---|---|---|
| FPN | 特征金字塔网络 | 自顶向下把高层语义上采样后与低层高分辨率特征相加，得到每层「既有分辨率又有语义」的金字塔（P2–P7）。 | 所有现代检测器的默认脖子；小目标全靠它把语义带到高分辨率层。 | 以为 FPN 就是「多尺度预测」——SSD 也在多个尺度上预测但**没有融合**；FPN 的关键是融合，因为低层单独用时语义太弱。 |
| level assignment formula | 层级分配公式 | k = ⌊k₀ + log₂(√(wh) / 224)⌋，k₀ = 4（即 224 px 的目标分到 P4）。 | 它是「哪个尺度归哪层管」的成文规则；代入 TSR 的尺寸分布会发现绝大多数标志都被 clamp 到最低层，该层严重过载。 | 以为公式只是拍脑袋的经验值——它的物理含义是「让目标尺寸与该层的有效感受野匹配」，改 k₀ 等价于整体平移「尺度↔层」的映射。 |
| P2 level | stride-4 特征层 | 金字塔中分辨率最高的那一层（输入的 1/4）。 | 加 P2 是小目标**收益最直接**的一招，也是最贵的：P2 一层的像素数就是 P3+P4+P5 之和的 3 倍，检测头总计算量约变成原来的 4 倍。 | 以为「加了 P2 就一定涨」——正样本数暴涨会同时带来更多误检，必须配套调整分配规则与正负样本平衡，否则 precision 掉得比 recall 涨得还多。 |
| PAN / PANet | 路径聚合网络 | 在 FPN 的自顶向下之后再补一条**自底向上**的通路，把低层的精确定位信息送回高层。 | 定位信息的传播路径从「穿过整个 backbone」缩短到几层，直接改善框的回归精度。 | 以为 PAN 只是「多加一条路」增加容量——它解决的是**信息路径长度**问题，不是容量问题。 |
| BiFPN | 双向加权特征金字塔 | EfficientDet 的脖子：双向融合 + 每条边一个可学习标量权重（fast normalized fusion）+ 同分辨率跳连 + 重复堆叠。 | 加权融合承认「不同来源的特征贡献不等」，这在小目标上尤其明显——高层对 P2 几乎只提供语义先验。 | 以为加权是某种注意力——它是**每条边一个标量**的极轻量权重，不是空间注意力，代价可以忽略。 |
| ASFF | 自适应空间特征融合 | 让**每个空间位置**自己学习各层特征的融合权重。 | 承认融合权重应该逐像素不同：有标志的位置该更依赖高分辨率层，天空区域不需要。 | 以为它与 BiFPN 功能重复——BiFPN 是每条边一个标量，ASFF 是每个位置一组权重，粒度差了好几个数量级。 |
| upsampling operator | 上采样算子 | FPN 里把高层特征放大的方式：最近邻 / 双线性 / 转置卷积 / CARAFE（内容感知重组）。 | 最近邻上采样会引入块状伪影，在 P2 这种高分辨率层上对小目标的定位有可测量的影响。 | 以为上采样方式无关紧要——在小目标场景，这是少数「改一行配置就有 0.3–0.5 AP_S」的地方。 |
| deformable attention | 可变形注意力 | 每个 query 只在少量**可学习的采样点**上取特征，而不是对全图做 attention。 | 对小目标友好：采样点能精确落在小目标上，不会被海量背景 token 稀释；也让多尺度 attention 的计算量降到可承受。 | 以为它只是「省计算」的工程技巧——它同时是**稀疏聚焦**机制，这才是小目标真正受益的原因。 |
| resolution vs depth | 分辨率与深度的取舍 | 同样的算力预算，是提高输入分辨率还是加深/加宽网络。 | 小目标场景下**分辨率的边际收益通常远高于深度**，这也是 EfficientDet 复合缩放的核心结论之一。 | 以为「分辨率翻倍 = 计算翻倍」——是**平方**关系：1.5× 分辨率就是 2.25× 计算，2× 分辨率是 4×。 |
| super-resolution for detection | 检测用超分 | 用 SR 网络先放大图像或特征，再送进检测器（Perceptual GAN、MTGAN 等路线）。 | 学术上常见的小目标路线，在极端 tiny 场景（遥感）有过收益。 | **以为超分能「补出」信息**——SR 生成的是符合先验的**合理纹理**，不是真实信息；对分类可能有害（幻觉出不存在的数字）。工程上收益通常远小于直接提高输入分辨率。 |
| anti-aliased downsampling | 抗混叠下采样 | 在 stride-2 操作前先做低通滤波（如 BlurPool），减少混叠。 | 直接对应「下采样丢失」这一难因，且几乎零参数成本。 | 以为它只影响平移不变性——对小目标它同时影响**特征的可分性**，因为混叠会让小目标与背景纹理的频谱混在一起。 |
| high-resolution branch | 高分辨率分支 | HRNet 式的设计：全程保持一条高分辨率通路，而不是先降再升。 | 避免「降采样丢失 → 上采样也补不回来」的信息瓶颈。 | 以为它等价于加 P2——HRNet 是**始终**维持高分辨率并多分辨率互相交换，代价与结构改动都比在脖子上加一层大得多。 |

## 三 · 分配与度量 · Assignment & Metrics

| 术语 (EN) | 中文 | 一句话定义 | 为什么重要 | 常见误解 |
|---|---|---|---|---|
| label assignment | 标签分配 | 决定每个 anchor / 特征点 / query 是正样本还是负样本、对应哪个 GT。 | **对小目标而言这是比 backbone 更关键的一环**：分配错了，再好的特征也拿不到监督信号。 | 以为分配只是训练细节——它决定了正样本的数量与空间分布，直接等价于「模型到底学到了什么」。 |
| center-based assignment | 中心先验分配 | 只把落在 GT 中心区域（如中心 ±r·stride）内的点当正样本，不看 IoU。 | **对尺度天然更公平**：不管框多小，中心总是存在，正样本数不会归零。FCOS / YOLOX 等 anchor-free 检测器的基础。 | 以为它完全不看尺度——center sampling 的半径 r 通常仍与 stride 挂钩，且必须配合层级分配限定每层负责的尺寸范围。 |
| scale-adaptive IoU threshold | 尺度自适应 IoU 阈值 | 对小目标放宽匹配阈值（如 0.5 → 0.3）。 | 最便宜的一招，一行配置就能让小目标拿到正样本。 | **以为阈值越低越好**——过低会把大量严重偏移的框判成正样本，回归目标变噪声，定位质量整体下降。 |
| ATSS | 自适应训练样本选择 | 对每个 GT 在每层取最近的 k 个候选，用这些候选 IoU 的**均值 + 标准差**作为该 GT 专属的阈值。 | 阈值随目标自适应，天然缓解尺度不公平；且几乎零成本，没有需要按尺度调的超参。 | 以为 ATSS 是「动态 k」——ATSS 的 k 是**固定**的，动态的是**阈值**；动态 k 是 OTA / SimOTA 的做法。 |
| SimOTA / dynamic-k | 动态 k 分配 | 用代价矩阵（分类 + 回归）为每个 GT 选 top-k 个候选，k 由该 GT 与候选的 IoU 之和动态决定。 | 让「容易的目标少给正样本、难的目标多给」，对小目标是一种隐含补偿。 | 以为 dynamic-k 一定利好小目标——若小目标的 IoU 普遍低，算出的 k 也会小，反而更稀缺；需要配合 NWD 之类的度量一起用。 |
| NWD | 归一化 Wasserstein 距离 | 把框 (cx, cy, w, h) 建模为 2D 高斯 N(μ, Σ)，μ = (cx, cy)、Σ = diag(w²/4, h²/4)，用二阶 Wasserstein 距离度量差异，再取 NWD = exp(−√(W₂²) / C) 归一化到 (0, 1]。 | **小目标度量的关键突破**：① 对尺度不敏感（相对位移相同则 NWD 相同）；② **两框完全不相交时仍有平滑梯度**——IoU 在这里恒为 0，什么也学不到。 | 以为 NWD 能直接替换所有 IoU——它主要用在**分配与损失的相似度度量**上；评测仍应用 IoU（否则无法与他人比较）。另外常数 C 必须按数据集的平均目标尺寸标定，照抄论文的数会失效。 |
| Wasserstein distance (W₂) | 二阶 Wasserstein 距离 | 两个分布之间「把一个搬成另一个」的最小代价；对角协方差高斯之间有闭式解：W₂² = ‖(cx_a, cy_a, w_a/2, h_a/2) − (cx_b, cy_b, w_b/2, h_b/2)‖²。 | 实现只有一行，没有任何理由不试；它把「框的相似度」变成了一个处处可微、处处非零梯度的连续量。 | 以为要跑最优传输的迭代求解——高斯之间的 W₂ 有闭式解，无需任何迭代。 |
| RFLA | 感受野先验的标签分配 | 把该层的**有效感受野**建模为高斯，用它与 GT 高斯之间的 KL 散度（RFD）做匹配，并用分层 top-k（HLA）保证每个 GT 至少拿到样本。 | 从「框与框的重叠」换成「感受野与目标的匹配」，本质上承认特征点感知的是一个高斯衰减的区域而非一个矩形。 | 以为 RFLA 是 NWD 的变体——两者都用高斯，但 NWD 建模的是**框**、RFLA 建模的是**感受野**，解决的是流水线上不同的环节，可以叠加。 |
| GIoU | 广义 IoU | 在 IoU 基础上减去「最小闭包框中不属于并集的部分」占闭包的比例。 | 解决 IoU 在两框不相交时梯度恒为 0 的问题。 | **以为 GIoU 解决了小目标**——它只提供了「把框拉近」的方向梯度，收敛慢；一旦两框重叠它就退化成 IoU，尺度敏感性问题原样保留。 |
| DIoU | 距离 IoU | 在 IoU 基础上额外惩罚中心点距离 ρ²(b, b_gt) / c²（c 为闭包对角线）。 | 直接优化中心对齐，收敛比 GIoU 快；也是 DIoU-NMS 的基础。 | 以为中心距项对小目标特别有效——分母 c² 是闭包对角线，在小框场景这一项数值很小，权重需要重新标定。 |
| CIoU | 完整 IoU | DIoU 再加一个宽高比一致性项 α·v。 | 把重叠面积、中心距、长宽比三要素补齐，长期是 YOLO 系的默认损失。 | 以为 CIoU 一定优于 DIoU——宽高比项在极小框上因宽高的量化误差而噪声很大，小目标场景有时反而不如 DIoU。 |
| SIoU | 角度感知 IoU | 引入角度代价，先把预测框拉到与 GT 同一水平或垂直轴上，再收敛距离与形状。 | 减少「绕远路」的回归轨迹，收敛更快。 | 以为角度项是给旋转框用的——SIoU 面向的是**水平框**，这里的角度指的是两框**中心连线**的方向。 |
| EIoU | 高效 IoU | 把 CIoU 的长宽比项拆成宽、高各自的独立惩罚，并可配 Focal 加权（Focal-EIoU）。 | 长宽比是耦合量，拆开后梯度方向更直接；Focal 加权还能抑制低质量样本主导梯度。 | 以为 EIoU 只是 CIoU 的小改动——拆解改变了梯度方向本身，在小目标上差异是可测量的。 |
| scale-aware loss | 尺度感知损失 | 按目标尺寸给损失加权（小目标权重更高），或用 IoU / 定位质量加权。 | 在「正样本已经存在」的前提下，纠正小目标梯度贡献过小的问题。 | **以为可以只靠加权解决小目标**——正样本为零时权重无效；且过度加权会让模型为小目标牺牲大目标，AP_L 掉得比 AP_S 涨得多。 |
| focal loss tuning | Focal Loss 的小目标调参 | γ 控制难样本聚焦强度、α 控制正负样本平衡。 | 小目标场景负样本更多、正样本更难，(α, γ) 的最优点会明显偏离默认的 (0.25, 2.0)。 | 以为 γ 越大越好——γ 过大时，「难样本」里混入的**噪声标签**（而小目标的标注噪声恰恰最大）会被重点放大，等于在学错的东西。 |
| quality branch | 质量预测分支 | 额外预测一个定位质量分数（IoU / centerness），推理时与分类分数相乘。 | 抑制「分类分高但定位差」的框——这种情况在小目标上尤其常见。 | 以为它只是个排序技巧——它同时给回归分支提供了额外的监督信号，去掉后回归质量也会掉。 |
| Gaussian bbox modeling | 框的高斯建模 | 把矩形框看成一个 2D 高斯分布（中心为均值、半宽半高为标准差）。 | 是 NWD、RFLA、GWD、KLD 这一整族方法的共同起点：一旦框变成分布，就可以用各种分布距离替代 IoU。 | 以为高斯建模只是数学包装——它带来了实质的性质改变：**处处可微、不相交时仍有梯度、对尺度可归一化**，这三条 IoU 一条都没有。 |

## 四 · 切片与高分辨率 · Slicing & High Resolution

| 术语 (EN) | 中文 | 一句话定义 | 为什么重要 | 常见误解 |
|---|---|---|---|---|
| SAHI | 切片辅助超推理 | 把大图切成若干重叠的小块，各自送进检测器，再把坐标还原并合并；可选叠加一次全图推理以保住大目标。 | **不改模型、不重训就能大幅提升小目标召回**，因为它把目标的相对尺寸放大了「原图边长 ÷ 切片边长」倍。 | 以为它就是多尺度测试（TTA）——TTA 是把同一张图整体缩放多次，SAHI 是**空间切分**：切片内目标的像素数不变，但它在输入里的**占比**变大了。 |
| slice overlap ratio | 切片重叠率 | 相邻切片的重叠像素 ÷ 切片边长，典型取 0.2。 | **下界由最大目标尺寸决定**：重叠像素必须 ≥ 目标的最大边长，否则一定存在某些位置的目标被所有切片切断。 | 以为重叠越大越好——重叠增大意味着步长减小，切片数按 1/(1−r)² 增长，代价迅速爆炸，且重复检测更多、合并更容易出错。 |
| cross-slice merging | 跨片合并 | 把各切片的框还原到原图坐标后去重与拼接。 | 同一目标会被多个切片检出；跨边界的目标会得到两个互补的**截断框**。 | **以为用普通 NMS 就行**——NMS 会保留一个截断框而丢掉另一半，得到一个偏小的框。应使用 NMM（Non-Maximum Merging，把高度重叠的框合并成外接框）或用 IoS 判定包含关系。 |
| NMM | 非极大合并 | 与 NMS 相对：高度重叠的框不是被抑制，而是被**合并**成它们的外接框。 | 切片场景的正确选择：两个截断框合并后才是完整目标。 | 以为 NMM 可以全局替代 NMS——在非切片场景，合并会把两个真实相邻的目标粘成一个，反而制造漏检。 |
| IoS | 交并小者比 | 交集面积 ÷ 两框中较小者的面积。 | 判断「截断框是否属于同一目标」时比 IoU 更合适——截断框与完整框的 IoU 可能只有 0.4，但 IoS 接近 1.0。 | 以为 IoS 可以拿来做评测——它对包含关系过于宽容（小框套在大框里 IoS 恒为 1），只适合做合并判据。 |
| tiling cost | 切片代价 | 切片数 n ≈ (⌈(W−s)/step⌉+1) × (⌈(H−s)/step⌉+1)，step = s − o。1920×1080、s = 512、重叠 20%（step = 410）→ 5×3 = 15 片，加一次全图共 16 次前向。 | **车端 33 ms 的预算里放不下十几次前向**——这是切片推理在量产系统里被否掉的直接原因。 | 以为可以靠 batch 摊平——batch 只提高吞吐、不降低总计算量，端到端**延迟仍然线性增长**。 |
| slicing-aided fine-tuning | 切片训练 | 用与推理端相同的切片方式生成训练数据，再微调模型。 | 切片会改变目标的尺寸分布与可见上下文范围，不做配套微调就存在训练-推理不一致。 | 以为切片只是推理端技巧——SAHI 论文里训练端的配套贡献了收益中相当大的一部分。 |
| two-stage cascade | 两级级联 | 第一级在低分辨率全图找候选 ROI（或粗类），第二级只对这些 ROI 做高分辨率精检/精分类。 | **延迟可控**：代价正比于 ROI 数量而非切片数，是量产系统的现实选择；也天然对应 TSR 的「检测 + 分类」两级方案。 | 以为级联一定更慢——只要第一级足够便宜、ROI 足够少，端到端可以比单级高分辨率更快。级联的真正代价是**误差相乘**。 |
| cascade recall | 级联召回 | 两级系统的总召回 = 第一级召回 × 第二级召回（或 × 分类准确率）。 | 90% × 90% = 81%——**这个乘法是级联系统最容易被忽视的代价**。 | 以为可以靠第二级救回第一级的漏检——第一级没有框出来的目标，第二级根本看不到它。 |
| cascaded sparse query | 稀疏查询式级联（QueryDet 式） | 用低分辨率层预测小目标的粗位置，只在这些位置上**稀疏地**计算高分辨率层。 | 拿到 P2 的精度，却不付 P2 的全图计算量。 | 以为稀疏计算在部署端一定快——稀疏 gather/scatter 算子在 TensorRT 上未必有高效实现，理论 FLOPs 降了但实测延迟可能不降，必须实测。 |
| ROI prior | ROI 先验 | 用消失点、车道线、地平线、高精地图把「可能有目标的区域」先验地限定在图像的一小块。 | **TSR 特有的巨大红利**：标志几乎只出现在道路两侧与上方，图像下半部分的路面完全不必精检。 | 以为可以硬编码一个固定 ROI——上下坡、颠簸、转弯都会让消失点移动几十到上百像素，必须动态估计并留足余量。 |
| vanishing point | 消失点 | 平行车道线在图像上的交点，对应无穷远方向的成像位置。 | 远处的小目标一定在消失点附近，它是动态 ROI 的锚点。 | 以为消失点固定在图像中心——俯仰角变化（刹车点头、载重、坡道）会让它上下移动，幅度足以让固定 ROI 完全切掉目标。 |
| dynamic resolution | 动态分辨率 | 按场景 / 车速 / 目标距离动态决定处理分辨率或 ROI 大小。 | 高速行驶需要看更远（更小的目标），低速不需要——把算力花在刀刃上。 | 以为动态分辨率会破坏一致性——只要**每一档配置都单独评测与标定**，它是可控的；不做分档评测才是真问题。 |
| letterbox inverse transform | letterbox 逆变换 | 把缩放 + padding（+ 切片偏移）后的坐标还原回原图坐标系。 | 切片推理里每个框至少要经过两次坐标变换，写错就是「所有框整体偏移」这一经典事故。 | 以为逆变换很简单——padding 是否居中、缩放比是否取整、是否 pad 到 stride 的整数倍，每一项都会引入偏移，必须端到端对拍验证。 |

## 五 · TSR 实战 · TSR in Practice

| 术语 (EN) | 中文 | 一句话定义 | 为什么重要 | 常见误解 |
|---|---|---|---|---|
| pinhole camera model | 针孔相机模型 | 物体的成像像素尺寸 px = f · S / Z，其中 f 是**像素单位**焦距、S 是物理尺寸（m）、Z 是距离（m）。 | **把「多远能看见」从经验变成算术**：给定标志尺寸与相机参数，检出距离可以直接解出来。 | 以为公式里的 f 是镜头的毫米焦距——它是**像素焦距**，需要用 f = (W/2)/tan(FOV_h/2) 从视场角换算。 |
| focal length in pixels | 像素焦距 | f = (W / 2) / tan(FOV_h / 2)。1920 宽、60° 水平 FOV → f ≈ 1663 px。 | 所有「像素 ↔ 物理量」换算的桥梁，也是相机选型比较的公共单位。 | 以为给定的 FOV 是对角视场——水平 / 垂直 / 对角三个 FOV 的数值差很多，代错会让结果偏差 20% 以上。 |
| typical TSR pixel size | TSR 的典型像素尺寸 | 60 cm 的限速牌、f ≈ 1663 px：30 m 处 33 px、60 m 处 17 px、100 m 处 10 px。 | **这组数直接证明 TSR 就是小目标问题**：要在 60 m 外检出，模型必须处理 17 px 的目标——已经在 COCO 的 small 桶深处。 | 以为「提高分辨率就能看更远」——分辨率翻倍只让像素数翻倍（17 → 33 px），检出距离并不线性外推，还会撞上镜头 MTF、运动模糊与 ISP 噪声的墙。 |
| angular resolution / IFOV | 角分辨率 | 每个像素对应的角度 ≈ FOV / W。60° / 1920 ≈ 0.031°/px。 | 相机选型的第一性指标；长焦相机的价值就是把角分辨率提高数倍。 | 以为像素多就等于看得远——同样 1920 宽，120° 广角的角分辨率只有 60° 的一半，看同样距离的牌少一半像素。 |
| multi-camera setup | 多相机分工 | 广角（近距离、大视野）+ 长焦（远距离、小视野）分工，各自跑各自的检测配置。 | **用光学手段解决小目标比任何算法都直接**，量产车普遍采用；也是系统设计题的标准答案之一。 | 以为长焦能替代广角——长焦视场太窄，近处的大标志、路口两侧的标志会完全出画；两者是互补不是替代。 |
| detection distance budget | 检出距离预算 | 从「需要多少反应时间」反推「多远必须检出」，再反推需要多少像素、什么分辨率、什么 stride。 | **把感知需求与整车安全需求打通**的完整推理链，是系统设计题的满分骨架。 | 以为越远越好——更远意味着更小的目标、更高的误检率与更大的算力开销；需求应由制动距离与规控响应时间界定，而不是「能看多远看多远」。 |
| minimum detectable size | 最小可检像素 | 检测器可靠工作的经验下界（配合 P2 与合适的分配约 8–12 px，再小召回快速塌陷）。 | 与检出距离预算联立后，直接给出分辨率与 FOV 的硬约束。 | 以为这纯粹是模型能力问题——它同时受**标注可行性**限制：人都标不准的目标，模型学不到，评测也测不准。 |
| FP per km | 每公里误检数 | 工程指标：平均每行驶 1 km 出现多少次误检。 | 比 precision 更贴近用户体验——precision 与场景中的目标数挂钩，而用户感知的是「多久闹一次」。 | 以为它和 precision 单调对应——同样的 precision，标志密集的城区与空旷高速的 FP/km 能差一个数量级。 |
| first-detection distance | 首次检出距离 | 同一块标志在车辆接近过程中第一次被**稳定**检出时的距离。 | 小目标改进最直观的业务指标：AP_S 涨 1 分不如「从 45 m 提前到 60 m 检出」有说服力。 | 以为单帧 AP 高就等于首检距离远——首检要求**连续数帧稳定**，单帧偶发的检出不算数，还会被下游的迟滞逻辑过滤掉。 |
| benefit-cost ranking | 收益-成本排序 | 把所有小目标方案按（预期 AP_S 增益 ÷ 延迟/显存/工程成本）排序。 | 算力预算是硬约束，必须排优先级：通常「提高输入分辨率 / 加 P2 / 换分配度量」在前，「切片推理 / 超分」在后。 | 以为要把论文里的方法全堆上——多数方法的**收益不可加**且相互强耦合（加了 P2 之后，NWD 的边际增益会明显缩水）。 |
| ablation plan | 消融计划 | 单变量、同训练预算、按尺寸分桶报告的实验矩阵。 | 小目标的改进量常常就在种子噪声的量级（±0.2–0.5 AP），不做多种子与分桶就无法判断真伪。 | 以为总 mAP 涨了就说明方法有效——必须单独看 AP_S 桶，也必须看 AP_L 有没有掉：**很多小目标方法是以牺牲大目标为代价换来的**。 |
| Scale Match | 尺度匹配 | TinyPerson 提出的做法：把预训练数据集的目标尺寸分布，变换到与目标数据集一致后再预训练。 | 直击「预训练数据里几乎没有 10 px 目标」这一分布鸿沟，是迁移学习在小目标上的关键修正。 | 以为多尺度训练就等于 Scale Match——多尺度训练是随机缩放整图，Scale Match 是**按目标尺寸分布做定向对齐**。 |
| stitching / Mosaic for small objects | 拼接类增强 | Mosaic（4 图拼接）、Stitcher 等把多张图缩小后拼在一起。 | 变相制造大量小目标，是数据侧最便宜的小目标增强（详见 C56）。 | 以为它无代价——拼接会改变目标尺寸分布，与真实部署分布不符，所以训练末期通常要关闭（close-mosaic）。 |
| copy-paste for rare small objects | 稀有小目标复制粘贴 | 把稀有类的小目标实例抠出来贴到新背景上。 | 长尾 + 小目标双重稀缺时最直接的补充手段，TSR 里价值极高（详见 C56）。 | 以为随便贴就行——尺度必须符合透视（贴在天上的 100 px 标志会教坏模型）、位置要合法、边缘要融合、光照要匹配，否则模型会学到贴图伪影这个捷径。 |
