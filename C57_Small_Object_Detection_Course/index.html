怎么用： 每个模块先读 HTML 讲解，再跑 notebook——后者用纯 numpy 把每个机制从零复现：IoU-位移敏感性曲线与临界位移的解析解、FPN 层级分配规则与各层负载统计、NWD（高斯建模 + Wasserstein 闭式解 + 归一化）与 IoU 的行为对比、完整的切片推理（切片生成 / 坐标还原 / 跨片 NMM 合并 / 重叠率下界推导）、以及一个针孔模型的像素尺寸计算器与「要在 X 米检出需要什么配置」的反解器。每个练习都有紧跟的 assert 自测判分。配套 术语词典 与 参考清单。本课的第一个主张是：「小目标难」不是一个原因，是五个互相独立的原因——信息量少、IoU 对位移极度敏感、正样本稀缺、下采样把它抹掉、标注噪声的相对量级大。它们各自有各自的解法，混在一起当成一个问题去治，就会出现「加了一堆 trick 但 AP_S 不动」的经典局面。所以本课的组织方式是：先把五个原因分别量化（模块 01），再按「架构 / 分配与损失 / 推理策略」三层分别给解法（模块 02–04），最后合成一套方案（模块 05）。本课的第二个主张，也是你必须带进面试的那句话：TSR 本质上就是小目标问题。这不是修辞——用针孔模型算一遍就知道：1920 宽、60° 水平 FOV 的前视相机上，一块 60 cm 的限速牌在 60 米外只有 17 个像素，100 米外只有 10 个像素。而「要在多远看见限速牌」是由制动距离与规控响应时间决定的整车安全需求，不是感知可以讨价还价的。于是「小目标检测」就成了这个岗位最核心、也最难绕过去的技术难点之一：它同时卡住了相机选型、输入分辨率、backbone stride、金字塔层级、标签分配、损失函数与部署算力预算——几乎每一个设计决策都要回到「最小的那块牌还剩几个像素」这个问题上。本课不需要 GPU，也不需要装 torch / mmdetection：我们复现的是这些方法的数学与账本（IoU 的几何、Wasserstein 的闭式解、金字塔的像素预算、切片的组合数、针孔的成像公式），而这恰恰是可迁移的那部分。每个模块末尾都有一个 🧪 真实工程胶囊，把当天学到的东西翻译成可原样复制到真实项目里的配置与代码片段。

MODULE 01

定量分析：小目标到底难在哪

8×8 的框对角位移 2 px，IoU 从 1.00 掉到 0.39，而 64×64 的框还有 0.88——同一个 0.5 阈值对不同尺度极不公平；临界位移 d ≈ 0.184w 意味着 8 px 目标只有 1.5 px 余量；stride 32 上 8 px 目标只占 0.25 个格子；有效感受野按 √n 增长而非 n；±2 px 标注误差对 8 px 框是 25% 相对噪声——AP_S 的天花板一部分是标注给的。

MODULE 02

架构层面的解法：分辨率、多尺度与上下文

FPN 的分配公式 k = ⌊4 + log₂(√(wh)/224)⌋ 会把小目标全部 clamp 到最低层；PAN 缩短定位信息的传播路径、BiFPN 用每条边一个标量做加权融合；加 P2 让检测头计算量 ×4（P2 一层就抵 P3+P4+P5 之和的 3 倍）；分辨率与算力是平方关系；可变形注意力受益于稀疏聚焦而非省算力；超分补的是纹理不是信息。

MODULE 03

分配与损失层面的解法

正样本为零时，任何 loss 加权都是乘以零——所以顺序必须是「先改分配，再换度量，最后调损失」；NWD 把框建成 2D 高斯并用 Wasserstein 闭式解度量，对尺度不敏感且在两框不相交时仍有梯度；RFLA 把高斯换成有效感受野，解决的是另一个环节；GIoU/DIoU/CIoU/SIoU/EIoU 的差异在小框上被放大——CIoU 的长宽比项在极小框上噪声很大。

MODULE 04

切片推理与高分辨率策略

SAHI 的本质是抬高目标的相对尺寸；重叠率的下界由最大目标尺寸给出，低于它必然有位置被切断；跨片合并要用 NMM/IoS 而非 NMS；1920×1080 切 512、重叠 20% 就是 15 片 ≈ 10× 计算量，33 ms 的车端预算放不下——所以量产解是两级级联，代价正比于 ROI 数而非切片数，而消失点与车道先验能把 ROI 压到图像的一小块。

TSR 小目标实战：从物理量到工程方案

px = f·S/Z 与 f = (W/2)/tan(FOV/2) 把「多远能看见」从经验变成算术：60 cm 的牌在 60 m 外是 17 px、100 m 外是 10 px；从制动距离反推检出距离再反推配置；广角+长焦分工是用光学而非算法解决小目标；方案按收益/成本排序（收益不可加）；评测必须按像素尺寸分桶，且首次检出距离比 AP_S 更能说服人。
