1为什么要"从零手写"

做 model evaluation 的研究科学家，每天要回答的问题是：这个数字可信吗？这个差异是真的吗？这个模型的失败模式是什么？ 这些问题没有一个能靠"调一个库函数"回答。你必须知道 AUC 是怎么算出来的、置信区间为什么是那个宽度、梯度为什么会爆炸、 k-means 为什么会收敛到局部最优。调库的人只能复述结论，手写过一遍的人能判断结论何时失效。

本课的纪律：核心算法一律 numpy 从零实现——OLS 的闭式解、logistic 回归的梯度、 决策树的 Gini 切分、PCA 的 SVD、k-means/EM 的迭代、Adam 的更新式、ROC/AUC/ECE 的定义，全部亲手写。 库（sklearn 之类）只在"对照答案"或"我们不教的预处理"时出现，绝不替你完成核心推导。

会用 model.fit(X, y) 不算会机器学习；能在白板上把 fit 里发生的每一步写出来、 并指出它在什么数据上会崩，才算。本课每章都逼你做到后者。

2为什么练习全部用真实数据集

很多教材用 np.random.normal 造数据演示算法。合成数据的问题是它太干净： 没有缺失值、没有量纲差异、没有类别不平衡、没有共线性、没有离群点，特征分布永远满足假设。 于是你学会的是"算法在理想世界里的样子"，一碰真实数据就懵。

本课所有练习都联网下载真实、公开、被引用过无数次的数据集： Palmer Penguins、UCI 乳腺癌、California Housing、UCI Wine、手写数字 optdigits、UCI Adult 收入、tiny-shakespeare 文本…… 你会亲眼看到：真实特征量纲差 1000 倍时梯度下降怎么走偏、类别不平衡时 accuracy 怎么骗人、 PCA 在真实图像上前几个主成分解释了多少方差。这些"脏"正是真实评测里每天要处理的东西。

4环境与依赖

全课 CPU 可跑，只依赖四个包，外加标准库：

numpy （数值核心）· pandas （只用于读 CSV）· matplotlib （画图）· requests / urllib （下载数据）

不需要 GPU、不需要 sklearn/torch、不需要 API key。安装：

pip install numpy pandas matplotlib requests jupyter
练习需要联网下载真实数据（首次运行）。下载会缓存到本地 ~/.ml_foundations_data/，第二次起离线可跑。 若你完全无网络，notebook 里每个数据集都给了"该数据集长什么样"的说明，可临时改读本地文件。

5全课复用的数据管线

每本 notebook 顶部都有同一个小工具：给一个 URL，下载、缓存、返回本地路径。它只有十几行，但体现了一个工程习惯—— 下载一次、缓存复用、可重复。这正是真实评测里管理数据集应有的样子。

直白讲

第一次运行时把数据从网上抓下来存到磁盘；以后每次直接读磁盘，不再联网。这样实验可重复、跑得快， 也不会因为某次网络抖动让结果不一样。

严谨讲

可重复性（reproducibility）要求数据来源固定。我们用稳定的 raw 链接（GitHub raw / UCI archive）作为 canonical source，本地缓存作为按文件名寻址的副本。 固定随机种子 + 固定数据 = 可复现的划分与指标。

6怎么用每本 notebook

每本 notebook 的结构都一样：

  1. worked sections：正文里可直接运行的示例，配 markdown 讲解——先看懂"标准答案怎么写"。
  2. ✏️ 练习：3–4 道，给 TODO 骨架 + assert 自测。assert 全过即过关。
  3. 📖 参考答案：文末。先自己做，卡住再看。
直接看参考答案再"对照"是自欺。assert 没过之前别翻到文末——卡 20 分钟学到的，比抄一遍多十倍。
学完本章，你应该能跑通环境、理解为什么用真实数据，并能解释下载缓存管线为什么对可复现性重要。 下一章开始动真格：手推 backprop。
