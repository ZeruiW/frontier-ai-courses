1面试推导题怎么答

research scientist 面试的白板题，考的从来不是你背没背过公式，而是你思维的条理和对失效边界的意识。同样写出正确答案，一个候选人是默写、另一个是现场分解并主动说出「这里要减最大值防溢出」「我会用数值梯度验证」——后者拿到 offer。面试官在白板前真正观察的，是你遇到一个没见过的变体时能不能从原理推，因为工作中遇到的永远是没见过的变体。一个稳健的回答结构是四步：

  1. 写清设定：维度、损失函数、什么对什么求导，把记号一次定死。含糊的记号是推导出错的头号来源。
  2. 分解：用链式法则把大导数拆成局部导数（模块 01 的「上游 × 局部」），一段一段算，别想一步到位。
  3. 给结论 + 直觉：写出最终梯度，并用一句话解释它的形状（「残差左乘输入」「预测减真值」），证明你理解而非记忆。
  4. 提验证与边界：主动说「我会用中心差分数值梯度校验」，并指出该结果何时失效（饱和、数值溢出、不可导点）。

同样重要的是怎么卡壳时不慌：推到一半忘了某步，就退回设定、写出已知的局部导数、用「形状必须和被求导量一致」（模块 01）反推该往哪拼——把思路说出声，面试官看的是过程不是一气呵成。坦诚说出「这一步我不太确定，但可以用数值梯度这样验证」，远胜于硬编一个看似自信的错答案。

最强的信号不是「我记得答案」，而是「我能现场推、能指出它何时失效、能说怎么验证」。本章每道 drill 都按这个标准训练你：先给结论与直觉，再要求你在 notebook 里把它实现并数值验证一遍——把「会背」变成「会做」。

2五个必背推导

这五个是 ML 面试的「乘法表」，必须能闭眼默写、并讲清每一项的物理含义与每个符号的维度。它们贯穿了本课前六章，彼此还互相呼应（注意残差结构在前三行反复出现）。

题目结论一句话直觉
OLS 闭式解$\hat w=(X^\top X)^{-1}X^\top y$正规方程：残差与列空间正交
Logistic + BCE 梯度$\nabla_w L=\tfrac1n X^\top(\sigma(Xw)-y)$残差左乘输入转置
Softmax + CE 梯度$\partial L/\partial z=p-y_{\text{onehot}}$预测概率减真值
bias-variance 分解$\text{err}=\text{bias}^2+\text{var}+\sigma^2$欠拟合 vs 过拟合 vs 噪声
L2 = 高斯先验 MAP$\arg\max_\theta \log p(x\mid\theta)-\tfrac\lambda2\|\theta\|^2$正则化 = 贝叶斯先验

OLS 的「残差与列空间正交」是最值得多说一句的几何直觉：最小二乘解就是把 $y$ 投影到 $X$ 的列空间上，残差 $y-X\hat w$ 与每一列都正交，于是 $X^\top(y-X\hat w)=0$，整理即得正规方程。理解了这个，你就明白为什么共线性（列几乎线性相关）会让 $X^\top X$ 接近奇异、解不稳定——投影的「基」快塌成一条线了。最后一行把模块 02 的 MAP 和模块 06 的正则化扣在一起：weight decay 不是启发式，是给权重一个零均值高斯先验后的最大后验估计。

每一行都准备好一个「追问的下一层」，面试官几乎一定会深挖。OLS 后面跟着「$X^\top X$ 不可逆怎么办」（答：用伪逆 / 岭回归加 $\lambda I$ 让它满秩，或用基于 SVD 的 lstsq）。logistic 后面跟着「为什么不用平方损失」（答：sigmoid + 平方损失非凸且梯度会饱和消失，BCE 给出凸目标和干净的 $p-y$ 梯度）。bias-variance 后面跟着「double descent 怎么回事」（模块 06）。把这些「第二跳」也准备好，你的回答就有了纵深，而不是答完一句就卡住。

3重点：softmax + 交叉熵梯度全推

这是最常考、最值得彻底搞懂的一个，因为它把链式法则、雅可比、和一个「惊人化简」全串在一起。softmax 把 logit 向量 $z\in\mathbb R^K$ 变成概率：$p_k=e^{z_k}/\sum_j e^{z_j}$。交叉熵 loss（真实类 $y$，one-hot）：$L=-\log p_y$。目标是推 $\partial L/\partial z_k$。

$$ \frac{\partial p_i}{\partial z_k}=p_i(\delta_{ik}-p_k),\qquad \frac{\partial L}{\partial z_k}=\sum_i \frac{\partial L}{\partial p_i}\frac{\partial p_i}{\partial z_k} = p_k-\mathbb 1[k=y]\;\;\Longrightarrow\;\;\nabla_z L=p-y_{\text{onehot}} $$

关键是中间那个 softmax 雅可比 $\partial p_i/\partial z_k=p_i(\delta_{ik}-p_k)$（分 $i{=}k$ 与 $i\ne k$ 两种情况，用商法则可得）。把它和 $\partial L/\partial p_i=-y_i/p_i$ 代进链式法则，所有 $p$ 在求和里神奇地约掉，只剩干净的 $p-y$。这个干净结果正是 softmax 和交叉熵被配对使用的根本原因——梯度等于「预测减真值」，不饱和、计算极简、与 logistic+BCE 的 $p-y$ 完全同构。

直白说

不管推导多绕，结论就一句：梯度 = 预测概率 − 真实标签。模型对真实类给的概率离 1 越远、对错误类给的越高，梯度就越大、推得越狠；一旦预测对了（$p\to y$）梯度趋零、停止更新。这就是「哪里错得多，往哪里改得多」。

严谨说

softmax 是 categorical 分布在指数族中的典范联系函数（canonical link），交叉熵是其负对数似然。指数族 + 典范联系的组合有一条定理：loss 对自然参数（这里是 logit $z$）的梯度恒为「期望充分统计量 − 观测充分统计量」，即 $p-y$。OLS（$\hat y-y$）、logistic（$\sigma-y$）只是同一定理在高斯、伯努利分布下的特例。

实现 softmax 必须先减去最大值再取指数：用 $p_k=e^{z_k-\max z}/\sum_j e^{z_j-\max z}$。数学上分子分母同乘 $e^{-\max z}$ 不改结果，但数值上避免了大 logit 让 $e^{z_k}$ 溢出成 inf（继而 inf/inf=nan）。这是面试和真实代码都必被抓的稳定性细节——能主动写出 z - z.max()，就是写过真代码的信号。配套地，交叉熵也应直接用 log-sum-exp 算 $\log p_y = z_y - \log\sum_j e^{z_j}$，而不是先 softmax 再取 log。

从单样本推广到一个 batch 也值得心里有数：设 $Z\in\mathbb R^{n\times K}$ 是 logits、$P=\text{softmax}(Z)$ 逐行做、$Y$ 是 one-hot 标签矩阵，则整批的 $\partial L/\partial Z=(P-Y)/n$，而对一层线性 $Z=XW$ 的参数梯度就是 $\nabla_W L=X^\top(P-Y)/n$——又回到了模块 01 的「残差左乘输入转置」。能在白板上从单样本一路写到 batched 矩阵形式，并保持维度自洽，是很强的信号。

面试加分项：被问到时，主动补一句「这个 $p-y$ 的结构和线性回归的 $\hat y-y$、logistic 的 $\sigma-y$ 是同一个故事——它们都属于指数族 + 对应的典范联系函数（canonical link），梯度天然是残差形式」，立刻把三个孤立结果统一成一个原理，展示你看到的是底层结构而非三道孤立题。notebook 第一节让你从零实现稳定 softmax、推完梯度再用数值梯度逐元素验证，并在真实 Wine 三分类上训出一个 softmax 回归。

4概率题与贝叶斯：基率谬误

概率题是另一类高频考点，核心几乎总是贝叶斯定理与基率（base rate）。$P(A\mid B)=\dfrac{P(B\mid A)P(A)}{P(B)}$ 人人会背，但能不能在一个有陷阱的实际情境里正确套用，才是区分点。最经典的就是「医学检测假阳性」题。

微例（手算医检后验）。某病患病率 $P(D)=1\%$。检测敏感度 $P(+\mid D)=99\%$（真病人 99% 检出），特异度 $P(-\mid \neg D)=95\%$（即假阳率 $P(+\mid\neg D)=5\%$）。问：一个人检测呈阳性，他真患病的概率 $P(D\mid +)$ 是多少？
套贝叶斯：$P(D\mid+)=\dfrac{P(+\mid D)P(D)}{P(+\mid D)P(D)+P(+\mid\neg D)P(\neg D)}=\dfrac{0.99\times0.01}{0.99\times0.01+0.05\times0.99}=\dfrac{0.0099}{0.0099+0.0495}\approx \mathbf{16.7\%}$。
反直觉吧？检测「99% 准」，阳性后真患病却只有约六分之一。原因是基率太低：健康人是病人的 99 倍，即使每人只有 5% 假阳，绝对数量（约 4950 个假阳 vs 990 个真阳，按十万人算）仍远超真阳。这就是基率谬误——忽略先验、只盯似然。

这道题的工程意义极大：在罕见事件（欺诈、安全告警、稀有疾病）上，一个看起来很准的分类器会产出海量假阳。这正是模块 06 「不平衡数据要看 PR 而非 ROC」的概率版本——precision 恰好就是 $P(D\mid+)$。面试里能把这道题和 precision、和不平衡评测连起来讲，说明你不是孤立记公式，而是有一张连通的知识图。一个快速心算技巧：当患病率极低、特异度不够高时，后验约等于 $\dfrac{\text{患病率}\times\text{敏感度}}{\text{假阳率}}$ 的量级——先验主导一切。

这类题常见的几个变体也要会接：「怎么提高阳性预测值」——要么提高检测特异度（降假阳率，分母变小），要么提高检测前的先验（只在高危人群中筛，相当于人为抬高基率），这正是「两步筛查」的统计原理；「连续两次独立检测都阳性呢」——把第一次的后验当作第二次的先验再套一遍贝叶斯，后验会显著跳升（约 16.7% → 约 80%），这就是为什么复检如此有效。能现场做这个「后验当先验」的迭代，是对贝叶斯更新真正理解的标志。蒙提霍尔、三门问题等也是同一套先验/似然机制的伪装，遇到先别急着用直觉，老老实实写出贝叶斯定理。

5k-fold 交叉验证与嵌套 CV

数据少时单次 train/val 划分方差大、据此选模型不可靠。k-fold CV 把数据分 $k$ 折，轮流用 1 折验证、其余训练，平均 $k$ 个验证分，用它选超参（如 L2 强度）比单次划分稳得多。

5-fold: [val][ train ] 折1 [train][val][train ] 折2 ... [ train ][val ] 折5 报告 = 5 个验证分的均值 ± 标准差

但只用一层 CV 选超参、再用同一套数据报成绩，会高估性能——你已经用 CV 分数挑过模型了。正解是嵌套 CV：外层 CV 负责估计泛化，在它的每个训练块内部再跑一层 CV 选超参，两层数据严格隔离。这样报出的才是「先选模型、再在没碰过的数据上评估」的诚实流程。代价是计算量翻几倍（外层 $k_1$ × 内层 $k_2$ × 超参候选数次训练），所以实践中常在数据较少、又必须诚实报告泛化时才上嵌套 CV；数据充裕时一个独立 held-out 测试集就够了。

$k$ 的选择是一个偏差-方差权衡：留一法（$k=n$）每次训练数据最多、偏差最小，但 $n$ 个模型高度相关、平均方差降不下来且极贵；$k=5/10$ 是公认甜点。分类任务务必用分层 k-fold 保持每折类别比例，不平衡时尤其关键。时间序列则绝不能随机分折（会用未来预测过去），要用前向滚动的时间切分。能在面试里区分「该用普通 CV / 分层 CV / 时间序列 CV」，说明你想过数据的真实结构，而不是机械套模板。

测试集只能碰一次。用 CV（或嵌套 CV）在训练数据内部完成一切调参与模型选择，定稿后才把测试集拿出来跑一次、报最终成绩，且不再据此改动任何东西。反复用测试集调参 = 把测试集变成训练集，报出的泛化是假的——这是评测里最致命、面试官最爱追问的错误。被问「你怎么保证没有数据泄漏」，答得出「预处理只在训练折拟合 + 嵌套 CV + 测试集单次」就过关。

6bootstrap 置信区间

一个准确率 0.92 该配多宽的误差棒？孤零零一个点估计在评测里是不负责任的。bootstrap 给出一个几乎不需要分布假设的答案：从测试集有放回重采样 $B$ 次（每次抽出与原集等大的样本），每次重算指标，得到指标的经验分布，取 2.5% 与 97.5% 分位数即 95% 置信区间。

$$ \text{重采样 }B\text{ 次}\;\to\;\{\hat\theta^{*}_1,\dots,\hat\theta^{*}_B\}\;\to\;\text{CI}_{95\%}=[\,q_{2.5\%},\,q_{97.5\%}\,] $$

它的魔力在于：用重采样模拟「如果我重新收集一批测试数据，指标会怎么波动」，从而把单点变成带不确定性的区间。这对 accuracy、AUC、F1 这类没有简单解析方差公式的指标尤其有用。要比较两个模型，更该用配对 bootstrap（每次重采样的是同一批样本上两模型的差值），它消去了样本难度的共同波动、功效更高——这点和模块 02 的配对检验是同一个道理。notebook 里你会给真实 Wine 数据上的准确率和宏 AUC 算 bootstrap CI。

一个能立刻拉开差距的数量级直觉：二项比例的标准误约 $\sqrt{p(1-p)/n}$。在 $n=200$ 个测试样本上，一个 0.9 的准确率的标准误约 $\sqrt{0.09/200}\approx 0.021$，95% 区间约 $\pm 0.04$——也就是说 200 题上「71% vs 70%」的差距完全淹没在噪声里，根本不显著。这正是模块 02 反复强调的：别被一次 leaderboard 名次忽悠，小测试集上的细微差距大多是抽样噪声。bootstrap 把这个抽象警告变成了你能算出来、画出来的具体区间，面试里能顺手报出这个量级，说明你对「样本量 → 误差棒宽度」有真实的感觉。

bootstrap 不是万能的：它假设测试集本身能代表目标分布（垃圾进垃圾出），对极小样本或重尾分布的极端分位数估计也不稳。它给的是「采样不确定性」，不覆盖分布偏移、标注错误等系统性误差。报区间时要说清它量的是哪种不确定性。

7ML/eval system design 框架

「设计一个评估 X 的系统」这类开放题没有标准答案，考的是你有没有结构化的思考骨架。下面这类题最常见的失败是「跳过定义直接谈方案」——被问「设计一个评估代码生成模型的系统」，弱回答立刻谈跑什么 benchmark；强回答先花一分钟把问题钉死：评功能正确性还是代码风格？成功是单测通过率还是人工偏好？离线还是线上？目标与口径定清，后面所有决定才有依据。下面这套五步框架几乎能套任何评测 system design 题，它正是一个真实评测科学家的工作流：

  1. 明确目标与口径：评什么能力？成功怎么定义？用什么指标？（别一上来就谈模型——先把问题定义清楚，这一步最能区分高低。）
  2. 数据：从哪来、怎么标注、有没有污染/泄漏、分布覆盖够不够、样本量够不够（功效分析）。
  3. baseline：majority、随机、简单模型——没有 baseline 的分数没有意义（模块 06 的 99% 反例）。
  4. 指标与误差棒：结合不平衡/校准/排序选指标、报 bootstrap 置信区间、做显著性检验（模块 02、06）。
  5. 失败模式与监控：会怎么坏（Goodhart、过拟合 benchmark、reward hacking、分布偏移）、上线后怎么持续监控。
这个框架直接通向 C3（评测科学）和 C5（安全评估）。面试时能把「目标口径 → 数据污染/泄漏 → baseline → 指标 + 误差棒 + 显著性 → 失败模式/监控」五步从容讲完，并在每一步主动点出对应的陷阱，你就已经像一个真正的评测研究科学家在思考了——而这正是这门课要把你训练成的样子。

8行为与权衡类问题

除了推导与设计，面试还有一类「讲清权衡」的问题，没有唯一答案，考的是判断力与表达。这类题的答法是：先给一句话立场，再用本课的原理支撑，最后点出边界条件。几个高频例子：

  • 「模型欠拟合还是过拟合，怎么判断、怎么治？」 看 train/test 误差的差（模块 06）：都高且接近 → 欠拟合，加复杂度/减正则；间隙大 → 过拟合，加正则/早停/数据。
  • 「表格数据上你会先试什么？」 梯度提升树（XGBoost/LightGBM）做强 baseline——它在中小表格数据上常稳压深度网络（模块 03），且省去大量调参；先打过这个 baseline 再谈神经网络。
  • 「accuracy 90% 的模型能上线吗？」 反问基率与代价：99:1 数据上 90% 还不如 majority；要看 precision/recall、看校准、看子群表现，再结合错误代价决定（模块 06）。
  • 「L1 还是 L2？」 要稀疏/特征选择用 L1（拉普拉斯先验）；只想平滑收缩/抗共线性用 L2（高斯先验）；两者都要用 elastic net（模块 02、06）。
  • 「你怎么处理类别不平衡？」 先别急着重采样——先确认指标对不对（改看 PR/recall 而非 accuracy）、阈值按代价调；真要动数据，再考虑类权重、过采样（SMOTE）或欠采样，并强调这些只在训练集上做、绝不碰验证/测试集的分布。
这类题最大的坑是给绝对答案（「深度学习总是更好」「F1 永远比 accuracy 好」）。成熟的回答永远带「取决于……」并说清取决于什么——数据规模、不平衡程度、错误代价、可解释性需求。面试官想确认的是你知道没有银弹，且能把权衡讲到点子上。

9研究前沿与延伸

本课把经典 ML 数学打成了地基，但研究前沿把同样的工具搬到了更大的舞台。下面几条是从本章直接延伸出去的方向，也是后续课程的入口：

  • 评测科学（C3）：本章的 CV、bootstrap、显著性检验、system design 框架，在 LLM 评测里会全面展开——如何给 benchmark 分数配误差棒、如何做配对比较、如何抗数据污染与 Goodhart。这是本课最直接的下游。
  • 不确定性与 LLM-judge：softmax 概率的校准（模块 06）在生成式模型里变成「语义不确定性」「自洽性」等更难的问题，直接关系到能否信任模型自评、能否用模型当裁判。
  • 可解释性（C6）：本章的梯度与 logistic 回归，是 linear probing、attribution、influence functions 的数学内核——读懂模型内部表示，从这里起步。
  • RLHF 与偏好学习：奖励模型本质就是本课的 logistic 回归（在偏好对上做二分类），DPO 等方法把它进一步化简——你会发现前沿对齐技术的内核，仍是这门课讲过的似然、梯度与正则。
  • 面试之外：这些「必背推导」真正的价值不是应付白板，而是让你在读论文、复现实验、诊断训练时有第一性原理可依——能从公式判断一个结果合不合理、能在别人的代码出 bug 时知道该往哪看，而不是只会跑别人的代码。
Efron & Tibshirani 1993 An Introduction to the Bootstrap（bootstrap 奠基）； Wasserman All of Statistics（假设检验与 CV 的统计基础）；本章的 CV/bootstrap/system design 在 C3 LLM_Evals 课会全面展开到 LLM 评测场景。详见 论文清单。
学完本章，你应该能：现场推导 softmax-CE 梯度并数值验证、手算医检贝叶斯后验并解释基率谬误、用（嵌套）k-fold CV 正确选超参、给任何指标算 bootstrap CI、用五步框架回答开放的 eval system design 题、并在权衡类问题上给出带边界条件的成熟回答。恭喜，你完成了 C7 ML 基础课——带着这套第一性原理，去 C1 LLM 内核与 C3 评测科学吧。
