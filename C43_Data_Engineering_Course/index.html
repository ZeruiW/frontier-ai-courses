6 模块 去重 · 流式加载 · 分词吞吐 · 质量过滤 · 溯源 numpy/pandas/标准库 + 对拍参考 复杂度账 + 吞吐账体现 PB 级 CPU only · 无需 GPU/集群
怎么用： 每个模块先读 HTML 讲解 建立「规模带来质变」的工程直觉，再跑 notebook 亲手用 numpy/pandas/标准库 在小规模真实数据上复现工程机制，并为每个机制算一笔 复杂度账与吞吐账——把「PB 级会怎样」从纸面推到可验证的数字。每个练习都有紧跟的 assert 自测判分。配套 术语词典 与 论文清单。本课的立场是：C21（大规模预训练）讲数据的「科学」——该保留什么、该怎么配比、合成数据怎么造；本课补数据的「基础设施手艺」——当语料是 PB 级、token 是万亿级时，去重、加载、分词、过滤、溯源这五件事各自暴露出的工程与规模问题怎么解。本环境无 PB 级集群：我们用小规模真实模拟 + 复杂度/吞吐账体现规模问题——比如用几千条文本跑通 MinHash+LSH 去重管线、与暴力 Jaccard 对拍，再用复杂度公式推演这条管线在 1e12 文档上为什么 O(n²) 不可行、分桶后为什么可行；用一个 shuffle 缓冲区模拟器量化「缓冲多大才接近全局打乱」。学完你能读懂 FineWeb/Dolma/WebDataset/Mosaic StreamingDataset 的设计取舍，并能为一条真实数据管线做容量/吞吐/正确性的工程规划。
