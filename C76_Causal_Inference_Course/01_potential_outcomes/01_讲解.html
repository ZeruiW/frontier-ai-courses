1潜在结果：把「效应」写成一个能被讨论的对象

日常语言里的「这个改动带来了多少提升」是含混的：提升相对于什么？潜在结果框架（potential outcomes framework，又称 Neyman–Rubin 因果模型）先把这个「什么」固定下来。

对每个个体 $i$ 和每个可能的处理值 $t$，假设存在一个确定的结果 $Y_i(t)$：个体 $i$ 若接受处理 $t$ 会取到的结果。这里有两个不平凡的假设被悄悄用掉了：

  1. $Y_i(t)$ 只依赖 $i$ 自己的处理，不依赖别人的处理。这是 SUTVA（Stable Unit Treatment Value Assumption）的第一半，也叫「无干扰」（no interference）。社交产品、拍卖市场、库存共享全都违反它——模块 05 会量出违反的代价。
  2. 处理 $t$ 只有一个版本。「上线新推荐算法」若在不同机房、不同客户端版本上实际是不同的东西，$Y_i(1)$ 就不是一个函数值而是一族。这是 SUTVA 的第二半，也叫一致性（consistency）。
\[\tau_i = Y_i(1) - Y_i(0), \qquad Y_i^{\text{obs}} = T_i Y_i(1) + (1-T_i) Y_i(0)\]
第二式说明每个个体只有一个潜在结果可见，另一个永远缺失。所以 $\tau_i$ 不是「难估」，是不可观测。因果推断能做的只是估计 $\tau_i$ 的某种平均——而「哪一种平均」是一个必须显式做出的建模选择，不是技术细节。

根本问题：一半的数据永远缺失

2四个目标量：它们数值上不相等

记号定义回答的问题在合成人群上的值
ATE$E[\tau_i]$对全体人群平均，效应是多少$1.000105$
ATT$E[\tau_i \mid T_i{=}1]$对已经被处理的人，效应是多少$1.375748$
ATC$E[\tau_i \mid T_i{=}0]$如果把处理推给还没有的人，效应是多少$0.626013$
CATE$E[\tau_i \mid X_i{=}x]$对特征为 $x$ 的人，效应是多少$1 - 0.75x$（构造已知）

三个常数量由处理率 $\pi = P(T{=}1)$ 线性联系：$\text{ATE} = \pi\,\text{ATT} + (1-\pi)\,\text{ATC}$，这只是全期望公式。notebook 里把它验证到浮点精度，并检查 $\pi \to 1$ 时退化为 ATT。

直白说

在这个人群上 ATT 是 ATC 的 2.20 倍。也就是说，「已经用上这个功能的人从它得到的收益」是「还没用上的人会得到的收益」的两倍多。如果一份周报写着「该功能带来 1.38 的提升」而决策是「推给剩下的人」，那么这份周报用错了目标量，真实预期是 0.63。

严谨说

当 $\tau_i$ 与 $T_i$ 相关时 $\text{ATT} \neq \text{ATC}$。此处 $\tau_i = 1 - 0.75 x_i$ 而 $P(T_i{=}1) = \sigma(1.2 x_i)$ 均随 $x_i$ 单调，但方向相反，故 $\text{Cov}(\tau_i, T_i) < 0$，由 $\text{ATT} - \text{ATC} = \text{Cov}(\tau, T)/[\pi(1-\pi)]$ 得二者之差为正。

本课后面每个估计量都对应一个特定目标量：IPW 默认估 ATE，倾向得分匹配常估 ATT，工具变量估的是 LATE（局部平均效应，只对「被工具推动的人」），断点回归估的是断点处的 CATE。把它们放在一张表里比较大小，通常是在比较四个不同的量。

先选目标量，再选估计量

3CATE：从「效应有多大」到「该给谁」

ATE 是一个数，CATE 是一个函数。产品决策通常需要后者：如果 $\tau_i$ 对一部分人为负，那么全量投放的 ATE 正与存在受损人群可以同时为真。

在 notebook 的人群里，ATE $=+0.9985$，而 $9.1\%$ 的个体效应为负——ATE 完全看不出这一点。这是「平均」二字的代价。

定向投放的收益由异质性强度决定，不由 ATE 决定

设 $\tau_i = 1 - h x_i$，$h$ 越大异质性越强。若按 CATE 的估计值决定是否投放，而估计带噪声 $\text{sd}$，notebook 测出的收益（相对全量投放）是：

$h$$\text{sd}(\tau)$负效应占比$\text{sd}{=}0.25$$\text{sd}{=}0.5$$\text{sd}{=}1.0$$\text{sd}{=}2.0$
$0.25$$0.250$$0.0\%$$0.999$$0.972$$0.850$$0.702$
$0.75$$0.750$$9.1\%$$1.024$$1.001$$0.918$$0.775$
$1.50$$1.500$$25.3\%$$1.221$$1.202$$1.138$$0.988$
$3.00$$3.001$$37.0\%$$1.765$$1.753$$1.710$$1.574$

三处值得注意。第一，$h{=}0.25$（几乎无异质性）时定向在每一个噪声水平下都是净亏，最差降到 $0.702$ 倍——因为此时没有可利用的信号，噪声只制造错误的排除。第二，ATE 在这五行里几乎不变（$0.988$–$0.999$），所以光看 ATE 无法判断定向有没有价值。第三，盈亏平衡的噪声水平满足 $\text{sd}^{*} \approx 0.8\text{--}1.0 \cdot \text{sd}(\tau)^2/\text{ATE}$——对异质性是二次的，所以异质性翻倍能容忍的 CATE 噪声涨约 $4$ 倍而不是 $2$ 倍。

「按模型分数投放」在工程上很自然，但模型分数通常是 $\hat{E}[Y \mid X]$（预测），而决策需要 $\hat{E}[\tau \mid X]$（效应）。这两者可以完全相反：最可能转化的人往往是不需要干预就会转化的人，对他们的效应恰恰最小。上表的 $h$ 越大，这个错误的代价越大。

一个常见的因果误用

4识别 vs 估计：两类完全不同的失败

因果推断的两个阶段常被混为一谈，但它们的失败方式完全不同：

目标量 识别（identification） 估计（estimation） E[tau] --> 能否写成可观测分布的函数 --> 给定有限样本，怎么算 "假设" 决定成败 "方差/正则/收敛" 决定成败 | | 失败: 偏差不随 n 消失 失败: 方差大，但 n 增大就好 补救: 换设计（模块 04） 补救: 加样本/换估计量（模块 03）

在可忽略性（ignorability，又称条件独立、无未观测混杂）$\{Y(0), Y(1)\} \perp T \mid X$ 之下，ATE 可识别：

\[E[\tau] = E_X\big[\,E[Y \mid T{=}1, X] - E[Y \mid T{=}0, X]\,\big]\]

这个公式右边全是可观测量，所以问题降级成了估计问题。notebook 用最朴素的估计量——分层（subclassification）——验证它：把 $X$ 按分位数切成 $K$ 层，层内做差，再按层大小加权。

层数 $K$分层估计偏差消除的偏差比例
$1$（=朴素差）$+1.582183$$+0.582281$$0\%$
$2$$+1.214277$$+0.214375$$63.2\%$
$5$$+1.060040$$+0.060138$$\mathbf{89.7\%}$
$10$$+1.021652$$+0.021750$$96.3\%$
$50$$+0.999955$$+5.3\times10^{-5}$$\approx 100\%$
$200$$+0.996530$$-0.003372$反弹（层内样本不足）

$K{=}5$ 消除 $89.7\%$ 的偏差，与 Cochran 1968 年那条「五层足以消除约 $90\%$ 偏差」的经典结论一致。而 $K{=}200$ 的反弹说明分层也有偏差-方差权衡：层数太多则层内样本不足，某些层甚至只有单臂。

上表的实现遇到「层内只有单臂」时会跳过该层——这是标准做法，但它意味着估计目标不再是全人群 ATE，而是「两臂齐全的层上的 ATE」。notebook 在 $n{=}4000$ 上量出了丢弃比例：$K{=}50$ 丢 $0\%$、$K{=}200$ 丢 $2.5\%$、$K{=}400$ 丢 $8.3\%$、$K{=}800$ 丢 $22.2\%$。更值得注意的是 $K{=}400$ 的 RMSE（$0.01707$）反而低于 $K{=}100$（$0.01851$），而 RMSE 选出的最优 $K^{*}{=}200$ 本身已经在丢样本了——所以 RMSE 不是选层数的正确判据：它相对的是一个已经被悄悄换掉的目标。这是本课反复出现的模式：失效不报错，只换掉你在估的东西。

缺一臂的层被静默丢掉，于是估计目标被换掉了

工程上遇到「结论不稳」时的第一反应通常是加数据、加特征、换模型。这三招全都只对估计问题有效。如果问题在识别，加数据会让错误的结论看起来更可信，而加特征甚至可能制造新的偏差——模块 02 会给出偏差从 $0$ 跳到 $2.59$ 的例子。

6同一个调整公式的三种实现

识别公式 $E[\tau] = E_X[E[Y\mid T{=}1,X] - E[Y\mid T{=}0,X]]$ 只说了「要什么」，没说「怎么算」。工程上有三条常见路线，它们估的是同一个量，但在不同的地方会失效：

路线做法最容易失效的地方本课的位置
分层 / 匹配把 $X$ 相近的人配成组，组内做差$X$ 维度高时组内配不上；缺一臂的层被静默丢弃本模块
加权按 $1/e(X)$ 或 $1/(1-e(X))$ 重加权重叠退化时方差爆炸（ESS $4000 \to 616$）模块 03
回归 / 建模拟合 $E[Y\mid T,X]$ 再取预测差模型误配；而模型越强越危险（修正项被吃掉）模块 03

三者的差别不在「准不准」，而在把假设放在哪里：分层几乎不假设函数形式，代价是维度；加权假设 $e(X)$ 估对，代价是方差；回归假设 $E[Y\mid T,X]$ 的形式，代价是误配。

为什么本模块先讲分层

因为它是唯一能把失效直接看见的实现。notebook 里 $K{=}400$ 时有 $8.3\%$ 的样本落在缺一臂的层里、$K{=}800$ 时是 $22.2\%$——这些样本被跳过，于是估计目标从「全人群 ATE」变成「两臂齐全的层上的 ATE」。

加权和回归会把同一件事藏起来：加权把它变成一个巨大的权重，回归把它变成一次外推。两者都不会告诉你有多少样本实际上没有可比对象，而分层会——它把那些人明确地扔掉了。

无论最终用哪种实现，都先跑一次粗分层（$K{=}10$ 左右）并报告缺一臂的层占多少样本。这个数是重叠问题的下限估计，而且不依赖任何模型。如果它已经很大，那么加权与回归给出的漂亮数字都是外推。

一条可以直接用的诊断

7SUTVA 的一致性部分：工程上的具体形态

第 1 节把 SUTVA 拆成两半：无干扰（模块 05 处理）和一致性——「处理只有一个版本」。后者在论文里几乎不被讨论，因为在临床试验里它基本自动成立；而在线上系统里它经常不成立。

场景为什么违反一致性后果
同一次「上线」打包了多个变更$T{=}1$ 实际是若干不同处理的混合估到的是混合效应；单独回滚任一项都无法预测
不同客户端版本上行为不同$Y_i(1)$ 依赖于 $i$ 的版本效应随版本分布漂移，看起来像「效应在衰减」
功能有降级路径（超时回退旧逻辑）处理组里一部分人实际收到的是对照这是不依从（non-compliance），估到的是 ITT
模型每天重训处理在时间上不是同一个东西早期与晚期的效应不可加；分时段看会互相矛盾

ITT 与 ATT 的区别

第三行值得单独说。当处理组里有一部分人实际没收到处理时，按指派比较得到的是 ITT（intention-to-treat，意图处理效应），而不是 ATT。两者的关系是

\[\text{ITT} = c \cdot \text{ATT}_{\text{依从者}}\]

其中 $c$ 是依从率（在只有单向不依从、且未依从者效应为零时）。所以 ITT 总是被依从率稀释。工程上常见的错误不是算错，而是换算：看到 ITT $=0.5$、依从率 $=50\%$，就报告「真效应是 $1.0$」——这个换算要求「未依从者的效应恰为零」，而那是一个额外的假设，不是算术。

答案不在统计层：让「上线」在所有单元上是同一件事。具体做法是把处理定义写进实验配置（而不是写在文档里）：一次实验只改一个开关、降级路径要么关掉要么记录、重训的模型要冻结到实验结束。这些是工程约束，而它们决定了统计结果有没有意义——这也是本课反复出现的模式：识别层的问题必须在识别层解决。

一致性该怎么保证

8CATE 怎么估：三种做法与它们各自的偏向

第 3 节把 CATE 的用途说清了（定向投放），但没说怎么估。这里补上，因为三种常见做法的偏向方式不同，而选错会让第 3 节那张表里的噪声 $\text{sd}$ 变大好几倍。

做法怎么做偏向什么时候合适
S-learner（单模型）把 $T$ 当一个特征，拟合 $\hat{f}(X,T)$，取 $\hat{f}(X,1)-\hat{f}(X,0)$偏向零——正则化会把 $T$ 这一维压掉，因为它只解释一小部分方差效应相对结果的量级不太小
T-learner（双模型）两臂各拟合一个 $\hat{m}_t$，取差放大两个模型各自的偏差；小臂上的误差直接进入差两臂样本量相当、都足够大
X-learner / DR-learner先估 $\hat{m}_t$，再对伪结果（AIPW 型的单点得分）做回归继承模块 03 的双重稳健性；但需要 $\hat{e}$两臂样本量不平衡，或效应量级很小

第一行的偏向值得注意，因为它系统性地低估异质性：S-learner 的正则化把 $T$ 与 $X$ 的交互项压掉，于是估出来的 CATE 曲线比真实的平。而第 3 节的表说明，定向的收益完全取决于 $\text{sd}(\tau)$——所以一个把曲线压平的估计器会同时让「定向看起来没价值」和「实际定向效果差」，两个错误方向一致，很难被发现。

$\tau_i$ 不可观测，所以没有直接的「CATE 的 MSE」可算。常用替代是提升曲线（uplift curve）：按 $\hat{\tau}$ 降序取前 $k\%$ 的人，在随机化的留出集上算他们的实际处理效应。注意这个评估必须用留出的随机化数据——用训练数据评估会把过拟合读成异质性，而那正是第 3 节表里「噪声 $\text{sd}$」变大的主要来源。

评估 CATE 模型不能用预测误差

最后一点连回本模块第 5 节：以上三种做法全都建立在可忽略性之上。如果存在未观测混杂，CATE 的估计不仅偏，而且偏的方向随 $X$ 变化——于是「按 $\hat{\tau}$ 定向」会系统性地把资源投给混杂最强的那部分人，而不是效应最大的那部分人。

9把假设写在纸上

本模块的四个假设，以及每个假设在什么场景下最可能被违反：

假设形式最常见的违反场景本课的处理位置
无干扰（SUTVA-1）$Y_i(t)$ 不依赖 $T_j, j\neq i$社交图、共享库存、竞价市场、双边平台模块 05
一致性（SUTVA-2）处理只有一个版本灰度里不同客户端版本行为不同；「上线」实际是多个变更的打包模块 05（口径）
可忽略性$\{Y(0),Y(1)\} \perp T \mid X$有未观测的动机/资质变量（自选择）模块 02（图）/ 04（换设计）
正性 / 重叠$0 < P(T{=}1\mid X) < 1$规则准入（分数超过阈值必然获批）、历史策略是确定性的模块 03

这张表是本课的骨架。每个后续模块要么放松一个假设，要么量化违反它的代价。注意四个假设里只有正性是可以从数据里检查的——其余三个都必须靠对业务机制的了解来论证。

潜在结果框架本身不解决任何问题，它的价值在于把「这个数字对不对」这个无法讨论的问题，换成了「这四个假设里哪一个不成立」这个可以讨论、可以查证、可以设计实验去检验的问题。
