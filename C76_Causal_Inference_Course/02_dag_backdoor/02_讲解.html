控制得越多越好多控制总不会更坏对撞变量 $C$（处理与结果的共同后代）偏差从 $0$ 跳到 $\mathbf{2.59}$

正确的判据来自图：把变量之间的因果假设画成有向无环图（DAG），然后用后门准则（back-door criterion）机械地判断哪些调整集合法。本模块把这个判据实现成代码，并在一个小 DAG 上枚举全部 $8$ 个子集——结果只有 $1$ 个合法。

DAG 的价值不在于「让因果关系更直观」，而在于它把「该控制什么」变成一个可判定的问题。$8$ 个候选子集里恰好 $1$ 个合法，这个比例说明靠直觉挑选控制变量的成功率接近随机猜测。

2三种基本结构与 d-分离

路径上的信息能否流通，只取决于三种局部结构。记 $\to$ 为因果方向，$\perp$ 为独立，$Z$ 为被条件的变量集：

① 链（chain） A -> B -> C 不控制 B: A 与 C 相关 控制 B: A 与 C 独立 <- 阻断 ② 叉（fork） A <- B -> C 不控制 B: A 与 C 相关（混杂！） 控制 B: A 与 C 独立 <- 阻断 ③ 对撞（collider） A -> B <- C 不控制 B: A 与 C 独立 控制 B: A 与 C **相关** <- 打开！

前两种是「控制它能阻断」，第三种反过来：$B$ 是对撞时，不控制它路径本来是断的，控制它反而把路径打开。而且这个效应对 $B$ 的后代同样成立——控制对撞的任何后代都会部分打开路径。

对撞偏差：从无关到 $-0.917$

notebook 里取两个独立变量 $X, Y \sim N(0,1)$ 与 $Z = X + Y + \varepsilon$，$\varepsilon \sim N(0, 0.3^2)$。$X$ 与 $Y$ 之间不存在任何因果关系，测出的边际相关是 $+0.00062$。而回归 $Y \sim X + Z$ 给出 $X$ 的系数 $-0.91698$：

做法$X$ 的系数解读
$Y \sim X$$+0.00062$正确：$X$ 与 $Y$ 无关
$Y \sim X + Z$$\mathbf{-0.91698}$控制对撞 $Z$ 后凭空出现强负关联
限定在 $\vert Z\vert < 0.2$ 的 $66{,}106$ 个样本内$\text{corr} = -0.90527$分层看同样出现——所以这不是回归的锅
闭式解 $-1/(1+\sigma^2)$$-0.91743$与回归系数差 $4.5\times10^{-4}$

直白说

直觉：$Z$ 大意味着「$X$ 大或 $Y$ 大」。固定住 $Z$ 之后，知道 $X$ 大就意味着 $Y$ 必须小（否则 $Z$ 会更大）。于是「已知 $Z$」这个条件把两个无关变量绑在了一起。现实中的例子：只在被录取的学生里看「成绩」与「课外活动」的关系，会看到虚假的负相关，因为录取本身是两者的对撞。

严谨说

在联合正态下 $\text{Cov}(X, Y \mid Z) = \text{Cov}(X,Y) - \text{Cov}(X,Z)\text{Cov}(Z,Y)/\text{Var}(Z)$。取 $Z = X + Y + \varepsilon$，$\varepsilon \sim N(0,\sigma^2)$，则 $\text{Cov}(X,Z) = \text{Cov}(Y,Z) = 1$，$\text{Var}(Z) = 2+\sigma^2$，故 $\text{Cov}(X,Y\mid Z) = -1/(2+\sigma^2)$。$\sigma = 0.3$ 时为 $-0.4785$，条件相关为 $-1/(1+\sigma^2) = -0.91743$，与实测的回归系数 $-0.91698$ 差 $4.5\times10^{-4}$。所以对撞偏差的强度不是「可能有多大」，而是可以事先算出来：$\sigma = 0.1$ 给 $-0.9901$，$\sigma = 1.0$ 给 $-0.5000$，$\sigma = 3.0$ 给 $-0.1000$——$Z$ 越接近 $X$ 与 $Y$ 的确定性函数，控制它的破坏越大。

3后门准则

给定 DAG、处理 $T$、结果 $Y$，集合 $Z$ 满足后门准则当且仅当：

  1. $Z$ 中不含 $T$ 的任何后代；
  2. $Z$ 阻断了 $T$ 与 $Y$ 之间所有后门路径（即从 $T$ 出发第一步是指向 $T$ 的箭头的路径）。

满足后门准则时，$E[\tau]$ 由调整公式识别：

\[E[Y(t)] = \sum_{z} E[Y \mid T{=}t, Z{=}z]\, P(Z{=}z)\]

在一个小 DAG 上枚举全部子集

X (混杂: 影响 T 也影响 Y) / \ v v T ---------> Y 直接效应 2.0 \ ^ / \ / / M / M 是中介: T -> M -> Y (贡献 0.9*1.0 = 0.9) / T ------>C<------ Y C 是对撞: T 和 Y 的共同后代 总效应 = 2.0 (直接) + 0.9 (经 M) = 2.9 可观测的候选调整变量: X, M, C

notebook 实现了 Bayes-Ball 算法与后门准则，对 $\{X, M, C\}$ 的全部 $2^3 = 8$ 个子集逐一判定，并与回归系数对照：

子集后门准则回归系数与总效应 $2.9$ 之差

$\{X\}$✓ 合法$\mathbf{+2.90168}$$+0.002$
$\{M\}$✗ 不合法$+2.73210$$-0.168$
$\{C\}$✗ 不合法$+0.06546$$-2.835$
$\{X, M\}$✗ 不合法$+2.00079$$-0.899$
$\{X, C\}$✗ 不合法$+0.30406$$\mathbf{-2.596}$
$\{M, C\}$✗ 不合法$+0.11323$$-2.787$
$\{X, M, C\}$✗ 不合法$+0.50375$$-2.396$

三处值得停下来看。第一，只有 $\{X\}$ 合法，而它恰好是唯一无偏的（$+0.00168$）——准则与数值完全一致。第二，$\{X\} \to \{X,C\}$ 只多控制了一个变量，偏差从 $0.002$ 变成 $-2.596$。第三，$\{X,M\}$ 给出 $+2.00079$，看起来像个「不太准」的估计，实际上它精确地无偏地估出了直接效应 $2.0$——它答对了另一个问题。

$\{X,M\}$ 那一行没有任何异常信号：系数稳定、置信区间正常、换 seed 也复现。它错的地方在于控制中介变量把总效应换成了直接效应。如果决策关心的是「上线这个功能会带来多少提升」（总效应），而报告给出的是直接效应，那么经由 $M$ 的那 $0.9$ 就凭空消失了——$31\%$ 的效应，不留痕迹。

「答对了另一个问题」是最难发现的错误

4M-bias：连「只控制处理前变量」都不安全

上一节的 $C$ 是处理的后代，所以「不要控制处理后的变量」似乎能挡住它。这条规则在工程上非常流行，因为它只需要时间戳就能执行。但它是错的。

U1 U2 U1, U2 都是**未观测**的 / \ / \ v v v v T Z <------- Y Z 是 U1 与 U2 的**对撞** | ^ Z 在**处理之前**就被测到 +---------------------+ T -> Y 真效应 = 1.0 注意: U1 不影响 Y，U2 不影响 T -> T 与 Y 之间**本来没有混杂**，不控制任何东西就是无偏的
控制的变量集$T$ 的系数偏差
$\varnothing$（不控制）$+1.00128$$+0.001$（正确）
$\{Z\}$（控制处理前变量）$\mathbf{+0.68794}$$\mathbf{-0.312}$
$\{Z, U_1\}$$+1.00324$$+0.003$（补上 $U_1$ 又对了）
$\{Z, U_2\}$$+1.00340$$+0.003$（补上 $U_2$ 也对了）
$\{U_1, U_2\}$$+1.00332$$+0.003$

$Z$ 在处理之前测到、与 $T$ 之间没有任何因果箭头，看起来像一个无害的基线协变量——而且它与 $T$ 的相关是 $+0.4889$，在任何「按相关性筛特征」的流程里都会被选进去。控制它把偏差从 $+0.00128$ 变成 $-0.31206$——真效应的 $31\%$。

而后两行给出了修补方式：只要把 $U_1$ 或 $U_2$ 中任意一个也控制上，偏差就消失了。但那两个变量按设定是未观测的——所以现实中的处境是：你能观测到造成问题的那个变量，却观测不到能修好它的那两个。

「把处理前能拿到的特征都塞进倾向得分模型」是工业界的默认做法，而 M-bias 说明这个做法可以制造偏差。唯一的判据仍然是图：$Z$ 是不是某两个混杂的共同后代？这个问题不能从数据里学出来（$Z$ 与 $T$ 在数据上就是独立的），只能靠对业务机制的了解回答。

这条反例的实践含义

公平地说，M-bias 的量级取决于图的参数，在很多现实情形下它比遗漏一个真混杂造成的偏差小得多。本节的论点不是「不要控制处理前变量」，而是「时间先后不是判据」——判据只能是图。

5后门走不通时：前门准则

后门准则要求「有一组可观测变量能阻断所有后门路径」。如果混杂完全不可观测，后门就走不通了——但还有一条前门（front-door）：如果效应全部经由一个可观测的中介 $M$，且 $M$ 本身不被混杂影响，那么可以分两步走。

U (完全不可观测的混杂) / \ v v T ------> Y <- 后门 T <- U -> Y 无法阻断 \ ^ v / M <- 但效应**全部**经由 M，且 U 不影响 M

前门准则的三个条件：① $M$ 拦截了 $T$ 到 $Y$ 的所有有向路径；② 没有从 $T$ 到 $M$ 的未被阻断的后门路径；③ 所有从 $M$ 到 $Y$ 的后门路径都被 $T$ 阻断。此时

\[P(Y{=}y \mid do(T{=}t)) = \sum_m P(m \mid t) \sum_{t'} P(y \mid m, t') P(t')\]

两个求和分别对应两步：$T \to M$ 用观测的条件分布（因为条件 ② 保证它无混杂），$M \to Y$ 用以 $T$ 为调整集的后门调整（条件 ③）。

条件 ① 要求没有任何绕过 $M$ 的通道——这与模块 05 的替代性假设是同一个条件，而那一节会量出它失效时的代价（符号反转）。所以前门准则与代理指标是同一枚硬币：前者用「全部经由 $M$」来做识别，后者用它来做预测，两者对这个假设的依赖强度完全一样。

6工具变量与「白拿」的控制变量在图上的位置

模块 04 会用工具变量做识别。这里先把它在图上的位置说清楚，因为它和上一节的表里两类变量容易混。

工具 I: 纯结果预测变量 P: I P | | v v U -> T -> Y <- U U -> T -> Y <- P ^ I 影响 T，不影响 Y P 影响 Y，不影响 T 控制 I 会**放大方差** 控制 P **降低方差**且无害
变量对 $T$对 $Y$控制它的后果不控制它的后果
工具 $I$有影响无直接影响放大方差（吸走了 $T$ 的外生变动）无偏，且可用于 IV 识别
纯预测变量 $P$无影响有影响降低方差，无偏无偏，但方差更大

两者在图上是镜像的，而控制它们的后果相反。这是「好控制 / 坏控制」清单里最容易记错的一对：工具变量是识别资源，把它当协变量控制掉等于把资源浪费掉；纯预测变量是方差资源，不控制它等于把资源浪费掉。

直白说

直觉：控制工具变量之后，$T$ 剩下的变动就只有内生的那部分了——你恰好把干净的信号扣掉，留下了脏的。而控制纯预测变量只是把 $Y$ 里与处理无关的噪声解释掉，所以估计更精确而不改变期望。

严谨说

记 $T = \pi I + v$，$Y = \beta T + \gamma P + u$，其中 $\text{Cov}(v,u) \neq 0$。控制 $I$ 后 $T$ 的残差方差从 $\pi^2 + \sigma_v^2$ 降到 $\sigma_v^2$，而 OLS 的方差 $\propto 1/\text{Var}(T \mid \text{控制集})$，故上升。控制 $P$ 则使残差方差 $\sigma_u^2$ 降低 $\gamma^2\text{Var}(P)$，故方差下降。

7为什么本课不覆盖因果发现

既然判据是图，一个自然的想法是：能不能从数据里把图学出来？这个方向叫因果发现（causal discovery），有 PC、GES、NOTEARS 等一系列算法。本课不覆盖它，理由有三条，而它们都不是「算法不好」。

  1. 观测数据的上限是马尔可夫等价类。在只有观测数据、且不加额外假设时，$A \to B$ 与 $A \leftarrow B$ 产生完全相同的联合分布。算法能识别的是一个等价类，而本课需要的方向信息恰恰在等价类内部无法区分。第 2 节的三种结构里只有对撞能被观测数据区分出来（因为它的条件独立模式独一无二）。
  2. 在线业务里有更可靠的信息来源：系统架构（谁调用谁）、埋点顺序（谁先发生）、以及「谁能改什么」（哪些量是可干预的）。这些信息的可靠性远高于从有限样本里做的独立性检验，而后者在高维下的假阳性率是众所周知的问题。
  3. 发现出来的图仍然要被审查。即使算法给出一个正确的等价类，选择其中哪一个成员、以及怎么处理算法认为不存在而领域知识认为存在的边，最终都回到人的判断。所以因果发现改变的是「图从哪里来」，不改变本模块的结论——该控制什么必须由图决定。
把领域知识写成图（如本模块胶囊里的 SPEC），然后用因果发现算法去检验它：算法认为该有而图里没有的边、以及图里有而数据强烈否定的边，都是值得复核的地方。这样用法的价值是发现分歧，而不是替代判断——与模块 04 的事前登记模板同一个思路。

8中介、代理与「好控制/坏控制」清单

把上面的结论整理成一张可以直接查的表。设目标是 $T \to Y$ 的总效应：

变量的角色图上的位置控制它本课的数值
混杂（confounder）$T \leftarrow X \rightarrow Y$必须控制不控制时偏 $+0.731$
中介（mediator）$T \rightarrow M \rightarrow Y$不要控制（会变成直接效应）$2.90 \to 2.00$
对撞（collider）$T \rightarrow C \leftarrow Y$绝不控制$2.90 \to 0.30$
中介的后代$M \rightarrow M'$不要控制（部分阻断）介于两者之间
对撞的后代$C \rightarrow C'$不要控制（部分打开）介于两者之间
工具（instrument）$I \rightarrow T$，$I \not\to Y$控制会降低精度（放大方差）模块 04 会用它做识别
纯结果预测变量$P \rightarrow Y$，$P \not\to T$控制无害且降低方差唯一「白拿」的一类
M-bias 型$T \leftarrow U_1 \rightarrow Z \leftarrow U_2 \rightarrow Y$不要控制（即使它在处理前）$+0.001 \to -0.312$

这张表的结构值得注意：八类变量里只有一类（纯结果预测变量）是无条件安全的，而它恰好是唯一不影响处理的那一类。换句话说，「与处理相关的变量」几乎都需要图上的论证才能决定去留。

如果目标是直接效应呢

那么控制中介 $M$ 就是对的——$\{X,M\}$ 给出的 $2.00079$ 精确无偏。所以上表的每一行都隐含「目标是总效应」这个前提。这不是术语细节：模块 05 会给出一个真实场景，决策关心总效应而监控指标只能反映直接效应。

还有一类变量上表没列，因为它介于两者之间：混杂的代理。若真混杂 $U$ 不可观测，但有一个 $W$ 满足 $U \to W$，那么控制 $W$ 会部分阻断后门路径——阻断的程度取决于 $W$ 对 $U$ 的信息量。notebook 的练习 2 里图 3 正是这种情形：$X \to W \to Y$ 时控制 $X$ 或 $W$ 都合法（$3/4$ 个子集合法），此时应选方差最小的那个。但要注意：代理控制不完全时残余混杂仍在，而这个残余不会随样本量消失（模块 01 第 5 节的现象）。

既然判据是图，而图是假设，那么变量选择就不能完全由数据驱动。有一类算法（因果发现 / causal discovery）尝试从数据里学图，但它们只能识别到马尔可夫等价类——在观测数据上，$A \to B$ 与 $A \leftarrow B$ 通常无法区分。本课不覆盖因果发现，因为在线业务里通常有更可靠的信息来源：系统架构、埋点顺序、以及「谁能改什么」。下一节把这三条理由展开。

为什么本节没有「自动选变量」的方法

最后回到本模块开头那两条民间规则。它们之所以流行，是因为都能不看图就执行：「控制得越多越好」只需要一个特征列表，「只控制处理前变量」只需要时间戳。而正确的判据需要一个东西是这两者都不提供的——对因果方向的断言。这个断言不能从数据里学出来（下一节），所以它必须被人写下来、被 review、被版本管理。本模块的胶囊做的就是这件事。
