1一个恒等式先把整门课框定了

在线实验做久了会形成一种直觉：把两组的指标一减，就是效应。这个直觉在随机化成立时是对的，而且它对得如此可靠，以至于人们很少去问它为什么对。本课从那个「为什么」开始，因为答案里藏着一条恒等式，而恒等式的每一项都对应本课后面的一个模块。

记 $Y_i(1)$ 与 $Y_i(0)$ 为个体 $i$ 在处理与不处理下各自会取到的结果（potential outcome，潜在结果），$T_i \in \{0,1\}$ 是实际处理。个体因果效应 $\tau_i = Y_i(1) - Y_i(0)$ 永远观测不到——任一时刻我们只能看到 $Y_i = Y_i(T_i)$ 中的一个。这是因果推断的根本问题。

\[\underbrace{E[Y \mid T{=}1] - E[Y \mid T{=}0]}_{\text{朴素差（能算）}} = \underbrace{E[Y(1) - Y(0) \mid T{=}1]}_{\text{ATT（想要）}} + \underbrace{E[Y(0) \mid T{=}1] - E[Y(0) \mid T{=}0]}_{\text{选择偏差}}\]

这不是近似，是代数恒等式：把中间项 $E[Y(0)\mid T{=}1]$ 加一次减一次即可。配套 notebook 在一个已知全部 $Y(0)/Y(1)$ 的合成人群上把它验证到浮点精度——朴素差 $1.582605$ = ATT $0.647736$ + 选择偏差 $0.934869$，两边之差恰为 $0$。

它把「我的估计错了多少」变成了一个有名字的量：选择偏差 $= E[Y(0)\mid T{=}1] - E[Y(0)\mid T{=}0]$，即「处理组的人如果没被处理，会不会本来就跟对照组不一样」。所有识别策略——随机化、后门调整、工具变量、双重差分——做的都是同一件事：给这一项一个等于零（或可估计）的理由。

为什么这条恒等式值得记住

在同一个合成人群上，三个常被混用的目标量数值上并不相等：ATE $=0.999902$、ATT $=0.647736$、ATC $=1.350613$——$\text{ATT}/\text{ATC} = 0.480$，即已经被处理的人从处理里获益更少（自选择进来的人往往本来就会做得不错）。而选择偏差 $0.934869$ 是真效应的 0.93 倍，于是朴素差把 ATE 高估了 1.58 倍——不是因为样本量不够，是因为估的不是同一件事。

2随机化解决了什么

随机分配处理让 $T$ 与 $(Y(0), Y(1))$ 独立，于是 $E[Y(0)\mid T{=}1] = E[Y(0)\mid T{=}0]$，选择偏差结构性地为零。notebook 里在同一人群上重随机三次，选择偏差落在 $-0.0069$ / $-0.0067$ / $-0.0017$；而样本量每乘 $4$ 时 RMSE 的比值是 $2.20$ / $1.96$ / $1.92$，即 $\propto 1/\sqrt{n}$——剩下的只是噪声，不是偏差。

这就是 A/B 测试的全部力量所在，也是 C10 模块 07 的领地：随机化把因果问题降级成了统计问题，之后的事情是检验、功效、多重比较、序贯与方差缩减。那些内容本课一概不重复。

C10-07 假设随机化有效，然后把统计做对。本课处理它无效或不够的情形：不能随机化（只有观测数据）、随机化被违反（干扰、不依从）、随机化本身有效但测的不是你要的量（个体随机化下的干扰、短期代理指标）。两门课不重叠：本课里没有 $z$ 检验、功效曲线、Bonferroni 或 CUPED。

这张表里最值得注意的一点：五个失效场景里，没有一个会报错。每一个都给出一个格式正确、置信区间漂亮、能写进周报的数字。所以本课的可交付物不是「更好的估计量」，而是知道每个估计量在什么条件下悄悄失效。

4三个会在后面反复出现的反直觉

① 控制更多变量可以让结果更糟

在一个真实总效应为 $2.9$ 的图上，控制 $\{X\}$ 给出 $2.899$（无偏），而再加一个变量控制 $\{X, C\}$ 给出 $0.307$——偏差从 $0$ 变成 $2.59$。$C$ 是处理与结果的共同后代（对撞），控制它打开了一条假路径。更进一步：模块 02 会构造一个连「只控制处理前变量」都不安全的例子（偏差 $+0.001 \to -0.312$）。

② 弱工具变量不是「噪声大」，是悄悄退回它本该修掉的估计

内生性让 OLS 上偏到中位数 $1.7994$（真值 $1.0$）。第一阶段 $F$ 中位数为 $0.46$ 时，2SLS 的中位数是 $1.8009$——与 OLS 已经无法区分。而它的均值在正负之间乱跳，因为恰好识别的 2SLS 没有有限矩，报告均值本身就是错的。

③ 短期代理指标可以在符号上骗你

结构 $T \to S \to Y$ 加一条 $T \to Y$ 的直接通道。短期代理 $S$ 上涨 $+1.005$，代理指标模型据此预测长期效应 $+1.005$，而真实长期效应是 $-0.999$。代理指标只能看见「经过 $S$ 的那部分」，绕过 $S$ 的通道它完全看不见，也不会告警。

以上三条以及后面所有结论，都在 notebook 里由断言验证，而不是由叙述断定。多处结论是在探数阶段被测量结果推翻后重写的——例如「RDD 带宽越小偏差越小」在两侧曲率对称时是假的（偏差在左右之差里恰好抵消，最优带宽变成用满全部数据），而「合成控制的 pre 期拟合越好越可信」在四种设定里的预测力是掷硬币。

本课的一条纪律

5怎么用这门课

六个模块沿「假设从强到弱」排列，而不是沿「方法从简到繁」排列：

  1. 模块 01：潜在结果框架——把问题写成一个有明确目标量的形式。ATE / ATT / ATC / CATE 的区别、识别与估计的分工。
  2. 模块 02：因果图与识别——后门准则告诉你控制什么，以及为什么「控制得越多越好」和「只控制处理前变量」两条民间规则都是错的。
  3. 模块 03：倾向得分、IPW、双重稳健、双重机器学习——在后门假设成立后，怎么估，以及每个估计量的静默失效模式。
  4. 模块 04：准实验——后门假设不成立时，DiD / IV / RDD / 合成控制各自借用什么外生性，以及各自的假设为什么不可检验。
  5. 模块 05：线上归因——回到实验有效但口径错的情形：SUTVA 与干扰、集群随机化与 switchback、多触点归因、代理指标。

模块之间的依赖是线性的：后一个模块放松前一个模块的一条假设，或者量化违反它的代价。所以顺序读比挑着读更省力，而模块 02 是全课的枢纽——它给出的「该控制什么」是模块 03 全部估计量的输入，而模块 04 处理的正是「它给不出合法调整集」的情形。

每个模块的 notebook 是纯 numpy、CPU、离线，含 4 个练习（TODO 桩 + 自测断言）、参考答案与一个真实工程胶囊。不需要任何真实实验数据：所有数据生成过程的真值都是已知的，这正是能判断估计量对错的前提。
