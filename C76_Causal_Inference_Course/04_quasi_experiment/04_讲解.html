1换设计，而不是换估计量

模块 03 的全部工具都建立在可忽略性之上：存在一组可观测的 $X$ 使得条件独立成立。模块 01 已经量出，这个假设不成立时偏差不随样本量消失（$n$ 从 $2\times10^3$ 到 $2\times10^6$，偏差从 $+0.8644$ 到 $+0.8534$）。

本模块处理的正是这种情形。共同思路：不再假设可观测变量足够，而是去找一个外生的变化来源——时间、规则阈值、工具、或者对照单位的组合。

方法借用的外生性核心假设假设可检验吗
DiD处理发生的时点平行趋势（处理组若未处理，趋势与对照组相同）不可（只能检验处理前的部分）
工具变量 / 2SLS一个只经由 $T$ 影响 $Y$ 的变量 $Z$外生性 + 相关性 + 排他性相关性可检验；外生性与排他性不可
断点回归 / RDD规则阈值两侧的准随机性结果函数在阈值处连续部分可（密度检验、协变量跳变）
合成控制多个对照单位的加权组合因子结构在 pre/post 之间稳定不可（pre 期拟合优度不是它）
四种方法的核心假设都无法从数据中检验。所以每一节都同时给出两样东西：① 假设成立时的正确性；② 假设不成立时的偏差，以及常用的「检验」为什么挡不住它。这不是悲观：知道一个假设不可检验，比误以为它已被检验要安全得多。

本模块的统一结论

2双重差分：平行趋势不可检验

DiD 用「处理组的前后变化」减去「对照组的前后变化」，从而消掉两组的水平差异：

\[\widehat{\tau}_{\text{DiD}} = (\bar{Y}^{\text{post}}_{\text{treat}} - \bar{Y}^{\text{pre}}_{\text{treat}}) - (\bar{Y}^{\text{post}}_{\text{ctrl}} - \bar{Y}^{\text{pre}}_{\text{ctrl}})\]

notebook 里两组的水平差是 $3.0$，真效应 $\tau = 2.0$（只在 $t \geq 4$ 生效）。标准做法是先跑一个 pre-trend 检验：把处理前的期间一分为二做同样的 DiD，若 $\vert t\vert < 1.96$ 就认为平行趋势成立。

情形DiD 估计偏差pre-trend $\vert t\vert$检验结论
平行趋势成立$+2.0016$$+0.002$$0.77$通过 ✓
处理前就分叉（$0.3t$）$+3.2016$$+1.202$$6.08$拒绝 ✓
只在处理后分叉（$0.5$/期）$\mathbf{+3.2516}$$\mathbf{+1.252}$$\mathbf{0.77}$通过 ✗
只在处理后水平跳（$1.5$）$\mathbf{+3.5016}$$\mathbf{+1.502}$$\mathbf{0.77}$通过 ✗

后两行是本节的要点：pre-trend 检验的 $t$ 值与「平行趋势成立」那一行完全相同（$0.77$），而 DiD 偏了 $+1.25$ / $+1.50$。对应的 event-study 系数（相对 $t{=}3$）是

[-0.099  0.126 -0.062  0.  |  2.454  2.955  3.576  3.838]
  ^--- 处理前 4 期全部贴近 0 ---^     ^--- 处理后被污染 ---^

处理前的四个点漂亮地贴在零线上——这正是论文里常见的那种 event-study 图。它没有说错任何事：处理前趋势确实平行。它只是没有、也不可能说出处理后本会不会平行。

而且它的功效还常常不足：Roth (2022) 指出，在典型样本量下，一个足以让 DiD 严重有偏的趋势差往往不足以被 pre-trend 检验拒绝。所以「pre-trend 通过」的信息量比通常假设的要低得多。DiD 的有效性最终依赖制度知识——「处理时点为什么与其他冲击无关」——而不是任何统计检验。

pre-trend 检验只能证伪，不能证实

3工具变量：弱工具悄悄退回 OLS

工具变量 $Z$ 需要三个条件：相关性（$Z$ 影响 $T$）、外生性（$Z$ 与误差项无关）、排他性（$Z$ 只经由 $T$ 影响 $Y$）。两阶段最小二乘（2SLS）先用 $Z$ 预测 $T$，再用预测值估效应。

notebook 里内生性使 OLS 上偏到中位数 $1.7994$（真值 $1.0$）。把工具强度 $\pi$ 从 $0.5$ 降到 $0.005$：

$\pi$第一阶段 $F$ 中位数OLS 中位数2SLS 中位数2SLS 均值2SLS 四分位距

$0.200$$39.80$$+1.7687$$+0.9949$$+0.974$$0.222$
$0.100$$9.88$$+1.7917$$+0.9911$$+0.862$$0.461$
$0.050$$2.47$$+1.7979$$+1.0778$$-0.125$$0.838$
$0.020$$0.68$$+1.7993$$+1.5135$$-0.599$$1.241$

最后一行：2SLS 的中位数 $1.8009$ 与 OLS 的 $1.7994$ 已经无法区分。弱工具不是「噪声大」，是悄悄退回它本该修掉的那个有偏估计。而 $F$ 中位数在 $\pi{=}0.1$ 时是 $9.88$，恰好在 $10$ 附近——这就是「第一阶段 $F > 10$」这条经验规则的来源（Staiger & Stock 1997）。

$\pi$ 小时 2SLS 的均值在 $-0.599$ 与 $+0.492$ 之间乱跳，而中位数是平滑单调的。原因：恰好识别的 2SLS 没有有限矩（分母 $\hat{\pi}$ 可以任意接近 $0$）。所以「多跑几次取平均」不能救弱工具——报告均值本身就是错的，应报告中位数与分位距。notebook 量出 $\pi{=}0.005$ 时 2SLS 的取值范围是 $[-1978.6, +804.9]$，且 $\vert\hat\beta\vert > 10$ 的比例是 $3.65\%$。

均值那一列不可读，而这本身是一个结论

2SLS 估的是 LATE，不是 ATE

即使工具很强，2SLS 识别的也只是被工具推动的那部分人的效应（LATE，local average treatment effect）。模块 01 已经量出 ATT/ATC 可以相差 $2.09$ 倍；LATE 与 ATE 的差距同理，取决于「被工具推动的人」与全人群有多不同。把 2SLS 的结果写成「该功能的效应是 X」是一次无声的口径替换。

4断点回归：偏差来自两侧曲率之差

RDD 利用规则阈值：分数刚过线与刚没过线的人在其他方面几乎相同，所以阈值两侧的结果之差就是效应。实现上是在阈值附近的带宽 $h$ 内做局部线性拟合，取两侧在阈值处的截距之差。

我最初的实验设计是错的，值得先讲。基线函数取 $f(x) = x + 2x^2$（关于断点对称），结果偏差几乎不随 $h$ 变化（$0.0057 \to 0.0014$），最优带宽是用满全部数据：

$h$样本量对称曲率：估计$\vert$偏差$\vert$RMSE
$0.05$$301$$+0.9943$$0.0057$$0.1067$

$0.70$$4196$$+0.9969$$0.0031$$0.0289$
$1.00$$6000$$+0.9986$$0.0014$$\mathbf{0.0258}$

原因：局部线性拟合在 $[0,h)$ 上因曲率产生的截距偏差，与在 $(-h,0]$ 上产生的偏差大小相同，在两侧之差里恰好抵消。所以要看到真正的偏差-方差权衡，曲率必须两侧不同：

现在有了内点最优 $h^{*} = 0.20$，而 $h{=}1.0$ 的偏差是 $0.4175$（真效应的 $42\%$）。

RDD 的偏差取决于两侧函数形状的差异，不是曲率本身的大小。这意味着「结果对分数是非线性的」并不自动意味着 RDD 有偏——而「两侧的非线性方式不同」才是危险信号。后者可以部分诊断：分别在两侧拟合并比较二阶项。

5合成控制：pre 期拟合优度是掷硬币

合成控制用多个对照单位的加权组合来构造处理单位的反事实，权重由 pre 期的拟合决定。经典做法把权重限制在单纯形上（$w \geq 0$，$\sum w = 1$），理由是避免外推。

直觉上「pre 期拟合得越好，post 期的反事实越可信」。notebook 测了四种设定（$J{=}20$ 个捐赠者、$n_{\text{pre}}{=}30$ 期、真 $\tau{=}3.0$、$200$ seeds）：

情形权重pre 期 RMSE$\sum\vert w\vert$post 均值post 标准差post RMSE
凸包内 / 因子稳定单纯形$0.2670$$1.00$$+3.0124$$0.1128$$\mathbf{0.1135}$
凸包内 / 因子稳定无约束$\mathbf{0.1764}$$5.29$$+3.0388$$0.1740$$0.1783$
凸包外 / 因子稳定单纯形$1.7233$$1.00$$+2.9346$$0.7831$$0.7858$
凸包外 / 因子稳定无约束$\mathbf{0.2294}$$7.14$$+3.0339$$0.2210$$\mathbf{0.2236}$
凸包内 + post 新因子单纯形$0.2670$$1.00$$+3.0722$$0.3283$$\mathbf{0.3362}$
凸包内 + post 新因子无约束$\mathbf{0.1764}$$5.29$$+3.1022$$0.5540$$0.5633$

无约束 OLS 在全部 $4$ 种设定里 pre 期拟合都更好（$0.1764$ vs $0.2670$，$0.2294$ vs $1.7233$），而 post 期 RMSE 只在 $2$ 种里更好——pre 期拟合优度对 post 期精度的预测力是 $2/4$，即掷硬币。

而两种权重的优劣有明确的分界：

  • 处理单位在捐赠者凸包内时，单纯形更好（$0.1135$ vs $0.1783$，优 $\mathbf{1.57}$ 倍）——无约束的 $\sum\vert w\vert = 5.29$ 是在做外推，付了方差的代价。
  • 处理单位在凸包外时，单纯形更差（$0.7858$ vs $0.2236$，劣 $\mathbf{3.51}$ 倍）——它根本拟合不上（pre RMSE $1.7233$），约束此时是负担而不是保护。
  • post 期出现新因子时两者都退化，而 pre 期拟合完全没变（$0.2670$ / $0.1764$，与无新因子那两行逐位相同）——所以这种失效在 pre 期无从察觉。
第三条是最重要的：pre 期 RMSE 在「因子稳定」与「post 出现新因子」两种情形下逐位相同（差 $0.00\times10^{0}$），而 post RMSE 相差 $3.0$ 倍（$0.1135 \to 0.3362$）。所以合成控制的可信度不能由 pre 期拟合来论证。应报告的是：$\sum\vert w\vert$（外推程度）、处理单位是否在凸包内、以及 post 期是否有理由相信因子结构未变。最后一项是制度知识，与 DiD 的平行趋势一样不可检验。

6RDD 的另外两个诊断，以及模糊断点

上一节只处理了带宽与多项式次数。RDD 还有两个可检验的部分，这也是它在四种方法里假设最接近可检验的原因。

  1. 密度检验（McCrary）：分数在阈值处的密度应连续。如果有人能操纵分数刚好过线，密度会在阈值右侧堆积。这个检验直接针对「阈值两侧准随机」这个前提。
  2. 协变量跳变检验：把 $Y$ 换成任何不应该被处理影响的基线协变量，重跑同一个 RDD。估计值应为 $0$。若某个基线协变量在阈值处跳变，说明阈值处还有别的规则同时生效。

这两个检验与模块 02 的关系值得点出：第二个检验实际上是在问「阈值这个准工具是否满足排他性」——它只该通过 $T$ 影响 $Y$。这与工具变量的排他性是同一个条件，区别只在 RDD 里它有一部分能被检验。

模糊断点：RDD 与工具变量的交汇

如果过线只是提高了被处理的概率而非必然被处理（模糊断点，fuzzy RDD），那么「是否过线」就成了一个工具变量，而估计变成阈值处的一次 2SLS：

\[\hat{\tau}_{\text{fuzzy}} = \frac{\lim_{x\downarrow 0} E[Y\mid x] - \lim_{x\uparrow 0} E[Y\mid x]}{\lim_{x\downarrow 0} E[T\mid x] - \lim_{x\uparrow 0} E[T\mid x]}\]

分母就是第一阶段。于是本模块第 3 节的弱工具问题全部适用：如果过线只把处理概率从 $0.40$ 提到 $0.45$，分母是 $0.05$，而弱工具的失效是静默的——它会朝 OLS 的方向漂移，而不是给出一个明显不对的数字。

锐断点 RDD 估的是阈值处的 CATE，而模糊断点估的是阈值处、被阈值推动的那部分人的 LATE。两者都不是 ATE，也不是任何「整体人群」的效应。把 RDD 的结果写成「该规则的效应是 X」时，$X$ 只对分数恰好在阈值附近的人成立——而那通常恰好是最不典型的一批用户。

一个容易被忽略的口径

选择顺序上有一条经验：先问「有没有一个规则阈值」（RDD 的假设最接近可检验），再问「有没有一个明确的时点」（DiD），最后才考虑工具变量（外生性与排他性都不可检验，且弱工具的失效是静默的）。

还有一条与本课范围有关的说明：本模块只处理单一处理时点的 DiD。现实中处理常常在不同单位、不同时间陆续发生（交错处理，staggered DiD），此时双向固定效应估计量会隐含地用「已处理单位」做对照，从而可能得到与所有个体效应都反号的加权平均。这是本模块最重要的延伸方向，参考文献里给出了入口。

模块 03 的四个诊断量（ESS、trim 比例、修正项、折内外残差比）在本模块全部失效——它们检测的是「估计有没有算好」，而本模块的失效在「识别有没有成立」这一层。所以准实验的质量保证必须是设计层面的：事前登记假设、事前定好诊断、事后不换。
