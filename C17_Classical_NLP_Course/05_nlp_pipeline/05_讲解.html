1文本分类流水线全景

前四个模块拆解了 NLP 的核心算法。这一模块把视角拉回到工程现实：当你拿到一堆原始文本、要做一个文本分类器（垃圾邮件检测、情感分析、新闻分类），完整的流水线是什么样的？从原始字符串到分类结果，要经过哪些环节，每个环节的经典做法又是什么？

一条典型的经典文本分类流水线有四个环节，本模块逐一攻克：

经典文本分类流水线 (本模块的四个环节) 原始文本 ──①分词+归一化──► token 序列 (小写/去标点/去停用词/词干) │ ▼ ②特征提取 词袋 / TF-IDF 向量 (文档 -> 实数向量) │ ▼ ③分类器 朴素贝叶斯 / 逻辑回归 (向量 -> 类别概率) │ ▼ ④评测 精确率 / 召回率 / F1 / 混淆矩阵 (这个分类器到底好不好?)

这条流水线看似平凡，却是整个应用 NLP 的骨架。即便在大模型时代，做一个文本分类任务时，一个 TF-IDF + 逻辑回归的基线常常几分钟就能搭好、且强得惊人（见 references 的 NBSVM）——在动用大模型之前，它是你应该先跑的对照。更重要的是，这条流水线里的每个概念（分词、特征、分类、评测）都是理解现代 NLP 的基础词汇。

直白说

做文本分类就像做菜：先把食材（原始文本）洗净切好（分词归一化），再调成合适的形态（特征向量），下锅烹饪（分类器），最后尝味道打分（评测）。每一步都有讲究，缺一不可。

严谨说

形式上，文本分类是学一个映射 $f:\text{document}\to\{c_1,\dots,c_m\}$。经典方法把它分解为：表示 $\phi:\text{doc}\to\mathbb{R}^V$（分词+特征）+ 分类器 $g:\mathbb{R}^V\to\{c_i\}$（NB/logreg）。现代端到端方法（BERT 微调）把 $\phi$ 和 $g$ 一起学，但评测 $f$ 好坏的指标（P/R/F1）完全沿用经典。

本模块的核心问题：给定原始文本，如何一步步把它变成可分类的向量、训练一个分类器、并科学地评测它好不好？——答案是分词归一化 → TF-IDF → 朴素贝叶斯/逻辑回归 → P/R/F1。学完你能从零搭一条完整的文本分类管线，并讲清为什么不平衡数据要看 F1 而非 accuracy。

2分词与归一化

第一步：tokenization（分词）与 normalization（归一化）。把原始字符串切成 token，并统一形态以降低稀疏。看起来简单，细节却很多。

分词：英文最朴素的是按空格和标点切（"Hello, world!" → [hello, world]），但要处理缩写（don't→do n't?）、连字符（state-of-the-art）、URL、表情符号。中文没有空格，需要专门的分词算法（最大匹配、HMM/CRF 分词——正是模块 03/04 的应用！）。分词口径直接决定下游所有统计，是流水线的地基。

归一化把同一含义的不同写法合并，降低词表大小与稀疏：

操作作用例子注意
小写化 lowercasing合并大小写Apple/apple → apple可能丢失信息（Apple 公司 vs 苹果）
去标点 punctuation去掉标点符号world! → world标点有时有用（情感：!!! ）
去停用词 stop words删高频功能词the/is/of → 删除情感/作者识别里可能有用，慎删
词干提取 stemming粗暴砍词缀running → run可能过头（happily→happili）
词形还原 lemmatization还原到词典词元better → good更准但更重（需词典+词性）

一个关键认识：没有「正确」的归一化，只有「适合任务」的归一化。主题分类里去停用词、词干提取通常有益（关注内容词）；但情感分析里 not、停用词、甚至标点（!!!）都携带信号，过度归一化反而有害。归一化是有损压缩——每一步都在丢信息换取降稀疏，是否值得取决于你的任务。

分词与归一化是最容易被轻视、却最影响结果的环节。一个常见错误是训练和测试用不同的预处理（如训练去了停用词、测试没去），导致词表不匹配、性能莫名暴跌。铁律：把预处理封装成一个函数，训练和测试用同一个。本课所有管线都遵守这条。

3词袋与 TF-IDF

第二步：把 token 序列变成数值向量（分类器只吃数字）。最简单的是 bag-of-words（词袋）：把文档表示成「词→计数」的向量，完全忽略词序（the cat sat 和 sat cat the 向量相同）。词袋丢了语序，却出奇地有效——对很多分类任务，出现了哪些词比词的顺序更重要。

但原始计数有个问题：the、of 这类词在每篇文档都高频出现，却几乎没有区分力。我们想要的是既在本文档高频、又在语料中稀有的词——它们才有区分度。TF-IDF 正是为此设计：

\[\mathrm{tfidf}(t, d) = \underbrace{\mathrm{tf}(t, d)}_{\text{词频}} \times \underbrace{\log\frac{N}{\mathrm{df}(t)}}_{\text{逆文档频率 IDF}}\]

两个因子各司其职：term frequency（TF，词频）衡量「词 $t$ 对文档 $d$ 有多重要」（在 $d$ 里出现越多越重要）；inverse document frequency（IDF，逆文档频率）衡量「词 $t$ 有多稀有」——$N$ 是总文档数，$\mathrm{df}(t)$ 是含 $t$ 的文档数。出现在越少文档里的词，IDF 越高、越有区分力。

TF-IDF 的精妙在于两因子的相乘：the 虽然 TF 高，但它出现在几乎所有文档里（df 大），IDF≈$\log(N/N)=0$，乘起来被压到接近 0；而一个只在体育新闻里高频出现的词（如 touchdown），TF 高且 df 小，IDF 大，TF-IDF 值高——它正是区分「体育」类的好特征。TF-IDF 自动地压低普遍词、抬高有区分度的词，无需手工指定停用词。

从信息论看，IDF 其实在度量一个词的自信息（surprisal）：$\log\frac{N}{\mathrm{df}(t)}=-\log\frac{\mathrm{df}(t)}{N}\approx-\log P(t\text{ 出现在随机文档})$。越罕见的词，出现时带来的「信息量」越大、越值得关注——这与「停用词信息量低、专业术语信息量高」的直觉完全吻合。理解这一点，你就明白 TF-IDF 不是个拍脑袋的启发式，而是有信息论根基的：它本质上在用「词频 × 词的稀有度（自信息）」来量化每个词对区分这篇文档的贡献。这也是它能跨越检索与分类两大领域、历经几十年不衰的原因。

直白说

TF-IDF 就是给每个词打一个「重要性分」：在这篇文档里出现得多（TF 高），同时在所有文档里又比较罕见（IDF 高），分才高。the、of 到处都是，分接近 0；专业术语既高频又稀有，分很高。

严谨说

IDF 的对数是关键：它把「稀有度」从线性压成对数尺度，避免极稀有词（df=1）的权重爆炸。常见变体还有 $\log\frac{N}{\mathrm{df}(t)}+1$（平滑，避免 IDF=0）、TF 取对数 $1+\log\mathrm{tf}$（抑制长文档高频词）。最后通常对每篇文档的 TF-IDF 向量做 L2 归一化，消除文档长度的影响。

TF-IDF 是信息检索（搜索引擎排序）与文本分类的共同支柱，几十年长盛不衰。它简单、无需训练、可解释，至今是文本特征的强基线。Manning《Introduction to Information Retrieval》是其权威出处，详见 references。即便在 embedding 时代，TF-IDF 在小数据、需可解释的场景仍极有竞争力。

4分类器：朴素贝叶斯与逻辑回归

第三步：分类器。有了 TF-IDF 向量，怎么预测类别？两个经典选择，正好对应模块 04 的生成式 vs 判别式对偶。

朴素贝叶斯：生成式、数频率

naive Bayes（朴素贝叶斯）用贝叶斯定理 + 一个「朴素」假设。要算 $P(c\mid d)$（文档 $d$ 属于类 $c$ 的概率），贝叶斯定理给出 $P(c\mid d)\propto P(c)P(d\mid c)$。「朴素」之处在于假设给定类别，各词条件独立：$P(d\mid c)=\prod_t P(t\mid c)$。于是：

\[\hat{c} = \arg\max_c\; P(c) \prod_{t \in d} P(t \mid c) = \arg\max_c\Big[\log P(c) + \sum_{t \in d} \log P(t \mid c)\Big]\]

$P(c)$ 是类先验（数各类文档占比），$P(t\mid c)$ 是「类 $c$ 里词 $t$ 的频率」，配合 拉普拉斯平滑（同模块 02！）处理类 $c$ 里没出现的词。实际算时在对数空间（连乘变连加，防下溢——又是老朋友）。朴素贝叶斯训练只需数频率，极快，是文本分类的经典强基线。「条件独立」假设当然不成立（词之间显然相关），但它在实践中出奇地好用——这是机器学习里著名的「错误假设、正确预测」现象。

逻辑回归：判别式、学权重

logistic regression（逻辑回归）直接建模 $P(c\mid d)$，用特征的线性组合过 sigmoid/softmax。它和朴素贝叶斯是一对生成-判别镜像（正如 CRF↔HMM）：朴素贝叶斯数频率估 $P(t\mid c)$，逻辑回归用梯度下降学每个词的权重 $w_t$。逻辑回归能用任意（重叠）特征、不受条件独立假设束缚，数据足够时通常比朴素贝叶斯更准。

注意一个优美的联系：模块 04 的 CRF 是「序列版的逻辑回归」，而这里的逻辑回归是「单标签的 CRF」（序列长度为 1，无转移特征）。整个经典 NLP 的判别式模型，本质都是对数线性模型这一个家族——逻辑回归、最大熵、CRF 只是它在不同输出结构上的化身。

一句话选型：数据少、要快、要可解释 → 朴素贝叶斯；数据多、要更准、特征复杂 → 逻辑回归。二者都该在上深度模型前先跑——它们常常已经足够好，且能告诉你任务的难度下界。记住这对生成-判别镜像，你就把模块 04 和 05 的分类器串成了一条线。

5评测：为什么 F1 而非 accuracy

第四步、也是最容易被做错的一步：评测。一个分类器到底好不好？最直觉的指标是 accuracy（准确率，预测对的占比），但它在类别不平衡时具有严重的误导性。

accuracy 陷阱

举个经典例子：做疾病检测，99% 的人没病。一个永远预测「没病」的傻瓜分类器，accuracy 高达 99%！但它一个病人都没查出来——完全无用。accuracy 被多数类主导，掩盖了模型在少数类（往往是我们真正关心的类）上的彻底失败。这就是为什么不平衡数据绝不能只看 accuracy。垃圾邮件、欺诈、疾病、命名实体——现实中重要的分类任务大多不平衡。

救星是 precision（精确率）与 recall（召回率）。它们从混淆矩阵的四个数（TP/FP/FN/TN）算出，聚焦于我们关心的那个类：

\[\text{precision} = \frac{TP}{TP+FP}, \qquad \text{recall} = \frac{TP}{TP+FN}\]

精确率回答：「预测为正的里面，有多少真的是正？」（查得准不准——FP 少则高）。召回率回答：「真正的正例里，找回了多少？」（查得全不全——FN 少则高）。那个永远说「没病」的分类器：召回率 = 0（一个病人没找到），立刻暴露其无用——而 accuracy 看不出来。

精确率和召回率通常此消彼长：把判定阈值调严，精确率升、召回率降（宁可漏报不误报）；调松则反之。怎么用一个数概括？F1 score——二者的调和平均：

\[F_1 = \frac{2 \cdot \text{precision} \cdot \text{recall}}{\text{precision} + \text{recall}}\]

为什么用调和平均而非算术平均？因为调和平均惩罚极端：只要 P 或 R 有一个很低，F1 就被拉低（算术平均会被另一个高值「救」回来）。那个傻瓜分类器：P 无定义/R=0 → F1=0，诚实地反映它毫无用处。F1 是分类与 NER 的主流单一指标，notebook 会从零实现并与手算对拍。

直白说

精确率 = 「你说是的，有多少真是」；召回率 = 「真是的，你找回多少」。一个查得准、一个查得全，常常顾此失彼。F1 把两者揉成一个数，且只要有一个差，F1 就好不了——逼你两头都顾。

严谨说

多类时还要区分 macro 与 micro 平均：macro 对每类 F1 取算术平均（每类等权，凸显小类表现）；micro 把所有类的 TP/FP/FN 汇总后算一次（被大类主导，等于多类 accuracy）。不平衡数据报告时务必说清用哪种——macro-F1 才能反映模型在小类上是否真的有用。

6完整管线与工程要点

把四个环节拼成一条完整的、可评测的文本分类管线，并理清几个工程要点。端到端流程：

完整文本分类管线 (训练 + 评测) 训练文档+标签 ──预处理(分词/归一)──► token │ ▼ (在训练集上 fit) 建词表 + 算 IDF ──► TF-IDF 向量化器 (记住词表与 idf) │ ▼ 训练分类器 (朴素贝叶斯数频率 / 逻辑回归梯度下降) │ ▼ (测试文档 用同一个预处理+向量化器 transform) 预测类别 │ ▼ (与真值比) 混淆矩阵 -> Precision / Recall / F1 (macro/micro)

几个决定成败的工程要点：

  • 训练/测试用同一套变换：词表和 IDF 必须只在训练集上 fit，再用同一个变换器 transform 测试集。在测试集上重新算 IDF、或用全量数据建词表，都是数据泄漏（test leakage），会高估性能。这是初学者最常踩的坑。
  • OOV 处理：测试文档里训练没见过的词，要么忽略、要么映射到 <unk>（同模块 02/03）。向量化器必须能优雅处理未见词。
  • 先跑强基线再上复杂模型：TF-IDF + 逻辑回归/朴素贝叶斯 几分钟搭好，常常已经很强（NBSVM）。它给你一个性能下界——如果你的大模型还不如它，说明哪里错了。永远先有基线。
  • 评测要诚实：报告 F1（不平衡时）而非 accuracy，说清 macro/micro，用独立测试集，最好交叉验证。漂亮的 accuracy 可能只是多数类的幻觉。

直白说

整条管线就是：把文本洗成向量、训个分类器、用 F1 诚实地评测。它简单、快、可解释，是任何文本分类任务都该先跑的第一版。把它跑通跑对，你就有了衡量一切复杂方法的标尺。

严谨说

从机器学习工程看，这条管线体现了几个普适原则：fit/transform 分离（防泄漏）、预处理一致性（训练测试同变换）、基线优先（先简单后复杂）、指标匹配任务（不平衡用 F1）。这些原则不限于文本——任何监督学习任务都适用。经典 NLP 管线是学这些工程纪律的最佳载体。

7总纲：五模块与现代 NLP 的传承

把整门课的五个模块连起来，看清经典 NLP 这条流水线在更大图景里的位置——以及它与现代 NLP 的传承。本课五个模块其实覆盖了 NLP 的三个层次：

层次模块经典方法现代对应
表示 词01 词嵌入word2vec / GloVeBERT/GPT 的 embedding 层
语言模型 序列概率02 n-gramn-gram + KN 平滑GPT（困惑度评测一脉相承）
序列标注 序列→标签03 HMM / 04 CRF前向-后向 / ViterbiBiLSTM-CRF / BERT-CRF（CRF 层保留）
文本分类 文档→类别05 流水线TF-IDF + NB/logregBERT 微调（评测 P/R/F1 沿用）

这张表是整门课的总纲。它告诉你一个深刻的事实：现代 NLP 并没有抛弃经典，而是站在它的肩膀上。embedding 层是词向量的延续，GPT 的困惑度是 n-gram 的遗产，BERT-CRF 的 CRF 层就是模块 04 的前向+Viterbi，文本分类的 F1 评测从未改变。你学的不是过时的东西，而是现代 NLP 的地基与共同语言。

更重要的是方法论的传承。贯穿全课的几个核心思想，在现代 NLP 里反复出现：

  • 分布假设（观其伴知其义）：从 word2vec 到 BERT 的 masked LM，自监督学习的哲学根基从未改变。
  • 对数空间 + 动态规划：前向-后向、Viterbi、log-sum-exp，从 HMM/CRF 到 CTC 到现代序列模型一脉相承。
  • 生成式 vs 判别式：朴素贝叶斯↔逻辑回归、HMM↔CRF 的对偶，是理解一切概率模型的坐标系。
  • 平滑与正则化：从 Kneser-Ney 到神经网络的 dropout/label smoothing，「别把概率压成 0、别过拟合」的智慧相通。
  • 评测的科学：困惑度、P/R/F1、macro/micro，诚实评测的纪律是 NLP 永恒的基本功。

把整门课浓缩成一句话：经典 NLP = 现代 NLP 的地基、词汇表与方法论。你现在能从零写出 word2vec、n-gram、HMM、CRF、TF-IDF——这意味着当你面对任何「新」的 NLP 方法时，都能看穿它的本质：哪些是真创新，哪些是经典思想在更大算力上的回响。这就是地基课的终极价值。

8研究前沿与开放问题

经典文本分类管线简单可靠，但它有清晰的天花板，这些天花板正是现代 NLP 突破的方向——而管线的评测与基线思想被完整继承：

  • 词袋丢语序：TF-IDF/BoW 完全忽略词序（not good 和 good not 一样），无法处理否定、长程依赖、语义组合。RNN/Transformer 用序列建模捕捉语序与上下文，是这个局限的根本突破。
  • 特征是表面的：TF-IDF 只看词的表面形式，good 和 great 是无关的两维（同模块 01 的 one-hot 困境）。词嵌入 + 神经网络 用稠密语义表示，让相似词共享信息——模块 01 正是这个突破的起点。
  • 无法迁移知识：每个分类任务从零训练，学不到通用语言知识。预训练 + 微调（BERT/GPT）让模型先在海量文本上学通用表示，再用少量标注适配具体任务，是范式级的飞跃。
  • 但经典管线没有过时：小数据、需可解释、算力受限、要快速基线时，TF-IDF + 逻辑回归/朴素贝叶斯依然是首选。且无论多先进的模型，评测仍用 P/R/F1、仍需诚实的数据划分——这些纪律永恒。

最后，回望整门课的旅程：我们从把词变成向量（01）出发，学会给序列赋概率（02）、给序列标隐藏标签（03 生成式 / 04 判别式），最后把文档分类并科学评测（05）。这是一条从词到序列到文档、从表示到模型到评测的完整路径——大模型时代之前，整个 NLP 就建立在这些地基之上。

而今天的大模型，本质上是把这些经典思想——分布式表示、序列概率建模、自监督学习、动态规划解码——用更深的网络、更大的数据、更强的算力做到了极致。理解了经典 NLP，你就拥有了一双看穿现代 NLP 本质的眼睛：能分辨真创新与旧瓶新酒，能在合适的场景选择合适的工具，能读懂任何论文的来龙去脉。这，就是把地基夯死的终极回报。

延伸必读（见 ../references.md）：Manning《Introduction to Information Retrieval》（TF-IDF/向量空间/评测的权威）、Wang & Manning 2012（NBSVM，简单基线的强大）、McCallum & Nigam 1998（朴素贝叶斯事件模型）、Jurafsky & Martin《SLP》第 4–5 章（NB 与逻辑回归）。恭喜你读完整门课——你已掌握经典 NLP 的全部地基。带着这双眼睛，去看现代 NLP 吧。
