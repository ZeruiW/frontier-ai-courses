1这门课讲什么

欢迎来到 经典 NLP。这门课只追求一件事：让你从「会调用 NLP 库」变成「会从零写出库里的算法」。

今天提到 NLP，大多数人想到的是 from transformers import AutoModel 然后几行代码跑通一个十亿参数的模型。但在 Transformer、在 BERT、在 word2vec 之前，整个自然语言处理领域已经积累了几十年的智慧——怎么把词变成可以计算的对象？怎么给一句话赋概率？怎么在不知道答案的情况下给每个词标注词性？这些问题的经典答案——分布式表示、n-gram 语言模型、隐马尔可夫模型、条件随机场、TF-IDF——不仅本身优雅，更是理解今天大模型的唯一捷径：现代 NLP 的许多核心概念，不过是这些经典思想在更大算力上的回响。

举几个直接的传承：今天 embedding 层的灵魂，是 1950 年代 Firth 的分布假设；评价 GPT 好坏的困惑度，是 n-gram 时代就定下的标尺；Transformer 注意力里的 softmax 归一化，与 CRF 的配分函数是同一个数学结构；序列模型的前向算法（动态规划在指数空间求和），从 HMM 到 CTC 到今天的结构化预测一脉相承。不懂经典 NLP，你能用大模型，但读不懂它为什么这样设计、什么时候会失效、哪些「新方法」其实是老朋友换了身衣服。

学完你应当能回答这类问题（也是 NLP 岗位的高频面试题）：word2vec 的负采样到底在优化什么目标？为什么词向量能做 king−man+woman 的算术？n-gram 为什么必须平滑，Kneser-Ney 凭什么最好？HMM 的前向算法怎么把指数级求和降到多项式？CRF 和 HMM、和逻辑回归是什么关系？为什么不平衡数据要看 F1 而不是 accuracy？——并且能在 numpy 里把这些算法全部从零实现、用 assert 验证正确。

一句方法论上的话先说在前面：本课坚持纯 numpy 从零、不调任何 NLP 库。因为调库只能让你知道有这么个东西，从零实现才能让你真正理解它——当你亲手写出负采样的梯度、调试前向算法的对数空间数值、让 CRF 的配分函数归一化时，那些藏在 API 背后的设计取舍才会变成你自己的直觉。这种理解不随某个库的版本过时。

2世界观：NLP 的三次范式转移

把整个经典 NLP 放在历史长河里看，它经历了三次范式转移，本课的模块顺序正是沿着这条主线铺开的：

范式核心思想代表方法局限本课模块
符号主义 (1950s–80s)手写规则与词典有限状态机、CFG 文法规则爆炸、脆弱、不可扩展（作为背景）
统计派 (1990s–2000s)从语料数频率、用概率建模n-gram、HMM、CRF、朴素贝叶斯稀疏、特征靠人工02 / 03 / 04 / 05
分布式表示 (2010s–)把词/句嵌入稠密向量空间word2vec、GloVe、神经网络需大数据、可解释性差01（并通向现代）

注意这三次转移有一条贯穿始终的暗线：对「意义」的刻画越来越可计算、可学习、可泛化。符号主义把意义写死在规则里（不可学）；统计派让意义从数据里数出来（可学但稀疏）；分布式表示让意义成为连续空间里可微的向量（可学且可泛化）。今天的大模型站在第三次转移的顶点，但它的损失函数（预测下一个词）、它的评测（困惑度）、它处理序列的方式，处处是前两次转移的遗产。

不是怀旧

一个常见误解需要立刻破除：经典 NLP 不是「过时的、被深度学习取代的东西」。事实上：① 困惑度、交叉熵、P/R/F1 这些评测至今统治着 NLP；② 在数据稀缺、需要可解释、算力受限的场景，朴素贝叶斯/CRF 仍是又快又强的基线（见 references 的 NBSVM）；③ 现代架构里到处是经典思想的影子（embedding=分布假设、attention 归一化≈配分函数、BiLSTM-CRF 直接保留了 CRF 层）。本课的目标不是怀旧，而是把地基夯死——让你站在巨人的肩膀上，看清现代 NLP 的来路与本质。

3课程地图：从词到序列到文档

课程地图：从词到序列到文档

经典 NLP 的核心问题：怎么把语言变成可计算、可学习的对象？ 模块 01 词嵌入 把「词」变成稠密向量（word2vec / GloVe） │ 分布假设：意义 = 上下文 => 向量算术与相似 ▼ 模块 02 n-gram LM 给「词序列」赋概率（马尔可夫 + 平滑 + 困惑度） │ 语言模型的统计起点，KN 平滑解决零概率 ▼ 模块 03 HMM 给序列的每个词标「隐藏标签」（生成式） │ 前向-后向 + Viterbi：动态规划征服指数空间 ▼ 模块 04 CRF 同样标序列，但判别式 + 任意特征（更强） │ 配分函数 + 结构化感知机：HMM 的判别式升级 ▼ 模块 05 NLP 流水线 把「文档」分类（分词→TF-IDF→分类→评测） 一条完整管线，并照见现代 NLP 的来路

这五个模块覆盖了经典 NLP 的三个粒度：词（模块 01：表示）、序列（模块 02–04：语言模型与标注）、文档（模块 05：分类）。它们不是孤立的专题，而有内在的依赖与呼应：模块 03 的前向算法和模块 04 的配分函数是同一个动态规划（求和 vs 取最大）；模块 04 的逻辑回归是模块 05 朴素贝叶斯的判别式对手、又是 CRF 的「无结构」特例；模块 02 的困惑度与模块 05 的 F1 都是评测这件事的不同侧面。读到最后你会看到一张连通的网，而非五块碎片。

每一级台阶都对应一个可独立验证的能力：跑完模块 01 你能从语料训出词向量并验证 king−man+woman 指向 queen 附近；模块 02 你能算出一个语言模型的困惑度、看到平滑如何救活零概率；模块 03 你手写的前向算法会与暴力枚举所有路径的概率逐位相等；模块 04 你的结构化感知机会在 NER 上随训练把 F1 提上去；模块 05 你能跑通一条分词→TF-IDF→分类→F1 的完整管线。每一步都有 assert 兜底，绝不靠「感觉对了」。

4方法论：纯 numpy 从零 + 对拍 + 真实数据

方法论：纯 numpy 从零 + 对拍 + 真实数据

本课的三条工程纪律，决定了你能学到多深：

纪律一：纯 numpy 从零，不调 NLP 库。我们不 import nltk/spacy/gensim/sklearn 的现成模型，而是用 numpy（偶尔纯 Python 的 dict/Counter）把每个算法的数学亲手敲出来。word2vec 不是 gensim.models.Word2Vec 一行调用，而是你自己写前向、写负采样损失、写梯度、写更新；HMM 不是 hmmlearn，而是你自己写对数空间的前向递推与 Viterbi 回溯。代码量不大，但每一行都是理解。

纪律二：对拍（differential testing）。每个算法都和一个绝对可信的参考比对，用 assert 把正确性钉死。怎么确认前向算法对？——和暴力枚举所有隐状态路径的概率和比，必须相等（小规模下可枚举）。怎么确认 Viterbi 对？——它返回的最优路径得分，必须等于把这条路径代入得分函数手算的值。怎么确认平滑对？——所有 n-gram 概率之和必须归一化为 1。这套「先有 ground truth，再写优化实现」的纪律，正是真实算法开发的核心工作流。

直白说

我们把每个经典算法拆成「能在小例子上手算验证」的样子：词表只有几十个词、序列只有几个时间步、状态只有两三个。规模小到你能在纸上跟着算一遍，于是任何 bug 都无所遁形。看懂机制优先于追求性能。

严谨说

严谨地说，对拍的价值在于把「正确性」从主观判断变成可执行的断言。NLP 算法的 bug 常常很隐蔽——一个转置、一个对数底、一个边界条件错了，结果看起来差不多但其实错了。有了暴力参考与归一化检查，assert 会在第一时间抓住偏差，让你的实现可信到能当教学样例。

纪律三：真实数据，联网失败回退内置。玩具数据学不到真东西的「脾气」。本课尽量用真实公开语料：模块 01 用 tiny-shakespeare（莎士比亚文本）学词向量，模块 03/04 用 CoNLL-2003 风格的 NER 语料做序列标注。考虑到本环境可能无网络，每个真实数据胶囊都写成 try: 下载 … except: 回退到内置真实小样本 的形式——下载成功就用完整真实数据，失败则用一段内置的、同样真实的小样本，算法路径完全一致，保证无论有没有网都能跑通、都能学到真实数据的结构。

务必清楚本课不教什么：不教如何调优一个生产级 NLP 系统、不教深度学习框架、不追求 SOTA 分数、不处理超大规模语料的工程。这些是第二步。本课负责把第一步——经典算法的数学与正确实现夯死；这一步搞定，无论你接下来是做研究、用大模型、还是读论文，都会发现自己看得懂底层在发生什么了。

5环境与运行

环境与运行

环境极简：只需 numpy（画图可选 matplotlib，下载真实数据可选 urllib，标准库自带）。全课 CPU 秒级运行，无需 GPU、无需任何 NLP 库。

conda create -n classical-nlp python=3.11 -y && conda activate classical-nlp
pip install numpy            # 必需
pip install matplotlib       # 可选，仅用于画图
jupyter lab

每个模块配一个 notebook，结构统一：先用 numpy 把算法从零实现并验证（5–6 个 worked 小节，每节都跑出可打印的中间量与 assert 自测），再做 3–4 道带 assert 判分的 ✏️ 练习（先给骨架，自己填，再对照 📖 参考答案），最后一个真实数据胶囊（用 tiny-shakespeare / CoNLL 风格真实语料把纸面算法接到现实，联网失败自动回退内置真实样本）。

建议的学习节奏：先读完整章 HTML 建立数学直觉与算法全景，再打开 notebook 亲手实现。读和做缺一不可——只读会觉得「好像懂了」，真正动手写共现矩阵、调对数空间的数值、让前向算法和暴力枚举对上、让 F1 和手算一致时，才会发现魔鬼藏在哪些细节里（负采样的符号、对数下溢、平滑的归一、标签边界）。这门课的深度正是为「动手」服务的。

配套必读（见 references.md）：Jurafsky & Martin《SLP》是全程对照的字典级教材；Mikolov word2vec 两篇、Pennington GloVe 是模块 01 的源头；Kneser-Ney 1995 是模块 02 的平滑核心；Rabiner 1989 HMM 教程是模块 03 的唯一必读；Lafferty 2001 CRF 与 Collins 2002 结构化感知机是模块 04 的依据。

✅ 学完整门课，你应该能：
  1. 解释分布假设，并从零用 numpy 训练 skip-gram＋负采样词向量、验证类比与余弦相似；
  2. 推导 n-gram 的 MLE、说清零概率灾难，实现 Laplace/Good-Turing/Kneser-Ney 平滑并计算困惑度；
  3. 从零实现 HMM 的对数空间前向算法（对拍暴力枚举）与 Viterbi 解码，用它做词性标注；
  4. 讲清生成式 vs 判别式，实现线性链 CRF 的配分函数与结构化感知机，用它做 NER；
  5. 搭一条完整文本分类管线：分词→TF-IDF→朴素贝叶斯/逻辑回归→P/R/F1 评测；
  6. 说清每个经典算法与现代 NLP 的传承关系，判断何时经典方法仍是更优选择。
