1人评不是金标准，它本身要被评测

到这里，前三模块把自动评测的两条腿打牢了：金标本身可能含噪（01）、标注者之间的一致性要会量（02）、自动指标量的到底是什么（03）。但所有自动指标最终都要回答一个问题——它和人类的判断有多接近？于是绕了一圈，我们还是得正面面对最贵、最慢、却被默认为「金标准」的东西：人类评测。

这一模块的核心立场，是要拆掉一个根深蒂固的迷信：人评不是金标准，它本身就是一次测量，因此本身也要被评测。人类评分者会累、会偷懒、会被回答的长度和位置带偏、会用完全不同的内心标尺、会在 1–5 分里只敢打 3 和 4。把「人说好」直接当成「就是好」，等于把一把没校准、还会随心情漂移的尺子供上神坛。本模块教你像对待任何测量仪器一样对待人评：量它的信度（评分者间一致吗）、找它的系统偏置（顺序、长度），并用合适的聚合模型（Bradley-Terry）把一堆嘈杂的人类判断，提炼成一个带置信区间的、可信的排名。

直白说

打个比方：你要给十家餐厅排名，找了一群食客打分。问题来了——有人嘴刁一律打低分，有人逢吃必夸；先上的菜容易占便宜；分量大的看起来更超值。如果你只是把所有人的分一平均，得到的排名混进了食客的脾气和上菜顺序，而非餐厅的真实水平。本模块就是教你把这些杂质一层层剥掉。

严谨说

形式上：一次人评打分 score = 真实质量 + 评分者偏置 + 题目/位置/长度效应 + 随机噪声。我们想估的是真实质量（或对象间真实质量之差），但观测里混了后三项。测量科学的全部手艺，就是用设计（随机化、成对比较）压低某些项的影响，再用模型（去偏、回归、Bradley-Terry）把剩下的系统项扣除，最后用 bootstrap 给结论配一个诚实的误差棒。

一句话定调：人评是一台需要校准的仪器，不是真理本身。你不会盲信一支没校准的温度计，也不该盲信一份没量过信度、没查过偏置、没报过 CI 的人评结论。本模块给你三件工具：成对比较（降方差、抗尺度偏置）、Bradley-Terry（把胜负汇成排名）、偏置诊断与校正（顺序/长度）。

为什么人评值得专门花一个模块？因为它在大模型评测里的地位空前重要，却又最容易被误用。自动指标在开放式生成上越来越力不从心（模块 03 已说透 BLEU 与人评相关会断裂），于是人类偏好成了事实上的终极裁判——RLHF 用它训练奖励模型、Chatbot Arena 用它给全世界的模型排座次、论文用它证明「我们更好」。可正因为它是终极裁判，它的每一个缺陷都会被放大并传导：一个有长度偏置的人评，会训出一个啰嗦的模型；一个信度低的人评，会让排行榜变成抽签。把人评做成一门有设计、有校正、有误差棒的测量，而不是「找一群人投个票」，是这个模块要建立的专业素养。

2Likert 量表：绝对打分的陷阱

Likert 量表：绝对打分的诱惑与陷阱

最直觉的人评是 Likert scale（李克特量表）：让评分者在一个有序等级上给每个对象打绝对分，比如 1–5 的「很差 / 较差 / 一般 / 较好 / 很好」。它的优点很实在——可解释、可对单个对象打分、能直接算平均分。但绝对打分藏着几个系统性陷阱，每一个都会污染你的结论：

陷阱现象后果缓解
尺度差异 scale usage甲的 4 分≈乙的 2 分（内心标尺不同）对象均分混进了评分者脾气评分者去中心化（减各自均值）
天花板/地板 ceiling/floor大家挤在 4–5 分，区分不开好对象之间无法排序改用成对比较、扩展量表
中心趋向 central tendency不敢打极端分，只用中间档方差被压缩、信号变弱强制选择、双向量表
锚点漂移 anchoring看了一串烂的之后，标准悄悄放松分数依赖出现顺序随机化顺序、校准样例

其中最普遍、也最容易被忽视的是尺度差异。两个评分者可能对质量的排序完全一致，却因为一个人天生打分高、一个人天生打分低，让对象的平均分严重偏向「碰巧被宽松评分者评到」的那些。一个简单而有效的修法是评分者去中心化：先减去每个评分者自己所有打分的均值，这样就扣掉了「这个人整体偏高/偏低」的系统成分，只保留他对对象之间的相对判断。notebook 的第一个 worked 会从零实现它，并验证去偏后排名更接近真值。

还有一个比尺度差异更隐蔽的问题：Likert 的等级未必等距。从 4 到 5 的「一步」，和从 2 到 3 的「一步」，在评分者心里可能是完全不同的质量跨度，但你一旦对它们求平均，就默认了它们等距（把有序数据当成了区间数据）。这会让「平均分 4.2 vs 4.0」这种比较的含义变得模糊。严谨的做法要么把 Likert 当有序数据处理（用中位数、有序回归、或模块 05 的 IRT），要么干脆转向成对比较绕开这个假设。记住：一个数字越容易算（求平均），它背后被偷偷假设掉的东西往往越多——这正是测量科学要时时警惕的。

去中心化有个前提常被忘记：每个评分者要评足够多且有重叠的对象，他的均值才估得准、才可比。如果甲只评了 3 个简单题、乙只评了 3 个难题，减各自均值反而会把题目难度的差异错算成评分者偏置。设计阶段就要保证评分任务的交叉重叠——这也是后面成对比较和 Bradley-Terry 隐含的要求。

3成对比较：为什么 Arena 用 PK

成对比较：为什么 Arena 不用打分而用 PK

既然绝对打分这么多坑，现代大模型评测（最著名的是 Chatbot Arena）转向了另一种范式：成对比较（pairwise comparison）——不问「这个回答几分」，而问「A 和 B，哪个更好」。这个看似简单的转变，在测量上有两个深刻的好处：

  • 抗评分者尺度偏置：「A 比 B 好」是一个相对判断，不依赖评分者内心那把尺子的零点和刻度。嘴刁的人和好好先生，只要排序一致，对「谁更好」的回答就一致——尺度差异这个最大的污染源被结构性地消除了。
  • 方差更低：人类辨别「哪个更好」远比给出稳定的绝对分更可靠、更可重复。同一个人重复评，成对判断的一致性通常显著高于绝对打分，意味着每条标注携带的有效信息更多、达到同等结论所需样本更少。

代价当然有：成对比较只给出相对信息，你得把一大堆「A>B、C>A、B>D……」的零散胜负，重新拼成一个全局排名——这正是下一节 Bradley-Terry 要解决的问题。另外，朴素地两两都比一遍是 $O(n^2)$ 的对数，当对象很多时成本高，实践中靠稀疏采样 + 模型外推（只比一部分对、用 Bradley-Terry/Elo 补全）来控制。

还有一类被低估的好处：成对比较天然校准了任务难度。给「这个翻译几分」打绝对分，评分者得在脑子里凭空构建一把绝对标尺，这对没受过训练的人极难、极不稳定；而「这两个翻译哪个好」只需要局部比较，认知负担小得多、判断也快得多。这就是为什么众包成对比较的吞吐和质量常常双双优于绝对打分。但要当心一个反面：当两个对象质量极接近时，成对比较会退化成抛硬币（50/50），贡献的信息趋近于零——这时反而需要更多对局才能分出高下，或者干脆承认它们并列（这也是为什么现代 Arena 模型要显式建模 tie）。

直白说

直白说：与其让每个人凭空给「好不好」打个分（各人标准天差地别），不如让他们做最擅长的事——二选一。人对「哪个更好」的判断又快又稳，剩下的「拼成排名」交给数学。

严谨说

严谨说：成对比较把评分者特异的单调变换（每个人对质量到分数的映射不同）从信号里约掉了。只要评分者对真实质量的内部排序一致，他们的成对偏好就一致，与各自的「打分函数」无关——这是 Arena 选择 pairwise 的统计学根据。

4Bradley-Terry：把胜负拼成排名

Bradley-Terry：把胜负拼成排名

有了一堆成对胜负，怎么得到一个全局排名？Bradley-Terry model（1952）给出了最经典的答案。它给每个对象 $i$ 一个实力分 $s_i$（一个实数），并假设i 战胜 j 的概率只取决于两者实力之差：

\[P(i \succ j) = \sigma(s_i - s_j) = \frac{1}{1 + e^{-(s_i - s_j)}}\]

其中 $\sigma$ 是 logistic / sigmoid 函数。直觉很顺：实力相当（$s_i\approx s_j$）时胜率约 50%；实力差得越多，强者胜率越接近 1。给定所有观测到的成对结果，我们用极大似然（MLE）来估实力分——最大化「在当前 $s$ 下，观测到这些胜负的概率」：

\[\mathcal{L}(s) = \sum_{(i,j,\,y)} \big[\, y\,\log\sigma(s_i-s_j) + (1-y)\,\log\sigma(s_j-s_i) \,\big]\]

这里 $y=1$ 表示 $i$ 赢、$y=0$ 表示 $j$ 赢。这是一个凹的对数似然，可以用梯度上升稳稳地优化到全局最优。有一个必须处理的细节：实力分只在相差意义上可辨识——给所有 $s_i$ 同时加一个常数，所有胜率不变。所以要固定标度：要么钉住 $s_0=0$，要么把 $s$ 整体中心化到均值 0。不固定的话优化会沿着这个自由度乱漂、数值不稳。notebook 的核心 worked 会从已知的真实 $s$ 造数据、再用梯度上升把它估回来，并验证恢复出的排名与真实排名完全一致（实力分本身只能恢复到相差一个常数）。

怎么真正把 $s$ 算出来？最稳的办法是梯度上升。对数似然对 $s_i$ 的梯度有一个干净的形式：$\partial \mathcal{L}/\partial s_i = \sum_{\text{i 参与的对局}} (\text{实际胜负} - \text{预测胜率})$——即「$i$ 实际赢的次数」减去「按当前 $s$ 模型预测它该赢的期望次数」。这个「观测减期望」的残差结构，正是所有指数族 MLE 的共同长相（你在逻辑回归里见过同一个东西）。每步把 $s$ 沿梯度挪一点、再中心化到均值 0 固定标度，几十到几百步就收敛。因为似然是凹的，起点无关紧要、不会陷局部最优——这让 Bradley-Terry 成为少数既有统计原理、又数值友好的聚合方法。

Elo rating 你可能更熟悉——它就是 Bradley-Terry 的在线增量近似：每打一场就把赢家的分往上挪、输家往下挪一点（挪动量正比于「实际胜负 − 预测胜率」，和上面的梯度同源）。Arena 早期用 Elo，但 Elo 对对战顺序敏感（同一批对局换个顺序结果会变），后来多改用一次性对全部数据做 Bradley-Terry MLE（顺序无关、更稳）。两者背后是同一个概率模型。

5偏置：顺序与长度

偏置：顺序与长度，人和 AI 都中招

即便用了成对比较 + Bradley-Terry，还有两个系统性偏置会污染胜负本身，从源头带偏排名。它们对人类评分者和 LLM 评委（judge）都成立，而且后者往往更严重：

偏置机制在 Arena/judge 里的样子对策
顺序/位置偏置倾向于偏好出现在某个位置（如先出现）的选项judge 更常选「第一个」回答，与质量无关左右随机化 + 双向各评一次取平均
长度偏置倾向于认为更长的回答更好更啰嗦的模型胜率虚高（RLHF 著名问题）回归扣除长度、长度匹配对比

顺序偏置的危害在于它是一致方向的：如果每次都让模型 A 排在左边，A 就会系统性地白捡位置红利。解法是设计上的——把左右顺序随机化，最好让每一对都正反各评一次，这样位置效应在平均时相互抵消。如果没法重评，至少要在统计上把位置当成一个协变量估出来、扣掉。notebook 会模拟一个有位置效应的评委，展示朴素估计如何被带偏、随机化+校正后又如何回到真值。

长度偏置更阴险，因为长度和质量本身常常正相关（详细的回答确实常常更好），于是「偏好长回答」和「偏好好回答」纠缠在一起，难以分开。这正是 RLHF 里反复出现的麻烦——模型学会用啰嗦来讨好奖励模型/评委，胜率上去了，真实有用性却未必。处理的思路是把长度当成混杂变量，用回归把胜负里能由长度差解释的部分扣除，看剩下的「质量效应」还剩多少。notebook 会构造一个「质量相同、只是更长」的对照，展示朴素胜率被长度抬高、回归校正后趋近真实（无）效应。

长度偏置之所以是评测里的一道送命题，在于它和真实质量缠在一起、无法靠观测单独拆开。你看到「长回答胜率高」，无法直接判断这是因为长回答真的更好（信息更全），还是因为评委单纯偏爱长（与质量无关的偏置）。要分开，必须制造反事实：要么用回归把胜负里能被长度差解释的部分扣掉、看残余的质量效应（notebook 的做法），要么在数据上构造「内容等价、仅长度不同」的对照对。一个干净的诊断信号是：如果在质量本应相同的成对样本上，长的一方仍系统性胜出，那超出 50% 的部分就是纯长度偏置的量。把这个量估出来并扣除，你报告的胜率才是「质量胜率」而非「啰嗦胜率」。

judge 的隐形偏置

用 LLM-as-judge 做评测时，这些偏置会被放大且沉默：所有用同一个 judge 评出来的对局，共享同一套位置/长度/自我偏好（judge 偏爱与自己风格相近或自家模型的回答）的盲点，而你看不到一个「人类基准」来报警。把 judge 的结论当真之前，务必做位置随机化 + 长度敏感性分析 + 与小规模人评对齐三件事。

6信度与置信区间

信度与置信区间：这个排名稳吗

最后，任何人评结论都必须回答两个测量学问题：评分者之间一致吗（信度），以及这个排名换一批数据还成立吗（CI）。信度太低意味着任务定义或指南有问题——评分者各说各话时，再精巧的聚合也只是在平均噪声。

对连续/有序的人评打分，标准的信度度量是 ICC（组内相关系数，intraclass correlation）：它衡量「同一对象的不同评分者打分」相对于「不同对象之间」的变异有多小。直觉上，ICC = 对象间方差 / (对象间方差 + 评分者噪声方差)——对象之间的真实差异占总变异的比例越高，信度越高。ICC≈1 表示评分者高度一致（分歧远小于对象差异）；ICC≈0 表示评分者打分基本是噪声。（名义/类别标注则回到模块 02 的 κ/α；不同数据类型用不同的信度系数，但精神一致：扣掉碰巧一致、看真实信号占比。）

ICC 还揭示了一条提升人评质量的杠杆：多评分者平均。单个评分者的打分 = 真实质量 + 他的噪声；把 $k$ 个评分者平均，真实质量不变、而噪声方差缩到 $1/k$。于是「$k$ 人平均分」的信度（Spearman-Brown 公式）比单人高得多——这就是为什么 Arena 对每一对收集大量独立判断、而非信赖任何一个人。它和模块 01「多数票压随机噪声」是同一个道理在连续打分上的版本：增加评分者治得了随机噪声（方差），但治不了所有人共有的系统偏置（如长度偏置），后者只能靠设计与校正。

有了信度，还要给最终的数字配置信区间。无论是某个对象的平均分、还是 Bradley-Terry 的实力分、还是模型 A 对 B 的胜率，都是从有限样本估出的，带抽样方差。最通用的做法还是 bootstrap：把评测单元（一条打分、一场对局）有放回地重采样很多次，每次重新算一遍指标（重拟合 Bradley-Terry、重算胜率），这些值的分布就给出了 CI。notebook 会给实力分和胜率都加上 bootstrap CI，并演示一个关键判断：当两个模型的实力分 CI大面积重叠时，它们的排名差异不可信——和模块 01 里「差距要穿透噪声」是同一条纪律。

直白说

直白说：排行榜上第 3 名和第 4 名，如果它们的误差棒糊在一起，那这个「第 3 比第 4 强」就是个幻觉。看排行榜先看误差棒重不重叠，再谈名次。

严谨说

严谨说：bootstrap 通过对评测单元重采样近似估计量的抽样分布，给出无需解析公式的 CI。对 Bradley-Terry 这类需要拟合的指标，每个 bootstrap 样本都要重新拟合，才能把「拟合过程本身的不确定性」也包含进去——这是常见的实现疏漏。

7聚合、众包质控与实践

聚合、众包质控与落到实践

把这些拼成一套可操作的人评流程，并接到你日常的 model evaluation / RLHF 工作：

  1. 能 pairwise 就别 Likert：要排名/比较模型，优先成对比较——抗尺度偏置、方差低；只有需要绝对分（如「是否达标」）时才用 Likert，且务必去中心化。
  2. 设计阶段消偏置：成对比较一律左右随机化、正反各评；控制或记录回答长度，以便事后做长度敏感性分析。
  3. 众包质控：插入attention check（已知答案的陷阱题）、资格题、黄金样例，剔除乱点的标注者；对每对收集多份判断以降方差。
  4. 用 Bradley-Terry 聚合 + 报 CI：把成对胜负拟合成实力分排名，给每个分加 bootstrap CI，排名差异要穿透 CI 才算数。
  5. 量信度：报告评分者间信度（ICC / κ / α）；信度太低先回去改指南，而不是硬聚合。
  6. 人评也要被审计：把人评本身当一次测量——它的偏置、信度、CI 都要写进报告，而不是当成不容置疑的金标准。

还有一个常被忽视的设计维度：评什么、给谁评。同一批输出，让领域专家评、让众包工人评、让 LLM 评，结论可能大相径庭——专家更看专业正确性，众包更看流畅与表面合理，LLM 则带自己那套偏好。这不是谁对谁错，而是它们测的构念不同（回到模块 00 的效度问题）。所以报告人评时，评分者池是谁和结论本身一样重要：一句「人类更偏好我们的模型」，不交代评分者背景、任务指南、聚合方式，是无法被解读、更无法被复现的。把这些写清楚，人评才从「一次投票」变成「一次可检验的测量」。

这套流程的精神和全课一致：把每个评测数字当成一次有误差的测量。人评尤其需要这种警惕，因为它最贵、最被信任，也最容易让人忘记它其实是一群会累、会偏、会各执己见的人给出的嘈杂信号。一个评测科学家与「众包跑分员」的区别，正在于前者会问：这个「人说好」，去掉了评分者脾气吗？随机化了顺序吗？控制了长度吗？报了误差棒吗？

RLHF 的偏好数据，本质就是大规模的成对人评——本模块的每一条（pairwise 降方差、Bradley-Terry 建模、长度偏置、信度）都直接决定了你训出来的奖励模型学到的是真实偏好还是评分者的偏置。学好人评，是学好对齐的前提。

8研究前沿与开放问题

研究前沿与开放问题

人评看似古老，但在大模型时代正经历剧烈重构，几个前沿恰恰最关乎你日常依赖的排行榜是否可信：

  • LLM-as-judge 的偏置与自偏好：用强模型当评委便宜又快，但它有系统性的位置、长度、自我偏好（偏爱自家或与自己风格相近的输出）偏置，且所有评测共享同一套盲点。如何校准 judge、用多 judge 投票、与人评对齐、检测自偏好，是当下最热的方向。
  • Arena 的统计学：从 Elo 到 Bradley-Terry，再到带 tie、带协变量（风格控制）、带主动采样的版本——如何在稀疏、非随机配对、风格混杂下给出无偏且高效的排名，仍在快速演进（Chatbot Arena 的 style-controlled 排名是近期成果）。
  • 人评协议的标准化与可复现：研究反复发现人评结论高度依赖指南、评分者池、聚合方式，换个设置就翻盘。推动人评像实验一样预注册、报告完整协议与信度、可复现，正成为严肃工作的新基线。
  • 分歧即信号：与模块 01/02 呼应——对主观任务，评分者分歧未必是噪声而是真实的偏好多样性，把它建模（而非用多数票抹平）是前沿，尤其在多元价值对齐里。

必读：Bradley & Terry 1952（成对比较奠基）、Chiang 等 2024（Chatbot Arena）、Zheng 等 2023（Judging LLM-as-a-Judge / MT-Bench，系统研究 judge 偏置）、Karpinska 等 2021（众包人评的陷阱）。完整清单见 references.md。
