1这门课讲什么

欢迎来到 评测数据与测量科学。这门课只追求一件事：让你从「会跑评测脚本、会读榜单」变成「会做评测——把它当成一门测量科学来做」。

绝大多数人和模型评测的关系，止于 accuracy = (preds == labels).mean() 和 print(bleu_score)。这门课要往下钻一层：当你报告一个 accuracy=0.873 时，这个数字到底是什么？它是对什么潜在量的一次测量，这次测量带着多大的偏差（金标本身含噪、长度偏置、刷分）、多大的方差（测试集只有几百条）、你有没有给它一个置信区间？换一批标注者、换一个随机种子、多看几天 A/B，这个数字还稳吗？

这些问题的答案不在任何 evaluate.load(...) 的文档里，而在测量科学（measurement science）之中。测量科学有一套用了一百年的成熟语言来回答它们：效度与信度、估计量与被估量、偏差与方差、信度系数、项目反应理论、恰当评分规则、实验设计。本课就是把这套语言搬到 model evaluation 上——把评测的七项核心手艺（标签噪声、标注者一致性、生成指标、人评、IRT、校准、在线实验）一层层从零拆开、亲手用 numpy/pandas 重建。

学完你应当能回答这类问题（也是 RS-Evaluation 岗位的高频问题）：我的金标可信吗？两个标注者「一致」到底该怎么量，为什么不能只看一致率？BLEU/胜率/ECE 各自量了什么、什么时候会骗人？两个模型差 0.5 个点是真本事还是噪声？这个 A/B 我该跑多久、能不能中途停？——并且能在 numpy/pandas 里把这些指标都从零实现、与定义对拍。

一句方法论上的话先说在前面：本课的纪律是从零实现 + 与定义对拍。每一个指标——κ、BLEU、Bradley-Terry、ECE、CUPED——我们都不调库，而是照着原始定义亲手写出来，再用一个可信的参考（要么是定义的另一种算法、要么是 scipy/解析公式、要么是一个精心构造的已知答案）assert 它算对了。为什么这么较真？因为评测的 bug 极其阴险：一个算错的 κ、一个忘了 brevity penalty 的 BLEU、一个偷看了的 A/B，都不会报错，只会悄悄给你一个看起来合理但其实错了的数字，然后这个数字被写进论文、决定模型上线。把指标亲手实现一遍、对拍一遍，是把这类错误扼杀在摇篮里的唯一可靠办法。

2世界观：评测即测量（效度与信度）

贯穿全课的世界观可以浓缩成一句话：你报告的每一个评测数字，都是一次测量；而测量是有理论的。测量科学用两个正交的维度衡量任何测量的质量：

维度问的问题评测里的样子本课在哪打它
效度 validity我测的是不是我想测的？benchmark 分数 ↔ 真实能力；BLEU ↔ 翻译质量；胜率 ↔ 有用性贯穿全课：每个指标都问「它代表了构念吗」
信度 reliability我测得稳不稳、可重复吗？换标注者/种子/测试集，分数还一致吗01 噪声、02 一致性、04 信度、07 方差

直白说

打个比方：一杆秤。效度问的是「它称的是不是重量」（也许它其实对温度敏感，那它再稳也没用）；信度问的是「同一袋米称三次，读数一致吗」。一杆又准又稳的秤才能信。评测同理：一个高效度高信度的分数才配写进结论。

严谨说

形式上，把观测分写成 观测 = 真值 + 系统误差 + 随机误差。系统误差（bias）是效度问题，多采样消不掉，要靠更好的测量设计（去噪、去偏、对齐构念）；随机误差（variance）是信度问题，可靠 CI 与更多数据能压住它。本课的每个模块，都是在诊断并治理这两类误差中的某一种。

估计量 ≠ 真值

最常见、也最致命的评测错误，是把估计量当成被估量——把「我在这 500 条测试集上测得的 87.3%」当成「这个模型的真实准确率就是 87.3%」。它只是一次有限样本的估计，带着抽样方差；500 条上的 87.3% 与 86.1%，其 95% CI 很可能大面积重叠，即「区分不开」。不报告不确定性的评测，等于报告了一个不知精度的数——而不知精度的数无法支撑任何决策。本课处处要求：报分数，就报它的误差棒。

把这条世界观立住，本课每个模块就都有了统一的坐标：模块 01 治理金标里的系统误差（标签噪声）；模块 02 量化标注的信度（一致性）；模块 03 拷问自动指标的效度（它和人评相关吗）；模块 04 治理人评里的系统误差与信度（偏置与 CI）；模块 05 用 IRT 把题目难度与被试能力分开（更高效度的测量）；模块 06 治理概率预测的校准（让置信度说话算数）；模块 07 用统计检验与方差缩减治理线上测量的随机误差。七个模块，一条主线。

3课程地图：从一条标注到可信结论

课程地图：从一条标注到一个可信的结论

评测的生命周期：数据 → 指标 → 人评 → 理论 → 不确定性 → 决策 模块 01 标签噪声 你的金标可信吗？噪声给 accuracy 设的天花板、噪声模型、估计与清洗 │ 「ground truth 往往名不副实——先量它有多脏」 ▼ 模块 02 标注者一致性 两个人「一致」怎么量？观察一致率的陷阱、Cohen/Fleiss κ、Krippendorff α │ 「扣掉碰巧一致，剩下的才是真信号」 ▼ 模块 03 生成指标 BLEU/ROUGE/METEOR/BERTScore 各量了什么？n-gram、LCS、与人评相关、失效 │ 「一个自动分数的价值 = 它与人评的相关」 ▼ 模块 04 人类评测 Likert vs pairwise、顺序/长度偏置、Bradley-Terry 排名、bootstrap CI │ 「人评不是金标准，它本身也要被评测」 ▼ 模块 05 心理测量 IRT 题目难度 b、被试能力 θ、Fisher 信息、自适应测验、用 IRT 设计基准 │ 「把『题有多难』和『模型有多强』分开，才量得准」 ▼ 模块 06 校准 ECE/可靠性图、温度缩放、Brier 分解——让预测概率说话算数 │ 「准确率对了不够，置信度也要诚实」 ▼ 模块 07 在线 A/B 假设检验、功效/样本量、多重比较、序贯检验、CUPED 方差缩减 「把『这点差别是真本事还是抽样波动』算清楚，再下结论」

这不是松散的专题集合，而是一条评测数据流：原始标注（01–02）→ 把标注/输出压成分数（03 自动、04 人评）→ 用测量理论让分数更可信（05 IRT、06 校准）→ 把分数变成线上的可信决策（07）。每一站都在处理「从带噪的人类判断，到一个值得相信的数字」这条链上的一环。

每一级台阶都对应一个可独立验证的能力：跑完模块 01 你能从混淆估计噪声率、并算出它给 accuracy 设的天花板；模块 02 你手写的 κ/α 会与定义/参考逐位对上；模块 03 你的 BLEU 会复现论文数值、ROUGE-L 的 LCS 会与动态规划对拍；模块 04 你的 Bradley-Terry MLE 会收敛到正确排名、bootstrap CI 会覆盖真值；模块 05 你的 2PL 拟合会恢复出造数据时的真参数；模块 06 你的温度缩放会把 ECE 显著降下来；模块 07 你的 t/z 检验会与 scipy 对上、CUPED 会无偏地缩小方差。每一步都有 assert 兜底。

4方法论：从零实现 + 对拍 + 真实数据胶囊

方法论：从零实现 + 对拍 + 真实数据胶囊

本课每个 notebook 的结构都一样，对应三种学习活动：

  1. worked 小节（看懂机制）：先讲清一个指标的定义与动机，再用 numpy/pandas 从零把它实现出来，跑出可打印的验证并 assert 它算对了。不是调库，是亲手造轮子。
  2. ✏️ 练习（自己动手）：给一个带 TODO 的骨架，你来填核心逻辑，紧跟一个 assert 自测当场判分；做不出来再看 📖 参考答案。
  3. 🧪 真实数据胶囊（接到现实）：把方法用到真实公开数据上（联网下载真实标注/语料/作答；失败则回退到内置的真实数值），看它在真实数据上是什么样。

为什么把对拍（differential testing）提到方法论的高度？因为评测代码的正确性没有外部裁判——你算出的 κ=0.62，没人会告诉你它对不对。所以我们自己造裁判：要么用定义的另一种等价算法互相验证（如 κ 既按公式算、也按混淆矩阵算，两者必须相等），要么用一个已知答案的小例子（手工能算出 κ 的 2×2 表），要么用 scipy/解析公式 当对照（如 t 检验对拍 scipy.stats.ttest_ind）。凡是能对拍的地方，本课都对拍——这正是真实评测研究里建立可信度的工作流。

直白说

我们把每个评测概念翻译成 numpy/pandas 里看得见摸得着的东西：噪声是一个转移矩阵，一致性是几个计数相除，BLEU 是 n-gram 计数的几何平均，Bradley-Terry 是一次梯度上升，IRT 是一次联合 MLE，校准是分箱后比较两条曲线，A/B 是一个两样本检验。你写的是机制，不是性能。

严谨说

关键纪律是可复现的随机性与断言式验证：所有随机都用 np.random.default_rng(seed) 固定，所有「应该成立的性质」都写成 assert（如「完美校准的 ECE≈0」「t 检验与 scipy 一致」「2PL 恢复真参数」）。断言通过 = 你的实现与定义一致 = 你算的那个数字可信。

务必清楚本课不教什么：不教某个评测库的 API、不追最新榜单、不做大规模 GPU 推理。这些是工具，而本课负责的是工具背后的测量原理与正确性——懂了原理，换任何库（evaluate、lm-eval-harness、自研 pipeline）你都知道它在算什么、什么时候会算错。本课用纯 numpy/pandas、玩具规模，就是为了让机制无处藏身。

5环境与运行

环境与运行

环境极简：只需 numpy 与 pandas（个别对拍可选 scipy，画图可选 matplotlib）。全课 CPU 秒级运行，无需 GPU。

conda create -n eval-measurement python=3.11 -y && conda activate eval-measurement
pip install numpy pandas        # 必需
pip install scipy matplotlib    # 可选：scipy 用于个别对拍，matplotlib 用于画图
jupyter lab

每个模块的 notebook 里都有一个统一的真实数据下载 helper（hf_rows 走 HuggingFace datasets-server REST、_get 带本地缓存）。它把真实公开数据按需取来；一旦联网失败，每个胶囊都会 try/except 回退到内置的真实数值，保证你即使离线也能跑通全部 worked/练习/答案/自测，assert 一个都不会因为没网而失败。数据缓存在 ~/.eval_measurement_data/。

建议的学习节奏：先读完整章 HTML 把概念当测量问题想清楚，再打开 notebook 亲手实现。读和做缺一不可——只读会觉得「κ 不就是个公式」，真正动手写、调维度、让 assert 通过时，才会撞见魔鬼藏身的细节（边缘分布怎么算、brevity penalty 何时触发、温度往哪个方向调、CUPED 的 θ 怎么估）。这门课的深度正是为「动手」服务的。

配套先读：Jacobs & Wallach《Measurement and Fairness》建立「评测=测量」的世界观；Artstein & Poesio（IAA 权威综述）、Guo 2017（校准）、Kohavi 2020（A/B 实战）是各模块的主参考。完整清单见 references.md。

✅ 学完整门课，你应该能：
  1. 把任何评测分数看成「带偏差与方差的估计量」，并给它一个 bootstrap 置信区间；
  2. 从混淆估计标签噪声率、算出它给 accuracy 设的天花板、并据此校正与清洗；
  3. 从零实现 Cohen κ / Fleiss κ / Krippendorff α，并识别 prevalence/kappa 悖论；
  4. 从零实现 BLEU / ROUGE-N / ROUGE-L(LCS) / BERTScore，并判断一个自动指标何时会骗人；
  5. 用 Bradley-Terry MLE 把成对人评汇成排名，并校正顺序/长度偏置、给排名加 CI；
  6. 用 2PL IRT 联合 MLE 同时估计题目难度/区分度与模型能力，用 Fisher 信息选题；
  7. 用 ECE/可靠性图诊断校准、用温度缩放修复过度自信、用 Brier 分解定位弱点；
  8. 设计一个有功效的 A/B 实验：算样本量、控多重比较、做序贯检验、用 CUPED 缩方差。
