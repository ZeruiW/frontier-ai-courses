1从作答矩阵到能力：CTT 的纠缠

到这一步，你已经会量数据有多脏（01）、标注者多一致（02）、自动指标量了什么（03）、人评怎么做才可信（04）。但所有这些，最后都汇成一张作答矩阵：行是被试（在 LLM 评测里就是一个个模型），列是题目（一道道测试样本），格子里是「这个模型这道题答对了没」（0/1）。怎么从这张 0/1 矩阵里，量出一个模型「有多强」？这正是心理测量学（psychometrics）研究了一百年的问题。

最朴素的做法是数对了几题——这就是classical test theory（经典测验理论，CTT）的核心：用原始正确率当能力、用每题答对率当难度、用题总相关当区分度。它简单到几乎不需要解释，也是今天绝大多数 benchmark 报告分数的方式。但 CTT 有一个致命的纠缠：题目的难度和被试的能力，被搅在了同一个数字里。

直白说

打个比方：两个学生考了不同的卷子，一个考了 80 分、一个考了 70 分，你能说前者更强吗？不能——也许 80 分那张卷子简单得多。原始分同时反映了「人有多强」和「卷子有多难」，二者无法分离。在 LLM 评测里这天天发生：两个模型在不同子集、不同难度的题上刷分，原始正确率根本不可比。

严谨说

形式上：CTT 把观测分写成 X = T + E（真分 + 误差），但真分 T 是「针对这套题」的——换一套题，同一个人的真分就变了。题目难度（答对率 $p$）也依赖于来考的是哪批人——让学霸来考，每题答对率都高，题目显得简单。能力与难度互相依赖、无法独立估计，这叫sample/test dependence，是 CTT 最根本的局限。

一句话定调本模块：把「题有多难」和「模型有多强」拆成两组独立的参数，再用一条概率曲线把它们连起来。这就是 item response theory（IRT，项目反应理论）的全部野心。拆开之后，能力估计不再依赖具体考了哪套题，题目分析也不再依赖来考的是哪批模型——这对要公平比较模型、设计高效基准、识别坏题的评测科学家，是一件趁手到不可替代的兵器。

为什么一个评测科学家应该认真对待这套上世纪的心理测量理论？因为大模型评测正在重演教育测量走过的路。当年心理学家面对的问题——不同的人考不同的卷子，分数怎么比？哪些题是好题、哪些在浪费考试时间？怎么用最少的题最快地测准一个人？——几乎逐字对应今天的：不同模型在重叠但不完全相同的基准上刷分怎么比？一个上万题的 benchmark 里哪些样本真的在区分模型、哪些是所有模型同对同错的废题？怎么从海量评测样本里挑出一个小而精的子集，省下绝大部分推理成本却几乎不损失排名信息？这些问题 IRT 在半个世纪前就给出了原则性的答案，而 model evaluation 社区（Lalor、Vania、Rodriguez 等）近年才开始系统地把它搬过来。学会它，你就站在了这条迁移的前沿。

2IRT 核心：一条曲线连接能力与难度

IRT 的核心思想：一条曲线连接能力与难度

IRT 的出发点是一个简单的概率断言：一个被试答对一道题的概率，只取决于「他的能力」和「这道题的参数」两件事，并且这个概率随能力单调上升——能力越强，答对越难的题的把握越大。把这个关系画出来，就是一条 S 形曲线，叫 item characteristic curve（ICC，题目特征曲线）：

P(答对) 1.0 | _____------ | _-/ | _/ <- 这道题的 ICC（一条 S 形曲线） 0.5 |............ / <--- 拐点在 θ = b（难度）：能力=难度时恰好 50% 答对 | _ / : | __--/ : 0.0 |__-/________:_________________________ 能力 θ 低 b（难度） 高 斜率 ∝ a（区分度）：越陡，越能区分 b 附近的能力差异

这条曲线的形状由题目参数决定，横轴位置由被试能力决定，两者各管一摊、互不污染——这就是 IRT 解开 CTT 纠缠的方式。曲线左右平移由难度 $b$ 控制（题越难，曲线越靠右，要更高能力才到 50%）；曲线陡峭程度由区分度 $a$ 控制（越陡，能力略高于/低于 $b$ 的人答对率差异越大）。本模块就从最简的 1PL（只有难度）讲到 2PL（难度 + 区分度），再讲怎么从作答矩阵把这些参数全估出来。

注意 IRT 的能力 $\theta$ 与难度 $b$ 活在同一个量尺上（都是实数，常标准化到均值 0、标准差 1），这是它的精髓：能力和难度可以直接比大小。$\theta > b$ 意味着这个被试在这道题上「赢面过半」。但这个量尺本身是没有绝对零点的——它只能确定到一个平移和缩放（见第 5 节的可辨识性），所以谈 IRT 参数时永远要记得：能比相对高低，不能比绝对数值。

3Rasch / 1PL：最简模型

Rasch / 1PL：最简的项目反应模型

最简单的 IRT 模型是 Rasch model（也叫 1PL，单参数逻辑斯蒂模型）。它假设所有题的区分度都一样，只有难度不同，于是答对概率是：

\[P(\text{答对} \mid \theta, b) = \sigma(\theta - b) = \frac{1}{1 + e^{-(\theta - b)}}\]

读法：被试能力 $\theta$ 减去题目难度 $b$，过一个 sigmoid。当 $\theta = b$，概率恰好 0.5——难度 $b$ 就是「答对率刚好 50% 所需的能力」。$\theta$ 比 $b$ 高 1 个单位，答对概率约 0.73；高 2 个单位，约 0.88。这条曲线对所有题平行（同样陡峭），只是左右位置不同。

直白说

Rasch 模型简单得近乎天真，但它有一个让心理测量学家着迷的性质：谁更强、和拿哪些题来比无关；哪题更难、和拿哪些人来考无关。这叫特定客观性——比较两个被试的能力差，不依赖具体用了哪些题（题的难度项会消掉）。这正是 CTT 给不了的。

严谨说

严谨说：Rasch 下，被试答对总数是其能力的充分统计量（sufficient statistic）——知道一个人答对了几题，就足以估其能力，不必看答对的是哪几题。这个优雅性质让 Rasch 在教育测量里有近乎信仰般的地位（有人坚持「数据要服从 Rasch，而非用更复杂模型去拟合数据」）。代价是它的强假设：所有题等区分度。现实里常不成立，于是有了 2PL。

在 LLM 评测的语境下，Rasch 已经能做一件有用的事：把「模型答对总数」从一个绝对分翻译成一个量尺上的能力位置。两个模型即便做的题集部分不同，只要题目难度已知，它们的 $\theta$ 就可比——这是用 IRT 做跨题集模型比较的起点。

值得停下来体会 Rasch「充分统计量」性质有多反直觉、又多有用。它说的是：在 Rasch 假设下，答对 7 题这件事，比「答对的是哪 7 题」携带的能力信息更多吗？——答案是一样多，知道总分就够了，答对的具体是哪几题不提供额外的能力信息。这正是「所有题等区分度」的直接后果：每道题对能力的「证词」权重相同，所以只需数票数。一旦区分度不等（2PL），这个优雅性质就破了——这时答对一道高区分度的难题，比答对一道谁都会的简单题，能更强地证明你的能力。于是 2PL 下「答对哪些题」比「答对几题」更有信息，原始总分不再是充分统计量——这恰恰是为什么 IRT 的 $\theta$ 能比原始正确率更有效度地度量能力。

42PL：加入区分度 a

2PL：加入区分度 a

Rasch 假设所有题一样陡，但现实里题目质量参差：有的题一问就能分出高下（能力稍高就明显更容易答对），有的题好坏通吃（能力高低答对率差不多，区分不了人）。把这个「陡峭程度」也参数化，就得到 2PL model（双参数逻辑斯蒂模型）：

\[P(\text{答对} \mid \theta, a, b) = \sigma\!\big(a\,(\theta - b)\big) = \frac{1}{1 + e^{-a(\theta - b)}}\]

多出来的 $a$ 是区分度（discrimination）：它是 ICC 在拐点 $\theta = b$ 处的斜率。$a$ 大 → 曲线陡 → 能力跨过 $b$ 时答对率骤升，这道题能敏锐地把能力略高于 $b$ 和略低于 $b$ 的人分开；$a$ 小 → 曲线平 → 这道题对区分能力几乎没用（甚至 $a<0$ 的题是「坏题」：能力越高反而越容易答错，多半是题目有问题或标签错了）。

参数符号几何意义在评测里的含义
难度 difficulty$b$ICC 左右位置（拐点横坐标）这道题要多强的模型才有 50% 把握答对
区分度 discrimination$a$ICC 在拐点的斜率（陡峭度）这道题区分强弱模型的能力；$a$ 小或负 = 坏题
能力 ability$\theta$被试在量尺上的横坐标这个模型的潜在能力位置

负区分度的题尤其值得警惕，因为它是自动发现坏题/错标的强信号。如果拟合出某道题的 $a < 0$，意味着能力越强的被试反而越容易答错它——这在一个良定义的题上几乎不可能，最可能的解释是：这道题的标准答案错了（强模型给出了正确答案却被判错），或题目本身有歧义、有陷阱、考的根本不是目标构念。回想模块 01 的标签噪声：负区分度正是 IRT 给出的、不需要干净子集的「疑似错标探测器」。这把模块 01 与模块 05 接上了——低/负区分度的题 = 该送去人工复核的候选，与置信学习的错标名单异曲同工，只是 IRT 用的是「题与能力的关系」而非「模型预测与标签的关系」。

把区分度 $a$ 当成「这道题的信噪比」。高 $a$ 的题像一把锋利的尺子，能量出细微的能力差；低 $a$ 的题像一把刻度模糊的尺子，量谁都差不多。评测科学家用 IRT 的一大动机，就是揪出基准里那些低区分度的「钝尺子」题——它们占着样本量却不提供区分信息，删掉它们能让基准更高效（第 7 节）。

5拟合：联合 MLE 估计参数

拟合：从作答矩阵联合估计所有参数

理论很美，但参数 $\theta, a, b$ 我们一个都不知道——只看得到一张 0/1 作答矩阵 $Y$（$Y_{pi}=1$ 表示被试 $p$ 答对题 $i$）。拟合 IRT，就是从 $Y$ 反推出所有被试的能力和所有题目的参数。最直接的办法是联合极大似然（joint MLE）：把全体 $\theta_p$ 与全体 $(a_i, b_i)$ 当作未知数，一起最大化对数似然：

\[\ell(\theta, a, b) = \sum_{p}\sum_{i} \Big[ Y_{pi}\log P_{pi} + (1 - Y_{pi})\log(1 - P_{pi})\Big],\quad P_{pi} = \sigma\!\big(a_i(\theta_p - b_i)\big)\]

这是一个光滑的优化问题，可以直接梯度上升：对每个 $\theta_p$、每个 $a_i$、每个 $b_i$ 求偏导，沿梯度走即可。notebook 会从零把这个联合 MLE 写出来（梯度上升，几千步），并验证它能从一份已知真参数生成的作答矩阵里，把难度、区分度、能力都恢复出来。

有一个实现上的细节，初学者几乎一定会踩，值得提前点破：不同类型参数的梯度量级天差地别。能力 $\theta_p$ 的梯度是对所有题求和（比如 50 项），而难度 $b_i$ 的梯度是对所有被试求和（比如 400 项）——后者的原始量级比前者大近一个数量级。若用同一个学习率对所有参数做sum 梯度上升，难度会被推得飞快、能力却几乎不动，优化彻底失衡。解法很简单但关键：把每类梯度都改成均值（除以求和的项数），让三类参数的更新步幅可比。notebook 的 fit_2pl_joint 正是这么做的，这也是它能稳定恢复参数、而朴素 sum 版会发散的原因——一个看似不起眼、却决定成败的工程点。

直白说

直白说：我们手里只有「谁答对了哪题」，要倒推出「每个人多强、每道题多难多利」。这像解一个巨大的拼图——用「强的人答对难题」「难题被答对得少」这些约束，把所有参数同时拧到最自洽的位置。梯度上升就是一点点拧的过程。

严谨说

严谨说：联合 MLE 简单但有偏（参数数量随被试与题目数一起涨，是所谓 incidental parameters 问题），题目参数的估计在被试数有限时不一致。更标准的做法是marginal MLE：把被试能力 $\theta$ 当作来自某分布（如标准正态）的随机量、对它积分掉，只估题目参数，再回过头估能力（EM 算法）。本模块用联合 MLE 是为了看清机制——它的梯度透明、一眼能懂；生产中估题库参数则多用边缘 MLE。

只能比相对，不能比绝对

IRT 参数有内在的可辨识性限制：能力量尺只能确定到一个平移和缩放。把所有 $\theta$ 和 $b$ 同时加 5、或所有 $\theta,b$ 缩放同时把 $a$ 反向缩放，似然完全不变。所以拟合时必须固定量尺（常把 $\theta$ 标准化到均值 0、方差 1），否则优化会漂移。评估恢复得好不好，也只能比标准化后的相关（参数向量 z-score 后求相关），绝不能比绝对数值——这是 notebook 里所有恢复 assert 都先标准化再比相关的原因。

6Fisher 信息：题在哪里最有用

Fisher 信息：一道题在哪里最有用

拟合出参数后，一个评测科学家最关心的问题是：这道题对「测准能力」到底贡献多少？而且是在能力的哪个区间贡献最大？答案是 Fisher information（费舍尔信息）。对 2PL 题，它有一个干净的闭式：

\[I_i(\theta) = a_i^2\, P_i(\theta)\,\big(1 - P_i(\theta)\big)\]

两个洞察藏在这条公式里。其一，信息在 $\theta = b_i$ 处最大（此时 $P=0.5$，$P(1-P)$ 取到峰值 0.25）——一道题对「难度恰好等于其难度的被试」最有信息量，对能力远高或远低于 $b$ 的人几乎没用（他们的答对结果几乎确定，没什么可学的）。其二，信息正比于 $a^2$——区分度越高，信息越多，且翻倍区分度信息翻四倍。这量化了上一节「高 $a$ 题是锋利尺子」的直觉。

整份测验的信息是各题信息之和（题目作答条件独立），而能力估计的测量标准误（SEM）正是测验信息平方根的倒数：

\[I_{\text{test}}(\theta) = \sum_i I_i(\theta), \qquad \mathrm{SEM}(\theta) = \frac{1}{\sqrt{I_{\text{test}}(\theta)}}\]

直白说

直白说：想把某个能力档的被试测准，就多上几道难度卡在那个档、且区分度高的题。信息越多，能力估计的误差棒越窄。这把「该出什么题」从拍脑袋变成了可计算的优化：缺哪个能力区间的精度，就补哪个区间的高信息题。

严谨说

严谨说：在 MLE 渐近理论下，能力估计 $\hat\theta$ 的方差约为 $1/I_{\text{test}}(\theta)$（Cramér-Rao 下界）。于是 SEM 直接告诉你能力估计的精度，且它随能力变化——一份题难度都集中在中等的测验，对中等能力者测得准、对极强极弱者测不准。notebook 会算出 2PL 题的信息曲线、验证它在 $\theta=b$ 处最大，并用信息之和算 SEM。

Fisher 信息是连接「IRT 理论」与「评测实践」的枢纽。它把自适应测验（下一节）和高效基准设计都变成了同一句话：在你最不确定的能力区间，挑信息量最大的题来问。记住这条，第 7 节的所有应用都是它的推论。

7自适应测验与用 IRT 设计基准

应用：自适应测验与用 IRT 设计基准

有了信息函数，两个强大的应用自然浮现。第一是 computerized adaptive testing（CAT，自适应测验）：不固定题目，而是根据被试当前的能力估计，动态挑下一道最有信息量的题。流程是一个闭环：估当前能力 → 选在该能力处信息最大的题 → 被试作答 → 更新能力估计 → 重复。GRE、GMAT 等考试就是这么做的——它能用少得多的题达到和固定长卷同等的测量精度。

自适应测验（CAT）的闭环： ┌─> 用已答题估当前能力 θ̂ │ │ │ ▼ │ 在 θ̂ 处选 Fisher 信息最大的下一题（信息聚焦在「你正卡着的能力档」） │ │ │ ▼ │ 被试作答 (0/1) ──> 更新 θ̂、SEM 缩小 └────────┘ 直到 SEM 够小（精度达标）就停 —— 比固定长卷省一大半题

第二个应用直击评测科学家的痛点：用 IRT 分析和设计基准。把模型当被试、测试样本当题目，对一个 benchmark 的作答矩阵拟合 IRT，你能做三件 CTT 做不到的事：

  • 识别坏题：区分度 $a$ 很低（甚至为负）的样本，对区分模型毫无用处——它们要么太简单/太难（所有模型同对同错），要么标签有问题。Vania 等 2021 正是用 IRT 给 NLP 基准的题「体检」。
  • 用能力而非原始分比模型：原始正确率把所有题等权重相加，被大量低区分度的简单题稀释；IRT 的 $\theta$ 按题目信息加权，是更有效度的能力度量。
  • 造更高效的基准：既然题目信息差异巨大，Rodriguez 等 2021 发现少量高信息题就能逼近用全集得到的模型排名。这意味着可以把一个上万题的基准瘦身到几百题，省下绝大部分推理成本而几乎不损失区分力——这正是自适应思想用在「评模型」而非「评人」上。

把这套思想落成一个评测科学家的操作配方：① 收集一张模型 × 样本的 0/1 作答矩阵（你跑基准时本就有）；② 对它拟合 2PL，得到每题的 $(a_i, b_i)$ 与每个模型的 $\theta$；③ 用区分度 $a$ 做题目体检——$a$ 低的题标记为「区分力弱」、$a$ 为负的题送人工复核疑似错标（接模块 01）；④ 用 Fisher 信息给题目排序，保留信息量最大的前若干道、构造一个瘦身基准，并验证它给出的模型排名与全集排名的相关足够高；⑤ 报告模型能力时给 $\theta$ 配一个由测验信息算出的 SEM 误差棒（呼应全课「每个分数都要带不确定性」的纪律）。这套流程把「评测」从「数对了几题」升级成「在一个有理论支撑的量尺上、带误差棒地、用经过体检的题来测量能力」——这正是测量科学相对于跑分脚本的全部价值。

把 IRT 搬到 LLM 评测有几个水土不服要当心：被试不是人而是模型，「能力」是否是一个良定义的单维构念存疑（模型可能在不同技能上强弱悬殊，需多维 IRT）；模型作答可能高度相关（同源模型、同样的预训练语料），违反 IRT 的局部独立假设；题目「难度」也可能随提示词、few-shot 等剧烈变化。IRT 是强力的镜头，但用前要先问：我的作答矩阵满足它的假设吗？

8研究前沿与开放问题

研究前沿与开放问题

IRT 是一门成熟学科，但把它用到大模型评测上，几乎每个角落都是活跃的前沿：

  • IRT 驱动的高效/自适应基准：Lalor 等 2016 用 IRT 构建评测量尺、Vania 等 2021 用它比较测试集与识别坏题、Rodriguez 等 2021 证明样本信息量差异巨大、少量高信息题即可复现排名。把自适应测验用于选题评模型，是降低评测成本的前沿方向。
  • 多维 IRT（MIRT）：单维 $\theta$ 假设模型能力是一根轴，但「推理、知识、代码、安全」显然不是一回事。多维 IRT 把能力建成向量，能刻画模型的能力剖面，但参数更多、更难辨识。
  • 3PL 与猜测参数：选择题里能力极低者也能蒙对，3PL 加一个下渐近 $c$（如四选一 $c\approx0.25$）建模这个下限。LLM 在多选基准上的「瞎蒙基线」正对应它。
  • 题目-被试之外的协变量：把提示词、few-shot 数、温度等也纳入模型（解释性 IRT / 混合效应），刻画「同一题在不同评测配置下难度如何变」，是连接 IRT 与 LLM 评测工程现实的桥。
  • 作答相关与局部独立的破裂：同源模型的错误高度相关，违反 IRT 的核心假设。如何在被试（模型）非独立时做稳健的能力估计，仍是开放问题。
