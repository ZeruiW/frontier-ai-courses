# 术语词典 · Glossary（评测数据与测量科学）

> 按主题分组，每条 2–3 句释义。读评测/测量/心理测量/实验设计的论文遇到生词回这里查；英文术语保留原文（社区通用语言）。本课把评测当成一门测量科学，下列术语既是统计/心理测量的标准概念，也对应 model evaluation 的日常实践。

## 测量科学基础 · Measurement Science

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| measurement | 测量 | 按一套规则给现象赋数。本课的核心立场：模型评测就是测量——你报告的每个分数都是对某个潜在量（能力、质量、偏好）的一次有误差的观测。 |
| validity | 效度 | 你测的是不是你想测的东西（构念）。一个 benchmark 分数高，未必代表真实能力强（可能测到了表面相关、数据泄漏、刷分）。效度是评测的第一性问题。 |
| construct / construct validity | 构念 / 构念效度 | 你真正想测的抽象属性（如「推理能力」「有用性」）及测量工具对它的代表程度。构念与指标的鸿沟是一切评测争议的根源。 |
| reliability | 信度 | 测量的稳定性/可重复性：同样的东西测两次结果一致吗。信度低则分数充满噪声；信度是效度的必要不充分条件（不稳的测量不可能准）。 |
| estimator / estimand | 估计量 / 被估量 | 估计量是你从数据算出的统计量（如样本 accuracy）；被估量是它想逼近的真值（如总体 accuracy）。混淆两者是评测最常见的认识论错误。 |
| bias (statistical) | 偏差 | 估计量期望与真值之差。系统性地偏高或偏低（如含噪标签压低 accuracy、长度偏置抬高某模型胜率），多采样也消不掉。 |
| variance | 方差 | 估计量在重复测量下的波动。小测试集、少标注者、少 A/B 流量都会放大方差，让偶然差异看起来像真实差异。 |
| confidence interval (CI) | 置信区间 | 一个随机区间，在重复实验中以指定概率（如 95%）覆盖真值。报告分数不报 CI，等于报了一个不知精度的数。本课处处要求给 CI。 |
| bootstrap | 自助法 | 用「有放回重采样」从单一样本近似估计量的抽样分布，从而不靠解析公式就能算标准误与 CI。评测里给任何指标加误差棒的瑞士军刀。 |
| effect size | 效应量 | 差异的实质大小（而非仅仅是否显著），如两模型 accuracy 之差、Cohen's d。大样本下微小且无意义的差异也能「显著」，故必须看效应量。 |

## 标注与标签噪声 · Annotation & Label Noise

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| annotation / labeling | 标注 | 由人（或模型）给样本赋予标签的过程，是监督数据与多数评测金标的来源。标注的质量直接决定评测的天花板。 |
| gold label / ground truth | 金标 / 真值 | 被当作正确答案的标签。关键认知：金标常常本身含噪、有争议、甚至没有唯一正确答案，「ground truth」往往名不副实。 |
| label noise | 标签噪声 | 标注与真实类别的偏差。它给评测设了天花板：用含噪金标，连完美模型也会被判错，测得的 accuracy ≤ 1 − 噪声率（对称噪声下近似）。 |
| symmetric / uniform noise | 对称噪声 | 每个真标签以相同概率被均匀翻成其它任一类。最简单的噪声模型，便于推导但常不现实（真实错误通常有方向）。 |
| class-conditional noise | 类条件噪声 | 翻转概率依赖真实类别（如「中性」常被误标成「负面」，反之少）。由一个噪声转移矩阵 T（行=真类、列=观测类）刻画，比对称噪声真实得多。 |
| noise transition matrix T | 噪声转移矩阵 | T[i,j] = P(观测=j｜真实=i) 的方阵。把干净分布与混淆联系起来：观测混淆 = T 作用于真实分布；估计 T 是去噪与校正的核心。 |
| instance-dependent noise | 样本相关噪声 | 翻转概率还依赖样本特征本身（难例更易错标）。最现实也最难处理的噪声，类条件假设在此失效。 |
| majority vote | 多数票 | 多个标注者对同一样本取多数作为聚合标签，降低随机方差。但消不掉所有标注者共有的系统性偏置。 |
| adjudication | 裁决 | 对标注者分歧的样本由专家或讨论裁定最终标签。比多数票更贵但更可信，常用于构建高质量评测集。 |
| soft label / label distribution | 软标签 / 标签分布 | 不强制唯一答案，而用各标注者投票比例作为标签分布。承认「人本就有合理分歧」，对主观任务（毒性、自然语言推理）尤其重要。 |
| annotator disagreement | 标注者分歧 | 标注者之间的不一致。它不总是噪声——有时反映任务本身的主观性或歧义，应区分「该消除的错误」与「该保留的合理分歧」。 |
| confident learning | 置信学习 | 用模型预测概率与给定标签的联合分布估计噪声、定位疑似错标样本的一类方法（Northcutt 等）。本课用其思想做噪声率估计与清洗。 |

## 标注者一致性 · Inter-Annotator Agreement (IAA)

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| observed agreement (p_o) | 观察一致率 | 两标注者标注相同的比例。直观但有致命缺陷：不扣除「碰巧一致」，在类别不平衡时会虚高，故不能单独作为一致性指标。 |
| chance agreement (p_e) | 期望一致率 | 若标注者各自按其边缘分布随机标注、纯靠运气会达到的一致率。chance-corrected 系数的核心就是把它扣掉。 |
| chance-corrected agreement | 偶然校正一致 | 形如 (p_o − p_e)/(1 − p_e) 的一致性度量：扣掉碰巧一致、再对「可改进空间」归一。κ 系列与 α 都是这个框架的实例。 |
| Cohen's kappa (κ) | 科恩 κ | 两个固定标注者的偶然校正一致系数，p_e 由两人各自的边缘分布算得。范围常在 [−1,1]，1=完美、0=仅达随机水平。 |
| Fleiss' kappa | 弗莱斯 κ | 把 κ 推广到「每条目由若干标注者标、标注者可不同」的场景，用所有标注的整体边缘分布算 p_e。注意它并非 Cohen κ 的简单多人版。 |
| weighted kappa | 加权 κ | 给不同程度的分歧赋不同惩罚（如有序量表上差 1 级比差 3 级轻）。用权重矩阵实现，等价于在有序/区间数据上的特定 α。 |
| Krippendorff's alpha (α) | 克里彭多夫 α | 最通用的一致性系数：α = 1 − D_o/D_e（观测不一致 ÷ 期望不一致），支持任意标注者数、缺失数据、名义/有序/区间/比率多种度量。本课推荐的默认 IAA。 |
| nominal / ordinal / interval metric | 名义 / 有序 / 区间度量 | α 中定义「两标签差多远」的距离函数：名义（相同=0 否则=1）、有序（按秩距离）、区间（差的平方）。选错度量会得到误导性的 α。 |
| prevalence / kappa paradox | 流行率 / κ 悖论 | 当某一类别极端常见（高 prevalence）时，即使观察一致率很高，κ 也可能很低甚至为负。提醒：κ 必须连同边缘分布一起解读，不能只看一个数。 |
| coincidence matrix | 重合矩阵 | Krippendorff α 的计算基础：统计所有「可配对的标注值对」的共现次数，由它同时算出 D_o 与 D_e。 |
| agreement benchmark | 一致性标尺 | 对 κ/α 取值的经验解读（如 Landis-Koch：0.6–0.8 为「substantial」）。务必把它当粗略参考而非铁律——合适阈值依任务与风险而定。 |

## 生成指标 · Generation Metrics

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| n-gram | n 元组 | 文本中连续 n 个 token 的片段。BLEU/ROUGE 等指标的基本单位，用候选与参考的 n-gram 重叠近似「内容是否对得上」。 |
| BLEU | —— | 机器翻译经典指标：取 1..4-gram 的修剪精度（clipped precision）的几何平均，再乘简短惩罚（brevity penalty）。基于精度、偏向「说的都对」。 |
| modified / clipped precision | 修剪精度 | BLEU 的核心修正：候选某 n-gram 的计数被「截断」到它在参考里出现的最大次数，防止靠重复高频词（如反复输出 the the the）刷高精度。 |
| brevity penalty (BP) | 简短惩罚 | BLEU 中惩罚过短候选的因子（候选比参考短则 <1）。因为纯精度鼓励「少说少错」，BP 补上对召回的约束。 |
| ROUGE / ROUGE-N | —— | 摘要经典指标：基于召回的 n-gram 重叠（ROUGE-N），强调「参考里的内容有没有被覆盖」。与 BLEU 的精度视角互补。 |
| ROUGE-L / LCS | —— / 最长公共子序列 | 基于候选与参考的最长公共子序列长度的 F 值，不要求连续匹配，能奖励语序大体正确的长片段。LCS 由经典动态规划求得。 |
| METEOR | —— | 在 unigram 上做考虑同义词/词干的对齐，算 F 值（召回权重更高）并加碎片化惩罚。比 BLEU 更贴近人评，但需语言资源。 |
| chrF | —— | 字符级 n-gram 的 F 值，不依赖分词、对形态丰富语言与拼写变体鲁棒，是 BLEU 的常用补充。 |
| BERTScore | —— | 用预训练语境嵌入计算候选与参考 token 间的相似度并贪心匹配，算 P/R/F。能抓「同义不同词」，但慢、依赖具体模型、可被嵌入空间几何愚弄。 |
| embedding-based / learned metric | 嵌入型 / 学习型指标 | 用神经表示或在人评上训练的模型（如 COMET、BLEURT）打分。相关性更高，但不透明、可被对抗、跨域可能失效。 |
| reference-based vs reference-free | 有参考 vs 无参考 | 指标是否需要标准答案。无参考指标（如某些 QE/LLM-as-judge）省去金标，但更易被表面流畅性带偏。 |
| metric–human correlation | 指标-人评相关 | 自动指标的「元评测」：在系统层或句子层与人类判断的相关（Pearson/Spearman/Kendall）。指标的价值不在数值本身，而在它与人评的相关有多高。 |

## 人类评测 · Human Evaluation

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| Likert scale | 李克特量表 | 让评分者在有序等级（如 1–5「很差…很好」）上打绝对分。直观但受评分者尺度差异、天花板/地板效应、锚点漂移困扰。 |
| pairwise comparison | 成对比较 | 让评分者在两个输出里选更好的一个。比绝对打分方差更低、更抗评分者尺度偏置，是 Chatbot Arena 等的基础。 |
| Bradley-Terry model | 布拉德利-特里模型 | 从成对胜负拟合每个对象的实力分 s：P(i 胜 j) = σ(s_i − s_j)。把一堆两两比较汇成一个排名，用 MLE 估计 s。 |
| Elo rating | Elo 评分 | Bradley-Terry 的在线增量近似，逐场更新实力分。Arena 排行榜常用，但对配对策略与顺序敏感。 |
| order / position bias | 顺序 / 位置偏置 | 评分者系统性偏好出现在某个位置的选项（如先出现者）。需用左右随机化 + 统计校正来消除。 |
| length bias | 长度偏置 | 评分者（人或 LLM judge）倾向于认为更长的回答更好，与质量无关。是 RLHF 与 judge 评测里著名的混杂因素。 |
| rater bias / leniency-severity | 评分者偏置 / 宽严 | 不同评分者的系统性倾向（一律打高/打低、用分范围不同）。可用减去各自均值、或 IRT/混合效应模型建模来校正。 |
| inter-rater reliability | 评分者间信度 | 多个评分者打分的一致程度（如 ICC、α）。人评结论可信的前提；信度太低说明任务定义或指南有问题。 |
| ICC (intraclass correlation) | 组内相关系数 | 衡量「同一对象的不同评分者打分」相对于「不同对象」的一致性，是连续/有序人评信度的标准度量。 |
| annotation guideline | 标注/评测指南 | 给评分者的书面标准与示例。模糊的指南是低信度的头号原因；好评测的一半工作在写清指南。 |
| crowdsourcing | 众包 | 用大量非专家评分者（如 MTurk）规模化收集判断。便宜但需质量控制（注意力检查、资格题、聚合）防止低质/作弊。 |

## 心理测量与 IRT · Psychometrics & Item Response Theory

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| classical test theory (CTT) | 经典测验理论 | 把观测分 = 真分 + 误差的框架，用题目难度（答对率）、区分度（题总相关）、信度（如 Cronbach α）刻画测验。简单但题目与被试参数纠缠在一起。 |
| item response theory (IRT) | 项目反应理论 | 把「题目参数」（难度、区分度）与「被试能力」分开建模，用一条概率曲线连接两者。让能力估计不依赖具体题集、题目分析不依赖具体被试。 |
| latent ability (θ) | 潜在能力 θ | 被试在某构念上的位置（一个实数）。IRT 的目标量之一；模型越能力强的被试，答对难题的概率越高。 |
| item difficulty (b) | 题目难度 b | 题目在能力量尺上的位置：能力 θ = b 的被试恰好有 50%（2PL/Rasch）概率答对。b 越大题越难。 |
| item discrimination (a) | 题目区分度 a | 题目反应曲线在 b 处的陡峭程度：a 越大，能力略高于/低于 b 的被试答对率差异越明显，题目越能区分能力。 |
| guessing parameter (c) | 猜测参数 c | 3PL 模型里能力极低者仍能蒙对的下渐近概率（如四选一 c≈0.25）。建模选择题的下限。 |
| Rasch / 1PL model | 拉希 / 单参数模型 | P(对) = σ(θ − b)，所有题区分度相同。参数最少、具备「特定客观性」等良好性质，是 IRT 的最简形式。 |
| 2PL model | 双参数模型 | P(对) = σ(a(θ − b))，每题各有难度与区分度。本课的 worked 例子，用联合 MLE 同时估计所有 θ 与 (a,b)。 |
| item characteristic curve (ICC) | 题目特征曲线 | 答对概率随能力 θ 变化的 S 形曲线。难度决定它左右位置、区分度决定它陡峭程度，是 IRT 的核心可视化。 |
| Fisher information | 费舍尔信息 | 某能力点上题目/测验对能力估计的「精确度贡献」。2PL 题在 θ≈b 处信息最大，是自适应选题与测验设计的依据。 |
| test information / SEM | 测验信息 / 测量标准误 | 各题信息之和；其平方根的倒数是该能力点的测量标准误（SEM）。信息越高、SEM 越小、能力估计越准。 |
| adaptive testing (CAT) | 自适应测验 | 根据被试当前能力估计动态选「信息量最大」的下一题，用更少题达到同等精度。GRE 等考试与高效 LLM 基准的思路。 |
| joint / marginal MLE | 联合 / 边缘极大似然 | 拟合 IRT 的两种法：联合（同时估 θ 与题参数，简单但有偏）、边缘（对 θ 积分后估题参数，更标准）。本课用联合 MLE 演示机制。 |

## 校准与不确定性 · Calibration & Uncertainty

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| calibration | 校准 | 预测概率是否「说话算数」：在所有「自信 70%」的预测里，是否约 70% 真的正确。校准与准确率正交——可以准但不校准，也可以校准但不准。 |
| confidence / predicted probability | 置信度 / 预测概率 | 模型对其预测赋予的概率（如 softmax 最大值）。校准研究的对象就是这个数与真实正确频率的关系。 |
| reliability diagram | 可靠性图 | 把预测按置信度分箱，画「箱内平均置信度 vs 箱内真实准确率」。对角线=完美校准，曲线在对角线下方=过度自信。 |
| ECE (Expected Calibration Error) | 期望校准误差 | 各置信度箱里 \|准确率 − 平均置信度\| 按样本数加权的平均。最常用的单数字校准指标，但对分箱方式敏感、会掩盖箱内异质。 |
| MCE (Maximum Calibration Error) | 最大校准误差 | 所有箱中校准差距的最大值，关注最坏情形的校准。风险敏感场景比 ECE 更该看它。 |
| overconfidence / underconfidence | 过度 / 不足自信 | 平均置信度高于（低于）实际准确率。现代神经网络（尤其交叉熵训练 + 高容量）普遍过度自信，是温度缩放要解决的问题。 |
| temperature scaling | 温度缩放 | 训练后用单个标量 T 去除 logits（softmax(z/T)）再归一，只调校准不改 argmax 预测。最简单有效的事后校准法（Guo 等 2017）。 |
| Platt scaling / isotonic | 普拉特缩放 / 保序回归 | 其它事后校准法：Platt 用逻辑回归映射分数到概率；isotonic 用单调函数，更灵活但更易过拟合小验证集。 |
| Brier score | 布里耶分数 | 概率预测的均方误差：mean((p − y)^2)。一个同时奖励校准与区分度的恰当评分规则（proper scoring rule）。 |
| Brier decomposition | 布里耶分解 | 把 Brier 拆成「可靠性（校准差）− 分辨率（区分度）+ 不确定性（基率难度）」三项，分别诊断模型在哪一环节弱。 |
| proper scoring rule | 恰当评分规则 | 当且仅当报告真实概率时期望得分最优的评分规则（如 Brier、对数损失）。它让「诚实报告不确定性」成为最优策略。 |
| selective prediction / abstention | 选择性预测 / 弃答 | 允许模型在没把握时拒答，用风险-覆盖（risk-coverage）曲线权衡作答比例与作答准确率。 |

## 在线 A/B 评测 · Online A/B Evaluation

| 术语 (EN) | 中文 | 释义 |
|-----------|------|------|
| A/B test / RCT | A/B 实验 / 随机对照试验 | 把流量随机分到对照(A)与处理(B)，比较线上指标。随机化让两组在其它因素上可比，从而把差异归因于改动本身。 |
| hypothesis test | 假设检验 | 在「无差异」原假设 H0 下，看观测差异有多罕见（p 值）。是判断「这点差别是真本事还是抽样波动」的标准框架。 |
| null / alternative hypothesis | 原 / 备择假设 | H0（通常「两组无差异」）与 H1（有差异）。检验是在控制「H0 为真却拒绝」错误率（α）的前提下，尽量多地发现真效应。 |
| p-value | p 值 | 在 H0 为真时，得到「至少这么极端」的统计量的概率。p 小说明数据与 H0 不符；但 p 不是「H0 为真的概率」，误读极其普遍。 |
| type I / II error (α, β) | 第一类 / 第二类错误 | α=H0 真却被拒（假阳性）；β=H1 真却没发现（假阴性）。功效 = 1 − β。实验设计就是在固定 α 下把功效做高。 |
| statistical power | 统计功效 | 当真有指定大小的效应时，实验能检出它（拒绝 H0）的概率。功效不足的实验「没显著」≠「没效应」，只是看不见。 |
| MDE (minimum detectable effect) | 最小可检出效应 | 在给定样本量、α、功效下能可靠检出的最小效应。和样本量、方差一起决定一个实验值不值得做。 |
| sample size / power analysis | 样本量 / 功效分析 | 在跑实验前据目标 MDE、α、功效、基线方差反推所需样本量。跳过它是线上实验最常见的浪费。 |
| two-sample test (t / z) | 两样本检验 | 比较两组均值/比例：连续指标用 t 检验、比例用两比例 z 检验。本课从零实现并与解析公式对拍。 |
| multiple comparisons | 多重比较 | 同时检验很多指标/变体时，假阳性会累积。需用 Bonferroni、Benjamini-Hochberg（控制 FDR）等校正，否则「总能找到显著的」。 |
| peeking / sequential testing | 偷看 / 序贯检验 | 反复在实验中途看结果并随时叫停会大幅抬高假阳性。序贯方法（α-spending、always-valid p 值）让「边看边停」仍受控。 |
| CUPED | —— | 用实验前协变量（如用户的实验前指标）回归扣除其可解释的方差，在不引入偏差的前提下缩小方差、提升功效（Deng 等 2013）。 |
| variance reduction | 方差缩减 | 一类在不改变估计目标的前提下减小估计方差的技术（CUPED、分层、控制变量）。等价于「用更少样本达到同等功效」。 |
| Simpson's paradox | 辛普森悖论 | 聚合数据的结论与每个子群内的结论相反，源于混杂变量在组间分布不均。提醒线上实验要警惕分群与混杂。 |
| novelty / primacy effect | 新奇 / 首因效应 | 用户对新改动短期内的异常反应（追捧或抗拒），会污染早期 A/B 读数。需观察足够长、看趋势是否收敛。 |
