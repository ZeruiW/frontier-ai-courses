怎么用： 每个模块先读 HTML 讲解 建立「生产系统为什么这样设计」的工程直觉，再跑 notebook 亲手用纯 Python 把控制平面的逻辑从零实现一遍——镜像层缓存、SSE 编解码、Erlang-C 容量模型、reconcile 循环、探针状态机、装箱调度器、HPA 闭环仿真、序贯检验、spot 期望成本、backfill 调度器——并为每个机制算一笔 SLO 账、容量账与成本账。每个练习都有紧跟的 assert 自测判分。配套 术语词典 与 参考清单。本课的立场是：C24（高效推理服务）讲引擎内部怎么跑得快，C37（MLOps）讲模型生命周期怎么管；本课补中间那个缺口——这个跑得快的引擎，怎么被打包、被调度、被发布、被扩缩、被计费，才能承载真实流量。本环境没有 Docker/Kubernetes/GPU/云账号：但云原生这一层的困难几乎全是「逻辑与数学」的困难而非「跑得动」的困难——K8s 调度器本质是装箱算法、Deployment 控制器本质是一个 reconcile 循环、HPA 本质是带纯延迟的比例控制器、金丝雀判据本质是序贯假设检验。这些都能用几十行 Python 写出来并用 assert 验证其性质。讲解里的 Dockerfile / YAML / sbatch 片段是可直接使用的正确写法，仅作对照展示、不参与运行。学完你能为一个 LLM 服务做完整的部署设计，并回答「几个副本、多少钱、发布怎么不出事」。
