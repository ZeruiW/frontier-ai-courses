1动机：条件太弱，需要放大

到这里，我们的生成模型已经能从噪声采样出像样的图（模块 01–03），但有个致命的实用问题：它生成得太「自由」了。你给它 prompt「一只戴帽子的猫」，普通条件采样确实会朝这个方向走，但条件信号往往太弱——生成的图可能是只猫，帽子却若有若无，或者构图飘忽、不够贴合描述。原因在于：条件 c 只是去噪网络众多输入之一，它对最终输出的影响被海量的「怎么画都行」的自由度稀释了。我们需要一个旋钮，能主动放大条件的话语权。

最早的解法是 classifier guidance（Dhariwal & Nichol 2021）：另训一个能在带噪图上分类的分类器，用它的梯度 ∇ₓ log p(c|x) 在每步采样里把图往「更像类别 c」的方向推。这有效，但代价很重：你得额外训练一个噪声鲁棒的分类器，而且它和扩散模型是两套东西、要分别维护、还容易被对抗梯度带偏。能不能不要这个外挂分类器？

Ho & Salimans 2022 的 classifier-free guidance (CFG) 给出了一个惊人简洁的答案：让同一个去噪网络同时学会「带条件」和「不带条件」两种预测，采样时把两者的差外推放大，就等价于隐式地用了一个分类器——却一个分类器都不用训。这个想法如此好用，以至于今天几乎每一个文生图模型的采样都默认开着 CFG；那个让你调「prompt 贴合度」的强度滑块，背后就是它。

为什么「条件太弱」是扩散特有的、而非随便就能靠加大条件权重解决的问题？因为扩散的训练目标（预测噪声的 MSE）是一个逐样本的回归，它只要求网络对每个带噪样本给出无偏的噪声估计——它不直接优化「生成的图有多贴合条件」这件事。换句话说，模型学到的是 p(x|c) 的一个忠实但温和的近似：忠实意味着它不会乱来，温和意味着它不会刻意夸大条件。对追求「图必须明确符合 prompt」的实用场景，这种温和恰恰不够——我们需要一种采样时的手段，在不重训模型的前提下，把条件的影响人为放大。CFG 正是这样一个纯采样时的技巧：训练只多做一件小事（随机丢条件），放大全在采样时发生。

一句话抓住 CFG：先问模型「随便画一张」（无条件），再问「按这个 prompt 画一张」（有条件），两者之差就是「这个 prompt 到底要我往哪改」——然后沿这个方向多走几步。多走的倍数就是引导强度。不需要任何额外分类器，因为「条件 vs 无条件之差」本身就编码了条件的方向。

2核心机制：一个网络，两种预测

核心机制：一个网络，两种预测

CFG 的第一步在训练时就埋下了：让同一个去噪网络 εθ 既能做条件预测，又能做无条件预测。做法朴素得出奇——训练时以一定概率（典型 10%~20%）把条件丢掉，换成一个特殊的「空条件」∅（null token / 空 prompt / 可学习的 null embedding）：

训练一步（带条件丢弃）： 1. 取 (图 x, 条件 c)，编码、采 t、采噪声 ε，闭式加噪得 x_t 2. 掷骰子：以概率 p_drop≈0.1 把 c 替换成空条件 ∅ 3. 网络预测：ε̂ = εθ(x_t, t, c 或 ∅) 4. 损失 ‖ε − ε̂‖²，反传 => 网络同时见过「带 c」和「带 ∅」的样本，学会了两种模式

于是一个网络身兼两职：喂真条件 c 得到条件预测 ε_c = εθ(x_t,t,c)；喂空条件 ∅ 得到无条件预测 ε_∅ = εθ(x_t,t,∅)。采样时两个都算一遍（所以 CFG 的采样要跑两次网络，算力翻倍——这是它的主要代价），再做关键的外推：

\[\tilde\epsilon \;=\; \epsilon_\varnothing \;+\; w\,\big(\epsilon_c - \epsilon_\varnothing\big)\]

把这个 ε̃ 当作「被引导过的去噪预测」喂进采样器（DDPM/DDIM/flow 都行）。本课全程用这个约定：w 是引导强度。注意三个可直接验证的事实——w=0 时 ε̃=ε_∅（纯无条件，prompt 被忽略）；w=1 时 ε̃=ε_c（普通条件采样，不放大）；w>1 时把预测沿 ε_∅→ε_c 的方向外推到 ε_c 之外，即「比模型自己以为的还要更贴合条件」。

这里有个值得停下来体会的设计精妙之处：训练时随机丢条件，竟一举两得。它既让网络获得了无条件生成能力（喂 ∅ 时就是个无条件模型），又没有损害条件生成能力（90% 的时间仍在学带条件）。一个网络、一次训练，同时学会了两种模式，采样时随取随用。相比之下，classifier guidance 要维护两个独立模型（扩散 + 分类器），CFG 把它们合二为一——这种「用一点训练时的随机性换来采样时的巨大灵活性」的思路，是值得记住的设计模式。

注意 CFG 是外推（extrapolation）而非插值。w 在 0 与 1 之间是插值（在两个合理预测之间），但实用 w 通常是 7~12，远大于 1——这把预测推到了ε_c之外、两个预测都没覆盖的区域。外推天然有风险（推出数据流形），这正是后面「过饱和」的根源。记住：CFG 的威力和它的副作用同源，都来自外推。

3为什么等价于一个分类器

为什么这等价于一个分类器

CFG 最漂亮的地方，是它数学上确实等价于 classifier guidance——却不用训分类器。推导只需一个桥梁：扩散网络预测的噪声 ε 正比于数据分布的分数（score）的负方向，ε(x_t,t) ∝ −∇ₓ log p(x_t)（这是 score-based 视角，C16 讲过）。

于是条件与无条件预测之差，恰好是条件似然的梯度：

\[\epsilon_c - \epsilon_\varnothing \;\propto\; -\nabla_x\big[\log p(x_t\mid c) - \log p(x_t)\big] \;=\; -\nabla_x \log p(c\mid x_t)\]

最后一步用了贝叶斯：log p(x|c) − log p(x) = log p(c|x) − log p(c)，而 log p(c) 不含 x、梯度为零。所以 「条件预测减无条件预测」就是「那个本来要外训的分类器的梯度」！CFG 用一个网络的两次前向，免费得到了 classifier guidance 要靠外挂分类器才能拿到的东西。代入外推式可见，CFG 实际是在从一个被指数加权过的分布里采样：

\[\tilde p(x\mid c) \;\propto\; p(x)\,\big[p(c\mid x)\big]^{\,w}\]

直白说

通俗讲：p(c|x)^w 里的 w 是个「放大镜」。w 越大，分布越偏向「分类器极度确信是 c」的那些 x——也就是最典型、最无歧义的样本。代价是：那些虽然也符合 c、但不那么典型的样本被压制了，多样性随之下降。

严谨说

严谨地：w>1 把条件似然 p(c|x) 指数锐化，等价于把采样温度调低。这解释了 CFG 的核心权衡——锐化分布提升了「样本符合条件」的概率（保真），却削减了分布的支撑集（多样性）。两者此消彼长，由 w 单调控制。

这个等价还解释了一个实践疑问：为什么 CFG 比它的前身 classifier guidance 好用那么多？classifier guidance 要的那个外挂分类器，必须在带噪图上训练（因为采样的每一步都作用在不同噪声级别的 x_t 上），这本身就难——一个在干净图上训好的分类器，面对半是噪声的图会彻底失灵。而 CFG 把这个分类器免费地、隐式地藏在了去噪网络里：去噪网络本来就见过所有噪声级别的样本，它的「条件减无条件」自然就是一个各噪声级别都正确的隐式分类器梯度。一举消除了「另训噪声鲁棒分类器」这个最大的工程负担——这才是 CFG 真正的胜利。

把这层等价关系记牢，胜过记公式：CFG = 用模型自己当分类器。它问模型两个问题（带条件、不带条件），用回答之差当作「条件指明的方向」，再放大。所以 CFG 的质量天然受限于模型自己对条件的理解——模型没学好的条件，CFG 放大的也是错的方向。

4引导强度 w：保真 vs 多样

引导强度 w：保真 vs 多样的旋钮

w 是 CFG 唯一也是最重要的旋钮，它在两个互相拉扯的目标之间滑动：

引导强度 w效果保真度 (CLIP/对齐)多样性典型问题
w=0纯无条件，忽略 prompt最低最高图和 prompt 无关
w=1普通条件采样中高条件信号偏弱
w=3~8（常用区）放大条件高（甜点）中—— 平衡点 ——
w>12过度引导看似更贴但失真低过饱和、伪影

这条权衡是 CFG 的全部精髓，也是你在任何文生图 UI 里调那个滑块时实际在做的事。调高 w：图越来越紧扣 prompt（CLIP score 上升）、越来越「典型」，但也越来越千篇一律——同一 prompt 不同种子生成的图越来越像。调低 w：图更多样、更有惊喜，但可能离 prompt 越来越远。Ho & Salimans 的原论文就用 FID（衡量整体质量/多样性）和 IS（衡量类别清晰度）画出了这条权衡曲线：存在一个中间的 w 让两者达到最佳折中，两头都不是最优。

一个常被忽略的细节：最优 w 依赖模型、数据集、采样器、甚至 prompt。条件信号本身强（如清晰的类别标签）时，小 w 就够；条件弱或抽象（如复杂长文本）时，往往要更大的 w 才推得动。这也是为什么不同模型推荐的默认 w 差别很大（见本模块胶囊），以及为什么没有「万能的最佳 w」。

还要理解 CFG 与评测指标的微妙关系，否则容易被带偏。调高 w 几乎总能让 CLIP score（图文对齐度）上升，于是看起来「更好」；但 FID（衡量与真实分布的接近程度、隐含多样性）往往先降后升——存在一个让 FID 最优的中等 w，再往上 FID 反而变差（因为多样性塌缩、且过饱和让图偏离真实分布）。所以单看 CLIP score 选 w 会系统性地把 w 选得过大。这是评测扩散模型的一个经典陷阱：两个指标指向不同的 w，真实的「好」在它们的折中处，而非任何单一指标的极值。

CFG 拉满 = 翻车

最反直觉、也最该牢记的一点：w 不是越大越好，更大的 w ≠ 更好的图。超过某个阈值后，CFG 的外推把去噪预测推出了真实数据流形，结果是颜色过饱和、对比过强、细节崩坏、出现不自然的高频伪影。新手最常见的错误就是「prompt 不够贴就一路把 CFG 拉满」，结果得到一张「很努力但很丑」的图。正确做法是找那个甜点 w，而非最大化它。

5负向提示：换掉基线

负向提示：把无条件基线换成「不想要的」

CFG 的外推式里，ε_∅ 扮演「基线/参照系」的角色——我们沿「从基线指向条件」的方向放大。negative prompt（负向提示）是一个聪明的推广：把这个基线从「空条件」换成「你明确不想要的内容」的条件预测 ε_neg：

\[\tilde\epsilon \;=\; \epsilon_{\text{neg}} \;+\; w\,\big(\epsilon_c - \epsilon_{\text{neg}}\big)\]

现在外推方向变成「从『不想要的』指向『想要的』」，放大它就等于既朝想要的靠近，又主动远离不想要的。比如正 prompt 写「一张人像」，负 prompt 写「blurry, lowres, extra fingers」，模型就会被推离模糊、低清、多手指这些常见缺陷。这是实践中极其常用的可控手段——很多「质量提升咒语」本质就是塞进负 prompt 的。

直白说

通俗讲：普通 CFG 是「朝目标走」，负 prompt 是「朝目标走、同时背对雷区」。把参照系从「中立的空白」换成「明确的反例」，外推这条线就同时具备了「吸引」和「排斥」两个作用。

严谨说

严谨地：负 prompt 把采样分布变成 p(x)·[p(c|x)/p(c_neg|x)]^w 的形态——既放大目标条件似然，又压制负条件似然。它仍是同一套外推机制，只是把基线预测从 ε_∅ 替换为 ε_neg，无需任何训练改动，纯采样时的技巧。

实践中负 prompt 极其常用，且有一些反复出现的套路值得知道。最常见的是塞入质量负词（blurry, lowres, jpeg artifacts, bad anatomy 等），把生成推离这些常见缺陷——很多社区流传的「画质提升咒语」本质就是一串负 prompt。还有内容排除（不想要某物体/风格时写进负 prompt）。但也要警惕：负 prompt 同样受 w 放大，写得过激或过多会和正 prompt 互相拉扯、把图推向奇怪的方向。它和正 prompt 是一对方向相反的力，配平才好用——这也再次印证了 CFG「一切都是外推、基线决定远离什么」的统一视角。

负 prompt 揭示了 CFG 的一个深层视角：引导的本质是「在两个预测之间外推」，基线选什么，就决定了你在远离什么。空条件 ∅ 是「远离平庸/无条件」，负 prompt 是「远离指定的坏内容」。理解了这点，你就能自由设计各种引导（如风格引导、构图引导）——它们都是同一个外推式的不同基线。

6过饱和与缓解

过饱和与缓解：让外推别跑太远

先把过饱和这个现象说清楚。当 w 过大，生成的图会出现一组典型病征：颜色过浓过艳、明暗对比拉到极端、边缘出现不自然的硬光晕、细节区域崩成奇怪的高频噪点。数值上，这对应去噪预测 ε̃ 的幅度（方差）被外推放大了——外推把预测推到了真实噪声分布的尺度之外，于是每一步去噪都「用力过猛」，累积下来就把图推离了自然图像的流形。理解了「过饱和 = 外推导致的幅度膨胀 + 流形偏离」，下面的缓解方法就都顺理成章了。

既然 CFG 的副作用来自外推跑出数据流形，缓解思路就两类：要么把跑出去的拉回来，要么别让它跑那么久。三种主流方法：

  1. CFG rescale（Lin 2024）：外推会让预测的方差膨胀（这正是过饱和的数值表现）。解法是引导后把 ε̃ 的标准差重新缩回条件预测 ε_c 的水平：ε̃ ← ε̃ · (std(ε_c)/std(ε̃))（再与原 ε̃ 按系数混合）。保留方向、压住幅度。
  2. 动态 / 调度 CFG：让 w 随去噪步变化而非全程恒定。常见策略是「早期强、后期弱」——早期需要强引导来确定构图与语义，后期细节阶段强引导只会添乱、引发伪影。这能在对齐和自然之间取得更好平衡。
  3. 限定区间引导：干脆只在中间一段时间步施加引导，最开始（纯噪声、引导无意义）和最后（细节、引导有害）都关掉。Karras 等的实验表明这能显著减少伪影。

这些方法有个共同的认识：恒定的大 w 是一种粗糙的全局手段，而过饱和往往是「在不该强引导的时间/位置强引导」造成的。所以更精细的做法是让引导在合适的时候、合适的强度起作用。前沿模型（如 SD3、Flux）大多内置了某种形式的引导调度，而非让用户面对一个生硬的全局 w。

为什么「早期强、后期弱」的调度几乎总是有益？这背后有个清晰的直觉，和扩散采样的阶段性有关。采样早期（高噪）决定的是全局结构——构图、主体、语义骨架，此时强引导能确保图朝 prompt 的方向立住；采样后期（低噪）处理的是局部细节——纹理、边缘、微调，此时图的内容已基本定下，强引导不仅帮不上忙，反而会把已经合理的细节往「极端典型」推，正是过饱和与伪影的高发区。所以让引导在该用力时用力、该松手时松手，比全程一个生硬的大 w 自然得多。这也呼应了模块 03 的视角：采样是一条轨迹，轨迹的不同阶段有不同的需求。

还有一条更激进的路线和模块 05 相通：引导蒸馏。CFG 要跑两次网络（条件 + 无条件），算力翻倍。可以把「带 CFG 的两次前向」蒸馏进一个单次前向就内置了引导的学生网络——Flux schnell、SDXL-Turbo 等少步模型常把 CFG 一并蒸馏掉，既快又省。这是「把采样开销压到极致」的一环，详见下一模块。

一个实用提醒：上面这些缓解技巧不是「越多越好」地叠加。它们各自针对过饱和的不同侧面（幅度、时机、区间），通常选一两个针对你观察到的具体伪影即可。盲目全开可能互相干扰、甚至损失本该有的引导效果。先看图诊断问题，再对症下药——这和调 w 本身是同一种克制的智慧。

7把玩具跑起来：CFG 强度扫描

把玩具跑起来：CFG 与强度扫描

配套 notebook 用纯 numpy 在一个带条件的 2D 玩具上把 CFG 跑通：

  1. 条件玩具数据：两个分得很开的高斯团当作两个「类别」（条件 c∈{0,1}）；全体数据的混合当作「无条件」分布。
  2. 玩具去噪器：用闭式后验均值构造每个类别的条件去噪器 ε_c 与混合的无条件去噪器 ε_∅（沿用模块 01 的 optimal_eps 思路）。
  3. CFG 外推：实现 cfg_predict(ε_c, ε_∅, w)=ε_∅+w(ε_c−ε_∅)，验证 w=0→ε_∅、w=1→ε_c 两个精确等式。
  4. 强度扫描：对 w∈{0,1,2,4,8} 各采一大批样本，测「落在目标类别附近的比例」——会看到它随 w 单调上升（保真↑），同时样本方差随 w 下降（多样性↓）。
  5. 负引导：把基线换成另一类，验证生成的均值被推离那个负类别。

通过这个玩具，你会亲眼量化本模块的每个论点：CFG 的两个边界等式精确成立、w 越大越扣条件但越不多样（保真-多样权衡的数字证据）、以及负引导确实把分布推离指定内容。维度小到能画散点、能 print 比例，但 ε̃=ε_∅+w(ε_c−ε_∅) 这条外推式与真实 SD 采样里那一行 CFG 代码逐字对应。

notebook 的去噪器是闭式玩具（不训练），但 CFG 外推、负引导、动态 w 的逻辑与真实实现完全一致。想深入直接看 Ho & Salimans 2022 (CFG) 原论文，以及 diffusers 库采样循环里的 noise_pred_uncond + guidance_scale * (noise_pred_text - noise_pred_uncond) 那一行。

8研究前沿与开放问题

研究前沿与开放问题

  • 更好的引导，更少的副作用：CFG 的外推本质就会牺牲多样性、引入伪影。autoguidance（Karras 2024）用一个更弱的同族模型当基线（而非无条件预测），被证明能更干净地提质——引导研究正在寻找比「条件减无条件」更好的方向。
  • 引导强度的自动化：最优 w 依赖模型/prompt/步数，目前靠手调或固定默认值。如何逐样本、逐步、逐 prompt 自适应地选 w（甚至让模型自己学出引导强度），是活跃方向。
  • 免引导生成：CFG 要两次前向、算力翻倍。能否训出不需要 CFG 就自带强条件对齐的模型？引导蒸馏（把 CFG 蒸进单次前向）和一些新训练目标正朝这个方向走（与模块 05 相通）。
  • 过饱和的根本理解：过饱和与流形偏离的精确关系、为什么某些时间步/区域更敏感，仍缺乏完整理论。CFG rescale、区间引导都是经验补丁，更原理性的解法在探索中。
  • 引导用于可控编辑：把「在两个预测间外推」推广到风格、构图、属性的精细控制（如不同区域用不同引导、不同 token 用不同强度），是连接 CFG 与可控生成、图像编辑（如 prompt-to-prompt、注意力控制）的前沿交叉点，也是把「一个全局 w」拆成「细粒度引导场」的方向。

必读：Ho & Salimans 2022《Classifier-Free Diffusion Guidance》（CFG 原始论文）；前身 Dhariwal & Nichol 2021（classifier guidance）；进阶看 Lin 2024（CFG rescale / 过饱和修复）、Karras 2024（autoguidance）。完整清单见 references.md。
