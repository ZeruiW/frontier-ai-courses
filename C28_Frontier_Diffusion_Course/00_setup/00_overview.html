1这门课讲什么

欢迎来到 扩散与流前沿。这门课只追求一件事：让你从「会调用 Stable Diffusion / Flux」变成「看懂它们为什么这么设计、并能写出核心机制」。

过去几年，文生图/视频从玩具变成产品，背后不是某一个魔法，而是一串可以逐个拆解的工程与数学选择。为什么扩散不在像素上做、要先压进一个 latent 空间？为什么去噪骨干从卷积 U-Net 换成了 Transformer？为什么最新模型（SD3、Flux）不再说「扩散」而说「flow matching」、训练目标变成回归一条直线？为什么有个叫 CFG 的旋钮一调高图就更贴 prompt、再高就「糊」了？为什么 Turbo/LCM 能把上百步采样压成一步？——这五个问题，正是本课的五个模块。

这门课刻意不重讲扩散基础。前向加噪、反向去噪、score matching、DDPM 的训练目标，都是 C16（生成模型）的内容；这里默认你已经懂「把数据加噪成高斯、再学网络一步步去噪」这套框架，把全部篇幅留给真正前沿、领先实验室真实在用的五块技术。如果你对 x_t=√ᾱ_t·x_0+√(1-ᾱ_t)·ε 这行公式感到陌生，建议先过一遍 C16 再回来。

学完你应当能回答这类问题（也是生成方向岗位的高频面试题）：latent 扩散省的是哪部分算力、代价是什么？DiT 的 adaLN-zero 为什么要初始化成零？flow matching 和扩散到底什么关系、直线路径好在哪？CFG 的 w 调大调小各牺牲什么？consistency model 凭什么能一步生成？——并且能在 numpy 里把这五样东西的核心都从零实现、和朴素参考对拍验证。

2技术谱系：从 DDPM 到 SoRA

一张技术谱系图：从 DDPM 到 SoRA

当代生成模型不是孤立的发明，而是一条清晰的演化链。把它画出来，本课五个模块的位置就一目了然：

基础（C16）：DDPM —— 加噪/去噪，像素空间，UNet，上百步采样 │ ┌─────────────────┼──────────────────┬────────────────────┐ ▼ ▼ ▼ ▼ ① latent 扩散 ② 骨干换 Transformer ③ 训练目标换 flow ④ 采样可控/可压 (LDM/SD, 模块01) (DiT, 模块02) (flow matching, 模块03) (CFG 模块04 / consistency 模块05) │ │ │ │ └────────┬────────┴─────────┬────────┘ │ ▼ ▼ ▼ SD3 / Flux = latent + DiT + flow + CFG Turbo/LCM = 上面 + 少步蒸馏（实时） │ ▼ 时空 patch SoRA / 视频 = DiT 推广到时空

读这张图的方式：基础扩散是树根，四个方向是四根主枝，前沿模型是把这些枝叶组合起来的果实。Stable Diffusion 3 几乎把前四个模块（latent + DiT + flow + CFG）全用上了；Flux 在此之上加少步蒸馏；SoRA 把 DiT 的 patch 从二维图像推广到三维时空。没有哪个前沿模型是凭空出现的——它们都是这几块积木的不同拼法。本课就是把每块积木单独拿出来、拆到你能自己拼。

直白说

你可以把这门课想成「逆向工程一台 SD3」：先看它把扩散搬进 latent 省算力（模块 01），再看它用 Transformer 当大脑（模块 02），再看它用直线流学得更稳更快（模块 03），再看它用 CFG 让你能用文字控制（模块 04），最后看 Turbo 版怎么把它压成实时（模块 05）。

严谨说

更严谨地说：这五块技术分别作用在生成管线的不同层面——表示空间（latent）、函数逼近器（DiT 骨干）、学习目标与轨迹几何（flow matching）、采样时的条件控制（CFG）、采样步数的压缩（consistency）。它们正交、可独立替换，这正是为什么能被组合，也是为什么值得分开学。

4方法论：用 numpy 玩具复现

方法论：用 numpy 玩具复现前沿

本环境没有 GPU、不训练真实大模型。但前沿生成模型的难点从来不是「跑得动」，而是机制为什么这么设计、数学上对不对：latent 两阶段为何解耦、adaLN 怎么注入条件、直线速度场的目标是什么、CFG 外推的代数、一致性自洽损失的形式。这些用 numpy 在 CPU 上玩具规模也能精确表达和验证。

打个比方：学发动机原理不必先有一辆法拉利。生成模型的「原理」是分布怎么被一步步变形、条件怎么注入、轨迹怎么积分、步数怎么压缩；这些都是和规模无关的算法结构。我们把真实模型里 512×512×3 的图像，换成 2D 平面上的双月/八高斯分布，或几十维的小「图」；把上亿参数的 DiT，换成几层的小网络。维度小到能 print 出来、能画散点图，但机制一模一样——真实模型只是同一逻辑放大加工程。

直白说

我们把每个前沿机制翻译成 numpy 里看得见的东西：latent 空间就是一个低维投影，扩散就是给 2D 点加高斯噪声，patchify 就是把小图切成块再展平，速度场就是「每个点该往哪走」的箭头，CFG 就是两个预测向量的外推，一致性就是「不同时刻预测应一致」的 MSE。你写的是结构与正确性，不是 FID。

严谨说

关键纪律是对拍（differential testing）：每个机制都和一个绝对可信的朴素参考比对。VAE 往返要近似恒等、闭式加噪要等于逐步加噪、直线路径的速度场恒为 x_1-x_0、CFG 在 w=1 时要等于普通条件采样、一致性函数在 t=0 要是恒等。结构正确 → assert 通过 → 逻辑可迁移到真实实现。

前沿概念本课的 numpy 玩具对应真实模型
latent 空间2D/低维分布上的线性编解码SD 的 VAE encoder/decoder
DiT 去噪骨干小图 patchify + adaLN 调制 + 自注意力DiT / MM-DiT block
flow 速度场2D 上的向量场 + Euler/Heun 积分SD3/Flux 的 rectified flow
classifier-free guidance条件/无条件预测向量的外推一切文生图的 CFG 开关
consistency 函数ODE 轨迹相邻点的自洽 MSECM / LCM 的少步采样

务必清楚本课不教什么：不训练能出好图的真实模型、不测 FID、不调大规模超参、不写 GPU 算子。这些在你理解了机制之后，是第二步（references 里的开源实现接手）。本课负责把第一步——机制与正确性夯死；这一步搞定，读真实代码与论文才不再是天书。

5环境与运行

环境与运行

环境极简：只需 numpy（画 2D 分布散点可选 matplotlib）。全课 CPU 秒级运行，无需 GPU、不装 torch/diffusers。

conda create -n frontier-diffusion python=3.11 -y && conda activate frontier-diffusion
pip install numpy            # 必需
pip install matplotlib       # 可选，仅用于画 2D 分布/采样轨迹
jupyter lab

每个模块配一个 notebook，结构统一：先用 numpy 把机制从零实现并对拍（5–6 个 worked 小节，每节跑出可打印的验证与 assert），再做 3–4 道带 assert 判分的 ✏️ 练习（先给骨架，自己填，再对照 📖 参考答案），最后一个真实数据胶囊（用真实模型的配置/形状/超参算一笔账，把玩具接到现实）。

建议的学习节奏：先读完整章 HTML 建立直觉与数学框架，再打开 notebook 亲手实现。读和做缺一不可——只读会觉得「好像懂了」，真正动手写加噪闭式、调 patchify 维度、让速度场 MSE 收敛、让 CFG 在 w=1 退化时，才会发现魔鬼藏在哪些细节里（缩放系数、维度对齐、边界条件、数值稳定）。这门课的深度正是为「动手」服务的。

配套先读：若扩散基础不熟先过 C16；然后 Rombach《Latent Diffusion》开门、Peebles《DiT》看骨干、Lipman《Flow Matching》看新范式。完整清单见 references.md。

✅ 学完整门课，你应该能：
  1. 说清 latent 扩散省的是哪部分算力、下采样因子 f 的权衡，并能在玩具上实现 VAE 往返 + latent 扩散；
  2. 实现 patchify/unpatchify 与 adaLN-zero 条件注入，讲清 DiT 为何取代 U-Net、为何能 scale；
  3. 推导并实现 flow matching 的速度场目标，理解直线路径与 reflow，讲清 flow 与扩散的统一关系；
  4. 实现 classifier-free guidance 的外推，说清引导强度 w 对保真-多样的权衡、负 prompt 与过饱和；
  5. 实现一致性模型的自洽损失与边界条件，做单步/少步采样，讲清它与扩散的质量-步数权衡；
  6. 把 SD3/DiT/Flux/LCM 的设计选择对应回这五块技术，读懂它们的开源实现与论文。
