1像素空间太贵：latent 的动机

扩散模型的第一版（DDPM）直接在像素空间操作：一张 512×512 的 RGB 图就是 512×512×3 ≈ 786432 维的向量。去噪网络要在这个百万维空间里，一步步把噪声雕成图像，而且采样要跑几十上百步、每步都过一遍大网络。结果是又慢又贵：训练要海量算力，推理在消费级显卡上慢到难以接受。这是 2021 年扩散虽然质量惊艳、却难以普及的根本瓶颈。

Rombach 等人 2022 年的 Latent Diffusion (LDM) 给出了一个简单而深刻的解法，它也是 Stable Diffusion 的核心：不要在像素上扩散，先把图像压到一个低维的 latent 空间，在那里扩散，最后再解码回像素。一张图先经 VAE 编码成 64×64×4 ≈ 16384 维的 latent，扩散只在这个小了约 48 倍 的空间里发生。同样的网络、同样的步数，算力直接降一两个数量级——高分辨率开源生成由此成为可能。

直白说

打个比方：要给一篇万字长文「换个说法」，没必要逐字母改，先把它压成一份要点提纲（latent），在提纲层面改写，再展开成完整文章。图像的像素里有大量人眼根本不在意的冗余（相邻像素几乎一样、高频纹理可后补），先把这些冗余压掉，扩散就只需操心真正承载语义的少量信息。

严谨说

形式上：设 VAE 编码器 E、解码器 D，图像 x 的 latent 为 z=E(x)。LDM 把扩散的全部前向/反向过程从 x 空间搬到 z 空间：在 z 上加噪、训去噪网络、采样出 ẑ，最后 x̂=D(ẑ) 一次性解码。扩散的维度从 dim(x) 降到 dim(z)，而后者小一两个数量级。

值得强调，这个想法之所以「深刻」，在于它揭示了一个被忽视的事实：扩散把绝大部分算力浪费在了人眼根本不在意的地方。Ho 的原版 DDPM 在像素上逐步去噪，意味着网络要花同样的力气去雕琢「这片天空的第 10001 个像素该是哪个蓝」——可这种微观细节既不影响「图里是什么」，又完全可以由一个解码器在最后一步批量补出。把这些感知冗余从扩散的工作清单里划掉，剩下的语义内容只需在一个小了几十倍的空间里生成，质量却几乎不损——这就是 latent 扩散用一个简单结构换来巨大效率的根本原因，也是它从 2022 年起统治开源生成的理由。

一句话抓住 LDM：把「压缩」和「生成」拆成两件事，各用最擅长的工具。压缩交给自编码器（一次性、确定性、擅长去冗余），生成交给扩散（迭代、随机、擅长建模分布）。下一节会看到，这个拆分不只是省算力，还在概念上更干净。

2两阶段分工：感知压缩 vs 语义生成

两阶段分工：感知压缩 vs 语义扩散

LDM 最重要的思想，是把图像生成显式拆成两个职责不同的阶段：

阶段由谁负责做什么性质
① 感知压缩VAE（E/D）去掉人眼不敏感的高频冗余，把图压成规整的低维 latent，并能高保真还原确定性、一次性、只训一次
② 语义生成扩散网络在 latent 空间建模数据分布，从噪声采样出有意义的 latent随机、迭代、表达力强

为什么这个拆分是对的？因为图像信息天然分两层。Rombach 画过一条「率失真」曲线：图像的比特绝大多数花在感知细节（纹理、噪点、细微梯度）上，而这些对「图里是什么」几乎无贡献。VAE 负责把这部分感知冗余压掉（perceptual compression），剩下的 latent 主要承载语义结构（构图、物体、关系）。于是扩散——这个昂贵但强大的生成器——只需在语义层面工作，不必浪费算力去逐像素生成那些本可由解码器补出的细节。

这个拆分还有一个概念上的好处，常被效率叙事盖过：它让两个阶段各自的「目标」变得纯粹。若在像素上端到端训扩散，网络既要学语义（这是只猫）又要学渲染（猫毛的微观质感），两个目标耦合、互相牵制。拆开后，VAE 用确定性的重建/感知损失把「渲染」学到极致，扩散用概率目标把「语义分布」学到极致——每个网络只做自己最擅长、最容易优化的事。这也是为什么 latent 扩散不仅更快，往往同等算力下质量还更高：不是因为信息更多，而是因为分工让每部分都学得更好。

直白说

通俗讲：VAE 像一个「画框 + 笔触引擎」，它学会了「好图长什么质感」；扩散则像「构图师」，只负责决定画面里有什么、怎么布局。构图师不需要亲手画每一根头发丝——他给出 latent，笔触引擎（解码器）自动渲染出逼真的细节。

严谨说

严谨地：两阶段是解耦训练的。先单独训 VAE（自编码重建损失 + 感知损失 + 轻微对抗损失 + KL 正则），训好后冻结；再在其 latent 上训扩散。这样扩散面对的是一个固定、规整、低维的 latent 分布，训练目标干净、收敛稳定。

两阶段也带来一个根本约束：扩散生成质量的上限被 VAE 的重建质量卡死。VAE 还原不出的细节（如清晰小字、规则纹理），扩散再强也变不出来——它只在 latent 空间工作，最后那一步解码不归它管。这就是为什么 SD3/Flux 都在反复升级 VAE（更多 latent 通道、更好的重建），以及为什么早期 SD 画文字总是糊的。

3VAE：把图像压进 latent

VAE：把图像压进 latent

LDM 的压缩器是一个 VAE（变分自编码器），但用法和经典 VAE 略有不同——它不追求 latent 严格服从标准高斯，只要求 latent规整、低维、可高保真解码。其结构是：

  • E: x → (μ, σ)：编码器（卷积下采样）把图像压成 latent 的均值与方差。SD 用下采样因子 f=8：512×512×3 → 64×64×4。
  • z = μ + σ⊙ε：重参数化采样一个 latent（ε∼N(0,I)），训练时引入随机性，推理时常直接取 μ。
  • D: z → x̂：解码器（卷积上采样）把 latent 还原成图像。

训练目标是几项之和：重建损失（‖x-x̂‖ 让还原准）、感知损失（用预训练网络的特征比对，让还原看起来对而非逐像素对）、轻微的对抗损失（一个判别器逼解码器产生锐利真实的纹理）、以及一个很弱的 KL 正则（KL(N(μ,σ)‖N(0,I)) 防止 latent 方差爆炸、保持空间规整）。其中感知 + 对抗损失是关键——正是它们让 VAE 能在很高的压缩比下还原出锐利逼真的图，而不是经典 VAE 那种模糊的平均脸。

\[\mathcal{L}_{\text{VAE}}=\underbrace{\|x-\mathcal{D}(z)\|_1}_{\text{重建}}+\lambda_{\text{perc}}\,\mathcal{L}_{\text{LPIPS}}(x,\hat x)+\lambda_{\text{adv}}\,\mathcal{L}_{\text{GAN}}+\beta\,\mathrm{KL}\big(\mathcal{N}(\mu,\sigma)\,\|\,\mathcal{N}(0,I)\big)\]

还有一个看似琐碎、实则致命的工程细节：latent 缩放。VAE 输出的 latent 方差未必是 1，而扩散假设加的是单位方差噪声。SD 实测出一个常数（约 0.18215），把 latent 乘上它使方差≈1，再喂给扩散。不做这步缩放，扩散训练会直接发散。notebook 里我们会在玩具上复现「不缩放就训不动」这个现象。

一个自然的疑问：既然只是想降维，为什么不直接把图缩小（resize 到 64×64）就好？因为简单缩小是不可逆的硬丢弃——丢掉的高频细节再也回不来，解码出的图必然糊。VAE 的高明在于它学的是一个可逆的、内容自适应的压缩：哪些细节能丢、哪些必须留，由数据驱动地学出来；而且解码器记住了「这类图的细节长什么样」，能在还原时合成出合理的高频纹理，而非简单插值。这就是为什么 VAE 的 latent 虽小，解码却能锐利——它不是在「放大模糊的小图」，而是在「从语义编码渲染细节」。这一点也预示了它的软肋：解码器没见过的细节（如特定字体的小字）它编不出来，于是糊。

把 VAE 想成「学过的有损压缩」（像 JPEG，但为生成而生）。JPEG 用固定的 DCT 变换；VAE 用神经网络学一个为后续扩散量身定制的压缩——既要压得狠（省算力），又要还原得真（保质量），还要 latent 空间规整（利于扩散建模）。这三个目标的平衡，就是为什么 VAE 要那么多损失项。

4在 latent 上做扩散

在 latent 上做扩散：和像素扩散一模一样

一旦有了冻结的 VAE，latent 扩散的训练和普通扩散没有任何区别——只是把所有 x 换成 z=E(x)。这正是 LDM 优雅的地方：它不改扩散的数学，只换了扩散发生的空间。整个训练循环是：

训练一步（latent 扩散）： 1. 取一张图 x，编码：z0 = E(x) * scale # 进入 latent 空间（一次性） 2. 采时间步 t ~ U(1..T)，采噪声 ε ~ N(0, I) 3. 闭式加噪：z_t = √ᾱ_t · z0 + √(1-ᾱ_t) · ε # 和像素扩散同一公式，只是对象是 z 4. 网络预测噪声：ε̂ = εθ(z_t, t, c) # c = 条件(文本/类别)，下一节讲 5. 损失：‖ε - ε̂‖²，反传更新 εθ # 经典 DDPM 目标 （VAE 全程冻结，不参与训练）

采样也一样，只是终点不同：从纯噪声 z_T∼N(0,I) 出发，用任意采样器（DDPM/DDIM/DPM-Solver）在 latent 空间逐步去噪得到 ẑ_0，最后只在最末尾解码一次：x̂ = D(ẑ_0 / scale)。注意解码只发生一次（在所有去噪步之后），所以解码器的开销可忽略——昂贵的是 latent 空间里那几十步去噪，而它们现在便宜了 48 倍。

直白说

所以学过基础扩散（C16）的你，已经会了 latent 扩散的 90%。唯一的新东西就是头尾各加一次 VAE 编/解码，中间的「加噪—去噪」完全照搬。这也是为什么本课把它放第一个模块——它是从「基础」迈向「前沿」最平滑的一步。

严谨说

一个值得注意的推论：latent 扩散的 SNR、噪声表设计、loss 加权，原则上都该针对 latent 的统计重新调（latent 的尺度、各通道方差与像素不同）。实践中 SD 直接复用了像素扩散的线性噪声表（配合 latent 缩放），但后续工作（如 zero-terminal-SNR、EDM 风格噪声表）指出这并非最优——这是模块 03/04 会再触及的细节。

降维≠降质

一个常见误解：以为 latent 扩散「降维了所以信息变少、质量必然下降」。不对。降的是人眼冗余，语义信息几乎无损地保留在 latent 里；质量瓶颈在 VAE 的重建能力，而非扩散在低维空间「看不全」。事实上同等算力下，latent 扩散因为不必浪费在像素细节上，整体质量反而更高——这正是它成为主流的原因。

5Stable Diffusion 完整架构

Stable Diffusion 的完整架构

把前面拼起来，再加上「文本条件」，就是完整的 Stable Diffusion。它由三大件组成：

组件作用SD1/2 用什么SD3/Flux 升级为
VAE（E/D）图像 ↔ latent 的感知压缩KL-VAE, f=8, 4 通道更多通道(16)、更好重建
去噪骨干在 latent 上预测噪声/速度U-Net + cross-attentionDiT / MM-DiT（模块 02）
文本编码器把 prompt 编码成条件向量CLIP text encoderCLIP + T5-XXL

文本如何注入？SD1/2 的 U-Net 用 cross-attention：每个图像位置（query）去「查阅」所有文本 token（key/value），从而把 prompt 的语义渗透到生成的每一处。时间步 t 则通过正弦嵌入 + MLP 注入。整条管线是：prompt → 文本编码器 → 条件向量 c；噪声 z_T + c + t → 去噪骨干迭代 → ẑ_0 → VAE 解码 → 图像。

Stable Diffusion 推理全景： prompt ──► [文本编码器 CLIP/T5] ──► 条件向量 c ─────────┐ ▼ z_T ~ N(0,I) ──► [去噪骨干 (UNet/DiT)] ◄── t (时间步嵌入) (latent) │ 重复 N 步：z_t → z_{t-1}（每步用 c 引导，CFG 见模块04） ▼ ẑ_0 (干净 latent) ──► [VAE 解码 D] ──► 512×512 图像 （只解码一次）

理解了这张图，你就理解了当代几乎所有文生图模型的骨架。SD3、Flux、甚至视频模型 SoRA，都是在替换其中的某个组件：把 U-Net 换成 DiT（模块 02），把扩散目标换成 flow matching（模块 03），把采样压成少步（模块 05）。但「VAE 压缩 + latent 去噪 + 条件注入 + 解码」这个两阶段 + 条件的骨架始终不变。本课后面的模块，本质都是在升级这张图里的某个方框。

再点出一个采样视角的细节，为模块 03/05 埋伏笔：上图中「重复 N 步」的去噪，既可以用随机的 DDPM，也可以用确定性的 DDIM。DDIM 把反向过程写成一个常微分方程（ODE）的离散化——给定同一个初始噪声 z_T，它每次都生成同一张图，且可以大步跳、几十步甚至更少就出图。这个「扩散其实可以是一个确定性 ODE」的洞察，正是模块 03（flow matching 把生成直接定义成 ODE）和模块 05（consistency 把 ODE 压成一步）的起点。所以你在这里看到的 latent 去噪循环，不是终点，而是后面所有「更快采样」故事的开篇。

为什么 SD3/Flux 要叠加 T5-XXL 文本编码器？因为 CLIP 的文本理解偏「看图说话」式的浅层对齐，对长 prompt、拼写、计数、空间关系理解弱。T5 是强语言模型，能解析更复杂的指令。这印证了一个趋势：生成质量的瓶颈正从「画得真」转向「听得懂」——文本编码器越来越重要。

6为什么是 latent：算力账与权衡

为什么是 latent：算力账与权衡

把 latent 扩散省的算力算一笔账。扩散每步的计算量大致正比于其操作空间的元素数。像素空间 512×512×3≈7.9e5，latent 空间 64×64×4≈1.6e4，比值约 48 倍。也就是说，latent 扩散的每一步去噪，理论上比像素扩散省约 48 倍的计算——而采样要跑几十步，这个节省被逐步放大。训练同理：能在相同算力下处理多得多的图、迭代更多步。

\[\frac{\text{像素空间维度}}{\text{latent 空间维度}}=\frac{H\cdot W\cdot 3}{(H/f)(W/f)\cdot c}=\frac{3f^2}{c}\overset{f=8,c=4}{=}\;48\]

但下采样因子 f 不是越大越好，它是一个核心权衡：

f 取值latent 大小扩散算力重建质量
f=4128×128（大）省得少细节保留好
f=8（SD 选择）64×64（适中）省约 48×甜点：质量/算力平衡
f=16/3232×32（很小）省得多细节丢失、解码模糊

Rombach 实验发现 f=4~8 是甜点：f 太小（如 1，即像素扩散）几乎不省算力；f 太大（16/32）则 VAE 压得太狠、丢失细节、解码变糊，扩散学得再好也救不回。SD 选 f=8 正是这个平衡点。这也解释了一个现象：提高生成分辨率，往往是加大 latent（或换更强 VAE），而非简单放大像素——因为算力账要在 latent 空间算。

这笔账还有一个常被忽略的维度：注意力的成本。去噪骨干里若含自注意力（U-Net 的中段、DiT 的全程，见模块 02），其计算量正比于 token 数的平方。在像素空间，token 数 ∝ 像素数，注意力成本爆炸；搬进 latent 后 token 数降为原来的 1/f²，注意力成本降 f⁴ 倍（f=8 即约 4096 倍）。所以 latent 化对「Transformer 骨干」的意义远比对卷积骨干更大——这正是为什么 DiT 这种纯注意力骨干几乎只在 latent 空间用，也是 latent 扩散与模块 02 的 DiT 天然互补的深层原因。

还有个隐藏成本常被忽略：VAE 本身要先训练好，而训一个高质量 VAE（感知 + 对抗损失、防止伪影、各通道均衡）相当不平凡。latent 扩散把「生成」的难度降低了，却把一部分难度转移到了「训练好压缩器」上。SD3 论文里关于 16 通道 VAE 的讨论，正是这部分隐藏工作量的体现。

7把玩具跑起来：最小实现

把玩具跑起来：latent 扩散的最小实现

配套 notebook 不加载真实 SD（保持纯 numpy、CPU 秒级），而是搭一个能完整跑通两阶段的玩具：

  1. 玩具数据：把若干「小图」（其实是几十维向量，可视作展平的小 patch）作为我们的「图像」，它们其实活在一个低维子空间里（有冗余可压）。
  2. 玩具 VAE：用 PCA / 线性投影当编码器 E（降到 latent 维度），其转置当解码器 D。验证 D(E(x))≈x（重建），且 latent 维度远小于原维度（压缩）。
  3. latent DDPM：在 latent 上实现闭式加噪、一个小去噪网络（甚至闭式最优去噪）、DDPM 采样。验证采样出的 latent 解码后落在数据流形附近。

通过这个玩具，你会亲手确认本模块的每个论点：VAE 往返近似恒等（重建对拍）、latent 维度远小于像素（压缩比）、latent 加噪 == 像素加噪同一公式（闭式对拍）、不做 latent 缩放扩散就训不动（数值现象）、以及在 latent 上采样 + 解码能还原数据分布（端到端）。维度小到能 print、能画散点，但每一步都和真实 SD 的逻辑一一对应。

notebook 的玩具 VAE 用线性投影（PCA），真实 SD 用深度卷积 + 感知/对抗损失——结构更复杂，但「编码到低维、解码还原、扩散只在 latent 上」的骨架完全相同。读完想深入，直接看 Rombach 2022 (LDM) 与 diffusers 库的 AutoencoderKL 实现。

8研究前沿与开放问题

研究前沿与开放问题

  • 更好的 latent 空间：VAE 的重建上限直接卡死生成质量。SD3 用 16 通道 VAE 提升细节，但「latent 该多大、几通道、是否该为 DiT/flow 量身设计」仍是开放问题。也有工作探索完全去掉 VAE 的端到端像素 DiT。
  • latent 与扩散的协同设计：目前 VAE 与扩散分开训、latent 统计被动接受。能否联合优化、或让 VAE 产出「更适合扩散建模」的 latent（如各向同性、流形更平），是活跃方向。
  • 单步 / 端到端：latent 扩散仍需多步采样。把它与少步蒸馏（模块 05）、对抗目标结合，做到「latent + 单步」是实时生成的关键（SDXL-Turbo、LCM 走的就是这条路）。
  • 视频与 3D 的 latent：视频/3D 的冗余更大、压缩潜力更高，但时空一致的 VAE 远比图像难。SoRA 用时空 latent，但高质量视频 VAE 仍是瓶颈。
  • latent 的可解释与可编辑：latent 空间的几何（插值是否语义连续、方向是否对应概念）尚未被充分理解，直接关系到可控编辑、风格迁移等下游应用。

必读：Rombach 2022《High-Resolution Image Synthesis with Latent Diffusion Models》（LDM/SD 原始论文）；进阶看 SDXL（工程化）、SD3（16 通道 VAE + DiT + flow）、VQGAN（VAE 的感知/对抗训练前身）。完整清单见 references.md。
