1从 U-Net 到 Transformer 骨干

模块 01 把扩散搬进了 latent 空间，但还没碰「去噪网络长什么样」。早期 Stable Diffusion 的去噪骨干是 U-Net——一个带跳跃连接的编码-解码卷积网络，扩散从 DDPM 起就用它。U-Net 有很强的归纳偏置（局部性、平移等变），擅长纹理，在中小规模上效果好。但当人们想把模型做大、做通用时，U-Net 暴露了两个短板：scaling 行为不平滑（堆大了收益递减、难调），以及长程依赖弱（卷积感受野有限，全局结构靠少数注意力层勉强补）。

Peebles & Xie 2023 的 Diffusion Transformer (DiT) 做了一件「显然但有效」的事：把去噪骨干从卷积 U-Net 整个换成标准 Transformer。既然 Transformer 在语言、在视觉分类（ViT）上都被证明能随规模平滑变强，为什么不让它当扩散的大脑？DiT 的回答是肯定的——它不仅可行，还揭示了扩散模型也有干净的 scaling law：质量随计算量可预测地提升。这一发现直接催生了 SD3、Flux、以及视频模型 SoRA——它们的骨干全是 DiT 的变体。

直白说

一句话：DiT 把「图像去噪」重新表述成「序列处理」。先把 latent 切成一串小块（token），像处理一句话一样用 Transformer 处理它们，最后拼回去。Transformer 不挑数据类型——文字、图块、视频帧块，只要变成 token 序列，同一套注意力机制都能处理。这种通用性正是它能 scale、能跨模态的根源。

严谨说

严谨地：DiT 用 patchify 把 H×W×C 的 latent 切成 (H/p)·(W/p) 个 token，走 N 层标准 Transformer block（自注意力 + MLP），用 adaLN 注入时间步与条件，最后 unpatchify 投回 latent 形状。整个网络没有卷积、没有 U-Net 的跳连，就是一个序列模型——但作用在图块上。

为什么这件「显然」的事直到 2023 才被做对、做火？因为它需要两个前置条件凑齐：① latent 扩散（模块 01）把空间压小，使注意力的 O(n²) 成本可承受；② 一个稳定的条件注入方式（adaLN-zero），让深 Transformer 在扩散这种敏感任务上训得动。DiT 的贡献与其说是「想到用 Transformer」，不如说是把它真正调稳、并量出 scaling law。

2Patchify：图像变 token 序列

Patchify：把图像变成 token 序列

Transformer 吃的是 token 序列，而 latent 是 H×W×C 的张量。第一步 patchify 把后者变成前者，做法和 ViT 完全相同：

  1. 把 latent 切成 p×p 的不重叠小块（patch）。若 latent 是 32×32×4、p=2，则切出 16×16=256 个块。
  2. 把每个 p×p×C 的块展平成长度 p²·C 的向量。
  3. 用一个线性层把每个展平向量投到 Transformer 的隐藏维 d，得到一个 token。
  4. 给每个 token 加上位置嵌入（标明它在图中的 2D 位置），因为注意力本身对顺序无感。
\[\text{token 数}\;n=\frac{H}{p}\times\frac{W}{p},\qquad \text{每 token 维度}\;d;\qquad \text{patchify}:\ \mathbb{R}^{H\times W\times C}\to\mathbb{R}^{n\times d}\]

patch 大小 p 是核心超参，它直接决定序列长度 n，从而决定算力：p 越小、token 越多、越精细，但注意力成本按 n² 涨。DiT 论文系统扫了 p∈{2,4,8}：p=2 质量最好但最贵，p=8 便宜但糙。这正是「token 数 = 算力旋钮」的体现，和语言模型里序列长度的地位一样。

输出端有个对称的 unpatchify：网络最后把每个 token 投回 p²·C 维、reshape 成 p×p×C 的块、按位置拼回 H×W×C 的 latent。patchify 进、unpatchify 出，保证去噪网络的输入输出形状一致（都是一个 latent），符合扩散「预测同形状噪声」的要求。这一进一出是 DiT 把「序列模型」套到「图像去噪」上的胶水。

这里藏着一个深刻的对比，呼应模块 01 的算力账。卷积的成本随像素数线性增长，而自注意力随 token 数平方增长。所以「把图切成多少 token」对 Transformer 骨干是生死攸关的——这也是为什么 DiT 几乎只在 latent 空间用（token 已经少了几十倍），且 patch 不能太小。换句话说，patchify 不只是「把图喂进 Transformer 的格式转换」，它还是控制注意力爆炸的闸门：p 把 H×W 个像素位置压成 (H/p)(W/p) 个 token，注意力成本随之降 p⁴ 倍。理解这一点，才理解 DiT 设计里每个超参背后的算力权衡。

位置嵌入不是可选项。把图切成 token 后，序列里 token 的顺序是人为拉平的，注意力看不出哪个块在左上、哪个在右下——若不加位置信息，模型会把图当成一袋无序的块，生成全是乱的。DiT 用固定的 2D 正弦位置编码（不学习），ViT 多用可学习的。本质都是把空间结构显式注入到本无空间概念的注意力里。

3时间步嵌入：告诉网络现在多噪

时间步嵌入：让网络知道「现在多噪」

扩散去噪网络是同一套权重处理所有噪声级别的：第 1 步（几乎纯噪声）和第 999 步（几乎干净）都用它。所以网络必须知道「现在是第几步、噪声有多大」，否则无从下手。这个信息通过 时间步嵌入 注入。

做法和 Transformer 的位置编码同源：把标量时间步 t 先用正弦编码映射成一个高维向量（不同频率的 sin/cos），再过一个小 MLP 得到时间步嵌入 emb_t∈R^d。正弦编码的好处是：它把一个标量平滑地展开成多尺度的特征，让网络既能分辨相邻步（高频分量），又能感知大范围的噪声趋势（低频分量）。

\[\text{PE}(t)_{2i}=\sin\!\Big(\frac{t}{10000^{2i/d}}\Big),\quad \text{PE}(t)_{2i+1}=\cos\!\Big(\frac{t}{10000^{2i/d}}\Big);\qquad \text{emb}_t=\text{MLP}(\text{PE}(t))\]

如果有额外条件（类别标签、文本），通常也编码成一个向量 emb_c，与时间步嵌入相加或拼接成一个统一的「条件向量」c = emb_t + emb_c。DiT 的关键设计是：这个条件向量不作为额外 token 塞进序列（那样会增加序列长度、且注入方式生硬），而是通过下一节的 adaLN 去调制每一层——这是 DiT 区别于「把条件当 token」的 U-ViT 等方案的核心选择。

把时间步嵌入想成给网络的「闹钟」：它告诉网络现在几点（去噪进行到哪一步），网络据此调整行为——早期（高噪）专注勾勒大轮廓，后期（低噪）专注修细节。没有这个闹钟，同一套权重不知道该粗画还是细修，必然学不好。所有扩散骨干（U-Net 也一样）都有时间步嵌入，DiT 只是把它和条件合并、经 adaLN 注入。

4adaLN-zero：条件注入核心

adaLN-zero：DiT 的条件注入核心

这是 DiT 最关键、也最该理解的设计。问题是：怎么把条件向量 c（时间步 + 类别/文本）注入 Transformer 的每一层？DiT 的答案是 adaptive normalization (AdaLN)——用条件去调制归一化层的缩放和平移。

标准 LayerNorm 是 LN(h)=γ·norm(h)+β，其中 γ,β 是学到的固定参数。AdaLN 把它们改成由条件向量预测的：γ,β = MLP(c)。于是每一层的归一化行为都随当前时间步与条件动态变化——这是一种轻量却强大的条件注入（FiLM 思想：feature-wise linear modulation）。DiT 进一步对每个 block 的注意力和 MLP 子层各预测一组 (γ,β)，还额外预测一个残差缩放系数 α：

\[h \leftarrow h + \alpha_1\cdot\text{Attn}\big(\gamma_1\!\odot\!\text{norm}(h)+\beta_1\big),\qquad h \leftarrow h + \alpha_2\cdot\text{MLP}\big(\gamma_2\!\odot\!\text{norm}(h)+\beta_2\big)\]

现在到 adaLN-zero 这个画龙点睛之笔：把残差缩放 α 的预测层初始化为零，使训练一开始每个 block 的 α≈0，于是 h ← h + 0 = h——每个 block 初始就是恒等映射。整个 DiT 一开始等价于「什么都不做」，再从这个干净起点逐渐学会贡献。这个技巧（借鉴自 ResNet 的 zero-init 残差、GAN 的 zero-init）让非常深的 DiT 也能稳定训练，是 DiT 能 scale 到几十层的关键。

直白说

通俗讲：adaLN-zero 让网络「先安静，再发言」。如果一开始每层都乱调归一化，深网络的信号会被搅乱、训练发散。让每层从「恒等（不干扰）」起步，再慢慢学着调制，就像新员工先观察再插手，稳得多。

严谨说

严谨地：zero-init 残差使初始输出方差不随深度累积爆炸（每层贡献从 0 开始），梯度也更干净。它把「深度」从训练负担变成可用容量，配合 Transformer 的残差结构，是 DiT 论文中唯一让训练稳定性显著提升的架构选择（他们对比过 in-context、cross-attention、adaLN、adaLN-zero，后者明显最好）。

zero-init 的威力

别小看「初始化成零」这个细节。DiT 论文的消融实验显示：同样的 adaLN，零初始化 vs 普通初始化，FID 差距巨大。这类「让模块初始为恒等」的 zero-init 技巧在现代深度模型里反复出现（LoRA 的 B 矩阵零初始、各种残差适配器）——记住这个模式，它远比看起来重要。

5DiT vs U-Net：范式更替

DiT vs U-Net：一次范式更替

把 DiT 和 U-Net 正面对比，看清这次骨干更替换来了什么、代价是什么：

维度U-Net（SD1/2）DiT（SD3/Flux/SoRA）
基本算子卷积 + 少量注意力纯注意力 + MLP
归纳偏置强（局部性、平移等变）弱（几乎无空间先验）
长程依赖靠少数注意力层勉强补天生全局（每层全连接注意力）
条件注入cross-attention（文本）adaLN-zero（时间步/类别）
scaling 行为堆大收益递减、难调平滑可预测（有 scaling law）
小数据 / 小模型更省、更稳需更多数据才发力
算力瓶颈卷积为主注意力 O(n²)，靠 latent 化压

核心权衡是归纳偏置 vs 可扩展性。U-Net 的卷积自带「图像是局部的、平移不变的」先验，小数据下这是免费的好处——不用从数据里学这些规律。但先验也是枷锁：它限制了模型能表达的函数，大数据下反而拖后腿。Transformer 偏置弱、几乎从零学一切，小数据下吃亏，但数据和规模一上来，它能学到比人手设计的先验更好的规律——这正是「大数据下弱偏置胜出」的 bitter lesson 在扩散骨干上的复现。

这也解释了为什么 DiT 几乎总和 latent 扩散（模块 01）绑定出现：DiT 的注意力是 O(n²) 的，在像素空间 token 数爆炸、算不动；搬进 latent 后 token 数降几十倍，注意力才可承受。latent 化让 DiT 可行，DiT 又让扩散能 scale——两者是相互成就的前沿组合，合起来就是 SD3/Flux 的基本盘。

还有一个常被问到的实务点：DiT 丢掉了 U-Net 标志性的「跳跃连接」，会不会丢失多尺度信息？答案是不会，因为机制不同。U-Net 需要跳连，是因为卷积下采样会逐层丢失空间分辨率，必须用跳连把高分辨率特征「接力」到解码端。而 DiT从不下采样——所有 token 自始至终保持同一分辨率、每层都能通过全局注意力直接访问任意位置，多尺度信息天然保留在序列里，无需跳连补救。这是「卷积金字塔」与「等分辨率 Transformer」两种范式的根本差异：前者靠层级结构 + 跳连传递信息，后者靠全局注意力一步到位。

不必把这看成「DiT 全面碾压 U-Net」。在小数据、小算力、或强结构先验有用的场景（如医学影像），U-Net 仍可能更优。DiT 的胜出是在「大数据 + 大算力 + 追求通用」这个前沿设定下的——而这恰好是领先实验室所处的设定。选骨干和选别的架构一样，看的是你的数据与算力规模。

6Scaling law：为何成大模型骨干

Scaling law：DiT 为何成为大模型骨干

DiT 论文最有影响力的结果，不是「Transformer 能当扩散骨干」，而是扩散模型有干净的 scaling law：生成质量（FID）随模型计算量（Gflops）平滑、可预测地下降。

Peebles 用一个统一的「计算量」指标（由深度、宽度、patch 数共同决定的每次前向 Gflops）横扫了不同大小的 DiT，发现：不管你用什么方式增加计算（加深、加宽、减小 patch 增加 token），只要总 Gflops 上去了，FID 就跟着降，且不同配置几乎落在同一条曲线上。这意味着扩散和语言模型一样，进入了「可预测地花钱买质量」的时代——这对工业界是巨大的吸引力。

直白说

通俗讲：scaling law 把「炼丹」变成了「投资」。以前堆大模型像赌博，不知道值不值；有了 scaling law，你能预测「再花 2 倍算力，FID 大概降到多少」，从而理性地决定投多少。这种可预测性，是 DiT 取代 U-Net 成为大模型骨干的商业理由（不只是技术理由）。

严谨说

严谨地：U-Net 不是不能 scale，而是它的 scaling 不如 Transformer 平滑、各组件（深度/宽度/分辨率）耦合、最优配置难找。Transformer 的均匀结构（堆同样的 block）让 scaling 干净——这与语言模型的经验一致，也是为什么「把成功的 Transformer scaling 经验搬到扩散」如此自然且有效。

这条 scaling law 直接通往 SoRA。视频是图像的时间堆叠，token 数更多、算力需求更大——正是 scaling 友好的骨干才扛得住。SoRA 把 DiT 的 2D patch 推广成时空 patch（把视频切成时空小立方体当 token），用同一套「patchify + Transformer + scaling」的配方，把图像生成的成功复制到视频。没有 DiT 的 scaling 论证，就不会有 SoRA 这种「大力出奇迹」的视频模型——这是模块 02 影响力的最佳注脚。

把这条线索拉到本课全局：scaling law 之所以重要，是因为它把「该不该换骨干」从审美之争变成了可量化的工程决策。U-Net 时代，提升质量靠各种手工技巧（更好的注意力位置、更巧的跳连），收益难预测、不可复制；DiT 时代，提升质量主要靠加算力，路径清晰、可投资。这正是为什么短短两年内，几乎所有领先实验室都把骨干切换到了 DiT——不是因为它在小基准上分数更高，而是因为它给出了一条可预测地通往更强模型的路。这也是本课反复强调「前沿」二字的含义：前沿不只是更好的结果，更是更可扩展的方法。

DiT 还有个多模态变体 MM-DiT（SD3 用）：把图像 token 和文本 token 拼在一起做联合双流注意力，让文本和图像深度互相 attend，比 U-Net 时代单向的 cross-attention 对齐更好。这是模块 04（可控生成）的架构基础之一。

7把玩具跑起来：搭一个 DiT block

把玩具跑起来：从零搭一个 DiT block

配套 notebook 用纯 numpy 把 DiT 的每个零件从零搭出来，在一个玩具小图（如 8×8×3 的张量当 latent）上验证：

  1. patchify / unpatchify：把小图切块、展平、投影成 token 序列，再逆回去。验证 unpatchify(patchify(x)) 形状还原、且线性投影可逆时数值还原。
  2. 正弦时间步嵌入：实现多频 sin/cos 编码，验证不同 t 得到不同嵌入、且相近 t 嵌入也相近（平滑）。
  3. adaLN 调制：用条件向量预测 γ,β,α，验证 adaLN-zero 初始时 block 是恒等映射（最关键的性质）。
  4. 一个完整 DiT block：自注意力（从零实现）+ adaLN + 残差，跑一遍前向，验证形状一致、且 zero-init 时输出 == 输入。

通过这个玩具，你会亲手确认本模块的核心论点：图像能被无损地序列化成 token 再拼回（patchify 对拍）、时间步被平滑编码（嵌入连续性）、以及最重要的——adaLN-zero 让深 DiT 从恒等起步（零初始化时整个 block 输出等于输入，对拍 atol 级一致）。这些都是真实 DiT 稳定可 scale 的根基。

notebook 的注意力和 MLP 是玩具实现（小维度、不训练），但 patchify、adaLN-zero、时间步嵌入的逻辑与真实 DiT 逐行对应。想深入直接读 Peebles & Xie 2023 (DiT) 与其官方代码 DiT/models.py，以及 SD3 的 MM-DiT。

8研究前沿与开放问题

研究前沿与开放问题

  • 更高效的注意力：DiT 的 O(n²) 注意力在高分辨率/视频上仍是瓶颈。线性注意力、窗口注意力、token 合并/剪枝、以及把 FlashAttention（C36/C08）用上，都是让 DiT 扩到更大序列的活跃方向。
  • 条件注入的演化：从 adaLN（DiT）到 MM-DiT 的联合注意力（SD3），条件注入仍在演化。如何最高效地融合文本/图像/多模态条件，是当前架构竞争的焦点。
  • DiT 的 scaling 极限：图像 DiT 的 scaling law 已较清楚，但视频/3D/多模态的 scaling 行为、最优 patch 与深宽比配比，仍在摸索。SoRA 之后这是最热的方向。
  • 架构与目标的协同：DiT 骨干 + flow matching 目标（模块 03）+ 少步蒸馏（模块 05）的组合，哪种搭配最优？SD3 给了一组答案，但设计空间远未穷尽。
  • 统一的生成骨干：能否用一个 DiT 同时做图像、视频、音频、甚至跨模态生成？「一切皆 token + 一个大 Transformer」的愿景正在被推进，DiT 是其图像/视频侧的承载，与语言模型的 Transformer 在底层架构上正在收敛。
