1这门课讲什么

欢迎来到 现代模型架构（前沿）。这门课只讲一件事：把领先实验室真实在用的架构组件从零手写一遍。

如果你读过原版 Transformer（C1 课程），你会发现今天的 Llama-3、DeepSeek-V3、Qwen、Mixtral、Mamba 在结构上做了一系列看似零碎、实则环环相扣的改动。本课的视角是：每一处改动都在解决一个具体的瓶颈——要么是质量，要么是 KV cache 显存，要么是训练稳定性，要么是序列长度。

学完你应当能回答这类面试题：为什么 Llama 用 RoPE 而不是绝对位置编码？GQA 相比 MHA 省了多少 KV cache？MLA 又比 GQA 强在哪？MoE 怎么把参数和算力解耦？RMSNorm 凭什么能省掉 LayerNorm 的减均值？Mamba 为什么是线性时间？——并且能在 numpy 里把它们都实现出来。

2演化主线与课程地图

演化主线：vanilla Transformer → 现代 LLM

vanilla Transformer (2017) │ 位置：绝对正弦 → 难外推、相对关系靠学 │ 注意力：MHA → KV cache 随头数线性涨（推理瓶颈） │ FFN：ReLU → 等参数下表达力一般 │ 归一化：Post-LN → 深层难训、需 warmup ▼ 现代 LLM (Llama-3 / DeepSeek-V3 / Qwen) │ 位置：RoPE ← 模块 01 相对位置、可外推 │ 注意力：GQA / MLA ← 模块 02 压 KV cache │ FFN：SwiGLU (+MoE) ← 模块 03 门控前馈 + 稀疏激活 │ 归一化：Pre-RMSNorm ← 模块 04 更省、更稳 ▼ 另一条路线 Mamba / SSM ← 模块 05 线性时间，绕开注意力

这张图就是课程地图。模块 01–04沿着 Transformer 的改良路线走；模块 05介绍一条绕开注意力的替代路线（状态空间模型）。

4环境与运行

环境极简：只需 numpy（画图可选 matplotlib）。全课 CPU 秒级运行，无需 GPU、torch、API key。

conda create -n frontier-arch python=3.11 -y && conda activate frontier-arch
pip install -r requirements.txt
jupyter lab

notebook 里的实现都是教学玩具版：维度小、追求看懂机制而非性能。真实工程实现（FlashAttention 融合、Triton kernel、分布式 MoE）在 C36/C24/C8 课展开。
