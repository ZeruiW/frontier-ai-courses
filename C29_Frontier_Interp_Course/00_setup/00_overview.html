1这门课讲什么

欢迎来到 前沿机制可解释性。这门课只追求一件事：让你从「会看 SAE 的特征仪表盘」变成「会从零训一个 SAE、会写 attribution patching、会用特征做 steering 与后门检测」。

机制可解释性（mechanistic interpretability）的野心，是把神经网络从一个行为黑盒还原成一台可读、可验证、可干预的机器——不只问「模型答得对不对」，而是问「它用了哪些特征、经过哪些组件、按什么算法得出这个答案」。如果我们能读懂并操控这些内部机制，就能在模型说之前知道它在想什么——这对评测、对齐、安全监控都是质的飞跃。

但这条路有一个拦路虎，它决定了整门课的结构：叠加（superposition）。神经网络要表示的特征数，远多于它的神经元数；于是它把多个特征非正交地挤进同一组神经元，结果是单个神经元对一堆互不相关的概念都激活（多义性）——你盯着一个神经元，根本读不出它在干什么。这就是为什么本课不从「读神经元」讲起，而从用字典学习把叠加拆开（SAE）讲起：要读懂模型，得先把被压在一起的特征解压成一组单义的特征。

学完你应当能回答这类问题（也是前沿 interp / 对齐岗位的高频面试题）：为什么不能直接读神经元？SAE 凭什么能从叠加里拆出单义特征？L1 / TopK / JumpReLU 三代 SAE 各解决了什么问题？attribution patching 为什么能把 O(N) 次 patching 压成一次前后向？SAE 特征 steering 和 difference-of-means 方向有何异同？怎么用特征检测一个潜伏后门？机制证据能不能写进 safety case，局限在哪？——并且能在 numpy 里把这些机制都从零实现、对拍 ground truth。

2与 C06 基础 interp 的分工

这门课和 C06 基础 interp 是什么关系

先把分工说清楚，免得重复。C06（基础机制可解释性）教的是 interp 的入门三件套：linear probe（在激活上训线性分类器读概念）、activation patching（替换激活做因果干预）、logit lens（把中间层投到词表看模型「当前的猜测」），以及表示即向量、表示几何这些地基。

本课（C29，前沿深化）默认你已经会这些，直接往前推一大步。我们的核心张力不再是「概念是不是一个方向」，而是叠加逼得我们必须用字典学习——并由此打开前沿 interp 真正在用的四件重武器：

主题C06 基础（已学）C29 前沿（本课）
读表示linear probe 读一个已知概念方向SAE：无监督把整层激活拆成上万个单义特征（L1/TopK/JumpReLU 三代）
特征本身「概念≈方向」的假设与验证叠加几何 + auto-interp：特征怎么挤、怎么自动命名、怎么度量拆得干净
因果定位逐个组件做 activation patchingattribution patching：一次前后向归因所有节点/边，规模化电路发现
干预沿一个方向 ablation/加法SAE 特征 steering：钳制特征、与 CAA 对比、量化副作用
安全用例deception probe 的雏形后门检测 + crosscoder model diffing：把机制证据接进 safety case 并讨论其局限

一句话定位：C06 让你能读一个你已经知道要找的方向；C29 让你能无监督地发现成千上万个你事先不知道的特征、把它们连成电路、并因果地操控它们。如果你对 probe / patching / logit lens 还不熟，强烈建议先过 C06——本课不会再从头讲它们。

3课程地图：从叠加到安全审计

课程地图：从叠加到安全审计

核心困境：特征数 ≫ 神经元数 → 叠加 → 多义 → 读单神经元行不通 模块 01 SAE 稀疏自编码器 字典学习把叠加解压成单义特征 │ L1 → TopK → JumpReLU 三代；dead features；重建-稀疏前沿；从零训 ▼ 模块 02 单义特征与叠加 叠加几何（怎么挤）、单义vs多义、特征激活统计、auto-interp 命名 │ 「特征到底长什么样、怎么知道拆干净了？」 ▼ 模块 03 电路与 Attribution 电路=因果子图；attribution patching 一阶近似；节点/边归因 │ 「哪些组件/特征因果地导致了这个行为？」 ▼ 模块 04 特征 Steering SAE 特征 clamp、强度扫描、与 CAA 对比、副作用度量、组合干预 │ 「读懂之后，能不能定向、干净地操控它？」 ▼ 模块 05 可解释性用于安全 后门/欺骗检测、crosscoder model diffing、机制证据进 safety case 与其局限 「这一切，怎么变成可信的安全证据？」

这不是松散的专题集合，而是一条递进链：先有 SAE 把叠加拆开（01），才能看清单个特征（02）、把特征连成电路（03）、进而操控特征（04）、最终把这套能力用于安全（05）。每一模块都建立在前一模块的产物之上：模块 03 的稀疏特征电路用模块 01 的 SAE 特征当节点；模块 04 的 steering 钳制的就是模块 01/02 的特征；模块 05 的后门检测与 model diffing 是前四模块工具的安全应用。

每一级台阶都对应一个可独立验证的能力：模块 01 你从零训的 SAE 会在合成数据上恢复出我们植入的真特征（匹配率可对拍）；模块 02 你能量化叠加程度、给特征排激活直方图；模块 03 你写的 attribution patching 会与真 activation patching对拍到近似误差可控；模块 04 你的特征 steering 会随强度单调改变目标行为、并能测出副作用；模块 05 你的后门探针会以高 AUC 在触发前报警。每一步都有 assert 兜底。

4方法论：合成数据 + toy 模型，在已知真相里学

方法论：用合成数据与 toy 模型，在「已知真相」里学

这是 interp 这门学科的标准方法论，也是本课的纪律：先在我们知道全部真相的玩具沙盒里把方法校准好，再上真模型。Toy Models of Superposition（Elhage 2022）正是这么做的——在一个能完全分析的小模型里搞懂叠加，再推广。本课全程沿用这条路。

直白说

真模型有上万维、数十亿参数，你不知道它真正的特征是什么，于是无法判断你的 SAE / patching / steering 到底对不对——你只能看「解释听起来合不合理」，这极易自欺。

严谨说

合成数据相反：特征是我们亲手植入的，因而完全已知。于是每个方法都能对拍ground truth：SAE 学到的字典 vs 真特征（匹配率、余弦相似度）、attribution patching vs 真 activation patching（近似误差）、steering 的效果 vs 我们埋的因果结构。有了可信的标尺，才谈得上方法可靠。

具体到本课的两样玩具：

  • 合成叠加数据：在低维空间（如 d=20）里植入比维度更多的真特征（如 m=40~80 个），按一个稀疏先验随机激活、线性叠加、加噪，生成「看起来像 residual stream」的激活。我们知道每个真特征方向与每条样本激活了哪些特征——这是检验 SAE / 特征分析的完美靶场（模块 01/02）。
  • numpy toy transformer：一个维度极小、参数我们完全掌握的玩具注意力 + MLP，用来做 activation patching 与 attribution patching 的对拍、以及电路定位（模块 03）；steering 与后门检测也在它和合成激活上演示（模块 04/05）。

务必清楚本课不做什么：不训真的十亿参数模型、不跑 GPU、不追 SOTA 数字。这些在你掌握了机制结构之后，是第二步（references 里的 TransformerLens / SAELens / Neuronpedia 接手）。本课负责把第一步——机制的结构与正确性夯死：你在 numpy 里验证过的 SAE 训练、归因近似、steering 干预逻辑，可以几乎一对一搬到真工具上。

5环境与运行

环境与运行

环境极简：只需 numpy（个别可视化可选 matplotlib）。全课 CPU 秒级运行，无需 GPU、无需下载大模型、无需联网。

conda create -n interp python=3.11 -y && conda activate interp
pip install numpy            # 必需
pip install matplotlib       # 可选，仅用于画帕累托前沿/直方图
jupyter lab

每个模块配一个 notebook，结构统一（对标本系列所有课）：先用 numpy 把机制从零实现并对拍/自检（5–6 个 worked 小节，每节都 print 出可读验证 + assert 兜底），再做 3–4 道带 assert 自测判分的 ✏️ 练习（先给骨架，自己填，再对照 📖 参考答案），最后一个真实数据胶囊（用真实 SAE / 模型的公开配置或数值算一笔账，把玩具接到现实）。

建议的学习节奏：先读完整章 HTML 建立机制直觉与数学，再打开 notebook 亲手实现。读和做缺一不可——只读会觉得「好像懂了」，真正动手训那个 SAE、让它恢复真特征、调稀疏度、写归因近似时，才会撞见魔鬼藏在哪些细节里（解码器列归一化、dead 特征、阈值、近似在哪失效）。这门课的深度正是为「动手」服务的。

配套先读：Elhage 2022《Toy Models of Superposition》建立叠加直觉（本课起点）；Bricken 2023《Towards Monosemanticity》是 SAE 的圣经；Templeton 2024《Scaling Monosemanticity》看它在 Claude 上的样子。完整清单（含 TopK/JumpReLU/attribution/crosscoder）见 references.md。

✅ 学完整门课，你应该能：
  1. 讲清为什么叠加使「读神经元」失效，从而为什么需要字典学习 / SAE；
  2. 从零训一个 SAE（L1 / TopK / JumpReLU），在合成数据上恢复植入的真特征并对拍匹配率；诊断并复活 dead features；画重建-稀疏帕累托前沿；
  3. 度量叠加程度、给特征排激活统计与直方图、说清 auto-interp 怎么自动给特征命名与打分；
  4. 实现 attribution patching 并与真 activation patching 对拍，理解一阶近似在哪准、哪失效；做节点/边归因定位电路；
  5. 用 SAE 特征做 steering（钳制 + 强度扫描），与 difference-of-means/CAA 对比，量化 off-target 副作用；
  6. 用特征/探针检测潜伏后门、用 crosscoder 思想做 model diffing；说清机制证据进 safety case 的价值与（相关性、对抗鲁棒性）局限。
