1范式转移：为什么 2025 之后评测的主战场是推理模型

2024 年 9 月 OpenAI 发布 o1，2025 年 1 月 DeepSeek 发布 R1 [DeepSeek-AI 2025, arXiv:2501.12948]—— 两个模型立起了同一个范式：用强化学习教会模型生成很长的思维链（chain-of-thought, CoT）， 在回答之前先"想"几千甚至几万个 token。从此 frontier 模型在数学、代码、科学问答上的成绩 不再主要由参数量决定，而是同时由推理时愿意花多少算力决定：o1 的 AIME 正确率随 思考 token 数近似对数线性上升；R1 在 RL 训练中自发学会了反思、回溯与自我验证。

直白讲

以前的模型像闭卷抢答：看到题目立刻报答案，水平高低全看"脑子里存了什么"（训练算力）。 推理模型像开卷慢做：先打草稿、检查、推翻重来，草稿纸给得越多分越高（测试时算力）。 于是"这个模型多强"这个问题本身变了——你必须先说清楚给了多少草稿纸，分数才有意义。 评测从"量一个点"变成了"量一条曲线"。

严谨讲

设任务分布 $\mathcal{D}$、推理策略 $\pi$（采样温度、思考长度、采样数、聚合方式……）、 测试时算力预算 $C$。旧范式评测估计的是标量 $A(\theta)$；新范式下能力是二元函数 $$A(\theta; C) = \mathbb{E}_{x\sim\mathcal{D}}\big[\mathrm{acc}\big(\pi_\theta(x; C)\big)\big],$$ 即 accuracy–compute curve。任何跨模型比较若不做 budget-matched（预算对齐），就引入了一个一阶混淆变量—— 这正是本课模块 05/07 要展开的测量学问题。

对 evaluation scientist，工作对象从"模型"换成了"模型 × 推理策略 × 预算"三元组：

维度chat 模型时代（–2024）推理模型时代（2024–）
输出形态直接给答案（或短解释）长 CoT（数千~数万 token）+ 最终答案，两者要分开评
决定性能的旋钮参数量、训练数据（train-time compute）再加一排：thinking budget、采样数 N、聚合方式、搜索宽度（test-time compute）
评测产物一个分数 + 误差棒一条 accuracy–compute 曲线；单点比较必须声明预算
典型失败模式幻觉、拒答失准overthinking / underthinking、CoT 不忠实、对 verifier 的 reward hacking
单次查询成本近似常数可变且可控——成本本身成为评测的一个轴
基准状态MMLU 类基准趋饱和AIME/GPQA 被快速刷穿，FrontierMath、HLE 等接棒，污染问题更尖锐
预算不对齐的比较会直接翻车。[Brown 2024, arXiv:2407.21787] 显示弱模型采样 N 次的 coverage 随 N 近似幂律增长；[Snell 2024, arXiv:2408.03314] 显示在 compute-optimal 的测试时策略下， 小模型可以在同等 FLOPs 上击败大 14 倍的模型。也就是说：A 在"单次回答"上赢了 B，换成"同等美元成本" 口径后结论完全可能反转。今天读任何 reasoning 榜单，第一件事是找脚注里的采样数与思考预算——找不到，分数等于没说。

2大图景：train-time vs test-time compute

预训练 scaling laws（Kaplan 2020、Chinchilla 2022）支配了 2020–2024：能力 ≈ 参数 × 数据的幂律。 但这条轴越来越贵——数据见顶、单次训练 run 上亿美元。Test-time compute (TTC) 作为第三条 scaling 轴登场：不动权重，在推理时多花算力换能力。它的三个正交维度，正好构成本课的骨架：

测试时算力的三个正交维度（统一货币：生成的 token 数 C） ① 更长 sequential ── 一条链想得更久：更长 CoT、自我反思、修订 │ （o1/R1 的主轴；s1 的 budget forcing） → 模块 01, 06 │ ② 更宽 parallel ──── 并行采样 N 条独立链再聚合： │ self-consistency / majority vote / best-of-N → 模块 02, 03 │ ③ 更深 search ────── 把"生成一条链"升级成"在步骤树上搜索"： │ step-level beam、Tree-of-Thoughts、MCTS → 模块 04 │ └── 经济学问题：固定预算 C，三个维度怎么配最优？ → 模块 05 省钱问题：怎么用更少的 C 达到同样的分？ → 模块 06 测量问题：这一切怎么评得公平、报得诚实？ → 模块 07

形式化地，给定预算 $C$，测试时计算的"效用曲线"是对策略空间的上确界 $U(C) = \max_{\pi \in \Pi(C)} A(\theta; \pi)$。[Snell 2024] 的核心发现是： 最优策略随题目难度变化——简单题上顺序修订（sequential）更划算， 难题上并行采样 + verifier 搜索更划算，而极难题上再多 TTC 也救不回来（天花板由基座能力决定）。 于是出现了 train-time 与 test-time 算力之间的"汇率"问题：同样一份 FLOPs， 花在预训练还是花在推理，哪边边际收益高？答案依赖难度分布与查询量——这是模块 05 的主线。

两条轴并不独立：R1 的故事是"花 train-time compute，教会模型花 test-time compute"—— RLVR 训练让长 CoT、自我验证、回溯涌现出来。"训练 vs 推理"的边界正在变软： 训练塑造模型使用测试时算力的效率，部署方控制预算与聚合策略——评测必须把两层分开归因。

4方法论：模拟推理器 —— 不调 API 的统计实验

本课所有 notebook 只用 numpy / matplotlib / pandas / 标准库， 不调任何 API、不下载任何权重，每个 cell 在笔记本电脑 CPU 上秒级跑完。 核心装置是一个贯穿全课的模拟推理器（simulated reasoner）：

模拟推理器 = 一个参数完全可控的合成推理过程 一条推理链 chain：k 步，每步独立以概率 p 做对 └ 可选：做错的步以概率 r 被自我纠错（self-correction） 最终答案：全部步骤正确 → 输出正确答案 否则 → 从 m 个错误答案中（按某分布）抽一个 verifier：一个有 TPR/FPR 的噪声分类器，给链/步打分 旋钮：p（单步能力）、k（题目深度）、r（反思能力）、 错误答案分布（错得散还是错得齐）、verifier 噪声、token 成本

直白讲

物理学家研究真实气体之前，先把分子简化成"无体积、只弹性碰撞的小球"——理想气体模型。 它显然是假的，但 PV=nRT 抓住了主要矛盾，而且每个量都可控可测。 我们对推理模型做同样的事：把"模型在想"简化成"每步以概率 p 做对"。 这个假模型足以定量复现真现象：误差复利、多数投票的增益、verifier 引导搜索的收益与 Goodhart 翻车、inference scaling 曲线、overthinking——而且因为 ground truth 在我们手里， 每个实验都能跟解析式对答案。

严谨讲

独立步骤模型下链成功率有闭式解 $P_{\text{chain}} = p^k$（带自纠错时 $P = (p + (1-p)r)^k$）；$N$ 条独立链做多数投票的成功率是二项尾概率 （Condorcet 陪审团定理的设定）；pass@k 有无偏估计量 $1 - \binom{n-c}{k}/\binom{n}{k}$ [Chen 2021, arXiv:2107.03374]。模拟推理器让我们在已知数据生成过程的前提下 校准这些估计量的偏差与方差——这正是评测科学的标准动作：先在 ground truth 可知的 合成环境里验证测量仪器，再拿去测真实系统。

为什么不直接评真模型？①可复现——API 评测贵且不可复现（模型静默升级、温度不可控），合成实验 seed 固定后比特级可复现； ②可归因——真实评测里"采样多了为什么涨分"有十种解释，合成环境里每个因素单独可关； ③方法论同构——估计量、置信区间、预算核算的数学在两边完全一样，notebook 里的每个函数都能直接用于真实评测日志。

代价要说清楚：模拟推理器的"每步独立同分布"假设在真实模型上系统性偏乐观—— 真实采样之间高度相关（同一个坑大家一起掉），错误也不是无记忆的（一步错往往步步错）。 模块 02 会显式引入相关性参数并展示 majority vote 的收益如何随相关性坍缩； 模块 07 会讨论把合成结论外推到真实模型时的检查清单。理想气体不是用来否认分子间作用力的， 而是让你在看到偏差时知道偏差相对于什么基线而言。

6简史：scratchpad → CoT → o1/R1（2021–2026）

时间里程碑关键思想
2021Scratchpad [Nye 2021, arXiv:2112.00114]；GSM8K + verifiers [Cobbe 2021, arXiv:2110.14168]让模型把中间计算写出来，多步任务成功率大涨——"想"可以外化为 token。Cobbe 同时埋下两颗种子：采样多条解、训练 verifier 重排序（ORM 雏形），以及用采样数换性能的曲线。
2022Chain-of-Thought [Wei 2022, arXiv:2201.11903]；zero-shot CoT [Kojima 2022, arXiv:2205.11916]；Self-Consistency [Wang 2022, arXiv:2203.11171]few-shot 给推理示范，CoT 能力随规模涌现；"Let's think step by step" 一句话就能触发；采样多条链对答案做 majority vote 稳定涨分——并行 TTC 的第一个标准配方。
2023过程监督 PRM [Lightman 2023, arXiv:2305.20050]；Tree-of-Thoughts [Yao 2023, arXiv:2305.10601]；Self-Refine [Madaan 2023, arXiv:2303.17651]；CoT 忠实性质疑 [Turpin 2023, arXiv:2305.04388]逐步打分的 process reward model 显著优于只看结果的 ORM；推理被显式建模成树上搜索（生成→评估→回溯）；模型自我迭代修订；同时第一盆冷水：CoT 给出的理由可能与真实决策因素无关。
2024Large Language Monkeys [Brown 2024, arXiv:2407.21787]；compute-optimal TTC [Snell 2024, arXiv:2408.03314]；OpenAI o1（2024-09）coverage 随采样数幂律增长，"重复采样也是一种 scaling"；TTC 的最优分配随难度变化，小模型 + 聪明的测试时策略可胜 14 倍大模型；o1 把这一切产品化——RL 训练的内生长 CoT，AIME 成绩随思考 token 对数线性上升。
2025DeepSeek-R1 [DeepSeek-AI 2025, arXiv:2501.12948]；s1 [Muennighoff 2025, arXiv:2501.19393]；Kimi k1.5 [arXiv:2501.12599]纯 RLVR（GRPO）让自我验证、反思、"aha moment"涌现，全套开源权重 + 蒸馏小模型，复现门槛骤降；s1 用 1k 样本 SFT + budget forcing（强行续写 "Wait"）就得到可控的 TTC scaling——顺序扩展惊人地便宜。
2025–2026效率与评测的反思：overthinking [Chen 2024, arXiv:2412.21187]、GSM-Symbolic 扰动评测、AIME 污染争议、FrontierMath / HLE 接棒长 CoT 边际收益递减且常见"想太多反而错"；推理基准被迅速刷穿，扰动鲁棒性与防污染成为标配；报告口径混乱使 budget-matched 评测规范成为社区议题——本课的落点。
给 evaluation scientist 的读图法。注意重心迁移：2021–2022 在回答"模型能不能想"（存在性）， 2023 在回答"怎么挑出对的那条"（选择），2024–2025 在回答"怎么训会想、算力怎么花"（scaling 与工程化）， 2025 起在回答"怎么测得准、花得省、报得诚实"——恰好落进你的主业。本课终点模块 07 就停在这个接口上。

7研究前沿与开放问题

  • budget-matched 评测的标准化。pass@1 的采样温度与思考预算、avg@k 与 cons@k 的口径、 accuracy–compute 曲线是否应成为榜单默认产物？目前各家自报口径互不可比，"评测出来的差距其实是预算差距"的事故每月都在发生。
  • 可验证域之外，TTC 还成立吗？数学/代码有 cheap verifier，RLVR 与测试时搜索都靠它。 开放式任务（写作、科研、agentic 长任务）缺少可靠 verifier——self-reward 会自我强化偏差， LLM-as-judge 有自身系统误差。verifier-free 的 TTC（以及"泛化 vs 蒸馏自基座"之争）是开放前线。
  • CoT 忠实性与可监控性。推理模型把"思考"写在明面上，看似送给安全评测一个审计面； 但 RL 优化可能让 CoT 漂移成不忠实甚至不可读的"内部语言"[Turpin 2023; Lanham 2023, arXiv:2307.13702]。 "保持 CoT 可监控"是否应作为训练约束，是 2025–2026 安全评测的热点（衔接 Safety_Evals_Course）。
  • 自适应算力：何时该停？overthinking 的量化与早停策略决定部署经济学。 理想形态是模型自己学会"这题值多少 token"——目前主要还靠外部预算控制。
  • train-time 与 test-time 的汇率与闭环。蒸馏把 TTC 的收益固化回权重（R1-distill）， "采样→筛选→再训练"的自我改进循环把两条轴接成飞轮；这个汇率如何随能力水平变化，定量结论还很初步。
  • 推理基准的饱和与污染。AIME 题目年年泄漏进训练集，GSM-Symbolic 式扰动显示部分"推理能力"是模板记忆；给推理模型出题本身正在变成一个研究方向。
