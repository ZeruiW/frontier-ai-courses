3D 表示与点云深度学习

从 2D 到 3D，最常听到的说法是「多了一个维度」。而工程上真正的后果是：几乎每一个量都变成了三个因子的积——网格规模 $(L/r)^3$、卷积核 $k^3$、IoU 的三个乘子，而锚框还要再乘朝向。更麻烦的是它们互相加强：网格规模逼你用大体素 → 量化误差变大 → IoU 掉下来 → 正样本变少 → 训练更难。这门课沿着这条链走一遍，而每一步都给出一个可以在几十行 numpy 里验证的量。

怎么用： 先读模块的 NN_讲解.html，再跑同目录下的同名 .ipynb。本课有学习成分，但全程 numpy、不训练任何真实网络——因为 3D 网络的关键设计几乎都由结构性质决定，而结构性质可以在不训练的情况下被精确验证：「max-pool 置换不变」是恒等式、「临界点集不超过 $D$ 个点」是定理、「常规稀疏卷积会膨胀」是集合运算的结果、「朝向离散化会漏正样本」是几何计算。五条里没有一条依赖权重取值——所以它们比任何精度数字都稳定：换数据集不变，换年份也不变。代价也说清楚：本课不能回答「哪个模型精度更高」，而关于信息流的一切都成立。点云从模块 01 起用一个真实的 64 线环扫模型（射线与地面/AABB 求交，一帧 102,668 点、89% 命中率），但它假设完美反射、无遮挡阴影、无大气衰减——所以本课的相对结论可迁移，具体百分比只属于本课的配置。课程里有多处与直觉相反、而被真实计算否掉的结论：sum/mean 不是逐位置换不变的（浮点加法不满足结合律）、max 并没有完全丢弃点数（线性探针 $R^2{=}0.76$）、膨胀最快的不是薄结构而是散开的点、IoU 对朝向不是单调的；还有三处「本课自己的配置通不过自己的审计」（模块 03 的连通性、模块 04 的高斯半径、模块 05 的口径天花板）——三条独立的推理指向同一件事：0.2 m 的网格 + IoU-0.5 的口径，对交通标志是不成立的组合。每个模块末尾的 🧪 真实工程胶囊 给出可原样复制的落地代码（spconv 的两种卷积与规则表复用、MMDetection3D 的采样偏倚、nuScenes 的中心距离口径、以及两个只需要配置就能跑的审计）。
