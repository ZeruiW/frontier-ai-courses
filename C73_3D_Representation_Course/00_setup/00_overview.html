1三个乘子：为什么 3D 的一切都更难

从 2D 到 3D，最常听到的说法是「多了一个维度」。而工程上真正的后果是：几乎每一个量都变成了三个因子的积。这一条贯穿本课六个模块。

量2D3D后果
网格规模$(L/r)^2$$(L/r)^3$$100\times100\times8$ m 的场景在 $r{=}0.05$ m 下是 6.4 亿格 / 640 MB，而其中只有 0.018% 非空（模块 01）
卷积代价$k^2$$k^3$$3\times3\times3$ 是 27 而不是 9——密集 3D 卷积在这个场景上是 283 GFLOP（模块 03）
IoU两个乘子三个乘子每轴 10% 的相对误差：2D IoU 0.681，3D 只有 0.574（模块 05）
锚框数尺度 × 长宽比再乘 朝向而只用 0°/90° 两个朝向时，45° 的目标一个正样本都拿不到（最好 IoU 0.425，模块 04）

直白说

这四行不是四个独立的困难，它们是同一件事的四个面。而且它们互相加强：网格规模让你不得不用大体素，大体素让量化误差变大，量化误差让 IoU 掉下来，IoU 掉下来让正样本变少，正样本变少让训练更难。所以 3D 方法的历史基本上就是「怎么绕开这条链」的历史。

严谨说

而本课的组织方式就是沿着这条链走：模块 01 摆出四种表示各自怎么应对「$(L/r)^3$」；模块 02 讲点云路线（完全绕开网格）为此付出了什么；模块 03 讲体素路线怎么靠稀疏性把 $k^3$ 拿回来；模块 04 讲检测头怎么绕开朝向离散化；模块 05 讲评测指标本身被三个乘子放大了多少。每一步都有一个可计算的数，而它们全部在 notebook 里被验证。

2四种三维表示，四种取舍

同一个物体的四种存法 点云 (point cloud) 体素 (voxel) {(x,y,z)} × N occupancy[i][j][k] ✓ 精度只受传感器限制 ✓ 规则网格 -> 能直接用卷积 ✓ 内存 ∝ 点数 ✗ 内存 ∝ (L/r)³ ✗ 无序、无邻域结构 ✗ 量化误差 <= r√3/2 ✗ 密度极不均匀 网格 (mesh) 隐式 (implicit / SDF) 顶点 + 面 f(x,y,z) -> 距离或占据 ✓ 表面连续、可渲染 ✓ 分辨率无关、内存 = 参数量 ✓ 内存小 ✓ 天然光滑 ✗ 拓扑难学（面的连接关系） ✗ 查询需要前向计算 ✗ 从点云重建本身是个难问题 ✗ 单个网络通常只表示一个物体/场景

而「哪一种更好」是个错问题——正确的问法是「这个任务的哪个量是瓶颈」。

瓶颈是该选为什么
精度（要厘米级的位置）点云 / 隐式体素的量化误差有下界 $r\sqrt3/2$，而 $r$ 又被内存卡住
要用卷积体素（+ 稀疏化）规则网格是卷积的前提；而稀疏卷积把 $(L/r)^3$ 的代价降到占用率的倒数
内存 / 带宽点云 / 隐式$r{=}0.05$ m 的密集体素是 640 MB，而同一场景的点云是 1.44 MB
要渲染或做几何编辑网格表面显式存在；而这也是 C75（三维重建与生成）的落点
邻域/局部结构体素 / 有 kNN 的点云裸点云没有邻域概念——这正是 PointNet 的限制来源（模块 02）
一个常被忽略的事实：精细体素化几乎等于点云。notebook 第 3 节量到：$r{=}0.05$ m 时平均每格只有 1.03 个点——也就是说体素化已经不再压缩任何东西，它只是给点云套上了 6.4 亿个格子的外壳。所以「体素分辨率越高越好」在某个点之后是纯浪费，而那个点可以用「平均每格点数」这一个数字找出来。

5方法论：不训练网络，怎么学网络结构

本课有学习成分，但全程 numpy、不训练任何真实网络。这看起来矛盾，而它其实是这门课最有效的部分。

直白说

理由是：3D 网络的关键设计几乎都由结构性质决定，而结构性质可以在不训练的情况下被精确验证。「max-pool 是置换不变的」是一个恒等式，不是一个实验结果；「临界点集不超过 D 个点」是一个定理，可以逐位验证；「常规稀疏卷积会膨胀」是一个集合运算的结果。这些都不需要训练，而它们恰好是「为什么 PointNet 长这样」「为什么要子流形稀疏卷积」「为什么从 anchor 走向 center」的全部答案。

严谨说

代价也要说清楚，它有两条。① 本课不能回答「哪个模型精度更高」——那需要真实数据集与训练，属于工程实验而不是本课。② 本课的「网络」是随机初始化的，所以关于特征质量的一切都无从谈起；但关于信息流的一切都成立——临界点集、膨胀率、正样本比例都与权重取值无关。所以本课的结论是「结构性的」，而它们比精度数字更稳定：换数据集不变，换年份也不变。

本课会验证的五个「结构性事实」，以及它们各自是什么

事实它是什么怎么验证在哪个模块
max-pool 置换不变恒等式随机置换后逐位比较（差 0.0）02
临界点集 $\le D$定理（PointNet 原论文）数不同 argmax 的个数，并删掉其余点验证输出不变02
量化误差 $\le r\sqrt3/2$几何上界逐点算位移，比上界01
常规稀疏卷积会膨胀集合运算的结果对活跃集反复做 $3^3$ 邻域并集03
朝向离散化会漏正样本几何计算多边形裁剪算旋转框 IoU，扫全部锚框04

五条里没有一条需要训练，也没有一条依赖权重取值。而它们恰好就是「为什么 PointNet 长这样」「为什么要子流形稀疏卷积」「为什么从 anchor 走向 center」的全部答案。

每个模块的固定结构

  • 讲解页：结构性质 → 可验证的量 → 它决定了什么设计
  • notebook：6–8 个 worked 小节，每节以 assert 结尾
  • 4 道 ✏️ 练习：TODO 骨架 + assert 判分 + 📖 参考答案
  • 🧪 真实工程胶囊：接 PyTorch / spconv / MMDetection3D 的代码
一个必须提前说明的边界。本课的合成点云是几何上合理但物理上简化的：没有真实 LiDAR 的射线模型（所以没有遮挡阴影、没有随距离衰减的点密度、没有反射率）。因此本课关于「占用率」「膨胀率」的相对结论可迁移，而具体百分比只属于本课的合成配置。真实 64 线 LiDAR 的点密度随距离按 $1/d^2$ 掉，这会让远处的占用率比本课更低——也就是本课的结论方向不变、幅度更强。
