# C73 · 3D 表示与点云深度学习

> **有学习成分，但全程 numpy、不训练任何真实网络。**
> 验证的是**结构性事实**——恒等式、定理、集合运算与几何计算，
> 它们与权重取值无关，所以比任何精度数字都稳定。

## 这门课在回答什么

从 2D 到 3D，最常听到的说法是「多了一个维度」。
**而工程上真正的后果是：几乎每一个量都变成了三个因子的积。**

| 量 | 2D | 3D | 后果 |
|---|---|---|---|
| 网格规模 | $(L/r)^2$ | $(L/r)^3$ | $r{=}0.05$ m → **6.4 亿格 / 640 MB**，其中 0.018% 非空 |
| 卷积代价 | $k^2$ | $k^3$ | 27 而不是 9 |
| IoU | 两个乘子 | **三个乘子** | 每轴 10% 相对误差：2D 0.681 vs **3D 0.574** |
| 锚框数 | 尺度 × 长宽比 | 再乘**朝向** | 2 个朝向让 45° 的目标 **0 个正样本** |

**而这四件事互相加强**：网格规模逼你用大体素 → 量化误差变大 → IoU 掉下来
→ 正样本变少 → 训练更难。**六个模块就是沿着这条链走。**

## 几个与直觉相反、而被真实计算否掉的结论

- **`sum` / `mean` 不是逐位置换不变的**。浮点加法不满足结合律，相对差 1.43e-15；
  而 `max` / `min` 是（它们是选择操作）。**所以置换不变性的单元测试不能一律用「恰好相等」。**
- **`max` 并没有「完全丢弃点数」**。线性探针给出 $R^2=0.76$——
  因为从更多样本里取最大值，期望更大（极值统计量依赖样本量）。
- **「max 最鲁棒」不准确**。对**点数**变化 mean 最稳（4.0% vs max 8.5%）；
  对**密度分布**变化才是 max 最稳（−11% vs mean +43%）。
  而点云的主要扰动是密度，所以选 max——**不是因为它更好，而是因为它对这个领域的主要扰动免疫**。
- **膨胀率最快的不是薄结构，而是完全散开的点**（22.05× vs 薄片 4.32×）。
  而规则密度的排序恰好相反，两者之积被核大小 27 框住。
- **拼接 `[max, mean]` 不是「兼得」，是被范数大的那一半支配**（46.9 vs 6.3）。
- **「只用临界点重算」不保证逐位相等**——BLAS 对不同形状的矩阵乘走不同路径
  （本课在 $N{=}128,D{=}16$ 上量到 2ε）。**「逐位相等」的断言必须说清「重算了什么」。**
- **IoU 对朝向不是单调的**：方形目标以 90° 为周期（45° 是 0.707，90° 回到 1.000）。
- **加锚框朝向解决「漏掉」，不解决正负不平衡**（133 → 258 个正锚，而比例 0.0416% → 0.0403%）。

## 本课最硬的一条结论

**对交通标志，「IoU ≥ 0.5」这个口径的天花板由标注噪声决定，而不是由模型能力决定。**

推导是闭合的：

1. $\text{IoU}=q/(2-q)$ 且 $q=\prod(1-\delta_i/s_i)$，所以**单轴容差恰好 $s_i/3$**；
2. 标志厚 0.1 m ⇒ 各向同性容差 **0.049 m**；
3. 而典型标注噪声 **0.05 m** ⇒ **容差/噪声 = 0.98×**；
4. 于是让预测**等于真值**、只给真值加标注噪声，
   AP@IoU0.5 的上界只有 **0.392**（同一张表里卡车与轿车都是 1.000）。

**所以标志那一列量的不是模型能力，是标注噪声。**
而中心距离口径下，同样的实验对四个类别都给出 **1.000**。

由此得到一条可以直接用的判据：$\dfrac{s_{\min}/3}{\sigma_{\text{ann}}} \gtrsim 3$。
四个类别的比值是：卡车 15.93× · 轿车 9.18× · 行人 3.32× · **标志 0.98×**。

## 三处「本课自己的配置通不过自己的审计」

这不是失误，是设计：**审计要能抓住真实的疏漏，包括作者的。**

- 模块 03：0.2 m 的体素网格下，标志碎成 2 个不连通分量 → 纯子流形骨干**在架构上**无法聚合它。
- 模块 04：0.2 m 的 BEV 网格下，标志的高斯半径 0.08 格 → 有效正样本面积 **0 格**。
- 模块 05：0.05 m 的标注噪声下，标志的 IoU-0.5 天花板只有 0.392 → **该类别的排名不可信**。

三条独立的推理指向同一件事：**0.2 m 的网格 + IoU-0.5 的口径，对交通标志是不成立的组合。**
而修法不是调参数，是换通路（C72 模块 03 的已知尺寸测距）或换口径。

## 边界

本课的合成点云是**几何上合理但物理上简化**的：
虽然模块 01 起用了真实的 64 线环扫射线模型（射线与地面/AABB 求交），
但它假设完美反射、无遮挡阴影、无大气衰减、无反射率。
场景里只有 4 辆车 + 3 块标志，所以地面点占比偏高。

**因此本课的相对结论（比值、趋势、排序）可迁移，而具体百分比只属于本课的配置。**
真实 LiDAR 的远处更疏，会让本课的结论方向不变、幅度更强。
