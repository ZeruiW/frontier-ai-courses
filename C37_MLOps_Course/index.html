MLOps 与生产生命周期

训练完和上线后才是开始 · 用标准库 + numpy/pandas 从零实现一套能跑的 ML 生命周期工具 · 实验追踪 / 版本 / 门禁 / 漂移 / 重训练 · 中文讲解 + 英文术语

6 模块 实验追踪 · 版本 · 门禁 · 漂移 · 反馈重训练 从零造工具（非调 API） PSI/KS/bootstrap 自己实现 纯 stdlib + numpy/pandas · 可实跑
怎么用： 每个模块先读 HTML 讲解 建立「生命周期视角」与系统直觉，再跑 notebook 亲手用标准库 + numpy/pandas 从零实现一件真能跑的工具，并用 ✏️ 练习的 assert 判分。配套 术语词典 与 参考清单。本课的立场来自 Sculley 等人那篇著名论文：真正的机器学习代码只是冰山一角，环绕它的是体量大得多的「系统性技术债」——配置、数据依赖、监控、复现、重训练。换句话说，训练完一个好模型只是开始，把它安全地养在生产里才是 MLOps 的主战场。我们不堆砌 MLflow/DVC/Evidently 的 API，而是把这些工具的核心机制从零拆开重写：实验追踪器（参数/指标/产物 + run 比较 + 复现）、内容寻址版本库（hash + lineage + diff）、评测门禁（阈值 + 回归 + bootstrap 显著性）、漂移检测器（PSI + KS + 滑窗告警）、反馈→重训触发器（收集→触发→重训→评估→灾难性遗忘度量）。全部纯 numpy/pandas/标准库（用 tempfile/sqlite3/hashlib/json 做真实小工具，逻辑正确、可实跑、assert 全过）。学完你能看懂任何 MLOps 平台在替你做什么、它的设计取舍在哪，并能在没有平台时自己搭一套最小但正确的生命周期基础设施。
