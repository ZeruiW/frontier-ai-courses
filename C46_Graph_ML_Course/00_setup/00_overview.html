1这门课讲什么：为什么需要图

欢迎来到 图机器学习 / 图神经网络（GNN）。这门课补齐前沿 AI 课程体系里一直缺失的一整条分支——几何深度学习（geometric deep learning）中处理图这种非欧、置换不变数据的核心。它的目标只有一个：让你从「会调用 PyG / DGL」变成「会从零写出 GCN、GAT、GraphSAGE、图 Transformer」。

先回答一个最根本的问题：我们已经有了 CNN 和 Transformer，为什么还需要专门的图模型？答案在于数据的形状。CNN 假设数据排在规则网格上（图像的像素、音频的采样点），每个位置都有固定数目、固定方位的邻居，于是可以用一个共享的小卷积核滑过去。但现实里大量最有价值的数据根本不在网格上：社交网络里每个人的朋友数天差地别、彼此没有「左右上下」之分；一个分子里每个原子连着不定数目的键；知识图谱、引文网络、推荐系统的用户-商品图、交通路网、程序的抽象语法树——它们的共同点是用图（节点 + 边）表示，邻居数目可变、邻居之间没有天然顺序。

直白说

一句话：CNN 处理「方格纸」，Transformer 处理「序列」（一种特殊的全连接图），而 GNN 处理任意形状的关系网。当你的数据天生是「谁和谁相连」时，硬把它塞进网格或序列会丢掉最重要的结构信息——而 GNN 直接在图上算，让每个节点的表示由它的邻居和邻居的邻居逐层刻画。

严谨说

形式上，图数据破坏了 CNN/RNN 依赖的两个前提：固定的邻居数与邻居的有序性。一个节点可能有 2 个或 2000 个邻居，且这些邻居本质上是一个集合，没有第 1 个、第 2 个之分。因此图模型的运算必须对邻居置换不变（permutation invariant）——重排邻居编号，结果不变。这条对称性约束，是几何深度学习对图模型的核心要求，贯穿全课。

学完你应当能回答这类问题（也是图 ML / 推荐 / 药物发现岗位的高频面试题）：图拉普拉斯到底编码了什么、为什么它的特征向量是「图的傅里叶基」？GCN 的 ÂXW 是怎么从谱卷积推出来的、为什么要对称归一化？GNN 堆深了为什么会过平滑？GAT 的注意力和 GraphSAGE 的采样各解决了什么问题？图 Transformer 凭什么能绕开过挤压、它怎么知道图的结构？——并且能在 numpy 里把这些机制全部从零实现、在小图上对拍验证。

2图上的三类任务与对称性

图上的三类任务：节点 / 边 / 图级

在动手之前，先建立一张任务地图。几乎所有图学习问题都落在三个层次上，它们决定了网络最后一层和损失怎么设计：

任务层次预测对象典型例子输出形状关键操作
节点级 node-level每个节点的标签/属性引文网论文分类、欺诈账号检测每节点一个向量/类别节点表示（置换等变）
边级 edge-level节点对之间是否/如何相连推荐、知识图谱补全、链接预测每对节点一个分数编码器 + 解码器 + 负采样
图级 graph-level整张图的标签/属性分子毒性/溶解度、图分类每图一个向量/类别readout 池化（置换不变）

这三类任务对对称性的要求恰好不同，这是几何深度学习的精髓所在。节点级任务要置换等变：把节点重新编号，每个节点的预测应当随之同样地重排（而不是乱套）。图级任务则要置换不变：整张图的标签不该因为我们换了节点的编号而改变——所以图级任务必须用一个对顺序不敏感的 readout（sum/mean/max）把节点表示汇成图向量。边级任务介于两者之间：先用等变的 GNN 得到节点表示，再用一个解码器给节点对打分。记住「节点级=等变、图级=不变」这条对应，是设计任何图模型架构的第一性原则。

本课六个模块的安排正是沿着「先打地基、再建主干、最后落到三类任务」展开：模块 01 用谱图理论把图的数学讲透（这是 GCN 的来源）；模块 02–03 从零实现三大主力消息传递 GNN（GCN/GAT/SAGE），主要在节点级任务上验证；模块 04 引入图 Transformer 处理长程依赖；模块 05 把这些零件落到边级（链接预测）和图级（图分类）任务，并直面 GNN 的两大病理——过平滑与过挤压。

一个有用的类比：把节点表示想成「每个人的简历」。GNN 每一层就是「让每个人参考身边朋友的简历，更新自己的简历」。迭代几轮后，一个人的简历就融入了朋友圈、乃至朋友的朋友圈的信息。节点级任务 = 看每个人最终的简历；图级任务 = 把全公司的简历汇总成一份公司画像。这条直觉会贯穿全课。

3课程地图：从图拉普拉斯到图 Transformer

课程地图：从图拉普拉斯到图 Transformer

几何深度学习的图分支：数据是关系网，运算必须置换不变/等变 模块 01 图与谱基础 邻接/度/拉普拉斯、谱与连通性、Fiedler 谱聚类、随机游走/PageRank │ 「图的数学语言；GCN 的谱卷积从这里来」 ▼ 模块 02 消息传递 + GCN MPNN(消息/聚合/更新)、GCN 的 ÂXW 推导、对称归一化、过平滑 │ 「最核心的一层：按图结构混合邻居 + 线性变换 + 非线性」 ▼ 模块 03 GAT + GraphSAGE 注意力聚合(可学边权)、邻居采样+聚合器、归纳 vs 直推 │ 「让聚合更聪明(GAT)、让模型可扩展可泛化到新节点(SAGE)」 ▼ 模块 04 图 Transformer 全局自注意力、拉普拉斯特征向量位置编码、结构/距离编码 │ 「绕开局部消息传递的过挤压，一步建立长程依赖」 ▼ 模块 05 可扩展 + 应用 采样/分块、过平滑/过挤压诊断、链接预测、图级分类 「把前四块落到边级与图级真实任务」

这不是松散的专题集合，而是一条严格递进的依赖链。模块 01 的图拉普拉斯直接长出模块 02 的 GCN（GCN 就是谱卷积的一阶近似）；GCN 的固定聚合权重在模块 03 被 GAT 的可学注意力替代、被 GraphSAGE 的采样聚合器扩展；模块 04 的图 Transformer 用的位置编码正是模块 01 的拉普拉斯特征向量；而模块 02 暴露的过平滑、模块 04 动机里的过挤压，在模块 05 被正面诊断与缓解。读到最后你会发现：图 Transformer 的位置编码、GCN 的归一化、谱聚类，全都根植于模块 01 那个 $L=D-A$。把这条链打通，几何深度学习的图分支就不再是一堆论文名词，而是一个可以从第一性原理推出来的连贯体系。

每一级台阶都对应一个可独立验证的能力：模块 01 你能从谱「数出」连通分量、用 Fiedler 向量把 SBM 的两个社区切开；模块 02 你手写的 GCN 前向会同时通过稀疏与稠密两种实现的对拍，并能用 Dirichlet 能量量化过平滑；模块 03 你能算出 GAT 的注意力系数并验证它在邻域内归一化、能让 SAGE 在采样子图上聚合；模块 04 你能把拉普拉斯特征向量做成位置编码喂进全局注意力；模块 05 你能训出一个链接预测器并算出它的 AUC。每一步都有 assert 兜底，绝不靠「感觉对了」。

4方法论：纯 numpy、从零、小图对拍

方法论：为什么纯 numpy、从零、用小图？

本课全程纯 numpy、CPU 可跑、不依赖 PyG/DGL/PyTorch。这不是因陋就简，而是一个刻意的教学选择——它逼你只关注真正难的部分：图运算的结构与正确性。

真实框架（PyG/DGL）把最精妙的东西藏在了高度优化的 C++/CUDA 算子里：稀疏矩阵乘、scatter/gather 聚合、邻居采样。你 import torch_geometric 然后 GCNConv(16, 7) 一行就跑通了，但一层 GCN 内部到底把哪些向量按什么权重加到了一起，反而看不见。本课的做法相反：用 numpy 把每一种聚合都显式地写成对邻居的循环或一次矩阵乘，让你亲眼看到「消息沿边流动」这件事。等你理解了结构，换到任何框架都只是换语法。

直白说

我们把每个 GNN 机制翻译成 numpy 里看得见摸得着的东西：一次「传播」就是邻接矩阵乘特征 A @ X；「对称归一化」就是左右各乘一个对角阵；「注意力聚合」就是先算边分数、按邻域 softmax、再加权求和；「readout」就是对节点维求和。你写的是结构，不是性能。

严谨说

关键纪律是对拍与可复现（differential testing & reproducibility）：每个实现都和一个绝对可信的参考比对。谱聚类的结果和我们生成 SBM 时埋下的 ground-truth 社区标签比；稀疏（逐边循环）传播和稠密（Â@X）传播比；注意力系数和手算的 softmax 比；训练时损失必须单调下降、并收敛到一个我们能预期的水平。固定随机种子，结果每次都一样。

GNN 概念本课的 numpy 实现对应真实框架
一步邻居传播A @ X（或逐边累加）稀疏 spmm / scatter_add
对称归一化Dinv_sqrt @ A @ Dinv_sqrtgcn_norm / 预计算 Â
注意力聚合边分数 → 邻域 softmax → 加权和GATConv 的 scatter_softmax
邻居采样对每节点随机取固定数目邻居下标NeighborSampler / SAGEConv
readout 池化H.sum(0) / mean / maxglobal_add_pool
正确性保证对拍参考 + assert + 固定种子单元测试 / 与参考实现对拍

为什么把对拍提到方法论的高度？因为图代码的 bug 极其阴险：邻接矩阵忘了对称化、归一化时度数取错、采样时把自己漏掉、聚合时维度广播错位——这些往往不报错，只是悄悄给出看起来差不多但其实错了的结果。在 numpy 模拟里，我们有绝对可信的参考（生成数据时就知道真相、稠密实现可当稀疏实现的金标准），任何偏差都会被 assert np.allclose(...) 当场抓住。这套「先有 ground truth，再实现」的纪律，正是真实 GNN 研发的核心工作流。

务必清楚本课不教什么：不教 PyG/DGL 的 API 细节、不追求大图上的训练速度、不写 CUDA 稀疏算子、不刷 OGB 排行榜。这些在你有了正确的图运算结构之后，是第二步（references 里的 PyG 文档、OGB、Cluster-GCN 接手）。本课负责把第一步——结构、数学与正确性夯死；这一步搞定，第二步才有意义。

5环境与运行

环境与运行

环境极简：只需 numpy（可选 matplotlib 画图、networkx 取 Karate club 数据；都不是必需，缺了有内置回退）。全课 CPU 秒级运行，无需 GPU、PyG、DGL、torch。

conda create -n graph-ml python=3.11 -y && conda activate graph-ml
pip install numpy            # 必需
pip install matplotlib networkx   # 可选：画图 / 取 Karate club；缺了有内置回退
jupyter lab

每个模块配一个 notebook，结构统一：先用 numpy 把机制从零实现并对拍/验证收敛（5–6 个 worked 小节，每节都跑出可打印的验证与 assert），再做 3–4 道带 assert 判分的 ✏️ 练习（先给骨架，自己填，再对照 📖 参考答案），最后一个真实数据胶囊（用真实公开图——Karate club / 小 Cora-like 引文图——把纸面知识接到现实，联网失败则回退到内置的真实数值）。

建议的学习节奏：先读完整章 HTML 建立直觉与数学框架，再打开 notebook 亲手实现。读和做缺一不可——只读会觉得「好像懂了」，真正动手写传播循环、调归一化、让 assert 通过、看损失下降时，才会发现魔鬼藏在哪些细节里（对称化、加自环、度归一化、邻域 softmax 的归一化范围）。这门课的深度正是为「动手」服务的。

配套先读：Bronstein 等《Geometric Deep Learning》导论建立「GNN = 对置换群的不变/等变学习」世界观；von Luxburg 谱聚类教程配模块 01；Kipf GCN（2017）是模块 02 的终点站。完整清单见 references.md。

✅ 学完整门课，你应该能：
  1. 说清图数据为何非欧、为何要置换不变/等变，并把任务归类为节点/边/图级；
  2. 从零构建邻接/度/拉普拉斯矩阵，从谱数出连通分量、用 Fiedler 向量做谱聚类、算随机游走平稳分布；
  3. 推导并实现 GCN 的传播规则 σ(ÂXW)（对拍稀疏/稠密），用 Dirichlet 能量诊断过平滑；
  4. 从零实现 GAT 注意力聚合（验证邻域内归一化、多头）与 GraphSAGE 采样 + 聚合器（区分归纳/直推）；
  5. 用拉普拉斯特征向量做位置编码、搭一个玩具图 Transformer 的全局自注意力；
  6. 训练一个链接预测器（负采样 + 点积解码、算 AUC）和一个图级分类器（readout），并说清过平滑与过挤压的成因与对策；
  7. 把验证过的 numpy 逻辑映射到 PyG/DGL 的层，知道下一步怎么上真实大图。
