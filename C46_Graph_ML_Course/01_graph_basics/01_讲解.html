1图的矩阵化与图拉普拉斯

要在图上做深度学习，第一步是把图翻译成线性代数——因为神经网络只会算矩阵。这一模块就把一张图彻底矩阵化，并由此进入谱图理论（spectral graph theory）：通过一个叫图拉普拉斯的矩阵的特征值与特征向量，我们能从代数里读出图的拓扑——它连不连通、有几块、怎么切最自然、信息在上面扩散多快。这些不只是漂亮的数学，更是下一模块 GCN 的直接来源。

先立三块基石。给定一张 $n$ 个节点的无向图：邻接矩阵 A ∈ ℝ^{n×n}（$A_{ij}=1$ 当 $i,j$ 相连，无向则对称）；度矩阵 D（对角阵，$D_{ii}=d_i=\sum_j A_{ij}$ 是节点 $i$ 的邻居数）；以及二者之差——图拉普拉斯：

\[L = D - A\]

直白说

邻接矩阵记「谁连谁」，度矩阵记「每个点有几条边」。拉普拉斯 $L=D-A$ 把它们合成一个差分算子：它衡量一个信号在图上「邻居之间差异有多大」，就像微积分里的二阶导数衡量函数有多弯。差异越小（相邻节点取值越接近）= 信号在图上越「光滑」。

严谨说

$L$ 的精髓藏在它的二次型里。对任意节点信号 $x\in\mathbb{R}^n$，可以证明（本模块 notebook 会逐项验证）：

\[x^\top L x = \frac{1}{2}\sum_{(i,j)\in E}(x_i - x_j)^2 \ \ge\ 0\]

这个恒等式是整个谱图理论的心脏。它说：$L$ 的二次型等于「所有边两端取值之差的平方和」（的一半）。两个直接推论立刻浮现——其一，$L$ 是半正定的（二次型恒 ≥ 0），所以特征值全部非负；其二，让 $x^\top L x$ 尽量小，就是在找一个相邻节点尽量接近的「平滑信号」。于是「图上的频率」有了精确含义：特征值小 = 低频 = 在图上平滑，特征值大 = 高频 = 相邻剧烈变化。这正是把傅里叶分析搬上图的入口，第 3 节展开。

为什么叫「拉普拉斯」？在规则网格上，$L=D-A$ 恰好是连续拉普拉斯算子 $\nabla^2$ 的离散版（二阶差分）。把图想成一张任意形状的「膜」，$L$ 度量这张膜上某个信号的「弯曲程度」。GCN、谱聚类、扩散、热传导，本质都是在这张膜上让信号变平滑——理解 $L$，就抓住了全课一半的数学。

最后强调一个常被忽略但极重要的性质：$L$ 的每一行之和恒为 0（因为 $D_{ii}=\sum_j A_{ij}$，对角元恰好抵消该行所有 $-A_{ij}$）。这等价于说常向量 $\mathbf 1$ 永远是 $L$ 的特征向量，对应特征值 0（$L\mathbf 1=0$）。这条看似平凡的事实，正是第 4 节「谱与连通性」一切结论的种子——连通分量数、Fiedler 向量、谱聚类全都从「零特征值」生长出来。本模块 notebook 第一件验证的事就是它。

动手算一遍

取一条三点路径 $1\!-\!2\!-\!3$（边 $\{1,2\},\{2,3\}$）。度是 $d_1=1,d_2=2,d_3=1$，于是 $L=\bigl(\begin{smallmatrix}1&-1&0\\-1&2&-1\\0&-1&1\end{smallmatrix}\bigr)$。每行之和都是 0（验证 $L\mathbf 1=0$）；中间节点度为 2、两端为 1，这就是「中心更被压」的雏形。

验证心脏恒等式

取信号 $x=(1,0,-1)^\top$（左右反号、形如一阶模式）。逐项算 $x^\top L x=(x_1-x_2)^2+(x_2-x_3)^2=1+1=2$；而直接乘 $x^\top(Lx)$ 也得 2，两条路径吻合。再取常信号 $x=(1,1,1)^\top$ 则 $x^\top L x=0$——印证「平滑信号 = 零频」。这正是 notebook 会逐项对拍的微例。

把这条三点链推到 $n$ 点链或环，你会看到一个普遍规律：$x^\top L x$ 永远等于「相邻差的平方和」，而让它最小（在 $x\perp\mathbf 1,\|x\|=1$ 约束下）的解，就是那条最「缓变」的非常向量——它恰是 $\lambda_2$ 对应的特征向量。这个微例虽小，却已经把「拉普拉斯度量平滑、低频对应缓变模式」这条贯穿全模块的主线完整演示了一遍。建议在 notebook 里把节点数从 3 加到 10，亲眼看特征值如何随链长变密、最低的非零特征值如何随链变长而变小（链越长越「难混合」）。

2三种拉普拉斯与归一化

三种拉普拉斯：组合型与两种归一化

$L=D-A$ 称组合拉普拉斯（combinatorial Laplacian），最直观但有个毛病：它对度数敏感——高度数节点在二次型里权重天然大，特征值范围随图而变，不利于跨图比较与稳定的谱卷积。于是有两种归一化拉普拉斯，把度的影响标准化：

名称定义特征值范围用途/特点
组合型 combinatorialL = D − A[0, ≤ 2·max_deg]二次型直观；零特征值重数 = 连通分量数
对称归一化 symmetricL_sym = I − D^{-1/2} A D^{-1/2}[0, 2]GCN 谱卷积的出发点；对称、谱规整
随机游走型 random-walkL_rw = I − D^{-1} A[0, 2]与随机游走/扩散直接相关；谱聚类常用

三者紧密相关：L_rw = D^{-1} L，而 L_sym = D^{1/2} L_rw D^{-1/2}，所以 L_sym 与 L_rw 有相同的特征值（相似变换不改谱），只是特征向量差一个 D^{±1/2} 的缩放。对称归一化的核心动作是把每条边按两端度数缩放：边 $(i,j)$ 的权重从 1 变成 1/√(d_i d_j)。高度数节点不再因为「朋友多」就在聚合里压倒一切——这正是下一模块 GCN 用 Â=D̃^{-1/2}ÃD̃^{-1/2} 的根本原因。

为什么 GCN 偏偏选对称归一化而非随机游走归一化？因为对称版保持矩阵对称（实对称矩阵有正交特征基、特征值实），谱性质最规整，且其特征值被限制在 $[0,2]$、重整化后谱半径稳定——这对堆叠多层的数值稳定至关重要。Kipf & Welling 2017 §2 与 von Luxburg 2007 对此有完整讨论。

3图的傅里叶变换：拉普拉斯特征基

图的傅里叶变换：拉普拉斯的特征基

既然 $L$ 是实对称半正定矩阵，它必有正交特征分解：

\[L = U \Lambda U^\top,\qquad \Lambda=\mathrm{diag}(\lambda_1\le\lambda_2\le\cdots\le\lambda_n),\ \ U^\top U = I\]

这一步看似平平无奇，却是把傅里叶分析整体搬上图的关键。在经典信号处理里，傅里叶基是一组从低频到高频的正弦波；在图上，拉普拉斯的特征向量就扮演傅里叶基的角色——它们是图上从「最平滑」到「最震荡」的一组正交模式，对应的特征值 $\lambda_k$ 就是「频率」。

直白说

把特征向量 $u_k$ 想成图上的「驻波」。$\lambda_1=0$ 对应的 $u_1$ 是常向量（处处相等，最平滑，零频）；$\lambda$ 越大的 $u_k$ 在相邻节点间正负交替越剧烈（高频）。任何节点信号都能写成这些模式的叠加。

严谨说

定义图傅里叶变换：信号 $x$ 的谱表示是 $\hat x = U^\top x$（把 $x$ 投影到每个频率模式上）；逆变换 $x = U\hat x$。于是「图上的卷积」被定义为谱域逐元素相乘：$g \star x = U\,\mathrm{diag}(\hat g)\,U^\top x$。这正是谱图卷积网络（Bruna 2014、ChebNet）的出发点，也是 GCN 的祖宗。

但这条「先特征分解、再谱域相乘」的路线有两个现实问题，催生了下一模块的简化：其一，特征分解 $O(n^3)$ 对大图不可行；其二，谱域的滤波器不是局部的（一个谱系数牵动全图）。ChebNet 用切比雪夫多项式逼近滤波器、把它变成 $K$-跳局部运算绕开了特征分解；而 GCN 进一步取 $K=1$ 的一阶近似 + 重整化，最终落到一个朴素得惊人的传播规则 σ(ÂXW)——下一模块会把这条推导走完。但谱视角的价值不止于推导 GCN：模块 04 的图 Transformer 会直接拿这里的特征向量当位置编码，所以这套谱语言务必吃透。

4谱与连通性：从代数读拓扑

谱与连通性：从代数读出拓扑

谱图理论最漂亮的结论，是把图的拓扑性质（连不连通、有几块）翻译成纯代数事实（特征值是不是 0）。核心定理只有一句话：

谱-拓扑定理

图拉普拉斯 $L$ 的特征值 0 的重数，恰好等于图的连通分量个数。特别地，$\lambda_1=0$ 永远成立（常向量是特征向量），而 $\lambda_2>0$ 当且仅当整图连通。

为什么？回到那个心脏恒等式 $x^\top L x=\tfrac12\sum_{(i,j)\in E}(x_i-x_j)^2$。要让它 $=0$（即 $x$ 是零特征值的特征向量），必须每条边两端取值都相等。在一个连通块内，相等会沿边传遍整块 → 该块内 $x$ 是常数。所以「零特征向量」= 「在每个连通块上各取一个常数」，其自由度（线性无关的个数）正好等于连通块数。这就是定理的全部证明——干净得令人惊叹，notebook 会在合成图上逐一验证。

第二小特征值 $\lambda_2$ 有个专名叫代数连通度（algebraic connectivity）或谱隙（spectral gap），它对应的特征向量叫 Fiedler 向量。$\lambda_2$ 的大小度量图「有多难被切开」：

  • λ₂ = 0 → 图不连通（已经断成至少两块）；
  • λ₂ 很小（接近 0）→ 图「勉强连通」，存在一个瓶颈：去掉少数边就能把图切成两大块。这正是模块 04/05 讲的过挤压（over-squashing）发生的地方；
  • λ₂ 大 → 图连接紧密、没有明显瓶颈，信息（随机游走）混合得快。

谱隙还直接控制随机游走的混合速度和GNN 需要多少层信息才能传遍全图——隙大则混得快、几层就够；隙小则有瓶颈、堆很多层也难穿过（且会过平滑）。Cheeger 不等式把 $\lambda_2$ 与图的「最稀疏割」严格地联系起来，是这一切的理论基石（见 references 的 Chung 1997）。

Cheeger 不等式

定义图的电导（conductance） $h(G)$ 为「割边数 / 较小一侧的体积」在所有二分上的最小值——它量化「最稀疏的瓶颈有多窄」。Cheeger 不等式（归一化拉普拉斯版）夹住了它：$\dfrac{\lambda_2}{2}\le h(G)\le\sqrt{2\lambda_2}$。这条双边界把一个组合量（最稀疏割，NP 难直接求）和一个可算的代数量（$\lambda_2$，一次特征分解）严格绑定——谱聚类之所以"有理可依"、过挤压之所以能用 $\lambda_2$ 诊断，根都在这里。$\lambda_2\to 0$ 即 $h(G)\to 0$，瓶颈无限窄。

5谱聚类：用 Fiedler 向量切图

谱聚类：用 Fiedler 向量把图切开

既然 $\lambda_2$ 度量图有多难切、Fiedler 向量指向那个「最自然的切口」，一个自然的想法就是：用 Fiedler 向量给节点排序、按它的符号把图二分——这就是谱聚类（spectral clustering）的核心，也是本模块的第一个完整算法。

直觉是这样的：我们想找一个把节点分成两组的方案，使得被切断的边尽量少（两组之间连接稀疏、组内连接稠密）。直接搜索是 NP 难的组合问题，但如果把「分组」用一个 $\pm1$ 的指示向量 $x$ 表示，那个心脏恒等式告诉我们：被切断的边数 $\propto x^\top L x$。于是「最小割」松弛成一个连续优化：

\[\min_{x}\ x^\top L x \quad \text{s.t.}\ \|x\|=1,\ x\perp \mathbf{1}\]

约束 $x\perp\mathbf 1$（与常向量正交）排除了平凡解「所有点一组」。由瑞利商理论，这个问题的最优解正是第二小特征向量——Fiedler 向量。于是算法极简：算出 Fiedler 向量，按其分量的符号（或中位数）把节点分两组即可。要分 $k$ 组就取最小的 $k$ 个特征向量、把每个节点映射成一个 $k$ 维坐标，再在这个谱嵌入上跑 k-means。

谱聚类（k 路）四步： 1. 构图、算归一化拉普拉斯 L_sym = I - D^{-1/2} A D^{-1/2} 2. 特征分解，取最小的 k 个特征向量 -> 列拼成 U_k ∈ ℝ^{n×k} 3. (对称归一化版) 把 U_k 的每一行单位化 -> 节点的 k 维谱嵌入 4. 在谱嵌入上跑 k-means -> 得到 k 个簇

本模块 notebook 会在一个随机块模型（SBM, stochastic block model）上完整跑这套流程：SBM 是生成「有社区结构的图」的标准模型——块内连边概率 $p$ 高、块间概率 $q$ 低，于是图天然分成几个社区。因为是我们自己生成的，每个节点真正属于哪个社区是已知的 ground truth，可以直接拿谱聚类的结果去对拍——这正是「先有真相、再验证算法」的方法论。你会看到：当 $p\gg q$ 时谱聚类几乎完美还原社区，而当 $p\approx q$（社区结构模糊）时它如何逐渐失效。

谱聚类不是万能的：它假设「簇 = 图上密集连接的块」（即同配 homophily）。当簇的定义与连接结构不一致（异配），或谱隙过小（社区边界模糊）时会失效。此外，从 $\pm1$ 离散问题松弛到连续特征问题是有近似间隙的——Fiedler 向量给的是松弛最优，按符号取整后未必是真正的最小割。但在 SBM 这类有清晰块结构的图上，它出奇地好用。

6随机游走与 PageRank

随机游走与 PageRank：图上的扩散

谱是图的「静态频率视角」；随机游走（random walk）则是「动态扩散视角」，两者其实是一枚硬币的两面。随机游走是这样一个过程：站在某节点，每步等概率随机跳到一个邻居。它的转移矩阵正是行归一化的邻接矩阵：

\[P = D^{-1}A,\qquad P_{ij} = \frac{A_{ij}}{d_i}\ (\text{从 } i \text{ 跳到 } j \text{ 的概率})\]

$P$ 是行随机矩阵（每行和为 1）。如果当前节点分布是行向量 $\pi^{(t)}$，下一步就是 $\pi^{(t+1)}=\pi^{(t)}P$；走 $k$ 步就是乘 $P^k$。随着 $k\to\infty$，分布收敛到一个不再变化的平稳分布（stationary distribution） $\pi$，满足 $\pi P=\pi$（即 $\pi$ 是 $P$ 的左特征向量，特征值 1）。

直白说

平稳分布回答「长期来看，随机游走者待在每个节点的概率是多少」。在无向连通图上有一个漂亮的闭式解：$\pi_i \propto d_i$——度越大的节点越常被访问。这非常直观：朋友越多的人，越容易被随机串门撞见。

严谨说

这里藏着一个贯穿全课的关键联系：反复用对称归一化邻接 $\hat A$ 聚合（GCN 干的事），数学上等价于一种随机游走/扩散。游走收敛到与度成正比的平稳分布 → 所有节点表示趋同 → 这正是模块 02 要讲的过平滑（over-smoothing）的根源！谱隙小则收敛慢但终究会收敛。

PageRank 是随机游走的一个著名变体，最初为网页排序而生（Google 的奠基算法）。它在每步以概率 $\alpha$ 传送（teleport）回一个随机节点，避免游走者卡在死胡同或孤立子图里：

\[\pi = (1-\alpha)\,\pi P + \alpha\,\frac{\mathbf{1}^\top}{n}\]

$\alpha$（重启概率，典型 0.15）控制「局部 vs 全局」：$\alpha$ 大则更看重传送、分布更均匀；$\alpha$ 小则更接近纯随机游走。把传送向量从「均匀」换成「集中在某个种子节点」，就得到个性化 PageRank（personalized PageRank, PPR）——以该节点为中心的影响力分布。PPR 在现代 GNN 里很重要：APPNP/PPNP 等方法用它来一次性聚合多跳邻居而不必堆很多层，从而既扩大感受野又避开过平滑——这是对模块 02 过平滑问题的一种优雅回应。notebook 会用幂迭代从零算出平稳分布与 PageRank，并验证 $\pi_i\propto d_i$。

幂迭代微例

怎么从零算平稳分布？最朴素的工具是幂迭代：随便取一个概率行向量 $\pi^{(0)}$，反复乘 $P$ 直到不再变化。仍用三点链 $1\!-\!2\!-\!3$：$P=\bigl(\begin{smallmatrix}0&1&0\\1/2&0&1/2\\0&1&0\end{smallmatrix}\bigr)$。从 $\pi^{(0)}=(1,0,0)$ 出发迭代几步，分布会摆动着收敛到 $\pi=(1/4,1/2,1/4)$——恰好正比于度 $(1,2,1)$！这就亲手验证了 $\pi_i\propto d_i$，也说明为什么不必做 $O(n^3)$ 特征分解、只用反复矩阵-向量乘就能拿到平稳分布（大图上这是唯一可行的路）。注意纯链是二部图、会有周期性振荡，加自环或传送项即可抹平——这正是 PageRank 引入 $\alpha$ 的另一重动机。

这四条线在下一模块汇成一点：GCN 的一层 $\sigma(\hat A X W)$ = 用对称归一化邻接（归一化视角）做一步扩散（游走视角），而这步扩散正是谱卷积的一阶近似（谱视角），堆太多层就会收敛到平稳分布而过平滑（连通性/扩散视角）。所以本模块不是「GNN 之前的预备知识」，而是 GNN 本身的数学源代码——理解了 $L$、$\lambda_2$、$P$、$\hat A$，你就已经理解了 GCN 的一半。

从工程角度还有一句要记住：本模块的运算大量涉及特征分解（$O(n^3)$）和稠密矩阵乘，这在玩具图上没问题、也最适合看清机制，但真实大图（百万节点）上必须改用稀疏运算、迭代特征求解器（如 Lanczos）、以及避免显式特征分解的近似（ChebNet 的多项式、PPR 的幂迭代）。本课先把机制学透，扩展性留给模块 05 与 references。

临别再把谱视角拔高一层，作为通往 GCN 的最后一块跳板：图上的「卷积」本质就是在谱域对每个频率分量乘一个增益 $\hat g(\lambda)$。$\hat g$ 在低频（小 $\lambda$）大、高频（大 $\lambda$）小，就是低通滤波（平滑、去噪）；反过来抬高高频就是高通（凸显差异，正是异配图所需）。GCN 选的滤波器恰是一条把高频压低的「软低通」——这一句话提前剧透了下一模块的全部张力：为什么 GCN 在同配图上好用、为什么堆深会过平滑（低通到极致只剩零频的直流分量）、为什么异配图上要换高通。把 $L=U\Lambda U^\top$、$\hat g(\lambda)$、低通/高通这三个词刻进脑子，你就握住了从谱图理论到整个图神经网络的那把总钥匙。

8研究前沿与开放问题

研究前沿与开放问题

  • 谱 GNN 的复兴：GCN 把谱卷积简化成一阶后，谱视角一度被冷落；近年 BernNet、JacobiConv 等用更灵活的多项式滤波器重新逼近任意谱响应，在异配（heterophily）图上超越 GCN。「该用多复杂的谱滤波器」仍是开放问题。
  • 位置编码的谱来源：拉普拉斯特征向量做位置编码（模块 04）面临符号与基歧义（$u$ 与 $-u$、同特征值子空间内任意旋转都合法）。SignNet/BasisNet（Lim 2023）等试图构造不变编码，但「图上最好的位置编码是什么」远未定论。
  • 谱隙、过挤压与图重连：$\lambda_2$ 小 = 有瓶颈 = 过挤压严重。用 Ricci 曲率（Topping 2022）等定位瓶颈边并重连图，是缓解过挤压的活跃方向；如何重连而不破坏原结构是核心难点。
  • 可扩展的谱方法：大图上避免 $O(n^3)$ 特征分解——随机化数值线性代数、稀疏迭代求解器、以及完全绕开谱的局部近似，是把谱方法用到真实规模的瓶颈。
  • 有向图与高阶结构：有向图的拉普拉斯不对称（谱可能复数），超图（hypergraph）/单纯复形（simplicial complex）的「拉普拉斯」如何定义并用于学习，是几何深度学习的前沿。
