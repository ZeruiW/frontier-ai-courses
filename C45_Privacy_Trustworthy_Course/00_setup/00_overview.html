1这门课讲什么

欢迎来到 隐私保护与可信 ML。这门课只追求一件事：让你从「会说我们重视用户隐私」变成「会算出隐私预算 ε、会写 DP-SGD、会跑联邦聚合、会做并验证机器遗忘」。

绝大多数团队和隐私的关系止于一句 PR 话术——「我们采用业界领先的隐私保护技术」。这门课要往下钻：当你说一个模型「保护隐私」时，到底防的是谁、防到什么程度、有没有数学保证、花了多少代价？一个在医疗数据上训练的模型，会不会从它的预测里反推出某个病人得了什么病？把一个人的数据从训练集删掉，模型权重里他的影子真的消失了吗？这些问题的答案不在任何合规承诺书里，而在具体的算法与可证明的保证之中。

本课的核心立场是：隐私不是一句口号，而是可证明、可度量、可审计的工程。我们把隐私保护拆成三条互相正交又可叠加的技术主线——形式化隐私（差分隐私：给隐私一个数学定义和预算）、去中心化（联邦学习：数据根本不离开设备）、可遗忘性（机器遗忘：让模型忘记一个人）——每一条都从零用 numpy 实现、与参考实现对拍、用 assert 钉死正确性。

学完你应当能回答这类问题（也是隐私 / 可信 ML 岗位的高频面试题）：(ε,δ)-DP 到底在保证什么？敏感度怎么算、噪声怎么标定？DP-SGD 比普通 SGD 多做了哪两件事、隐私会计怎么累加 ε？联邦学习的 FedAvg 凭什么在数据不集中时还能收敛、非 IID 为什么是它的命门？安全聚合怎么让服务器看不到单个更新？被遗忘权在模型层面怎么落地、精确遗忘和近似遗忘差在哪、怎么验证真的忘了？——并且能在 numpy 里把这些机制都从零实现、和参考实现对拍。

一句方法论上的话先说在前面：本课不教你背法条，而教你把隐私要求翻译成可执行、可验证的机制。GDPR 说「用户有被遗忘权」，这句话落到工程上就是模块 04 的 SISA 分片与影响函数；监管说「数据要最小化」，落地就是模块 03 的联邦学习让数据不出本地；「要有量化的隐私保证」就是模块 01/02 的 ε 预算与 DP-SGD。法规是 why，本课是 how——把 how 练扎实，才不至于让隐私停留在 PPT 上。

2世界观：威胁谱系与三条防御主线

贯穿全课的世界观可以浓缩成一张图：隐私威胁来自模型会泄露训练个体，防御则沿三条主线展开。先看威胁——为什么一个训练好的模型本身就是隐私风险：

隐私威胁攻击者做什么为什么可能本课对应的防御
成员推断 membership inference判断某条记录是否在训练集里模型对见过的样本更自信（过拟合的指纹）DP（模块 01/02）从定义上压制
数据重建 reconstruction把训练样本逐字复原出来大模型会逐字记忆罕见样本DP 限制单样本影响 + 遗忘删除
属性推断 attribute inference反推个体的敏感属性模型编码了与属性相关的关联DP + 数据最小化（FL）
数据集中风险 centralization一次拖库泄露所有人把原始数据堆在一处联邦学习（模块 03）数据不出本地
隐私 ⇄ 效用

最反直觉、也最重要的一条认知：一个泛化得好的模型，和一个泄露隐私的模型，往往是同一个模型。模型要学到规律就得拟合数据，而拟合到极致就会记住个别样本——尤其是罕见的、独特的样本（往往正是最敏感的个体）。所以隐私和效用存在根本张力：没有免费的隐私。差分隐私把这个张力量化成一条权衡曲线（花多少 ε 换多少准确率），而不是假装它不存在。本课每个技术都在这条权衡上选一个工作点，并诚实地把代价摆出来。

再看防御的三条主线，它们针对威胁的不同环节、可以正交叠加：差分隐私管「输出会不会泄露个体」——给隐私一个数学定义和可累加的预算；联邦学习管「原始数据要不要集中」——让数据留在设备、只传模型更新，从源头减少风险；机器遗忘管「事后能不能撤回」——让用户撤回授权后模型也忘记他。三者不是竞争关系：真实系统常常联邦学习 + DP + 安全聚合一起上（模块 03/05 会拼起来），各防一个环节。

把这张「威胁—防御」对照表刻进脑子，是做任何隐私设计的第一步。新手最常犯的错是把隐私当成单一开关——以为「加了 DP 就安全了」或「联邦了就不泄露了」。实际上每种技术只防特定威胁、留有特定缺口（DP 不防数据被偷、FL 不防从聚合结果反推、遗忘删不掉已扩散的副本），正确的姿势是先想清威胁模型、再对症组合。本课每个模块都会明确说清「它防什么、不防什么」。

3课程地图：从口号到可审计的隐私管线

课程地图：从一句口号到可证明、可审计的隐私管线

威胁：训练好的模型会泄露训练个体（成员推断 / 重建 / 属性推断） 模块 00 总览 可信 ML 全景：隐私/合规/去中心三主线；威胁↔防御谱系 │ 「先想清防谁、防到什么程度，再谈技术」 ▼ 模块 01 差分隐私 (ε,δ)-DP 定义、敏感度、Laplace/Gaussian、组合、预算 │ 「给隐私一个数学定义 + 可累加的预算」 ▼ 模块 02 DP-SGD per-sample 裁剪 + 高斯噪声 + 隐私会计累加 ε │ 「把 DP 装进训练：每步是一次高斯机制」 ▼ 模块 03 联邦学习 FedAvg、非 IID/漂移、安全聚合 —— 数据不出本地 │ 「换个轴：不是加噪，而是数据根本不集中」（与 DP 正交叠加） ▼ 模块 04 机器遗忘 SISA 精确遗忘 / 影响函数近似遗忘 + 遗忘验证 │ 「事后撤回：让模型忘记一个人」 ▼ 模块 05 可信部署 DP+FL+遗忘 拼成端到端管线 + 预算管理 + 合规 + 审计 「把三条主线组装成能上线、能过审计的系统」

注意这不是松散的专题集合，而是一条有内在逻辑的递进：模块 01 先给隐私一把数学尺子（差分隐私），模块 02 用这把尺子改造训练（DP-SGD），模块 03 换一个正交的轴——不是给输出加噪，而是让数据根本不集中（联邦学习），模块 04 处理事后撤回（机器遗忘），模块 05 把前面所有零件组装成能上线、能过审计的管线。前四个模块是工具，第五个是把工具拼成系统。

每一级台阶都对应一个可独立验证的能力：跑完模块 01 你能手算敏感度、实现 Laplace/Gaussian 机制并经验验证 ε；模块 02 你的 DP-SGD 会与非私有 SGD 对拍（看清效用代价）、会计器会累加出 ε；模块 03 你手写的 FedAvg 在同分布下会与集中式训练几乎一致、并能量化非 IID 的伤害；模块 04 你的影响函数遗忘会逼近真实重训、并用成员推断验证「忘了没」；模块 05 你能跑一条端到端隐私管线并产出合规报告。每一步都有 assert 兜底，绝不靠「感觉安全了」。

4方法论：用 numpy 实现并对拍参照

方法论：没有真实隐私事故，怎么学隐私防御？

本环境没有 GPU、不训大模型、不接真实用户数据。但隐私技术的难点从来不是规模，而是机制是否正确、保证是否成立、代价是否算清：噪声标定对不对、敏感度算没算错、ε 累加得对不对、遗忘是否真的抹掉了影响。这些都能用 numpy 在玩具规模上精确地实现和验证。

打个比方：学会计不需要管理一家世界五百强，用几笔账就能把借贷平衡练到肌肉记忆。隐私工程的「账」是隐私预算的核算、噪声与敏感度的标定、遗忘前后影响的对比；这些都和数据规模无关。一个真实 DP-SGD 系统里那行「裁剪每个样本的梯度、加高斯噪声、向会计器报告这一步的 ε」，在 numpy 里就是几行可以逐一 assert 的代码——我们让它在小数据上跑出来、好观察、好验证。机制一模一样，只差规模。

直白说

我们把每个隐私机制翻译成 numpy 里看得见、验证得了的东西：一次 DP 查询就是「真值 + 一个采自 Laplace/Gaussian 的噪声」，DP-SGD 就是「逐样本梯度 → 裁剪 → 求和 → 加噪 → 平均」的几个循环，联邦聚合就是「各客户端本地训练后按数据量加权平均」，遗忘就是「影响函数一步更新 vs 真重训」的对照。你写的是机制与正确性，不是生产性能。

严谨说

关键纪律是对拍（differential testing）：每个机制都和一个可信参照比对。DP 机制对拍它的理论期望与方差（无偏性、噪声尺度）以及经验 ε（用相邻数据集上的输出分布估计实际隐私损失）；DP-SGD 对拍非私有 SGD（量化效用代价）；FedAvg 对拍集中式训练（同分布下应几乎一致）；近似遗忘对拍真实重训（金标准）。机制正确 → 数值符合理论；数值符合 → 你的隐私逻辑可以原样搬到 Opacus/Flower。

隐私概念本课的 numpy 实现对应真实工具
DP 机制（加噪）真值 + np.random 的 Laplace/Gaussian 噪声google-dp / diffprivlib
逐样本梯度裁剪 + 加噪手算每样本梯度、按 L2 范数裁剪、加高斯Opacus / TF-Privacy
隐私会计（累加 ε）组合定理 / RDP 直觉的标量累加Opacus RDP accountant
联邦 FedAvg多客户端本地 SGD + 加权平均Flower / TFF
安全聚合成对随机掩码求和相消Bonawitz SecAgg
机器遗忘影响函数一步更新 vs 重训对拍（研究原型 / 自建）

为什么把对拍提到方法论的高度？因为隐私的 bug 极其阴险：噪声加少了看起来一切正常、模型照常工作，隐私却已经漏了；遗忘没删干净也不会报错，被删的人依旧能被成员推断揪出来。这类错误不会崩溃、不会抛异常，只会悄悄地不安全。在 numpy 模拟里，我们有绝对可信的参照——理论上该有的期望/方差、相邻数据集上的真实分布、从头重训的金标准——任何偏差都会被 assert 当场抓住。本课每个机制都「先写参照、再写机制、立刻对拍」，这正是真实隐私工程（与已知保证、与重训对账）的核心工作流，只是我们在更干净的环境里把它练成肌肉记忆。

务必清楚本课不教什么：不教法律条文细节、不做真实大模型的 DP 微调、不实现生产级密码学（安全聚合只做直觉级 numpy 模拟）、不替代专业的隐私合规审计。这些在你有了正确的机制直觉之后，是第二步（references 里的 Opacus、Flower、PATE、各国法规与专业审计接手）。本课负责把第一步——机制与正确性、保证与代价夯死；这一步搞定，第二步才有意义。

5环境与运行

环境与运行

环境极简：只需 numpy（画隐私-效用曲线可选 matplotlib）。全课 CPU 秒级运行，无需 GPU、无需深度学习框架、无需联网（胶囊用内置真实数值，联网可选）。

conda create -n privacy python=3.11 -y && conda activate privacy
pip install numpy            # 必需
pip install matplotlib       # 可选，仅用于画隐私-效用 / ε-准确率曲线
jupyter lab

每个模块配一个 notebook，结构统一：先用 numpy 把机制从零实现并对拍（5–6 个 worked 小节，每节都跑出可打印的验证与 assert），再做 3–4 道带 assert 判分的 ✏️ 练习（先给骨架，自己填，再对照 📖 参考答案），最后一个真实数据胶囊（用真实的隐私参数 / 法规要求 / 公开案例数据算一笔账，把纸面知识接到现实）。

建议的学习节奏：先读完整章 HTML 建立威胁模型与理论框架，再打开 notebook 亲手实现。读和做缺一不可——只读会觉得「好像懂了 ε」，真正动手标定噪声、累加预算、让 assert 通过时，才会发现魔鬼藏在哪些细节里（敏感度算错、δ 选得离谱、裁剪范数太小、遗忘只删了表面）。这门课的深度正是为「动手」服务的。

配套先读：Dwork & Roth《算法基础》建立 DP 的定义与组合直觉；Abadi 2016（DP-SGD）、McMahan 2017（FedAvg）、Bonawitz 2017（安全聚合）、Bourtoule 2021（SISA 遗忘）、Guo 2020（certified removal）是四条主线的奠基。完整清单见 references.md。

✅ 学完整门课，你应该能：
  1. 把一个隐私需求映射到威胁模型，说清防谁、防到什么程度、留有什么缺口；
  2. 写出 (ε,δ)-DP 的定义，手算查询的敏感度，实现 Laplace / Gaussian 机制并经验验证其隐私与效用；
  3. 用串行 / 并行组合与 RDP 直觉核算多次发布的总隐私预算；
  4. 从零实现 DP-SGD（逐样本裁剪 + 高斯噪声 + 会计），并量化它相对非私有训练的效用代价；
  5. 从零实现 FedAvg（对拍集中式），诊断非 IID 与客户端漂移，并解释安全聚合如何与 DP 正交叠加；
  6. 实现精确（SISA）与近似（影响函数）遗忘，并用成员推断 / 重训对照验证遗忘是否真的发生；
  7. 把 DP+FL+遗忘组装成端到端隐私管线，做预算分配与组合核算，并产出合规清单与审计报告。
