# Agent 安全与提示注入 —— 依赖清单
# 纯 numpy + Python 标准库，CPU 可跑、断网可跑，单个 notebook 通常几秒到一分钟跑完。
#
# 本课不调用任何 LLM API，也不包含针对真实系统的可用攻击载荷：
# 被攻击的 agent 是一个几十行的规则匹配器，「注入」是 [[INJECT:action]] 这样的占位符标记，
# 而「模型服从注入的概率」是一个可调旋钮 —— 这让你能定量研究防御的效果
# （「这个防御把 ASR 从 42% 降到 0.3%」），而不需要真实模型。
#
# 防御侧则全部是真实实现（权限系统、范围检查、出站白名单、审计、金丝雀判分），
# 因为它们本来就不依赖模型。

numpy          # 全课：ASR 与 ASR@k 的模拟、确认疲劳的衰减模型、边际贡献与二阶交互
jupyterlab     # 运行 notebook
ipykernel      # 注册 Jupyter kernel

# —— 以下全部是 Python 标准库，无需安装 ——

# json          # 全课：spec/lock/审计记录的稳定序列化
# hashlib       # 02/03 模块：工具清单的内容哈希、动作 digest（TOCTOU 防御）

# urllib.parse  # 04 模块：URL 解析、query 提取、多轮 URL 解码
# ipaddress     # 04 模块：SSRF 防御（私有网段与元数据地址校验）
# posixpath     # 03 模块：路径规范化（.. 穿越的正确修法）
# dataclasses   # 03 模块：frozen 的动作对象（确认与执行之间不可变）
# itertools     # 02/03/05 模块：组合枚举、加载顺序的全排列、防御组合搜索
# collections   # 全课：Counter / defaultdict
# math          # 全课：log/exp（信息量上界、k50、疲劳衰减）
