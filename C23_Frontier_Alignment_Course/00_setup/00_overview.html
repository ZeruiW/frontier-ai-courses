1这门课追问什么

欢迎来到 前沿对齐：CAI · RLAIF · 可扩展监督。这门课只追问一个问题，并把它追到底：当一个任务强到人类已经难以可靠地评判模型的输出时，我们还能从哪里得到对齐它所需的监督信号？

这个问题听上去抽象，却是当下每一家前沿实验室的核心工程难题。今天的对齐主力工艺是 RLHF（人类反馈强化学习）：人给一堆回答打分排序，我们从这些偏好里训一个奖励模型，再用强化学习让模型去追求高奖励。它之所以能成立，隐含了一个前提——人类能够判断哪个回答更好。可一旦任务超出人类的舒适区（评判一段复杂代码有没有微妙后门、一篇论文的证明对不对、一个长程计划是否暗藏风险），这个前提就开始松动。人评得慢、评得贵、还会评错；而模型越强，它越能产出看起来对、其实错或人类根本看不懂对不对的输出。

于是对齐研究分裂出一束彼此呼应的答案，正是本课的五个模块：让 AI 按一部明文宪法给自己当老师（Constitutional AI / RLAIF，模块 01）；正视那个被我们当目标优化、却会被钻空子的奖励代理（奖励建模与过优化，模块 02）；让两个 AI互相揭穿好让弱裁判也能判对（可扩展监督与辩论，模块 03）；用弱监督去引出强模型本就具备的能力（weak-to-strong，模块 04）；以及让模型在回答前显式地推理一份规范再下笔（deliberative alignment，模块 05）。

把整门课压成一句话：对齐的难点正在从「优化」转移到「监督」。怎么把一个目标优化进模型，我们已经相当在行（RL 很能打）；难的是给出一个正确的目标，并在人类看不清的地方仍能校验它。本课的五个方法，是同一个监督难题的五种攻法——它们不互斥，真实系统常常叠着用。

学完你应当能回答这类问题（也是对齐/后训练岗位的高频考点）：RLHF 的瓶颈到底卡在哪一步？Constitutional AI 用什么替代了人类标注，代价是什么？为什么对一个奖励模型优化过头反而变差（Goodhart）、怎么用集成的分歧来缓解？debate 凭什么能让弱裁判监督强模型、它的命门又在哪？weak-to-strong 现象说明了什么、PGR 怎么算？deliberative alignment 把安全从隐式记忆变成了显式推理，好处和风险各是什么？——并且能在 numpy 里把这五样东西都从零模拟出来、用 assert 验证逻辑正确。

2地基：RLHF 三步与它的三道裂缝

先把地基铺平：RLHF 三步与它的三个裂缝

几乎所有现代对齐方法都站在 RLHF 的肩膀上（或在修补它），所以先把它讲清楚。RLHF 是一条三段流水线：

① SFT 监督微调 用人写/筛选的优质示范，标准的下一-token 监督学习 │ 产出一个「会好好说话」的基线策略 π_ref ▼ ② RM 奖励建模 收集人类偏好对 (chosen, rejected)，训一个打分模型 r(x,y) │ 用 Bradley-Terry：P(chosen≻rejected)=σ(r_chosen − r_rejected) ▼ ③ RL 策略优化(PPO) 让策略 π_θ 去最大化 r(x,y) − β·KL(π_θ ‖ π_ref) KL 项把它拴在 π_ref 附近，别为了刷分跑飞

这条流水线极其有效，却有三道一旦任务变难就会扩大的裂缝，本课的模块恰好各补一道：

裂缝在哪一步症状本课的应对
标注瓶颈② 收集偏好人类标注又贵又慢，尤其标「有害性」既费神又伤害标注者用 AI 反馈替代（CAI/RLAIF，模块 01）
奖励失真③ 优化 RMRM 是真偏好的不完美代理，优化过头会被钻空子（Goodhart）过优化诊断 + RM 集成保守奖励（模块 02）
监督天花板②③ 都依赖人能评判任务一旦超出人类评判能力，整条链失去正确信号debate / RRM / w2s / deliberative（模块 03–05）

注意这三道裂缝有个共同的深层成因：RLHF 把「人类能评判」当作了免费且可靠的资源。当这个假设成立时它工作得很好；当模型逼近甚至超过人类水平时，三道裂缝同时变宽。本课后半程（03–05）正是在直面那个终极版本的问题——如何监督一个比你聪明的系统——这也是 OpenAI superalignment、Anthropic scalable oversight 共同的命题。

一个贯穿全课的措辞纪律：奖励模型、宪法、规范，都是我们想要的东西的「代理（proxy）」，不是它本身。RLHF 优化 RM、CAI 执行宪法、deliberative alignment 推理 spec——一旦把代理误当成真目标拼命优化，Goodhart 定律就会来收账（模块 02 会量化这件事）。把「代理 ≠ 真目标」刻在脑子里，是看懂本课所有失效模式的钥匙。

3五模块：一条「监督从哪来」的主线

五个模块：一条「监督信号从哪来」的主线

问题：任务强到人类难以可靠监督时，对齐信号从哪来？ 01 Constitutional AI 信号来自「AI 按明文宪法给自己的反馈」 │ 人写原则 → 模型自我批判-修订 → AI 标注偏好做 RL(RLAIF) ▼ 02 奖励建模与过优化 正视信号载体本身：RM 是有缺陷的代理 │ Bradley-Terry 训 RM → 优化过头 gold 分倒 U → 集成分歧抗 hacking ▼ 03 可扩展监督与辩论 让弱监督者也能判对：靠对抗与分解 │ debate(揭穿>欺骗) · recursive reward modeling · sandwiching ▼ 04 Weak-to-Strong 弱监督能「引出」强模型已有的能力 │ 弱标签训强学生 → 学生超过老师 → PGR 度量 + 置信损失 ▼ 05 Deliberative 信号来自「模型对明文规范的显式推理」 回答前检索/推理 spec 条款 → 一致性评分 → 拒绝校准/抗越狱

这不是松散的专题集合，而是一条有内在逻辑的递进。模块 01 给出第一个绕开人类标注的办法（让 AI 按规则当老师），但它依赖一个能被优化的信号——奖励模型，于是模块 02 把这个信号本身翻过来检查，揭示它会失真。模块 02 的失真根源是「人类（或代理）评判力有限」，于是模块 03 正面进攻「如何让有限的评判力监督更强的模型」（辩论与分解）。模块 04 给出一个出人意料的乐观信号：弱监督也许主要在引出强模型已有的能力，而非从头教它。模块 05 则把监督从「事后给偏好」前移到「事前推理规范」，让对齐变得可审计、可更新。读到最后你会发现，它们都是同一道题的不同解法。

每一级台阶都对应一个可在 notebook 里独立验证的能力：模块 01 你会写出一个按原则批判-修订回答、并生成 AI 偏好对的循环；模块 02 你手搓的 RM 会复现倒 U 过优化曲线、并用集成分歧造出更抗 hack 的保守奖励；模块 03 你的辩论模拟会显示弱裁判准确率随论证质量上升；模块 04 你的强学生会在带噪弱标签下超过弱老师、并算出 PGR；模块 05 你的 spec-following 评分器会区分「真按规范推理」和「嘴上说说」。每一步都有 assert 兜底，绝不靠「感觉对了」。

4方法论：用 numpy 在沙盒里模拟对齐

方法论：没有大模型，怎么学前沿对齐？

本环境没有 GPU、不联网、不加载大模型。但前沿对齐方法的难点从来不是「跑一个 70B 模型」，而是它们的逻辑结构：偏好怎么变成奖励、优化为什么会失真、辩论为什么能放大监督、弱标签为什么能引出强能力、规范推理为什么更稳健。这些结构用 numpy 在玩具模型上也能精确地表达和验证。

直白说

我们把每个方法翻译成 numpy 里看得见摸得着的东西：一个「模型」就是一个打分函数或一个小线性分类器，一份「偏好」就是按 Bradley-Terry 合成的一对样本，一次「自我批判」就是按关键词规则找违规、一次「辩论」就是双方轮流亮出可被裁判核验的证据。你写的是机制与权衡，不是 SOTA 数字。

严谨说

关键纪律是可验证（assert-backed）：每个机制都设一个我们知道真相的合成沙盒（埋入真概念、设定 gold 奖励、给定真有害标签），让方法的效果能与 ground truth 对照。Bradley-Terry 的偏好概率必须随分差单调、过优化必须真的出现倒 U、w2s 的 PGR 必须落在 [0,1] 的合理区间——任何偏差都会被 assert 当场抓住。结构正确，机制就站得住，逻辑便能迁移到真实管线。

对齐概念本课的 numpy 模拟对应真实系统
奖励模型 r(x,y)一个线性/打分函数，按特征给分RLHF 里的 RM（一个带标量头的 LLM）
人类偏好对Bradley-Terry 按 gold 分合成 (chosen,rejected)标注者标的偏好 / Anthropic/HH 数据
自我批判-修订按原则关键词规则改写回答CAI 让模型自己 critique+revise
AI 反馈偏好用 gold/原则函数自动给偏好标签RLAIF 的 AI 标注
辩论双方轮流亮可核验证据 + 弱裁判打分AI safety via debate 协议
weak-to-strong弱标签训强线性探针，比对 ceilingBurns et al. 用 GPT-2→GPT-4 类比
spec-following检索匹配规范条款 + 一致性评分deliberative alignment 的 CoT 推理 spec

为什么把「设一个知道真相的沙盒」提到方法论的高度？因为对齐方法的失效极其隐蔽：reward hacking 不会报错，它只是让一个看起来在变好的训练悄悄走向变差；一个高准确率的监督协议可能只是在读伴生特征；w2s 的提升可能来自数据泄漏而非真泛化。在真实系统里这些要靠昂贵的人评和大量算力才能发现；而在玩具沙盒里，我们人为设定了 ground truth（真概念方向、gold 奖励、真有害标签），任何「proxy 上去了但 gold 下来了」的偏离都立刻可见。先在已知真相的沙盒里把直觉和判据校准好，再上真模型——这正是严肃对齐研究的工作顺序。

务必清楚本课不教什么：不训练真实大模型、不跑 PPO/真实 RL、不追 SOTA 分数、不下载数据集。这些在你理解了方法的逻辑结构之后，是第二步（references 里的 TRL/trlx、各论文的开源实现接手）。本课负责把第一步——机制、为何有效、在哪失效夯死；这一步搞定，第二步才有意义、也才不会被漂亮的数字蒙住眼睛。

5环境、运行与研究前沿

环境、运行与研究前沿

环境极简：只需 numpy（个别可视化可选 matplotlib）。全课 CPU 秒级运行，无需 GPU、无需联网、无需任何大模型或数据集下载。

conda create -n align python=3.11 -y && conda activate align
pip install numpy            # 必需
pip install matplotlib       # 可选，仅用于画过优化曲线等
jupyter lab

每个模块配一个 notebook，结构统一：先用 numpy 把机制从零实现并验证（5–6 个 worked 小节，每节都跑出可打印的数字与 assert 自检），再做 3–4 道带 assert 判分的 ✏️ 练习（先给骨架，自己填，再对照 📖 参考答案），最后一个真实数据/配置胶囊（用真实系统的设定或公开数值算一笔账，把玩具知识接到现实）。建议节奏：先读完整章 HTML 建立动机与机制框架，再打开 notebook 亲手实现——只读会觉得「好像懂了」，真正动手写偏好损失、调 KL、让 assert 通过时，才会撞见魔鬼藏身的细节。

配套先读（建立全局）：Leike et al. 2018《Scalable agent alignment via reward modeling》给出「学奖励 + 优化奖励」的框架；Amodei et al. 2016《Concrete Problems in AI Safety》列出本课每个模块对应的具体安全问题。各模块的核心必读见每章末与 references.md。

研究前沿与开放问题（贯穿全课）

  • AI 反馈的天花板：RLAIF 用 AI 替代人类标注，但 AI 反馈本身从哪获得对齐？是否只是把人类偏见换成模型偏见、并把错误规模化？（模块 01）
  • 过优化无法根除：RM 集成能缓解 reward hacking，但所有成员共有的盲区仍会被钻；如何检测「集成都错」的区域是开放的（模块 02）。
  • debate 的混淆论证：若辩手能给出人类无法在合理步数内证伪的错误长论证，「揭穿>欺骗」的假设就失效——debate 能否扩展到真正超人任务尚无定论（模块 03）。
  • w2s 是引出还是侥幸：强学生超过弱老师，多大程度是真「引出」潜在能力、多大程度是任务简单或数据泄漏？能否扩展到真正的人类-超人差距？（模块 04）
  • 规范推理可被伪装：deliberative alignment 让模型显式推理 spec，但模型可能学会「表面引用规范、实则另有打算」（unfaithful CoT），如何保证推理忠实仍是难题（模块 05）。

这些前沿问题分别由 Bai 2022（CAI）、Gao 2023（过优化）、Irving 2018（debate）、Burns 2023（w2s）、Guan 2024（deliberative）开启或推进。把它们当成本课的「未完成章节」——你学完后能读懂、甚至能参与的真实研究。完整清单见 references.md。
