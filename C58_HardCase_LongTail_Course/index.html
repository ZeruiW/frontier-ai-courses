MODULE 00

课程总览与环境

数据飞轮是自动驾驶感知唯一不会被架构趋同抹平的护城河；闭环三环节「触发 → 挖掘 → 验证」为什么是串联而非并联；「加了数据没涨」的四个根因；长尾的幂律本质——α ≈ 1 时前 20% 的类吃掉七成样本，所以尾部靠随机采样在数学上就是采不到的。

MODULE 01

类别不平衡的处理谱系

前景-背景不平衡与类别间长尾是两个问题，解法族完全不同；RFS 的平方根是防过拟合的刹车；CB Loss 用有效样本数 (1−β^n)/(1−β) 承认「样本会互相覆盖」；LDAM 把 margin 按 n^(−1/4) 分配；EQL/EQLv2 处理检测独有的「稀有类被负梯度淹没」；logit adjustment 零训练成本且可回滚；解耦训练证明长尾主要伤的是分类器而不是表示——这一条决定了你该重训什么。

MODULE 02

难例挖掘：OHEM、难负样本与难例的类型学

OHEM 不先 NMS 去重就会被一个难区域的重叠框吃光名额；Focal Loss 是 OHEM 的连续化，软权重 vs 硬截断的取舍是面试常问；hard negative 的定义是「自信地错」而不是「分低」；难例四类里最危险的是标注错误——噪声标签的 loss 同样很高，挖掘过头等于反复讲错的教材；用损失轨迹与多模型一致性把难例和噪声分开，是这一节最可迁移的技能。

主动学习与线上触发策略

问题从「挖什么」变成「回传什么」：带宽与标注预算才是真约束；框级不确定性到图级的聚合方式会决定触发器的系统性偏好；熵里混着不可约的偶然不确定性，BALD 用互信息把认知不确定性单独拿出来；多帧类别跳变是 TSR 上最有效且零标注成本的触发信号；影子模式是拿到「自信且错」样本的唯一通道；触发器必须做 PR 分析并接受一个事实——它本身就是有偏的采样器。

MODULE 04

大规模挖掘基础设施

嵌入检索是长尾挖掘的主力，但没有 recall@k 评估的检索等于抽奖；ANN 索引的召回-延迟-内存三角与索引过期的静默失效；场景标签体系与三条自动打标路（元数据 / 规则 / VLM），以及「用未评估的模型给模型选数据」这个陷阱；感知哈希与嵌入聚类分别抓像素级和语义级重复；core-set 的 k-center 贪心最小化覆盖半径（2-近似），目标是覆盖而不是找最难；标注预算按缺口 × 难度 × 单价分配；数据血缘决定出事时能不能回溯。

MODULE 05

闭环验证：证明数据真的有用

三个必答问题：目标场景涨了吗、其他场景掉了吗、涨的是不是种子噪声；换种子 ±0.2–0.5 mAP 意味着「+0.3」不构成证据；回归门禁的容差要按实测种子方差设；20 个切片同时看，α=0.05 下有 64% 概率至少一个假显著，必须做 BH/FDR 校正；新旧数据配比与灾难性遗忘；边际收益曲线 AP(n) ≈ a − b·n^(−c) 把「还值不值得标」变成一个数字；挖掘集与评测集的泄漏是最隐蔽的作弊；闭环真正的 KPI 是周期时间。
