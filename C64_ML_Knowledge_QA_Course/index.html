ML/DL 技术知识问答

HR 白纸黑字写着一面包含 Technical Knowledge Assessment，而全库里最接近的 C07 教的是数学推导——softmax 梯度、贝叶斯公式、k-fold 怎么证明。推导会了不等于面试答得好：考官要的是在 60 秒内讲清楚，并在被追问时接得住。这门课把 ML/DL 的核心知识点全部改写成「一句话定义 → 为什么需要 → 什么时候失效」的三段式，外加 150+ 题的快问快答题库和一份 90 分钟复习清单。

6 模块 三段式答法：一句话定义 → 为什么需要 → 什么时候失效 四维评分：准确性 / 深度 / 边界意识 / 诚实度 150+ 题快问快答题库 · 必答/加分/边界三层分级 CPU only · 纯 numpy/标准库 · 无需 GPU
怎么用： 每个模块先读 HTML 讲解（每个知识点都按三段式 + 典型追问 + 踩雷点展开），再跑 notebook——把「你以为你懂」变成「亲手跑出来验证过」。你会亲手实现的东西包括：偏差-方差的数值分解实验（画出经典 U 形，并复现双下降曲线）、L1/L2 解路径与 dropout 的集成等价性验证、CV 在时序数据上泄漏的量化演示、六种优化器在同一玩具问题上的轨迹对比、Adam 里 L2 与解耦 weight decay 的差异量化、warmup 有无的梯度范数对比、初始化方案对前向传播激活方差的影响追踪、从零实现 scaled dot-product attention 并验证 √d_k 的必要性（softmax 饱和实验）、BN/LN/GN 在小 batch 下的统计量稳定性对比、同一份预测在平衡/不平衡数据下 ROC-AUC 与 PR-AUC 的分歧演示、可靠性图与 ECE、温度缩放、三种置信区间对比（小样本下 Wilson 区间的优势）、A/B 样本量与功效计算、辛普森悖论的可复现构造，以及一套闪卡式自测引擎（随机抽题、隐藏答案、按主题统计弱项、SM-2 式间隔重复调度）。本课的核心主张：C07 教你推导，本课教你在 60 秒内讲清楚并接住追问——考官评的从来不是「你是不是背下了定义」，而是四件事：准确性（说对了没）、深度（能不能再往下展开一层）、边界意识（知不知道它什么时候不成立——这是区分度最高的一维）、诚实度（不会的东西敢不敢说不会）。本环境不需要 GPU：所有实验都是纯 numpy/CPU，断网可跑，秒级出结果。
