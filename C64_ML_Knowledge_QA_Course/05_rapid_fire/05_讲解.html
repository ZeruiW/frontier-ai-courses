1整门课的收官：这套题库怎么用

走到这里，你已经读完了「一句话定义 → 为什么需要 → 什么时候失效」的四轮训练（机器学习基础、优化与训练、深度学习架构、评估与统计）。这一模块不再引入任何新概念——它把前四个模块揉成一份题库（question bank），加上一台真正能跑的自测引擎，目标只有一个：面试前一周，你能不能高效地找到自己最薄弱的地方，并把它补上。

题库分三层，这个分层本身就是一个面试信号——面试官的追问顺序，通常就是按这三层往下探的：

层级考察什么答错的后果示例问题
必答地基概念，任何一个 ML/CV 岗都默认你会答错或说不清，直接影响「继续深聊」的意愿——这是一票否决级的信号「Precision 和 Recall 分别回答什么问题？」
加分细节、边界条件、机制对比，考察你是否真的用过而不是背过答不上不扣底分，但答上了会明显拉开与其他候选人的差距「AdamW 和 Adam+L2 为什么不等价？」
边界开放问题、前沿争议、你大概率答不全的领域这一层的正确答案往往是「诚实地说不知道，并给出你会怎么查」，不是硬答「双下降现象有没有一个大家公认的完整理论解释？」

直白说

很多人复习到这里会想「再多刷点题」，但这时候边际收益最高的动作不是读更多新知识点，是找出自己在已经学过的东西里到底哪些还没记牢——这正是间隔重复算法要解决的问题：它不会让你重复练熟悉的题（浪费时间），也不会让你完全不碰生疏的题（考试时会忘），而是精确地把你的时间导向「刚好快忘、最该复习」的那些题。

严谨说

本模块的 notebook 实现了一台闪卡引擎（flashcard engine）：150+ 题以结构化数据内置，每题标注主题 / 层级 / 频率；引擎按 SM-2 算法（Wozniak 的间隔重复调度算法，Anki 等软件的理论基础）维护每张卡片的「易记因子（EF）/ 复习间隔 / 复习次数」，随机抽题、隐藏答案、按你的自评分调度下一次复习时间；再按主题聚合出弱项报告，最后自动生成 90 分钟的复习时间分配表。

这一模块也是全书里唯一一个你应该反复运行、而不是读一遍就够的模块——面试前的最后一周，每天花 20 分钟跑一轮 notebook 里的闪卡引擎，比再读一遍任何一门课的正文都更有针对性。

这也是整个 C00–C64 课程体系里最后一次强调这一点：这套题库是为 XPENG TSR 岗位一面的「Technical Knowledge Assessment」环节准备的，本模块第 6 节会给出通向检测专项深挖内容的完整入口。

2题库 · 机器学习基础（呼应 C64-01）

下面是「机器学习基础」这一主题的代表性抽样（完整 35 题在 notebook 的结构化数据里）。每题给「一句话答案 / 典型追问 / 踩雷点」——这正是你在白板前应该输出的三件东西。

题目一句话答案典型追问踩雷点层级/频率
高方差的信号是什么？训练误差低、验证误差高，且两者差距会随模型复杂度继续拉大「怎么和高偏差区分？」→ 高偏差是两者都高把「验证误差高」单独当高方差的信号，忘了对比训练误差必答·高频
双下降现象是什么？模型复杂度越过插值阈值后，测试误差会先升后再次下降「经典偏差-方差理论为什么解释不了？」→ 经典理论假设的是单调关系以为双下降否定了偏差-方差权衡——它只是补充了一个经典理论没覆盖的区间加分·中频
L1 为什么产生稀疏解？L1 的等高线是菱形，最优点更容易落在坐标轴顶点（某些系数恰好为 0）「L2 呢？」→ 圆形边界，最优点几乎不会恰好落在轴上混淆「L1 让权重变小」和「L1 让权重变 0」——后者才是稀疏性的定义必答·高频
Dropout 为什么等价于隐式集成？每次前向传播都相当于采样一个子网络，等价于对指数级多个子网络做平均「推理时为什么要按保留概率缩放？」→ 保证期望输出与训练时一致忘了推理时的缩放（或用错 inverted dropout 的写法）加分·中频
为什么时序数据不能用普通 k 折？普通 k 折会让「未来」的样本出现在训练集里，预测「过去」，造成信息泄漏「那应该怎么做？」→ 按时间顺序切分，只能用过去预测未来以为随机打乱后 k 折就没有泄漏问题——打乱本身就是泄漏的来源必答·高频
bagging 为什么降方差、boosting 为什么降偏差？bagging 并行训练多个高方差基学习器再平均，抵消随机性；boosting 顺序纠正前一轮的残差，逐步逼近真值「随机森林为什么对超参数不敏感？」→ 平均本身自带正则化把两者的机制记反——这是最常见的口误必答·高频
生成式模型和判别式模型的区别？生成式建模联合分布 $P(x,y)$（能采样），判别式直接建模 $P(y\mid x)$（只能分类）「小样本场景为什么常选生成式？」→ 对数据分布做了更强的假设，方差更低以为「生成式」只能指 GAN/扩散模型——朴素贝叶斯也是生成式模型加分·中频
维度灾难是什么？高维空间里样本会变得稀疏，任意两点的距离趋于相等，基于距离的方法开始失效「流形假设怎么缓解它？」→ 真实数据往往集中在一个低维流形上，有效维度远低于原始维度以为维度灾难只是「特征太多计算慢」——它的核心是距离度量本身失去区分度加分·中频

直白说

这些题看起来都很基础，但面试官很少只问「是什么」——他们几乎总会追问一句「那什么时候它不成立」。比如问完 bagging 降方差，几乎必然追问「那 bagging 能不能降偏差」（答案是：基本不能，如果基学习器本身偏差就很大，平均再多个也没用，这时候该用 boosting）。

严谨说

把这张表当作一个自检清单：对每一题，你能不能在心里补一句「什么时候它反而是错的」？如果补不出来，说明你现在的理解还停留在「记住了结论」，而不是「理解了机制」——回到 C64-01 对应小节，重点看那里的失效场景讨论，而不是重新读一遍定义。

3题库 · 优化与训练（呼应 C64-02）

优化与训练这一段的题，面试官爱用「为什么不用另一个」的句式来问——所以答案不能只背「Adam 结合了动量和自适应学习率」，还要能说清它换来了什么、付出了什么代价。

题目一句话答案典型追问踩雷点层级/频率
为什么 CV 检测任务里 SGD+Momentum 常常仍是首选？Adam 类方法收敛快但常收敛到更「尖锐」的极小值，泛化性有时不如 SGD+Momentum 找到的「平坦」极小值「那什么时候该用 Adam？」→ Transformer、小数据、快速迭代实验阶段以为 Adam 永远比 SGD 好——这是没做过大规模检测训练的信号加分·高频
AdamW 和 Adam+L2 为什么不等价？Adam 的自适应学习率会重新缩放梯度（含 L2 正则项），导致有效的权重衰减强度被每个参数的历史梯度悄悄改变；AdamW 把权重衰减从梯度更新里解耦出来，直接乘在参数上「解耦之后有什么好处？」→ 权重衰减的强度不再受自适应学习率的干扰，更符合直觉的超参数语义把 AdamW 说成「Adam 加了个正则项」——它是把正则项挪出了自适应缩放的作用范围必答·高频
Warmup 为什么必要？训练初期梯度方差大、Adam 的二阶矩估计还不准，直接用目标学习率容易导致更新方向不稳定甚至发散「Transformer 为什么对 warmup 格外敏感？」→ LN + 自注意力在训练初期的梯度尺度本身波动更大以为 warmup 只是「经验技巧」——它对应一个具体的数值不稳定机制必答·高频
He 初始化为什么专为 ReLU 设计？ReLU 会让一半的激活值变成 0，方差減半，He 初始化把方差乘 2 做补偿，保持前向传播的激活方差稳定「Xavier 用在什么场景？」→ 假设激活函数关于 0 对称（如 tanh/sigmoid），ReLU 不满足这个假设把 Xavier 和 He 的适用激活函数记反必答·中频
大 batch 训练为什么泛化更差？大 batch 的梯度噪声更小，优化过程更容易收敛到损失曲面上「尖锐」的极小值区域，这类区域对测试分布的微小偏移更敏感「线性缩放规则是什么？」→ batch size 扩大 k 倍，学习率也扩大 k 倍（配合 warmup）以维持有效噪声水平以为大 batch 只是「训练更快」没有代价——收敛速度和泛化性在这里是两件事加分·中频
Focal Loss 的 α 和 γ 各自作用是什么？α 处理类别数量的不平衡（给稀有类更大权重），γ 处理难易样本的不平衡（降权已经分对的简单样本）「γ=0 时 Focal Loss 退化成什么？」→ 带 α 加权的标准交叉熵把 α 和 γ 的职责记反——这是白板题里最容易说错的一句必答·高频
Label Smoothing 解决什么问题，副作用是什么？防止模型对训练标签过度自信（把 one-hot 目标软化），改善校准；副作用是会轻微损害需要「非常自信输出」的场景（如知识蒸馏的教师模型）「和温度缩放的关系？」→ label smoothing 是训练期的校准手段，温度缩放是训练后的校准手段（见 C64-04）以为 label smoothing 只对准确率有影响——它主要影响的是校准，见 C64-04加分·中频
「为什么不用另一个」是这一段的通用追问模板。如果你的答案只有「A 更好」而没有「A 在什么场景下反而更差」，面试官会认为你只是记住了一个流行结论，而不是真的比较过。

4题库 · 深度学习架构（呼应 C64-03）

架构题最容易被问到的形式是「给你一个具体的层，解释它为什么这么设计」——所以每题都要能落到「不这么设计会有什么后果」这个具体后果上。

题目一句话答案典型追问踩雷点层级/频率
1×1 卷积的三个作用？跨通道信息融合、升维/降维（控制参数量与计算量）、增加非线性（配合激活函数）「和全连接层的区别？」→ 1×1 卷积逐空间位置独立作用，权重在空间维度共享只答出「降维」一个作用——面试官期待你说出至少两个必答·高频
BN 在检测任务上为什么容易出问题？检测任务显存占用大，单卡 batch 往往很小，BN 的均值/方差统计量在小 batch 下估计噪声很大，训练/推理的统计量差异被放大「怎么解决？」→ 同步 BN（多卡汇总统计量）、GroupNorm（不依赖 batch）、冻结 BN 统计量做微调以为 BN 的问题只在小模型上出现——本质是 batch size，和模型大小无关必答·高频
为什么 Transformer 用 LN 不用 BN？LN 在样本内部（跨特征维度）归一化，不依赖 batch 内其他样本，天然适配变长序列和推理时 batch=1 的场景「LN 放在 attention 前还是后？」→ Pre-LN 训练更稳定（梯度直接跨层传播），Post-LN 原始设计但更难训练把 LN/BN 归一化的维度记反（LN 是样本内，BN 是 batch 内）必答·高频
为什么 attention 要除以 $\sqrt{d_k}$？点积的方差随维度 $d_k$ 线性增长，不缩放会让 softmax 输入的尺度过大，梯度趋于饱和（softmax 梯度接近 0）「怎么验证这个饱和现象？」→ 固定 $d_k$，比较缩放前后 softmax 输出的熵，见 C64-03 的对应实验只说「防止数值过大」——没说清具体是 softmax 饱和导致梯度消失必答·高频
转置卷积的棋盘效应从哪来？当 kernel size 不能被 stride 整除时，输出像素被重叠覆盖的次数不均匀，形成周期性的棋盘状伪影「怎么避免？」→ 让 kernel size 是 stride 的整数倍，或用「插值 + 普通卷积」替代转置卷积以为棋盘效应是任意转置卷积的通病——它只在 kernel/stride 搭配不当时出现加分·中频
深度可分离卷积的收益和代价？把标准卷积拆成逐通道卷积+1×1 卷积，参数量和计算量大幅下降；代价是通道间信息交互能力变弱，同等参数量下表达能力打折「什么场景下这个代价可以接受？」→ 移动端/车端算力受限场景，用宽度换回一部分表达能力以为深度可分离卷积「参数少所以更好」——它是一个明确的效率-能力权衡加分·高频
CNN vs Transformer 的核心取舍是什么？CNN 的局部性 + 平移不变性是强归纳偏置，小数据下更容易训练；Transformer 几乎没有归纳偏置，需要更多数据/更长训练才能学到同等的先验「ViT 在小数据集上为什么打不过 ResNet？」→ 归纳偏置需要靠数据量弥补，小数据下这笔账划不来把归纳偏置的取舍简单等同于「哪个模型更先进」——这是两种不同的建模假设，没有绝对优劣必答·高频

直白说

架构题的「为什么这么设计」几乎都能追到同一个母问题：这个设计省了什么、又付出了什么。1×1 卷积省参数、深度可分离卷积省计算量、LN 省掉对 batch 的依赖——把每个设计翻译成这个句式，你会发现答案自然就带上了「什么时候它反而是错的」。

严谨说

更进一步，几乎所有归一化层（BN/LN/GN/IN）的区别都能归纳成一句话：「在哪个维度上求均值和方差」。BN 在 batch 维、LN 在特征维、GN 在分组的通道维、IN 在单样本单通道的空间维——记住这一句，四种归一化的适用场景就能现场推导出来，不需要死记硬背四张表。

5题库 · 评估、概率与统计（呼应 C64-04）

这一段是整个 C64 里区分度最高的主题（见 C64-04 §1），题库也相应偏「场景 + 反直觉数字」，而不是纯公式默写。

题目一句话答案典型追问踩雷点层级/频率
不平衡数据下 ROC-AUC 为什么会骗人？ROC 的假阳性率分母含海量真阴性，稀释了假阳性的影响；正类稀少时该看 PR-AUC「能举个数字例子吗？」→ 1:99 的数据上 ROC-AUC 可以到 0.97，precision 却只有 0.47只会背「ROC-AUC 对不平衡不敏感」，说不出具体的数学根源（真阴性分母）必答·高频
为什么「高置信不等于高准确」？现代深度网络普遍过度自信，softmax 输出的置信度往往系统性高于真实正确率「怎么量化？」→ ECE，怎么修？→ 温度缩放（不改变预测排序，只压平置信度）以为置信度天然就是概率——它只有经过校准才能当概率用必答·高频
Wilson 区间相比正态 CI 的优势？小样本或极端比例（$\hat p$ 接近 0/1）时，正态近似会给出越界（超出 [0,1]）的区间，Wilson 区间天然落在 [0,1] 内且覆盖率更接近名义值「什么时候正态近似就够用？」→ 样本量大、比例适中时两者几乎重合不管样本量大小都无脑用正态公式加分·中频
「+0.3 mAP 算不算提升」怎么答？先看多种子的方差范围（检测任务典型 ±0.2–0.5），再看用配对还是非配对检验，最后才下结论「只跑了一个种子怎么办？」→ 诚实说明「暂时无法判断是信号还是噪声」看到数字变好就直接下结论「有提升」，没有方差参照系必答·高频
辛普森悖论的本质机制？分组内的趋势一致，合并后反转——因为各组的样本权重在方案间分布不同，合并比例被权重而非「真实优劣」主导「怎么在自己的数据里发现它？」→ 任何整体指标都按关键维度切片复核一遍只会讲故事（辛普森堡录取率案例），说不出「权重主导」这个数学机制加分·中频
基率谬误的经典例子？患病率 0.1%、检测灵敏度/特异度都 99% 时，一次阳性结果里真阳性的概率大约只有 9%「为什么会这么低？」→ 贝叶斯公式的分母被数量庞大的健康人群的假阳性主导只记得「结论反直觉」，算不出贝叶斯公式的分母展开必答·高频
A/B 测试里 peeking（提前偷看）为什么破坏显著性？反复在多个时间点检验同一个假设，等价于隐式做了多重比较，实际第一类错误率远高于设定的 $\alpha$「怎么避免？」→ 预先固定样本量/时长，或用序贯检验等专门设计的方法以为「多看几眼没关系，反正最后看的是同一个结果」——每一次查看都是一次独立的检验机会加分·中频
期望的线性性为什么不需要独立性假设？$E[X+Y]=E[X]+E[Y]$ 对任意随机变量都成立，是积分/求和运算本身的线性性质，与 $X,Y$ 是否独立无关「那方差呢？」→ $\text{Var}(X+Y)$ 在独立时才等于两个方差之和，否则要加协方差项下意识给期望线性性加上「因为独立」这个不必要的条件边界·低频

这一段的题几乎都可以用「先讲机制，再给一个具体数字」的两步答完——光讲机制显得空、光给数字显得像背答案，两者结合才是「真的算过」的证据。

7面试当天 90 分钟复习清单

面试当天的复习不应该是「从头到尾再读一遍」——那样大概率读不完，还会因为「来不及」而焦虑。正确的用法是把 90 分钟按弱项权重分配，而「弱项权重」应该来自你过去几天用闪卡引擎积累的真实数据，而不是主观感觉。

时间块默认分配（无历史数据时）做什么产出
0–10 分钟10 min读一遍本模块 §2–§5 的代表性题表，找回「三段式答法」的语感热身，不追求答对，追求「话说得利落」

\[t_i \;=\; \Big\lfloor \text{floor} + (T - n\cdot\text{floor}) \cdot \frac{w_i}{\sum_j w_j} \Big\rceil, \qquad w_i = \frac{1}{\overline{EF}_i}\]

直白说

这张默认表格适合还没用过闪卡引擎的第一次复习。但如果你已经用 notebook 练了几天，第二个时间块（10–55 分钟）不应该再是「平均分给每个主题」，而应该按每个主题当前的平均易记因子（EF）反比分配——EF 越低，说明你在这个主题上失误越多，应该分到的时间越多。

严谨说

分配公式是「比例分配 + 最低时长下限」的组合（与 C62-00 的时间预算器同构）：每个主题先保证一个最低时长 floor（防止某个主题分到 0 分钟），剩余时间按权重 $w_i = 1/\overline{EF}_i$ 比例分配，最后一个主题吸收取整误差，保证总和严格等于 90 分钟。notebook 里的 schedule_90min就是这个公式的完整实现，输入就是弱项报告的输出。

不要把 90 分钟花在你已经很熟的主题上求心理安慰。「再读一遍架构那节，感觉很有把握」是复习时间最常见的低效用法——有把握恰恰说明这不该是这 90 分钟的重点，弱项报告存在的意义就是替你做这个判断，而不是凭感觉。

8知识边界练习：诚实地说「我不知道」

「边界层」题目（见 §1 分层表）大概率答不全，这是设计使然——面试官问这类题，从来不是真的期待一个完整答案，而是想看你在知识边界之外会怎么反应。这一节把「诚实」从一个态度问题，变成一个可以练习的三段式结构。

部分作用话术模板（中）话术模板（EN）
① 承认明确划出「这不在我确定知道的范围内」的边界，而不是含糊过去「这一点我没有把握，不想瞎猜误导你。」"I'm not fully sure about this, I don't want to guess and mislead you."
② 给出查证路径证明你知道怎么找到答案，即使现在答不出来「如果是我，我会先看这篇论文的消融实验部分/去实测一下小规模场景。」"If it were up to me, I'd check the ablation section of the paper / run a small-scale test."
③ 给出相邻已知把话题拉回你确实掌握的邻近知识，展示你不是一无所知「但相关的是，我知道在 XX 场景下类似的机制是……」"But related to this, I do know that in XX scenario a similar mechanism is ..."

拿一个具体例子过一遍完整结构：面试官问「双下降现象有没有一个大家公认的完整理论解释？」

满分答法示例：「这个我没有把握说有一个大家公认的完整理论——我知道的是有几个角度在解释它（有效模型容量、隐式正则化），但据我所知业界还没有完全统一的说法。如果是我要深入研究，我会先去看 Belkin 等人 2019 年那篇提出双下降的原始论文，再看有没有后续综述整理了各家解释。但相关的是，我知道传统偏差-方差理论假设的是模型复杂度和泛化误差之间的单调关系，双下降恰恰是在插值阈值附近打破了这个单调假设。」

直白说

对比一下反面例子：「双下降？就是模型变复杂之后误差先升后降，呃……原理应该是和正则化有关系吧。」——这句话犯了三个错误同时发生：没有明确承认不确定（「应该」两个字模糊带过）、没有查证路径、相邻已知也说得含糊（「和正则化有关系」没有说清楚具体机制）。面试官记住的不是「他不知道」，是「他不知道自己不知道」——这比诚实的「我不知道」扣分更多。

严谨说

更系统地说，边界层练习要求你提前列出一份「我不确定的领域」清单，而不是等到被问到才临场发挥。对本课程覆盖的每个主题，问自己「如果面试官往深处再追问两层，我会在哪一层开始编造」——那一层往上，就是你该主动准备诚实话术的地方。notebook 练习 4 会给你一个「诚实答案结构检查器」，帮你在写自己的话术脚本时验证结构是否完整。

最差的反应是「硬答一个听起来很像那么回事的答案」。面试官大概率就是这个领域的行家，编造的答案一旦被追问细节就会当场露馅，而且这种「不懂装懂」的信号会让面试官回头怀疑你之前所有答对的题——这是边界层题目杀伤力最大的地方：它不仅测边界层本身，还会反向污染必答层和加分层的可信度。

9研究前沿与开放问题

整门课的最后一组问题，关于「快问快答」这个考察形式本身正在往哪里演化，以及间隔重复这套学习方法的边界在哪。

  • 技术知识问答正在被 LLM 重新定义。当候选人可以在面试后立刻用大模型验证任何一个知识点的对错时，「知道一个事实」的价值持续下降，「知道这个事实在什么条件下失效」以及「知道自己不知道什么」的价值在持续上升——这正是本课程把「什么时候失效」和「知识边界练习」作为核心设计的原因，但这个判断本身是否会被下一代面试形式验证，还有待观察。
  • SM-2 算法已经 30 多年，但它对「相关知识点之间的联系」建模很弱。真实的知识不是 150 张互相独立的卡片，而是一张网——理解「Adam 为何有效」会同时加深「校准为何会失效」的理解（两者都涉及自适应统计量的不稳定性）。基于知识图谱的自适应调度是间隔重复系统的一个活跃研究方向，但还没有成熟到能替代 SM-2 这类简单模型的地步。
  • 「诚实地说不知道」在多大程度上真的能被面试评分体系奖励，缺乏公开的量化证据。本课程假设「诚实的边界意识」会被优秀的面试官奖励，这是行业内的普遍共识，但不同面试官、不同公司文化下的实际权重差异很大，这也是为什么本课程反复强调「读面试官的信号」（见 C65-04）比死记硬背某个固定策略更重要。
  • 题库本身的时效性问题。ML/DL 领域每年都有新的架构、新的评测范式出现（例如大模型时代对「幻觉」「对齐」的评测方法），一份静态的 150 题题库会随时间贬值——更可持续的做法是把「怎么写出一道好的快问快答题」本身当成一项可迁移的能力，本模块的题目结构（一句话答案 / 典型追问 / 踩雷点）就是为了让你能自己扩充这份题库，而不只是背诵它。

★ 必读：P.A. Wozniak, SuperMemo: The SM-2 Algorithm（1990 年代公开描述，详见 SuperMemo 官方算法文档）——本模块闪卡引擎的调度算法来源。★ Belkin, Hsu, Ma, Mandal, Reconciling Modern Machine Learning Practice and the Bias-Variance Trade-off（PNAS, 2019）——双下降现象的奠基性论文，见本模块 §2 的边界层例题出处。
