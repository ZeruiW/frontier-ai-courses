# ML/DL 技术知识问答

这门课补的是一块**看起来"已经学过"、实际在面试形式下从未被专门练过**的缺口。

HR 给出的一面形式白纸黑字写着：

> First Round Interview Format (including but not limited to):
> **Technical Knowledge Assessment**, Problem-Solving, and Practical (Coding) Exercise
> "it'll include coding, system design, **ML knowledge**, etc."

而在这批补全课诞生之前，全库里最接近的是 **C07 · ML 基础与面试数学**——但 C07 教的是**推导**：
手推 softmax 的梯度、证明贝叶斯公式、解释 k-fold 的方差。这些推导会了，
不等于你能在考官打断你之前、用一句话讲清楚"为什么需要它"。

## 核心主张

> **C07 教你推导，本课教你在 60 秒内讲清楚并接住追问。**

技术知识考察真正的评分维度只有四个，而且区分度并不均匀：

1. **准确性**——说对了没有（门槛，答错直接扣分，但答对本身不加分）；
2. **深度**——能不能在被追问时再往下展开一层，而不是重复第一句话；
3. **边界意识**——你知不知道这个知识点**什么时候不成立**（区分度最高的一维，绝大多数候选人在这里露怯）；
4. **诚实度**——遇到真不会的东西，敢不敢说"我不确定"而不是硬编一个听起来合理的答案。

这门课把每一个 ML/DL 知识点都改写成**三段式**：一句话定义 → 为什么需要它 → 什么时候它失效，
外加"面试官的典型追问"和"踩雷点"，让每个知识点都能同时支撑 60 秒版本和 3 分钟版本的答案。

## 三段式答法速记卡

这是贯穿全课的骨架，00 模块给出模板与自检器，01–04 模块的每一个知识点都严格按这个结构展开。

| 环节 | 一句话 | 建议时长 | 被追问时怎么接 |
|---|---|---|---|
| ① 一句话定义 | 用最精确但最短的一句话说清楚"它是什么" | 10–15 秒 | 如果考官点头示意继续，直接进入②，不要重复定义 |
| ② 为什么需要它 | 说清楚"不用它会怎样"——用一个具体反例或数字，而不是抽象地说"更好" | 20–30 秒 | 考官追问"具体怎么个更好法"时，给出①②之外提前准备好的一个数字或实验结论 |
| ③ 什么时候它失效 | 主动说出边界条件、反例场景、已知的局限性 | 20–30 秒 | 这一步说得好，考官通常会转向下一题——因为你已经证明了你不是在背书 |

- **60 秒版本**：①②③ 各压缩到一句话，共 3–4 句，适合"快问快答"环节或开场自我介绍里的技术亮点。
- **3 分钟版本**：①一句话不变，②③ 各展开成 2–3 句并给出一个可复现的小实验或具体数字（本课每个 notebook 都准备了这类实验）。
- **接不住追问怎么办**：诚实说法固定句式——"这块我不是完全确定，我的理解是 X，如果不对我会去查 Y（或者用 Z 现场推一下）"。这句话本身已经在展示**边界意识**和**诚实度**这两个高分维度。

## 学习路径（按你还剩多少时间选）

### 路径 A · 还有一周（约 8–12 小时）

完整走一遍 `00 → 01 → 02 → 03 → 04 → 05`，每天一个模块：先读 HTML 讲解（30–40 分钟，
每个知识点都按三段式过一遍并**大声说出来**，不要默读），再跑 notebook 把每个实验/演示亲手跑一遍
（40–60 分钟）。最后两天专门刷 05 的题库，用闪卡引擎随机抽题，隐藏答案自己先答，
再对照"一句话答案/典型追问/踩雷点"打分，重点标记连续答错两次以上的题。

判断走完了没有的标准：**随便给你一个知识点，你能不能在 15 秒内说出①②③三句话而不用查任何笔记。**

### 路径 B · 还有三天（约 5–6 小时）

`00 → 05 的必答题全过一遍 → 01/02/03/04 只看题库里标记为"加分"和"边界"的那部分详解`。

理由：**必答题决定你会不会被直接淘汰，加分题决定你能不能被记住**，
而每个知识点的完整推导细节在时间紧张时的边际收益不如"确保 150 道必答题不失分"。

- **Day 1**：00 全部（三段式答法必须能脱稿复述）+ 05 题库过一遍全部**必答**题。
- **Day 2**：01 + 02（ML 基础与优化训练是被问到频率最高的两块）。
- **Day 3**：03 + 04（架构与评估统计）+ 05 题库里的**加分**题，重点过一遍"边界"题的诚实答法。

### 路径 C · 只剩一晚（约 2.5 小时）

**不要试图学新知识，只做两件事：**

1. **过一遍 05 题库的全部必答题**（90 分钟）——这份清单就是按"答错基本出局"的标准筛出来的，
   投入产出比全课最高。每题只看"一句话答案"，答不上来的立刻标记，不要在这一晚试图理解推导。
2. **重读 00 模块的三段式答法与"我不知道"的正确说法**（30 分钟）——这不增加你会的知识，
   但能保证你在任何一个答不上来的问题上都不会当场语塞，是性价比最高的兜底动作。

剩下时间：把 04 模块的 ROC-AUC vs PR-AUC、校准与温度缩放这两条快速过一遍——
这是"听起来懂评估"最廉价的加分点，也是被问到概率最高的追问方向之一。

**明确不要做的事**：不要在最后一晚试图证明双下降曲线的理论推导，或纠结 Wilson 区间的公式细节。
遇到这类被追问到深处的问题，诚实地说"这块我记得结论是……，完整推导我需要查一下"，
比含糊地编一个公式更安全。
