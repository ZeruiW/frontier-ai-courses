1这门课讲什么

欢迎来到 生成模型。这门课只追求一件事：让你从「会调用生成模型」变成「会从零写出每一族生成模型」。

绝大多数人和生成模型的关系，止于 pipe = StableDiffusionPipeline.from_pretrained(...) 和 pipe('a cat').images[0]。这门课要往下钻到地基：当一个模型能凭空画出一张从未见过、却像真的一样的图时，它内部到底在做什么数学？为什么自编码器能压缩重建却不能采样？为什么 VAE 在重建之外还要硬加一个 KL 项？GAN 明明没有似然，凭什么也能学出分布？扩散模型把图片加噪成雪花再猜回去，这听起来荒唐的过程为何成了画质之王？流匹配又是怎么把它们统一成「学一个搬运噪声的速度场」的？

这些问题的答案不在任何 API 文档里，而在一个共同的母题中——如何从一堆样本里，学出一个你能从中采样出新样本的概率分布 p(x)。五族模型只是对这同一个问题给出的五种不同回答，各有各的代价与妥协。本课就是沿着这条主线，把自编码器、VAE、GAN、扩散、流匹配五族模型，用纯 numpy 从零（自己写前向、自己写反向、自己写采样）一族一族重建、在玩具分布上看着它们收敛。

学完你应当能回答这类问题（也是生成式 AI 岗位的高频考点）：AE 和 VAE 差在哪一项、为什么这一项让它能采样？VAE 的 ELBO 两项各自管什么、重参数化技巧到底解决了什么？GAN 在最优判别器下其实在最小化什么散度？DDPM 为什么训练目标只是「预测噪声」的 MSE、它和 VAE/score 是什么关系？Flow Matching 凭什么不用积分 ODE 就能训练？——并且能在 numpy 里把这五族都从零实现、跑到收敛、与解析参考对拍。

一句方法论上的话先说在前面：本课的价值不在「我们没有 GPU 也能学」这个妥协，而在它逼你只关注真正难的部分——目标函数与采样机制的数学正确性。网络主干（用 MLP 还是 U-Net 还是 Transformer）、数据规模、训练技巧，这些有了正确的目标与采样之后都是工程量，且年年在变；而「这族模型到底在优化什么、怎么从它采样、为什么这样能学出分布」是不随架构过时的硬功夫。把它练扎实，换到任何框架、任何主干都立刻能上手。

2世界观：从判别 p(y|x) 到生成 p(x)

贯穿全课的世界观，是一条从判别到生成的视角转换。你之前见过的大多数模型是判别式的：给一张图，输出它是猫还是狗，即建模 p(y|x)。生成模型要做的事根本不同——它要建模数据本身的分布 p(x)，并且能从中采样出新的 x。这难得多：判别只需画一条决策边界，生成却要把整个高维数据流形的形状都学下来。

维度判别模型 discriminative生成模型 generative
建模对象p(y|x) 条件分布 / 决策边界p(x) 或 p(x,z) 数据分布本身
能做什么分类、回归、打分采样新样本、（部分）算似然、补全、表示
典型代表logistic 回归、ResNet 分类器VAE、GAN、扩散、流
难点找对边界即可学下整个高维分布的形状

直白说

判别模型像一个鉴定师：给它东西，它告诉你这是什么、真不真。生成模型像一个画家：你不给它任何输入，它能凭空画出一张全新的、像模像样的作品。鉴定比创作容易——这就是为什么生成模型整体更难、更晚成熟。

严谨说

形式上：判别模型只需估计 p(y|x)，而生成模型要估计（或隐式地表示）整个 p(x)。后者是一个高维分布，直接写出它的密度往往不可能（隐变量模型的 p(x)=\int p(x,z)dz 积不出来）。如何绕过这个不可解的积分，正是 VAE（用下界）、GAN（干脆不算似然）、扩散（拆成许多小步）、流（用可逆变换）各自的招法。

所以本课的五个模块，本质是五种绕开「直接算 p(x) 不可行」的策略。把这条主线记住，你会发现它们不是五个孤立的专题，而是同一个困境的五种解法——这也是最后两个模块（扩散与流）能被统一起来的根本原因。

3五族模型的统一地图

五族模型的统一地图

目标：从样本学出一个能【采样】的分布 p(x)。难点：p(x)=∫p(x,z)dz 积不出来。 模块 01 自编码器 AE x →编码→ z →解码→ x̂，只学压缩与表示 │ （还不是生成模型：隐空间无结构，采不了样） ▼ 给隐空间加上概率结构 + 先验 模块 02 VAE 编码器输出分布 q(z|x)，最大化 ELBO=重建−KL │ （能采样了！但样本偏模糊） ←显式似然下界 ├──────────────┐ ▼ ▼ 模块 03 GAN 绕开似然：G 造假、D 鉴别，对抗到 p_g=p_data │ （样本锐利，但训练不稳、易模式坍塌） ←隐式、无似然 ▼ 把生成拆成许多步小去噪 模块 04 扩散 DDPM 前向逐步加噪 → 学反向逐步去噪（预测噪声） │ （画质之王，但采样要很多步） ←变分界 / score ▼ 取连续极限：去噪 = 沿一个向量场流动 模块 05 流匹配 回归一个把噪声搬到数据的速度场，ODE 采样 （统一扩散与流，采样可极少步） ←连续流

注意这不是松散的专题集合，而是一条有内在逻辑的演进链：自编码器（01）给出编码-解码的骨架但采不了样；VAE（02）给隐空间加概率结构与先验，第一次能采样，但用下界换来的样本偏模糊；GAN（03）干脆放弃似然、用对抗逼近分布，换来锐利样本却付出训练不稳的代价；扩散（04）把生成拆成许多步小去噪，稳定又高质却慢；流匹配（05）取连续极限，把去噪看成沿速度场流动，统一了扩散与流、并让采样可以极少步。每一族都在修补前一族的某个缺陷，又引入新的取舍。

读到最后你会发现一个惊人的事实：扩散与流匹配在数学上是同一件事的两种写法——预测噪声、估计 score、回归速度场，可以互相换算。这正是本课刻意的编排：把五族看似各异的模型，还原成对同一个采样难题的连续谱系，让你既见树木（每族的细节）又见森林（它们的统一）。这也是通往前沿扩散课（C28）最稳的地基。

4方法论：用 numpy 从零、在玩具分布上对拍

方法论：没有 GPU、没有框架，怎么学写生成模型？

本环境没有 GPU、不装 PyTorch/JAX/diffusers。但生成模型的难点从来不是 nn.Conv2d 的调用语法，而是目标函数与采样机制的数学结构：ELBO 两项怎么来、重参数化为何能让梯度穿过采样、minimax 怎么交替、加噪闭式怎么推、速度场回归的目标是什么。这些结构用 numpy 在 CPU 上、在玩具分布上，完全能精确地表达和验证。

打个比方：学作曲不一定要一支交响乐团。生成模型的「乐理」是分布如何被参数化、损失如何引导它逼近数据、样本如何被采出来；这些都是和算力、框架无关的数学结构。一个真实的 VAE 训练循环里那行 loss = recon + kl; loss.backward()，框架替你算了反向；我们在 numpy 里就自己把这个反向写出来——这恰恰逼你彻底搞懂每一项梯度从哪来。结构一模一样，只差「自动求导」这层便利。

直白说

我们把每族模型缩到最小可玩的尺度：数据是 1D 双峰、2D 两个月牙或 8 个高斯、或 8×8 的小图；网络是几十个参数的小 MLP；反向传播手写几行。你看到的不是 SOTA 画质，而是机制本身——损失怎么降、样本点怎么一步步爬向目标分布。

严谨说

关键纪律是对拍与可复现收敛：能算解析解的地方一律和解析解比对（线性 AE 的子空间对拍 PCA、高斯 KL 对拍闭式公式、DDPM 前向 q(x_t|x_0) 对拍闭式边缘、Flow Matching 速度场对拍解析目标）；不能算解析解的（GAN/采样）则固定随机种子、要求损失或分布距离单调改善到既定阈值，用 assert 兜底。结构正确 → 数值对上；数值对上 → 逻辑可原样搬到 PyTorch。

生成模型概念本课的 numpy 实现对应真实工具
前向 / 反向传播手写矩阵乘 + 链式法则求梯度nn.Module + autograd
从隐变量采样np.random + 重参数化 μ+σεtorch.randn + rsample()
训练循环for epoch: 算 loss、手算梯度、SGD 更新optimizer.step()
数据分布玩具 1D/2D（双峰、月牙、高斯混合）真实图像 / 文本数据集
正确性对拍解析解 / 收敛到阈值 + assert与参考实现对拍、看 FID

为什么把对拍与收敛阈值提到方法论的高度？因为生成模型的 bug 极其阴险：你的 ELBO 可能写错一个符号却照样在降、你的采样循环可能漏了一项噪声却照样出图、你的 GAN 可能因为 loss 写反而悄悄优化了错误的东西。这些 bug 往往不报错，只是悄悄给出看起来在学、其实学歪了的结果。在玩具分布上我们有绝对可信的参照（解析的 PCA 子空间、解析的高斯 KL、肉眼可辨的目标分布形状），任何偏差都会被 assert 当场抓住。本课每个模型都先写出可验证的小块、立刻对拍——这套「先有 ground truth，再扩规模」的纪律，正是真实生成模型研发的核心工作流。

务必清楚本课不教什么：不教卷积/U-Net/Transformer 主干的工程细节、不追求 SOTA 画质、不做大规模训练、不讲 classifier-free guidance 等前沿采样技巧。这些在你掌握了正确的目标与采样之后，是第二步（references 里的 DCGAN/Improved DDPM、以及前沿扩散课 C28 接手）。本课负责把第一步——五族模型的目标函数与采样机制夯死；这一步搞定，第二步才有意义。

环境与运行

环境极简：只需 numpy（画分布散点图可选 matplotlib）。全课 CPU 秒级到分钟级运行，无需 GPU、CUDA、PyTorch、JAX、diffusers。

conda create -n genmodels python=3.11 -y && conda activate genmodels
pip install numpy            # 必需
pip install matplotlib       # 可选，仅用于画 1D/2D 分布散点
jupyter lab

每个模块配一个 notebook，结构统一：先用 numpy 把这族模型从零实现并验证（5–6 个 worked 小节，每节都跑出可打印的结果与 assert 自测），再做 3–4 道带 assert 判分的 ✏️ 练习（先给骨架，自己填，再对照 📖 参考答案），最后一个真实数据/真实配置胶囊（用真实模型的超参或真实数据集的统计，把玩具知识接到现实）。

建议的学习节奏：先读完整章 HTML 建立动机、目标函数与采样机制的框架，再打开 notebook 亲手实现。读和做缺一不可——只读会觉得「公式好像懂了」，真正动手写 ELBO 的反向、调采样循环、让 loss 收敛到阈值时，才会发现魔鬼藏在哪些细节里（KL 的符号、重参数的方差、加噪的 sqrt、速度场的方向）。这门课的深度正是为「动手」服务的。

配套先读：Goodfellow《Deep Learning》第 14、20 章建立 AE 与生成模型全景；Kingma & Welling 2013（VAE）、Goodfellow 2014（GAN）、Ho 2020（DDPM）、Lipman 2023（Flow Matching）是四块基石。完整清单见 references.md。前沿扩散在 C28，本课不展开。

✅ 学完整门课，你应该能：
  1. 说清生成与判别的区别，并解释为什么直接算 p(x) 通常不可行；
  2. 从零写出含反向传播的自编码器，并证明/验证线性 AE 学到 PCA 子空间、实现去噪 AE；
  3. 完整推导 VAE 的 ELBO（重建 + KL），手写重参数化与高斯 KL 闭式，从零训练并采样，诊断后验坍塌；
  4. 写出 GAN 的 D/G 损失与交替更新，在 1D/2D 上收敛到目标分布，复现并缓解模式坍塌；
  5. 推导并实现 DDPM 的前向闭式 q(x_t|x_0)、噪声预测损失与反向采样，讲清它与 VAE/score 的关系；
  6. 实现 Flow Matching 的速度场回归与 Euler ODE 采样，说清它如何统一扩散与流；
  7. 把以上 numpy 实现映射到 PyTorch/真实主干，知道通往前沿扩散（C28）的下一步怎么走。
