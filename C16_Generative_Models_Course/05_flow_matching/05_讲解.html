1流匹配的思想：学一个搬运分布的速度场

我们已经走过四族模型，到了最后一站，也是最现代的一站——流匹配（Flow Matching，Lipman 等 2023）。它把扩散推到一个优雅的连续极限：与其像 DDPM 那样定义几百个离散的加噪/去噪步，不如直接学一个把噪声分布连续「搬运」到数据分布的速度场，生成时沿这个速度场积分一条 ODE 即可。这个视角不仅更简洁，还让采样可以用极少的步数（甚至一步），是当前文生图（如 Stable Diffusion 3、Flux）的主流框架。

先建立核心图像。想象数据空间里有一群粒子，初始时它们服从简单的噪声分布 p_0=\mathcal{N}(0,I)；我们希望在时间 t 从 0 走到 1 的过程中，让这群粒子流动到服从数据分布 p_1=p_{data}。支配每个粒子运动的，是一个速度场（velocity field） v(x,t)——它告诉位于 x、时刻 t 的粒子下一刻该往哪个方向、以多快速度移动。粒子的轨迹由常微分方程 dx/dt=v(x,t) 决定。学会了这个速度场，就学会了生成：从噪声采一个 x_0，沿 v 积分到 t=1，就得到一个数据样本。

直白说

打个比方：你想把一堆撒在地上的沙子（噪声分布）整理成一座沙雕（数据分布）。速度场就是一张处处标注「这里的沙子该往哪推」的地图。生成时，每粒沙子只要照着地图上自己脚下的箭头一小步一小步地挪，最终整堆沙子就自动汇成了沙雕的形状。流匹配要学的，就是这张箭头地图。

严谨说

形式上：流匹配学一个时变速度场 v_\theta(x,t)，使得由 ODE dx/dt=v_\theta(x,t) 定义的流（flow），把先验 p_0 推送（push-forward）成数据分布 p_1。这属于连续归一化流（CNF）的范畴——但流匹配的革命性在于，它能不积分 ODE就训练出这个速度场（下一节的「无模拟训练」），从而既有连续流的优雅，又有扩散的训练效率。

一句话抓住流匹配与扩散的关系：扩散是「离散的、加噪声的」搬运，流匹配是「连续的、可确定的」搬运——但它们学的是同一种东西：把噪声移到数据的方向场。还记得模块 04 那条金线（去噪 AE → 预测噪声 → score → 速度场）吗？这一模块就是它的终点。事实上，扩散的「概率流 ODE」与流匹配的速度场可以互相换算——它们是同一枚硬币的两面。带着「这是扩散的连续/统一版」的视角读本章。

2连续归一化流与它的困难

连续归一化流与它曾经的困难

流匹配属于连续归一化流（continuous normalizing flow, CNF）这一脉。要理解它的突破，先得知道 CNF 曾经卡在哪里。

传统的归一化流（normalizing flow，Rezende & Mohamed 2015）用一串可逆变换把简单分布（高斯）映成复杂数据分布，靠变量替换公式 \log p_x(x)=\log p_z(z)-\log|\det\partial f/\partial z| 精确算出似然。代价是网络必须可逆、且雅可比行列式要易算——这严重限制了结构（只能用耦合层等特殊设计，如 RealNVP、Glow）。

这里值得停一秒，体会那个雅可比行列式约束有多碍事。变量替换公式里的 \log|\det\partial f/\partial z| 一项，要求我们能算出变换的雅可比行列式——而一般神经网络的雅可比是个稠密大矩阵，算行列式要 O(D^3)、对高维数据（一张图几千上万维）根本承受不起。归一化流的全部架构智慧（耦合层、自回归流）本质都是在削足适履：刻意设计成让雅可比变成三角矩阵（行列式 = 对角线连乘，O(D) 可算）。代价是每一层的表达力都被这个「必须可逆且雅可比好算」的枷锁绑住，远不如一个自由的 MLP 灵活。「精确算似然」这个看似诱人的卖点，反而成了束缚结构的镣铐——这是理解后来扩散/流匹配为何宁可放弃精确似然也要换取架构自由的关键背景。

连续归一化流（Chen 等 2018，Neural ODE）把离散的可逆层取极限，用一个 ODE dx/dt=v_\theta(x,t) 定义连续形变。它优雅得多（任意网络都能当 v_\theta，不需要精心设计可逆结构），但训练曾经极其昂贵：要算似然就得解一个 ODE（还要解伴随 ODE 求梯度），每次前向/反向都要数值积分整条轨迹，慢且不稳。这让 CNF 多年来停留在小规模。

这就是流匹配登场的舞台：CNF 的形式很美（一个 ODE 就定义了生成），但「要积分 ODE 才能训练」这件事让它一直跑不快。流匹配的核心贡献，就是找到一种根本不用积分 ODE 就能训练速度场的办法（下一节）。它把 CNF 从「优雅但昂贵」变成「优雅且高效」，这正是它能在 2023 年后迅速成为主流的原因。下一节是全模块的技术核心，请重点读。

3核心：回归速度场，不积分 ODE

流匹配的核心：回归速度场，不积分 ODE

流匹配最关键的洞察是：我们不必先有一个完整的生成过程再去优化它，而可以先「钦定」一条好走的路径，再训练速度场去匹配这条路径的速度。这把训练从「解 ODE」变成了「做回归」。

具体地，先选一条概率路径（probability path） \{p_t\}_{t\in[0,1]}，从先验 p_0 连续过渡到数据 p_1。最简单、也最常用的是直线路径（rectified flow，Liu 等 2023）：对一对 (x_0,x_1)（噪声、数据），让它们之间走直线：

\[x_t=(1-t)\,x_0+t\,x_1,\qquad x_0\sim\mathcal{N}(0,I),\ x_1\sim p_{data},\ t\sim\mathcal{U}[0,1]\]

沿这条直线，粒子的速度是恒定的、且有解析解：对 t 求导，dx_t/dt=x_1-x_0。这就是目标速度！于是训练目标无比朴素——让网络 v_\theta(x_t,t) 回归这个目标速度：

\[\mathcal{L}_{\text{FM}}=\mathbb{E}_{t,\,x_0,\,x_1}\Big[\big\|\,v_\theta\big((1-t)x_0+t x_1,\ t\big)-(x_1-x_0)\,\big\|^2\Big]\]

读懂它：随机抽一个噪声 x_0、一个数据 x_1、一个时刻 t；算出直线上的中间点 x_t 和该点的目标速度 x_1-x_0；让网络看着 (x_t,t)预测这个速度；用 MSE 惩罚。没有 ODE 积分、没有对抗、没有 KL——又一个干净的回归任务，和 DDPM 的「预测噪声」如出一辙。这就是无模拟训练（simulation-free training）。

直白说

为什么对每一对 (x_0,x_1) 走直线、回归 x_1-x_0，就能学到正确的、把整个噪声分布搬到整个数据分布的速度场？关键的数学保证是：虽然每条直线的方向 x_1-x_0 各不相同，但网络对所有经过同一点 x_t 的直线速度求了平均（MSE 回归的最优解就是条件期望），这个平均恰好等于那个能实现整条概率路径的、真正的边缘速度场。

严谨说

形式上：这就是条件流匹配（conditional flow matching, CFM）定理（Lipman 2023）。难算的边缘速度场 v(x,t)=\mathbb{E}[\dot x_t|x_t=x] 无法直接回归，但论文证明：回归条件速度场（每对 (x_0,x_1) 的 x_1-x_0）与回归边缘速度场有相同的梯度。于是我们可以用前者（极易采样）替代后者（难算），训练目标完全等价。这是流匹配能成立的理论基石。

这个「对穿过同一点的多条直线求平均」的机制，是流匹配最反直觉也最精妙的地方，值得用一个微例把它具象化。设想空间里有一个固定的中间点 x，恰好有两对噪声-数据点的直线都在某个时刻经过它：第一对的目标速度是 x_1-x_0=(+2,0)（指向右），第二对是 (0,+2)（指向上）。网络在 x 处只能输出一个速度向量，而 MSE 回归会逼它输出这两个目标的平均 (+1,+1)（指向右上）。这个平均后的方向，正是「同时考虑了所有该往哪去的可能、加权折中」的边缘速度场——它才是真正能把整团噪声搬成整个数据分布的那个场。单条直线只知道一对点该怎么连，求平均后才浮现出搬运整个分布的全局方向。这就是为什么「对每对点回归一条简单直线」这件局部、廉价的事，累积起来能学到全局、昂贵的边缘速度场——也是条件流匹配定理在直觉层面的全部内容。

这个「回归条件速度 = 学到边缘速度场」的等价，是流匹配的灵魂，地位等同于 DDPM 的「预测噪声 = 估计 score」。两者精神一致：把一个难以直接优化的生成目标，化简成一个对随机采样的小批量做回归的简单目标。notebook 会在 2D 上把目标速度 x_1-x_0 与网络预测对拍，验证这个回归确实学到了能搬运分布的速度场。详见 references.md 的 Lipman 2023、Liu 2023。

4从零实现速度场回归

从零实现：速度场回归

把流匹配落到 numpy，零件少得惊人：一个速度场网络 v_\theta(x,t)、一条直线路径、一个 MSE 损失。训练循环：

# 每步：抽 (噪声 x0, 数据 x1, 时刻 t)
x0 = randn(B, 2)              # 先验噪声
x1 = sample_data(B)          # 数据（如 2D 月牙/八高斯）
t  = rand(B, 1)              # [0,1] 时刻
xt = (1 - t) * x0 + t * x1   # 直线上的点
v_target = x1 - x0           # 目标速度（解析！恒定）
loss = mean‖ v_theta(xt, t) - v_target ‖²

和 DDPM 一样，速度场网络要把时刻 t 作为输入（不同时刻的速度场不同），玩具实现里把 t 拼接到 x_t 上即可。网络结构就是个小 MLP，输出维度与数据维度相同（2D 数据输出 2D 速度向量）。整个训练只有一个网络、一个 MSE 损失，比 VAE/GAN 简单，和 DDPM 一样朴素——这正是流匹配（和扩散）相比早期 CNF 的巨大优势：把「解 ODE 训练」降级成了「做回归」。

一个值得强调的对照：DDPM 的网络预测噪声 \epsilon，流匹配的网络预测速度 x_1-x_0。两者都是「在带噪/插值的中间点上，回归一个指向正确方向的向量」。事实上，对于高斯先验 + 合适的路径，二者可以互相换算——这就是为什么说流匹配统一了扩散。notebook 会从零实现速度场网络的前向、手写反向、训练，并验证损失稳定下降、预测速度逼近解析目标。

还有一个值得玩味的设计自由度：噪声 x_0 和数据 x_1 怎么配对。最简单的是随机配对（每个 minibatch 里随机凑一对），这就是本课用的做法，已经能学得很好。但如果用最优传输（OT）来配对——让相距近的噪声-数据点优先配在一起——路径就更不容易交叉、速度场更光滑、采样需要的步数更少（OT-CFM，第 8 节前沿）。这揭示了流匹配框架的灵活性：路径形状（直线/曲线）、端点配对（随机/OT）都是可设计的旋钮，而扩散在这方面是被噪声调度锁死的。本课先用最简单的「直线 + 随机配对」把机制看清。

两个易错点：① 目标速度是 x_1-x_0（数据减噪声，指向数据方向），方向别写反——写成 x_0-x_1 会让采样朝噪声跑、彻底失败；② 中间点是 (1-t)x_0+t x_1，注意 t=0 在噪声端、t=1 在数据端（与扩散的时间方向相反，扩散 t=0 是数据），别把端点搞混。notebook 用解析目标对拍守住这些。

5ODE 采样：沿速度场积分

ODE 采样：沿速度场积分

训练好速度场 v_\theta 后，生成就是解 ODE dx/dt=v_\theta(x,t)：从噪声 x_0\sim\mathcal{N}(0,I) 出发，沿速度场积分到 t=1，得到数据样本。最简单的数值积分器是欧拉法（Euler）：

\[x_{t+\Delta t}=x_t+\Delta t\cdot v_\theta(x_t,t),\qquad t=0,\Delta t,2\Delta t,\dots,1\]

即「站在当前位置，朝当前速度方向走一小步 \Delta t，到新位置再问一次速度，再走一步」，重复 N=1/\Delta t 步到达 t=1。这和 DDPM 的反向采样形似（都是迭代地往「更像数据」的方向挪），但有个关键区别：流匹配的 ODE 采样是确定性的（给定 x_0 输出唯一，不加随机噪声），而 DDPM 反向每步要加噪声。确定性带来一个大好处——步数可以很少。

拿一个一维微例把欧拉采样走一遍，机制立刻透明。设我们用 N=2 步（\Delta t=0.5），从噪声采到 x_0=-1.0。第一步：在 t=0 处问网络速度，假设 v_\theta(-1.0,\,0)=+1.6，则 x_{0.5}=-1.0+0.5\times 1.6=-0.2。第二步：在 t=0.5 处再问速度，假设 v_\theta(-0.2,\,0.5)=+1.2，则 x_{1.0}=-0.2+0.5\times 1.2=+0.4。于是这个起点为 -1.0 的噪声粒子，两步就被速度场流到了数据样本 +0.4。注意每一步都重新在新位置查询速度（不是一路用初始速度直冲）——这正是欧拉法逼近曲线轨迹的方式，也是为什么路径越直、用越少步就越准：直线路径上速度处处相同，理论上一步（x_1=x_0+v）就能精确到达，这就是 rectified flow 拼命「拉直」路径的全部动机。把这个两步小算例和 DDPM 那个动辄几百步的反向链一对照，「流匹配采样为何能快」就不再是一句口号。

步数 N 是速度-质量的旋钮：步数越多积分越精确、样本越好，但越慢。流匹配（尤其直线路径的 rectified flow）的一大卖点是用很少的步数就能出好样本——因为直线路径「最直」，欧拉法这种一阶方法的积分误差最小。极端情形下，rectified flow 经过「拉直」（reflow）甚至能做到一步采样。这与 DDPM 动辄几百步形成鲜明对比，是流匹配在工业界（实时文生图）受青睐的核心原因。

直白说

用更高阶的积分器（如 Heun，二阶）能在同样步数下更准，进一步减少所需步数。这是个纯数值方法的权衡：阶数越高每步越准但每步更贵。但即便最简单的欧拉法，配上直线路径，流匹配也已经能用远少于扩散的步数生成高质量样本。

严谨说

形式上：ODE 采样在求解初值问题 x(0)=x_0\sim p_0,\ dx/dt=v_\theta，终点 x(1) 的分布就是学到的生成分布。积分误差（欧拉法是 O(\Delta t) 每步）决定了它离真实 p_1 多近。路径越直、v_\theta 越光滑，误差越小、所需步数越少——这是 rectified flow 刻意「拉直路径」的动机。

notebook 会在 2D 分布（如 8 个高斯组成的环、或两个月牙）上跑通完整的「速度场回归 → 欧拉 ODE 采样」，并用分布距离验证生成样本收敛到目标。你会亲眼看到一团高斯噪声，如何沿学到的速度场流动、逐渐分裂汇聚成目标的多个簇——而且只用十几步就相当不错。对比模块 04 的几十步 DDPM，你会直观感受到流匹配「采样高效」的威力。

6流匹配与扩散的统一

流匹配与扩散的统一

学到这里，可以把流匹配和扩散并排，看清它们其实是同一件事的两种表述——这是本模块（也是全课）的高潮。

本质学 score / 去噪方向学搬运分布的速度场

它们的深层联系是：扩散的「概率流 ODE」（Song 2021）就是一个特定的流匹配速度场。任何扩散过程都对应一个确定性的 ODE，沿它积分能得到与扩散随机采样相同的边缘分布；而这个 ODE 的速度场，恰好可以由流匹配的框架学出来（用对应的概率路径）。反过来，流匹配可以选择各种概率路径，扩散对应的只是其中一类特殊路径。所以流匹配是更一般的框架，扩散是它的一个特例——这正是「流匹配统一扩散」的确切含义。

这个等价不是一句空泛的口号，它具体到「预测的两个量可以互相换算」。回想 DDPM 的网络吐出噪声 \epsilon_\theta，而流匹配的网络吐出速度 v_\theta。对于直线路径 x_t=(1-t)x_0+t x_1（且 x_0 是高斯噪声），目标速度恒为 x_1-x_0；而扩散里 x_0 扮演的正是噪声 \epsilon 的角色。于是「速度 = 数据 − 噪声」与「噪声 = 加在样本上的扰动」之间只差一个由当前时刻 t 和路径形状决定的已知线性变换——给定其一，可以代数地解出另一。换句话说，一个训练好的扩散模型，不需重训就能被改写成一个流匹配速度场，反之亦然；它们对同一份知识用了不同的「坐标」来记。理解这一点，你就真正看穿了「统一」二字：不是两套理论碰巧结论相似，而是同一个对象的两种参数化。这也解释了为什么近年很多文生图模型在扩散与流匹配两种实现间切换时，往往只需改训练目标的形式、网络主体几乎照搬。

把全课五族模型在脑海里连成一条线，你会看到一个优美的演进：AE（编码-解码骨架）→ VAE（加概率，能采样）→ GAN（放弃似然，对抗求锐利）→ 扩散（拆成多步去噪，既稳又锐）→ 流匹配（取连续极限，统一并高效化）。而那条贯穿始终的金线——去噪 AE 学 score → 预测噪声 → 速度场——在流匹配这里汇成终点：所有这些模型，本质都在学「如何把简单分布搬运成数据分布」，只是搬运的方式（一步/多步/确定/随机）和学习的目标（重建/对抗/噪声/速度）各异。理解了这条线，你就握住了生成模型的统一图景。

7为什么流匹配成了新主流

为什么流匹配成了新主流

流匹配（及其直线特例 rectified flow）在 2023 年后迅速成为文生图等领域的主流框架，背后有几个扎实的理由，值得收束一下。

  • 训练稳定 + 高效：和扩散一样是简单的回归目标（无对抗、无 ODE 积分），继承了扩散「稳如监督学习」的优点，又比早期 CNF 高效得多。
  • 采样步数少：确定性 ODE + 直线路径让欧拉法的积分误差小，用远少于扩散的步数（十几步甚至几步）就能出好样本，对实时应用至关重要。
  • 框架统一、灵活：流匹配能选各种概率路径（扩散只是其一），可以针对任务设计「最好走」的路径（如最优传输路径），理论上更一般、实践上更可调。
  • 可拉直、可蒸馏：rectified flow 可以反复「拉直」路径（reflow）逼近一步生成；这条线直通「一步/几步生成」的前沿，是当前最快文生图模型的基础。

这也呼应了模块 03 末尾那条「生成模型在融合、而非简单替代」的判断。回看五族模型的整体演进，你会发现它不是「新的全面碾压旧的」，而是每一族都在解决前一族的某个痛点，同时把前一族的好东西继承下来：VAE 继承 AE 的编码-解码、补上「能采样」；GAN 放弃似然换锐利；扩散用多步去噪同时拿到稳和锐；流匹配把扩散连续化、统一化、高效化。它们更像一个逐步精炼的家族谱系，而非一连串推倒重来。理解这一点，比记住「谁是当前 SOTA」更重要——因为 SOTA 会变，而这条演进的逻辑不会。

但也要把话说回来、保持清醒：流匹配不是万能。它和扩散在很多方面（训练目标、采样质量上限）是相通甚至等价的，所谓优势主要体现在采样效率和框架灵活性上，而非生成质量有本质飞跃。在很多场景，一个调好的扩散模型和一个流匹配模型质量相当——选哪个常常取决于工程考量（步数预算、是否需要确定性采样、是否要蒸馏）。把流匹配理解成「扩散的一个更灵活、更高效的现代化重写」，比把它当成颠覆性的新范式更准确。

一个实用的判断：需要极致质量、步数无所谓 → 扩散/流匹配都行，调好即可；需要快（实时、少步、甚至一步） → 流匹配/rectified flow 是当前首选；需要可控、可蒸馏 → 流匹配的灵活路径更有发挥空间。这些前沿（一步生成、最优传输路径、蒸馏）的深入展开在 C28，本课把地基——「速度场回归 + ODE 采样」——夯实，到 C28 就能轻松接住。

8研究前沿与开放问题

研究前沿与开放问题

  • 最优传输与更直的路径：直线路径已很好，但用最优传输（OT）配对 (x_0,x_1) 能让路径更不交叉、更易积分、采样更少步。OT-CFM、minibatch OT 是活跃方向。
  • 一步生成与蒸馏：rectified flow 的 reflow、一致性模型（consistency models）等把多步流/扩散蒸馏成一步或几步生成，是当前「最快生成」的前沿。
  • 与扩散的统一理论：随机插值（stochastic interpolants，Albergo & Vanden-Eijnden 2023）等框架把扩散、流、桥（Schrödinger bridge）都纳入「在两分布间插值」的统一视角，是理论主线。
  • 离散与流形上的流匹配：把流匹配推广到离散数据（文本、图）、黎曼流形（如分子构象、地球数据）上，需要重新定义路径与速度，是正在开拓的方向。
