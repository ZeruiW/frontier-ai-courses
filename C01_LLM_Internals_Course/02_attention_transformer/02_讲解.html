1注意力解决什么问题：变长序列的内容寻址

模块 01 把文本变成了一串 token id，embedding 层再把它们变成向量序列 $x_1,\dots,x_T\in\mathbb{R}^{d}$。 现在的问题是：如何让第 $t$ 个位置的表征用上前面所有位置的信息，且 $T$ 是变化的？ 这是序列建模的核心难题，attention 之前的主流答案是 RNN/LSTM。

直白讲

RNN 把整个历史压进一个固定大小的隐状态，像传话游戏一样一格一格往后传 —— 传得越远丢得越多，而且必须逐步串行算。 Attention 换了一种思路：每个位置直接对所有历史位置发起一次"按内容查询"—— "谁的内容和我现在需要的相关？"——相关者多贡献、无关者少贡献，一步矩阵乘法到位，不经过中间转述。

严谨讲

Attention 实现的是内容寻址（content-based addressing）：输出是值向量的凸组合 $o_t=\sum_{s} \alpha_{ts} v_s$，权重 $\alpha_{ts}$ 由查询 $q_t$ 与键 $k_s$ 的相似度经 softmax 归一化得到， 天然适配任意长度 $T$。任意两位置间的交互路径长度为 $O(1)$（RNN 为 $O(T)$），且对 $T$ 维全并行 [Vaswani 2017]。

维度RNN / LSTMSelf-Attention
历史信息的载体固定维度隐状态（有损压缩）全部位置的 K/V 向量（无压缩，按需取用）
长程依赖路径$O(T)$ 步，梯度逐步衰减$O(1)$ 步，任意两位置直连
训练并行性时间维串行（$h_t$ 依赖 $h_{t-1}$）时间维全并行（一次矩阵乘）
每层计算复杂度$O(T\,d^2)$$O(T^2 d)$ —— 二次方代价，模块 06 的主题
寻址方式按位置顺序隐式传递按内容显式查询
把这张表读成一笔交易：attention 用 $O(T^2)$ 的计算与显存，买来了无损历史 + 常数路径 + 全并行。 在 GPU 时代这笔交易极其划算 —— 可并行意味着可 scaling，这是 Transformer 取代 RNN 的根本原因。 而 $T^2$ 的账单要到长上下文推理时才真正到期（KV cache，模块 06）。

2Scaled Dot-Product Attention 完整推导

2.1 QKV 投影：一份输入，三种角色

输入序列堆叠为矩阵 $X\in\mathbb{R}^{T\times d}$。用三个可学习矩阵把每个位置投影成三种角色：

$$ Q = XW_Q,\quad K = XW_K,\quad V = XW_V,\qquad W_Q,W_K\in\mathbb{R}^{d\times d_k},\; W_V\in\mathbb{R}^{d\times d_v} $$
  • Query $q_t$：位置 $t$ "想找什么"（查询向量）；
  • Key $k_s$：位置 $s$ "能提供什么"（被检索的索引）；
  • Value $v_s$：位置 $s$ "实际交付什么"（被聚合的内容）。

相关性用点积度量：$\text{score}_{ts} = q_t^\top k_s$。为什么 K 和 V 要分开？因为"匹配用的特征"和"传递的内容"未必相同 —— 解耦索引与内容，是 attention 比简单加权平均更有表达力的关键。

2.2 为什么除以 $\sqrt{d_k}$：点积方差推导

这是面试与论文中最常被追问的细节，值得完整推一遍。设 $q,k\in\mathbb{R}^{d_k}$ 的各分量独立同分布， 零均值、单位方差（初始化时近似成立）。点积 $q^\top k=\sum_{i=1}^{d_k} q_i k_i$ 的均值与方差：

$$ \mathbb{E}[q^\top k] = \sum_{i=1}^{d_k}\mathbb{E}[q_i]\,\mathbb{E}[k_i] = 0 $$ $$ \mathrm{Var}(q^\top k) = \sum_{i=1}^{d_k} \mathrm{Var}(q_i k_i) = \sum_{i=1}^{d_k} \mathbb{E}[q_i^2]\,\mathbb{E}[k_i^2] = d_k $$

即点积的标准差随 $\sqrt{d_k}$ 增长。$d_k=64$ 时分数典型幅度已达 $\pm 8$ 以上，直接喂给 softmax 会怎样？ softmax 在大幅度输入下趋于 one-hot：最大分量权重 $\to 1$，其余 $\to 0$。注意 softmax 的雅可比 $\frac{\partial \alpha_i}{\partial z_j} = \alpha_i(\delta_{ij}-\alpha_j)$， 当 $\alpha$ 接近 one-hot 时该雅可比几乎处处为零 —— 梯度消失，训练初期就学不动。 除以 $\sqrt{d_k}$ 把分数方差拉回 $1$，使 softmax 工作在梯度健康的区间 [Vaswani 2017]。

2.3 softmax 归一化与加权求和

$$ \mathrm{Attention}(Q,K,V) = \mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V $$ $$ \alpha_{ts} = \frac{\exp\!\big(q_t^\top k_s/\sqrt{d_k}\big)}{\sum_{s'}\exp\!\big(q_t^\top k_{s'}/\sqrt{d_k}\big)}, \qquad o_t = \sum_{s} \alpha_{ts}\, v_s $$

softmax 沿 key 维（每行）归一化：每个 query 的注意力权重 $\alpha_{t,\cdot}$ 构成一个概率分布， 输出 $o_t$ 是所有 value 的凸组合。整个算子里唯一的非线性就是这个 softmax，其余全是线性代数。

实现时三个高频错误：① softmax 的维度写错（应当是 scores 的最后一维，即 key 维）； ② 忘记 $\sqrt{d_k}$ 缩放，小模型上看似能训、规模一大就发散； ③ 缩放用的是每个头的维度 $d_k=d/h$，不是模型维度 $d$。notebook 里我们会与 F.scaled_dot_product_attention 逐数值对拍，任何一处写错都过不了 assert。

3Causal Mask：decoder-only 的自回归约束

GPT 类模型的训练目标是自回归语言建模：$p(x)=\prod_t p(x_t\mid x_{<t})$。 预测第 $t$ 个 token 时绝不能看到 $t$ 之后的内容，否则模型学会"抄答案"，训练 loss 漂亮、生成时完全失效。 但 attention 的矩阵乘 $QK^\top$ 默认让每个位置看到所有位置 —— 必须显式屏蔽未来。

做法：在 softmax 之前，给所有 $s>t$（上三角）的分数加上 $-\infty$：

$$ \tilde{S}_{ts} = \frac{q_t^\top k_s}{\sqrt{d_k}} + M_{ts},\qquad M_{ts} = \begin{cases} 0 & s \le t \\ -\infty & s > t \end{cases} $$

$\exp(-\infty)=0$，被屏蔽位置的权重精确为零，且每行剩余权重仍然归一 —— 这就是"mask 实现为 $-\infty$ 加法"的原因： 它把约束干净地塞进了 softmax 的归一化里，而不是事后把权重清零再手动重归一。

允许的注意力模式（T=5，行=query t，列=key s）：✔ 可看，─ 被 mask 成 -inf s=1 s=2 s=3 s=4 s=5 t=1 │ ✔ ─ ─ ─ ─ │ 位置1只能看自己 t=2 │ ✔ ✔ ─ ─ ─ │ t=3 │ ✔ ✔ ✔ ─ ─ │ 下三角矩阵 t=4 │ ✔ ✔ ✔ ✔ ─ │ torch.tril(torch.ones(T,T)) t=5 │ ✔ ✔ ✔ ✔ ✔ │ 位置5可以看全部历史
Causal mask 还带来一个训练效率上的妙处：一条长度 $T$ 的序列，一次前向就同时构成 $T$ 个监督样本 （每个位置都在用自己的前缀预测下一个 token），且互不泄漏。这是 decoder-only 架构训练吞吐极高的原因之一，模块 03 训练时会直接看到。

4多头注意力 MHA：子空间并行与参数量

4.1 子空间并行假设

单头 attention 每个位置只输出一个权重分布 —— 它"这一层只能重点关注一种关系"。 Multi-Head Attention 的假设是：序列中并存多种关系（句法依赖、共指、位置邻近、语义相似……）， 与其用一个大头混着学，不如把表征切成 $h$ 个低维子空间，让每个头在自己的子空间里独立做一套 attention [Vaswani 2017]：

$$ \mathrm{head}_i = \mathrm{Attention}(XW_Q^{(i)},\, XW_K^{(i)},\, XW_V^{(i)}),\qquad W^{(i)}_{Q,K,V}\in\mathbb{R}^{d\times d_h},\;\; d_h = d/h $$ $$ \mathrm{MHA}(X) = \mathrm{Concat}(\mathrm{head}_1,\dots,\mathrm{head}_h)\, W_O,\qquad W_O\in\mathbb{R}^{d\times d} $$

4.2 头维度切分：不增加计算量的并行

关键工程事实：$h$ 个头不是 $h$ 倍计算量。每个头的维度是 $d_h=d/h$， 实现上先用一个 $d\times d$ 的大矩阵算出 $Q$（$K,V$ 同理），再 reshape 成 $[B, h, T, d_h]$ —— 切头只是 view + transpose，总 FLOPs 与单个 $d$ 维大头基本相同。 每个头输出 $T\times d_h$，沿特征维拼回 $T\times d$，最后过输出投影 $W_O$ 让各头信息交融。

4.3 参数量精确计算

$$ \#\text{params}_{\text{MHA}} = \underbrace{3(d\cdot d + d)}_{W_Q,W_K,W_V\ (\text{含 bias})} + \underbrace{d\cdot d + d}_{W_O} = 4d^2 + 4d $$

注意参数量与头数 $h$ 无关 —— $h$ 只决定这 $4d^2$ 如何被划分成子空间，不改变总量。 这个公式在 notebook 里会与 sum(p.numel()) 逐项 assert。

[Vaswani 2017] Attention Is All You Need 同时给出了本章的三块基石：scaled dot-product attention、 multi-head 机制、以及 "attention + FFN + 残差 + LayerNorm" 的 block 结构。原文是 encoder-decoder 架构（机器翻译）； GPT 系把它裁成 decoder-only —— 只保留带 causal mask 的 self-attention，删掉 cross-attention。 各头是否真的学到可解释的分工，是可解释性研究的长期话题：实践中能找到位置头、句法头、以及检索式的 induction head， 但也有大量头可被剪枝而几乎不掉点。

5FFN/MLP：4× 扩展、GELU 与参数大头

每个 block 的后半段是一个逐位置前馈网络（FFN，也叫 MLP）：先升维 4 倍、过非线性、再降回来：

$$ \mathrm{FFN}(x) = \mathrm{GELU}(xW_1 + b_1)\,W_2 + b_2,\qquad W_1\in\mathbb{R}^{d\times 4d},\; W_2\in\mathbb{R}^{4d\times d} $$

三个要点：① FFN 对每个位置独立同构地作用，不做任何跨位置交互 —— 跨位置的信息搬运全部由 attention 负责， FFN 负责对搬运来的信息做逐 token 的非线性变换（主流可解释性观点把它视为键值式的"知识存取"层）； ② $4\times$ 是 [Vaswani 2017] 沿用至今的工程默认值，并非理论最优（现代变体如 SwiGLU 用 $\tfrac{8}{3}d$ 补偿门控参数，模块 07）； ③ GPT-2/nanoGPT 用 GELU 而非 ReLU：$\mathrm{GELU}(x)=x\,\Phi(x)$（$\Phi$ 为标准正态 CDF）， 处处平滑、负区有非零梯度，深网络里优化更稳。

为什么 FFN 占参数大头：逐组件参数量表

取 $d$=模型宽度，$h$=头数，$V$=词表大小，$T_{\max}$=上下文长度，$L$=层数。每层各组件（含 bias）：

组件参数量公式占每层比例（近似）
MHA（$W_{Q,K,V}$ + $W_O$）$4d^2 + 4d$$\approx 1/3$
FFN（$W_1$ + $W_2$）$8d^2 + 5d$$\approx 2/3$
2 × LayerNorm（$\gamma,\beta$）$4d$可忽略
每层合计$\approx 12d^2$—
Token embedding（与 lm_head 权重 tying）$Vd$小模型中占比大，
随 $L,d$ 增大被稀释
Position embedding（learned）$T_{\max}d$

结论：FFN 以 $8d^2$ 对 MHA 的 $4d^2$，稳定占据 Transformer 主体参数的约 2/3。 整模型近似 $\#\text{params}\approx 12Ld^2 + (V+T_{\max})d$ —— 这正是模块 05 scaling laws 里 $N$ 的来源， 也解释了为什么 MoE（模块 07）选择稀疏化 FFN 而不是 attention：钱（参数）在哪里，就在哪里做手术。

6残差与 LayerNorm：Pre-LN vs Post-LN 与残差流

6.1 两种放置方式

attention 和 FFN 都包在"残差 + 归一化"里，但 LayerNorm 放在子层之前还是之后，差异远比看起来大：

$$ \textbf{Post-LN（原始 Transformer）:}\quad x \leftarrow \mathrm{LN}\big(x + \mathrm{Sublayer}(x)\big) $$ $$ \textbf{Pre-LN（GPT-2 / nanoGPT 及之后）:}\quad x \leftarrow x + \mathrm{Sublayer}\big(\mathrm{LN}(x)\big) $$

[Xiong 2020] 从梯度角度给出了解释：Post-LN 中 LayerNorm 挡在残差主干上，输出层附近梯度幅度大、 且随深度恶化，必须配合 learning-rate warmup 并小心调参，否则深层模型直接发散； Pre-LN 中存在一条从输出直达每一层输入的恒等路径（identity path），梯度表现良好， 可以去掉 warmup、用更大学习率稳定训练。这是所有现代 GPT 系模型采用 Pre-LN 的原因（代价是有效深度略减、 最终性能在可比设置下有时略逊于调好的 Post-LN —— 工程上稳定性赢了）。注意 Pre-LN 还需要在所有 block 之后补一个最终 LN（ln_f）， 否则残差流的幅度未经归一直接进 lm_head。

Post-LNPre-LN
残差主干每层被 LN 打断恒等直通，从不被打断
深层梯度顶层大、底层小，易爆/易消失各层均匀，尺度健康 [Xiong 2020]
warmup必需，且对超参敏感可省略或大幅缩短
采用者原始 Transformer (2017)、BERTGPT-2、nanoGPT、LLaMA（换 RMSNorm，模块 07）及几乎所有现代 LLM

6.2 残差流视角（为可解释性埋线）

Pre-LN 结构下有一个极有用的心智模型：把贯穿全网的残差主干看成一条残差流（residual stream）—— 一条 $d$ 维的"共享总线"。每个 attention 头、每个 FFN 都只是从总线上读取（经 LN），计算后把增量写回（加法）； 没有任何组件能"重写"总线，只能往上叠加。于是第 $L$ 层后的表征可以严格展开为：

$$ x_L = x_0 + \sum_{\ell=1}^{L}\Big[\mathrm{MHA}_\ell\big(\mathrm{LN}(\cdot)\big) + \mathrm{FFN}_\ell\big(\mathrm{LN}(\cdot)\big)\Big] $$

模型的最终预测是所有子层贡献的线性叠加（直到最后的 ln_f 和 lm_head）。 机械可解释性（mechanistic interpretability）的大量工具 —— logit lens、activation patching、circuit 分析 —— 都建立在"读写残差流"这个视角上。做 model evaluation 时它同样关键：想知道"哪一层让模型决定说谎"， 本质上就是在问"哪个子层往残差流里写入了那个方向"。

8位置编码：attention 为什么需要它

一个容易被忽略的数学事实：self-attention 本身是置换等变的。 设 $P$ 为任意置换矩阵，则 $\mathrm{Attention}(PQ, PK, PV) = P\,\mathrm{Attention}(Q,K,V)$ —— 把输入序列打乱，输出只是同样地被打乱，每个 token 的表征完全不变。 也就是说，不加位置信息的 Transformer 把句子看成一个词袋："狗咬人"和"人咬狗"没有区别。 必须显式注入位置信息，主流两条路：

Sinusoidal（[Vaswani 2017] 原始方案）Learned（GPT-2 / nanoGPT 方案）
形式$PE_{(t,2i)}=\sin(t/10000^{2i/d})$，$PE_{(t,2i+1)}=\cos(\cdot)$，固定不学一张可学习的 $T_{\max}\times d$ embedding 表
参数量0$T_{\max}\cdot d$
超出训练长度可计算任意位置（但效果无保证）查不到表，硬上限 $T_{\max}$
编码的是绝对位置（不同频率的正弦组合，线性变换可表达相对偏移）绝对位置（完全靠数据学）

两者实测差距不大 [Vaswani 2017]，本课程跟随 nanoGPT 用 learned。 它们的共同短板是都编码绝对位置，而语言更在意相对位置（"前一个词"比"第 1024 号位置"更本质）， 且外推到更长上下文都不可靠 —— 现代模型几乎全部转向把相对旋转直接作用在 Q/K 上的 RoPE，留到模块 07 展开。

9研究前沿与开放问题

  • $O(T^2)$ 能否绕开？ FlashAttention 不改数学只改访存（模块 06）；线性 attention 与 SSM（Mamba，模块 07）直接改算子。 开放问题是这类替代在检索式能力（如 in-context 精确回忆）上是否存在本质损失 —— 评测上要用 needle-in-a-haystack、 associative recall 这类针对性任务，而非只看平均困惑度。
  • 注意力头的功能分工：induction heads 等 circuit 已被定位，但"多少头是冗余的、剪掉后哪些行为退化"仍无系统答案。 对 evaluator 的含义：聚合分数掉 0.5% 的剪枝，可能集中摧毁某一种能力 —— 需要按能力分桶评测。
  • Pre-LN 之后：残差流幅度随深度持续增长，催生了 RMSNorm、QK-Norm、sandwich-norm 等变体； 超深模型（百层以上）的归一化最优配方仍在演化（模块 07）。
  • FFN 是"知识库"吗？ 键值记忆假说支持定点知识编辑（如 ROPE/ROME 系工作），但编辑的副作用（涟漪效应） 评测仍不成熟 —— 改掉一条事实后，如何系统度量被波及的推理链？
  • 评测视角：本章每个组件都对应一类可测的失败模式 —— mask 错位 → 数据泄漏型虚高分；位置编码外推失败 → 长上下文性能悬崖； softmax 饱和 → 训练不稳定。读懂内核，才能把 benchmark 异常归因到机制。
