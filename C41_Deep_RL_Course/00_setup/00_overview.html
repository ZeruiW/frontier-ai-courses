1这门课讲什么：跨过函数逼近这道坎

欢迎来到 深度强化学习与决策。这门课只做一件事：把你从「会写表格 RL」带过「函数逼近」这道坎，进入深度 RL 与决策/控制的世界。

在 C13 强化学习地基里，你已经从零实现过 MDP 与值迭代、Q-learning/TD、REINFORCE 策略梯度、Actor-Critic 与 GAE、赌博机探索——但它们几乎都活在表格世界里：状态可枚举、每个 $(s,a)$ 存一个数、贝尔曼算子是压缩映射、收敛有保证。现实世界不是这样。Atari 的一帧画面有 $256^{84\times84\times4}$ 种可能、机械臂的关节角是连续的——状态根本数不过来。

唯一的出路是函数逼近：用一个神经网络 $Q_\theta(s,a)$ 或 $\pi_\theta(a|s)$ 去泛化，让没见过的状态也能借相似状态的经验给出合理估计。这一步看似只是「把查表换成网络」，却打开了潘多拉魔盒：表格法的收敛保证当场失效，训练可能发散、震荡、崩溃。本课的六个模块，本质上就是在系统地回答一个问题——当 RL 遇上深度网络，会冒出哪些新的恶魔，人们又发明了哪些武器去降服它们。

一句话定位这门课：C13 教你 RL 的「物理定律」（贝尔曼、策略梯度），C41 教你在「真实的、数不清状态的世界」里让这些定律不崩溃地运转。你会从零写出能玩 toy 游戏的 DQN、能学连续控制的 PPO/SAC、能从固定数据集学策略的 CQL/IQL、能在「脑中想象」里规划的世界模型、以及把 RL 变成序列建模的 Decision Transformer——全部纯 numpy、在自写的 toy 环境里、跑得出可复现的结果。

一句方法论上的话先说在前面：本课不重复 C13 的表格法。我们默认你已经会贝尔曼方程、会推策略梯度定理、知道 GAE 是什么。本课的篇幅全部花在「表格→逼近」之后才出现的东西上——致命三要素、经验回放、目标网络、信赖域、最大熵、分布偏移、模型误差累积、内在奖励、序列建模。这些是深度 RL 真正的难点与魅力所在。

2从表格到逼近：三件事变了（致命三要素）

从表格到逼近：三件事变了

把 $V/Q/\pi$ 从查表换成神经网络，至少有三件根本性的事发生了变化。理解它们，就理解了本课所有算法设计的动机：

维度表格 RL（C13）函数逼近 / 深度 RL（C41）
状态表示每个状态一个条目，互不影响参数共享：更新一个状态会牵动相似状态（泛化，也可能干扰）
收敛保证贝尔曼算子是 $\gamma$-压缩，值迭代必收敛可能发散：投影 + 自举 + 离策略 = 致命三要素
数据来源在线交互，用完即弃可回放（off-policy 复用）、可纯离线（固定数据集）
动作空间多为离散、可枚举可连续（机械臂关节），需新的策略表示与优化
瓶颈状态太多存不下采样效率（真实交互贵）、稳定性、探索
致命三要素

最该刻进脑子的一条是致命三要素（deadly triad）[Sutton & Barto 第 11 章]：当 ① 自举（用自己的估计当目标，如 TD/Q-learning）、② 离策略（用别的策略的数据，如 replay）、③ 函数逼近（用网络泛化）三者同时出现时，值估计可能发散到无穷。去掉任意一个通常都稳：纯蒙特卡洛（无自举）、纯在线同策略（无离策略）、或表格（无逼近）。但深度 off-policy RL（DQN/SAC）恰恰三者全占——所以 DQN 的两大发明（经验回放、目标网络）本质都是在驯服这个三要素，而非消除它。模块 01 会让你亲眼看到一个朴素 Q 网络如何发散、再看两个技巧如何把它拉回来。

把这张表记住，本课每个模块都在打其中一格：模块 01 打稳定性（致命三要素）；模块 02 打策略优化的稳定与连续动作；模块 03 打纯离线的数据分布偏移；模块 04 用模型打采样效率；模块 05 打探索与决策的新范式。

3课程地图：六个模块如何递进

课程地图：六个模块如何递进

C13 地基（已学）：MDP/贝尔曼 · Q-learning/TD · REINFORCE · Actor-Critic/GAE · 赌博机 —— 全是「表格 / 浅层」版本，收敛有保证、状态可枚举 │ 跨过「函数逼近」这道坎（致命三要素登场） ▼ 模块 00 总览 从表格到逼近的世界观、致命三要素、numpy toy 环境方法论 │ ▼ 模块 01 DQN 值函数逼近：replay 打破相关性 + target net 稳目标 + Double/Dueling │ 「把 Q-learning 搬上神经网络而不发散」 ▼ 模块 02 PPO / SAC 策略优化长大：信赖域→clip(PPO)；最大熵+双Q+温度(SAC, 连续控制) │ 「把策略梯度变成生产级、能连续控制」 ▼ 模块 03 离线 RL 只给固定数据集：分布偏移/外推误差 → BC、CQL(保守)、IQL(expectile) │ 「不许再交互，如何安全地从数据学策略」 ▼ 模块 04 世界模型 学动态模型 → MPC 规划 / Dyna / latent 想象(Dreamer)；采样效率 │ 「学一个模型，在脑中模拟与规划」 ▼ 模块 05 探索 + 前沿 RND/好奇心内在奖励 · 多智能体 RL · Decision Transformer(RL=序列建模)

这条链有清晰的内在逻辑。01 与 02 是两大支柱——值方法（学 Q 再贪婪）与策略方法（直接优化 $\pi$），合起来覆盖了在线深度 RL 的主干。随后三个模块各自回应在线深度 RL 的一个致命短板：03 离线回应「真实交互代价太高甚至禁止」；04 模型回应「无模型法太费样本」；05 探索/前沿回应「稀疏奖励下根本探索不到信号」以及「能不能干脆换个范式（序列建模）」。

每一级台阶都对应一个可独立验证的能力：模块 01 你手写的 DQN 会在 toy 环境把回报从随机水平显著拉高；模块 02 你的 PPO 会在连续/离散 toy 控制里稳定提升回报；模块 03 你会亲眼看到 CQL/IQL 在分布偏移下不崩、而朴素 Q 崩；模块 04 你学的动态模型 + MPC 能在少量交互内规划出好动作；模块 05 你的 RND 内在奖励能驱动智能体探索到稀疏奖励、DT 能按目标回报条件生成动作。每一步都有 assert 与稳健阈值兜底，绝不靠「看着像收敛了」。

4方法论：纯 numpy + 自写 toy 环境 + 可复现

方法论：纯 numpy + 自写 toy 环境，为什么够、怎么保证可复现

本环境不装 PyTorch、不装 Gym、没有 GPU。但深度 RL 的难点从来不是框架 API，而是算法结构与训练动力学：致命三要素为什么发散、clip 为什么稳、保守正则为什么能压住 OOD、模型误差为什么累积。这些用纯 numpy 在小 toy 环境里能精确地表达、观察、验证。

打个比方：要弄懂发动机原理，不必先有一辆法拉利。深度 RL 的「发动机原理」是数据怎么流、目标怎么算、梯度怎么更新、为什么稳/不稳；这些和环境是 Atari 还是 GridWorld、网络是百万参数还是两层 MLP 无关。我们把每个算法的训练循环从零手写——小 MLP 的前向与反向传播、Adam 优化器、replay buffer、$\varepsilon$-贪婪、GAE、clip 目标、保守正则、MPC 打靶、RND 误差、DT 序列——跑在自写的玩具环境上，规模小到能秒级迭代、小到能把每个中间量打印出来核对。

直白说

我们把深度 RL 的每个机制翻译成 numpy 里看得见的东西：网络就是几个矩阵、反向传播就是链式法则手算、replay 就是一个 deque、target 网络就是另一份权重的拷贝、世界模型就是一个回归 $s'$ 的小网、内在奖励就是两个网络输出之差。你写的是算法结构，不是 SOTA 分数。

严谨说

关键纪律是可复现（reproducibility）：深度 RL 出了名地受随机种子摆布 [Henderson 2018]。所以本课每个训练实验都固定 seed、并用稳健阈值判定成功——不是要求「达到某个精确回报」，而是断言「最终回报 ≥ 随机基线 + 一个有意义的间隔」「训练后期均值 > 前期均值」这类方向性、留足余量的判据。这样 assert 既能抓住「真的学到了」，又不会因为一点随机波动而假阴性。

深度 RL 概念本课的 numpy 实现对应真实工具
神经网络 (Q/π/模型)手写小 MLP：几个权重矩阵 + 激活 + 反向传播torch.nn.Module
优化器手写 Adam / SGDtorch.optim.Adam
环境 environment自写 GridWorld / numpy CartPole / 连续玩具Gymnasium / MuJoCo
replay buffercollections.deque + 随机采样替换缓冲区 / D4RL 数据集
可复现性固定 seed + 稳健阈值 assert多 seed 取均值 ± 方差

务必清楚本课不追求什么：不追求 SOTA 回报、不在 Atari/MuJoCo 真环境上跑、不调出能发论文的曲线。这些在你掌握了算法结构之后，是换环境、加规模、调超参的工程活（references 里的 Spinning Up、CleanRL、Stable-Baselines3 接手）。本课负责把第一步——算法结构、训练动力学、为什么稳/不稳夯死；这一步搞懂，换到 PyTorch + 真实环境只是规模问题。

5环境与运行

环境与运行

环境极简：只需 numpy（画学习曲线可选 matplotlib）。全课 CPU 上秒到分钟级运行，无需 GPU、PyTorch、Gym。

conda create -n deep-rl python=3.11 -y && conda activate deep-rl
pip install numpy            # 必需
pip install matplotlib       # 可选，仅用于画学习曲线 / 回报曲线
jupyter lab

每个模块配一个 notebook，结构统一（对标全站规范）：先用 numpy 把机制从零实现并验证（5–6 个 worked 小节，每节都跑出可打印的结果与 assert 自检），再做 3–4 道带 assert 判分的 ✏️ 练习（先给骨架与 TODO，自己填，紧跟一个自测 cell，再对照 📖 参考答案），最后一个真实数据/真实配置胶囊（用真实算法的标准超参或公开 benchmark 数字算一笔账，把 toy 接到现实）。

建议的学习节奏：先读完整章 HTML 建立算法直觉与数学框架，再打开 notebook 亲手实现。读和做缺一不可——只读会觉得「公式好像懂了」，真正动手写训练循环、调 target 更新频率、让回报曲线爬起来、让 assert 通过时，才会撞见深度 RL 真正的细节魔鬼（目标在动、方差爆炸、OOD 高估、误差累积）。这门课的深度正是为「动手把它跑通」服务的。

配套先读：Sutton & Barto 第 9–11 章（函数逼近与致命三要素）建立稳定性直觉；OpenAI Spinning Up 当深度 RL 的工程字典（PPO/SAC 推导对照）；各模块核心论文（DQN、PPO、SAC、CQL/IQL、World Models/Dreamer、RND、Decision Transformer）见 references.md。

✅ 学完整门课，你应该能：
  1. 说清致命三要素为什么导致发散，并指出 experience replay 与 target network 各驯服了哪一面；
  2. 从零写出 DQN（replay + target + Double + Dueling），让它在 toy 环境显著优于随机策略；
  3. 推导 PPO 的 clipped surrogate（它在近似什么信赖域约束），并从零实现一个能提升回报的 PPO；
  4. 讲清 SAC 的最大熵目标、双 Q、温度自调与重参数化，理解它为何适合连续控制；
  5. 解释离线 RL 的分布偏移/外推误差，并对比 BC、CQL（保守惩罚）、IQL（expectile）三种应对；
  6. 学一个动态模型并用 MPC 随机打靶规划，说清模型误差为何累积、Dyna 如何混合真实与模拟经验；
  7. 实现 RND 内在奖励驱动稀疏奖励探索，并用 Decision Transformer 按目标回报条件生成动作；
  8. 把以上 numpy 训练循环映射到 PyTorch + Gymnasium 的真实实现，知道下一步怎么上规模。
