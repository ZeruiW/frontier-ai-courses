1基于模型 RL：在脑中模拟世界

模块 01–03 全是无模型（model-free）的：DQN/PPO/SAC 直接从经验里学 $Q/\pi$，从不试图理解「环境是怎么运转的」；离线 RL 也只从固定数据学策略。它们都把环境当成一个黑盒——给动作、收状态和奖励，仅此而已。这条路简单、通用，但有个致命短板：极度费样本。DQN 玩 Atari 要上亿帧、SAC 学个机器人要几十万到百万步真实交互。

人类显然不是这样学的。你学骑车不需要摔几十万次——你脑子里有一个世界如何运转的模型：把龙头往左、车会往左倒；蹬快点、会更稳。你能在脑中想象「如果我这样做会发生什么」，然后挑一个好的去做。这就是基于模型（model-based）的核心思想：

  • 先学一个动态模型 $\hat T(s'|s,a)$ 和奖励模型 $\hat r(s,a)$——预测「在状态 $s$ 做动作 $a$ 会到哪、得多少奖励」；
  • 再用这个模型做两件事之一（或都做）：① 规划（在脑中前瞻搜索好的动作序列，如 MPC）；② 生成想象经验去训练策略（如 Dyna、Dreamer）。

好处立竿见影：模型一旦学好，你可以在脑中（模型里）做无限次廉价的「试错」，而不必每次都真去环境里走一步。这把样本效率（达到某性能所需的真实交互量）提升一到几个数量级——这正是基于模型 RL 的最大卖点，在真实机器人、医疗等真实交互昂贵的场景尤其关键。代价是：模型不可能完美，它的误差会污染规划与想象，本模块的核心张力就在于此。

模型换样本效率

一句话定位本模块：无模型 RL 把环境当黑盒、靠海量试错；基于模型 RL 先学一个『世界的近似』，再在脑中规划与想象，用模型换样本效率。学完你会从零学一个 toy 动态模型、用它做 MPC 随机打靶把一个点质量控制到目标、实现 Dyna 把真实与想象经验混合、并亲眼看到模型误差如何随 rollout 步数累积——以及世界模型（Dreamer 直觉）如何在 latent 空间里把这一切做大。

2学一个动态模型

学一个动态模型

基于模型的第一步是拟合动态。给定交互数据 $\{(s,a,s',r)\}$，学一个模型预测下一状态与奖励。最简单的形式是确定性回归：

\[\hat{s}' = f_\theta(s, a), \qquad \hat{r} = g_\phi(s, a)\]

常见的两个实现选择：

  • 预测增量而非绝对值：让模型输出 $\Delta s = s'-s$ 而非直接预测 $s'$。因为相邻状态通常很接近，预测增量的尺度更小、更好学、误差更可控。这是 MBRL 的标准技巧。
  • 确定性 vs 概率模型：确定性模型输出单点 $\hat s'$；概率模型输出一个分布（如高斯 $\mathcal N(\mu,\sigma)$），能表达不确定性——这对「该信模型多远」至关重要（见第 5 节）。PETS、PlaNet 等用概率集成。

模型的损失就是普通的监督回归（MSE）。注意一个深刻的区别：学模型是纯监督学习——没有自举、没有分布偏移（在训练数据上）、没有致命三要素，比学 $Q/\pi$ 稳定得多、可复现得多。这也是基于模型 RL 的一个隐性优势：把「难的、不稳的 RL 部分」缩小，把「稳的、好优化的监督学习部分」放大。但天下没有免费午餐——模型的误差会在使用时（规划/想象）暴露出来，这才是真正的战场。

还有一个常被追问的设计点：要不要预测奖励与终止？在 toy 里奖励常是状态的已知函数（如「到原点的距离」），可以不学；但在真实任务里，奖励/终止也得从数据学（Dreamer 就专门学一个奖励预测器和折扣/终止预测器），否则纯想象 rollout 无法自洽地算回报。原则是：规划/想象需要用到的一切量，模型都得能预测——状态转移是骨架，奖励与终止是让回报计算闭环的必要补充。这也预示了第 6 节世界模型为何是「一整套预测器」而非单个动态网。

一个关键陷阱：模型的训练数据来自某个策略的交互，于是模型只在那个策略访问过的状态分布上准。当你用模型去规划/训练出一个新策略，新策略会访问模型没见过的状态——模型在那里的预测不可信。这是模型层面的分布偏移（呼应模块 03 值层面的分布偏移）。解法：交替「用当前策略采新数据更新模型」与「用模型改进策略」（如 Dyna、MBPO 的循环），让模型与策略的分布同步演进。

3用模型规划：MPC 与随机打靶

用模型规划：MPC 与随机打靶

有了模型，最直接的用法是规划（planning）——不学策略，而是在每一步用模型向前模拟、挑一个好的动作执行。MPC（模型预测控制）是其中最实用的范式：

  1. 从当前状态 $s$ 出发，在模型里模拟若干候选动作序列（每条长 $H$ 步），算每条的累计（模型预测）回报；
  2. 选回报最高的那条序列，但只执行它的第一个动作 $a_0$；
  3. 到了下一个真实状态，丢掉旧计划、用新观测重新规划（滚动时域，receding horizon）。

「只执行第一步、然后重规划」是 MPC 对模型误差的天然鲁棒性来源：即使 $H$ 步的模型预测越往后越不准，你也只信任并执行了最准的第一步，下一步用真实观测重新校准。这让 MPC 即便配一个不完美的模型也能稳定工作。

怎么在模型里搜出好的动作序列？最简单的是 random shooting（随机打靶）：

def mpc_action(s, model, reward_fn, horizon=15, n_samples=200):
    best_return, best_a0 = -inf, None
    for _ in range(n_samples):                # 撒一批随机动作序列
        seq = random_actions(horizon)         # 每条 horizon 步
        sim, ret = s, 0
        for a in seq:                         # 在模型里 rollout
            ret += reward_fn(sim, a)
            sim = model(sim, a)               # 用学到的模型推进
        if ret > best_return:                 # 留最优的
            best_return, best_a0 = ret, seq[0]
    return best_a0                            # 只返回第一个动作

随机打靶无需梯度、几行实现、对模型形式无要求，缺点是高维动作下采样效率低。进阶是 CEM（交叉熵法）：迭代地把采样分布往高回报序列收紧（保留 top-k 精英、用它们的均值方差更新采样分布），几轮后集中到好序列附近，比纯随机高效得多。PETS、PlaNet 都用 CEM。notebook 会让你用学到的模型 + 随机打靶把一个点质量从远处控制到目标。

MPC 与「学一个策略」是两种互补的决策范式，值得对比清楚。学策略（DQN/PPO/SAC）把所有思考压进训练、部署时一次前向就出动作——快，但换了 reward 就得重训、且策略是个黑盒。MPC把思考推迟到运行时——每步现搜，所以换 reward 立刻生效（模型不变、只换打靶时的 reward_fn）、决策过程透明可解释，代价是每步在线搜索的算力。在机器人、需要频繁切换目标、或对安全/可解释有要求的场景，MPC + 学到的模型是极常用的组合；而在目标固定、追求部署延迟极低的场景，学好的策略更合适。二者也能融合（用学到的策略给 MPC 提供候选/初始化）。

MPC 的哲学是「不学策略，每步现想」：把「该做什么」这个决策，从「预先训练一个策略网络」改成「运行时用模型实时搜索」。好处是不需要训练策略、换目标（reward）立刻生效、且对模型误差鲁棒（只信第一步）；代价是每步都要在线搜索（算力换灵活）。这与无模型 RL「训练时费劲、部署时一次前向」恰好互补——是机器人控制里极常用的一招。

4Dyna：真实与想象经验混合

Dyna：把真实与想象经验混合

规划是「用模型现场决策」，另一条路是用模型生成想象经验来训练一个策略/值函数。Dyna（Sutton 1991）是这条路的奠基框架，思想极其简洁：

┌──────────────► 真实环境 ──── (s,a,r,s') ───┐ │ (少量真实交互) │ 策略/值 Q ① 直接 RL 更新 Q ▲ │ │ ② planning 更新(大量) ③ 用真实经验也更新模型 │ ▼ └──── 想象经验 (s,a,r̂,ŝ') ◄──── 学到的模型 ◄┘ (从模型采大量廉价模拟)

每一步真实交互，Dyna 做三件事：① 用这条真实经验直接更新 $Q$（就是普通的 model-free 更新）；② 用它更新动态模型；③ 然后从模型里采样 $k$ 条想象经验（随机挑见过的 $(s,a)$，用模型预测 $\hat s',\hat r$），把这些想象经验也喂给同一个 $Q$ 更新。关键洞察：对 $Q$ 的学习算法而言，它分不清一条经验是真实采的还是模型生成的——只要模型够准，想象经验和真实经验一样能推动学习。

于是 Dyna 用「1 条真实 + $k$ 条廉价想象」替代了「需要 $k+1$ 条真实」，样本效率提升约 $k$ 倍。$k$ 是核心旋钮：模型越准，$k$ 可以越大（更多想象、更省真实样本）；模型越差，$k$ 要越小（少信模型，避免想象的错误污染 $Q$）。现代版本如 MBPO 把这个思想做精：用短程（few-step）模型 rollout 喂给 SAC，并理论地回答「该信模型 rollout 多少步」。

Dyna 还揭示了基于模型与无模型的一个连续谱而非二分：$k=0$ 就是纯无模型（DQN/Q-learning），$k\to\infty$ 且模型完美就接近纯规划（值迭代）。中间的任意 $k$ 都是「用多少模型、用多少真实」的混合。这个视角很解放——你不必在「无模型」和「有模型」之间二选一，而是按模型的可信度动态调节混合比例。一个有意思的退化：当 $(s,a)$ 离散且模型就是「记住见过的 $(s,a)\to(r,s')$」（表格模型，notebook 就这么做），Dyna 的想象更新本质就是在已见过的转移上反复做动态规划——把稀疏真实经验里蕴含的信息榨干，这正是它加速学习的来源。

Dyna 的一句话精髓：『对学习算法撒一个善意的谎』——用模型生成的假经验冒充真经验去训练，只要模型够准，学习者照样进步、却省下了真实交互。它和 MPC 的区别在于产物：MPC 不产生策略（每步现想），Dyna 产生一个被想象经验加速训练好的策略/值函数。两者可以结合，也各有适用场景。notebook 会让你实现 Dyna，对比「纯真实经验」与「真实 + 想象」的学习速度。

5模型误差与复合误差的累积

模型误差与复合误差：致命的累积

基于模型 RL 的阿喀琉斯之踵是模型误差，尤其是它在多步 rollout 中的累积（compounding error）。问题机制：模型在每一步都有小误差，但这个误差会进入下一步的输入，再被模型放大，再进入下下步……

\[\text{误差}(\hat s_H) \approx \sum_{t=1}^{H} (\text{Lipschitz 常数})^{H-t}\cdot \epsilon_t \quad\Longrightarrow\quad \text{随 } H \text{ 指数式累积}\]

直觉：一个单步预测准到 99% 的模型，rollout 10 步后可能已经面目全非——因为误差被反复喂回、逐步偏离真实轨迹，最终模型想象出的状态在真实环境里根本不存在。这就是为什么：

  • MPC 的 horizon $H$ 不能太长：太长则后段预测全是垃圾，规划基于幻觉。实践中 $H$ 取十几到几十步，靠「只执行第一步 + 重规划」规避后段误差。
  • Dyna/MBPO 的 rollout 要短：MBPO 的核心结论是用很短（如 1–5 步）的模型 rollout，宁可想象得浅也不让误差累积失控。「该信模型多远」直接由模型的单步误差决定。
  • 概率模型 + 集成：用模型集成（ensemble）的预测分歧来估计不确定性——多个独立训练的模型在某 $(s,a)$ 上预测分歧大，说明那里数据稀疏、不可信。据此在模型「不确定」的地方停止 rollout 或施加保守惩罚（PETS、MOPO）。

这条「误差累积」的物理定律，解释了基于模型 RL 几乎所有的设计取舍——不是不想 rollout 得长（长更省真实样本），而是模型误差不允许。整个领域的进步，很大程度上就是「把可信 rollout 的有效 horizon 往长里推」：更好的模型、更好的不确定性估计、latent 空间预测（更平滑、误差更小）。

复合误差定律

把这条定律记死：模型的单步误差再小，多步 rollout 也会让它指数累积、想象出现实中不存在的状态。所以基于模型 RL 的黄金法则是『用模型走短，用真实校准』——MPC 只信第一步、Dyna/MBPO 只 rollout 几步、世界模型靠不断的真实观测重新锚定 latent。任何「让模型自己跑很长」的方案，都要先回答「误差累积怎么办」。

6世界模型：在 latent 空间里想象

世界模型：在 latent 空间里想象

把基于模型的思想推到极致、并搬到高维观测（图像）上，就是world model（世界模型）。Ha & Schmidhuber 2018 的开创工作给出经典三件套：

  • V（视觉，VAE）：把高维观测（如游戏画面）压缩成低维 latent dynamics 向量 $z$——在像素空间预测太难太糙，先编码到紧致的 latent；
  • M（记忆，RNN）：在 latent 空间预测演化 $z_{t+1}\sim p(z_{t+1}|z_t,a_t,h_t)$——这就是 latent 空间里的动态模型，带记忆（隐状态 $h$）处理部分可观测；
  • C（控制器）：一个很小的策略，输入 latent $z$ 与记忆 $h$、输出动作。因为感知与动态已被 V/M 处理，控制器可以极简。

最震撼的是：Ha & Schmidhuber 展示了智能体能「在自己的梦里」训练——完全在学到的世界模型里（不碰真实环境）想象 rollout、训练控制器，再把学到的策略搬回真实环境也能用。这把「想象」从一个辅助技巧提升为学习的主舞台。

Dreamer（Hafner 2020+）把这条线做成当代 SOTA：在学到的 latent 世界模型里想象长程 rollout、用 actor-critic在想象中训练策略（优势、值函数全在 latent 想象里算），只用极少真实交互。DreamerV3 更做到一套超参通吃上百个任务（从 Atari 到机器人到 Minecraft 挖钻石），是世界模型方法成熟的标志。

注意世界模型如何同时调用了本课前面所有模块的零件：它在想象 rollout 上跑的是模块 02 的 actor-critic / 策略优化；它必须直面本模块第 5 节的复合误差（靠 latent 空间预测更平滑来缓解）；它的训练数据来自真实交互，又要应对模型层面的分布偏移（靠持续用新策略采数据更新模型）。可以说世界模型是深度 RL 各条线索的汇合点——把感知（编码）、记忆（RNN/状态）、想象（latent 动态）、决策（actor-critic）拧成一个系统。这也是为什么它被许多人视为通向更通用智能体的一条主路：一个能在脑中模拟世界并据此规划的智能体，离「会推理、会想象后果」的智能更近了一步。

直白说

世界模型的直觉就是『先学会做梦，再在梦里练习』：把真实交互主要用来「学会一个逼真的梦境（世界模型）」，然后把绝大部分的策略学习挪进这个廉价、可无限采样的梦里完成。真实样本主要用于修正梦境、而非直接训策略。

严谨说

技术上，latent 空间是关键：在压缩的、平滑的 latent 里预测动态，比在像素空间预测误差更小、更稳（缓解第 5 节的复合误差），且 actor-critic 在 latent 上算想象回报与值的梯度可以高效反传。Dreamer 还学一个 latent 的奖励预测器与折扣/终止预测器，让纯想象 rollout 自洽完整。

世界模型是把感知、记忆、想象、规划统一起来的雄心方向，也与「智能体的内部世界观」「基于模型的推理」等更大的 AI 议题相连。必读 Ha & Schmidhuber 2018（World Models，行文极具启发）、Hafner 的 Dreamer 系列。notebook 会用一个 toy 的「编码 + latent 预测」展示这个思想的骨架。详见 references。

7基于模型 vs 无模型：权衡与结合

基于模型 vs 无模型：权衡与结合

把两条路线放一起对比，建立选型直觉：

维度无模型 (DQN/PPO/SAC)基于模型 (MPC/Dyna/Dreamer)
样本效率低（需海量真实交互）高（模型里廉价想象/规划）
最终性能（渐近）通常更高（不受模型误差限）可能被模型误差封顶（但 Dreamer 已逼近/超越）
计算成本训练贵、部署快（一次前向）规划类部署贵（在线搜索）；想象类训练贵
稳定性RL 部分难调（致命三要素）学模型是稳的监督学习；但误差累积是新风险
灵活性换 reward/目标要重训MPC 换 reward 立即生效（模型不变）
适用模拟便宜、可大量采样真实交互昂贵（机器人）、需快速适应新目标

经验法则：真实交互昂贵（机器人、真实控制）→ 基于模型，把每条宝贵样本榨干；模拟极便宜、能大规模并行（游戏、RLHF）→ 无模型往往更简单且渐近性能更好。二者并非对立——结合是当前前沿：MBPO（短 rollout 喂 SAC）、Dreamer（想象里跑 actor-critic）、MuZero（学一个『只为规划够用』的隐式模型 + MCTS，无需环境规则即达 AlphaZero 水平）都是融合的代表。

一个值得记住的统一视角：模型给了你一个『可微/可采样的环境替身』。有了它，你可以做无模型做不到的事——前瞻规划、对 reward 求梯度、在想象里安全地试错。RL 的很多前沿（采样效率、长程信用分配、快速适应）都指向「学到并善用一个好模型」。本课把 model-based 放在 offline 之后，正因为它们是省真实交互的两条主路、且常常合流（在离线数据上学模型再保守规划）。

8研究前沿与开放问题

研究前沿与开放问题

  • 可信 rollout 的 horizon：复合误差让长程想象失真。如何更好地估计模型不确定性、自适应地决定「该信模型多远」（MBPO 给了一个答案，但远未解决），是核心课题。
  • 为规划而学 vs 为预测而学：MuZero 的洞察是模型不必预测真实观测，只需预测「规划所需的量」（值、策略、奖励）。这种以终为始的隐式模型可能比逼真重建更有用——但何时该这样、何时需要真实重建，仍在探索。
  • 世界模型的 scaling：DreamerV3 用一套超参通吃上百任务，暗示世界模型可能像 LLM 一样从规模中受益。把世界模型做大、做通用（甚至用视频预训练）是激动人心的方向。
  • 基于模型 + 离线：在固定离线数据上学模型、再保守地规划（MOPO/COMBO），把样本效率与离线安全结合——但模型在离线数据外的外推不确定性如何控制，是难点。
  • 规划与学习的统一：AlphaZero/MuZero 把搜索（规划）与学习（网络）拧成一股——网络给搜索提供先验与价值，搜索给网络提供更好的训练目标，互相增强。把这套「学习引导的搜索」推广到连续控制、随机环境、不完美信息博弈，仍是开放前沿。
