1探索：撞不到奖励怎么办（+ 两条前沿）

到这里，前四个模块给了你深度 RL 的主干：DQN、PPO/SAC、离线、世界模型。但有一个贯穿始终却一直没正面解决的问题——探索。回忆 C13 的赌博机：探索是 RL 的根本张力（利用已知 vs 搏取未知）。前四模块的探索都很初级：DQN 用 $\varepsilon$-贪婪（随机乱试）、SAC 用熵（动作上加随机）。这些是局部、无方向的探索——在当前行为附近抖一抖。

局部探索在大多数任务上够用，但碰到稀疏奖励（sparse reward）就彻底失灵。想象一个游戏：你要走一长串正确动作才能拿到第一个奖励（如《蒙特祖玛的复仇》要找钥匙、开门、躲骷髅才得分）。$\varepsilon$-贪婪靠随机乱试撞到这条长链的概率，是指数级地小——你可能玩几百万步都拿不到一个非零奖励，于是根本没有信号可学。这类硬探索（hard exploration）问题是局部探索的滑铁卢，需要系统化、有方向的探索。

本模块讲三个主题，前一个是探索的正面进攻，后两个是 RL 的两个重要前沿方向：

  • 结构化探索：用intrinsic reward（内在奖励）主动奖励「新颖 / 惊讶」的状态——count-based、RND（随机网络蒸馏）、好奇心。让智能体主动想去没去过的地方，而非被动乱试。
  • 多智能体 RL（MARL）：多个学习中的智能体共处一环境，彼此互为环境——带来非平稳、博弈、合作/竞争、均衡等单体 RL 没有的全新难题。
  • Decision Transformer：把 RL 整个重铸成序列建模——不学值/策略，而是把 (回报, 状态, 动作) 当序列、用 Transformer 自回归预测动作，推理时按「想要的回报」条件生成。一条与前四模块完全不同的技术路线。
撞不到奖励怎么办

一句话定位本模块：前四模块假设『总能撞到奖励』，本模块正面解决『撞不到奖励怎么办』(探索)，再眺望两个前沿——多个智能体一起学(MARL)、以及干脆把 RL 变成序列预测(Decision Transformer)。学完你会实现 count-based 与 RND 内在奖励驱动探索、看两个学习者在博弈里收敛到混合纳什均衡、并用 Decision Transformer 按目标回报条件生成动作。

2探索的根本难题：稀疏奖励

探索的根本难题：稀疏奖励

先把问题量化。设一个任务需要连续做对 $L$ 步特定动作才得第一个奖励，每步有 $|\mathcal A|$ 个动作。$\varepsilon$-贪婪在没有任何信号时近似随机，撞对整条链的概率约 $|\mathcal A|^{-L}$——随链长指数衰减。$L=20$、$|\mathcal A|=4$ 时这个概率是 $4^{-20}\approx10^{-12}$，意味着平均要试上万亿步才撞到一次奖励。这就是稀疏奖励的残酷数学。

直白说

局部探索（$\varepsilon$-贪婪、熵）像在原地打转时偶尔随机迈一步：适合「奖励信号密集、稍微试试就能改进」的任务，但面对「要走很远才有第一个反馈」的任务，它几乎不可能靠运气走到。

严谨说

出路是内在动机（intrinsic motivation）：给智能体一个自造的奖励信号，奖励「去新地方 / 遇到意外」，加到稀疏的外在奖励上。这样即使外在奖励还是零，内在奖励也能驱动智能体系统地铺开探索整个状态空间，大大提高撞到外在奖励的机会。总奖励 $r_t = r_t^{\text{ext}} + \beta\, r_t^{\text{int}}$。

内在奖励的核心设计问题是：怎么量化『新颖 / 惊讶』？三条主流思路，难度递增：

  • 计数（count-based）：访问次数少 = 新颖。表格里直接数 $N(s)$，奖励 $\propto1/\sqrt{N(s)}$。简单、有理论（连接 UCB），但大/连续状态空间无法精确计数。
  • 预测误差 / 新颖性：训一个预测器，它预测不准的状态 = 没见过的状态 = 新颖。RND、好奇心都属此类，巧妙地把「新颖性」变成可学的回归误差，绕开了密度估计。
  • 信息增益 / 不确定性：奖励「能最大程度减少模型不确定性」的状态（贝叶斯最优探索的方向）。理论最优但计算昂贵。

内在奖励有个著名陷阱——noisy-TV problem（电视雪花问题）：如果环境里有一个本质随机、无法预测的东西（如一台播放雪花的电视），预测误差类的内在奖励会永远很高（因为雪花永远预测不准），智能体会着迷地盯着它看、再也不去真正探索。这暴露了「预测误差」的缺陷：它分不清「新颖（值得探索）」与「随机（不可预测但无意义）」。好奇心的 ICM 用逆模型、RND 用确定性目标，都是为了缓解这个问题（见下两节）。

3RND：随机网络蒸馏

RND：随机网络蒸馏

RND（随机网络蒸馏，Burda 2018）是预测误差类探索里最优雅、最可扩展的一个。它的巧思在于精心选择『预测什么』，从而天然规避 noisy-TV 问题。机制只有三个部件：

  • 目标网络 $f$（固定、随机）：一个随机初始化后永不训练的网络，把状态映到一个特征向量 $f(s)$。它就是个固定的随机函数。
  • 预测网络 $g_\theta$（训练）：训练它去拟合目标网络的输出，即最小化 $\|g_\theta(s)-f(s)\|^2$。
  • 内在奖励 = 预测误差：$r^{\text{int}}(s)=\|g_\theta(s)-f(s)\|^2$。
\[r^{\text{int}}(s) = \big\| g_\theta(s) - f(s) \big\|^2, \qquad f \text{ 固定随机}, \quad g_\theta \text{ 训练去拟合 } f\]

为什么这能衡量新颖性？因为预测网络只在见过的状态上被训练去匹配 $f$。对访问过很多次的状态，$g_\theta$ 已经学会精确复现 $f(s)$，误差→0（不新颖）；对没见过的新状态，$g_\theta$ 从未在那里被训练、只能瞎猜，误差很大（新颖）。于是预测误差自动反映了状态的『没见过程度』——一个隐式的、连续空间也能用的伪计数。

RND 为什么不怕 noisy-TV？关键在目标 $f$ 是确定性的随机函数（同一个 $s$ 永远给同一个 $f(s)$）。雪花电视的随机性来自环境的随机转移，但 RND 预测的是一个确定函数在当前状态上的值——只要状态本身被见过，$g_\theta$ 就能学准，与环境后续是否随机无关。这把「预测下一状态」（会被环境随机性坑）换成了「预测一个固定函数在当前状态的值」（只看状态新不新），巧妙地把新颖性与环境随机性解耦。这是 RND 在《蒙特祖玛的复仇》等硬探索任务上突破的关键。

还有几个让 RND 实际可用的工程细节值得一提：内在奖励的尺度会随训练整体衰减（所有状态都越来越熟），所以实践中要对内在奖励做running 标准化（除以其运行标准差）以保持稳定的探索压力；状态输入也要标准化（否则目标网在不同尺度的维度上输出失衡）。此外 RND 常把内在奖励当成一个非回合制（non-episodic）的信号——新颖性是关于「这辈子见没见过」而非「这一局见没见过」，这对长期探索更合理。这些细节看似琐碎，却是 RND 从「漂亮想法」变成「真能 work」的关键，再次印证了 RL 里『实现即算法』。

RND 极简（两个小网 + 一个 MSE）却 scalable，是内在动机探索的里程碑。notebook 会让你从零实现 RND，亲眼看到：在见过的状态上内在奖励随训练衰减，在新状态上保持高位——正是探索想要的信号。详见 references 的 Burda 2018；好奇心 ICM 见 Pathak 2017。

4好奇心与其它探索方法

好奇心与其它探索方法

curiosity（好奇心，ICM，Pathak 2017）是另一条预测误差路线，但预测的是自己动作的后果：在一个学到的特征空间里，预测「在 $\phi(s)$ 做动作 $a$ 后的下一特征 $\phi(s')$」，预测误差作内在奖励。它最聪明的设计是用一个逆模型（从 $\phi(s),\phi(s')$ 反推动作 $a$）来学特征 $\phi$——这迫使特征只编码智能体能控制的部分，自动滤掉与控制无关的环境噪声（如背景里飘动的树叶、雪花电视），从特征层面缓解 noisy-TV。

把探索方法谱系理一遍（难度/复杂度递增）：

方法新颖性怎么定义优点局限
ε-贪婪 / 熵不定义，纯随机抖动零成本、够用于密集奖励局部、无方向，稀疏奖励下失效
count-based访问次数少 $1/\sqrt{N(s)}$简单、有 UCB 理论连续/大空间无法精确计数(需伪计数)
RND对固定随机网的预测误差scalable、不怕 noisy-TV需调内在奖励权重；非语义新颖
ICM 好奇心预测自身动作后果的误差逆模型滤无关噪声特征学习更复杂
bootstrapped DQNQ 集成的分歧(后验采样)有原则的深度探索需维护多个 Q 头
Go-Explore先返回有希望的状态再探索攻克极难探索任务需能返回状态(确定性/可存档)

这些方法不是互斥的。实践中常组合：count/RND 提供内在奖励、配合一个强的 RL 算法（PPO/DQN）去优化「外在 + 内在」总奖励。核心 takeaway：探索的本质是『把『没见过』变成一个可优化的奖励信号』——不同方法只是用不同方式（计数、预测误差、不确定性）量化「没见过」，再让标准 RL 去最大化它。看清这一点，所有探索方法都成了同一主题的变奏。

5多智能体 RL：环境里有别的学习者

多智能体 RL：当环境里有别的学习者

MARL（多智能体 RL）研究多个学习中的智能体共处一个环境。它绝不是「单体 RL 跑很多份」那么简单——一个根本性的新难题立刻冒出来：非平稳性。

在单体 RL 里，环境的转移与奖励是固定的（平稳 MDP），所以贝尔曼方程、收敛保证都成立。但在 MARL 里，每个智能体眼中的「环境」包含了其它智能体的策略——而那些智能体也在学习、策略在不断变化。于是从任一智能体的视角看，环境的转移/奖励随时间漂移（non-stationarity），平稳 MDP 假设被打破，单体 RL 的收敛保证统统失效。你以为学到了好策略，结果对手一变，它就不再最优。

MARL 的设定也比单体丰富得多：

  • 合作：所有智能体共享一个目标（如一队机器人协作搬运）。核心难题是信用分配——团队成功了，是谁的功劳？常用范式 CTDE（集中训练、分散执行）：训练时用全局信息、执行时各自只看局部（QMIX、MADDPG）。
  • 竞争：零和博弈（如围棋、星际对抗），一方所得即另一方所失。解概念是Nash equilibrium（纳什均衡）；self-play（自我博弈）是关键武器——与自己的历史版本对战，自动生成难度递增的对手（AlphaGo/AlphaZero 的核心）。
  • 一般和：既非纯合作也非纯竞争（如交通、市场），最复杂，均衡可能多个、可能难求。

一个经典而深刻的小例子：石头剪刀布。没有纯策略最优解（任何确定出法都会被克制），唯一纳什均衡是均匀混合（各 1/3）。有趣的是，让两个无悔学习（no-regret）的智能体互相对打，它们的平均策略会收敛到这个混合纳什——notebook 会让你亲眼验证。这揭示了 MARL 一个美丽的联系：学习动力学与博弈论均衡之间的桥梁。

MARL 的一句话核心：当环境里有别的学习者，环境就不再平稳——你在追一个会还手、会进化的对手。这让单体 RL 的很多保证失效，但也开启了 self-play 这种『自己和自己卷出超人水平』的强大范式（AlphaZero 围棋、OpenAI Five Dota）。CTDE、self-play、均衡求解是 MARL 的三大支柱。

6Decision Transformer：RL 即序列建模

Decision Transformer：RL 即序列建模

前面所有方法（DQN/PPO/SAC/离线/MARL）都围绕值函数或策略梯度。Decision Transformer（DT，Chen 2021）提出一条完全不同的路：把 RL 整个重铸成序列建模，用训语言模型的方式训 RL。

核心想法颠覆直觉。传统 RL 问「在状态 $s$ 下，选什么动作能最大化未来回报？」（一个优化问题）。DT 反过来问——「要达到回报 $R$、在状态 $s$ 下，该输出什么动作？」（一个条件预测问题）。它把轨迹组织成一个序列：

\[\big(\hat R_1, s_1, a_1,\ \hat R_2, s_2, a_2,\ \dots,\ \hat R_t, s_t, a_t\big)\]

其中 $\hat R_t$ 是 return-to-go（剩余回报，从 $t$ 到回合末的回报之和）。用一个 Transformer 自回归地建模这个序列、预测动作 $a_t$——训练就是纯粹的监督学习（预测下一个 token，和 GPT 一模一样），没有自举、没有 TD、没有致命三要素、没有策略梯度的方差。

推理时的魔法在 return-to-go 这个条件 token：你想要多好的表现，就把目标回报当作 prompt 喂进去——「我想拿 100 分」，DT 就生成能拿 100 分的动作序列；「我想拿 50 分」，它就生成 50 分的。每走一步，把已得奖励从目标回报里扣掉、更新 RTG，继续生成。这叫 return-to-go 条件生成，是 DT 把「优化」变成「条件采样」的关键。

直白说

DT 的直觉：把 RL 数据当成一本『行为说明书』——里面记满了「想达到这个回报、在这个情况下，前人是这么做的」。DT 就是在背这本说明书，推理时你说「我要这个回报」，它就翻出对应的做法。学习 = 监督地背说明书；决策 = 按目标回报查说明书。

严谨说

这条路属于 upside-down RL（颠倒的 RL，Schmidhuber 2019）/ RvS 一脉：不学「什么动作最优」，而学「要达到某结果该输出什么」。优点是稳定、简单、可直接用 Transformer 的全部规模红利、天然适合离线（就是从固定轨迹学）。它在离线 RL 上是个强基线，且把 RL 接入了「大序列模型」的浪潮（与 LLM、Gato 等通用智能体相连）。

为什么这条「反过来问」的路能 work？因为它把一个困难的优化问题（在指数级大的策略空间里找最大化回报的策略）换成了一个容易的监督学习问题（拟合『回报+状态→动作』这个映射）。代价是你得在数据里见过对应回报水平的行为——DT 不创造超出数据的策略，它只是把数据里「达到各种回报的做法」组织成一本可按回报查询的说明书。这也直接引出了它的短板。

但 DT 有个已知短板：轨迹拼接（trajectory stitching）能力弱。值方法靠动态规划能把次优轨迹的好片段缝成更优策略（模块 03 讲过）；DT 只是在模仿「条件于回报」的数据，若数据里没有高回报轨迹、只有能拼出高回报的碎片，DT 较难自己拼出来 [Emmons 2021, RvS]。所以 DT 不是值方法的替代品，而是一条各有所长的平行路线——监督学习的稳定简单 vs 动态规划的拼接能力，是它与 CQL/IQL 的根本权衡。

Decision Transformer 是近年 RL 最有影响力的『换范式』工作之一，把 RL 与序列建模/LLM 的世界打通。notebook 会用一个 toy DT 让你验证return-conditioning：条件于高目标回报输出高回报动作、条件于低目标回报输出低回报动作。详见 references 的 Chen 2021、Janner 2021（Trajectory Transformer）、Emmons 2021（RvS，客观看待其边界）。

7把全课串起来：决策的版图

把全课串起来：决策的版图

到这里，C41 的六个模块走完了。退一步看，它们其实是在回答『如何让智能体在与世界（或数据、或彼此）的互动中学会做好决策』这个大问题的不同侧面：

模块解决的核心问题代表方法
01 DQN把值方法搬上神经网络而不发散replay + target + Double/Dueling
02 PPO/SAC稳定、高效地优化策略（含连续控制）clip 信赖域、最大熵 + 双 Q
03 离线 RL不许交互，从固定数据安全学策略BC、CQL 保守、IQL expectile
04 世界模型学一个模型来省真实交互、规划想象MPC、Dyna、Dreamer
05 探索/前沿撞不到奖励怎么办 + 两条新范式RND 内在奖励、MARL、Decision Transformer

把它们放进一张更大的认知地图：值 vs 策略（01 vs 02）是怎么学的两条主干；在线 vs 离线（01/02 vs 03）是能不能交互；无模型 vs 有模型（01–03 vs 04）是要不要学环境；优化 vs 序列建模（01–04 vs DT）是把决策当优化问题还是预测问题。这四条轴，张成了现代决策学习的版图。

而探索（05）则是一条横贯所有轴的暗线——无论你用什么方法，「如何获得有信息量的数据」都是绕不开的根本约束。这也呼应了开篇 C13 赌博机的教诲：探索与利用的张力，从最简单的赌博机一直延伸到最前沿的决策智能体。

学完整门课，你应该获得的不只是一堆算法，而是一套『拆解任何 RL 方法』的坐标系：它是值还是策略？在线还是离线？有模型还是无模型？优化还是序列建模？怎么探索？怎么保证稳定（致命三要素那一关过了吗）？拿到一篇新 RL 论文，用这套坐标系一套，你就能快速定位它在版图的哪个位置、解决了哪个老问题、做了什么新权衡。这种结构化的理解，比记住任何单个算法都更持久、更有迁移力。

8研究前沿与开放问题

研究前沿与开放问题

  • 探索的可扩展性与语义：RND/好奇心驱动的是『没见过』的探索，但人类探索是有目的、有语义的（去厨房找吃的，而非随机推开每扇门）。如何让探索由目标/语言/常识引导，而非纯新颖性，是大方向（与 LLM 结合的『语言引导探索』正在兴起）。
  • MARL 的可扩展与稳定：智能体数目一多，非平稳与信用分配急剧恶化；大规模合作（群体智能）、开放式多智能体（对手不断进化）仍缺乏稳健方法。emergent communication、population-based training 是活跃前沿。
  • 序列建模 RL 的边界：DT 把 RL 接入大模型，但拼接弱、对回报条件的可靠性、能否真正『规划』而非『记忆』都有争议。Trajectory Transformer、Gato、以及把 RL 与 LLM 融合（RLHF 反过来用 RL 思路）是热点。
  • 通用决策智能体：能否像 LLM 一样，用海量离线决策数据 + 序列建模训出一个通用的决策模型（一个策略玩几百个任务）？Gato、DreamerV3、Decision Transformer 都是尝试，但离『决策的 GPT 时刻』还有距离。
  • RL 与基础模型的双向融合：一方面 RL 用来对齐 LLM（RLHF/RLAIF，见 C22）；另一方面 LLM 的世界知识/推理能力用来给 RL 提供奖励、探索方向、子目标。两个领域正在深度交汇，可能孕育下一代智能体。
