1离线 RL：不许试错，只给一份数据

到目前为止（模块 01/02），所有算法都能与环境交互：DQN 用 $\varepsilon$-贪婪边探索边学、PPO/SAC 不断采新轨迹。但现实里有一大类问题根本不许试错：训一个医疗决策策略，你不能拿真实病人做 $\varepsilon$-贪婪实验；训自动驾驶，你不能让车随机打方向看会不会撞。你手里只有一份别人采好的、固定的历史数据集，必须从它里面榨出一个尽可能好的策略，而且训练全程不许再碰环境。这就是offline RL（离线 / 批量 RL）。

听起来像监督学习——给定数据、学个函数。但它远比监督学习凶险，凶险全在一个词：distribution shift（分布偏移）。监督学习里训练分布≈测试分布，学到的函数只在见过的数据附近用。而 RL 的目标是找一个比数据更好的策略——这个更好的策略必然想做一些数据里没怎么出现过的动作（否则它不会比采数据的策略更好）。一旦它这么做，你就进入了数据没覆盖的区域，而在那里你的值估计无从校验。

更糟的是 Q-learning 的 $\max_{a'}$ 会主动追逐这些没覆盖的动作。回忆模块 01 的过估计：$\max$ 偏爱被高估的动作。在线时这无所谓——你会去试它、收到真实回报、被纠正；但离线时你永远不会去试，那个高估的幻觉值就一直留在目标里、被自举不断放大，最终让整个 Q 函数崩坏、策略追着幻觉走向灾难。这是离线 RL 的头号杀手，本模块的三个算法（BC、CQL、IQL）都是来对付它的。

离线 RL 的核心矛盾

一句话点破离线 RL 的核心矛盾：你想要的「比数据更好的策略」，恰恰要求它偏离数据；而偏离数据，正是值估计失控的根源。所以离线 RL 的全部艺术，是在「改进」与「别走太远」之间走钢丝——要么约束策略别离行为策略太远（policy constraint），要么让值函数对没覆盖的动作保守（CQL），要么干脆不查询没覆盖的动作（IQL）。三条路，本模块各走一遍。

2分布偏移与外推误差：把杀手看清楚

分布偏移与外推误差：把杀手看清楚

把杀手拆成两个互相咬合的概念。distribution shift：学到的策略 $\pi$ 想访问的状态-动作分布，偏离了数据集里behavior policy $\pi_\beta$ 的分布。extrapolation error：在数据没覆盖的 $(s,a)$ 上，Q 网络只能外推，而那里没有任何真实回报来纠正它——网络爱报什么是什么。

两者的恶性循环是这样转起来的：

① 网络在 OOD 动作 (s,a_ood) 上随意外推 -> 偶然给出高 Q │ ▼ ② Q-learning 目标 y = r + γ·max_a' Q(s',a') 的 max 专挑这个高估 │ ▼ ③ 回归把 Q(s,·) 拉向这个虚高目标；策略 argmax 也开始偏爱 a_ood │ ▼ ④ 离线！永远不会真去执行 a_ood、收不到现实反驳 -> 高估永不修正 │ └──────► 自举把幻觉值越滚越大 -> Q 崩坏、策略追着幻觉走

注意第④步是离线特有的死结。在线 RL 里这个循环会自愈：策略一旦偏爱 $a_{\text{ood}}$ 就会去执行它，环境立刻用真实的低回报打脸，高估被拉回。离线 RL 抽掉了「去执行、被打脸」这一环，于是循环失去了唯一的纠错机制，只能任由幻觉发酵。你会在 notebook 里亲眼看到：给一个 OOD 动作初始化一个虚高的 Q，朴素离线 FQI 不但不修正它，还让它把周围所有状态的 Q 都顶起来。

为什么不能「只在数据覆盖的 $(s,a)$ 上更新、对 OOD 视而不见」就完事？因为麻烦不在更新哪些 $(s,a)$，而在目标里的 $\max_{a'}$ 要『查询』哪些 $(s',a')$。即使你只对数据内的 $(s,a)$ 做回归，那条 TD 目标 $r+\gamma\max_{a'}Q(s',a')$ 仍然枚举了 $s'$ 下的所有动作——包括 OOD 的。只要其中一个被外推得虚高，$\max$ 就会选它，污染就从「查询」这一步渗进来。这正是为什么后面 IQL 的核心妙招是把目标里的 $\max$ 换成一个『只看数据内动作』的近似——从源头掐断 OOD 进入目标的通道。看清「污染从 $\max$ 的查询进来」，是理解三种解药的关键。

一个关键澄清：离线 RL 的难不在「数据少」，而在「数据的分布」。即便给你海量数据，只要它来自一个固定的行为策略、没覆盖你想要的好动作，分布偏移依旧致命。反过来，数据覆盖得好（行为策略足够多样、探索充分）时，离线 RL 会容易很多。所以离线 RL 论文里数据集分 random/medium/expert/混合等质量等级（见 D4RL），不同覆盖度下算法表现天差地别。

3最朴素的基线：行为克隆 BC

最朴素的基线：行为克隆（BC）

既然偏离数据这么危险，最保守的做法就是干脆不偏离——直接模仿数据里的动作。这就是behavior cloning（行为克隆，BC）：把离线数据当监督学习，训一个策略 $\pi(a|s)$ 去拟合数据中 $(s,a)$ 对的动作映射。

\[\mathcal{L}_{\text{BC}}(\theta) = -\mathbb{E}_{(s,a)\sim\mathcal{D}}\big[\log \pi_\theta(a|s)\big]\]

BC 的优点是极致的简单与稳健：没有自举、没有 $\max$、没有分布偏移——它只在数据覆盖的地方做预测，与普通分类/回归无异。如果你的数据来自一个专家（如人类司机的优质驾驶记录），BC 往往是个出奇强的基线，甚至能打败设计复杂的离线 RL 算法——这也是为什么任何离线 RL 论文都必须把 BC 列为对照。

但 BC 有两个根本天花板：

  • 无法超过示范者：BC 的目标就是复刻数据里的行为，所以它的水平上限就是采数据那个策略的平均水平。数据是中等水平，BC 就是中等；它学不会「比老师更好」。
  • 不会拼接（no stitching）：假设数据里有两条次优轨迹——A 把你从起点带到中点、B 把你从中点带到终点，但没有一条完整的好轨迹。一个会「trajectory stitching（轨迹拼接）」的值方法能把 A 的前半 + B 的后半缝成一条最优路径；BC 不会，它只会模仿见过的整条（次优）轨迹。

这两个天花板正是值方法（CQL/IQL）相对 BC 的价值所在：它们通过学 Q/V 做动态规划，能够从次优数据里组合出超越数据的策略——代价是要直面分布偏移。所以离线 RL 的真正战场，是「如何既享受值方法的拼接能力、又不被分布偏移反噬」。下面两节就是两种答卷。

记住这个对照：BC 安全但平庸（学不会超过数据），值方法强大但危险（能拼接出更优策略，但会被 OOD 高估反噬）。离线 RL 的 CQL/IQL，本质都是「给值方法装上对付 OOD 的安全阀，让它在不崩的前提下保留拼接能力」。notebook 会让你看到：在需要拼接的数据上，朴素值方法崩、BC 平庸、而 CQL/IQL 既不崩又超过 BC。

4CQL：保守 Q 学习

CQL：保守 Q 学习

CQL（保守 Q 学习，Kumar 2020）的思路直击要害：既然问题是 OOD 动作的 Q 被高估，那就在训练时主动把它们压低。具体地，在标准 TD 损失之外，加一个保守正则项——压低所有动作的 Q（尤其网络想抬高的那些），同时抬高数据里真实出现过的动作的 Q：

\[\mathcal{L}_{\text{CQL}} = \underbrace{\mathbb{E}\big[(Q_\theta(s,a)-y)^2\big]}_{\text{标准 TD}} + \alpha\,\underbrace{\mathbb{E}_s\Big[\log\!\sum_{a'} e^{Q_\theta(s,a')} - \mathbb{E}_{a\sim\mathcal{D}}\,Q_\theta(s,a)\Big]}_{\text{保守正则}}\]

拆解那个保守项。$\log\sum_{a'}e^{Q(s,a')}$ 是 LogSumExp，一个软的 $\max$——它对当前 Q 最高的动作（往往正是被高估的 OOD 动作）施加最大的下压力；减去 $\mathbb E_{a\sim\mathcal D}Q(s,a)$（数据内动作的 Q）则把数据覆盖的动作往上托。两者相减、乘以权重 $\alpha$ 一起最小化，效果就是：

  • OOD 动作的 Q 被系统性压低（它们贡献了大部分 LogSumExp，却不在数据里被托起来）；
  • 数据内动作的 Q 被相对抬高（被第二项保护）；
  • 于是 $\max_{a'}Q$ 不再追逐 OOD 幻觉——它们的 Q 已经被压到数据内动作之下了。

CQL 可以证明它学到的是真实 $Q^\pi$ 的一个下界（lower bound）：宁可保守地低估，也不冒进地高估。这正是离线 RL 想要的安全性——低估顶多让你错过一些好动作（保守），高估却会让你追逐灾难性的幻觉动作。$\alpha$ 控制保守程度：太小压不住 OOD、太大则过度保守、退化得接近 BC。它是 CQL 最重要的超参。

直白说

CQL 的直觉像给一个爱吹牛的估值师套上『对没见过的东西一律往低了报』的纪律：凡是数据里没真正成交过的动作，它的估值都被主动调低；只有数据里反复出现、有据可查的动作，估值才被保住。于是『挑估值最高的动作』时，那些靠吹牛(外推)虚高的 OOD 动作早被压下去了。

严谨说

形式上，CQL 在 $\mathbb E_s[\log\sum_{a'}e^{Q(s,a')} - \mathbb E_{a\sim\mathcal D}Q(s,a)]$ 上最小化：第一项 LogSumExp 是软 $\max$，对当前 Q 最高的动作梯度最大(压得最狠)；第二项保护数据内动作。可证它给出 $Q^\pi$ 的一个下界，且 $\alpha$ 越大下界越保守。这是『悲观面对不确定』在值函数上的精确实现。

从数据流的角度看 CQL 的精妙：它不改变标准 TD 的结构（还是 $\max$ 自举），而是额外塑形 Q 地形，让 OOD 动作在被 $\max$ 选中之前就已经被压到谷底。换句话说，CQL 承认「$\max$ 会去查 OOD」这件事改不了，于是提前把 OOD 的坑填平——等 $\max$ 去查时，那些 OOD 动作的 Q 已经低于数据内动作，自然不会被选。这与 IQL「干脆不让 $\max$ 查 OOD」是两种哲学：CQL 改造地形、IQL 改造查询。两者都能让最终的 $\arg\max$ 落在数据支撑内，殊途同归。

CQL 是离线 RL 最有影响力的算法之一，思想可加在任何基于 Q 的方法（DQN/SAC）上，只需多一个正则项。notebook 会让你亲手实现这个保守惩罚，并验证它把一个虚高的 OOD 动作 Q 从 +5 压到负值。详见 references 的 Kumar 2020。

5IQL：隐式 Q 学习（不查 OOD）

IQL：隐式 Q 学习（连 OOD 都不查询）

CQL 是「查询 OOD 动作、但惩罚它们」。IQL（隐式 Q 学习，Kostrikov 2021）更釜底抽薪：压根不查询 OOD 动作的 Q。它的洞察是——离线 RL 的麻烦全来自目标里那个 $\max_{a'}Q(s',a')$（要枚举包括 OOD 在内的所有动作）。如果能只用数据里出现过的动作来近似这个 $\max$，OOD 问题就从源头消失了。

IQL 用expectile regression（expectile 回归）实现这一点。expectile 是分位数的「平方损失版」——一个非对称的 L2 损失，权重 $\tau$ 偏向高估侧：

\[L_2^\tau(u) = |\tau - \mathbb{1}(u<0)|\cdot u^2, \qquad u = \text{target} - \text{pred}\]

当 $\tau\to1$ 时，expectile 回归的解逼近被拟合那组数的最大值（而 $\tau=0.5$ 退化为普通均值回归）。IQL 用一个高 $\tau$（如 0.7~0.9）的 expectile 来学状态值 $V(s)$，使 $V(s)$ 近似数据内动作中的最大 $Q$——这就在不显式枚举任何动作（更不碰 OOD）的前提下，得到了一个「数据内的最优」估计。Q 与 V 的训练相互配合：

IQL 的三步做什么为什么避开 OOD
① 学 $V$（expectile）$V(s)\leftarrow$ 高-$\tau$ expectile 回归拟合 $Q(s,a_{\text{data}})$只用数据内动作 $a_{\text{data}}$，$\tau\to1$ 近似其中的 max
② 学 $Q$（标准 TD）$Q(s,a)\leftarrow r+\gamma V(s')$目标用 $V(s')$ 而非 $\max_a Q(s',a)$——没有 max、没有 OOD 查询
③ 抽策略（AWR）优势加权回归 $\exp(A/\beta)$ 加权的 BC在数据动作上做加权模仿，永不输出 OOD 动作

为什么 expectile 能在「只看数据内动作」时近似 max？直觉是：普通均值回归（$\tau=0.5$）会被低值样本拉低，得到的是数据内动作的平均 Q；而把 $\tau$ 调高（偏向高估侧），损失对「目标高于预测」的样本惩罚更重、对「目标低于预测」的样本惩罚更轻，于是拟合出的 $V$ 被往上推、贴近那批数据内动作里最高的那个 Q。$\tau\to1$ 时它就逼近这批值的最大值——但全程只用到了数据里真实出现的动作的 Q，从未枚举、更未查询任何 OOD 动作。这就是 IQL 的核心戏法：用一个回归的非对称性，换来了「数据内的 max」而不付「查询 OOD」的代价。

第③步的advantage-weighted regression（AWR/AWAC）很巧妙：它是一个加权的行为克隆——多模仿那些优势 $A(s,a)=Q(s,a)-V(s)$ 高的数据动作、少模仿优势低的。这样抽出的策略天然只在数据支撑内（它只会输出数据里见过的动作），却因为偏向高优势动作而超过了无差别模仿的 BC。整个 IQL 因此完全不查询任何 OOD 动作的 Q——分布偏移被结构性地绕开，而非像 CQL 那样事后惩罚。这让 IQL 实现简单、超参不敏感，是当今离线 RL 的强基线。

CQL vs IQL 的一句话区别：CQL「看了 OOD 动作但把它们打压下去」；IQL「干脆不看 OOD 动作，用 expectile 在数据内偷偷近似 max」。两条路殊途同归——都让最终策略待在数据支撑内，从而避开外推误差。notebook 会让你实现 expectile 回归，看它如何随 $\tau\to1$ 从均值滑向最大值。

6三种方法的统一视角与权衡

三种方法的统一视角与权衡

把本模块三种方法（加上提过的 policy constraint 一类）放进一张图，会看到它们都在回答同一个问题——如何让最终策略不偏离数据支撑太远，只是切入点不同：

方法怎么对付分布偏移优点代价 / 风险
BC 行为克隆完全不偏离（直接模仿）极简、稳健、专家数据下很强学不会超过数据、不会拼接
policy constraint（BCQ/TD3+BC）显式约束 $\pi$ 接近 $\pi_\beta$（KL/BC 正则）直觉直接、可加在任何 actor 上约束强度难调；约束太紧≈BC
CQL 保守 Q惩罚/压低 OOD 动作的 Q（学下界）强、思想通用、可加于 DQN/SAC$\alpha$ 难调；过度保守损性能
IQL 隐式 Q用 expectile 在数据内近似 max，不查 OOD实现简单、超参稳健、强基线expectile $\tau$ 需调；拼接能力略弱于显式 DP

选型经验：数据接近专家 → BC 或 IQL（简单够用）；数据是混合/次优、需要拼接 → CQL 或 IQL（值方法的拼接力）；想要最稳的强基线、不想精调超参 → IQL 常是首选。这些方法也并非互斥——TD3+BC 就是「值方法 + BC 约束」的极简组合，说明「别离数据太远」这一条原则可以用各种方式注入。

还有一条实践上极重要却常被忽略的轴：策略约束 vs 值正则的施加位置不同。policy constraint（如 TD3+BC）把约束加在策略上（直接拉策略靠近 $\pi_\beta$）；CQL 把约束加在值函数上（塑形 Q）；IQL 则把约束内建进训练目标的结构（用 expectile + AWR 让 OOD 无从进入）。施加位置越靠「下游」（越接近最终策略），通常越直接但越粗暴；越靠「上游」（改训练目标本身），通常越优雅但越需要想清楚机制。理解这条轴，你能预测一个新离线算法大概会有什么样的优缺点。

一个更深的统一视角：离线 RL 的所有方法，本质都是在原始 RL 目标上加一个「悲观」或「保守」的偏置——对不确定（没覆盖）的地方假设最坏而非最好。这与在线 RL 的探索哲学（对不确定的地方乐观、去试试看）恰好相反。在线乐观探索、离线悲观保守——因为在线能用试错纠错，离线不能。把这条对立轴记住，你就抓住了离线 RL 区别于在线 RL 的灵魂。

7离线到在线，与实践要点

离线到在线，与实践要点

纯离线之外，还有几个重要的实践变体与衔接，值得知道：

  • offline-to-online 微调：先离线学一个不错的策略（省真实交互），再放到环境里少量在线微调突破数据天花板。是工业界常用的折中——离线打底、在线冲顶。
  • 数据集质量决定一切：同一算法在 expert 数据上可能完胜、在 random 数据上可能完败。报告离线结果必须带数据集质量（D4RL 的分层就是为此）。
  • 评估的难题：离线训练时没有环境可测真实回报，怎么知道哪个 checkpoint 好？off-policy evaluation（OPE）是个独立的难问题——这也是为什么离线 RL 落地比看起来难。
  • 序列建模路线：Decision Transformer（模块 05）把离线 RL 重铸成「给定目标回报的序列预测」，是完全不同的一条技术路线，用监督学习绕开了 Q 学习的分布偏移（但也牺牲了部分拼接能力）。

把本模块放进全课地图：模块 01/02 是在线深度 RL（能交互），本模块是纯离线（不能交互）。下一模块（基于模型）则从另一个角度省真实交互——学一个模型来代替真实环境，在模型里规划/想象。离线 RL 与基于模型 RL 常常结合（如在离线数据上学模型、再在模型里保守地规划，如 MOPO/COMBO），是当前样本高效 RL 的两大支柱。

最后一个实践提醒：离线 RL 的论文分数对实现细节、归一化、数据预处理极度敏感（和 PPO 一样，见模块 02）。同一个 CQL/IQL，不同代码库的分数能差很多。所以读离线 RL 结果时，比起「哪个算法分高」，更该关注「它在什么数据质量、用了哪些技巧、评估是否可信」。本课的 toy 实现重在让你看懂机制，真实分数请以标准库（CORL、d3rlpy）为准。

8研究前沿与开放问题

研究前沿与开放问题

  • 悲观的正确剂量：CQL 的 $\alpha$、IQL 的 $\tau$ 都在调「多保守」。太保守损性能、太冒进崩坏，最优点依数据质量而变，且没有可靠的离线方法来选它（因为不能在线验证）。自适应保守度是开放课题。
  • 离线 RL 的评估（OPE）：不与环境交互如何可信地估计一个策略的回报？重要性采样类、模型类、FQE 各有偏差与方差问题。没有好的 OPE，离线 RL 的模型选择就是盲选。
  • 数据覆盖的理论刻画：到底需要怎样的数据覆盖（concentrability）才能保证离线 RL 学到近优策略？理论界有一系列 coverage 假设与下界，但与实践的差距仍大。
  • 离线 + 基于模型：在离线数据上学动态模型、再保守地在模型里规划（MOPO、COMBO），把模型的样本效率与离线的安全结合，是当前 SOTA 方向之一。
  • 大规模与基础模型化：把海量离线轨迹当成「决策的预训练语料」，训通用决策模型（Decision Transformer、Gato 一脉）。RL 能否像 LLM 那样靠规模 + 离线数据涌现通用能力，是激动人心的开放问题。
