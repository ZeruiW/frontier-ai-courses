1为什么 Transformer 时代还学经典架构

欢迎来到 经典神经网络架构。先回答一个你可能正想问的问题：都 Transformer 时代了，为什么还要回头学卷积和 RNN？

三个理由。第一，它们没有过时，只是退到了幕后：卷积仍是视觉、音频、生物序列的主力，RNN/GRU 仍活跃在流式、低延迟、边缘设备的场景；连 Transformer 自己也在不断「回收」这些老架构的零件（卷积 stem、状态空间模型 SSM 对 RNN 的复兴）。第二，也是本课最看重的——Transformer 不是凭空出现的，它是这条脉络的集大成。残差连接来自 ResNet（模块 02）、层归一化来自 RNN 时代（模块 02/04）、注意力来自 seq2seq（模块 05）。C1 课程直接从注意力讲起，跳过了这条历史主线；可不补这条线，你会把 Transformer 的每个设计都当成「天降神谕」死记，而不是理解它在治什么病、继承了谁。第三，这些经典架构是学习「归纳偏置」最好的教材：每一种结构都是对数据某种先验的硬编码，理解这一点，你看任何新架构都会先问「它假设了什么」。

一句话定位本课：它是 Transformer 的「前传」。学完你会带着一整套零件走进 C1——「哦，自注意力就是模块 05 那个注意力的自指版；残差和 LayerNorm 是模块 02 的老朋友；自回归解码是模块 05 seq2seq 的解码循环」。没有这套零件，Transformer 是一座空中楼阁；有了它，Transformer 不过是把熟悉的积木换了种搭法。

方法论上，本课只有一条铁律：不调库，从零写，对拍正确。每个算子——卷积的前向反向、池化、残差块、BPTT、LSTM 的门、Bahdanau 注意力——我们都用 numpy 亲手实现，再用一个绝对可信的参考（朴素双重实现、scipy.signal、或数值梯度）把它对拍到 1e-10。这套纪律的价值在第 4 节展开；先记住：这门课的深度，全在「亲手写对」这四个字里。

2两大家族：空间 vs 时序

两大家族：空间 vs 时序

Transformer 之前的深度学习，主要是两条平行的故事线，各自回应一类数据的结构：

维度CNN 家族（空间）RNN 家族（时序）
处理什么网格数据：图像、音频谱、棋盘序列数据：文本、语音、时间序列
核心假设（归纳偏置）局部性 + 平移等变（邻近像素相关、模式可在任意位置出现）时序因果 + 参数随时间共享（当前依赖历史、规则不随时刻变）
参数怎么共享卷积核在所有空间位置复用同一组权重在所有时间步复用
奠基结构卷积 + 池化（LeNet→AlexNet→VGG→ResNet）循环 cell（RNN→LSTM/GRU）
致命弱点感受野有限、难建模长程全局关系梯度消失、难学长依赖、必须串行
本课模块01（卷积/池化）、02（CNN 演化）03（RNN/BPTT）、04（LSTM/GRU）

两条线在模块 05 交汇：seq2seq 先用 RNN 搭起「读一个序列、写另一个序列」的框架，却卡在「定长瓶颈」上；注意力为打破这个瓶颈而生——而注意力，正是 Transformer 的核心。所以本课的结构不是六个孤立专题，而是两条家族线最终汇入注意力这条大河，下一站就是 C1 的 Transformer。

记住这张对照表，本课每个模块都在填它的某一格。尤其记住「归纳偏置」这一行——它是贯穿全课的主线索：卷积把「局部 + 平移等变」写进结构，RNN 把「时序 + 时间共享」写进结构。结构与数据的先验越契合，需要的样本就越少。看任何架构（包括 Transformer）都先问这一句：它对数据做了什么假设？

课程地图：从卷积到注意力

两大家族 → 汇入注意力 → 通向 Transformer（C1） 空间线（CNN） 时序线（RNN） ─────────── ─────────── 模块 01 卷积与池化 模块 03 RNN 与 BPTT │ 互相关/感受野/参数共享 │ 循环 cell / 时间展开 │ conv2d 前向+反向(对拍 scipy) │ BPTT 推导 / 梯度消失爆炸 ▼ ▼ 模块 02 CNN 架构演化 模块 04 LSTM 与 GRU │ LeNet→AlexNet→VGG→ResNet │ 门控 / cell state │ 残差连接 / BN / 1x1 │ 梯度高速公路 / 长依赖 │ │ └──────────────┬─────────────────────┘ ▼ 模块 05 seq2seq 与注意力 encoder-decoder / 定长瓶颈 Bahdanau/Luong 注意力 / 对齐 │ ▼ ★ Transformer（C1 课程）★ 自注意力 + 残差 + LayerNorm

这张图里藏着本课的两条暗线。第一条是残差/归一化的传承：模块 02 的残差连接与 BatchNorm/LayerNorm，会在 C1 的 Transformer 里原样出现——届时你会认出它们是老朋友。第二条是注意力的诞生逻辑：它不是凭空设计的，而是模块 05 里 seq2seq 撞上「定长瓶颈」后，被逼出来的解药。理解了「注意力在解决什么问题」，你才真正懂 Transformer 为什么长那样。

每一站都对应一个可独立验证的能力：模块 01 你手写的 conv2d 会与 scipy.signal.correlate2d 逐位一致；模块 02 你能算出任意 CNN 的参数量与感受野、并让残差块的反向通过数值梯度检验；模块 03 你的 BPTT 会与数值梯度对拍一致、并能复现梯度消失的指数衰减曲线；模块 04 你的 LSTM/GRU cell 会对拍通过、并在长依赖任务上跑赢朴素 RNN；模块 05 你拼出的 seq2seq+注意力会在「复制/反转」玩具任务上学会、对齐矩阵会显出清晰的对角线。每一步都有 assert 兜底。

4方法论：从零写、对拍正确

方法论：为什么从零写、对拍正确

市面上学这些架构，多数是 nn.Conv2d、nn.LSTM 调一调、看 loss 降下来就算「学会了」。本课刻意反其道——每个算子都从零用 numpy 写出来，再和一个可信参考对拍。为什么值得这么麻烦？

因为调库会制造一种「我懂了」的幻觉。你能跑通 nn.LSTM，不代表你说得清遗忘门的梯度怎么流、为什么 cell state 能缓解梯度消失。而当你被迫亲手写出 backward、并让它通过数值梯度检验时，任何含糊的理解都会暴露成一个过不了的 assert。「能从零写对」是检验「真懂」的唯一硬标准——这正是研究科学家与调包侠的分界线。

直白说

我们把每个机制翻译成 numpy 里看得见的东西：卷积是一组滑窗循环，池化是窗口取最值/均值，BPTT 是沿时间倒着累加梯度，注意力是一次打分 + softmax + 加权求和。你写的是机制本身，不是性能。

严谨说

关键纪律是对拍（differential testing）与数值梯度检验。前向有解析参考的（卷积、池化）就和 scipy 或朴素双实现比 np.allclose(..., atol=1e-10)；反向没有现成参考的（BPTT、LSTM、注意力）就用有限差分 (f(x+ε)-f(x-ε))/(2ε) 当 ground truth，要求相对误差 < 1e-5。结构正确 → 数值一致 → 逻辑可迁移到任何框架。

机制本课的 numpy 实现对拍/验证方式对应框架
卷积前向滑窗互相关（四重循环 / im2col）scipy.signal.correlate2dnn.Conv2d
卷积反向对输入/核分别推导梯度数值梯度检验autograd
池化窗口 max/avg + argmax 路由朴素双实现互验nn.MaxPool2d
BPTT时间展开 + 倒序累加共享权重梯度数值梯度检验autograd over nn.RNN
LSTM/GRU逐门前向 + 链式反向数值梯度检验nn.LSTM / nn.GRU
注意力打分 → softmax → 加权和朴素实现 + 对齐可视化nn.MultiheadAttention

务必清楚本课不追求什么：不追求训练大模型、不追求 SOTA 指标、不追求 GPU 速度。这些在你理解了机制之后都是工程问题（换框架、加数据、上 GPU）。本课负责把机制与正确性这块地基夯死——这一步扎实了，调库才不是黑箱、读论文才不费劲、改架构才有底气。

5环境与运行

环境与运行

环境极简：numpy 必需，scipy（模块 01 对拍卷积）与 scikit-learn（加载 optdigits 真实数字）强烈建议，matplotlib 可选（画特征图/对齐矩阵）。全课 CPU 秒级运行，无需 GPU。

conda create -n classic-nn python=3.11 -y && conda activate classic-nn
pip install numpy scipy scikit-learn   # 必需 + 强烈建议
pip install matplotlib                  # 可选：画特征图 / 对齐矩阵
jupyter lab

每个模块配一个 notebook，结构统一（对标全站 house style）：先用 numpy 把机制从零实现并对拍（5–6 个 worked 小节，每节都跑出可打印的验证与 assert），再做 3–4 道带 assert 判分的 ✏️ 练习（先给骨架，自己填，紧跟自测，再对照 📖 参考答案），最后一个真实数据胶囊（用 optdigits 真实手写数字或真实模型配置跑一遍，把机制接到现实，含 TODO+assert+答案三件套）。

建议节奏：先读完整章 HTML 建立直觉与理论框架，再打开 notebook 亲手实现。读和做缺一不可——只读会觉得「好像懂了」，真正动手写滑窗、推反向、调维度、让 assert 通过时，才会发现魔鬼藏在哪些细节里（卷积的核翻转、BPTT 的梯度累加、softmax 的数值稳定、注意力的维度对齐）。这门课的深度正是为「动手」服务的。

配套先读：花书第 9（CNN）、10（RNN）章当理论字典；colah 的《Understanding LSTM Networks》建立门控直觉；Karpathy《The Unreasonable Effectiveness of RNNs》当 RNN 热身。脉络的终点是 Vaswani 2017《Attention Is All You Need》——学完本课再读它会格外通透。完整清单见 references.md。

✅ 学完整门课，你应该能：
  1. 解释卷积的局部性/参数共享/平移等变，从零写出 conv2d 前向与反向并对拍 scipy；
  2. 算任意 CNN 的参数量与感受野，讲清残差连接为何能堆深、BN 在训练/推理为何不同；
  3. 推导 BPTT，从零实现并通过数值梯度检验，复现并解释梯度消失/爆炸；
  4. 从零实现 LSTM/GRU 的门控前向与反向，讲清 cell state 为何是「梯度高速公路」；
  5. 搭出 seq2seq + Bahdanau 注意力，在玩具任务上训练、画出对齐矩阵、做贪心解码；
  6. 把上述零件对应到 Transformer，带着「这些我都从零写过」的底气走进 C1。
