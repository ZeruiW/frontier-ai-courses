1演化总览：CNN 为什么越做越深

上一模块我们从零造出了卷积与池化这两块积木。这一模块要回答一个看似简单、实则贯穿整个深度学习史的问题：有了卷积和池化，该怎么把它们堆成一个能用的网络？答案不是一蹴而就的，而是 1998 到 2015 这十几年里，被 ImageNet 的压力一步步逼出来的——从 LeNet 的 7 层到 ResNet 的 152 层，每一次跃迁背后都有一个具体要解决的病。读懂这条演化线，比记住任何单个网络的结构都重要。

一句话概括这条主线：CNN 的进化史，就是一部「如何把网络做得更深而不崩」的历史。为什么执着于深？因为深度是表达力的来源——浅网络只能拼出简单特征的线性组合，深网络才能逐层地把边缘→纹理→部件→物体这条抽象阶梯搭起来（这正是上一模块感受野逐层扩大的语义版本）。可是「深」本身会带来三个拦路虎：参数爆炸、过拟合、以及最致命的——梯度在深层网络里消失或爆炸，让网络根本训不动。本模块的五个主角，每一个都是在拆掉其中一两个拦路虎。

网络年份深度（约）关键创新拆掉了哪个拦路虎
LeNet-519987 层卷积+池化+全连接的范式奠基：证明端到端可学
AlexNet20128 层ReLU、dropout、GPU、数据增强过拟合 + 训练效率
VGG201416/19 层全用 3×3 小卷积堆叠参数效率 + 深度
GoogLeNet201422 层Inception 多尺度 + 1×1 降维算力 + 多尺度
ResNet2015152 层残差连接 F(x)+x梯度消失 / 退化

把本模块当成一条「治病史」来读：LeNet 立下框架，AlexNet 用 ReLU/dropout 治过拟合与慢训练，VGG 用小核堆叠治参数效率，ResNet 用残差连接治深网络的梯度消失与退化。记住每个创新治的是什么病，你就不会把它们当成孤立的 trick，而能在自己设计网络时对症下药。

还有一条暗线值得现在就点破：ResNet 的残差连接，后来原样变成了 Transformer 的标配。本模块第 4 节会讲清残差连接为何能让梯度「直通」深层——这套机制在 C1 的 Transformer 里会再次出现（每个子层都是 x + Sublayer(x)）。同理第 5 节的归一化思想也会延续到 LayerNorm。所以这一模块不只是「CNN 的历史」，更是在为读懂 Transformer 攒零件。

2LeNet → AlexNet：范式与复兴

LeNet-5（LeCun 1998）是第一个真正意义上的卷积网络：两层 卷积+池化 提特征，再接三层全连接做分类，端到端用梯度下降训练识别手写数字。它的结构今天看朴素得可爱，但「卷积层堆叠提特征 + 全连接头分类」这个范式，统治了之后近二十年的视觉网络设计。

然后是十四年的沉寂——直到 2012 年的 AlexNet（Krizhevsky、Sutskever、Hinton）在 ImageNet 上把错误率近乎腰斩，引爆了整个深度学习的复兴。AlexNet 的结构其实就是加大加深版的 LeNet，但它系统性地引入了几样后来成为标配的东西：

  • ReLU 激活：用 max(0,x) 替代 sigmoid/tanh。正区间导数恒为 1，不像 sigmoid 两端饱和导致梯度消失，让深网络的训练快了数倍——这是「能把网络做深」的第一块拼图。
  • Dropout：训练时随机「丢弃」一部分神经元，逼网络不依赖任何单个特征，是对付大网络过拟合的强力正则。
  • GPU 训练：把卷积的海量并行交给 GPU，让训练大网络在时间上变得可行（这正是 C36 那门课的主题）。
  • 数据增强：随机裁剪、翻转、颜色扰动，用变换凭空造出更多训练样本，进一步压过拟合。

直白说

LeNet 证明了卷积网络能学；AlexNet 证明了只要够大、够深、有足够数据和算力，再配上 ReLU 和 dropout，卷积网络能学得非常好。从 LeNet 到 AlexNet，结构没有质变，是「规模 + 几个关键 trick」的胜利。

严谨说

形式上最关键的改变是激活函数。sigmoid 的导数 σ'(x)=σ(1-σ) 最大只有 0.25，且两端趋于 0；多层连乘后梯度指数衰减。ReLU 在正区间导数为 1，梯度可以无衰减地穿过任意多层（负区间为 0，带来稀疏性）。这是用激活函数的选择来缓解梯度消失——和后面残差连接是同一个母题的不同手法。

一个常被忽略的点：AlexNet 的成功不全是结构功劳，很大程度上是 ImageNet（120 万张标注图）这个数据规模与 GPU 算力同时就位的结果。深度学习的每一次跃迁，几乎都是结构 + 数据 + 算力三者共振，而非单一结构的天才设计。这个教训在大模型时代依然成立。

3VGG：3×3 小核堆叠的智慧

VGG（Simonyan & Zisserman 2014）把网络的设计哲学推向了极简与规整：抛弃 AlexNet 里 11×11、5×5 等花式大卷积核，整个网络只用 3×3 卷积（外加 2×2 池化），靠不断堆叠把深度做到 16 甚至 19 层。这个看似保守的选择，背后是一个漂亮的洞察。

3.1 为什么两个 3×3 胜过一个 5×5

核心论点是：堆叠多个小卷积，能用更少的参数获得与大卷积相同的感受野，还多了几层非线性。先看感受野——两个 3×3 卷积层叠加，第二层每个输出看到第一层的 3×3 区域，而第一层每个位置又看到输入的 3×3，所以第二层的输出实际覆盖输入的 5×5 区域：

\[\underbrace{3\times3 \;\to\; 3\times3}_{\text{两层}} \;\equiv\; \text{感受野 } 5\times5, \qquad \underbrace{3\to3\to3}_{\text{三层}} \equiv 7\times7\]

再看参数量。设输入输出都是 $C$ 通道，一个 $5 imes5$ 卷积的参数是 $5^2 C^2 = 25C^2$；而两个 $3 imes3$ 卷积是 $2 imes(3^2 C^2) = 18C^2$。感受野一样大，参数却少了 28%；三个 $3 imes3$（$27C^2$）对一个 $7 imes7$（$49C^2$）省得更多。而且每多一层就多一个 ReLU——

直白说

用乐高打比方：与其用一块又大又贵的 5×5 积木，不如用两块便宜的 3×3 拼出同样的覆盖范围。不仅省料，两块之间还能塞一层非线性，让网络的「表达弯曲度」更高。

严谨说

形式上：$n$ 个 $3 imes3$ 堆叠的感受野是 $(2n+1) imes(2n+1)$，参数 $9nC^2$ 随 $n$ 线性增长，而等效大核的参数 $(2n+1)^2 C^2$ 随 $n$ 二次增长。小核堆叠把「增大感受野」的代价从二次降到线性，同时插入 $n$ 个非线性——这就是 VGG 既深又（相对）省参数的数学根据。

VGG 留给后世最重要的遗产不是某个具体网络，而是一条设计准则：用深度换宽度、用小核堆叠换大核。这条准则简单到能写进一行——「能用 3×3 堆出来的，就别用大核」——却极其有效，至今仍是卷积骨干网络的默认起点。

VGG 的代价是参数量仍然巨大（主要堆在末端的全连接层，VGG-16 有约 1.38 亿参数，光三层全连接就占了九成多）。这暴露了一个新问题：全连接头太重。下一节的 ResNet 与更早的 NiN 会用全局平均池化把它干掉。

4退化问题与残差连接

VGG 把深度推到 19 层后，一个反直觉的现象拦住了去路。He 等人 2015 年发现：把朴素网络从 20 层堆到 56 层，训练误差反而上升了——注意是训练误差，不是测试误差，所以这不是过拟合，而是更深的网络更难优化。他们称之为 degradation problem（退化问题）。

退化为什么诡异？因为理论上深网络不该更差：如果多出来的那些层都学成恒等映射（什么都不改），56 层至少应该和 20 层打平。可实践中，让一堆非线性层去逼近一个恒等映射，竟然很难。He 的解法天才地简单——既然学恒等这么难，那就把恒等「免费」送给网络。

4.1 残差连接：让网络学「增量」

普通层学的是从输入到输出的完整映射 $H(x)$；residual connection（残差连接）换个目标，让层只学相对于输入的增量 $F(x) = H(x) - x$，再把输入直接加回去：

\[y = F(x) + x \qquad(\text{残差块}：F \text{ 是若干卷积/激活})\]
普通块 残差块 (residual block) x x ───────────────┐ │ │ │ (identity / skip) [conv-relu-conv] [conv-relu-conv] │ │ │ F(x) │ ▼ ▼ │ H(x) (+)◄───────────────┘ │ ▼ y = F(x) + x

这个 +x 叫 skip connection（跳跃连接）。它带来两个决定性好处。其一，恒等映射变成默认值：网络只要把 $F$ 学成 0，就自动恢复成恒等——「再加一层至少不会更差」从此有了结构保证，退化问题迎刃而解。

4.2 梯度直通：为什么残差能堆到上百层

其二，也是更深刻的——残差连接为梯度开了一条直通的高速公路。对 $y = F(x)+x$ 求梯度，反向传播时：

\[\frac{\partial y}{\partial x} = \frac{\partial F(x)}{\partial x} + I\]

那个 +I（单位矩阵，来自 +x）是关键。在堆叠 $L$ 个残差块时，浅层梯度是一串 $(\,\partial F_i/\partial x + I\,)$ 的连乘——展开后总有一项是所有 $I$ 相乘 = $I$，意味着无论中间的 $\partial F/\partial x$ 多小，至少有一条恒等通路把梯度原封不动送到浅层。对比普通深网络的梯度是一串雅可比的纯连乘（任何一项小于 1，连乘后就指数衰减到零），残差的 +I 从根上阻断了这种指数衰减。

直白说

把梯度想成从楼顶往下传的水。普通深网络像层层水阀，每过一层就被拧小一点，传到底层只剩一滴；残差连接像在旁边修了一条直通管道，水可以绕过所有水阀畅流到底——这就是它能堆到 152 层甚至上千层的原因。

严谨说

形式上：普通网络 $\partial L/\partial x_0 = \prod_i J_i$，任一 $\|J_i\|<1$ 则乘积 $ o 0$（梯度消失）。残差网络 $\partial L/\partial x_0 = \prod_i (J_i + I) = I + ( ext{高阶项})$，那个 $I$ 保证了梯度有一个不衰减的下界。本模块 notebook 会用数值实验直接量出：同样深度，残差栈的输入梯度范数比朴素栈大几个数量级。

务必分清残差连接解决的是优化问题（让深网络训得动），而不是表达力问题。更深的普通网络理论上表达力不弱（它能表示恒等的超集），但优化器找不到那个好解。残差连接没有增加表达力，它是把损失曲面「捋平」、让优化器够得着好解。这与 BatchNorm 平滑曲面是同一类思路——深度学习里很多突破，本质是让本就存在的好解变得可被优化器找到。

5BatchNorm：训练 vs 推理

与 ResNet 几乎同期，Batch Normalization（Ioffe & Szegedy 2015，BN）从另一个角度攻克深网络的训练难题，成了和残差连接并列的两大「深度催化剂」。它的做法是：在网络中间，对每个特征，按当前 mini-batch 做标准化（减均值、除标准差），再用两个可学习参数缩放和平移回去。

5.1 前向：标准化 + 仿射

设某特征在一个 batch 上的值为 $\{x_1,\dots,x_m\}$，BN 的前向分四步：

\[\mu = \tfrac1m\sum_i x_i,\quad \sigma^2 = \tfrac1m\sum_i (x_i-\mu)^2,\quad \hat x_i = \frac{x_i-\mu}{\sqrt{\sigma^2+\epsilon}},\quad y_i = \gamma\,\hat x_i + \beta\]

前两步算 batch 的均值方差，第三步把特征标准化到零均值单位方差（$\epsilon$ 防除零），第四步用可学习的 $\gamma,eta$ 把分布挪回网络需要的位置。为什么要先标准化再用 $\gamma,eta$ 挪回去、绕一圈？因为这给了网络自主选择每个特征分布的能力——它甚至能学到 $\gamma=\sigma,eta=\mu$ 来抵消标准化（恢复原状），所以 BN至少不会损害表达力，却为优化提供了极大便利。

5.2 训练 vs 推理：两套统计量

BN 有一个极易出错、面试高频的细节：训练和推理用的统计量不同。训练时用当前 batch 的 $\mu,\sigma^2$（因为要对 batch 做标准化）；但推理时往往一次只来一个样本，没有 batch 可言，于是改用训练阶段滑动平均累积下来的全局统计量：

阶段用什么均值/方差为什么
训练 train当前 mini-batch 的 $\mu,\sigma^2$需对 batch 标准化；同时滑动更新全局统计 $\mu_{run},\sigma^2_{run}$
推理 eval训练期累积的滑动平均 $\mu_{run},\sigma^2_{run}$推理无 batch（或不该依赖它）；要确定性、可复现的输出

滑动平均的更新通常是 running = momentum*running + (1-momentum)*batch。忘记切换 train/eval 模式，是 BN 最经典的 bug——用 eval 模式训练会让梯度不流经统计量，用 train 模式推理会让单样本的输出依赖于「同 batch 的其他样本」而抖动甚至崩溃。

直白说

BN 像给每层的输入「自动调音」：不管前面的层把信号放大成多大、偏移到多远，BN 都把它拉回一个稳定的音量再往下传，于是后面的层永远在熟悉的范围里工作，学习率可以开得更大、训练更稳更快。

严谨说

BN 的好处：① 允许更大学习率、加速收敛；② 降低对初始化的敏感；③ 有轻微正则作用（batch 统计带来的噪声）。原论文把动机归于减少 internal covariate shift（内部协变量偏移），但 Santurkar 2018 用实验表明，BN 的主要功劳其实是平滑了损失曲面——又一个「论文给的解释未必是真正起作用的机制」的经典案例。

BN 依赖足够大的 batch才能估准统计量；小 batch（如检测、分割任务）下 BN 会失效。这催生了 Layer Normalization（对单样本全特征归一化，不依赖 batch）、GroupNorm 等替代品。其中 LayerNorm 正是 RNN（模块 04）与 Transformer（C1）的归一化首选——又一条通向 Transformer 的伏笔。

61×1 卷积与瓶颈块

还有一块小而精妙的积木值得单独讲：1×1 convolution（1×1 卷积）。乍看很怪——一个 1×1 的核，空间上只覆盖单个像素，能有什么用？关键在于它在通道维度上做文章。

1×1 卷积对每个空间位置独立地把所有输入通道做一次线性组合（再加偏置、过激活）。也就是说，它等价于在每个像素位置上做一次全连接，把 $C_{in}$ 个通道映射到 $C_{out}$ 个通道，而完全不动空间结构：

\[y[:,h,w] = W\,x[:,h,w] + b, \qquad W \in \mathbb{R}^{C_{out}\times C_{in}}\]

它的三大用途：

  • 升降维（改通道数）：把 256 通道压成 64 通道（或反之），且代价极小。这是控制网络「宽度」与算力的旋钮。
  • 跨通道信息融合：让不同通道的特征在每个位置上交互混合，增加表达力。
  • 加非线性：1×1 卷积后接 ReLU，能在几乎不增加感受野的前提下，凭空多一层非线性。

6.1 瓶颈块：用 1×1 让深网络算得起

1×1 卷积最漂亮的应用是 ResNet 深层版的 bottleneck block（瓶颈块）。直接对 256 通道做 3×3 卷积太贵（$3^2 imes256^2 pprox 59$ 万参数）；瓶颈块改成先用 1×1 降维、再 3×3 处理、最后 1×1 升维的三明治：

朴素残差块 (256ch) 瓶颈残差块 (256ch) x (256) x (256) │ │ 1x1, 256->64 (降维，省算力) [3x3, 256->256] [3x3, 64->64 ] (在窄通道上做重活) [3x3, 256->256] [1x1, 64->256] (升维，复原通道) │ + x │ + x ▼ ▼ ~118 万参数 ~7 万参数 (省 ~16x)

直白说

瓶颈块像沙漏：先把又宽又厚的特征捏细（1×1 降维），在细的地方做最贵的 3×3 卷积，再撑回原来的宽度（1×1 升维）。最贵的那道工序在最窄处进行，总算力因此大降——这就是 ResNet-50/101/152 能在算力上可行的关键。

严谨说

算个账：直接两个 $3 imes3$（256→256）约 $2 imes9 imes256^2 pprox 118$ 万参数；瓶颈 $1 imes1(256{ o}64)+3 imes3(64{ o}64)+1 imes1(64{ o}256)$ 约 $256\cdot64 + 9\cdot64^2 + 64\cdot256 pprox 7$ 万参数，省了十几倍，而表达力相近。用 1×1 在通道维做「降维-处理-升维」，是深网络控制算力的通用招式，GoogLeNet 的 Inception 也靠它。

记住 1×1 卷积的本质：它是「逐像素的全连接」，专管通道维的混合与升降，不碰空间。一旦理解这点，你会在无数现代架构里认出它——SENet 的通道注意力、MobileNet 的 pointwise 卷积、乃至 Transformer 里 token 维的线性投影，骨子里都是这个「在特征维做线性变换」的同一个想法。

7参数量与感受野的计算

会算一个网络的参数量与感受野，是设计和读懂 CNN 的硬功夫——前者决定模型多大、会不会过拟合，后者决定网络能「看多远」、能否覆盖目标尺度。这两个量都有干净的闭式公式，本节给齐，notebook 里会让你亲手算真实网络。

7.1 参数量

一个卷积层的参数量（含偏置）是：

\[\#\text{params} = (\underbrace{k_h \times k_w \times C_{in}}_{\text{每个核的权重}} + \underbrace{1}_{\text{偏置}}) \times C_{out}\]

注意参数量与输入空间尺寸 $H,W$ 无关——这正是上一模块「参数共享」的体现：同一个核扫遍整张图，无论图多大，参数都只是核的大小。对比之下，全连接层的参数是 $( ext{in}+1) imes ext{out}$，会随输入尺寸暴涨——这就是为什么 VGG 的参数几乎全堆在末端的全连接层，而用全局平均池化替代它能省掉九成参数。

层类型参数量公式随输入尺寸 H,W
卷积 conv$(k_h k_w C_{in}+1)\,C_{out}$无关（参数共享）
全连接 fc$(\,\text{in}+1)\,\text{out}$in 通常含 H,W → 暴涨
BatchNorm$2\,C$（$\gamma,\beta$）无关
池化 pool0无参数

7.2 感受野

感受野（输出一个位置看得到的输入范围）随层逐渐累积。设第 $l$ 层核大小 $k_l$、步幅 $s_l$，则感受野 $r$ 与累积步幅 $j$（jump，相邻输出像素对应的输入间距）按下式逐层递推：

\[j_l = j_{l-1}\cdot s_l, \qquad r_l = r_{l-1} + (k_l - 1)\cdot j_{l-1}\]

初始 $j_0=1, r_0=1$。直觉是：每加一层，感受野扩大 $(k_l-1)$ 倍当前的累积步幅——所以靠后的层、或步幅/池化之后的层，每一层都能让感受野猛涨（因为此时 $j$ 已经很大）。这解释了为什么深层 CNN 的顶层能「看到」整张图。

直白说

感受野像视野范围：网络越往深，每个神经元「站得越高」，看到的输入区域越大。要识别一只猫，顶层神经元的感受野必须大到能framing整只猫——感受野不够大，再多层也白搭。

严谨说

两种扩大感受野的手段：① 堆更多层（线性增长，VGG 路线）；② 用 stride/池化降采样（让 $j$ 翻倍，感受野指数式跳涨）。实际网络两者并用。空洞卷积（dilation）则是第三种——在不增加参数、不降分辨率的前提下，把核元素间隔拉开来撑大感受野，常用于分割。

一个常见误区：把「理论感受野」当成「有效感受野」。Luo 等 2016 发现，CNN 的有效感受野（真正显著影响输出的区域）往往远小于理论感受野，且呈高斯衰减——边缘的输入像素虽在理论感受野内，实际贡献微乎其微。所以「理论上看得到」不等于「真的在用」，设计时要留足余量。

8研究前沿与开放问题

从 ResNet 至今，CNN 架构的探索并未停止，与 Transformer 的碰撞更让这个领域焕发新生。几个值得关注的方向：

  • 更干净的恒等通路（pre-activation ResNet）：He 等 2016 的后续工作发现，把 BN 和 ReLU 放到卷积之前（pre-activation），能让残差的恒等通路完全畅通无阻，梯度传得更彻底，可堆到 1000+ 层。印证了第 4 节「干净的 +I 通路是关键」。
  • BatchNorm 到底为什么有用：原论文的「内部协变量偏移」解释被 Santurkar 2018 用实验推翻，提出 BN 主要是平滑损失曲面。归一化的真正机理至今仍是活跃的研究问题，也催生了 LayerNorm/GroupNorm/RMSNorm 等一族变体。
  • CNN vs Transformer 之争：ViT（2020）证明纯注意力也能在视觉上超越 CNN，但需要海量数据；ConvNeXt（2022）反手把 ResNet 按 Transformer 的设计哲学（大核、LayerNorm、GELU、更少激活）现代化改造，又追平了 ViT。说明结构细节之外，训练配方同样决定成败。
  • 卷积与注意力的融合：现代视觉骨干越来越多地混用卷积（擅长局部、平移等变、样本高效）与注意力（擅长全局关系），如 CoAtNet、MobileViT。两大归纳偏置不是替代而是互补——这正呼应本课「理解每种结构假设了什么」的主线。
  • 高效架构：MobileNet（深度可分离卷积）、EfficientNet（复合缩放）等把 1×1 与分组卷积用到极致，在手机/边缘设备上跑 CNN，是「算力受限场景下的架构设计」这一实用方向。

回望整条演化线，一个母题反复出现：深度学习的进步，常常不是增加表达力，而是让本就存在的好解变得「可被优化器找到」。ReLU、残差连接、BatchNorm、好的初始化——它们都不是让网络「能表示更多」，而是让网络「能训得起来」。这个视角会一直陪你到 Transformer 乃至更大的模型。
