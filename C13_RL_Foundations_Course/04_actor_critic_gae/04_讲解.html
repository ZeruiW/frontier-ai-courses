1actor-critic：价值与策略的联姻

模块 03 的 REINFORCE 无偏但方差大，baseline 缓解了一部分。但 baseline 那里我们用的是蒙特卡洛回报 $G_t$——必须跑完整条回合才能算，且 $G_t$ 仍是整条剩余轨迹随机性的累积，方差天然偏大。本模块把这个最后的短板补上：用一个学出来的价值函数（critic）来替代蒙特卡洛回报，既不必等回合结束、又进一步降方差。这就是 actor-critic（演员-评论家）。

名字很形象。actor（演员）是策略 $\pi_\theta$——负责做动作，它用模块 03 的策略梯度更新。critic（评论家）是价值函数 $V_\phi$——负责评判，它用模块 02 的 TD 学习更新，给 actor 提供「这一步比平均好多少」的低方差信号。两者协作：actor 演出一步，critic 立刻打分（用 TD 误差），actor 据此微调，critic 也据此修正自己的评判。这是模块 01 提过的「广义策略迭代」（GPI）的又一个实例——评估（critic）与改进（actor）互相驱动。

直白说

把它想成「运动员 + 教练」。运动员（actor）做动作，教练（critic）在旁边实时点评「这步不错 / 这步亏了」。运动员不必等整场比赛打完看最终比分（那是 REINFORCE 的做法、反馈又慢又糙），每做一个动作就得到教练即时、稳定的反馈。而教练自己也在比赛中不断提升评判水平。两者一起成长，比单打独斗快得多。

严谨说

形式上，actor-critic 把策略梯度里的加权项从蒙特卡洛回报 $G_t$ 换成基于 critic 的 advantage 估计 $\hat A_t$。最简单的版本用单步 TD 误差当 advantage：$\hat A_t=\delta_t=r_t+\gamma V_\phi(s_{t+1})-V_\phi(s_t)$。策略梯度变成 $\nabla_\theta J\approx\mathbb{E}[\sum_t\nabla_\theta\log\pi_\theta(a_t\mid s_t)\,\delta_t]$。这就同时实现了「在线（不必等回合结束）」与「低方差（$\delta$ 只含一步随机性 + 自举）」——但代价是引入了偏差（critic 不准）。下面几节就是把这个 bias-variance 权衡讲透、并做成一个可调的旋钮。

actor-critic 是价值方法与策略方法的联姻：它要 critic（价值方法）不是为了从 critic 导出策略（那是 Q-learning 的路子），而是借 critic 来给策略梯度降方差。这个分工很关键：actor 负责表达和优化策略（处理连续动作、随机性、探索），critic 负责提供低方差的学习信号。现代主流算法（A2C、PPO、SAC、以及 RLHF）几乎全是 actor-critic 架构——理解它，就理解了深度 RL 的主流范式。

2advantage 与 TD 误差的关系

advantage：为什么它是最好的加权信号

回到核心问题：策略梯度 $\nabla_\theta J=\mathbb{E}[\nabla\log\pi\cdot\Psi_t]$ 里，加权项 $\Psi_t$ 该用什么？模块 03 用过 $G_t$（回报）和 $G_t-b$（带 baseline）。理论上 $\Psi_t$ 可以是好几种等价（期望相同）但方差不同的量：

$\Psi_t$ 的选择是什么偏差方差
$G_t$（总回报）整条轨迹回报无偏最高
$G_t$（reward-to-go）从 $t$ 起的回报无偏高
$G_t - b(s_t)$回报减 baseline无偏中
$Q^\pi(s_t,a_t)$动作价值无偏（若 Q 准）中
$A^\pi(s_t,a_t)=Q-V$优势函数无偏（若 A 准）最低

理论上的最优选择是 advantage（优势函数）$A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s)$——它度量「在状态 $s$，动作 $a$ 比该状态的平均水平好多少」。用 advantage 当加权项，策略梯度的含义最干净：把比平均好的动作概率推高、比平均差的推低，而「平均」这个基准（$V$）被自动扣掉了。这正是模块 03 baseline 思想的理论归宿——最优的 baseline 就是 $V^\pi$，减掉它得到的就是 advantage。

但 advantage 我们不知道——$Q^\pi$ 和 $V^\pi$ 都得估。关键洞察是：TD 误差 $\delta_t$ 是 advantage 的一个无偏估计（当 $V=V^\pi$ 时）：

\[\mathbb{E}\big[\delta_t \mid s_t,a_t\big] = \mathbb{E}\big[r_t + \gamma V^\pi(s_{t+1}) \mid s_t,a_t\big] - V^\pi(s_t) = Q^\pi(s_t,a_t) - V^\pi(s_t) = A^\pi(s_t,a_t)\]

这个等式是 actor-critic 的理论支柱：我们只需学一个 $V_\phi$（比学 $Q$ 简单，少一维），用 $\delta_t=r_t+\gamma V_\phi(s_{t+1})-V_\phi(s_t)$ 当 advantage，就能得到（近似）无偏、低方差的策略梯度信号。$\delta_t$ 只含一步的真实随机性（$r_t,s_{t+1}$）加上自举的 $V$，方差远小于含整条轨迹的 $G_t$。代价：若 $V_\phi\ne V^\pi$（critic 不准），$\delta_t$ 就有偏。这个「方差小但有偏（依赖 critic 准确度）」与「方差大但无偏（蒙特卡洛）」的张力，就是下一节 GAE 要调和的。

3GAE：bias-variance 的旋钮

GAE：把 bias-variance 做成一个旋钮

单步 TD 误差 $\delta_t$（方差最低、偏差最高，因为最依赖 critic）和蒙特卡洛 advantage $G_t-V(s_t)$（方差最高、无偏）是两个极端。中间还有n-step的连续谱：

\[\hat A_t^{(n)} = \underbrace{r_t + \gamma r_{t+1} + \dots + \gamma^{n-1} r_{t+n-1} + \gamma^n V(s_{t+n})}_{n\text{-step return}} - V(s_t)\]

$n=1$ 是 $\delta_t$（最依赖 critic、低方差高偏差），$n=\infty$ 是蒙特卡洛（不依赖 critic、高方差无偏）。选哪个 $n$？Generalized Advantage Estimation（GAE，Schulman 2016）给出一个优雅的答案：不选，全都要——对所有 $n$-step advantage 做指数加权平均，权重由一个参数 $\lambda\in[0,1]$ 控制。它有一个极其简洁的递归形式：

\[\hat A_t^{\text{GAE}(\gamma,\lambda)} = \sum_{l=0}^{\infty}(\gamma\lambda)^l\,\delta_{t+l} = \delta_t + \gamma\lambda\,\hat A_{t+1}^{\text{GAE}}\]

第一个等号是定义（TD 误差的几何加权和），第二个等号是它的递归实现——从后往前一遍扫描就能算出整条轨迹的 advantage，$O(T)$，极其高效（notebook 会推导并验证两者等价）。这个 $\lambda$ 就是 bias-variance 的连续旋钮：

  • $\lambda=0$：$\hat A_t=\delta_t$，退化为单步 TD advantage（最低方差、最高偏差，最依赖 critic 准确度）。
  • $\lambda=1$：$\hat A_t=\sum_l\gamma^l\delta_{t+l}=G_t-V(s_t)$，退化为蒙特卡洛 advantage（最高方差、无偏，望远镜望到底，几乎不靠 critic）。
  • $0<\lambda<1$：在两者间连续插值，通常 $\lambda=0.95$ 左右是最佳折中（实践默认值）。

为什么是 $(\gamma\lambda)^l$ 这个权重？直觉：越远的 $\delta_{t+l}$ 越含更多未来的随机性（方差大），用 $(\gamma\lambda)^l$ 给它们指数递减的权重——近处的 $\delta$（低方差）权重大、远处的（高方差）权重小，从而在「用多步真实信息降偏差」与「不要引入太多远期方差」间取得平衡。$\lambda$ 越大，越信任远处的 $\delta$（越像蒙特卡洛）；$\lambda$ 越小，越只信眼前一步（越像 TD）。

GAE 的 $\lambda$ 和模块 02 提过的 TD(λ)/资格迹是同一个思想——用几何权重融合所有 $n$-step 回报，只不过 GAE 把它用在 advantage 估计上、且写成了便于实现的递归。记住这个统一视角：$\gamma$ 是「未来奖励的折扣」（环境/任务给定），$\lambda$ 是「自举多步 vs 一步的偏好」（算法的方差控制旋钮）。两者都出现在 $(\gamma\lambda)^l$ 里，但意义完全不同——$\gamma$ 关乎你多在乎未来，$\lambda$ 关乎你多信任 critic。混淆这两个是常见的概念错误。

4bias-variance 权衡：GAE 的灵魂

bias-variance 权衡：GAE 的灵魂

GAE 之所以重要，是因为它把 RL 里无处不在的偏差-方差权衡做成了一个可调、可理解的旋钮。把这个权衡彻底想清楚，是本模块的核心收获。

先理解两端的本质。蒙特卡洛（$\lambda=1$）用真实的整条回报，不依赖任何价值估计，所以无偏——它看到的是「真实发生了什么」。但真实轨迹充满随机性（环境随机转移、策略随机选动作），整条累积下来方差巨大，尤其长视界、强随机环境下，$G_t$ 的抖动能淹没真实信号。

单步 TD（$\lambda=0$）只看一步真实奖励 + 自举的 $V(s_{t+1})$，随机性被截断在一步内，所以方差极低。但它把「之后会怎样」完全交给了 critic 的估计 $V$——如果 $V$ 不准（训练初期总是不准），这个偏差会传导进每一步的 advantage，且因为自举会自我强化（错误的 $V$ 产生错误的 $\delta$，又用来更新 $V$）。这是它有偏的来源。

中间的 $\lambda$巧妙地两头取好处：用近处几步的真实奖励（可信、降偏差），但不一路用到底（避免累积太多远期方差），远处则渐渐交给 critic。$\lambda=0.95$ 之所以是常见甜点，是因为它在大多数任务上让「多步真实信息带来的偏差下降」恰好压过「多步随机性带来的方差上升」。但最优 $\lambda$ 依任务而定——critic 越准，可以用越小的 $\lambda$（更信任它）；环境越随机，可能要用更小的 $\lambda$（少引入轨迹方差）。

GAE 的 λ 旋钮：在偏差与方差之间连续滑动 λ=0 ────────────────────────────────────────────── λ=1 单步 TD λ≈0.95 蒙特卡洛 ▲ 最依赖 critic ▲ 实践甜点 ▲ 不靠 critic 偏差: 高 ◄──────────────────────────────────────► 偏差: 0(无偏) 方差: 低 ◄──────────────────────────────────────► 方差: 高 critic 越准 → 可用更小 λ(更信它) 环境越随机 → 倾向更小 λ(少引入轨迹方差)

一个常见误解：以为「无偏总是更好」，所以 $\lambda=1$（蒙特卡洛）最优。错。在样本有限的现实里，方差才是策略梯度的主要敌人——一个有点偏但方差小的估计，常常比无偏但方差爆炸的估计学得快得多、稳得多。这正是 GAE（以及整个自举思想）的价值：用可控的、随训练减小的偏差，换取大幅降低的方差。理解这一点，你就理解了为什么深度 RL 几乎从不用纯蒙特卡洛、而是用 GAE($\lambda\approx0.95$) + critic。notebook 会数值展示：方差随 $\lambda$ 单调上升（实测 $\lambda=0$ 到 $\lambda=1$ 方差涨约 100×）。

5A2C：组装完整算法

A2C：把 actor、critic、GAE 拼成一个算法

有了 actor（策略梯度）、critic（TD 价值学习）、GAE（advantage 估计），把它们组装起来就是 A2C（Advantage Actor-Critic，Mnih 2016 的同步版）——一个完整、实用的策略梯度算法。流程是：

A2C（Advantage Actor-Critic）一轮迭代 1. 用当前策略 π_θ 采一批轨迹(rollout) 2. 用 critic V_φ 算每步 TD 误差 δ_t = r_t + γV_φ(s_{t+1}) − V_φ(s_t) 3. 用 GAE 把 δ 聚成 advantage: Â_t = Σ_l (γλ)^l δ_{t+l} (一遍反向扫描) 4. critic 目标(回报): R_t = Â_t + V_φ(s_t) ← 即 TD(λ) 回报 5. 更新 actor: θ ← θ + η_a · Σ_t Â_t · ∇_θ log π_θ(a_t|s_t) 6. 更新 critic: φ ← φ − η_c · ∇_φ Σ_t (V_φ(s_t) − R_t)² ← 回归到 TD(λ) 回报 (可选) 加熵正则 + β·∇H(π) 防塌缩

几个实现要点值得记住。critic 的回归目标用 $R_t=\hat A_t+V_\phi(s_t)$（即 TD(λ) 回报）——注意这个目标要当作常数（不对它求 critic 的梯度，即 stop-gradient），否则 critic 会「作弊」地把目标拉向自己。actor 的 advantage同样对 actor 是常数（advantage 由 critic 提供，不参与 actor 的梯度）。这两个 stop-gradient 是 actor-critic 正确实现的关键，新手极易搞错。

A2C 相比 REINFORCE 的进步是全方位的：方差更低（GAE + critic）、可在线/小批量更新（不必等长回合）、样本利用更好。它的异步多 worker 版叫 A3C，是深度 RL 早期的里程碑。而把 A2C 的「裸更新」换成「用裁剪限制每次更新幅度」就是 PPO——当今最主流的策略梯度算法，也是 RLHF（C22）的默认选择。换句话说，你在本模块拼出的 A2C，就是 PPO 的骨架：PPO = A2C(actor-critic + GAE) + 信赖域式的裁剪。把 A2C 理解透，PPO 论文里就没有新原理，只有「怎么更稳地更新」这一个工程问题。

stop-gradient 陷阱

最致命、也最隐蔽的实现 bug 是没做 stop-gradient。critic 的回归目标 $R_t=\hat A_t+V_\phi(s_t)$ 里含 $V_\phi$ 自己——如果你让梯度穿过这个目标里的 $V_\phi$，critic 就会「作弊」：与其把预测拉向真实回报，不如把目标拉向当前预测（两边一起动、loss 假装下降），结果 critic 学到一个退化解、advantage 全错、actor 跟着崩。在 numpy 里我们手动只更新 $V[s]\leftarrow V[s]+\alpha(R_t-V[s])$、把 $R_t$ 当常数（天然 stop-gradient）；在 PyTorch 里必须显式 .detach() 目标。同理 actor 的 advantage 也要 detach（它是 critic 给的信号，不该回传到 critic）。这两个 detach 漏一个，深度 actor-critic 就训不出来——而在表格实现里它是天然正确的，正好让你先建立对「什么该当常数」的清晰认知。

actor 和 critic 的学习率（$\eta_a,\eta_c$）通常critic 比 actor 大（如 critic 0.3、actor 0.1）。原因：critic 需要先大致学准，才能给 actor 提供有用的 advantage 信号——若 critic 落后于 actor，actor 会被错误的 advantage 误导。这是 actor-critic 的一个微妙稳定性问题（两个相互依赖的学习过程的耦合），也是它有时比纯策略梯度更难调的原因。在表格环境里你能清楚看到 critic 学准的过程；到了深度 RL，这个耦合 + 函数逼近会让调参更微妙——又一个「先在表格夯实」的理由。

6toy chain 上的 A2C + GAE

把它跑起来：toy chain 上的 A2C + GAE

notebook 会在链 MDP（模块 03 的环境）上跑通完整的 A2C，并把 GAE 的所有关键性质数值验证：

  • GAE 递归 == 显式几何和：验证 $\hat A_t=\delta_t+\gamma\lambda\hat A_{t+1}$ 这个 $O(T)$ 递归，与按定义 $\sum_l(\gamma\lambda)^l\delta_{t+l}$ 的显式求和逐位相等。
  • $\lambda=0$ 退化为 TD：验证 GAE($\lambda=0$) 逐位等于单步 TD 误差 $\delta_t$。
  • $\lambda=1$ 退化为 MC：验证 GAE($\lambda=1$) 逐位等于蒙特卡洛 advantage $G_t-V(s_t)$。
  • 方差随 $\lambda$ 单调上升：在固定策略 + 准确 critic 下，采大量 advantage 估计，验证其方差随 $\lambda$ 从 0 到 1 单调增大（实测约 100×），而均值（真 advantage）基本不变——这是 bias-variance 权衡的铁证。
  • A2C 收敛：完整训练 actor + critic，验证策略学会向右、回报上升，且 critic 的 $V$ 估计逼近真值。

这套实现把本模块的理论落成可运行、可复现的代码。特别是 GAE 的反向扫描递归——短短几行，却是 PPO 等现代算法每次更新都在跑的核心子程序。你在 numpy 里把它写对、验证它在两个极端退化正确、看到方差随 $\lambda$ 的变化，就真正掌握了这个深度 RL 的关键组件。换到 C41 的 PPO，这段 GAE 代码几乎可以原样搬过去（只是 $V$ 从表格换成网络输出）。

实现 GAE 时最容易错的地方是轨迹末尾的自举值（last value / bootstrap value）：若回合自然终止（到达目标），$s_T$ 是终止态，$V(s_T)=0$；若回合是被截断（达到最大步数但没真正结束），则应该用 critic 估计 $V_\phi(s_T)$ 来自举（因为后面还有未来，只是我们没跑）。混淆这两种情况（终止 vs 截断）是 RL 实现里一个经典 bug，会让接近回合末尾的 advantage 系统性错误。notebook 里我们显式区分 done 与 truncated，并 assert 终止态的自举值为 0。

7actor-critic 家族与实践要点

actor-critic 家族与实践要点

actor-critic 是一个大家族，本模块的 A2C 是最基础的一支。把家族谱系理清，能帮你定位各种现代算法：

算法在 A2C 基础上加了什么解决的问题
A3C多 worker 异步并行采样打破样本相关性、加速
A2C（本模块）同步 actor-critic + GAE基线版本
TRPO/PPO用 KL 约束 / 裁剪限制更新步长防过早塌缩、稳定大步更新
SAC最大熵目标 + 双 Q critic + 重参数化样本效率、连续控制、探索
DDPG/TD3确定性 actor + Q critic（off-policy）连续动作的 off-policy 学习
GRPO去掉 critic，用组内相对回报当 advantageLLM RL 省去价值网络（C22）

实践要点（也是未来调 PPO 的 checklist）：① critic 学习率通常大于 actor（critic 先学准才能帮 actor）；② advantage 常做标准化（减均值除标准差，稳定梯度尺度，模块 03 讲过其代价）；③ 熵正则几乎必加（防塌缩）；④ 区分 done 与 truncated（自举值处理）；⑤ stop-gradient（critic 目标与 actor 的 advantage 都当常数）。这五条踩过任何一条都会让 actor-critic 学不好——而在表格环境里它们的影响都清晰可见、可对拍验证。

一个值得强调的现代趋势：GRPO（DeepSeek）在 LLM 的 RL 微调里干脆去掉了 critic——它对同一个 prompt 采样一组（group）回复，用组内回报的相对排名/标准化当 advantage，省去了训练价值网络的开销和不稳定。这其实是回到了「baseline」的最朴素形式（模块 03）：组内平均回报就是一个经验 baseline，组内 advantage = 个体回报 − 组平均。看，最前沿的 LLM RL 方法，本质仍是本课模块 03–04 这些地基的重新组合——这再次印证：地基不牢，上层全是玄学；地基扎实，前沿一望即懂。

8研究前沿与开放问题

研究前沿与开放问题

  • critic 的偏差与稳定性：actor 与 critic 相互依赖，critic 的偏差会误导 actor、actor 改变分布又影响 critic 的训练数据——这个耦合的稳定性、收敛性在函数逼近下仍无完整理论。目标网络、双 critic（TD3/SAC）是工程上的缓解。
  • 自适应 λ 与 γ：GAE 的 $\lambda$、折扣 $\gamma$ 目前多靠手调或网格搜索。自动、自适应地调节它们（甚至 meta-learning 它们）是活跃方向，关系到算法能否少调参地迁移到新任务。
  • 去 critic 化：GRPO 等证明在某些场景（尤其 LLM）可以不用 critic、用组内 baseline 替代，省开销又更稳。什么时候 critic 不可或缺、什么时候可省，是当前（尤其 LLM RL）的热点问题。
  • off-policy actor-critic：A2C 是 on-policy 的（数据用一次就丢）。把 actor-critic 做成 off-policy（复用数据、提样本效率）需要重要性采样修正（Degris 2012）或确定性策略（DDPG），但稳定性更难——离线 RL 把这推到极致。
  • 从 A2C 到 PPO 再到 LLM：PPO 的裁剪机制为何有效、其与信赖域的精确关系、在 LLM 上的种种适配（token-level vs sequence-level advantage、KL 的作用）仍在被深入研究。本模块的 A2C + GAE 是读懂这一切的入场券。
