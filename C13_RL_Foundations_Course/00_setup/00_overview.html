1这门课讲什么

欢迎来到 强化学习地基。这门课只追求一件事：让你从「会调 gym 和 PPO」变成「能从 Bellman 方程一路推到 GAE，并亲手把每个估计量写出来」。

绝大多数人和 RL 的关系，止于 env = gym.make(...) 加上 model = PPO('MlpPolicy', env).learn(...)。这门课要往下钻到地基：当 PPO 在更新策略时，它到底在最大化什么？那个 advantage 是怎么估出来的、为什么要那样估？为什么 Q-learning 不用知道环境模型也能学到最优策略，而它凭什么收敛？为什么策略梯度里要减一个 baseline——减了之后梯度的期望没变，方差却小了一个数量级，这是魔法吗？

这些问题的答案不在任何库的文档里，而在几个朴素而深刻的数学结构里：MDP 把序贯决策形式化，Bellman 方程把「长期价值」拆成「即时奖励 + 折扣后继价值」的递归，压缩映射保证这个递归反复迭代必然收敛，时序差分把这套递归从「需要模型」解放成「只需采样」，策略梯度定理让我们能对策略本身直接求梯度，GAE 则用一个旋钮在偏差与方差之间连续滑动。六个模块，就是把这条从 Bellman 到 GAE 的链条一环一环拆开、亲手重建。

学完你应当能回答这类问题（也是 RL 岗位与深度 RL 课程的高频考点）：Bellman 期望方程与最优方程差在哪？价值迭代为什么收敛、收敛多快？Q-learning 和 SARSA 的更新只差一个符号，行为为何天差地别？策略梯度的 baseline 为什么不引入偏差？GAE 的 λ 到底在调什么？UCB 的置信项是怎么来的？——并且能在 numpy 里把这些算法都从零实现、在 GridWorld 上对拍精确解、固定种子复现每条曲线。

一句方法论上的话先说在前面：本课刻意停在表格型、停在能求出真值的小环境，这不是简化，而是为了把注意力锁在真正难的东西上——算法的数学骨架与正确性。深度 RL 的不稳定（神经网络 + 自举 + off-policy 的「致命三要素」、超参敏感、随机种子方差）会把对算法本身的理解淹没掉。而「Bellman 备份对不对、TD 更新收不收敛、策略梯度估计有没有偏、GAE 递推写没写错」是不随实现规模过时的硬功夫。把它在干净环境里夯死，换到 C41 深度 RL、C22 推理 RL 里立刻能上手。

2RL 与监督学习的三点根本不同

在拆算法之前，必须先想清楚一个根本问题：强化学习和监督学习到底不一样在哪？很多人把 RL 当成「另一种机器学习」，但它的三点不同是结构性的，决定了它全部的难处。

维度监督学习强化学习
反馈信号每个样本有正确标签 $y$，告诉你「答案是什么」只有标量奖励 $r$，告诉你「做得好不好」，不告诉正确动作
数据分布样本 i.i.d.，与模型无关地给定数据由 agent 自己的策略生成；策略一变分布就变（非平稳、非 i.i.d.）
反馈时机即时：预测完立刻知道对错延迟：奖励可能在很多步之后才出现（信用分配难题）
目标最小化预测误差（单步）最大化长期累积回报（序贯，含未来）
RL 的本质难点

这三点不同里，最致命的是数据由策略自己生成。监督学习的训练集是固定的、给定的；而 RL 里你想学的策略同时也是产生训练数据的策略——策略变好 → 它去到新的状态 → 产生新的数据 → 又改变策略。这个自反馈回路是 RL 一切不稳定的根源，也是「探索」之所以是核心问题的原因：如果你的策略从不去某个状态，你就永远学不到那里该怎么做。监督学习里没有「探索」这回事，因为数据已经摆在那了。

第二致命的是延迟回报与信用分配（credit assignment）。下一盘棋，第 30 步走错导致第 80 步输掉——奖励（输）在第 80 步才出现，但功过要算到第 30 步头上。RL 必须解决「这个延迟到来的回报，该归因于此前哪一步」的问题。折扣因子、时序差分、GAE，本质都是在处理信用分配：把未来的奖励，以某种方式、按某种权重，回传给此前的状态和动作。这条主线会贯穿全部六个模块。

理解了这三点，就能理解本课模块的安排逻辑：先（模块 01）在已知模型的理想情况下，用 Bellman 方程把「长期价值」算清楚——这是不含学习、不含探索的纯规划，是一切的参照系；再（模块 02）拿掉模型，只靠采样学习，逼出时序差分与 Q-learning；然后（模块 03–04）从「学价值」转向「直接学策略」，处理策略梯度的方差问题；最后（模块 05）回到最纯粹的探索困境——单状态的多臂老虎机，把 explore-exploit 这个 RL 灵魂问题单独拎出来讲透。

3课程地图：从 Bellman 到 GAE

课程地图：从 Bellman 方程到 GAE

已知模型(规划) → 未知模型(学习) 模块 01 MDP & Bellman MDP 五元组、回报/折扣、Bellman 期望/最优方程 │ 价值迭代 + 策略迭代（压缩映射保证收敛到 V*） │ 「有模型时，长期价值怎么算清楚？」 ▼ 模块 02 TD & Q-learning TD(0) 自举、Q-learning(off-policy)、SARSA(on-policy) │ ε-greedy 探索、Robbins-Monro 收敛 │ 「没有模型，只靠采样怎么学到最优？」 ▼ ─────────── 从「学价值」转向「直接学策略」 ─────────── 模块 03 Policy Gradient log-derivative trick、策略梯度定理、REINFORCE │ baseline 降方差、回报标准化、熵正则 │ 「能不能不学价值，直接对策略求梯度？」 ▼ 模块 04 Actor-Critic & GAE 用 critic 估 advantage 替代 MC 回报 │ TD-error 作 advantage、GAE(λ) 调 bias-variance、A2C │ 「怎么把策略梯度的方差再压下去？」 ▼ 模块 05 Bandits & 探索 单状态老虎机：regret、ε-greedy、UCB1、Thompson 「explore-exploit 的最纯形式与最优解」

注意这不是松散的专题集合，而是一条逻辑递进的链。前两个模块沿「价值」展开：先有模型（DP），再无模型（TD/Q-learning）；中间两个模块转向「策略」：先纯策略梯度（REINFORCE），再用 critic 降方差（actor-critic/GAE）。而 GAE（模块 04）回头用到了模块 02 的 TD 误差、模块 01 的 Bellman 结构——它就是「把 TD 误差按 $(\gamma\lambda)$ 几何加权」，是前面所有零件的精巧组装。最后的老虎机（模块 05）则把贯穿全课的 explore-exploit 困境，剥离到最干净的单状态形式去彻底讲透。

每一级台阶都对应一个可独立验证的能力：模块 01 你手写的价值迭代与策略迭代会收敛到同一个 $V^*$（且对拍解析解）；模块 02 你的 Q-learning 在 GridWorld 上学出的贪心策略会等于 DP 求出的最优策略；模块 03 你能数值验证 baseline不改变梯度期望却显著降方差；模块 04 你的 GAE 在 $\lambda=1$ 时退化为蒙特卡洛优势、$\lambda=0$ 时退化为单步 TD；模块 05 你跑出的 UCB/Thompson 的 regret 会是次线性 $O(\log T)$ 而 ε-greedy（固定 ε）是线性的。每一步都有 assert 兜底，绝不靠「感觉对了」。

4方法论：纯 numpy + GridWorld + 对拍真值

方法论：为什么纯 numpy、为什么 GridWorld？

本课不装 gym、不装 torch，环境是几十行 numpy 手写的 GridWorld 与 toy MDP/老虎机。这看起来「简陋」，却是经过深思的选择，背后是两条纪律。

第一条纪律：在能求出真值的环境里学算法。GridWorld 状态少到可以枚举全部 $(s,a)$，于是我们能用动态规划解出解析精确的 $V^*$、$Q^*$、$\pi^*$。有了这个 ground truth，每个无模型算法都能对拍：Q-learning 学到的 $Q$ 该逼近 DP 的 $Q^*$，学出的贪心策略该等于 DP 的 $\pi^*$。这就像学物理先在无摩擦的理想斜面上验证 $F=ma$——不是因为现实没有摩擦，而是要先确认定律本身没记错。RL 算法的 bug 极其阴险（一个折扣放错位置、一个 max 写成 mean、advantage 符号反了），在能对拍真值的小环境里，这些 bug 会被 assert 当场抓住；而在 gym 的复杂环境里，它们只会让曲线「看起来差不多但其实错了」。

直白说

打个比方：学开车不必一上来就上高速。GridWorld 是 RL 的「驾校训练场」——画好了线、限定了速度、撞了也不要紧，但方向盘、油门、刹车的肌肉记忆和真实道路完全一样。你在这里练的是 Bellman 备份、TD 更新、策略梯度这些和环境规模无关的核心操作。

严谨说

形式上：表格型设定剥离了函数逼近这个混淆变量。深度 RL 的不稳定来自三者叠加（自举 + off-policy + 函数逼近 = deadly triad，Sutton & Barto §11.3）。本课全程表格型，没有函数逼近这一项，于是 TD/Q-learning 有干净的收敛保证（Robbins-Monro）。这让你能确信：算法骨架是对的；到了 C41 出问题，那是神经网络这个放大器引入的，不是算法逻辑错了。

第二条纪律：固定随机种子，让每个结论可复现。RL 实验的随机性极大——同一算法、不同种子，曲线可能天差地别。本课每个随机实验都固定 rng = np.random.default_rng(seed)，保证你重跑得到逐位相同的结果，每个 assert 都稳定通过。这不只是为了教学整洁：「报告多个种子、固定种子可复现」是严肃 RL 研究的基本纪律（太多论文的「提升」其实在种子方差之内）。本课从第一天就把这个习惯种下。

RL 概念本课的 numpy 实现对应真实工具
环境 environment手写 GridWorld 类（step/reset 返回 s,r,done）gym.Env / gymnasium
价值表 V/Qnumpy 数组 V[s] / Q[s,a]神经网络（DQN 的 Q 网络）
策略 πsoftmax over logits 或 ε-greedy策略网络（PPO 的 actor）
最优解 ground truth动态规划解析求出 V*/Q*/π*（真实环境无真值，故难 debug）
正确性验证对拍 DP 真值 + 固定种子复现刷 benchmark 分数 / 多种子均值

务必清楚本课不教什么：不教 gym/torch API、不调神经网络、不跑 Atari/MuJoCo、不处理高维观测。这些是第二步（C41 深度 RL 接手）。本课负责把第一步——算法的数学骨架与正确性夯死。这一步搞定，第二步的「深度」才不是空中楼阁。

5环境与运行

环境与运行

环境极简：只需 numpy（画 return/regret 曲线可选 matplotlib）。全课 CPU 秒级运行，无需 GPU、gym、torch。

conda create -n rl-foundations python=3.11 -y && conda activate rl-foundations
pip install numpy            # 必需
pip install matplotlib       # 可选，仅用于画 return / regret 曲线
jupyter lab

每个模块配一个 notebook，结构统一：先用 numpy 把算法从零实现并对拍/验证（5–6 个 worked 小节，每节都跑出可打印的结果与 assert 自测），再做 3–4 道带 assert 判分的 ✏️ 练习（先给骨架自己填，再对照 📖 参考答案），最后一个真实数据/真实配置胶囊（用经典 RL 基准设定或真实超参算一笔账，把纸面知识接到现实）。

建议的学习节奏：先读完整章 HTML 把数学推导想透，再打开 notebook 亲手实现。读和做缺一不可——只读会觉得「公式好像懂了」，真正动手写价值迭代的循环、调 Q-learning 的探索衰减、让 baseline 把方差压下去、让 GAE 的 $\lambda$ 滑动时，才会发现魔鬼藏在哪些细节里（折扣的位置、终止状态的处理、advantage 的归一化、置信项的常数）。这门课的深度正是为「动手」服务的。

配套必读：Sutton & Barto《Reinforcement Learning: An Introduction》（第二版全文免费公开）——本课每个模块都对标它的章节，是最权威的同步参考。各算法原始论文（Watkins、Williams、Schulman、Auer 等）见 references.md。

✅ 学完整门课，你应该能：
  1. 写出 Bellman 期望方程与最优方程，实现价值迭代/策略迭代并论证它们为何收敛、收敛多快；
  2. 从零实现 TD(0)、Q-learning、SARSA，说清 on-policy 与 off-policy 的本质区别与各自适用场景；
  3. 推导策略梯度定理与 log-derivative trick，实现 REINFORCE，并数值验证 baseline 为何不引入偏差却降方差；
  4. 实现 actor-critic 与 GAE(λ)，讲清 TD 误差为何是 advantage 的无偏估计、$\lambda$ 如何调 bias-variance；
  5. 实现 ε-greedy、UCB1、Thompson sampling，定义 regret 并解释为何好算法的 regret 是 $O(\log T)$；
  6. 把以上每个表格算法对应到它的深度 RL 后裔（DQN/PPO/SAC/RLHF），知道 C41、C22 在它们之上加了什么。
