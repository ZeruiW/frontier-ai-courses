6 模块 MDP/Bellman · TD/Q-learning · 策略梯度 · Actor-Critic/GAE · 老虎机/探索 纯 numpy 从零实现 对拍精确解 · 固定种子可复现 CPU only · 无需 gym/torch
怎么用： 每个模块先读 HTML 讲解 把数学（Bellman 方程、策略梯度定理、GAE 推导）想透，再跑 notebook 用纯 numpy 从零实现每个算法，在 GridWorld / toy 环境里跑出可复现的曲线，并通过 ✏️ 练习的 assert 判分。配套 术语词典 与 论文清单。本课的立场是：不止会调 gym 和 PPO，而是会从 Bellman 方程一路推到 GAE，并亲手把每个估计量写出来——价值迭代、策略迭代、TD(0)、Q-learning、SARSA、REINFORCE、baseline、actor-critic、GAE(λ)、UCB、Thompson sampling，一个不漏地拆开。全程纯 numpy、CPU 秒级：环境是手写的 GridWorld 与 toy MDP，小到能枚举全部状态、能解析求出真值，于是每个学到的价值/策略都能对拍精确解，每条 regret/return 曲线都能固定随机种子复现。这是后续 C41 深度强化学习（DQN/PPO/SAC）与 C22 推理 RL（RLHF/GRPO）的地基：深度 RL 不过是把这里的表格换成神经网络，地基不牢，上层全是玄学。
