6 模块 位置外推 · 精确注意力 · 稀疏 · 线性/SSM · KV 压缩 · 长基准评测 纯 numpy 从零 + 对拍参考 真实模型/基准配置 CPU only · 无需 GPU
怎么用： 每个模块先读 HTML 讲解 建立直觉与数学框架，再跑 notebook 用纯 numpy 从零实现每条长上下文技术、与朴素参考 np.allclose 对拍、通过 ✏️ 练习的 assert 判分。配套 术语词典 与 论文清单。本课的立场是：「长上下文」不是某个单点技巧，而是一套正交的工程配方——让一个在 4k 上训练的模型，稳定、高效、还真的有用地处理 128k 乃至 1M 的输入。这需要同时解决四个独立的瓶颈：① 位置编码外推（训练没见过的位置怎么办）、② 注意力的内存墙（n×n 矩阵爆显存）、③ 二次复杂度（算力随长度平方增长）、④ KV cache 显存（解码时缓存随长度线性膨胀）。本课五个模块各打一个瓶颈，最后用真实长上下文基准（大海捞针 NIAH / RULER）检验「能看长」是否等于「真的看见了」。纯 CPU/numpy：玩具规模、追求看懂机制，每个实现都与朴素版对拍到 1e-10，逻辑可一对一迁移到真实框架。
