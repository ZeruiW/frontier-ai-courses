怎么用： 每个模块先读 HTML 讲解，再跑 notebook——这门课的 notebook 和前八门有一点不同：它复现的不是模型，而是判断力。你会亲手写出一个bootstrap + 配对检验 + Benjamini–Hochberg 校正的显著性判定器（然后用它去审自己过去的「提升」）、一个完整的 TIDE 式误差分解器（六类误差 + 每类的修复收益 ΔAP）、一个能自动识别「高召回段崩塌 / 低召回段就不高」两种病症的 PR 曲线诊断器、三类经典数据管线 bug 的指纹检测器（类别偏移 / 坐标格式 / 通道顺序）、一个项目叙事自检器（缺代价？缺验证？缺归因？直接给你标出来），以及五道白板题（IoU / NMS / mAP / 匈牙利匹配 / Focal Loss）的参考实现与单元测试。本课的主张只有一句：工业界与学生的差距，不在会不会写模型，而在能不能对自己的结论负责。同一份配置换个种子，检测 mAP 就会抖 ±0.2–0.5——这意味着绝大多数「我把 mAP 提升了 0.3」的说法，在统计上和「我什么都没做」是不可区分的。能主动说出这一点的候选人，和不能的，是两个层次。同样，「mAP 掉了 2 个点」在会误差分析的人手里是一张可执行的待办清单（Bkg 误检占了 1.2 个点 → 先去看广告牌与车身贴纸），在不会的人手里只是一个坏消息。最后两个模块把前面所有课的产出组织成能讲的东西：3–4 个 10 分钟的深度故事、一份带评分要点的题库、以及一条面试前一周的冲刺路线（哪些模块必读、哪些可以放心跳过，见 README）。配套 术语词典 与 参考清单。
