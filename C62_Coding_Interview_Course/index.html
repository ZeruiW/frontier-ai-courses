编程面试实战：算法与数据结构

这是全库 62 门课里最大的一块空白——「链表」「双指针」两个关键词此前零命中，而 HR 白纸黑字写着一面包含 Practical (Coding) Exercise。本课不追求刷题量，只做一件事：把「压力下 45 分钟写出一段正确、可测、讲得清楚的代码」拆成可训练的六个步骤和五张能背下来的模板——双指针与滑动窗口、二分的三套边界、并查集、DP 五步、贪心的交换论证。每一道题都给暴力解与最优解的随机对拍，每一个结论都能被 assert 打脸或验证。

6 模块 双指针 · 滑窗 · 前缀和 · 二分 · 并查集 · DP · 贪心 50+ 题，每题暴力解 ⇄ 最优解对拍 六步答题协议 · 45 分钟时间预算 CPU only · 纯标准库 + numpy · 无需 GPU
怎么用： 每个模块先读 HTML 讲解（讲的是什么时候用哪个模板、以及为什么它不会漏解），再跑 notebook——后者用纯 Python/numpy 把每个技巧从零写一遍，并且每题都配一个随机对拍器：暴力解当作参照系，最优解跑一万组随机数据，一处不一致就 assert 失败。你会亲手实现的东西包括：双指针三形态与可变滑动窗口的统一模板、一维/二维前缀和与差分（二维那个就是 CV 里的积分图）、三套二分模板并用循环不变量断言 + 与 bisect 对拍、手写 quickselect 与堆解法并计时对比、带路径压缩与按秩合并的并查集——然后直接拿它做 bbox 聚类与图像连通域标记、把 NMS 写成图上的极大独立集再写成加权区间调度，用 DP 求出最优解并量化贪心 NMS 的次优程度、以及蓄水池采样、加权采样与 Fisher-Yates 洗牌的统计检验（错误洗牌的偏差会被卡方检验抓出来）。本课的主张是：算法面试的分差，八成不在你会不会那道题，而在三件小事上——有没有先说暴力解（面试官需要一个基线才能评估你的优化）、有没有说出循环不变量（这是「我想清楚了」与「我背下来了」的唯一可观测区别）、有没有自己跑边界用例（写完就说「好了」是最常见的失分点）。这三件事都不需要天赋，只需要把协议练成肌肉记忆。本环境不需要 GPU，也不需要联网或装任何刷题平台的 SDK：所有题目、参考解、对拍器与计时器都内置在 notebook 里，断网可跑，几秒出结果。另外请注意本课的边界：检测专项的白板题（IoU / NMS / mAP / 匈牙利 / Focal 手撕）在 C61-05，机器学习的数学推导在 C07——本课只管通用算法与数据结构这一块，三者互补，不重复。

MODULE 02

哈希、排序与二分

哈希是均摊 O(1) 不是保证 O(1)，而「均摊」这两个字面试官会追问；稳定排序在 NMS 同分场景下是可复现性的前提，不是审美偏好；二分的三套模板与开闭区间不一致导致的死循环——课上用循环不变量把每一套钉死并与 bisect 对拍；「在答案上二分」这个把最优化问题转成判定问题的套路，是中高频题的统一钥匙；Top-K 的三种解法与它们各自的适用区间。

MODULE 03

树、图与搜索

递归三要素与「递归转迭代 = 手写调用栈」；四种遍历 + 层序；BFS 求最少步数、DFS 求所有路径这条判据；并查集（路径压缩 + 按秩合并，单次近似 O(α(n))）——本课直接拿它做 bbox 聚类与切片推理的跨片合并，并与 O(n²) 逐对比较对拍；网格 BFS/DFS 就是图像的连通域标记；拓扑排序的两种写法；最后把 NMS 重述成图上的极大独立集，说明贪心为什么只是近似。
