# 编程面试实战：算法与数据结构

这门课补的是**全库最大的一块缺口**。

在 C00–C61 这 62 门课里，检测、TSR、部署、VLA 这些领域深度已经覆盖得相当密，
C61 还专门做了检测方向的面试题库。但用关键词把全库扫一遍会看到一个尴尬的事实：

| 关键词 | 全库命中 |
|---|---|
| 链表 / linked list | **0** |
| 双指针 / two pointers | **0** |
| 时间复杂度 | 1 门（且只是顺带提到） |
| 哈希表 | 1 门 |

也就是说：**算法与数据结构这一块，此前完全没有覆盖**。

而 HR 给出的一面形式是：

> First Round Interview Format (including but not limited to):
> **Technical Knowledge Assessment, Problem-Solving, and Practical (Coding) Exercise**

第三项 `Practical (Coding) Exercise` 就是这门课要解决的东西。

## 这门课不做什么

它**不是刷题网站的替代品**。刷题量本身不是瓶颈——真正的瓶颈是：
在一个被计时、被围观、还要一边写一边解释的 45 分钟里，
把一个模糊的题面变成一段正确、可测、讲得清楚的代码。

所以本课的组织方式不是「按题号推进」，而是：

1. **一套答题协议**（六步，可训练、可自检）；
2. **五张模板**（双指针与滑窗、二分的三套边界、并查集、DP 五步、贪心的交换论证）；
3. **50+ 道题**，每题都有暴力解与最优解的**随机对拍**——
   因为面试里你没有 judge，唯一能自证正确性的方式就是自己造一个。

## 三条学习路径（按你还剩多少时间选）

### 路径 A · 还有一周（约 10–14 小时）

完整走一遍：`00 → 01 → 02 → 03 → 04 → 05`。

每天一个模块，先读 HTML（40 分钟），再跑 notebook 并**把每道题的参考解遮住自己写一遍**（60–90 分钟）。
第 6、7 天全部用来跑 05 的 timed drill，**严格计时、出声讲、不许中途看答案**。

这是唯一能把「模板」变成「肌肉记忆」的路径。判断你走完了没有的标准很简单：
**能不能在不看笔记的情况下，10 秒内说出「找左边界」那套二分的循环不变量。**

### 路径 B · 还有三天（约 6 小时）

`00 → 01 → 02 → 05`，跳过 03、04 的讲解，只跑它们 notebook 里标了「高频/必会」的题。

理由是题型分布：ML/CV 岗的 coding 题里，**数组/字符串/哈希/二分合起来占了大头**，
树与图偏中频（并查集和网格 BFS 是主要形态），DP 出现频率不低但难题占比小。
三天时间投在 01/02 的边际收益最高。

每天安排：
- **Day 1**：00 全部 + 01 讲解 + 01 的前 5 题。
- **Day 2**：01 剩余 + 02 全部（二分三模板务必手写到不看模板也不写死循环）。
- **Day 3**：03 的并查集 + 04 的 DP 五步 + 05 的 4 道 drill（计时）。

### 路径 C · 只剩一晚（约 3 小时）

**不要试图学新东西，只做两件事**：

1. **读 00**（30 分钟）——把六步协议和 45 分钟预算表背下来。
   这一步的性价比最高：它不增加你会的题，但能让你已经会的题不掉分。
2. **跑 05 的 timed drill**（2 小时）——选 4 道，严格计时，**出声讲**，讲不出来就停下来重讲。
   哪怕题做不完也要坚持出声，因为沟通维度的分是当场给的。

剩下 30 分钟：把 01 的**双指针三形态触发信号**和 02 的**二分三模板**各扫一遍，
这两张表覆盖的题型加起来占比最高。

**明确不要做的事**：不要在最后一晚第一次学 DP。
状态定义这种东西现学现卖，在压力下只会让你在白板前卡死。
遇到 DP 题时诚实地说「我先写一个指数级的记忆化搜索保证正确，再讨论怎么优化」，
这个回答本身就能拿到不错的分数。

## 关于难度与频率标注

每道题都标了两个标签，用来在有限时间里排优先级：

- **频率**：高频 / 中频 / 低频 —— 指的是在**ML/CV 岗**（不是通用后端岗）的出现频率。
  这个分布和刷题网站的热度榜差别不小：矩阵、区间、采样类题在 CV 岗明显更高频，
  而链表、字典树、复杂图论明显更低频。
- **定位**：必会 / 加分 —— 「必会」的意思是答不出会被直接扣分，
  「加分」的意思是答不出不致命，但答出来能显出水平。

**如果时间不够，先把所有「高频 + 必会」的题做完再说。**

## 环境

见 `requirements.txt`。**纯 Python 标准库 + numpy + matplotlib，CPU 可跑，断网可跑，不需要 GPU。**

所有题目、参考解、随机对拍器、计时器与统计检验都内置在 notebook 里，
不依赖任何刷题平台的 API，也不需要联网提交。
每个练习都有紧跟的 `assert` 自测：做错了会立刻告诉你哪一组输入不一致。
