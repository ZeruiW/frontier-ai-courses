1从"会对齐"到"会对话"：visual instruction tuning 的诞生

到模块 04 为止，我们已经能把视觉编码器、connector、LLM 拼成一个 VLM，并用海量图文对做对齐预训练（pretraining / feature alignment）。但这样的模型只是"会描述图"——你给它一张图，它倾向于吐出一句 caption，不会跟你对话、不会follow你的指令、不会做多轮推理。它对齐了模态，却没学会"听话"。

直白讲

对齐预训练教会模型"图和字是怎么对应的"。但它从没见过"用户问一个问题、助手给一个有用回答"这种格式。 指令微调（instruction tuning）就是用一堆"图 + 指令 + 理想回答"的样例，把模型从"会描述"调教成"会对话、会照做"。

严谨讲

预训练优化的是图文条件语言建模 $p_\theta(\text{caption}\mid\text{image})$，分布偏向短描述。 指令微调（SFT, Supervised Fine-Tuning）在 $(\text{image},\,\text{instruction},\,\text{response})$ 三元组上做监督学习， 只对 response 的 token 计交叉熵，把模型的输出分布对齐到"helpful assistant"这一行为模式上。

真正点燃这条路线的是 LLaVA [Liu 2023, Visual Instruction Tuning]。它的关键洞见不是模型结构（结构极简：CLIP 编码器 + 一个线性/MLP 投影 + Vicuna LLM），而是数据的来源：

LLaVA 的核心 trick——用纯文本 GPT-4 自举生成视觉指令数据。 当时的 GPT-4 还看不见图，怎么让它生成"看图对话"？ 办法是把图像符号化：把 COCO 的人工标注——captions（5 句描述）+ bounding boxes（物体类别 + 坐标框）——以纯文本喂给 GPT-4， 让它"假装看过这张图"，据此生成对话、详细描述、复杂推理。GPT-4 从没见过像素，却能基于这些符号写出高质量的视觉指令数据。这是一次经典的能力蒸馏（用强文本模型的推理能力，蒸馏出多模态训练数据）。
COCO 人工标注（纯文本符号化表示） ┌────────────────────────────────────────────┐ │ Captions: "A man is riding a bike on..." │ │ Boxes: person:[0.41,0.52,0.18,0.30] │ │ bicycle:[0.38,0.61,0.22,0.25] ... │ └───────────────────┬──────────────────────────┘ │ 喂给纯文本 GPT-4（看不见图！） ▼ ┌──────────────────────────────────┐ │ GPT-4 生成三类指令数据 │ │ ① conversation 多轮问答 │ │ ② detail description 详细描述 │ │ ③ complex reasoning 复杂推理 │ └───────────────────┬───────────────┘ ▼ (真实图像 image, 指令 Q, 回答 A) 三元组 │ 对真实 VLM 做 SFT ▼ 会对话、会推理的 LLaVA

这套"两阶段"训练范式（先对齐预训练、再指令微调）此后成为几乎所有开源 VLM 的标准配方。本模块讲的就是第二阶段以及之后的偏好对齐。

2SFT 数据构造：detail / conversation / complex reasoning 三类

LLaVA 把视觉指令数据刻意分成三类，因为它们训练出的能力维度不同。研究科学家在评测一个 VLM 时，常常要反推它的 SFT 数据配比，因为配比直接决定能力画像。

类型形式训练出的能力评测/失败模式视角
conversation 对话多轮 Q&A，问物体、数量、位置、动作等可从图直接读出的事实多轮对话、指令跟随、感知问答占比过高 → 模型只会"看图说事实"，弱推理
detail description 详细描述单轮，要求详尽描述整张图长文本生成、覆盖度占比过高 → 模型话痨、爱编造细节（幻觉来源之一）
complex reasoning 复杂推理单轮，需要分步推理、常识、推断意图（"为什么"、"接下来会发生什么"）推理、常识、因果最稀缺也最贵；占比过低 → 推理类 benchmark（如 MMMU）拉胯
这三类的本质区别在于答案需要多少"图外知识"。conversation 几乎只需读图；detail description 需要语言组织能力；complex reasoning 需要把图像信息和 LLM 的世界知识做联合推理。后两者更依赖 LLM 底座的强度，前者更依赖视觉编码器的细粒度。

多轮对话的格式与 loss masking

多轮数据按 chat 模板拼成一条序列：<image> User: Q1 \n Assistant: A1 \n User: Q2 \n Assistant: A2 ...。 关键细节：只对 Assistant 的回答 token 计算 loss，User 的提问、image placeholder、系统提示一律 mask 掉（label 设为 -100，被交叉熵忽略）。否则模型会去"学习生成用户的问题"，浪费容量且降质。

$$ \mathcal{L}_{\text{SFT}} = -\sum_{i=1}^{L}\, \mathbb{1}[\,i\in\mathcal{A}\,]\,\log p_\theta\!\left(y_i \mid y_{

其中 $\mathcal{A}$ 是 assistant 回答 token 的下标集合，$\mathbb{1}[\cdot]$ 就是 label mask。这是 SFT 区别于普通语言建模的核心：只在"该回答的地方"学习。

视觉 token 永远不进 loss——它们是 condition，不是 target。一个常见 bug 是 image placeholder 在标签里没被正确替换/mask，导致 loss 异常或维度错位。读任何 VLM 训练代码，第一件事就是确认 labels 在哪些位置被设成 -100。

3高效微调：LoRA 与 QLoRA 的数学

一个 7B VLM 全参微调（full fine-tuning）需要存优化器状态、梯度、激活，单卡显存动辄上百 GB。研究迭代要快、要省，于是参数高效微调（PEFT, Parameter-Efficient Fine-Tuning）成为标配。其中最重要的是 LoRA。

LoRA：低秩增量 [Hu 2021]

直白讲

微调时权重的变化量 $\Delta W$ 其实"信息含量很低"——它躺在一个低维子空间里。 与其更新整个大矩阵，不如只学一个又瘦又小的"补丁"$BA$，原权重 $W_0$ 冻住不动。要训练的参数瞬间降到原来的零点几个百分点。

严谨讲

假设权重更新具有低内在秩（low intrinsic rank）。对线性层 $W_0\in\mathbb{R}^{d\times k}$， 把更新约束为低秩分解 $\Delta W = BA$，其中 $B\in\mathbb{R}^{d\times r}$、$A\in\mathbb{R}^{r\times k}$、秩 $r\ll\min(d,k)$。 训练时只更新 $A,B$，$W_0$ 冻结。

$$ h = W_0 x + \Delta W x = W_0 x + \frac{\alpha}{r}\,B A\,x, \qquad B\in\mathbb{R}^{d\times r},\; A\in\mathbb{R}^{r\times k},\; r\ll\min(d,k) $$

几个必须理解的点：

  • 秩 $r$：低秩瓶颈宽度。$r$ 越大表达力越强、参数越多；典型取 $8/16/32/64$。VLM 上常比纯 LLM 略大些。
  • 缩放 $\alpha$：把增量缩放为 $\frac{\alpha}{r}BA$。$\alpha/r$ 是有效学习强度；调 $r$ 时常同比例调 $\alpha$（如保持 $\alpha=2r$），使更新幅度大致不变。
  • 初始化：$A$ 用高斯随机、$B$ 初始化为 0，于是训练开始时 $\Delta W=BA=0$，模型行为等于原模型——保证微调从"无害"起步。
  • 可训练参数量：$r(d+k)$，相比全参 $dk$ 通常是0.1%–1% 量级。
  • 推理可合并：$W = W_0 + \frac{\alpha}{r}BA$ 可预先合并，推理零额外延迟（区别于 adapter）。
在 VLM 里，LoRA 通常加在 LLM 的注意力投影（q_proj/k_proj/v_proj/o_proj）和 MLP（gate/up/down_proj）上；视觉编码器常整体冻结，connector（投影层）则全参训练（它小，且是模态桥梁，值得全量更新）。"哪些模块挂 LoRA、哪些冻结、哪些全训"是 VLM 微调的核心设计选择。

QLoRA：4-bit 量化基座 + LoRA [Dettmers 2023]

LoRA 把可训练参数降下来了，但冻结的 $W_0$ 仍以 fp16 占着显存。QLoRA 进一步把基座本身量化到 4-bit，让 7B 模型在单张消费级卡上也能微调。三个关键技术：

技术做了什么为什么有效
NF4（4-bit NormalFloat）一种为近似正态分布的权重设计的 4-bit 数据类型，量化分位点按正态分布信息论最优摆放神经网络权重近似 $\mathcal{N}(0,\sigma^2)$，NF4 比普通 int4/fp4 量化误差更小
双重量化（double quantization）把量化用的 scale/缩放常数再量化一次量化常数本身也占显存（每 block 一个），二次量化省下约 0.4 bit/参数
paged optimizer用 NVIDIA 统一内存，把优化器状态在显存↔内存间分页换出避免长序列/峰值时的 OOM 崩溃
关键点：QLoRA 训练时，前向计算会把 4-bit 权重临时反量化（dequantize）回 bf16 参与矩阵乘，梯度只流向 fp/bf16 的 LoRA 参数 $A,B$；4-bit 基座始终冻结、不接收梯度。所以"4-bit"省的是存储，计算精度由反量化保证。论文证明 QLoRA 微调 65B 模型可在单张 48GB 卡完成，几乎不掉点。本章 notebook 用的就是这条路线（BitsAndBytesConfig(load_in_4bit=True, bnb_4bit_quant_type="nf4")）。

4偏好对齐：RLHF 流程与 DPO 推导

SFT 教模型"模仿好的回答"，但它只见过正样本，不知道"什么是更差的回答、为什么差"。偏好对齐（preference alignment）用成对比较（人类/模型更喜欢 A 还是 B）进一步打磨输出质量、有用性、安全性，并——对 VLM 尤其重要——抑制幻觉。

经典 RLHF 三段式

① SFT 得到 π_ref（参考策略，也是初始策略） │ ② Reward Model 用人类偏好对 (y_w ≻ y_l) 训练一个打分器 r_φ(x,y) │ （Bradley-Terry：P(y_w≻y_l)=σ(r(x,y_w)-r(x,y_l))） ▼ ③ PPO 强化学习最大化 r_φ，同时用 KL 拉住别跑太远： max_π E[r_φ(x,y)] − β·KL(π ‖ π_ref)

RLHF 效果好，但工程上痛：要训练并维护一个独立的 reward model，PPO 训练不稳、超参敏感、要同时在显存里放 4 个模型（policy / ref / reward / value）。DPO [Rafailov 2023] 的贡献是：把这套 RL 流程化简成一个等价的、可直接用偏好对做监督的分类损失，绕开显式 reward model 和 PPO。

DPO 推导：从 RLHF 目标到一个分类损失

第一步，KL 约束下的 RLHF 目标有闭式最优解。最大化 $\mathbb{E}[r(x,y)]-\beta\,\mathrm{KL}(\pi\|\pi_{\text{ref}})$ 的最优策略为：

$$ \pi^*(y\mid x) = \frac{1}{Z(x)}\,\pi_{\text{ref}}(y\mid x)\,\exp\!\Big(\tfrac{1}{\beta}\,r(x,y)\Big) $$

第二步，反解出奖励——把 $r$ 用策略表示（这就是 隐式奖励，DPO 的灵魂）：

$$ r(x,y) = \beta\,\log\frac{\pi^*(y\mid x)}{\pi_{\text{ref}}(y\mid x)} + \beta\log Z(x) $$

第三步，代入 Bradley-Terry 偏好模型 $P(y_w\succ y_l)=\sigma\big(r(x,y_w)-r(x,y_l)\big)$。配分函数 $Z(x)$ 只依赖 $x$，在差值中抵消。于是偏好概率只用策略本身就能写出，得到 DPO 损失：

$$ \mathcal{L}_{\text{DPO}}(\theta) = -\,\mathbb{E}_{(x,y_w,y_l)}\Big[\log\sigma\Big(\beta\log\frac{\pi_\theta(y_w\mid x)}{\pi_{\text{ref}}(y_w\mid x)} - \beta\log\frac{\pi_\theta(y_l\mid x)}{\pi_{\text{ref}}(y_l\mid x)}\Big)\Big] $$

把隐式奖励记为 $\;r_\theta(x,y)=\beta\log\dfrac{\pi_\theta(y\mid x)}{\pi_{\text{ref}}(y\mid x)}$，则损失就是一个标准的二分类（logistic）目标：

$$ \mathcal{L}_{\text{DPO}} = -\,\mathbb{E}\big[\log\sigma\big(r_\theta(x,y_w)-r_\theta(x,y_l)\big)\big] $$

直白讲

DPO 不再训一个独立的打分器。它直接说：语言模型自己就是奖励模型——一个回答"相对参考模型变得多大概率"就是它的隐式奖励。 训练目标很朴素：让 chosen 回答的概率相对参考模型涨、rejected 的相对降，二者拉开差距。

严谨讲

$\beta$ 控制偏离 $\pi_{\text{ref}}$ 的强度（等价于 RLHF 里的 KL 系数）：$\beta$ 大 → 更保守、贴近参考；$\beta$ 小 → 更激进。 梯度 $\nabla_\theta\mathcal{L}\propto -\sigma\big(\hat r_l-\hat r_w\big)\big[\nabla\log\pi_\theta(y_w)-\nabla\log\pi_\theta(y_l)\big]$， 即"模型当前越搞错偏好（$\hat r_l>\hat r_w$），更新越大"，是自带难例加权的对比学习。

实践三个坑：①$\pi_{\text{ref}}$ 通常就是 SFT 模型并全程冻结，每步要算它在 chosen/rejected 上的 logprob（显存里得放第二个模型，或用 LoRA 时直接禁用 adapter 当作 ref）。②DPO 前一般要先做一轮 SFT，否则 $\pi_{\text{ref}}$ 太弱、偏好信号无意义。③可能出现"chosen 和 rejected 概率同时下降、只是 rejected 降更多"的退化——监控两者的绝对 logprob，而非只看 margin。

5VLM 特有的对齐：抑制幻觉

在纯文本 LLM 里，对齐主要追求 helpful/harmless。到了 VLM，对齐多了一个压倒性的目标：抑制 object hallucination（物体幻觉）——模型描述出图里根本没有的物体、属性、关系。这是 VLM 评测（模块 07/08）最关注的失败模式之一。

为什么 VLM 爱幻觉？ 三个结构性原因：①SFT 数据里 detail description 充斥着"丰富但未必都被图支持"的描述，模型学会了"宁可多说"的语言先验；②LLM 底座的强语言先验会"脑补"常见共现物体（看到餐桌就说有叉子）；③视觉信号在长序列里被语言 token 稀释，模型逐渐"不看图、凭语言惯性往下说"。

直白讲：为什么对齐能减少幻觉

幻觉的回答和忠实的回答，往往用 SFT 的交叉熵看起来"都挺像样"，模型分不清。 偏好对齐直接给它成对样本："这个忠实于图的回答 > 这个编造了物体的回答"， 手把手教它压低脑补、抬高据图直说的概率。这是 SFT 给不了的负反馈。

严谨讲

SFT 是最大似然，只在正样本上施压，无法显式惩罚"高似然但不忠实"的输出（语言先验导致的幻觉恰恰高似然）。 偏好对齐引入对比/负向信号：DPO 的隐式奖励直接降低 rejected（幻觉）相对 $\pi_{\text{ref}}$ 的概率， 在分布上削弱与图像不一致的生成路径。

三条代表性路线

方法核心思想偏好对怎么来
RLHF-V [Yu 2024]细粒度人工纠正：标注者把模型回答中幻觉的片段级错误改对(原回答=rejected, 段级纠正后=chosen)，密集、精准、信号干净
POVID免人工：用 GPT-4V 注入错误 / 加噪图像，自动合成幻觉负样本chosen=真实回答；rejected=故意诱发幻觉的回答
mDPO给 DPO 加图像维度的偏好：同一文本下，对齐的图(chosen) vs 扰乱/无关的图(rejected)，逼模型"真的看图"构造 (image_w, image_l) 视觉偏好对，缓解 DPO 只学文本先验
标准 DPO 用在 VLM 上有个隐患：偏好对里 chosen/rejected 共享同一张图，文本差异大、图像无差异，模型可能学成"只看文本、忽略图像"的捷径——反而削弱视觉依赖。mDPO 正是针对这点：额外加一组只改图、不改文本的偏好对，强制梯度流经视觉路径。评测对齐过的 VLM 时，要专门验证"它是真的更看图了，还是只是文本风格变了"。

6训练实操要点：超参、冻结、灾难性遗忘

这一节是把上面的原理落到"调得动、调得对"的工程经验。研究科学家做评测时，理解这些超参如何影响行为，才能解释"为什么这个 checkpoint 这么表现"。

学习率与 warmup

  • LoRA 学习率远高于全参：LoRA 典型 $1\text{e-}4 \sim 2\text{e-}4$；全参微调通常 $1\text{e-}5 \sim 2\text{e-}5$。因为 LoRA 只动少量新参数，可以也需要更大步长。
  • connector 和 LLM 常用不同学习率：connector（新随机初始化）需要更大 lr，LLM（已预训练）需要更小 lr，避免一上来就破坏预训练知识。
  • warmup + cosine decay：前 3% 步线性 warmup，避免初期大梯度毁掉对齐；之后余弦衰减。VLM SFT 通常只跑 1 个 epoch（数据已是高质量蒸馏，多跑易过拟合 + 加重幻觉）。

冻结 vs 全参：一张决策表

组件对齐预训练阶段指令微调阶段理由
Vision Encoder冻结冻结（或最后几层小 lr 解冻）保护 CLIP 学到的视觉表征；解冻易过拟合且贵
Connector（投影）训练训练模态桥梁，必须学；它小，全参训也便宜
LLM冻结训练（全参 or LoRA）预训练只对齐特征；指令阶段才教 LLM "听话"

灾难性遗忘与模态偏置

纯文本能力退化：在多模态指令数据上微调 LLM，常导致它的纯文本能力（数学、代码、长文本推理）显著下降——这是 catastrophic forgetting 在 VLM 上的典型表现。缓解手段：①在 SFT 数据里混入纯文本指令数据（LLaVA-1.5 等的常见配方）；②用 LoRA 而非全参（低秩增量天然限制了对原能力的破坏）；③更小学习率 + 单 epoch。
模态偏置 / 语言捷径（modality bias / language shortcut）：模型倾向于不看图、只靠语言先验和问题本身作答。诊断方法很硬核——把图换成噪声或无关图，看准确率掉多少。掉得越少，说明模型越没在"看图"。很多 benchmark 的高分其实是语言先验刷出来的（MMStar [Chen 2024] 专门审计了这点，模块 07 详述）。

7评测视角：分别评测"能力提升"与"幻觉变化"

指令微调和对齐做完，必须分两条线评测，因为它们可能此消彼长——对齐降幻觉的同时可能降有用性/丰富度（"对齐税"）。把这两件事混在一个指标里看，会得出完全错误的结论。

幻觉变化是否更少描述不存在的物体？是否更忠实于图？POPE、HallusionBench（→ 08）
能力保持纯文本能力是否退化？是否还看图（非语言捷径）？纯文本基准回归 + 图像扰动对照（→ 07/08）
对齐税（alignment tax）的评测意识：一个 DPO 降了 POPE 幻觉率的 checkpoint，可能同时让回答变短、变保守，在 MM-Vet 这类"奖励丰富有用回答"的 benchmark 上掉点。报告对齐效果时，幻觉↓ 和 能力↓ 必须一起报，单独报任何一边都是误导。这正是模块 07/08 要训练的评测纪律。
评测幻觉的两种范式先记住：POPE [Li 2023] 把幻觉转成判别式问题——"图里有没有 X？"（yes/no），用采样策略（random/popular/adversarial）专门戳语言先验，可量化、可复现。HallusionBench [Guan 2024] 则用精心设计的图文陷阱测语言先验 vs 视觉证据的冲突。两者都在模块 08 展开。

8研究前沿与开放问题

  • 数据质量 vs 数量：LLaVA 用 GPT-4 蒸馏数据，但蒸馏会继承教师的偏见和幻觉。如何检测并过滤合成指令数据中的幻觉、用更弱监督拿到更忠实的数据，仍是开放问题。评测视角：训练数据的幻觉率是否可预测下游模型的幻觉率？
  • DPO 之后的对齐算法：KTO、IPO、ORPO、SimPO 等不断改进 DPO 的稳定性、对 $\beta$ 的敏感性、对偏好对质量的鲁棒性。在 VLM 上哪种最抗"语言捷径"尚无定论。
  • 对齐税的来源：为什么降幻觉常伴随有用性下降？是数据分布问题还是目标函数固有的？能否设计同时优化忠实性与有用性的目标（多目标对齐）？
  • 过程级 vs 结果级偏好：RLHF-V 的片段级纠正提示——更细粒度的偏好信号（token/段级）可能比整段偏好更高效。如何低成本获取过程级监督？
  • 评测的可信度：很多"对齐让 VLM 变好"的结论建立在易被语言先验刷分的 benchmark 上。建设抗捷径、真正考视觉依赖的评测（MMStar 方向）是评测研究科学家的核心战场（→ 07/08）。
