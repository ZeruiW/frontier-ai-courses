# C72 · 多视角几何与多传感器时空对齐

> **纯几何、无学习。** 全程 numpy / CPU / 断网可跑，不训练任何网络，不依赖 OpenCV。
> 本课自己实现投影、去畸变、DLT、标定约束、三角测量、PnP、IPM 与时间对齐——
> 因为「调 `cv2.undistortPoints`」学不到误差从哪来。

## 这门课在回答什么

检测课教的是「框在哪一格像素上」。而下游要的从来不是像素，是**米**。
**从像素到米，中间是一条有五个坐标系、每一环都会引入误差的链。
这门课的全部内容就是：把每一环的误差精确换算成米。**

而这一层的特点是：**几何错误不会报错，它只会安静地给出一个错误的米数。**

## 六个模块

| 模块 | 主题 | 带走的那个可计算的量 |
|---|---|---|
| 00 | 课程总览与环境 | `d_read = d·H/(H−z)`，相对误差 `z/(H−z)` **与距离无关** |
| 01 | 相机模型与畸变 | 畸变位移 0.26 → 197.71 px（**750 倍**，$\propto r^3$） |
| 02 | 标定：内参、外参与验收 | σ(pitch) **3.74° → 0.035°**，靠扩大图像行覆盖 |
| 03 | 多视角几何 | $Z^2$ 定律，以及公式里的 $\Delta d$ 要乘 $\sqrt2$ |
| 04 | BEV 投影与多相机融合 | **1% 坡度 = +50% @50m**，临界距离 $H/s$ |
| 05 | 时空对齐与跨镜关联 | 时间戳错位 × 车速；**与距离无关，与车速严格正比** |

## 本课的中心结论

**地面 IPM 对交通标志不适用**——而这有一个精确的形式：

$$d_{\text{read}} = d\cdot\frac{H}{H-z},\qquad
\frac{d_{\text{read}}-d}{d} = \frac{z}{H-z}$$

三条推论：

1. **相对误差与距离无关**。$H{=}1.5$、$z{=}1$ 时，10 m 读成 30 m、50 m 读成 150 m，
   **永远是 3 倍**。这否掉了「先做近处、远处以后再修」这个常见计划。
2. **$z=H$ 时发散**，而乘用车相机高度就是 1.2–1.5 m。
3. **$z>H$ 时无解**——射线在地平线以上。**而限速牌中心通常离地 2.0–2.5 m。**

所以 IPM 不是「差」，是**非常准但适用范围极窄**：
模块 03 量出它在假设成立时精度最高（±0.68 m @50m，优于已知尺寸的 ±1.30 m
与双目的 ±2.08 m）。把它用在标志上是**用错了工具**。

## 几个与直觉相反、而本课量出来的结论

- **多拍不能替代换朝向**：纯平移或只绕光轴转，拍 5 张的约束 rank 仍然是 2（需要 5）。
- **DLT 归一化的收益是数值条件，不是精度**：无噪声时值 45.8 倍，
  而 0.2 px 角点噪声一加上，差别只剩 13%，且归一化**略差**。
- **想把远处标准，采集必须覆盖近处**：只采远处地面时 σ(pitch)=3.74°，
  扩到全画幅是 0.035°——**改善 106 倍**，而这与「多拍几张」无关。
- **PnP 正交化不提高精度**：方向误差只改善 1.24 倍，重投影 RMS 反而变差 0.905 倍。
  它的理由是**合法性**（下游需要一个真正的旋转矩阵）。
- **rolling shutter 对小目标不值得建模**（0.005 px），而「整帧一个时间戳」值 0.667 m。
- **该外推就外推**：等一个 IMU 周期的延迟代价比外推误差大 2222 倍。

## 两个「本课自己的配置通不过自己的验收」

这不是失误，是设计：**验收清单要能抓住真实的疏漏，包括作者的。**

- 模块 02 练习 4：5 视角的标定配置 rank、Δv、重投影误差**全部合格**，
  却栽在「一个角点都没采到画幅边缘」上。
- 模块 04 练习 4：0.1 m 均匀网格 + 关心 80 m，在**采样率**与**坡度**两项上同时不合格。
  而修法不是调参数，是缩小 IPM 的适用范围。

## 为什么用合成场景

几何这一层要回答的全是「误差有多大」，而**真实数据集里没有一个字段告诉你
「这块标志离地 2.13 m」**。合成场景里每个点的三维坐标、每台相机的精确内外参、
每一帧的精确时间戳都是已知的——所以可以问「把外参故意拧错 1°，读出的米数变了多少」
并得到一个可断言的答案。

代价也说清楚：合成场景没有真实的噪声结构，也没有真实的畸变
（本课用标准 Brown–Conrady，广角/鱼眼在画幅角上会超出它的表达能力，
模块 01 第 6 节给出判别方法）。**所以本课的相对结论可迁移，
具体像素数只属于本课的合成配置。**
