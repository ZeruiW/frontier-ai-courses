文本数据增强与合成数据工程

标注不够时怎么「造」数据，以及——更重要的——怎么证明造得有用：词面增强 · 回译与释义 · LLM 指令合成 · 质量控制 · 能证伪自己的实验设计

6 模块 EDA · 回译 · Self-Instruct · Evol · Magpie 保真度 × 多样性 × 有效性 三重检验 规则可判定任务 -> 保真度可精算 CPU only · 无需 GPU/翻译模型/LLM API
怎么用： 每个模块先读 HTML 讲解——它不只讲「怎么造」，更讲「怎么判断造得有没有用」；再跑 notebook 用纯 numpy 把每种增强与每套检验从零实现：EDA 四操作与保护规则、可控失真的模拟回译器、完整的 Self-Instruct 循环与 ROUGE-L 去重、三层去污染检测、多样性度量、模式坍塌看板、配对 bootstrap 与功效分析。每个增强都必须过三重检验：保真度（标签有没有被破坏）、多样性（新样本有多新）、有效性（下游指标真的涨了且超过噪声）。每个练习都有紧跟的 assert 自测判分。配套 术语词典 与 参考清单。本课的立场是「有条件的怀疑」：增强在小数据、低资源、长尾与零标注冷启动场景确实有用，但增强的文献里充满了「在小数据集上涨了 1 分」这类不可靠结论（种子方差本身就有 2–3 分）。所以本课给你的不是「增强很棒」的信念，而是「怎么在自己的数据上判断它到底有没有用」的能力——包括接受「没用」这个答案。本环境没有 GPU / 翻译模型 / LLM API：我们用参数可控的模拟增强器（带 distortion 的假翻译器、带 bias/collapse 的假教师），并用规则可判定的合成任务让「标签保真度」变成一个可精确计算的数字——这让本课能做真实环境里做不到的实验，比如「把教师偏差从 0 调到 0.5，看学生的偏差怎么变」。
