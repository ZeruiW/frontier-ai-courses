# C67 · LLM-as-a-Judge 与评分模型

> **一句话**：本课教你怎么<strong>验证判分器本身</strong>——而 C66 教你怎么用判分器去量一个 agent。

6 个模块 · 纯 numpy / CPU / 断网可跑 · 每个模块 4 道 `✏️ 练习`（assert 判分）+ `📖 参考答案` +
`🧪 真实工程胶囊`。

## 这门课补的洞

| 已有 | 覆盖了什么 | 缺什么 |
|---|---|---|
| **C03 模块 04** · LLM judge | 一节课：judge 的存在、基本 prompt 形式、几个偏差的名字 | 怎么量化每个偏差、怎么在报告里把它减掉 |
| **C66** · Agent 评测 | 全课都在**使用**判分器（含 LLM judge） | judge 本身怎么被验证 |
| **C10** · 测量科学 | 标注、kappa、IRT、校准 | 「人类上界」与「judge 分辨力」这两个 judge 特有的量 |

核心主张：

> **judge 不是裁判，是一台测量仪器。**
> 尺子的误差与被测物无关；LLM judge 的误差与被测物**强相关**——
> 长文本被高估、自己的输出被高估、排在特定位置的被高估。
> 这意味着误差不会在平均之后抵消，而是**系统性地奖励某一类输出**。
> 先验证仪器，再相信读数；而一旦仪器变成优化目标，它就开始失效。

## judge 体检六项清单

任何一份用了 LLM judge 的报告，都应当能回答这六项。**全部答不上来的报告，读一下当参考即可，不要拿来做决策。**

| # | 检查项 | 缺了它会怎样 | 展开在 |
|---|---|---|---|
| 1 | 与人类的一致率，**且给出人类之间的一致率作为上界** | 读者把 0.82 与 100% 比，系统性低估 judge | 03 |
| 2 | swap 一致性（交换 A/B 后翻转比例） | 胜率可能大部分来自位置偏差 | 02 |
| 3 | 长度偏差幅度（控制质量后的边际效应） | 分数提升可能只是「写得更长」 | 02 |
| 4 | 自偏好（评自己 vs 评他人的分差） | 新版本的「提升」可能只是更像 judge 自己 | 02 |
| 5 | 分辨力（能不能区分已知差 X 点的两个模型） | 不知道这个数字有没有用 | 00 / 03 |
| 6 | 漂移（同一批样本隔一段时间重判） | 指标曲线上的跳变无法解释 | 03 |

## 一条贯穿全课的逻辑

```
00 仪器      judge 的误差与被测物相关 → 必须先验证仪器
01 设计      仪器的量程与噪声由设计决定 → 能写成校验就别打分
02 去偏      把系统偏差量出来、减掉、诚实报告残留的不可识别性
03 元评测    用人类上界校准你对「一致率」的解读
04 排名      聚合成排行榜时，看区间不看名次
05 训练信号  一旦仪器变成目标，它就开始失效 → 必须有独立信号
```

## 学习路径

### 路径 A · 完整走一遍（约 10–12 小时）

`00 → 01 → 02 → 03 → 04 → 05`，每天一个模块。

判断走完了没有的标准：**给你一份用了 LLM judge 的评测报告，
你能不能在五分钟内指出它缺了体检六项里的哪几项，以及这些缺失分别会让哪些结论失效。**

### 路径 B · 只想把手上的 judge 做对（约 4 小时）

`00 全部 → 01 全部 → 02 全部 → 03 第 2 节（人类上界）`。

理由：**01 的设计与 02 的去偏是「做了就立刻有收益」的两块**；
04 的排名只在你要出榜单时才需要，05 只在你要训 RM 时才需要。

### 路径 C · 只有两小时

`00 的三种用法 → 01 的 rubric 分解 → 02 的 swap 与长度控制 → 03 的人类上界`。

这四块是「知道了就能立刻少犯错」的部分。
