1为什么 mech interp 是 evaluation scientist 的显微镜

你已经在前面六门课里学会了把"跑个分"升级成"做测量"：误差棒、污染检测、能力引出、harness 工程。 但行为评测（behavioral evaluation）有一个结构性天花板：它只能观测输入–输出对， 把模型当黑箱。同一个外部行为，可以由完全不同的内部机制产生——而机制不同，意味着泛化、风险与失效模式完全不同。

直白讲

一个学生考了 90 分。他是真懂了，还是背了题库，还是猜对的，还是抄的？卷面分数本身分不清这四种情况—— 但下次换一张卷子，四种学生的命运截然不同。行为评测就是只看卷面分；机制可解释性是把学生的"草稿纸" （模型内部的激活与权重）拿过来看：他到底是怎么算出这个答案的。

严谨讲

行为评测估计的是条件分布 $p_\theta(y\mid x)$ 在某个任务分布上的统计泛函（正确率、win rate 等）。 但多个机制上不同的参数化可以在评测分布上产生几乎相同的 $p_\theta(y\mid x)$，却在分布外（OOD）分道扬镳—— 这正是构念效度 (construct validity)问题的机制版本。 Mechanistic interpretability 的目标是对网络内部计算做因果层面的逆向工程： 找出权重与激活中实现某个能力的具体回路 (circuit)，从而区分"行为等价但机制不同"的假设 [Olah 2020]。

对 evaluation 方向的 research scientist 来说，interp 至少在四类问题上提供行为评测给不了的证据：

评测中的难题行为评测的局限interp 能提供什么本课模块

一句话定位本课：前六门课教你把行为测准；这门课给你拆开机器的螺丝刀。 显微镜不取代体检表——interp 的结论同样需要评测科学的严谨性来约束（探针会作弊、解释会过拟合，模块 01/07 会专门讲）， 两者是互相校验的关系。

2核心世界观：residual stream 与"激活是向量"

整门课建立在一个统一的几何图景上，先把它立起来（模块 01–06 会反复回到这张图）：

token ──► embedding ─────────────────────────────────────► unembed ──► logits │ residual stream（贯穿全程的向量通道） ▲ │ x ∈ R^d_model │ ▼ │ x₀ ──►(+)──► x₁ ──►(+)──► x₂ ──► ... ──►(+)──► x_L ─────────┘ ▲ ▲ ▲ │ │ │ attention 头 MLP 层 attention/MLP "读取 x，写回 "读取 x，写回 每个组件都只是 一个向量" 一个向量" 向 stream 加一个向量
  • Residual stream 是中央总线：每层的 attention 头和 MLP 都从 stream 里读（线性投影）， 算完后把结果加回去。最终激活是所有组件写入的线性叠加： $x_L = x_0 + \sum_{\ell} \mathrm{Attn}_\ell(x) + \sum_{\ell} \mathrm{MLP}_\ell(x)$。 这个"求和分解"视角来自 [Elhage 2021, A Mathematical Framework for Transformer Circuits]，是全课最重要的一个等式。
  • 线性表示假设 (linear representation hypothesis)：概念/特征近似对应激活空间中的方向， 特征强度近似对应在该方向上的投影长度 [Park 2023, arXiv:2311.03658]。"读出一个特征"= 做一次内积； "写入一个特征"= 加一个向量。它只是近似（模块 05 讲叠加带来的修正），但惊人地好用。
  • 因果优先：相关性证据（探针能解码出特征）≠ 模型在用这个特征。要下因果结论，必须做干预—— patching（模块 04）、steering（模块 06）。这与评测科学里"观测 vs 实验"的区分一脉相承。
把这三条压成一句话：激活是向量，概念是方向，读取是内积，写入是加法，证明是干预。 配套 notebook 的两个热身实验（最小 residual stream、2D 玩具特征空间）就是让你亲手摸一遍前四个动词； 后面六个模块各自把其中一个动词展开成完整方法论。

4设计哲学：纯 numpy 从零、CPU 可跑

本课所有 notebook 只用 numpy / matplotlib / pandas / 标准库。 不用 PyTorch，不用 TransformerLens / nnsight，不下载任何模型权重，每个 cell 在笔记本电脑 CPU 上秒级跑完。 这是刻意的教学设计，不是省事：

  • 不依赖 TransformerLens，逼你理解每一步矩阵运算。工具库把 cache["blocks.3.attn.hook_z"] 递到你手上时，hook 在哪、维度怎么变、softmax 之前还是之后，全被封装掉了。本课里每一个激活都是你自己用 @ 乘出来的——patching 不是调一个 API，而是真的把一个数组切片赋值进另一次前向传播。 学完再用 TransformerLens，你会清楚每个 hook point 背后是哪行代码。
  • 小模型 + 合成任务足以承载全部核心概念。induction head 在两层 attention-only 模型上就完整存在 [Elhage 2021]；叠加现象用一个 5 维玩具模型就能复现 [Elhage 2022, arXiv:2209.10652]；SAE 的训练动力学在 几百维的合成数据上看得一清二楚。机制是普适的，规模只是工程。
  • CPU 可跑 = 实验回路最短。改一个超参、重跑、看图，整个循环 10 秒。interp 研究的日常恰恰是 这种高频小实验，而不是排队等 GPU。
  • 从零实现是最诚实的理解检验。评测科学里你已经体会过：bootstrap 自己写一遍才知道重采样维度多容易错。 同理，亲手实现 attention 的 QK/OV 分解、亲手训一个 SAE，比读十遍论文更能暴露你以为懂了其实没懂的地方。
代价要说清楚：本课的模型是玩具——真实 frontier 模型的回路远比两层 transformer 复杂，SAE 在真实模型上的 训练成本与超参敏感性也远超玩具设定。本课给你的是概念骨架与方法论直觉； 迁移到真实模型时请用 TransformerLens（GPT-2 级）或各 lab 的内部工具，论文清单里给了迁移路径。

6领域简史：从 Zoom In 到 circuit tracing（2020–2026）

时间里程碑关键思想
2016–2019前史：probing 与视觉特征可视化用线性分类器读 NLP 表征 [Alain & Bengio 2016, arXiv:1610.01644]；探针方法论的自我批判 [Hewitt & Liang 2019, arXiv:1909.03368]；CNN 特征可视化（OpenAI/Clarity 团队）。
2020Zoom In: An Introduction to Circuits [Olah 2020, Distill]提出纲领：特征 (features) 是网络的基本单元，回路 (circuits) 是特征间的连接，二者可以被系统地逆向工程——"神经网络的细胞生物学"。同年 nostalgebraist 提出 logit lens。
2021A Mathematical Framework for Transformer Circuits [Elhage 2021]residual stream 视角、QK/OV 回路分解、attention 头组合的代数。本课模块 02–04 的数学底座。
2022induction heads [Olsson 2022, arXiv:2209.11895]；Toy Models of Superposition [Elhage 2022, arXiv:2209.10652]；ROME [Meng 2022, arXiv:2202.05262]；IOI 回路 [Wang 2022, arXiv:2211.00593]第一个跨模型规模成立的"机制 ↔ 能力"对应（induction heads ↔ in-context learning）；叠加假说 (superposition) 解释"特征多于神经元"；causal tracing / patching 成为标准动作。
2023SAE 元年：Towards Monosemanticity [Bricken 2023]、[Cunningham 2023, arXiv:2309.08600]；自动可解释性 [Bills 2023, OpenAI]稀疏自编码器 (sparse autoencoder, SAE) 把叠加的激活拆成数千个近单义 (monosemantic) 特征；用 GPT-4 自动给神经元/特征写解释并打分——可解释性流水线开始规模化。
2024Scaling Monosemanticity [Templeton 2024]：SAE 上到 Claude 3 Sonnet在 frontier 模型中提取出数百万特征（著名的 Golden Gate Bridge 特征），并演示特征 steering 直接改变模型行为；Gemma Scope 等开源 SAE 套件跟进。
2025–2026circuit tracing / attribution graphs [Ameisen 2025; Lindsey 2025, On the Biology of a LLM]；审计实战 [Marks 2025, arXiv:2503.10965]用 cross-layer transcoder 自动追踪回路图：多步事实推理、加法的并行启发式、跨语言共享回路、CoT 不忠实的内部证据；"给模型植入隐藏目标→让审计团队盲测找出来"的对抗演练——interp 正式进入评测/审计工具箱。
给 evaluation scientist 的读图法。注意这条时间线的重心迁移：2020–2022 在回答"能不能逆向"（存在性）， 2023–2024 在回答"能不能规模化"（SAE + 自动解释），2025 起在回答"能不能用于审计与部署决策"—— 恰好落进你的主业。本课的终点模块 07 就停在这个接口上。

7研究前沿与开放问题

  • 解释的评测问题（interp 自己的 evals）。一个"特征解释"或"回路故事"怎么算对？ 自动解释的打分协议（simulation scoring）有自身偏差；社区开始给 interp 方法建 benchmark（如 SAE 评测套件、 棋类模型 ground-truth 测试床）。这本质是把评测科学反向应用到可解释性上——两个领域在此汇流。
  • 线性表示假设的边界。哪些特征不是方向（多维特征、环面结构如星期/月份）？ 叠加的几何到底长什么样？模块 05 给入门，前沿仍开放。
  • SAE 之后是什么？SAE 特征存在不完备（dark matter）、不稳定（同数据不同种子学出不同特征）、 重构误差不可忽略等问题；transcoder、cross-layer 方法、参数空间分解等替代品竞争中。
  • 白箱评测的标准化。探针/SAE 监视器能否进入部署前安全评测的正式清单？ 误报率怎么标定？模型会不会学会绕过内部监视器（interp-aware deception）？ [Marks 2025] 的审计演练是雏形，协议远未定型。
  • 从"看懂"到"保证"。机制理解能否升级为行为的形式化保证（如 heuristic arguments、 proof-style bounds）？这是 interp 与 alignment theory 的交界，也是最雄心勃勃的开放问题。
