1问题的形状：用一个 2D 先验去雕一个 3D 表示

3D 生成（SDS 路线）的循环： θ ──[可微渲染]──> x = g(θ) ──[加噪]──> x_t ↑ │ │ [预训练的 2D 扩散] │ │ └────────── 梯度 <──────────── ε̂(x_t, t, y) - ε θ ：一个 3D 表示的参数（NeRF 的权重、或 C74 的一堆高斯） g ：可微渲染器（C74 模块 03 就是它的一种） y ：文字提示（或一张参考图） 关键点：**扩散模型完全不知道 3D 的存在**。它只被要求「这张渲出来的图像不像噪声」。

直白说

所以 SDS 的全部内容是一句话：把「渲出来的每一张图都要像真实图像」当成对 3D 表示的约束。而它的适用条件很宽——不需要任何真实观测，所以它能做「只有文字」或「只有一张图」的情形。这与前三个模块有一个性质上的差别：① SfM、② MVS、③ 前馈都在拟合看到过的图像，而 SDS 在生成没看到过的部分。

严谨说

后果是「对不对」这个问题没有客观判据。模块 01–03 的误差都能对着真值算；SDS 生成的背面本来就不存在真值，所以只能问「它像不像先验认为合理的东西」。而这决定了本模块的分析方式：不去问「生成得好不好」，而去问「这个目标函数的最优解是什么形状」——而那是可以精确回答的，本模块就这么做。

2SDS 的梯度：那个 $-\epsilon$ 项与消失的雅可比

朴素想法是「把扩散模型的损失当成一个可微的图像评分，直接反传」。而扩散损失 $\mathcal L_{\text{diff}} = \mathbb E\Vert \hat\epsilon(x_t,t) - \epsilon\Vert^2$ 对 $x$ 求导会带上 $\partial\hat\epsilon/\partial x_t$——**U-Net 的雅可比**，既贵又不稳。SDS 的做法是**把它扔掉**：

\[\nabla_\theta \mathcal L_{\text{SDS}}= \mathbb E_{t,\epsilon}\Bigl[w(t)\bigl(\hat\epsilon(x_t,t,y) - \epsilon\bigr)\frac{\partial x}{\partial \theta}\Bigr]\]

直白说

扔掉雅可比不是近似——它对应一个不同但合理的目标。因为 $\hat\epsilon = -\sigma_t\nabla_{x_t}\log p_t(x_t)$，所以 $(\hat\epsilon - \epsilon)$ 这一项在期望下就是「把 $x$ 往 $\log p_t$ 上升的方向推」。换句话说：SDS 不是在最小化扩散损失，而是在做平滑后密度的梯度上升。这就是它是模式寻求的根本原因（第 3 节）。

严谨说

而那个 $-\epsilon$ 项值得单独说：它在期望下为零。因为 $\epsilon\sim\mathcal N(0,I)$ 与 $x$ 无关，所以 $\mathbb E[\epsilon\,\partial x/\partial\theta] = 0$。notebook 把这一点验到了一个很干净的形式：两个估计量之差恰好是$-\frac1n\sum w(t)\alpha_t\epsilon$，它完全不含 $x$——所以用同一批随机数时，这个差在 6 个不同的 $x$ 处逐位相同（标准差 $1.7\times10^{-17}$）。也就是说它是一个纯加性的、均值为零的噪声项，不改变任何不动点。

它常被说成「一个降方差的控制变量」。notebook 实测下来，这句话只在特定条件下成立。逐 $t$ 看效应完全反转：$t{=}0.05$（低噪）时含 $-\epsilon$ 的方差是不含的 391 倍；$t{=}0.95$（高噪）时只有 1/1533。机制很清楚：$t\to1$ 时 $x_t\approx\sigma_t\epsilon$，于是 $\hat\epsilon\approx\epsilon$，两者几乎抵消；而 $t\to0$ 时 $\hat\epsilon\approx0$，减去 $\epsilon$ 等于凭空加进一个方差为 1 的噪声。净效应还依赖当前的 $x$：在模式附近（$\pm2.5$）含 $-\epsilon$ 更好（1.65×），而在两模式之间（0.0）它反而差 0.57×。无条件成立的只有一条：它不改变期望。我最初写的是「它无条件降方差」，被实测推翻了——但结论的用途没变，因为闭式期望梯度只需要「期望不变」这一条。
本模块的分析策略就建立在这个观察上。既然 $-\epsilon$ 的期望为零、而 $\hat\epsilon$ 对一个已知的先验有闭式，那么整个 SDS 的期望梯度就有闭式：$g(x) = \mathbb E_t\bigl[w(t)\,\alpha_t\,\mathbb E_\epsilon[\hat\epsilon(\alpha_t x + \sigma_t\epsilon, t)]\bigr]$。notebook 用高斯混合当先验、用高斯-埃尔米特求积算 $\mathbb E_\epsilon$、用细网格算 $\mathbb E_t$——于是可以把 SDS 的动力学精确地画出来，没有任何随机性。

3SDS 的解是不动点，不是样本

先验取一个两模式的高斯混合：$\mu = \pm 2$、$\sigma = 0.35$、等权。把 SDS 的期望梯度算出来，找它的零点：

0.0000−0.1496不稳定（分水岭）
+1.5663+0.1080稳定（吸引子）

直白说

两个吸引子、一个分水岭——这是一个确定性的动力系统，不是一个采样过程。用精确期望梯度跑，从任何初值出发都收敛到两个点之一，模式内散布严格为 0。而真实的 SDS 用蒙特卡洛估计梯度，所以有残余散布：notebook 用 16 个采样的随机版量到模式内标准差 0.0431，而先验是 0.35——收缩 8.1 倍。所以「多样性坍缩」的准确说法是：残余的多样性只来自梯度噪声，而不是来自先验的分布。

严谨说

另一个后果：落到哪个模式由吸引域决定，而不是由先验的概率质量决定。notebook 把先验权重改掉重跑，结果比「比例被压平」更强：

直白说

第二行：占比被压向 50/50（54.4% vs 先验的 70%）——因为它由分水岭的位置（$+0.4851$）与初值分布决定，而不是由概率质量。

严谨说

第三行更强：$\pi{=}(0.9,0.1)$ 时次模式不再是吸引子，不动点只剩一个。所以次模式被生成的概率是零，而不是 10%。这就是「同一个提示词跑十次得到十个几乎一样的东西」的完整机制：不只是概率被压平，而是少数模式在 SDS 的动力学里直接消失。

而 ProlificDreamer（VSD）正是针对这一点：它把「找模式」改回「采样」。做法是维护一个关于 $\theta$ 的分布（用一个 LoRA 拟合它的 score），让目标变成两个分布之间的 KL 而不是一个点的密度。代价是要在优化过程中同时训练那个辅助模型——所以它慢得多，但输出的多样性与细节都明显更好。

4它收敛到的模式内移 21.7%，而这是可预测的

上表的吸引子在 $\pm1.5663$，而真实模式在 $\pm2.0$——**内移 21.7%**。这不是数值误差：

直白说

SDS 找的不是 $p$ 的模式，而是「对 $t$ 平均后的 $p_t$」的模式。而 $p_t$ 是 $p$ 与一个方差 $\sigma_t^2$ 的高斯的卷积——也就是平滑。平滑会把两个相邻的模式互相拉近（极限情况：$\sigma_t$ 足够大时两个模式合并成一个，位置在中点）。所以对 $t$ 求平均（$t$ 从 0.02 到 0.98，覆盖从几乎无噪到几乎纯噪）得到的吸引子必然介于「真模式」与「中点」之间。

严谨说

这解释了一个真实的观察：SDS 生成的东西倾向于「更中庸」。细长的结构变短粗、尖锐的特征变圆滑、两个应该分开的部件粘在一起。而它不是「优化没收敛」或「表示能力不够」，是目标函数的不动点本来就在那里。所以加迭代、加高斯、换渲染器都不会改善它。

严谨说

而表格的第 3、4 列说明 CFG 的另一个效应必须分开算：梯度幅度。$\max\vert g\vert$ 从 0.994 涨到 65.5（66 倍，近线性），所以稳定所需的学习率上界从 12.2 掉到 0.103（118 倍）。我第一次做这个实验时正是踩了这个：cfg=100 配固定 $lr{=}0.25$，400 步之后 $x$ 是 $10^{100}$。而我一开始把那个数当成了「CFG 的效应」写进结论里——它其实只是我没缩学习率。补一句准确的：那次 $10^{100}$ 出现在随机梯度版（无条件先验的代理 score 在数据支撑外线性增长，没有边界）；而 notebook 用网格插值的确定性版本时，同样的违规表现为一个周期-2 的极限环（在 $+0.78$ 与 $+3.33$ 之间来回跳，振幅 2.55，与两模式间距 4.0 同量级）。两者是同一个原因（$lr$ 超过 $2/\max\vert g'\vert$），只是一个无界、一个有界。所以比较不同 cfg 时必须把 $lr$ 按 $1/\text{cfg}$ 缩放，否则比的是步长而不是形状。

5$w(t)$ 与 $t$ 的采样范围：同一个旋钮的两种写法

第 4 节的内移 21.7% 是在 $w(t)=\sigma_t^2$、$t\in[0.02,0.98]$ 下测的。**换掉这两个之中的任何一个，不动点的位置就变了**——所以它们不是超参数细节，而是直接决定目标函数最优解在哪。

换权重

$w(t)$吸引子位置相对真模式 ±2.0
$\sigma_t^2$（DreamFusion 的选择）±1.5663内移 21.7%
$1$（对 $t$ 均匀）±1.8739内移 6.3%
$\mathrm{SNR} = (\alpha_t/\sigma_t)^2$±1.9974内移 0.1%
$1/\sigma_t^2$±1.9919内移 0.4%

直白说

SNR 加权几乎完全消除了内移（0.1%）。因为它把权重压在低噪（$\sigma_t$ 小、$\alpha_t$ 大）的那一端，而低噪处的 $p_t$ 几乎就是 $p$，没有平滑。那为什么 DreamFusion 不用 SNR 加权？因为低噪处的梯度信息量也最小——$\hat\epsilon$ 在 $t\to0$ 时趋于噪声本身，梯度趋于零。所以 SNR 加权在玩具先验上「更准」，在真实场景里会几乎不动。

严谨说

这是一个真实的取舍，而不是一个「更好的选择」：权重压向低噪 → 不动点更接近真模式，但收敛更慢、更容易卡在初值附近；权重压向高噪 → 收敛快、能大幅改变形状，但不动点更「中庸」。所以实践中的做法是退火——早期用高噪、后期用低噪。

直白说

关键在于「是否包含小 $t$」，而不是上界多大。只要区间里有低噪的样本，两个吸引子就在；而只采高噪段（$t \ge 0.5$）时，平滑已经把两个模式合成了一个，SDS 的动力系统里只剩一个位于中点的吸引子。这就是「SDS 早期生成一团糊」的精确含义——不是还没收敛，而是那个阶段的目标函数真的只有一个「中庸」的最优解。

严谨说

而这给出一条可操作的规则：$t$ 的采样必须包含低噪端。常见的实现是「$t\sim U[0.02, t_{\max}]$ 且 $t_{\max}$ 随迭代退火」——notebook 量了三个阶段：$[0.40,0.98]$ → ±0.9623；$[0.20,0.70]$ → ±1.7446；$[0.02,0.40]$ → ±1.9962。所以退火 $t_{\max}$ 的作用就是「让吸引子从中庸逐步移向真模式」——而这与 CFG 在做同一件事（第 4 节），只是机制不同。

6Janus 是目标函数的最优解

**Janus（多面）问题**：生成出来的物体正面和背面都是一张脸、或者一只动物有两个头。它常被当成「优化没收敛」，而它其实是**逐视角独立打分**这个目标的严格最优解。

构造（记「像正面」得 1.0、「像背面」得 0.2）： 方案 前视得分 后视得分 总得分 ──────────────────────────────────────────────────────── 一致（前=正面、后=背面） 1.0 0.2 1.2 Janus（两侧都是正面） 1.0 1.0 **2.0** <- 更高

直白说

所以只要先验对「背面」的打分低于对「正面」的打分，Janus 就严格优于正确答案。而这个条件几乎总成立：文字提示是「一只猫」，而扩散模型在训练数据里见到的猫绝大多数是正面/侧面。换句话说：Janus 是先验的视角偏置被逐视角独立目标放大的结果。

严谨说

而这决定了修法必须改目标，不能改优化器。加迭代、换初值、加正则强度都不改变「2.0 > 1.2」这个不等式。三条真实的修法：① 视角条件化——把相机方位放进提示或条件里（Zero-1-to-3），于是「背面」在后视的先验下得分变高；② 联合多视角先验——一次生成 4–6 个视角并要求它们互相一致（MVDream），于是「两侧都是正面」在联合先验下得分变低；③ 几何正则（对称性、法向一致）——最弱的一条，因为它不改先验的偏置，只是加了一个竞争项。

为什么②比①更彻底：它改的是先验的联合结构，而不只是边缘。①（视角条件化）仍然是逐视角独立打分——只是每个视角的打分函数不同了。所以它减轻了偏置，但没有引入「视角之间必须一致」这个约束。②直接让「不一致」本身变成低分，于是 Janus 不再是最优解。代价是先验必须重新训练成多视角的，而那需要 3D 或多视角数据——也就是回到了「数据」这个瓶颈。

7三条路线的分工：SDS、多视角扩散、前馈重建

SDS（逐场景优化）多视角扩散 + 重建前馈重建（LRM 类）
输入文字 或 单图文字 或 单图单图 或 少量图
每个资产的成本几十分钟的优化一次扩散采样 + 一次快速重建一次前向（秒级）
多样性差（第 3 节：解是不动点）好（真的在采样）确定性（同一输入同一输出）
几何一致性差（第 5 节：Janus）好（联合先验）取决于训练数据
细节好（可以优化很久）受限于扩散的分辨率受限于模型容量
需要 3D 数据吗不需要需要（训练多视角先验）需要（训练重建模型）

直白说

最后一行是这三条路线的真正分界。SDS 的全部价值在于「只用 2D 先验」——所以它在 2022–2023 年是唯一可行的路，因为那时没有足够的 3D 数据。而 Objaverse 等大规模 3D 数据集出现之后，②③ 变得可行，且它们在速度与一致性上全面更好。所以 SDS 的地位从「主流方法」变成了「不需要 3D 数据时的兜底」，以及「作为一个精修阶段」。

严谨说

而本模块的分析对②③同样有用，因为它们里面仍然有 SDS 的影子。很多流程是「多视角扩散给初值 → SDS 精修」，而精修阶段的内移（第 4 节）与过饱和（CFG 过冲）会照样发生。诊断方式：如果精修之后细节变多但形状变「胖」、颜色变艳，那就是第 4 节的两个效应——而对策是降 cfg（接受细节少一些）或用 VSD 替代 SDS。

与本课程其他模块的接口：SDS 优化的那个表示通常就是 C74 的 3DGS（或 NeRF），所以 C74 模块 03 的可微光栅化正是这里的 $\partial x/\partial\theta$；而生成出来的资产要评测、要出网格，就走本课模块 05；扩散模型本身（DiT、采样器、flow matching）在 C28。

8诊断：SDS 出了问题时该动哪个旋钮

症状最可能的原因动哪个旋钮
形状「胖」、细节圆滑、部件粘连第 4 节的内移——不动点本来就在那里退火 $t_{\max}$（第 5 节：$[0.02,0.30]$ 时内移 0.0%）；或换 SNR 加权，代价是收敛变慢
颜色过饱和、对比度过高CFG 过冲——吸引子被推到数据分布之外降 cfg。而如果同时已经退火了 $t_{\max}$，那么 cfg 需要降得更多（第 5 节的交互表）
训练几百步后炸成 NaN / 数值爆掉梯度幅度随 cfg 近线性增长（第 4 节：cfg=100 时 66 倍）按 $1/\text{cfg}$ 缩学习率，或加梯度裁剪。这是我自己第一次做实验时踩的坑
早期一直是一团糊，怎么都不成形$t$ 的采样范围没包含低噪端（第 5 节：$t\ge0.5$ 时只有一个中点吸引子）把 $t$ 的下界压到 0.02 附近
正反两面都是同一张脸 / 两个头Janus——目标函数的最优解（第 6 节）必须改目标：视角条件化，或换多视角先验。加迭代、换初值、加正则都不改变「2.0 > 1.2」这个不等式
同一个提示词跑十次几乎一样正常——SDS 的解是不动点（第 3 节）要多样性就得换目标（VSD），而不是换随机种子
把这张表压成一句话：SDS 的问题几乎都是「目标函数的不动点在哪」的问题，而不是「优化收敛得好不好」的问题。所以调参的正确心态是「我在移动不动点」，而不是「我在帮优化器找到最优解」。而这也是本模块把 $w(t)$、$t$ 范围、cfg 三个旋钮全部换算成「吸引子位置」来量的原因——那是它们唯一的共同度量。
