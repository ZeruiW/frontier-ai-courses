# C75 · 三维重建与 3D 生成

> 6 个模块 · 6 个 notebook · 24 道带自测的练习 · 纯 numpy / CPU / 离线

## 这门课在回答什么

**几何怎么从图像里被解出来** —— 以及在四种不同的数据条件下，它有四种不同的形态。

而在讲任何方法之前有一条**原理性**的限制：

> 把场景点 $X \to sX$、相机平移 $t \to st$，拍出的图像**逐位相同**
> （notebook 取 $s$ 到 $10^3$，最大像素差 $1.1\times10^{-13}$）。

所以「从图像得到米」在原理上不可能。每条路线都必须在某处引入外部信息，
而**引入的位置就是这些方法最大的区别**。

## 六个模块

| **00** | 总览与四条路线 | **绝对尺度不可观测**（逐位验证）；四条路线各注入一次错误；**束调整的秩亏恰好 7** |
| **01** | SfM：对应、增量重建、束调整 | **秩亏 7 且零空间解析**；**cond ∝ $(B/z)^{-2}$**，纯旋转时零空间涨到 **npt+6**；Schur 补快 $10^6$ 倍；**共面让 $E$ 退化而前向运动不会** |
| **02** | 稠密多视图立体 | **深度假设必须在视差上均匀**（深度均匀时近场步长 102.7 px）；**三类失效的签名不同**；**不等基线的 2 个视图就修好周期纹理**；**min 聚合最不稳健** |

| **05** | 网格化与 3D 重建评测 | **256 → 15 类，其中 46.9% 含面歧义**；**TSDF 占用率 $12r/L$**；**Chamfer 不是度量**（$20>5+5$）；**L1 线性 L2 平方**；**采样密度让 CD 变 2.9 倍** |

## 一条贯穿全课的线

每个模块都有一个「看起来是精度问题、实际是**可观测性**问题」的地方：

- **模块 01**：纯旋转 —— 深度不可观测（零空间从 7 涨到 npt+6），不是测不准；
- **模块 02**：周期纹理 —— 结构性歧义（误差与噪声**无关**），不是噪声；
- **模块 03**：绝对尺度 —— 原理不可观测，不是模型不够好；
- **模块 04**：Janus —— 目标函数的严格最优解，不是优化失败；
- **模块 05**：Chamfer —— 它不是度量，所以「差 0.1」这句话**没有传递性**。

把这五个分清，比记住任何一个算法都重要。

## 与其他课程的分工

| 课程 | 分工 |
|---|---|
| **C72**（多视角几何）| **硬前提**。C72 讲「已知对应关系时怎么算」，本课讲「对应从哪来、以及规模变大之后怎么解」。C72 的双目只作为四种测距法之一出现，本课模块 02 讲**稠密**匹配 |
| **C73**（3D 表示与点云）| C73 管「已经有点云之后怎么处理」，本课管「点云从哪来」。C73 明确声明不碰 SfM 与 ICP，正好是本课模块 01 |
| **C74**（3D 高斯溅泼）| C74 管「有了几何之后怎么渲染」，本课管「几何从哪来」。两处接口：① 3DGS 的输入是 SfM 的位姿与稀疏点；② 从 3DGS/2DGS 提网格用 C74 模块 01 的三种深度口径 |
| **C28**（扩散与流）| C28 讲扩散模型本身，本课模块 04 只讲「怎么把一个已有的 2D 先验用到 3D 上」 |
| **C18**（计算机视觉）| 本课把特征匹配当已知工具，SIFT/SuperPoint 的内部不在范围内 |

**本课不讲**：SLAM 的实时性与回环检测、特征提取器的内部（C18）、
扩散模型的训练与采样器（C28）、可微渲染的实现（C74）。

## 方法论：有真实优化，但没有神经网络训练

与 C72/C73/C74 不同，本课会**真的跑优化** ——
模块 01 有能收敛的束调整（LM + Schur 补）、模块 02 有能出深度图的平面扫掠、
模块 04 有在解析已知先验上跑的 SDS。因为这门课的核心问题**就是**优化的性质：
什么可观测、条件数多大、收敛到哪个不动点。

**但它不训练任何神经网络。** 模块 03 的单目深度与点图、模块 04 的扩散先验，
都用**解析构造的替身**（一个「仿射意义上完美」的预测器、一个高斯混合当扩散先验）。
理由是这两个模块要验证的是**口径**与**目标函数的性质**，而它们与网络权重无关。

**代价说清楚**：
① 本课不能回答「哪个单目深度模型更好」——只能告诉你**用什么口径去比**；
② SDS 实验是 1D 的 —— 能证明模式寻求与模式内移，不能预测真实生成的视觉质量；
③ MVS 是 1D 扫描线 —— 代价体规模、视差采样、窗口取舍都能量准，但不含真实的遮挡推理；
④ 束调整的规模是几十个相机 —— 稀疏结构与 Schur 补的收益按公式外推，不是实测。

## 本课程的六处诚实修正

写作过程中有六个我原本以为对、被自己的实验推翻的结论。它们**都留在课里**，
而且大多变成了更强的结论：

1. **「小基线会让束调整的条件数爆到 $10^{19}$」是一个坏掉的场景** ——
   我的第一版轨迹让相机转 100° 却几乎不平移，于是 40 个点里有 25–33 个**跑到了相机背后**
   （投影 $u$ 到 52 万像素）。换成 look-at 轨迹后标度律才干净地出来（$\propto (B/z)^{-2}$）。
2. **「数值判秩能找到 gauge 零空间」需要两个条件而不是一个** ——
   既要用谱间隙（不能用固定阈值），间隙本身**也**要够大；
   我漏了第二条，于是把「已固定 7 个自由度」的满秩情形报成了秩亏 2。
3. **「前向运动是退化的」抓错了对象** —— 前向运动**不**让 $E$ 退化（$\sigma_8/\sigma_9 = 1.3\times10^{15}$），
   退化的是**三角化**（极点附近视线夹角只有外圈的 1/7.5）。这是两件不同的事。
4. **「无纹理区的 argmax 会明显偏离真值」是一次运气** ——
   单个种子给出 −0.250 px（碰巧接近真值）。跨 300 个种子的标准差是 17.44，
   而「均匀分布在整个假设范围」的理论值是 17.32 —— 这才是「不携带信息」的精确说法。
5. **「SDS 里的 $-\epsilon$ 是一个降方差的控制变量」只在特定条件下成立** ——
   逐 $t$ 看效应完全反转：低噪端它让方差**涨 391 倍**，高噪端降 1533 倍。
   净效应还依赖当前的 $x$（模式附近好 1.65×，两模式之间差 0.57×）。
   无条件成立的只有一条：它不改变期望。
6. **「cfg=100 配固定 lr 会发散到 $10^{100}$」需要限定** ——
   那是**随机**梯度版（无界的代理 score）；用确定性网格版时同样的违规表现为一个
   **周期-2 的极限环**（振幅 2.55，与模式间距 4.0 同量级）。两者同一个原因：$lr$ 超过 $2/\max\vert g'\vert$。

另外还有两处「意外收获」——实验给出的结论比我要证的更强：

- **纯旋转时零空间不是「7 加一点」，而是恰好 npt + 6**（5 组配置全部吻合）：
  每个点的深度都不可观测 + 全局旋转 3 + 平移 3，而尺度被并进了逐点深度里。
- **先验权重 $(0.9,0.1)$ 时次模式<em>不再是吸引子</em>** —— SDS 给出 100%/0% 而不是 90%/10%。
  所以「多样性坍缩」不只是概率被压平，而是**少数模式在动力学里直接消失**。

4 道 `✏️ 练习`（TODO 骨架 + `assert` 判分 + `📖 参考答案`）+ 1 个 `🧪 真实工程胶囊`。

而它们是这门课里最容易被做错、且后果最大的两处。
