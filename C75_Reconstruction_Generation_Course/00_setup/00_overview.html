1一个约束先把整门课框定了：绝对尺度不可观测

本课的问题是「从图像得到几何」。而在讲任何方法之前，有一条**原理性**的限制必须先说清，因为它决定了每条路线的形状。

\[\text{把场景点 } X \to sX \text{、相机平移 } t \to st\;\Longrightarrow\; \pi(sX) = \frac{f\,sX}{sZ} = \frac{fX}{Z} = \pi(X)\]

直白说

投影是齐次的，所以整个场景放大 $s$ 倍、相机位置也放大 $s$ 倍，拍出的图像逐位相同。notebook 把 $s$ 取到 $10^3$ 与 $10^{-3}$，最大像素差 $1.1\times10^{-13}$——纯浮点舍入。所以「从图像得到米」在原理上是不可能的，无论用多少张图、多好的网络。

严谨说

于是每条路线都必须在某处引入外部信息，而引入的位置就是这些方法最大的区别。已知物体的物理尺寸（C72 模块 03 的做法）· 已标定的双目基线 · IMU 或轮速 · 或者——一个从数据里学到的尺度先验。最后那一种是 2024 年以来单目/前馈方法的做法，而它把一个几何问题换成了一个统计问题——好处是不需要标定，代价是尺度的正确性取决于测试场景与训练分布的接近程度。

这条限制常被含糊掉，而含糊的代价很具体。「我们的方法在 KITTI 上的绝对深度误差是 2.3%」这句话，如果没说清尺度是怎么定的，它可能在量三件完全不同的事：① 用真值的中位数对齐了尺度（那么它没有量尺度）；② 用标定好的基线（那么尺度来自硬件）；③ 网络直接输出米（那么它在量「训练分布覆盖得好不好」）。模块 03 会把这三种口径的差别量出来：同一个「仿射意义上完美」的预测，在不同对齐口径下的相对误差差 108 倍。

2四条路线与它们的适用区间

路线怎么做外部信息从哪来什么时候用它在哪个模块
① 几何优化
SfM + MVS		从图像里找对应 → 解位姿与稀疏点 → 稠密化需要外部尺度；位姿与内参由数据本身解出视角多（几十到几千张）、场景静态、要精度01 · 02
② 前馈回归
单目深度 / pointmap		一次前向直接输出深度或 3D 点训练数据里学到的先验视角极少（1–2 张）、要快、能接受尺度不确定03
③ 生成式
SDS / 多视角扩散		用一个 2D 生成先验去「雕」一个 3D 表示预训练的图像/视频扩散模型只有一张图或只有文字、允许「编」出没观测到的部分04
④ 可微渲染拟合
NeRF / 3DGS		给定位姿，优化一个表示去拟合图像位姿来自 ①；尺度也来自 ①已有位姿、要高质量新视角C74（本课不重复）
四条路线的依赖关系（箭头 = 「用到它的输出」）： ┌──────────────────────────────┐ 图像 ──> ① SfM ───┤ 位姿 + 内参 + 稀疏点 + 尺度基准 │ │ └───────────┬──────────────────┘ │ │ ├──> ② MVS ──> 稠密深度图 ──┐ │ ├──> 模块 05：网格化 + 评测 └──> ④ 3DGS/NeRF ──> 辐射场 ┘ （C74 的输出接到这里） ② 前馈回归：图像 ──> 深度/点图 （**不需要** ① —— 这是它的全部卖点） ③ 生成式： 文字/单图 ──> 3D （**没有** 真实观测可对齐，所以要靠先验）

直白说

这张图里最重要的一条是「② 不需要 ①」。传统流程里 SfM 是一切的第一步——C74 的 3DGS 需要它、MVS 需要它、评测的坐标系也来自它。而 SfM 在三种情况下会直接失败：视角太少、基线太短（模块 01：$B/z$ 趋 0 时条件数从 $10^3$ 跳到 $4.4\times10^{17}$）、或者纹理不足（模块 02：无纹理区的匹配代价曲线是平的）。「pose-free」这个词的真实含义就是「绕开这个失败模式」。

严谨说

而 ③ 与前三条有一个性质上的差别：它没有真实观测可以对齐。① ② ④ 都在拟合看到过的图像，所以「对不对」有客观判据；③ 在生成没看到过的部分，所以「对不对」取决于先验。模块 04 会把这一点的后果量出来：SDS 的模式内散布比先验收缩 7 倍——也就是说同一个提示词跑多次得到的结果几乎一样，而这不是 bug，是 SDS 的目标函数本来就在找模式而不是采样。

3课程地图

模块主题带走的那个可验证的量
01SfM：对应、增量重建、束调整束调整 Hessian 的秩亏恰好是 7（相似变换群），而这 7 个方向有解析形式（$\Vert JQ\Vert/\Vert J\Vert \approx 2\times10^{-11}$）· 投影掉 gauge 后的条件数 $\propto (B/z)^{-2}$，而 $B/z=0$ 时是 $4.4\times10^{17}$ 的悬崖 · Schur 补在 500 相机时快 $10^6$ 倍
02稠密多视图立体深度假设必须在视差上均匀：深度均匀时 $D{=}64$ 在近场的视差步长是 102.7 px · 所需 $D = f B(1/z_{\min}-1/z_{\max})$ · 三类失效：弱纹理随噪声渐进失效、周期纹理与噪声无关地结构性失效（峰-次峰间隔恰为 0）、而倾斜反而修好周期纹理
03前馈回归：单目深度与点图绝对尺度不可观测（图像逐位相同） · 仿射对齐 vs 纯尺度对齐差 108 倍——口径选错会把好模型报成差模型 · 点图能精确反解焦距（$1.9\times10^{-16}$），代价是它恰好 3.00× 过参数化
043D 生成：SDS 与多视角扩散SDS 是模式寻求的：模式内散布比先验收缩 7 倍 · 而它收敛到的模式系统性内移 22%（$\pm1.569$ vs 真值 $\pm2.0$）——因为它找的是「对 $t$ 平均后的平滑密度」的模式 · Janus 是目标函数的最优解，不是优化失败
05网格化与 3D 重建评测Marching Cubes 的 256 种情形归约为 15 类（仅旋转是 23 类），而 120/256 = 46.9% 含面歧义（6 类）· Chamfer 距离不是度量（三角不等式反例：20 > 5+5）· CD-L1 对离群点线性、CD-L2 平方（一个离群点让 L2 涨 293 倍）· 同一曲面改采样密度让 CD 变 3.3 倍
一条贯穿全课的线：每个模块都有一个「看起来是精度问题、实际是可观测性问题」的地方。模块 01 的纯旋转（深度不可观测，不是测不准）；模块 02 的周期纹理（结构性歧义，不是噪声）；模块 03 的绝对尺度（原理不可观测，不是模型不够好）；模块 04 的 Janus（目标的最优解，不是优化失败）；模块 05 的 Chamfer（不是度量，所以「差 0.1」这句话没有传递性）。把这五个分清，比记住任何一个算法都重要。

4与既有课程的分工

课程它讲什么分工
C72 · 多视角几何（硬前提）相机模型与畸变、标定与验收、对极/三角测量/单应/PnP、BEV、时空对齐C72 讲「已知对应关系时怎么算」，本课讲「对应关系从哪来、以及规模变大之后怎么解」。C72 的双目只作为四种测距法之一出现（精度对比），而本课模块 02 讲稠密匹配：代价体、平面扫掠、窗口大小的取舍
C73 · 3D 表示与点云深度学习点云/体素/网格/隐式四种表示、置换不变性、稀疏卷积、3D 检测与分割C73 管「已经有点云之后怎么处理它」，本课管「点云从哪来」。C73 明确声明不碰点云配准（ICP）与 SfM，正好是本课模块 01 的内容
C74 · 3D 高斯溅泼体渲染与 α 合成、高斯基元与投影、tile 光栅化、密度控制、球谐C74 管「有了几何之后怎么渲染」，本课管「几何从哪来」——而两者在两个点上接口：① 3DGS 的输入是 SfM 的位姿与稀疏点（本课模块 01）；② 从 3DGS/2DGS 提网格用的是 C74 模块 01 的三种深度口径（本课模块 05）
C28 · 扩散与流前沿DiT、flow matching、consistency、采样器C28 讲扩散模型本身，本课模块 04 只讲「怎么把一个已有的 2D 扩散先验用到 3D 上」——即 SDS 的梯度形式、它为什么是模式寻求的、以及多视角一致性
C18 · 计算机视觉特征、分割、检测的经典方法本课模块 01 会用到特征匹配，但把它当已知工具——SIFT/SuperPoint 的内部不在本课范围
一句话划清边界：本课不讲 SLAM 的实时性与回环检测（那是另一门课的量级）、不讲特征提取器的内部（C18）、不讲扩散模型的训练与采样器（C28）、不讲可微渲染的实现（C74）。本课讲的是「几何从图像里被解出来」这一条链，以及它在四种数据条件下的四种形态。

5方法论：这门课有真实优化，但没有神经网络训练

直白说

与 C72/C73/C74 不同，本课会真的跑优化——模块 01 有一个能收敛的束调整（Levenberg–Marquardt + Schur 补）；模块 02 有一个能出深度图的平面扫掠；模块 04 有一个在解析已知的先验上跑的 SDS。因为这门课的核心问题就是优化的性质：什么可观测、条件数多大、收敛到哪个不动点。

严谨说

但它不训练任何神经网络。模块 03 的单目深度与点图、模块 04 的扩散先验，都用解析构造的替身：一个「仿射意义上完美」的深度预测器、一个高斯混合当扩散先验。理由是这两个模块要验证的是口径与目标函数的性质，而它们与网络权重无关——「仿射对齐 vs 尺度对齐差 108 倍」对任何预测器都成立；「SDS 是模式寻求的」是它梯度形式的直接后果。

代价说清楚

  • 本课不能回答「哪个单目深度模型更好」——那需要真实数据集与训练；本课只能告诉你用什么口径去比
  • 本课的 SDS 实验是 1D 的——它能证明模式寻求与模式内移，但不能预测真实 3D 生成的视觉质量
  • 本课的 MVS 是 1D 扫描线——代价体的规模、视差采样、窗口取舍都能量准，但不含真实的多视角聚合与遮挡推理
  • 模块 01 的束调整规模是几十个相机——稀疏结构与 Schur 补的收益按公式外推到几千个相机，而不是实测

每个模块的固定结构

  • 讲解页：机制 → 可验证的量 → 它决定了什么设计
  • notebook：6–8 个 worked 小节，每节以 assert 结尾
  • 4 道 ✏️ 练习：TODO 骨架 + assert 判分 + 📖 参考答案
  • 🧪 真实工程胶囊：接 COLMAP / OpenMVS / DUSt3R / threestudio 的代码
