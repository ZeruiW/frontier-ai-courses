## 一、贯穿全课的那条限制

| 术语 | 一句话 | 本课的量 |
|---|---|---|
| **尺度不可观测** scale unobservability | 把场景点与相机平移一起乘 $s$，图像**逐位相同** | $s$ 取到 $10^3$ 与 $10^{-3}$，最大像素差 $1.1\times10^{-13}$（纯浮点舍入）|

| **可观测性 vs 精度** | 「测不准」与「测不了」是两件事 | 本课五个模块各有一例（见 README 的「贯穿全课的线」）|

## 二、SfM（模块 01）

| 术语 | 一句话 | 本课的量 |
|---|---|---|
| **SfM** Structure from Motion | 从多张图像同时解出相机位姿与稀疏 3D 点 | 三个子问题：找对应（启发式）· 决定顺序（贪心）· **束调整（唯一能精确分析的）** |
| **两两匹配的规模** | 全量是 $O(N^2)$ | $N{=}10^4$ → 5000 万对（10 ms/对 = 139 小时）|
| **检索式候选** vocabulary tree | 每图取 top-$k$ 个候选，$O(Nk)$ | $N{=}10^4$、$k{=}50$ → 25 万对，占全量 **0.50%**。<em>而漏掉的对可能正是闭环那一对</em> |
| **束调整** bundle adjustment | 同时优化所有相机与所有点，最小化重投影误差 | 500 相机 + 10 万点 = 303,000 个参数；稠密 $H$ 有 918 亿个元素 |
| **雅可比的稀疏度** | 每个观测只碰 $6+3=9$ 个参数 | 500 相机 / 10 万点 / 每点 5 次观测：密度 $2.97\times10^{-5}$（比稠密稀疏 **33,667 倍**）|
| **Schur 补** Schur complement | 点块 $H_{pp}$ 块对角 ⟹ 可逐点消掉，只解 $6n_c\times6n_c$ 的相机块 | 500 相机时加速 **$1.03\times10^{6}$** 倍。**精确，不是近似**（实测相对误差 $3.4\times10^{-14}$）· <em>点是「便宜」的、相机是「贵」的</em> |
| **LM 阻尼** Levenberg–Marquardt | $H$ 本身奇异（秩亏 7），所以必须加 $\lambda\,\mathrm{diag}(H)$ | 这不是可选的 —— Gauss-Newton 直接解会失败 |
| **gauge freedom** | 相似变换不改变任何重投影误差，所以解不唯一 | Hessian 的秩亏**恰好 7**，谱间隙 $6.5\times10^{12}$ |
| **gauge 零空间的解析构造** | 把群作用在参数上求导，得到 $150\times7$ 的 $G$ | $\Vert JQ\Vert_F/\Vert J\Vert_F = 2.3\times10^{-11}$，**且与条件数无关** |
| **数值判秩的两个陷阱** | ① 固定相对阈值在条件数大时失效；② 最大间隙在**满秩**时也存在 | ① 在有效 cond $\approx10^{11}$ 时报 13（错）；② 让「已固定 7 个」的满秩情形被报成秩亏 2 |
| **固定 gauge** | 固定 7 个自由度，或把 $H$ 投影到零空间的补上 | 只固定相机 0（6 个）→ 秩亏仍是 **1**（尺度自由）· **固定两个点的 6 个坐标 → 秩亏仍是 1**（绕两点连线的旋转）· 要用点固定需要**三个不共线的点** |
| **投影掉 gauge 后的条件数** | 「这次重建好不好解」的正确度量（gauge 无关）| $\propto (B/z)^{-2}$（小基线端实测指数 $-2.00$）· $B/z{=}1$ → $1.8\times10^{3}$；$B/z{=}0.0035$ → $6.0\times10^{8}$ |
| **纯旋转的悬崖** | $B/z = 0$ 时深度**不可观测**（不是测不准）| 条件数 $4.4\times10^{17}$（跳 9 个数量级）· **零空间从 7 涨到 npt + 6**（每点深度 + 全局旋转 3 + 平移 3；尺度被并进逐点深度里）|
| **$\sigma_z$ 与 cond 的关系** | $\mathrm{cond}(H)=\mathrm{cond}(J)^2$，而 $J$ 的最差方向 $\propto1/B$ | 三条独立推导对上：$\sigma_z\propto(B/z)^{-1}$、$\mathrm{cond}(H)\propto(B/z)^{-2}$、C72 的 $\sigma_z = z^2\sigma_d/(fB)$ |
| **两视图初始化** | 从哪一对开始；判据看 8 点法设计矩阵的 $\sigma_8/\sigma_9$ | $E$ 有 8 个自由度 ⟹ 零空间应**恰好 1 维** |
| **共面退化** planar degeneracy | 场景共面时 $E$ 只被确定到一个 **3 参数族** | $\sigma_8/\sigma_9 = 4.1$（vs 一般场景 $2.0\times10^{14}$）· **签名是「与噪声无关」**：0.2 px 与 1.0 px 噪声下 $E$ 的方向误差都是 3.15° |
| **前向运动** forward motion | 沿光轴前进时极点落在画面中心 | **$E$ 完全没问题**（$\sigma_8/\sigma_9 = 1.3\times10^{15}$）· 退化的是**三角化**：极点附近视线夹角 0.659° vs 外圈 4.93°（1/7.5）|
| **协方差的 gauge 依赖** | $\Sigma = \sigma^2(J^\top J)^{-1}$，而 $J^\top J$ 奇异 | 同一次重建报出 **1.65 倍**不同的点位不确定度，取决于固定了哪些参数。<em>只有 gauge 投影版可比</em> |
| **增量式漂移** drift | 朝向按 $\sqrt n$ 累积；尺度是**乘性**游走 | 每步 0.05°/±0.5%、200 步：朝向 0.71°、尺度 P5–P95 = 0.884–1.123 · **朝向被 180° 框住，尺度没有上界** |

## 三、稠密多视图立体（模块 02）

| 术语 | 一句话 | 本课的量 |
|---|---|---|
| **代价体** cost volume | $C[v][u][d]$：每像素每深度假设一个代价 | 1920×1080×256 = 5.31 亿体元 = **2.12 GB** fp32 |
| **平面扫掠** plane sweep | 假设场景在深度 $d$ 的平面上，把源图单应变换到参考视角 | 每个 $d$ 一次单应（C72 模块 03）|
| **coarse-to-fine** | 先低分辨率再逐级细化 | 降分辨率省 **8 倍**且深度精度不变（视差范围也减半 ⟹ $D$ 也减半）；降 $D$ 只省 2 倍且精度减半 |
| **视差域均匀采样** | 深度假设必须在**视差**上均匀，而不是在深度上 | 深度均匀 $D{=}64$：近场视差步长 **102.7 px**（等于没采样）· 视差均匀：恒为 2.640 px |
| **所需假设数** | $D = fB(1/z_{\min}-1/z_{\max})$（视差步长 ≤ 1 px）| 手持双目 168 · 车载双目 294 · **宽基线航拍 851** |
| **NCC** 归一化互相关 | $\mathrm{corr}$ of 去均值、归一化后的窗口 | 窗内方差为 0 时无定义 —— <strong>但真实数据永远有一点噪声，所以它不报 nan</strong> |
| **峰-次峰间隔** peak margin | 主峰与「排除主峰邻域后的次峰」之差；最有用的置信度 | rich **0.4692** · weak 0.0249 · periodic **0.0000**。<em>而三者的**峰值**都 > 0.99 —— 峰值没有区分力</em> |
| **弱纹理失效** | 间隔小 ⟹ 随噪声**渐进**失效 | $\sigma$ 0.01/0.05/0.2 → 失败率 0%/18%/**74%** |
| **周期纹理失效** | 有多个**完全等价**的解 ⟹ **与噪声无关**地失效 | 失败率 76%/74%/69%（σ 涨 20 倍不变）· 误差**恰好一个周期**（+16.000 px）|
| **无纹理区** | 最危险，因为它**不报错** | argmax 的标准差 **17.44**，而「均匀分布在 $[-30,30]$」的理论值是 **17.32** · $\vert$误差$\vert\le1$ px 的比例 6.7%（随机基线 3.3%）|
| **窗口大小的取舍** | 大窗对弱纹理有利、对倾斜不利。**没有通用答案** | slant=0 时弱纹理只有 win41 能用（0% vs win21 的 19%）；slant=0.1 时宽带纹理用 win41 **100% 失败**（win9/21 是 0%）|
| **视差梯度** disparity gradient | $\mathrm dd/\mathrm du = -(B/z)\tan\theta$ | 同一个梯度 0.3：窄基线（$B/z{=}0.05$）对应 80.5°；**宽基线（2.0）只对应 8.5°** |
| **视差梯度极限** disparity gradient limit | $\vert\mathrm dd/\mathrm du\vert = 1$（Burt & Julesz 1980）| 几何含义：表面与两条视线之一平行。**不是生理限制，是几何限制** |
| **斜面假设** slanted-plane / PatchMatch Stereo | 每像素的假设从「一个深度」换成「一个 3D 平面」 | 前平行假设整体消失 · **而它顺带修好周期歧义**（slant=0.3 + win41 时失败率从 85% 降到 1%）|
| **多视角聚合** | 多个源视图的代价聚合起来 | **不等基线的 2 个视图就把周期纹理从 71% 失败修到 0%** —— 因为「偏移一个周期」在各视图的视差坐标里对应**不同**的假设编号 |
| **聚合方式** | mean / median / **min（要求所有视图都同意）** | **min 最不稳健**：1/8 被遮挡就 28% 失败、2/8 时 59%；而 mean 在 4/8 时仍是 0% · 6/8 时 mean 24% < median 80% < min 95% |
| **WTA + 亚像素 + 置信度 + 左右一致性** | 从代价体到深度图的四步 | 亚像素有 **pixel-locking** 偏置；「标成无效比给一个错的深度好」|
| **左右一致性检验** | $\vert d_L(u) - d_R(u-d_L(u))\vert < \tau$ | **精确定位遮挡**（不通过的正是被挡住的 5 个左像素）· 而**周期错误通不过检测**（两侧一致地错，通过率 95.8%）|

## 四、前馈回归（模块 03）

| 术语 | 一句话 | 本课的量 |
|---|---|---|
| **相对深度 / 仿射不变视差 / 度量深度** | 单目模型的三种输出，含义完全不同 | 第三种「米」来自训练分布的统计，跨域会**整体缩放错**而图看起来合理 |
| **对齐域** alignment domain | 视差域 / 深度域 / 对数深度域 | 「视差域仿射完美」的预测器：视差域+仿射 AbsRel **0.003**；深度域+仿射 0.128（**42 倍**）|
| **规则：域必须匹配** | **对齐域必须与模型的不变性所在的域一致** | 对称地验了两个方向：深度域仿射完美的预测器反过来 —— 深度域+仿射 0.0003 vs 视差域+仿射 0.074（242 倍）· <em>所以评测协议**不能独立于模型来定**</em> |
| **对齐自由度** | 1（尺度）/ 2（仿射）/ 0（不对齐）| 位移 $b{=}0.42$ 时尺度对齐差 **108 倍**；$b{=}0$ 时两者等价 |
| **逐图 vs 全局对齐** | 每张图单独拟合，还是全数据集共享一组 | 逐图仿射 0.0028 vs 全局仿射 0.427（**154 倍**）· <em>而当所有图共享同一组 $(a,b)$ 时全局对齐几乎不吃亏 —— 差距来自「每图尺度不同」这个事实</em> |
| **为什么是仿射而不是尺度** | 混合数据集的标注定义不一致 + 深度的无界性（$z\to\infty$ 时视差 $\to 0$）| 两件事同时逼出「预测视差 + 仿射不变损失」 |
| **AbsRel / $\delta<1.25$ / RMSE-log** | 三个指标对**同一种**错误的反应不同 | 「5% 的像素错得离谱」：AbsRel（中位）几乎不动而 $\delta$ 掉下来 · 「8% 系统偏置」：AbsRel 明确而 $\delta<1.25$ **仍是 1.0000** |
| **点图** pointmap | 每像素对应一个 3D 点，且两张图共一个坐标系 | **焦距精确可解**（$1.9\times10^{-16}$）—— 所以内参被**输出**而不是被**输入** |
| **过参数化** | 点图 $3HW$ 个自由度 vs 需要的 $HW+1$ | 恰好 **3.00×** · 后果：一致性必须靠网络自己保证（深度图的冗余是 1.00×，**不可能**不自洽）|
| **射线一致性检验** | 从点图解出 $f$，再把点投影回它自己的射线上 | **不需要真值**，所以它是前馈方法最便宜的自检 · 自洽点图残差 $10^{-14}$，破坏 0.01 后 > 0.5 px |
| **全局对齐** global alignment | 把 $N$ 张图的两两点图拼成一个模型 | **秩亏恰好 7 —— 它就是一次束调整** · <em>我第一版写成 13，多出来的 6 立刻定位到「相机 4 从未出现在任何残差里」</em> |
| **pose-free 的真实含义** | 不是取消 SfM，而是换了它的**位置** | 从「必须先做对」变成「用来收尾，且初值很好」|
| **输出表示的四种选择** | 相对深度 / 度量深度 / 点图 / 直接出高斯 | 冗余 1.00× / 1.00× / 3.00× / > 14×。**冗余越大，网络要自己学会的一致性越多** |

## 五、3D 生成（模块 04）

| 术语 | 一句话 | 本课的量 |
|---|---|---|
| **SDS** Score Distillation Sampling | 用一个 2D 扩散先验去「雕」一个 3D 表示 | 梯度里**扔掉了 U-Net 的雅可比** —— 于是它不是在最小化扩散损失，而是在做**平滑后密度的梯度上升** |
| **$-\epsilon$ 项** | 期望为零，所以可以去掉 | 两个估计量之差恰好是 $-\frac1n\sum w\alpha_t\epsilon$，**完全不含 $x$**（6 个 $x$ 处逐位相同，标准差 $1.7\times10^{-17}$）|
| **它是控制变量吗** | **只在特定条件下** | 逐 $t$ 反转：$t{=}0.05$ 时含它的方差是不含的 **391 倍**；$t{=}0.95$ 时只有 **1/1533** · 净效应还依赖 $x$（模式附近好 1.65×、两模式之间差 0.57×）|
| **模式寻求** mode-seeking | SDS 的解是**不动点**，不是样本 | 精确梯度下模式内散布 **严格为 0**（$3.5\times10^{-15}$）；随机版 0.0431（先验 0.35，收缩 **8.1 倍**）|
| **模式内移** | SDS 找的是「对 $t$ 平均后的 $p_t$」的模式，而平滑把模式拉近 | 吸引子在 **±1.5663** vs 真模式 ±2.0 —— **内移 21.7%** · 实践后果：细长变短粗、尖锐变圆滑、该分开的粘一起 |
| **次模式的消失** | 先验不均衡时，少数模式**不再是吸引子** | $\pi{=}(0.7,0.3)$ → SDS 给 54.4%/45.6%（压向 50/50）· **$\pi{=}(0.9,0.1)$ → 只剩一个吸引子，SDS 给 100%/0%** |
| **CFG** classifier-free guidance | 把 score 沿「条件 − 无条件」方向外推 | **两个效应必须分开量** |
| **CFG 效应①（幅度）** | $\max\vert g\vert$ 随 cfg 近线性增长 | cfg 1→100：0.994 → 65.475（**66 倍**）· 稳定 $lr$ 上界从 12.2 掉到 0.103（118 倍）|
| **CFG 效应②（形状）** | 它**抵消**模式内移，而会过冲 | cfg 1 → ±1.5663（内移 21.7%）· **cfg≈3 恰好抵消（±2.0530）** · cfg=100 → ±2.3594（**外移 18%**，跑到数据分布之外 = 过饱和的机制）|
| **$w(t)$ 的选择** | $\sigma_t^2$（DreamFusion）/ 1 / SNR / $1/\sigma_t^2$ | 吸引子 ±1.5663 / ±1.8739 / **±1.9974** / ±1.9919 · <em>SNR 加权几乎消除内移，但低噪处梯度信息量最小 ⟹ 真实场景里几乎不动。这是取舍不是「更好」</em> |
| **$t$ 的采样范围** | 关键在「是否包含小 $t$」，而不是上界多大 | $[0.02,0.30]$ → 内移 0.0% · **$[0.50,0.98]$ → 只剩一个位于 0 的吸引子（两模式合并）** · 这就是「早期一团糊」的精确含义 |
| **两个旋钮不独立** | $t_{\max}$ 与 cfg 都在抵消同一个内移 ⟹ 同时开满会过冲 | $t_{\max}{=}0.98$ 时 cfg 1→100 跨 39.7 个百分点；$t_{\max}{=}0.20$ 时 cfg=1 已经无偏，再加 cfg=100 只带来 **+4.8% 的纯过冲** |
| **Janus 问题** | 正反两面都是正面 | **它是逐视角独立目标的严格最优解**（$1.0{+}1.0 = 2.0 > 1.0{+}0.2 = 1.2$）· 视角越多优势越大（0.8/1.6/2.4/4.0）|
| **Janus 的两种修法** | ① 视角条件化；② 联合多视角先验 | ① 把 back_pref 提到 front_pref 以上（**仍是逐视角独立**）· ② 一致性奖励 $\ge$ (front−back)×(n−1)（**改了先验的联合结构**，所以更彻底）|
| **VSD** ProlificDreamer | 把「找模式」改回「采样」（目标是两个分布的 KL）| 所以它不需要 cfg=100 去抵消内移 · 代价是要同时训练一个辅助模型 |

## 六、网格化与评测（模块 05）

| 术语 | 一句话 | 本课的量 |
|---|---|---|
| **Marching Cubes** | 逐体素单元把符号场变成三角网格 | $2^8 = 256$ 种配置 → **23 类**（仅旋转）→ **15 类**（加内外反演）· <em>轨道大小之和 = 256，且每个都整除群阶 48</em> |
| **面歧义** face ambiguity | 某面的两个对角顶点同号、另两个同号且两对反号 ⟹ 两种连法 | **120/256 = 46.9%** 的配置含歧义（**6** 个等价类）· 后果是相邻体素对共享面做出不一致选择 → **裂缝** |
| **一致的查表 / Dual Contouring** | 两类修法 | Marching Cubes 33、asymptotic decider、Lewiner 变体（skimage 用的就是这个，所以输出水密）|
| **补洞的代价** | 能出水密网格，但补出来的部分不对应任何观测 | 它在 **completeness 上「白拿分」** |
| **TSDF** truncated signed distance field | 只存 $\vert\text{sdf}\vert<\tau$ 的体素 | 占用率恰好 **$12r/L$**（表面积 $2L^2$、$\tau{=}3r$）· **分辨率越高越稀疏**：8 m / 5 mm 时只有 0.75%（稠密 16 GB vs 稀疏 0.12 GB）|
| **截断距离 $\tau$** | 它决定能融合多大的观测冲突 | 相差 $>2\tau$ 的两个观测形成**两个**零等值面（**双层墙**）· <em>而 200 步轨迹的 12% 尺度漂移在 8 m 处是 1 m —— 远超任何合理的 $\tau$。所以双层墙几乎总是位姿问题</em> |
| **泊松重建** Poisson reconstruction | 求指示函数 $\chi$ 使 $\nabla\chi$ 匹配点云法向场 | 全局求解 ⟹ 天然水密、平滑、能补小洞 |
| **法向的角度误差** | 位置误差 $\approx R\tan\theta$，**与 patch 尺度成正比** | $R{=}0.20$ m、错 15° → **53.6 mm** · 所以小尺度无害、大尺度致命（对应「局部干净、整体鼓起」）|
| **法向定向** normal orientation | 法向估计给出的是**无向**方向；朝向要单独确定 | 净通量 $= 1-2f$，**线性**下降；50% 反向时**归零** ⟹ 泊松解退化 · <em>这也是 2DGS 对几何重建有价值的原因：它的法向是显式参数且朝向唯一确定</em> |
| **Chamfer 距离** CD | 双向最近邻距离的均值之和 | 对称 ✓、非负 ✓、$\mathrm{CD}(A,A){=}0$ ✓、**三角不等式 ✗** |
| **CD 不是度量** | 反例：$A{=}\{0\}$、$B{=}\{0,10\}$、$C{=}\{10\}$ | $\mathrm{CD}(A,C) = 20 > 5+5$（**超出 2 倍**）· 后果：「CD 差 0.1」**没有传递性**，不能在它上面做聚类/检索/三角不等式剪枝 |
| **CD-L1 vs CD-L2** | 一个离群点的贡献是 $(d{-}1)/n$ 还是 $(d{-}1)^2/n$ | 50 倍半径的**一个**离群点：L1 涨 **1.31×**、L2 涨 **293×** · <em>理论增量与实测精确吻合（<2e-4）</em> · 而 F-score 只变 0.03% |
| **采样密度的影响** | CD 依赖点数，而几何没变 | 同一球面 200 → 8000 点：CD-L1 从 0.17433 到 0.06041（**2.9 倍**）· 所以比较前必须重采样到同一密度 |
| **F-score @ $\tau$** | 落在阈值内的比例的调和平均；**计数**指标 | 只依赖 $\tau/s$：F@$s$ 在五个密度下都是 0.52–0.55、F@$2s$ 都是 0.94–0.96、F@$5s$ 都是 1.0000 · <em>而固定的 F@0.02 跨密度差 81 倍</em> |
| **accuracy（precision）** | 预测点中落在真值 $\tau$ 内的比例 | 「多出一半」时它掉到 0.353 |
| **completeness（recall）** | 真值点中被预测覆盖的比例 | 「缺一半」时它掉到 0.4685 |
| **为什么必须分开报** | 「缺一半」与「多出一半」的 CD 几乎相同（0.329 vs 0.312）而含义相反 | 而修法完全不同：completeness 低 → 观测不足 / 阈值太严；accuracy 低 → 离群点 / 浮物 / 补洞 |
